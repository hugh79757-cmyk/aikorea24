Claude Fable 5는 현재 가장 강력한 공개 AI 모델이지만, 요금 구조가 이전 모델보다 크게 복잡해졌습니다. API 기준 입력 토큰당 10달러(약 1만 4천 원)로 Claude Opus 4.8의 두 배이며, 6월 23일 이후에는 구독 플랜에서도 크레딧이 소진되면 접근이 제한됩니다. 기업 도입을 검토하거나 개인 플랜을 선택하려는 분들이 놓치기 쉬운 세부 사항들을 정리합니다.

[관련 기사보기](https://aikorea24.kr/briefing/2026-06-11/#item-1)

Claude Fable 5와 Claude Mythos 5는 동일한 가격으로 제공됩니다. 아래는 API 기준 요금입니다.

## API 기준 토큰 요금 구조



**Claude Fable 5 및 Mythos 5**

입력 토큰(Base Input): 100만 토큰당 10달러(약 1만 4천 원)

출력 토큰(Output): 100만 토큰당 50달러(약 7만 원)

5분 캐시 쓰기(5m Cache Writes): 100만 토큰당 12.5달러

1시간 캐시 쓰기(1h Cache Writes): 100만 토큰당 20달러

캐시 히트 및 갱신(Cache Hits and Refreshes): 100만 토큰당 1달러

**Claude Opus 4.8 비교**

입력 토큰: 100만 토큰당 5달러

출력 토큰: 100만 토큰당 25달러

Fable 5는 Opus 4.8 대비 정확히 두 배 가격입니다. 앤트로픽은 이전 최고가 모델인 Claude Mythos Preview보다는 절반 이하 가격이라고 설명하고 있습니다.

## 구독 플랜별 접근 방식과 변경 사항

Claude.ai 구독 플랜(Pro, Max, Team, 시트 기반 Enterprise)에서는 별도의 단계적 출시 일정이 적용됩니다.

**6월 22일까지**: Fable 5 사용 시 Opus 4.8의 2배 사용량으로 차감됩니다. 추가 비용은 없습니다.

**6월 23일부터**: 크레딧 구매가 필요합니다. 앤트로픽은 향후 용량이 확보되면 정규 구독 플랜에 Fable 5를 다시 포함할 예정이라고 밝혔습니다.

실제 사용자 보고에 따르면 Max 플랜(월 200달러, 약 28만 원) 기준으로도 단일 세션에서 5시간 사용 한도를 모두 소진하는 경우가 발생했습니다. 하나의 프롬프트로 Pro 플랜 한도 전체가 소진된 사례도 있었습니다. 복잡한 코딩 또는 분석 작업을 대량으로 진행한다면 예상보다 빠르게 한도에 도달할 수 있습니다.

## 기업 사용자가 반드시 확인해야 할 사항

**30일 데이터 보관 정책 변경**

Mythos 클래스 모델 전체에 새로운 30일 데이터 보관 정책이 적용됩니다. 주목할 점은 **제로 데이터 리텐션(Zero Data Retention, ZDR) 계약을 체결한 기업에도 동일하게 적용된다**는 것입니다. ZDR 계약은 데이터가 서버에 저장되지 않는다는 것을 보장하는 계약으로, 의료, 법률, 금융 분야 기업들이 주로 요구합니다. 앤트로픽은 이 정책이 새로운 공격 방식을 탐지하기 위한 보안 목적이라고 설명하고 있습니다. 데이터 보안 요건이 엄격한 기업이라면 도입 전 법무팀 검토가 필요합니다.

**사용량 기반 Enterprise 플랜**

API 및 사용량 기반 Enterprise 플랜에서는 현재 즉시 사용 가능합니다. 시트 기반 Enterprise 플랜은 위에서 설명한 단계적 출시 일정을 따릅니다.

**안전 필터로 인한 Opus 4.8 자동 전환**

사이버 보안, 생물학, 화학, 모델 디스틸레이션(distillation, 기존 모델의 능력을 복제하는 작업) 관련 요청은 자동으로 Opus 4.8로 전환되거나 차단됩니다. Messages API에서는 기본적으로 요청이 차단되며, 개발자가 서버 측 폴백(fallback, 대체 처리)을 별도로 활성화해야 합니다. 이 필터가 전체 요청의 약 9%에 영향을 미친다는 점을 감안해 업무 적합성을 사전에 검토하시기 바랍니다.

## 실제 비용이 어느 수준인가

한 개발자의 사례가 참고가 됩니다. Claude.ai Max 플랜(월 200달러)에서 API 기반 Enterprise 청구 방식으로 전환한 뒤, 동일한 사용량 기준으로 Opus 4.8 비용이 월 200달러에서 1만 달러(약 1,400만 원)로 늘었습니다. Fable 5를 같은 수준으로 사용하면 약 2만 달러(약 2,800만 원)가 됩니다.

이 수치는 특수한 고사용량 사례이지만, 아직 토큰 소비량 대비 작업 완료율이 체계적으로 검증되지 않은 상황에서 기업 도입 시 초기 예산 계획을 보수적으로 잡을 필요가 있습니다.

## Fable 5 요금 선택 가이드

Fable 5를 어느 방식으로 접근할지는 사용 목적에 따라 다릅니다.

가끔 사용하거나 체험 목적이라면 6월 22일까지는 기존 Pro 또는 Max 플랜에서 추가 비용 없이 사용 가능합니다. 단, 사용량이 빠르게 소진될 수 있으므로 복잡한 작업은 나눠서 진행하는 것이 좋습니다.

코딩이나 분석 작업을 대량으로 처리하는 개발자나 팀이라면 API 기반 Enterprise 플랜에서 토큰 단가를 직접 계산한 뒤 도입 여부를 결정하는 것이 합리적입니다.

데이터 보안 요건이 있는 기업이라면 30일 데이터 보관 정책의 적용 범위를 법무팀 또는 보안팀과 검토한 후 도입을 결정하시기 바랍니다.

가장 강력한 성능이 필요한 작업에만 선택적으로 Fable 5를 쓰고 일반 업무는 Opus 4.8 또는 더 저렴한 모델로 처리하는 하이브리드 방식이 현재로서는 비용 효율적인 접근입니다.
