2026년 9월 8일(현지 시각) **오픈AI**는 세계 7대 수학 난제인 **나비에-스토크스 존재성과 매끄러움 문제**를 자사의 비공개 내부 모델로 해결했다고 공식 발표했습니다. 이는 2000년 클레이수학연구소가 상금 100만 달러를 걸고 지정한 밀레니엄 문제 중 그리고리 페렐만이 푸앵카레 추측을 해결한 2003년 이후 약 23년 만에 나온 두 번째 해결 사례이자, 사상 최초로 인공지능이 풀어낸 밀레니엄 난제라는 점에서 학계와 산업계의 비상한 관심을 모으고 있습니다.

다만 이번 발표가 곧 공식 인증으로 이어지는 것은 아닙니다. 가디언지도 "수십 년간 인류를 괴롭힌 문제를 해결했다고 주장했다"고 보도했듯, 밀레니엄 문제의 공식 해결 인정은 클레이수학연구소의 검증 절차를 거쳐야 하며, 오픈AI는 상금을 청구하지 않겠다고 밝힌 상태입니다. 동시에 발표 직후 공로 배분을 둘러싼 수학자들의 공개 논란이 벌어져, 기술적 성취와 윤리적 쟁점이 동시에 조명되고 있습니다.

발표 원문은 [오픈AI 공식 블로그](https://openai.com/index/navier-stokes-solution/)에서, 난제의 공식 설명은 [클레이수학연구소 밀레니엄 문제 페이지](https://www.claymath.org/millennium-problems/)에서 확인할 수 있습니다.

## 나비에스토크스 난제의 의미와 AI가 내놓은 결론

나비에-스토크스 방정식은 유체의 움직임을 기술하는 대표적 편미분방정식으로, 일기예보부터 비행기 날개 설계, 혈류 시뮬레이션까지 실용적 활용이 무궁무진한 도구입니다. 그런데 정작 방정식 자체의 근본적 질문은 지난 90년 동안 풀리지 않았습니다. 3차원 공간에서 유체의 흐름이 영원히 매끄럽게 유지되는지, 아니면 유한한 시간 안에 속도가 무한대로 발산하는 특이점인 블로업(blowup)이 발생하는지가 밀레니엄 문제가 묻는 핵심입니다.

오픈AI 모델이 내놓은 결론은 **매끄러운 흐름이 유한한 시간 안에 무너질 수 있다**는 것입니다. 소용돌이가 조여들면서 특이점이 형성되는 방향의 해가 존재함을 보임으로써, 존재성과 매끄러움에 관한 난제에 하나의 답을 제시한 셈입니다. 가디언지는 오픈AI의 증명이 "방정식이 종종 블로업하며 유체 속도가 불가능할 정도로 무한해질 수 있음을 시사한다"고 전했습니다.

| 구분       | 내용                                           |
| -------- | -------------------------------------------- |
| 문제 지정    | 2000년 클레이수학연구소 밀레니엄 문제 7건 중 하나               |
| 핵심 질문    | 3차원 유체 흐름이 항상 매끄러운가, 유한 시간 내 특이점(블로업)이 발생하는가 |
| 오픈AI 결론  | 매끄러운 흐름이 유한 시간 안에 무너질 수 있음                   |
| 이전 해결 사례 | 푸앵카레 추측(2003년 페렐만 해결, 상금 거부)                 |
| 상금       | 100만 달러, 오픈AI는 청구하지 않겠다고 밝힘                  |

이 성과는 AI가 수학 난제 영역에 본격적으로 진입했다는 신호로 읽힙니다. 오픈AI는 올해 5월에도 80년 전 제기된 수학 문제에서 진전을 이뤘다고 발표했고, 구글 딥마인드 역시 국제수학올림피아드 문제를 은메달 수준으로 푸는 성과를 공개한 바 있어, 대형 AI 기업들의 수학 분야 경쟁이 가속화되는 흐름 속에 이번 발표가 자리합니다.

## 1만 개 에이전트 88시간 프로젝트 규모와 Lean 증명 방식

이번 프로젝트에는 오픈AI가 보유한 최신 모델 **GPT-6 아스트라보다 상위 버전**으로 알려진 비공개 내부 모델이 투입되었습니다. 약 1만 개의 AI 에이전트를 병렬로 가동해 88시간 만에 해법에 도달했으며, 발표에 따르면 이 과정에서 약 1,300억 개의 출력 토큰이 소비되었습니다. 1,300억 토큰은 일반적인 소설책 수십만 권에 달하는 분량으로, 사람이 읽기보다 기계가 생성하고 검증하도록 설계된 규모의 연산입니다.

결과물은 165쪽 분량의 논문과 함께 제출됐고, 수학적 오류를 방지하기 위해 **Lean 정리 증명 언어**로 기계적 형식 검증까지 마쳤습니다. Lean은 논리의 모든 단계를 컴퓨터가 확인하는 도구로, 사람이 눈으로 검산하던 기존 방식을 넘어 논리적 무결성을 기계가 직접 보증하는 현대적 증명 절차입니다. 가디언지에 따르면 해당 해법의 검증 작업에는 GPT-6 아스트라가 약 17시간을 소요했습니다.

| 항목      | 수치                        |
| ------- | ------------------------- |
| 투입 모델   | GPT-6 아스트라보다 상위 비공개 내부 모델 |
| AI 에이전트 | 약 10,000개 병렬 가동           |
| 소요 시간   | 88시간                      |
| 출력 토큰   | 약 1,300억 개                |
| 증명 분량   | 165쪽 논문                   |
| 형식 검증   | Lean 프로젝트로 완료             |
| 검증 소요   | GPT-6 아스트라 약 17시간         |

오픈AI는 발표문에서 이 프로젝트를 시작한 계기가 "두 개의 밀레니엄 문제가 해결됐다는 소문을 들었기 때문"이라고 밝혔습니다. 이 소문은 실제로 버크마스터와 알푀게의 연구 진행 상황과 연결되는 부분으로, 발표의 기술적 성취 이면에 논란의 씨앗이 있었음을 보여줍니다.

## 버크마스터 오픈AI 공로 논란 쟁점 정리

증명 자체는 Lean으로 검증됐지만, 연구 경위와 공로를 두고는 팽팽한 대립이 이어지고 있습니다. 상대는 뉴욕대(NYU) 수학과의 **트리스탄 버크마스터 교수**와 AI 기업 앤트로픽 소속 연구자 **르벤트 알푀게**입니다. 두 사람은 기관과 무관한 개인 공동연구로, 매끄러운 외력이 작용하는 조건에서 다공성 매질과 부시네스크, 3차원 비압축성 오일러 방정식의 해가 유한 시간 안에 발산함을 증명했고, 8월 22일 Lean 검증까지 마친 상태였습니다.

경과를 시간순으로 정리하면 다음과 같습니다. 버크마스터는 9월 3일 자신들의 연구 진행 상황이 오픈AI에 전달됐다는 소문을 듣고 오픈AI 수학자에게 이메일을 보냈고, 9월 6일 오픈AI의 세바스찬 뷰벡 등과 통화에서 내부 모델이 나비에-스토크스 해법을 만들었다는 설명을 들었습니다. 그리고 이틀 뒤인 9월 8일 오픈AI가 공식 발표에 나선 것입니다.

| 시점     | 경과                            |
| ------ | ----------------------------- |
| 8월 15일 | 버크마스터·알푀게, 부시네스크·오일러 문제 중요 진전 |
| 8월 22일 | 두 사람의 증명 Lean 검증 완료           |
| 9월 3일  | 버크마스터, 연구 경위 소문 듣고 오픈AI에 이메일  |
| 9월 6일  | 뷰벡 등과 통화, 내부 모델 해법 설명 청취      |
| 9월 8일  | 오픈AI 공식 발표, 버크마스터 성명 공개       |

버크마스터의 주장은 세 가지로 압축됩니다. 첫째, 통화에서 자신들이 먼저 오일러 결과를 발표하고 다음 날 오픈AI가 나비에-스토크스를 발표하거나, 자신이 오픈AI 모델의 결과를 논문으로 정리하는 방식의 제안을 받았는데, 후자와 관련해 뷰벡이 앤트로픽 소속인 알푀게를 공저자에서 제외하라고 두 차례 요구했다는 것입니다. 둘째, 협의 경위를 공개하겠다고 하자 경력을 거론하는 압박성 발언을 들었다고 주장합니다. 셋째, 자신들의 연구 초안을 입력했던 코덱스(Codex) 세션이 모델 학습에 사용됐는지 물었지만 사용자 데이터 조회 없다는 답만 받고 학습 여부에 대한 답은 듣지 못했다고 밝혔습니다.

오픈AI 측 반박도 만만치 않습니다. 뷰벡는 기자간담회에서 두 사람의 연구를 사용했거나 오픈AI 서버에 공유된 자료에 접근했다는 의혹을 부인했고, 오픈AI는 연구진과 에이전트가 공개 전 상대 연구를 보지 않았으며 특정 사용자 데이터에 접근하지 않았다고 설명했습니다. 또한 두 사람의 오일러 연구 선행 성과를 인정하고 동시 공개와 공동 발표를 제안했다고 밝혔습니다. 다만 제품 사용에서 나온 비식별 데이터가 모델 개선에 기여했을 가능성은 낮지만 배제할 수 없다는 점은 스스로 인정했는데, 데이터 오염 가능성을 완전히 닫지 못한 셈입니다.

| 쟁점       | 버크마스터 측 주장                | 오픈AI 측 입장                                |
| -------- | ------------------------- | ---------------------------------------- |
| 연구 반영 여부 | 경쟁하는 접근법을 모델이 사용했을 가능성 제기 | 연구진·에이전트는 공개 전 연구를 보지 않았다고 부인            |
| 데이터 접근   | 코덱스 세션의 학습 여부 질문에 답을 못 받음 | 특정 사용자 데이터 미접근, 비식별 데이터 기여 가능성은 배제 불가 명시 |
| 공저자 구성   | 뷰벡이 알푀게(앤트로픽) 제외를 두 차례 요구 | 두 연구자의 선행 성과 인정, 동시 공개·공동 발표 제안          |

주목할 점은 버크마스터 본인이 성명에서 견지한 신중함입니다. 그는 "오픈AI의 증명을 보지 못했고, 우리 데이터가 사용됐는지도 모른다. 누구를 고발하는 것이 아니다"라고 명시하며, 자신의 문서가 연구 도용을 입증하는 것이 아니라 협의 경위와 문제의식을 기록한 것임을 분명히 했습니다. 즉 이 논란은 도용의 입증이 아니라 **공동 연구자 배제 요구와 데이터 사용 투명성**이라는 윤리적 쟁점에 초점이 맞춰져 있습니다.

## 판단 전 챙겨야 할 준비 사항

- **원문 확인 먼저**: 언론 요약이 아닌 [오픈AI 공식 블로그 발표문](https://openai.com/index/navier-stokes-solution/)과 165쪽 논문, Lean 프로젝트를 직접 확인하세요. 형식 검증 통과 여부가 이번 성과의 기술적 근거입니다.
- **주장과 인증의 구분**: 밀레니엄 문제의 공식 해결은 클레이수학연구소의 심사를 거쳐야 합니다. 현재 상태는 오픈AI의 발표와 주장 단계이며, 오픈AI는 100만 달러 상금을 청구하지 않겠다고 밝혔다는 점도 참고하세요.
- **논란의 성격 파악**: 버크마스터 성명은 도용 입장이 아니라 협의 경위 기록입니다. 양측 주장이 모두 공개된 상태이므어 일방적 결론을 내리기 전에 두 성명을 모두 읽어보시기 바랍니다.
- **데이터 오염 쟁점 추적**: 오픈AI가 "비식별 데이터가 모델 개선에 기여했을 가능성을 배제할 수 없다"고 인정한 부분은 AI 연구의 데이터 투명성 문제를 상징합니다. 후속 조사와 학계 검증 동향을 지속적으로 확인하세요.
- **AI 증명의 검증 체계 이해**: Lean 형식 검증은 논리적 무결성을 보증하지만, 사람이 읽을 수 있는 논문 정리와 학계 공동 검토는 별개 절차입니다. 버크마스터도 형식 검증만으로는 부족하고 읽을 수 있는 논문이 함께 공개돼야 한다고 강조했습니다.
- **후속 발표 지켜보기**: 이번 증명의 학계 반응과 클레이수학연구소의 공식 입장은 아직 나오지 않았습니다. 관련 수학자들의 후속 논평과 재검증 시도는 향후 수개월간 이어질 것으로 보입니다.

## 마무리 - 기술적 성취와 윤리적 과제를 남긴 발표
