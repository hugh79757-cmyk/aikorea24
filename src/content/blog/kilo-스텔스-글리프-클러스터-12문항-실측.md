킬로 스텔스 글리프 클러스터(free)는 OpenCode CLI에서 호출되는 추론 모델로, 코딩 실무 항목에서는 강점을 보였으나 긴 문맥 유지와 일부 형식 지침 준수에서는 한계가 있었습니다. 12문항 실측 결과 9점(11문항 응답, 1문항 미응답), 니들 컨텍스트 실측 하한은 8,192 토큰입니다.

킬로 스텔스 글리프 클러스터는 2026-10-07 외부에 공개된 Vercel AI Gateway 스텔스 추론 모델로, Kilo 경로에서는 "Stealth: Glyph Cluster (free)" 표시명으로 제공됩니다. 외부 공지에 따르면 256K 토큰 컨텍스트, 스트리밍 및 함수 호출을 지원하며 스텔스 기간 동안 무료(계정당 하루 100건 쿼터)라고 안내되지만, 제작사는 스텔스 기간을 비공개로 두고 있어 종료·변경 가능성이 있습니다. 이 글은 외부 공지 수치를 그대로 받아들이지 않고, OpenCode CLI로 직접 호출해 측정한 사실만 기록합니다.

## 측정 방법

OpenCode CLI([opencode.ai](https://opencode.ai)) 단일 경로로 12문항을 순차적으로 출제하고, 결정적 채점 함수(규칙 기반 채점)로 문항당 0/1점을 매겼습니다. LLM 판관은 사용하지 않았습니다(지시서 JUDGE-04 폐지). 문항 구성은 지시이행 2, 코딩실무 4, 맥락유지 2, 에이전트 4입니다. 1차 타임아웃 60초, 실패 시 180초로 1회 재시도했으며 그래도 답이 없으면 미응답으로 기록했습니다. 토큰 사용량은 CLI 경유로 측정되지 않으므로 미측정입니다.

## 12문항 평가 결과

| 항목 | 점수 | 비고 |
| --- | --- | --- |
| 지시이행 | 1 / 2 | Q1 한국어 지침은 내용상 맞으나 채점기 오탐으로 0점 |
| 코딩실무 | 4 / 4 | 버그 수정·테스트 작성·리팩토링·명세 구현 모두 통과 |
| 맥락유지 | 1 / 2 | Q7 긴 문서 내 함수 이름 찾기 미응답(0점), Q8 대화 기억 1점 |
| 에이전트 | 3 / 4 | PR 코드 리뷰 항목, 루트 원인 분석, 우선순위 판단 통과; 4단계 계획 JSON 키 불일치로 0점 |
| **합계** | **9 / 12** | 11문항 응답, 1문항 미응답(분모에서 제외) |

모델 역할 판단: 판단 근거 부족 — 손발 작업으로 한정. 사용 수준: 코딩실무 코딩 우수, 에이전트 에이전트 실무 가능, 한글 한글 부분 가능.

0점 문항 세 가지는 서로 다른 성격입니다.
- Q1(지시이행): 답은 한국어로 작성해 마지막 줄에 "---끝---"을 붙였으나, 채점기가 인라인 코드 표시(`add`, `def` 등 영어 식별자)를 영어 단어로 오판해 0점을 줬습니다. 인라인 코드 표시를 제거해 재채점하면 1점이 나오는 점으로 미뤄 **채점기 오탐**입니다.
- Q7(맥락유지): "The stealth model could not complete the request" 메시지와 함께 빈 답을 반환해 **실제 미응답**입니다. 이는 8,192 토큰을 넘긴 긴 문서를 넣었을 때 문맥을 유지하지 못한 결과로 보입니다.
- Q11(에이전트): 4단계 계획을 JSON으로 답했으나 채점기가 요구하는 키(screen, state_model, verify)와 질문에서 제시한 키(단계, 제목, (1)(2)(3))가 달라 0점을 받았습니다. 점수는 그대로 두고, **질문-채점기 불일치**임을 기록합니다.

Q1 오탐을 보정하면 실제 점수는 10 / 12가 되지만, 파이프라인에 기록된 측정값은 9 / 12입니다.

## 니들 컨텍스트 실측

8,192 토큰짜리 문서에 첫 문장 비밀번호를 묻는 니들 프로브를 통과했으나, 16,384 토큰 문서에서는 비밀번호를 되받지 못했습니다. 지침에 따라 **통과한 마지막 단계를 실측 하한**으로 기록하면 **8,192 토큰**입니다. 16,384 토큰에서 실패했으므로 실제 한계는 8K~16K 사이이며, 외부 공지의 256K 컨텍스트 주장은 이 실측으로 검증되지 않았으므로 **미확인**으로 둡니다.

## 스텔스 모델 유의사항

이 모델은 스텔스 기간 중에 있으므로 다음의 점을 유의해야 합니다.

- 제작사가 스텔스 기간을 비공개로 둡니다. 무료라고 해서 영구 무료가 아니며, 종료되거나 변경될 수 있습니다.
- Zero Data Retention(ZDR)을 지원하지 않습니다. 프롬프트와 응답이 보관되어 학습에 쓰일 수 있다는 공지가 있으므로, 민감한 코드나 개인정보, API 키를 입력하지 마십시오.
- 외부 공지 수치(256K 컨텍스트 등)는 실측 결과와 다를 수 있으며, 실측으로 확인되지 않은 내용은 미확인으로 처리합니다.

## OpenCode에서 사용하는 방법

OpenCode CLI에서 직접 호출할 수 있습니다. 모델 ID는 `kilo/stealth/glyph-cluster`입니다. 모델 카탈로그는 [models.dev](https://models.dev)에서 확인할 수 있습니다.

```
opencode run -m kilo/stealth/glyph-cluster --format json
```

`:free` 접미사 주의: 외부 안내에 `:free` 접미사가 있는 경우가 있으나, 실제 CLI 호출에 사용한 ID는 위와 같이 접미사 없이 `kilo/stealth/glyph-cluster`입니다. 접미사를 붙이면 모델을 찾지 못할 수 있으니, `opencode models`로 실제 ID를 확인한 뒤 사용하십시오. OpenCode 모델 데이터는 [opencode.ai/data](https://opencode.ai/data)에서도 확인할 수 있습니다.

하루 쿼터(외부 공지 기준 계정당 100건, UTC 자정 리셋)가 있으므로 대량 평가는 피하고 필요한 문항만 추려 호출하십시오.

## 이런 분께 추천합니다

- 코드 버그 수정, 테스트 작성, 리팩토링 같은 실무 코딩 작업을 무료 모델로 처리하려는 개발자
- OpenCode CLI 환경에서 추가 비용 없이 추론 모델을 시도해 보려는 팀
- 문맥이 짧은 단일 질문·단답 위주로 모델을 쓰는 사용자

긴 문서 요약이나 8K를 넘는 문맥 의존 작업, 민감 코드 입력이 필요한 업무에는 적합하지 않습니다.

## 솔직한 한계

- 긴 문맥 유지: 8,192 토큰을 넘긴 문서에서 비밀번호 회상 테스트가 실패했습니다. 긴 리포트나 다수 파일을 한 번에 묻는 용도에는 한계가 있습니다.
- 형식 지침: JSON만 출력하라는 지침을 일부 문항에서 지켰으나 키 이름이나 구조가 질문과 채점기 기대와 다를 수 있습니다.
- 스텔스 모델 특성: 무료 기간과 사양이 언제든 바뀔 수 있으며, 측정 결과는 2026-10-28 시점의 것입니다.
- 측정 범위: 12문항 결정적 채점에 기반한 결과로, 전체 모델 성능을 대표하지 않습니다.
