**Cloudflare Workers Free 플랜**은 무료 계정임에도 연산, 데이터베이스, 스토리지, 메시지 큐까지 개발에 필요한 거의 모든 서비스를 제공하는 것이 특징입니다. 2026년 9월 현재 기준으로 무료 계정에서도 Workers, Pages, KV, D1, R2, Durable Objects, Queues, Hyperdrive, Workflows를 사용할 수 있어, 소규모 서비스라면 비용 없이 운영이 가능한 수준의 구성을 갖추고 있습니다.

다만 각 서비스마다 **무료 사용량 한도**가 존재하고, 그 기준이 서비스별로 다르다는 점을 정확히 알아야 합니다. 대부분의 한도는 매일 UTC 0시에 초기화되는 일일 한도이며, 한도를 초과하면 유료 플랜과 달리 추가 과금 없이 그날 남은 시간 동안 해당 작업이 오류를 반환하며 차단됩니다. 즉 예상치 못한 청구서를 맞을 걱정은 없지만, 서비스가 그날 하루 동안 멈출 수 있다는 점을 인식하고 설계해야 합니다.



UTC 0 시는 한국시간 기준으로 오전 9시입니다. 



공식 기준은 [Cloudflare Workers 요금 문서](https://developers.cloudflare.com/workers/platform/pricing/)와 [Workers 한도 문서](https://developers.cloudflare.com/workers/platform/limits/)에서 확인할 수 있으며, 이 글에서는 서비스별 무료 한도를 한눈에 정리합니다.

## Cloudflare Workers와 Pages 무료 한도

### Workers 연산 요청 한도

Workers 자체의 무료 한도는 **하루 10만 건의 요청**입니다. 이 한도는 정적 자산(static assets) 요청을 제외한 실제 Worker 실행 요청에 적용되며, 정적 자산에 대한 요청은 무제한이고 과금되지도 않습니다. 따라서 이미지나 HTML 같은 정적 파일을 Workers와 함께 서빙하는 구조라면 정적 파일 트래픽이 아무리 몰려도 요청 한도를 소모하지 않습니다.

CPU 시간은 **요청당 10밀리초**까지 무료로 제공되며, 이를 초과하면 오류가 발생합니다. 참고로 유료 플랜은 요청당 최대 5분(기본값 30초)까지 CPU 시간을 늘릴 수 있으므로, 무거운 연산이 필요한 워크로드라면 무료 플랜의 10밀리초 제한이 실질적인 병목이 됩니다. 로그 기능인 Workers Logs는 하루 20만 건의 로그 이벤트 기록이 무료이며 보관 기간은 3일입니다.

| 항목           | 무료 한도           | 비고                      |
| ------------ | --------------- | ----------------------- |
| 요청 수         | 하루 100,000건     | 정적 자산 요청 제외, 정적 자산은 무제한 |
| CPU 시간       | 요청당 10밀리초       | 초과 시 오류, 유료는 최대 5분      |
| Workers Logs | 하루 200,000건 이벤트 | 보관 3일                   |

### Pages 정적 호스팅 빌드 한도

Cloudflare Pages는 정적 호스팅 자체에는 요청 수나 대역폭 제한이 없다는 점이 가장 큰 매력입니다. 무료 정적 사이트의 숙명인 트래픽 초과 요금 걱정이 Pages에는 존재하지 않습니다. 대신 빌드와 파일 수에 제한이 걸려 있습니다.

한 번에 하나의 빌드만 동시 진행 가능하며 **월 500회의 빌드**가 무료로 제공됩니다. 빌드는 20분 안에 완료되지 않으면 타임아웃되므로, 대형 모노레포를 Pages로 배포한다면 빌드 시간 관리가 필요합니다. 사이트당 최대 2만 개의 파일까지 업로드할 수 있고 개별 파일 크기는 25MiB가 상한이며, 계정당 최대 100개의 Pages 프로젝트를 생성할 수 있습니다. Pages Functions(서버 사이드 로직)를 사용하면 그 요청은 Workers의 하루 10만 건 한도를 함께 소모한다는 점도 기억해야 합니다.

| 항목                 | 무료 한도                        |
| ------------------ | ---------------------------- |
| 정적 요청, 대역폭         | 제한 없음                        |
| 빌드                 | 월 500회, 동시 1개, 20분 타임아웃      |
| 파일 수               | 사이트당 20,000개, 개별 파일 최대 25MiB |
| 프로젝트 수             | 계정당 100개                     |
| Pages Functions 요청 | Workers 하루 100,000건 한도 공유    |

## KV D1 R2 스토리지 서비스 무료 한도

### Workers KV 키 값 스토리지

Workers KV는 하루 **읽기 10만 건, 쓰기 1,000건, 삭제 1,000건, 리스트 요청 1,000건**이 무료로 제공되며, 저장 데이터는 총 1GB까지 무료입니다. 쓰기와 삭제 한도가 읽기 한도보다 훨씬 낮다는 점이 실무에서 자주 걸리는 부분입니다. 읽기가 많고 쓰기가 드문 캐시 시나리오에는 잘 맞지만, 사용자 입력을 빈번히 저장하는 서비스라면 쓰기 1,000건 한도에 금방 도달할 수 있습니다.

주의할 점 하나는 **존재하지 않는 키를 조회해 null이 반환되는 경우도 한도 차감 대상**이라는 것입니다. 공식 문서에 명시된 내용으로, 캐시 미스가 많은 패턴에서는 실제 데이터보다 조회 횟수가 더 많이 집계될 수 있습니다. 조회 로직 설계 시 null 반환 경로까지 고려해야 합니다.

### D1 SQL 데이터베이스

D1은 하루 **500만 행 읽기(rows read), 10만 행 쓰기(rows written)**가 무료입니다. [D1 요금 문서](https://developers.cloudflare.com/d1/platform/pricing/)에 따르면 총 스토리지는 계정 전체 기준 5GB까지 무료이며, 데이터베이스 하나의 최대 크기는 500MB로 제한됩니다.

행 하나(문자열, BLOB 포함)의 최대 크기는 2MB, SQL 문 하나의 최대 길이는 100KB로 제한됩니다. 무료 5GB 스토리지를 여러 데이터베이스로 나눠 쓸 수 있으므로, 서비스별로 데이터베이스를 분리하는 설계도 가능합니다.

### R2 객체 스토리지

R2는 앞선 서비스들과 달리 **월 단위 무료 한도**를 제공하며, egress 즉 외부로의 데이터 전송 비용이 아예 없다는 점이 가장 큰 특징입니다. [R2 요금 문서](https://developers.cloudflare.com/r2/pricing/)에 따르면 어떤 스토리지 클래스든 인터넷으로의 egress는 완전히 무료이며 별도 청구되지 않습니다. 이미지나 동영상 같은 대용량 파일을 직접 서빙해도 다운로드 트래픽 요금이 발생하지 않는다는 뜻으로, S3 호환 스토리지 중 가장 파격적인 조건으로 평가됩니다.

월 10GB-month의 저장 공간이 무료이고, Class A 작업(쓰기, 목록 조회 등 상태를 변경하는 작업)은 월 100만 건, Class B 작업(읽기 등 조회 작업)은 월 1,000만 건까지 무료입니다.

| 서비스        | 읽기                 | 쓰기                   | 저장 공간                | 초기화 주기    |
| ---------- | ------------------ | -------------------- | -------------------- | --------- |
| Workers KV | 하루 100,000건        | 하루 1,000건, 삭제 1,000건 | 1GB                  | 매일 UTC 0시 |
| D1         | 하루 500만 행          | 하루 100,000행          | 계정 전체 5GB(DB당 500MB) | 매일 UTC 0시 |
| R2         | Class B 월 1,000만 건 | Class A 월 100만 건     | 월 10GB-month         | 매월 1일     |
| R2 egress  | 무제한 무료             | 해당 없음                | 해당 없음                | 과금 없음     |

## Durable Objects Queues Hyperdrive Workflows 무료 한도

### Durable Objects 상태 유지형 객체

Durable Objects는 2025년 4월부터 Workers Free 플랜에 포함됐습니다. [공식 변경 이력](https://developers.cloudflare.com/changelog/post/2025-04-07-durable-objects-free-tier/)에 따르면 Free 플랜에서도 실제 애플리케이션을 만들 수 있는 수준의 한도를 제공한다는 방침으로 무료化됐습니다.

요청은 하루 10만 건까지 무료이며 여기에는 HTTP 요청, RPC 세션, 웹소켓 메시지, 알람(alarm) 실행이 모두 포함됩니다. 컴퓨트 지속 시간(duration)은 하루 13,000 GB-초까지 무료이며, 이는 Durable Object가 활성 상태로 실행 중이거나 하이버네이션이 불가능한 상태로 대기 중일 때 소모됩니다. 내부 SQLite 스토리지 사용량은 D1과 동일한 기준으로 과금되어, 무료 플랜에서는 하루 500만 행 읽기, 10만 행 쓰기, 총 5GB 저장공간이 D1과 별도로 동일하게 적용됩니다. 무료 플랜에서는 SQLite 기반 Durable Object만 생성 가능하며, 구형 키-값 기반 스토리지는 유료 플랜 전용입니다.

### Queues 메시지 큐

Queues는 하루 **1만 건의 작업(operation)**이 무료입니다. 여기서 1 작업은 64KB 단위의 쓰기, 읽기, 삭제 각각을 의미하므로, 메시지 하나를 정상적으로 큐에 넣고 읽고 삭제하는 데 보통 3번의 작업이 소모됩니다. 즉 실질적인 무료 처리량은 하루 약 3,300여 개의 메시지라고 이해하면 됩니다.

메시지 보관 기간은 무료 플랜에서 24시간으로 고정되어 있고 설정 변경이 불가능합니다. 유료 플랜은 기본 4일에서 최대 14일까지 설정 가능하므로, 처리 지연에 대비한 버퍼가 필요한 시스템이라면 이 차이를 반영해야 합니다.

### Hyperdrive와 Workflows

Hyperdrive는 외부 데이터베이스 커넥션 풀링과 가속 서비스로, 하루 10만 건의 데이터베이스 쿼리가 무료로 제공됩니다. 쿼리 집계 범위에는 SELECT, INSERT, UPDATE, DELETE, DDL이 모두 포함됩니다. 유료 플랜에서는 이 제한이 사실상 무제한으로 풀립니다.

Workflows는 내구성 있는 실행 워크플로우 서비스로, 요청은 Workers 요청 한도와 공유되어 하루 10만 건이며 호출당 CPU 시간은 10밀리초로 제한됩니다. 저장 공간은 1GB, 스텝(step) 실행은 하루 3,000회까지 무료입니다.

| 서비스                    | 무료 한도                                | 초기화       |
| ---------------------- | ------------------------------------ | --------- |
| Durable Objects        | 요청 하루 100,000건, duration 13,000 GB-초 | 매일 UTC 0시 |
| Durable Objects SQLite | D1과 동일한 행 기준 적용                      | 매일 UTC 0시 |
| Queues                 | 하루 10,000 작업(약 3,300 메시지)            | 매일 UTC 0시 |
| Queues 보관 기간           | 24시간 고정                              | 설정 불가     |
| Hyperdrive             | 하루 100,000 쿼리                        | 매일 UTC 0시 |
| Workflows              | Workers 한도 공유, 스텝 하루 3,000회, 저장 1GB  | 매일 UTC 0시 |

## Vectorize Containers 무료 계정 제약과 공통 원칙

### 무료 계정에서 쓸 수 없는 서비스

모든 서비스가 무료로 열려 있는 것은 아닙니다. Containers는 무료 플랜에서 아예 제공되지 않아 문서상 Free 항목이 전부 이용 불가로 표기됩니다. 컨테이너 기반 배포가 필요하다면 최소 월 5달러의 Workers Paid 플랜에 가입해야 하며, 유료 플랜에서도 25GiB-시간의 메모리, 375 vCPU-분, 200GB-시간의 디스크가 매월 포함된 형태로 제공됩니다.

Vectorize는 벡터 검색 데이터베이스로 월 3,000만 개의 쿼리된 벡터 차원, 총 500만 개의 저장 벡터 차원이 무료 한도로 문서에 명시되어 있습니다. 다만 같은 문서에 Vectorize가 현재 Workers 유료 플랜에서만 이용 가능하다는 문구도 함께 있어, 무료 플랜에서 이 한도를 실제로 이용할 수 있는지는 계정 상태에 따라 다를 수 있는 것으로 보입니다. RAG나 추천 시스템 등 벡터 검색 도입을 검토 중이라면 실제 사용 전 대시보드에서 직접 확인할 것을 권장합니다.

| 서비스                | 무료 플랜 사용                            |
| ------------------ | ----------------------------------- |
| Containers         | 제공되지 않음, 유료 플랜부터 이용 가능              |
| Vectorize          | 한도는 명시되나 유료 플랜 전용 문구 병존, 대시보드 확인 필요 |
| 그 외 Workers 계열 서비스 | 무료 한도 내 이용 가능                       |

### 일일 한도와 월간 포함량의 구분

무료 티어 전체를 관통하는 공통 원칙은, Cloudflare가 **일일 한도와 월간 포함량을 서비스에 따라 다르게 적용**한다는 점입니다. Workers, KV, D1, Durable Objects, Queues, Hyperdrive, Workflows는 매일 UTC 0시에 초기화되는 일일 무료 한도 방식입니다. 한국 시간 기준으로는 매일 오전 9시에 한도가 리셋되므로, 트래픽이 몰리는 시간대와 한도 초기화 시점을 함께 고려하면 하루를 두 번처럼 활용할 수도 있습니다.

반면 R2와 Vectorize는 월 단위로 초기화되는 무료 한도 방식을 사용합니다. 스토리지 용량과 대규모 작업은 월간 관리가 자연스럽고, egress 무료 정책도 월간 청구 구조와 맞물려 있기 때문입니다.

무료 플랜에서 한도를 넘기면 과금되는 것이 아니라 **해당 작업이 오류로 실패**하는 방식이라는 점도 유료 플랜과의 핵심적인 차이입니다. 예를 들어 KV 쓰기 한도를 초과하면 그날 UTC 0시까지 쓰기가 거부되며, 이때 서비스가 무응답이 되지 않도록 오류 처리 로직을 준비해 두는 것이 좋은 설계입니다. 유료 플랜으로 전환하면 이러한 일일 한도 자체가 사라지고 초과 사용량에 대해서만 종량제로 과금되는 구조로 바뀝니다.

## 시작 전 챙겨야 할 준비 사항

- **워크로드 유형 분류**: 읽기 위주 캐시라면 KV가, 관계형 질의가 필요하면 D1이, 파일 서빙이면 R2가 적합합니다. 각 서비스의 한도 구조가 다르므로 어떤 한도에 먼저 도달할지 시뮬레이션해 보세요.
- **UTC 초기화 시각 기억**: 일일 한도는 한국 시간 매일 오전 9시에 초기화됩니다. 배치 작업이나 트래픽 집중 시간대를 이 시점과 함께 계획하면 하루 한도를 효율적으로 쓸 수 있습니다.
- **초과 시 동작 설계**: 무료 플랜에서 한도 초과는 과금이 아니라 오류 차단입니다. KV 쓰기나 D1 쿼리 실패 시 폴백(fallback) 로직을 넣어 서비스가 멈추지 않게 하세요.
- **KV null 조회 주의**: 존재하지 않는 키 조회도 읽기 한도에서 차감됩니다. 캐시 미스가 많은 패턴이라면 조회 전 사전 검증이나 다른 캐시 레이어 도입을 고려하세요.
- **Queues 처리량 계산**: 하루 1만 작업은 메시지 약 3,300건 수준입니다. 대량 발송 알림 같은 배치 처리는 이 한도 내에서 나눠 실행하도록 설계하세요.
- **Vectorize 사용 전 확인**: 문서에 무료 한도와 유료 플랜 전용 문구가 병존하므로, 실제 도입 전 본인 계정 대시보드에서 이용 가능 여부를 직접 확인하세요.
- **최신 문서 재확인**: 무료 한도는 시기에 따라 조정됩니다. 이 글의 수치는 2026년 9월 기준이며, 배포 전 [Cloudflare 공식 문서](https://developers.cloudflare.com/workers/platform/pricing/)에서 최신 값을 다시 확인하시기 바랍니다.

## 마무리 - 무료 한도 안에서 설계하는 법

Cloudflare Workers Free 플랜은 Workers 하루 10만 요청, D1 하루 500만 행 읽기, KV 하루 10만 읽기, R2 월 10GB 저장과 무료 egress 등 상당한 수준의 무료 사용량을 제공합니다. Durable Objects와 Queues, Hyperdrive, Workflows도 2025년 4월부터 무료 계정에 열려 있어 소규모 프로덕트를 비용 없이 구성할 수 있습니다. 한도는 매일 UTC 0시에 초기화되는 일일 방식과 월 단위 방식이 서비스별로 다르고, 초과 시 추가 과금이 아닌 오류 차단으로 동작한다는 점이 유료 플랜과의 핵심 차이입니다. Containers를 비롯해 일부 서비스는 유료 플랜 전용이므로 아키텍처 설계 전 각 서비스의 이용 가능 여부를 공식 문서에서 확인하고, 폴백 로직까지 준비하는 것이 무료 티어를 안전하게 활용하는 방법입니다.
