2026년 9월 8일 **오픈AI**가 내부 모델로 **나비에-스토크스 존재성과 매끄러움 문제**를 해결했다고 발표하면서 하루 종일 관련 기사가 쏟아졌습니다. 그런데 정작 기사를 읽어도 이 난제가 무엇을 묻는 문제인지 쉽게 와닿지 않는 경우가 많습니다. 방정식 이름부터 생소하고 뉴스에는 블로업, 특이점, Lean 검증 같은 전문 용어가 섞여 나오기 때문입니다.

결론부터 요약하면, 나비에-스토크스 방정식은 **물과 공기 같은 유체가 어떻게 흐르는지를 기술하는 방정식**입니다. 일기예보부터 비행기 날개 설계, 혈류 시뮬레이션까지 실생활 곳곳에 쓰이는 유용한 도구인데, 이상하게도 방정식이 제대로 작동하는지에 대한 수학적 보증이 90년 동안 없었다는 것이 문제의 본질입니다.

난제의 공식 정의는 [클레이수학연구소 밀레니엄 문제 페이지](https://www.claymath.org/millennium-problems/)에서, 오픈AI 발표 내용은 [가디언지 보도](https://www.theguardian.com/science/2026/sep/08/openai-claims-to-have-solved-maths-problem-that-stumped-humans-for-decades)에서 확인할 수 있습니다.

## 나비에스토크스 방정식이란 유체의 뉴턴 제2법칙

나비에-스토크스 방정식을 한 문장으로 표현하면 **점성을 가진 유체에 작용하는 힘과 운동량의 변화를 기술하는 비선형 편미분방정식**입니다. 어렵게 들리지만 본질은 간단합니다. 중학교 물리에서 배우는 뉴턴의 제2법칙 $F = ma$를 유체에 적용한 것이 바로 이 방정식입니다.

고체인 공을 밀면 공 전체가 같은 가속도로 움직이지만, 물이나 공기는 밀어낸 부분만 움직이고 주변이 따라와서 소용돌이가 생깁니다. 그래서 유체에서는 힘과 가속도의 관계를 공간의 모든 지점, 모든 시각에 대해 따져야 합니다. 이를 수학으로 옮기면 시간과 공간에 대한 미분항이 가득한 편미분방정식이 되고, 그 대표적인 결과물이 나비에-스토크스 방정식입니다. 비압축성 뉴턴 유체에 대한 대표 형태는 다음과 같습니다.

$$\rho \left( \frac{\partial \mathbf{u}}{\partial t} + \mathbf{u} \cdot \nabla \mathbf{u} \right) = -\nabla p + \mu \nabla^2 \mathbf{u} + \mathbf{f}$$

여기서 $\mathbf{u}$는 유체의 속도, $p$는 압력, $\rho$는 밀도, $\mu$는 점성(끈적함)을 뜻합니다. 왼쪽 항이 유체의 가속, 오른쪽 항이 압력과 점성, 외력이 만드는 힘으로, 구조 자체는 $F = ma$와 같습니다.

| 구분      | 내용                         |
| ------- | -------------------------- |
| 방정식의 정체 | 뉴턴 유체 운동을 기술하는 비선형 편미분방정식  |
| 기본 원리   | 뉴턴 제2법칙 $F = ma$의 유체 버전    |
| 주요 변수   | 속도, 압력, 밀도, 점성             |
| 다루는 대상  | 물, 공기 같은 점성을 가진 유체의 흐름     |
| 핵심 특징   | 비선형 항 때문에 해를 일반적으로 구하기 어려움 |

이 방정식의 이름은 19세기에 점성 유체의 운동 방정식을 발전시킨 두 사람에게서 왔습니다. 프랑스의 **클로드 루이 나비에**(1785~1836)와 영국의 **조지 가브리엘토크스**(1819~1903)입니다. 두 사람이 각자 다른 접근으로 같은 방정식에 도달하면서 두 사람의 이름이 함께 붙게 되었습니다. 나비에는 1822년경,토크스는 이후 점성 항을 더 정교하게 다듬으며 오늘날의 형태로 완성했습니다.

## 방정식은 어디에 쓰이는가

나비에-스토크스 방정식이 중요한 이유는 활용 범위가 압도적으로 넓기 때문입니다. 유체가 움직이는 현상은 거의 모두 이 방정식의 지배를 받기 때문에, 현대 공학과 과학에서 빼놓을 수 없는 기본 도구로 자리 잡았습니다.

대표적인 활용 분야를 정리하면 다음과 같습니다.

| 분야      | 활용 예                        |
| ------- | --------------------------- |
| 기상 예측   | 대기의 흐름과 소용돌이 계산, 일기예보 모델    |
| 항공 공학   | 비행기 날개 주변 공기의 흐름, 양력과 항력 설계 |
| 의료 생체공학 | 혈관 속 혈류 시뮬레이션, 인공심판 설계      |
| 자동차 조선  | 차체와 선체 주변 유동 해석, 공기저항 감소    |
| 기계 공학   | 터빈과 펌프 내부 유체 거동 설계          |
| 환경 공학   | 하천 오염물 확산, 해류 예측            |

재미있는 사실은 이 방정식이 이토록 널리 쓰이면서도 정작 수학적으로는 미해결 상태였다는 점입니다. 공학자들은 근사와 수치해석으로 실용적 답을 얻어 써 왔지만, 수학자들의 눈에는 아직 답이 없는 질문이 남아 있었습니다. 그 질문이 바로 밀레니엄 난제로 지정된 존재성과 매끄러움 문제입니다.

## 왜 90년간 안 풀렸나 블로업과 특이점의 문제

밀레니엄 난제가 묻는 질문을 쉽게 풀면 다음과 같습니다. **처음에 매끄럽게 흐르던 유체가 시간이 아무리 흘러도 계속 매끄럽게 흐르는가, 아니면 어느 순간 갑자기 무너지는가?**

여기서 매끄럽다는 말은 유체의 속도가 공간과 시간에 걸쳐 연속적으로 잘 변한다는 뜻입니다. 컵 속 물을 저으면 물이 부드럽게 소용돌이치는데, 이런 상태가 매끄러운 흐름입니다. 문제는 방정식이 예측하는 극단적 상황입니다. 소용돌이가 점점 조여들면서 한 점으로 모이면 그 지점에서 유체 속도가 무한대로 치솟는 상태가 만들어질 수 있다는 것입니다. 이처럼 해가 특정 지점에서 발산해 버리는 현상을 **블로업**, 그 발산 지점을 **특이점**이라고 부릅니다.

| 개념      | 의미                              |
| ------- | ------------------------------- |
| 매끄러움    | 유체 속도가 연속적으로 잘 변하는 정상적 흐름       |
| 특이점     | 해가 발산해 속도가 무한대가 되는 지점           |
| 블로업     | 유한한 시간 안에 특이점이 발생하며 흐름이 무너지는 현상 |
| 존재성 문제  | 방정식의 해가 항상 존재하는가의 질문            |
| 매끄러움 문제 | 해가 항상 매끄러운 상태를 유지하는가의 질문        |

이 질문에 답하기 어려운 이유는 방정식의 **비선형성**에 있습니다. 소용돌이가 소용돌이를 키우고 그 소용돌이가 다른 흐름을 바꾸는 식으로 항들이 서로를 변화시키기 때문에, 흐름이 시간을 거슬러 어떻게 발전할지 일반적으로 예측할 수 없습니다. 2차원에서는 매끄러움이 증명되어 있지만 3차원, 즉 우리가 사는 실제 공간에서는 90년 동안 증명도 반증도 나오지 않았습니다.

오픈AI 모델이 내놓은 결론은 **매끄러운 흐름이 유한한 시간 안에 무너질 수 있다**는 방향이었습니다. 소용돌이가 조여들면서도 에너지는 유한하게 유지되는 특이점의 발생 가능성을 입증함으로써, 90년 묵은 질문에 하나의 답을 제시한 셈입니다.

## 밀레니엄 7대 난제와 이번 성과의 의미

나비에-스토크스 문제가 유독 주목받는 이유는 **밀레니엄 문제**이기 때문입니다. 클레이수학연구소는 2000년 5월 21세기 수학 발전에 기여할 7가지 문제를 선정하며 문제마다 상금 100만 달러를 걸었습니다.

| 난제                 | 상태                         |
| ------------------ | -------------------------- |
| 푸앵카레 추측            | 2003년 페렐만 해결(상금 거부)        |
| 나비에-스토크스 존재성과 매끄러움 | 2026년 9월 오픈AI 해법 발표(검증 계류) |
| P-NP 문제            | 미해결                        |
| 리만 가설              | 미해결                        |
| 양-밀스 이론 존재성과 질량 간극 | 미해결                        |
| 버치-스위너턴다이어 추측      | 미해결                        |
| 호지 추측              | 미해결                        |

7개 문제 중 그동안 해결된 것은 2003년 그리고리 페렐만이 증명한 **푸앵카레 추측**이 유일했습니다. 그마저 페렐만은 상금을 수령하지 않았습니다. 오픈AI의 발표가 사실로 공식 인정되면 푸앵카레 추측 이후 약 23년 만의 두 번째 해결 사례이자, 사상 최초로 **인공지능이 풀어낸 밀레니엄 난제**가 됩니다.

이번 프로젝트에 투입된 것은 GPT-6 아스트라보다 상위 버전으로 알려진 비공개 내부 모델이었습니다. 약 1만 개의 AI 에이전트가 88시간 동안 병렬로 작동해 약 1,300억 개의 출력 토큰을 소비했고, 결과물은 165쪽 분량의 증명으로 나왔습니다. 증명의 논리적 무결성은 **Lean**이라는 정리 증명 언어로 기계적 검증을 마쳤다는 점도 기존 수학 발표와 다른 부분입니다.

| 항목      | 수치                        |
| ------- | ------------------------- |
| 발표일     | 2026년 9월 8일(현지 시각)        |
| 투입 모델   | GPT-6 아스트라보다 상위 비공개 내부 모델 |
| AI 에이전트 | 약 10,000개                 |
| 소요 시간   | 88시간                      |
| 출력 토큰   | 약 1,300억 개                |
| 증명 분량   | 165쪽                      |
| 검증 방식   | Lean 정리 증명 언어 형식 검증       |

다만 두 가지는 아직 열린 문제로 남아 있습니다. 첫째, 밀레니엄 문제의 공식 해결 인정은 클레이수학연구소의 심사를 거쳐야 하며 현재는 발표 단계입니다. 오픈AI는 상금을 청구하지 않겠다고 밝혔습니다. 둘째, 발표를 앞두고 뉴욕대 트리스탄 버크마스터 교수가 앤트로픽 소속 연구자와 준비 중이던 유사 연구와의 관계를 문제 삼아 공로 배분 논란이 벌어졌고, 오픈AI는 연구 사용을 부인했습니다. 기술적 성과와 윤리적 쟁점이 동시에 검증 중인 상황입니다.

## 이해를 돕는 준비 사항

- **뉴턴 제2법칙부터 복기**: 나비에-스토크스 방정식의 뿌리는 $F = ma$입니다. 공 하나 밀기와 물 저어보기의 차이를 떠올리면 방정식의 존재 이유가 자연스럽게 이해됩니다.
- **블로업 개념에 집중**: 증명의 세부 논리보다 소용돌이가 조여들어 속도가 발산하는 상상만으로도 이번 발표가 무엇을 답했는지 그림이 그려집니다.
- **공식 원문 확인**: 이번 발표의 정확한 내용은 [오픈AI 공식 발표문](https://openai.com/index/navier-stokes-solution/)과 165쪽 논문, Lean 프로젝트에서 확인하세요. 언론 요약만으로는 세부 내용이 생략됩니다.
- **7대 난제 전체 훓어보기**: [클레이수학연구소 페이지](https://www.claymath.org/millennium-problems/)에서 나머지 6개 난제를 함께 보면 이 문제가 수학계에서 차지하는 위상을 가늠할 수 있습니다.
- **논란 정보 분리**: 오픈AI의 기술적 성과와 버크마스터 교수의 공로 논란은 별개 사안입니다. 두 성명을 모두 직접 읽고 판단하는 것이 정확합니다.
- **후속 소식 추적**: 클레이수학연구소의 공식 입장과 학계 검증 결과는 향후 수개월간 계속 업데이트될 예정입니다. 공식 인정 여부는 이후 발표를 지켜봐야 합니다.

## 마무리 - 유체의 법칙에 달린 미해결 질문

나비에-스토크스 방정식은 뉴턴의 제2법칙을 유체에 적용한, 물과 공기의 흐름을 지배하는 방정식입니다. 일기예보와 비행기 설계, 혈류 시뮬레이션까지 폭넓게 쓰이는 도구이지만 3차원에서 해가 항상 매끄럽게 존재하는지는 90년 동안 증명되지 않았고, 그 물음이 상금 100만 달러가 걸린 밀레니엄 난제입니다. 오픈AI는 매끄러운 흐름이 유한한 시간 안에 무너질 수 있음을 내부 모델로 증명했다고 발표했고, 1만 개 에이전트와 88시간, 165쪽의 Lean 검증 증명이 그 성과의 근거입니다. 이 발표가 푸앵카레 추측 이후 23년 만의 두 번째 밀레니엄 해결로 공식 인정될지는 클레이수학연구소의 검증과 공로 논란의 결론에 달려 있으므로, 공식 채널의 후속 발표를 지속적으로 확인하시기 바랍니다.
