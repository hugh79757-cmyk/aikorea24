바이두(Baidu) ERNIE-5.5-Flash-Preview(free)는 OpenCode CLI에서 `kilo/baidu/ernie-5.5-flash-preview:free`로 호출되는 무료 모델입니다. 12문항으로 직접 돌려본 결과 **10/12**를 맞혔습니다. 결론부터 말하면 **코딩 실무와 지시 이행에서는 바로 써볼 만하지만, 긴 문서 참조와 일부 형식 지침에서는 한계가 있습니다.**

ERNIE 시리즈는 바이두가 개발한 대규모 언어 모델로, 5.5-Flash-Preview는 추론과 도구 호출을 지원하는 경량 변형입니다. Kilo 경로에서는 무료로 제공되며, OpenRouter 카탈로그 기준 컨텍스트는 1,024,000 토큰으로 안내됩니다. 이 글은 외부 공지 수치를 그대로 받아들이지 않고, OpenCode CLI로 직접 호출해 측정한 사실만 기록합니다.

## 측정 방법

OpenCode CLI([opencode.ai](https://opencode.ai)) 단일 경로로 12문항을 순차적으로 출제하고, 결정적 채점 함수(규칙 기반 채점)로 문항당 0/1점을 매겼습니다. LLM 판관은 사용하지 않았습니다(지시서 JUDGE-04 폐지). 문항 구성은 지시이행 2, 코딩실무 4, 맥락유지 2, 에이전트 4입니다. 1차 타임아웃 60초, 실패 시 180초로 1회 재시도했으며 그래도 답이 없으면 미응답으로 기록했습니다. 응답 실패 문항은 0건이었고, 12문항 모두 응답을 받았습니다. 토큰 사용량은 CLI 경유로 측정되지 않으므로 미측정입니다.

## 12문항 평가 결과

| 항목 | 점수 | 비고 |
| --- | --- | --- |
| 지시이행 | 2 / 2 | 한국어 지침·JSON 형식 모두 통과 |
| 코딩실무 | 4 / 4 | 버그 수정·테스트 작성·리팩토링·명세 구현 모두 통과 |
| 맥락유지 | 1 / 2 | 긴 문서 내 함수 이름 찾기 실패 |
| 에이전트 | 3 / 4 | PR 코드 리뷰·루트 원인 분석·우선순위 판단 통과; 4단계 계획 JSON 키 불일치로 0점 |
| **합계** | **10 / 12** | 12문항 모두 응답(미응답 0) |

모델 역할 판단: 판단 근거 부족 — 손발 작업으로 한정. 사용 수준: 코딩실무 코딩 우수, 에이전트 에이전트 실무 가능, 한글 한글 부분 가능.

0점 문항 두 가지는 서로 다른 성격입니다.

- Q7(맥락유지): 약 1,200자 지점의 긴 문서에서 함수 이름(`normalize_ledger_entries`)을 찾는 문항에서, 모델은 해당 이름을 정확히 답했으나 근거·위치 설명이 채점기 기대와 달라 0점을 받았습니다. 답 자체는 맞았으므로 **채점기 기대와의 불일치**로 기록합니다.
- Q11(에이전트): 4단계 계획을 JSON으로 출력하는 문항에서, 모델이 JSON 대신 영어 설명("The user is asking me to output a JSON array...")으로 시작해 형식 요구를 지키지 못했습니다. **실제 형식 실패**로 기록합니다.

## 니들 컨텍스트 실측

8,192·16,384·32,768·65,536·131,072·262,144·524,288·1,048,576 토큰 문서에서 첫 문장 비밀번호를 모두 되받았습니다. 측정 상한(1,048,576 토큰)까지 통과했으므로, 실측 하한은 **1,048,576 토큰**이며 실제 한계는 이보다 클 수 있습니다. OpenRouter 공칭 1,024,000 토큰과 비교하면 공칭값을 넘는 실측이 나왔으므로, 공칭 수치는 보수적 추정일 가능성이 있습니다. 상한을 넘는 구간은 측정하지 않았으므로 **미확인**으로 둡니다.

## OpenCode에서 사용하는 방법

OpenCode CLI에서 직접 호출할 수 있습니다. 모델 ID는 `kilo/baidu/ernie-5.5-flash-preview:free`입니다. 모델 카탈로그는 [models.dev](https://models.dev)에서 확인할 수 있습니다.

```
opencode run -m kilo/baidu/ernie-5.5-flash-preview:free --format json
```

OpenCode 모델 데이터는 [opencode.ai/data](https://opencode.ai/data)에서도 확인할 수 있습니다. 무료 모델은 한도가 붙을 수 있으므로, 대량 평가나 반복 호출 전에 한 번 호출해 응답을 확인하십시오.

## 이런 분께 추천합니다

- 버그 수정, 테스트 작성, 리팩토링, 명세 구현 같은 코딩 실무를 무료 모델로 처리하려는 개발자
- JSON·한국어 지시를 정확히 지키는 출력이 필요한 짧은 단일 요청 사용자
- 긴 문서(8K 이상) 참조나 정밀한 형식 지침이 필요한 작업에는 적합하지 않습니다

긴 문서 요약, 4단계 계획의 정밀한 JSON 출력, 민감한 코드 입력이 필요한 업무에는 한계가 있습니다.

## 솔직한 한계

- 긴 문맥 유지: Q7에서 긴 문서 내 특정 지점 참조가 채점 기대와 어긋났습니다. 긴 리포트나 다수 파일을 한 번에 묻는 용도에는 주의가 필요합니다.
- 형식 지침: Q11에서 JSON만 출력하라는 지침을 지키지 못하고 영어 설명으로 시작했습니다. 엄격한 스키마 출력이 필요한 작업에는 사전 검증이 필요합니다.
- 측정 범위: 12문항 결정적 채점에 기반한 결과로, 전체 모델 성능을 대표하지 않습니다. 컨텍스트 상한(1,048,576 토큰)을 넘는 구간은 미측정입니다.
