## 한줄 요약

Mermaid는 외부에서도 아이폰 문자 메시지로 맥(Mac) 컴퓨터를 원격으로 조작할 수 있게 돕는 AI 에이전트 서비스입니다. 복잡한 원격 데스크톱 연결 없이 텍스트 지시만으로 맥의 메모, 메일, 브라우저 등 기존 앱을 알아서 작동시킵니다.

## 핵심 기능

- **문자 원격 제어**: 아이폰 문자로 지시하면 맥이 스스로 해당 업무를 수행합니다.
- **맥 순정 앱 연동**: Safari, 메모, 메일, VS Code 등 기존 설치 앱을 바로 활용합니다.
- **실시간 승인 기능**: 작업 진행 상황을 모니터링하고 최종 전송 전 승인할 수 있습니다.

## 사용법

**1. 맥과 아이폰에 앱 설치 및 연동**

공식 웹사이트에서 맥용 설치 파일을 다운로드하고 아이폰 앱과 동일한 계정으로 로그인합니다. 초기 페어링하려고 맥과 아이폰을 동일한 와이파이 네트워크에 연결해야 합니다.

**2. 아이폰에서 문자 메시지 전송**

아이폰의 메시지 앱을 열어 맥에게 지시사항을 보냅니다. 예를 들어 '메모장에 이번 주 쇼핑 목록을 작성해줘'와 같이 자연스러운 문장으로 입력합니다.

**3. 실시간 작업 모니터링 및 승인**

맥이 작업을 수행하는 동안 아이폰 화면으로 진행 상황을 확인합니다. 메시지 발송이나 파일 삭제와 같은 중요한 작업은 반드시 사용자의 승인을 거쳐야 실행됩니다.

**4. 원격 데스크톱 기능 활용**

단순한 텍스트 지시 외에 직접 조작이 필요할 때는 'Live Screen' 기능을 사용합니다. 이로 원격으로 맥 화면을 보며 마우스와 키보드처럼 직접 제어할 수 있습니다.

## 가격 정책

- **무료 플랜**: 현재 얼리 액세스(베타 테스트) 기간으로 무료 신청 후 이용할 수 있습니다.
- **유료 플랜**: 정식 출시 후 정액제 플랜 제공 예정이며, 예상 월 구독료는 약 20,000원($15) 안팎입니다.

비용 절약 팁: 현재 베타 신청을 등록해두시면 정식 출시 전 무료 이용 기회를 먼저 받으실 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 베타 테스트 기간으로 무료로 이용 가능합니다. 단, AI 모델을 활용한 작업 수행에는 일정 수준의 사용량 제한이 적용될 수 있습니다.

- **정식 출시 플랜(예상)** (월 20,000원($15) 내외): 정식 출시 이후 제공될 정기 구독형 모델로, AI 에이전트의 고급 기능과 무제한에 가까운 작업 환경을 제공할 것으로 보입니다.

- **베타 액세스** (무료): 공식 홈페이지로 얼리 액세스를 신청하면 정식 출시 전까지 무료로 서비스를 미리 체험할 수 있는 혜택을 제공합니다.

**환불과 해지**: 현재 베타 기간에는 비용이 발생하지 않으며, 정식 출시 이후의 결제 및 환불 정책은 공식 홈페이지의 이용 약관 페이지를 확인해야 합니다.

## 한국어 지원

공식 웹사이트 및 서비스 인터페이스는 영문으로 제공됩니다. 다만 맥에 설치된 앱 내 한국어 입력이나 한국어 지시문 처리는 맥OS 자체 시스템 언어 설정을 따라 동작합니다.

## 한국어 품질 실측

**메모 작성 요청**

- 프롬프트: 메모 앱을 열어서 '오늘 저녁 식사 메뉴는 김치찌개'라고 적어줘.
- 결과 예시: 맥의 메모 앱이 실행되고 해당 문구가 입력됩니다. 아이폰 화면에 '메모 작성이 완료되었습니다'라는 상태 메시지가 표시됩니다.
- 관찰: AI가 한국어 지시문을 이해하고 맥의 앱을 조작하는 데 무리가 없습니다.

**이메일 초안 작성**

- 프롬프트: 메일 앱을 열고 팀장님께 보낼 '내일 연차 신청합니다'라는 제목의 메일을 써줘.
- 결과 예시: 메일 작성 창이 나타나며 제목과 내용이 입력됩니다. 최종 발송 전 사용자에게 확인 버튼을 요청하는 알림이 뜹니다.
- 관찰: 복잡한 문장 구조도 맥OS의 기본 앱과 연동되어 정확하게 처리됩니다.

서비스 인터페이스는 영문이지만 사용자의 한국어 지시문은 맥OS의 언어 설정에 따라 원활하게 처리됩니다. 번역투 없이 자연스러운 한국어 명령을 입력해도 AI가 맥의 앱을 정확히 제어합니다.

## 이런 분에게 추천합니다

이런 분에게 추천합니다.
1. 외출이나 출장이 잦아 이동 중에도 사무실 맥 컴퓨터로 업무를 처리해야 하는 직장인에게 적합합니다.
2. 복잡한 원격 제어 프로그램 설정 없이 간편하게 맥을 조종하고 싶은 사용자분께 추천합니다.
3. 다양한 업무용 앱을 맥에서 동시에 활용하는 개발자나 기획자분께 유용합니다.

## 실제 활용 예시

- **직장인**: 퇴근길에 갑자기 생각난 업무 아이디어를 아이폰 문자로 보냅니다. 사무실 맥의 메모 앱이 자동으로 열리고 아이디어가 깔끔하게 정리되어 저장됩니다.
- **학생**: 도서관에서 공부하던 중 집에 있는 맥의 브라우저를 작동시켜 필요한 논문 자료를 검색하고 파일로 저장하도록 지시합니다.
- **소상공인**: 매장 외부에서 스마트폰 문자로 맥에 접속해 고객 안내 이메일 초안을 작성하게 하고 내용을 확인한 뒤 즉시 발송 승인을 내립니다.

## 유사 툴과 비교

**장점:**
- 화면 전체를 직접 조작하는 복잡한 원격 데스크톱 설치가 필요 없습니다.
- 자연어 문자 메시지 한 줄로 원하는 앱 작업을 자동 실행할 수 있습니다.

**단점:**
- 맥(Mac) 컴퓨터가 켜져 있고 인터넷에 연결되어 있어야만 작동합니다.

**이런 분에게 가장 적합합니다:** 스마트폰 하나로 집이나 사무실의 맥 업무를 간편하게 처리하고 싶은 맥 사용자에게 최고입니다.

## 장단점

**장점**

- 외부에서도 아이폰 문자 메시지만으로 사무실에 있는 맥을 즉시 제어할 수 있어 업무 효율성이 극대화됩니다.
- 별도의 복잡한 원격 데스크톱 설정 없이도 맥에 설치된 기존 앱들을 그대로 활용할 수 있어 매우 편리합니다.
- 중요한 업무 수행 시 실시간 승인 절차를 거치기 때문에 실수로 파일을 삭제하거나 잘못된 메일을 보낼 위험이 없습니다.
- 실시간 화면 공유 기능로 원격지에서도 맥의 상태를 직접 눈으로 확인하며 정밀한 작업 수행이 가능합니다.

**단점**

- 맥이 항상 켜져 있고 온라인 상태를 유지해야 하므로 전력 소모나 보안 측면에서 주의가 필요합니다.
- 현재 베타 버전으로 운영되어 정식 버전 출시 시 요금 체계나 기능에 변동이 생길 가능성이 존재합니다.
- 한국어 공식 지원이 되지 않아 문제 발생 시 영문으로 된 고객 지원 센터로 문의해야 하는 불편함이 있습니다.

## 주의사항

- **개인정보**: 원격 제어 중 맥에 저장된 민감한 개인정보나 기밀 문서가 노출될 수 있으므로 보안 환경을 확인하고 사용하십시오.
- **저작권/상업적 이용**: AI가 생성한 결과물의 저작권은 서비스 이용 약관을 따라야 하며 상업적 용도로 활용 시 법적 검토가 필요합니다.
- **요금/한도**: 현재는 무료 베타 기간이지만 정식 출시 이후에는 유료 구독으로 전환될 예정이므로 요금 정책을 주기적으로 확인해야 합니다.
- **계정 관리**: 맥과 아이폰에 동일한 계정으로 로그인해야 작동하므로 계정 정보 유출 방지하려고 2단계 인증을 반드시 설정하십시오.

## 자주 묻는 질문

**TeamViewer나 Chrome 원격 데스크톱과 어떻게 다른가요?**

기존 원격 제어는 화면을 보며 마우스를 직접 움직여야 하지만 Mermaid는 AI가 텍스트 명령을 이해하고 맥의 앱들을 직접 조작하여 결과를 보여줍니다.

**맥에 별도로 많은 설정을 해야 하나요?**

아닙니다. 맥 전용 앱을 다운로드한 후 자주 사용하는 애플리케이션 권한만 연결해주면 별도의 복잡한 세팅 없이 바로 사용 가능합니다.

**안드로이드 스마트폰에서도 사용할 수 있나요?**

현재는 아이폰(iOS) 베타 버전을 우선 지원하며 안드로이드용 서비스도 조만간 출시될 예정입니다.

**맥이 꺼져 있어도 원격 제어가 가능한가요?**

아니요, 맥이 반드시 켜져 있고 인터넷에 연결되어 있어야 합니다. 절전 모드에서 깨어날 수 있도록 맥의 전원 설정을 조정해야 합니다.

**안드로이드 폰에서도 사용할 수 있나요?**

현재는 아이폰만 지원하며 안드로이드 버전은 개발 중입니다. 공식 홈페이지에서 추후 업데이트 소식을 확인할 수 있습니다.

**와이파이가 없는 곳에서도 작동하나요?**

네, 초기 페어링 이후에는 모바일 데이터를 사용하여 어디서든 맥에 접근할 수 있습니다. 다만 안정적인 연결을 위해 원활한 네트워크 환경이 권장됩니다.

**어떤 앱들을 제어할 수 있나요?**

사파리, 크롬, 메모, 메일, 메시지, VS Code 등 맥에 기본 설치된 대부분의 앱을 제어할 수 있습니다. 앱 연동은 별도의 설정 없이 자동으로 이루어집니다.
