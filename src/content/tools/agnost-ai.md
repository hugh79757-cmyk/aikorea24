## 한줄 요약

Agnost AI는 기업용 챗봇이나 대화형 에이전트가 고객과 나눈 대화를 분석하는 도구입니다. 챗봇이 고객을 제대로 이해하지 못하거나 잘못된 정보를 제공하는 지점을 찾아내어, 서비스 운영자가 빠르게 개선하는 데 도움이 되습니다.

## 핵심 기능

- **오류 자동 탐지**: 챗봇의 할루시네이션이나 잘못된 답변을 실시간으로 찾아내어 고객 이탈을 방지합니다.
- **대화 자동 분류**: 수천 건의 대화를 주제별로 자동 분류하여 고객이 무엇을 원하는지 한눈에 파악합니다.
- **사용자 불만 분석**: 고객이 챗봇 이용 중 답답함을 느끼는 지점을 찾아내어 서비스 개선 우선순위를 정합니다.

## 가격 정책

- **무료 플랜**: 무료 체험로 별도의 회원가입 없이 라이브 데모를 직접 경험해 볼 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 공식 홈페이지 문의로 기업 규모에 맞는 맞춤형 견적을 제공합니다.

비용 절약 팁: 도입 전 라이브 데모로 우리 서비스의 대화 로그와 얼마나 잘 맞는지 먼저 테스트해 보세요.

## 한국어 지원

현재 인터페이스와 분석 기능은 영어로 제공되지만 대화 로그에 포함된 한국어 텍스트 데이터는 정상적으로 분석이 가능합니다.

## 이런 분에게 추천합니다

자체 챗봇을 운영하며 고객 응대 품질을 높이고 싶은 기업 담당자에게 추천합니다. 챗봇의 답변 오류로 인해 고객 불만이 늘어 고민인 서비스 기획자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 CS 챗봇의 상담 로그를 업로드하여, 고객이 가장 많이 묻는 질문인데 챗봇이 답변하지 못하는 항목을 찾아내어 답변 데이터를 보강합니다.
- **학생**: 직접 개발한 AI 챗봇 프로젝트의 성능을 테스트하기 위해, 사용자가 대화 도중 어떤 부분에서 대화를 포기하는지 분석하여 챗봇의 논리 구조를 수정합니다.
- **소상공인**: 쇼핑몰 주문 확인 챗봇의 대화 데이터를 분석하여, 고객들이 배송 관련 문의 시 챗봇이 제대로 응대하지 못하는 사례를 찾아내어 대응 매뉴얼을 개선합니다.

## 유사 툴과 비교

**장점:**
- 대화 로그와 실제 오류 지점을 시각적으로 매칭하여 분석 속도가 매우 빠름
- 복잡한 설정 없이도 대화 패턴을 자동으로 클러스터링해줌

**단점:**
- 한국어 전용 분석 도구가 아니므로 대화 맥락 파악 시 영어보다 정확도가 낮을 수 있음

**이런 분에게 가장 적합합니다:** 챗봇의 대화 품질을 정량적으로 측정하고 빠르게 개선점을 찾고 싶은 팀

## 자주 묻는 질문

**한국어 대화 데이터도 분석이 가능한가요?**

네, 텍스트 데이터 자체는 분석이 가능합니다. 다만 대화의 맥락을 이해하는 AI 모델의 최적화가 영어에 맞춰져 있어 한국어의 경우 정확한 의미 파악하려고 추가적인 검토가 필요할 수 있습니다.

**개인정보 보호는 어떻게 되나요?**

고객의 민감한 정보가 포함된 대화 로그를 다루므로, 업로드 전 개인정보를 비식별화 처리한 후 분석 도구에 연동하는 것을 권장합니다.

**어떤 종류의 챗봇과 연동할 수 있나요?**

API를 통해 대화 데이터를 전송할 수 있는 대부분의 챗봇 서비스와 연동이 가능합니다. 자세한 기술적 연동 방법은 제공되는 문서를 참조하시기 바랍니다.
