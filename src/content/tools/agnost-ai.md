## 한줄 요약

Agnost AI는 기업용 챗봇이나 대화형 에이전트가 고객과 나눈 대화를 분석하는 도구입니다. 챗봇이 고객을 제대로 이해하지 못하거나 잘못된 정보를 제공하는 지점을 찾아내어, 서비스 운영자가 빠르게 개선하는 데 도움이 되습니다.

## 핵심 기능

- **오류 자동 탐지**: 챗봇의 할루시네이션이나 잘못된 답변을 실시간으로 찾아내어 고객 이탈을 방지합니다.
- **대화 자동 분류**: 수천 건의 대화를 주제별로 자동 분류하여 고객이 무엇을 원하는지 한눈에 파악합니다.
- **사용자 불만 분석**: 고객이 챗봇 이용 중 답답함을 느끼는 지점을 찾아내어 서비스 개선 우선순위를 정합니다.

## 사용법

**1. 계정 연동하기**

공식 홈페이지에 접속하여 프로젝트를 생성하고 연동을 시작합니다. 안내되는 텍스트 프롬프트를 복사하여 개발 환경이나 코딩 에이전트에 붙여넣습니다.

**2. 분석 도구 설치**

터미널이나 코딩 도구에서 안내된 npx 명령어(skills add)를 실행하여 프로젝트에 Agnost AI 분석 기능을 추가합니다. 실시간 운영 데이터 수집을 위한 기본 설정이 완료됩니다.

**3. 운영 데이터 모니터링**

대시보드 화면에 접속하여 실제 챗봇이나 AI 에이전트가 처리한 대화 로그와 도구 호출 내역을 확인합니다. 오류가 발생한 지점이나 고객 불만 상황을 자동으로 감지하여 목록으로 보여줍니다.

**4. 수정 및 배포**

시스템이 감지한 오류를 실험을 실행하고 해결책을 검토합니다. 수정 사항이 준비되면 자동으로 풀 리퀘스트(PR)를 열어 빠르게 코드를 반영할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 체험로 별도의 회원가입 없이 라이브 데모를 직접 경험해 볼 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 공식 홈페이지 문의로 기업 규모에 맞는 맞춤형 견적을 제공합니다.

비용 절약 팁: 도입 전 라이브 데모로 우리 서비스의 대화 로그와 얼마나 잘 맞는지 먼저 테스트해 보세요.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 라이브 데모로 별도의 회원가입 없이 기능을 직접 체험해 볼 수 있습니다. 구체적인 무료 플랜의 메시지 수나 데이터 보관 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **맞춤형 기업용 플랜** (공식 페이지 문의 필요): 기업 규모와 트래픽에 맞춘 고급 모니터링 기능과 전용 기술 지원을 제공합니다.

- **엔터프라이즈 플랜** (공식 페이지 문의 필요): 대규모 AI 에이전트를 운영하는 기업을 위한 맞춤형 분석 및 보안 기능을 포함합니다.

**환불과 해지**: 환불 및 구독 해지 정책에 대한 구체적인 내용은 별도로 명시되어 있지 않으므로 공식 홈페이지 고객센터에 문의해야 합니다.

## 한국어 지원

현재 인터페이스와 분석 기능은 영어로 제공되지만 대화 로그에 포함된 한국어 텍스트 데이터는 정상적으로 분석이 가능합니다.

## 한국어 품질 실측

**고객 응대 챗봇 로그 분석**

- 프롬프트: 환불 규정이 어떻게 되나요? 챗봇이 엉뚱한 답변을 한 대화 로그를 분석해 주세요.
- 결과 예시: 사용자의 환불 질문를 챗봇이 오답을 반환한 로그를 감지하고 관련 오류 원인과 수정 제안을 요약하여 보여줍니다.
- 관찰: 한국어 텍스트 로그 분석은 정상적으로 이루어지나 대시보드 인터페이스는 영어로 표시됩니다.

**AI 에이전트 오류 추적**

- 프롬프트: 주문 조회 기능에서 발생한 도구 호출 실패 내역을 찾아주세요.
- 결과 예시: 주문 조회 API 호출 과정에서 발생한 예외 상황과 실패 지점을 타임라인 형식으로 시각화하여 제공합니다.
- 관찰: 기술적인 로그 데이터와 에러 메시지는 언어 장벽 없이 정확하게 파악할 수 있습니다.

인터페이스는 영어로 제공되지만 시스템에 입력되는 한국어 대화 로그와 텍스트 데이터는 문제없이 분석할 수 있습니다. 개발자 중심의 도구 특성상 전문적인 기술 용어가 많아 국내 실무자가 사용하기에는 약간의 적응 기간이 필요합니다.

## 이런 분에게 추천합니다

자체 챗봇을 운영하며 고객 응대 품질을 높이고 싶은 기업 담당자에게 추천합니다. 챗봇의 답변 오류로 인해 고객 불만이 늘어 고민인 서비스 기획자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 CS 챗봇의 상담 로그를 업로드하여, 고객이 가장 많이 묻는 질문인데 챗봇이 답변하지 못하는 항목을 찾아내어 답변 데이터를 보강합니다.
- **학생**: 직접 개발한 AI 챗봇 프로젝트의 성능을 테스트하기 위해, 사용자가 대화 도중 어떤 부분에서 대화를 포기하는지 분석하여 챗봇의 논리 구조를 수정합니다.
- **소상공인**: 쇼핑몰 주문 확인 챗봇의 대화 데이터를 분석하여, 고객들이 배송 관련 문의 시 챗봇이 제대로 응대하지 못하는 사례를 찾아내어 대응 매뉴얼을 개선합니다.

## 유사 툴과 비교

**장점:**
- 대화 로그와 실제 오류 지점을 시각적으로 매칭하여 분석 속도가 매우 빠름
- 복잡한 설정 없이도 대화 패턴을 자동으로 클러스터링해줌

**단점:**
- 한국어 전용 분석 도구가 아니므로 대화 맥락 파악 시 영어보다 정확도가 낮을 수 있음

**이런 분에게 가장 적합합니다:** 챗봇의 대화 품질을 정량적으로 측정하고 빠르게 개선점을 찾고 싶은 팀

## 장단점

**장점**

- AI 에이전트의 운영 중 오류를 자동으로 감지하여 개발자의 수동 모니터링 부담을 크게 줄여줍니다.
- 오류 발견 후 수정 사항을 반영하기 위해 자동으로 풀 리퀘스트를 생성하는 기능이 매우 편리합니다.
- 라이브 데모로 복잡한 가입 절차 없이 도구의 핵심 기능을 미리 체험해 볼 수 있습니다.
- 코딩 에이전트와 연동하여 간편하게 프로젝트에 분석 기능을 추가할 수 있는 확장성을 제공합니다.

**단점**

- 서비스 인터페이스가 영어로만 제공되므로 영어가 익숙하지 않은 사용자에게는 진입 장벽이 높습니다.
- 정확한 가격 정책과 요금제가 공개되어 있지 않아 예산 편성이 다소 번거로울 수 있습니다.
- 일반 직장인보다는 AI 에이전트를 직접 개발하고 운영하는 개발자에게 특화되어 있습니다.

## 주의사항

- **개인정보**: 고객과 챗봇이 나눈 대화 로그에는 민감한 개인정보가 포함될 수 있으므로 외부 분석 도구 연동 시 보안 정책을 반드시 확인해야 합니다.
- **저작권/상업적 이용**: 수집된 대화 데이터와 AI 분석 결과물의 소유권 및 재사용 규정은 서비스의 이용 약관을 준수해야 합니다.
- **요금/한도**: 맞춤형 견적 형태로 운영되므로 트래픽 급증 시 예상치 못한 비용이 발생할 수 있어 사전 문의가 필수적입니다.
- **계정 관리**: 프로젝트 연동 키와 코딩 에이전트 접근 권한 관리를 소홀히 할 경우 보안 사고로 이어질 수 있으므로 주의가 필요합니다.

## 자주 묻는 질문

**한국어 대화 데이터도 분석이 가능한가요?**

네, 텍스트 데이터 자체는 분석이 가능합니다. 다만 대화의 맥락을 이해하는 AI 모델의 최적화가 영어에 맞춰져 있어 한국어의 경우 정확한 의미 파악하려고 추가적인 검토가 필요할 수 있습니다.

**개인정보 보호는 어떻게 되나요?**

고객의 민감한 정보가 포함된 대화 로그를 다루므로, 업로드 전 개인정보를 비식별화 처리한 후 분석 도구에 연동하는 것을 권장합니다.

**어떤 종류의 챗봇과 연동할 수 있나요?**

API를 통해 대화 데이터를 전송할 수 있는 대부분의 챗봇 서비스와 연동이 가능합니다. 자세한 기술적 연동 방법은 제공되는 문서를 참조하시기 바랍니다.

**한국어 챗봇 대화 내용도 분석할 수 있나요?**

네, 대화 로그에 포함된 한국어 텍스트 데이터는 정상적으로 수집되고 분석됩니다. 다만 대시보드 메뉴와 분석 리포트 화면은 영어로 표시됩니다.

**어떤 개발 환경이나 도구와 연동할 수 있나요?**

Claude, Codex, Cursor 등 주요 AI 코딩 보조 도구와 쉽게 연동할 수 있습니다. 제공되는 명령어 프롬프트를 복사하여 프로젝트에 간편하게 추가할 수 있습니다.

**무료로 체험해 볼 수 있는 방법이 있나요?**

공식 홈페이지에서 제공하는 라이브 데모를 통해 별도의 회원가입 없이 기능을 직접 경험해 볼 수 있습니다. 이를 통해 우리 서비스 로그와 잘 맞는지 미리 테스트할 수 있습니다.

**오류를 발견하면 자동으로 수정까지 해주나요?**

시스템이 오류를 감지하고 실험을 거친 뒤 해결책을 담은 풀 리퀘스트(PR)를 자동으로 열어줍니다. 최종 코드 반영은 개발자가 직접 검토하고 승인할 수 있습니다.
