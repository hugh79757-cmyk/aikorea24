## 한줄 요약

Telemetry.dev는 AI 에이전트가 수행하는 복잡한 대화와 작업 과정을 추적하고 분석하는 관측 플랫폼입니다. 개발자가 AI의 응답 오류를 빠르게 발견하고 성능을 최적화하여 사용자에게 더 안정적인 서비스를 제공하는 데 도움이 되습니다.

## 핵심 기능

- **실시간 로그 추적**: AI 에이전트가 생성하는 모든 응답과 과정을 실시간으로 확인하여 즉각적인 대응이 가능합니다.
- **성능 시각화**: 응답 속도와 비용을 그래프로 보여주어 서비스 운영 효율을 한눈에 파악할 수 있습니다.
- **오류 자동 탐지**: 에이전트가 잘못된 답변을 하거나 시스템 오류가 발생했을 때 빠르게 원인을 파악해 줍니다.

## 사용법

**1. 계정 생성 및 SDK 연동**

공식 홈페이지에서 계정을 생성한 후, 제공되는 SDK 라이브러리를 사용 중인 AI 에이전트 코드에 삽입합니다. 연동이 완료되면 에이전트의 모든 활동이 대시보드로 전송되기 시작합니다.

**2. 실시간 대시보드 접속**

Telemetry.dev 관리자 페이지에 로그인하여 메인 대시보드에 접속합니다. 이곳에서 현재 작동 중인 에이전트의 응답 상태를 실시간으로 확인할 수 있습니다.

**3. 오류 로그 및 성능 분석**

에이전트가 생성한 응답 중 오류가 발생한 지점을 클릭하여 상세 로그를 확인합니다. 응답 속도와 토큰 사용량 그래프로 성능 저하 원인을 분석합니다.

**4. 에이전트 최적화 수행**

분석된 데이터를 바탕으로 프롬프트를 수정하거나 모델 설정을 변경합니다. 수정한 내용을 다시 배포하여 개선된 성능을 대시보드에서 재확인합니다.

## 가격 정책

- **무료 플랜**: 개발 및 테스트를 위한 무료 플랜을 제공하여 초기 도입 부담을 낮췄습니다.
- **유료 플랜**: Pro 플랜은 월 99달러(약 13만 원)부터 시작하며 대규모 데이터 처리와 고급 분석 기능을 포함합니다.

비용 절약 팁: 초기에는 무료 플랜으로 에이전트의 기본 성능을 측정해 본 뒤, 서비스 규모가 커지면 유료 플랜으로 전환하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 개발 및 테스트를 수행하는 초기 단계 사용자에게 무료 플랜을 제공합니다. 구체적인 메시지 처리량이나 기능 제한은 공식 요금 페이지에서 확인이 필요합니다.

- **Pro Plan** (월 99달러 (약 13만 원)): 대규모 데이터 처리 역량을 제공하며 복잡한 에이전트 분석을 위한 고급 기능을 포함합니다.

**환불과 해지**: 결제 및 환불 정책은 서비스 이용 약관에 따르며, 구체적인 조건은 공식 결제 페이지에서 확인이 필요합니다.

## 한국어 지원

현재 인터페이스는 영어로만 제공되지만 개발자가 사용하는 기술적인 로그 데이터 중심이므로 한국어 사용자도 큰 불편 없이 사용 가능합니다.

## 한국어 품질 실측

**에이전트 오류 분석**

- 프롬프트: 에이전트가 잘못된 정보를 제공하는 원인을 분석해 줘.
- 결과 예시: 에이전트 로그 분석 결과, 특정 컨텍스트에서 모델이 환각 현상을 일으키고 있습니다. 프롬프트 내 제약 조건을 강화하거나 지식 베이스를 업데이트하는 것을 권장합니다.
- 관찰: 입력값과 출력값이 모두 영어로 처리되므로 한국어 프롬프트에 대한 응답 정확도는 확인이 필요합니다.

**성능 리포트 생성**

- 프롬프트: 지난 일주일간의 응답 속도 변화를 보여줘.
- 결과 예시: 지난 7일간의 응답 속도 데이터입니다. 평균 1.2초에서 1.5초 사이로 안정적이나, 특정 시간대에 지연이 발생하고 있습니다.
- 관찰: 도구 인터페이스가 영어 전용이므로 한국어 데이터 처리에 대한 기술적 검토가 필요합니다.

현재 도구의 인터페이스는 영어로만 구성되어 있어 한국어 사용자에게는 직관성이 떨어질 수 있습니다. 전문적인 개발 용어가 많아 영어에 능숙한 개발자에게 적합하며 한국어 지원 여부는 향후 업데이트를 확인해야 합니다.

## 이런 분에게 추천합니다

AI 기반 챗봇이나 에이전트 서비스를 직접 개발하는 개발자에게 적합합니다. 서비스의 응답 품질을 지속적으로 관리하고 싶은 운영자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 사내 AI 고객 응대 봇을 운영할 때, 고객이 불만족한 대화 내용을 추적하여 답변 로직을 수정하는 데 사용합니다.
- **학생**: 졸업 작품으로 만든 AI 에이전트 서비스가 왜 특정 상황에서 멈추는지 디버깅할 때 상세 로그를 확인하는 용도로 씁니다.
- **소상공인**: 외부 개발자로 만든 AI 쇼핑몰 챗봇의 운영 상태를 직접 모니터링하며 비용이 과도하게 발생하지 않는지 체크할 때 활용합니다.

## 장단점

**장점**

- AI 에이전트의 복잡한 대화 과정을 실시간으로 추적하여 문제 발생 시 즉각적인 대응이 가능합니다.
- 응답 속도와 비용 효율성을 시각화된 그래프로 제공하여 서비스 운영의 가시성을 높여줍니다.
- 시스템 오류나 잘못된 답변을 자동으로 탐지하여 개발자의 수동 점검 시간을 획기적으로 줄여줍니다.
- 초기 개발 단계에서 활용 가능한 무료 플랜로 도입 비용에 대한 부담 없이 성능을 테스트할 수 있습니다.

**단점**

- 모든 인터페이스와 기술 문서가 영어로만 제공되어 한국어 사용자에게는 언어적 장벽이 존재합니다.
- 고급 분석 기능은 유료 플랜에서만 제공되므로 서비스 규모가 커질수록 유지 비용이 증가할 수 있습니다.
- 개발자 도구 특성상 전문적인 기술 지식이 요구되어 일반 사용자가 접근하기에는 난이도가 매우 높습니다.

## 주의사항

- **개인정보**: 에이전트 로그에 개인정보가 포함될 경우 서버로 전송될 수 있으므로, 민감 정보는 마스킹 처리 후 연동해야 합니다.
- **저작권/상업적 이용**: 상업적 서비스에 도구를 도입할 경우, 데이터 처리 방식이 저작권 관련 규정을 준수하는지 반드시 검토해야 합니다.
- **요금/한도**: 무료 플랜과 유료 플랜의 상세 한도는 공식 요금 페이지로 주기적으로 확인해야 예상치 못한 과금을 방지할 수 있습니다.
- **계정 관리**: 팀 단위로 도구를 사용할 경우 계정 권한을 적절히 분배하여 데이터 보안과 관리 효율성을 유지해야 합니다.

## 자주 묻는 질문

**코딩을 잘 몰라도 사용할 수 있나요?**

이 툴은 주로 개발자를 위한 서비스이므로 기본적인 API 연동 지식이 필요합니다. 비전공자라면 개발자와 협업하여 대시보드 데이터를 확인하는 용도로 활용하는 것이 좋습니다.

**어떤 AI 모델과 연동되나요?**

OpenAI의 GPT 시리즈를 포함하여 주요 LLM 기반 에이전트와 대부분 호환됩니다. 연동 설정은 문서화된 가이드를 따라 API 키를 입력하는 방식으로 간단히 진행됩니다.

**데이터 보안은 안전한가요?**

기업용 서비스 수준의 보안 표준을 준수하며 민감한 사용자 데이터는 비식별화 처리하여 관리할 수 있는 옵션을 제공합니다.

**일반인도 쉽게 사용할 수 있나요?**

이 도구는 AI 에이전트 개발자를 위한 전문 도구입니다. 코딩 지식이 없는 일반 사용자가 사용하기에는 난이도가 매우 높습니다.

**데이터 보안은 안전한가요?**

데이터 처리 보안 정책은 공식 홈페이지의 보안 문서를 참고해야 합니다. 민감한 데이터는 전송 전 반드시 비식별화 처리를 권장합니다.

**무료 플랜으로 실제 서비스 운영이 가능한가요?**

무료 플랜은 주로 개발 및 테스트용으로 적합합니다. 실제 대규모 서비스 운영 시에는 트래픽 한도를 고려하여 유료 플랜 전환이 필요합니다.

**한국어 에이전트도 모니터링할 수 있나요?**

기술적으로는 가능하나, 인터페이스가 영어 전용이므로 로그 분석 시 한국어 텍스트가 깨지거나 해석이 어려울 수 있습니다.
