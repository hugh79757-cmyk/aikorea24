Turn character images & frames into game-ready sprite sheets

## 한줄 요약

SpriteFrame은 정지된 캐릭터 이미지나 영상을 게임 개발에 즉시 사용할 수 있는 애니메이션 스프라이트 시트로 바꿔주는 서비스입니다. 복잡한 애니메이션 작업 없이도 AI가 자동으로 프레임을 생성해 주어 개발 효율을 크게 높여줍니다.

## 핵심 기능

- **이미지 투 스프라이트**: 정지된 캐릭터 이미지를 걷기, 뛰기 등 다양한 동작으로 자동 변환합니다.
- **영상 활용 변환**: 보유한 MP4 영상을 프레임 단위로 쪼개어 스프라이트 시트로 제작합니다.
- **게임 엔진 최적화**: 생성된 결과물을 PNG와 JSON 파일로 제공하여 게임 엔진에 바로 적용 가능합니다.

## 사용법

**1. 캐릭터 이미지 업로드**

메인 화면에서 캐릭터 PNG 또는 JPG 파일을 업로드합니다. 배경이 깨끗한 흰색인 전신 이미지를 사용해야 AI가 더 정확하게 인식합니다.

**2. 동작 설정 및 지시**

걷기, 달리기, 공격 등 원하는 동작을 선택하고 애니메이션 지시어를 입력합니다. AI가 캐릭터를 움직이게 하기 위해 필요한 프레임 수와 속도를 설정합니다.

**3. 스프라이트 시트 생성**

AI가 생성한 애니메이션을 미리보기로 확인한 후, 원하는 해상도와 프레임 크기를 조정합니다. 모든 설정이 완료되면 게임에 바로 사용하는 형태로 출력합니다.

**4. 데이터 내보내기**

생성된 결과물은 PNG 이미지와 함께 JSON 데이터 파일로 구성된 ZIP 형태로 다운로드합니다. 이 데이터를 유니티나 고도 엔진에 불러와 게임에 적용합니다.

비용 절약 팁: 무료 체험 크레딧으로 먼저 결과물의 퀄리티를 테스트한 후 유료 결제를 결정하는 것이 좋습니다.

## 한국어 지원

웹사이트 인터페이스는 영어로만 제공되지만, 직관적인 아이콘과 버튼 위주로 구성되어 있어 언어 장벽 없이 사용 가능합니다.

## 한국어 품질 실측

**게임 캐릭터 걷기 동작**

- 프롬프트: Side view, walking animation, character moving forward steadily.
- 결과 예시: 캐릭터가 옆모습으로 일정하게 걷는 모습이 담긴 스프라이트 시트 이미지와 각 프레임의 위치 정보가 포함된 JSON 파일이 생성됩니다.
- 관찰: 도구 자체가 영어 기반이므로 영어 프롬프트를 사용하는 것이 결과물 품질에 훨씬 유리합니다.

**영상에서 프레임 추출**

- 프롬프트: Extract 30 frames from the uploaded MP4 file.
- 결과 예시: 업로드한 영상 파일에서 30개의 정지 화면을 추출하여, 이를 하나의 스프라이트 시트 이미지로 자동 정렬해 보여줍니다.
- 관찰: 한국어 프롬프트는 지원하지 않으므로 영어 명령어를 사용해야 정상적인 작업이 가능합니다.

현재 도구는 한국어 인터페이스를 지원하지 않으며, 모든 명령과 설정이 영어로 진행됩니다. 따라서 영문 프롬프트를 활용해야 정확한 결과물을 얻을 수 있습니다.

## 자주 묻는 질문

**어떤 이미지 형식을 지원하나요?**

PNG, JPG, WebP 형식을 지원하며 최대 20MB 용량까지 업로드할 수 있습니다. 배경이 깔끔한 전신 캐릭터 이미지를 사용하면 더욱 정확한 결과를 얻을 수 있습니다.

**생성된 결과물은 어디에 사용하나요?**

생성된 PNG와 JSON 파일은 유니티(Unity)나 고도(Godot) 같은 게임 엔진에서 애니메이션 리소스로 바로 불러와 사용할 수 있습니다.

**상업적 이용이 가능한가요?**

일반적으로 유료 플랜을 사용하면 생성된 결과물을 상업적인 게임 프로젝트에 활용할 수 있습니다. 자세한 라이선스 규정은 서비스 이용 약관을 확인하시기 바랍니다.

**계정 없이도 사용할 수 있나요?**

PNG 프레임을 합치거나 MP4에서 프레임을 추출하는 기본 기능은 계정 없이도 즉시 사용 가능합니다. 하지만 AI 애니메이션 생성 등 고급 기능은 계정 생성 및 크레딧이 필요합니다.

**생성된 데이터를 유니티에서 어떻게 쓰나요?**

다운로드한 ZIP 파일 내의 PNG와 JSON 데이터를 유니티 프로젝트에 넣은 후, 스프라이트 에디터에서 슬라이스하여 애니메이션 클립으로 설정하면 됩니다.

**제공하는 JSON 파일의 용도는 무엇인가요?**

JSON 파일은 각 프레임의 위치와 시간 정보를 담고 있습니다. 이를 통해 게임 엔진이 스프라이트 시트를 올바르게 읽고 애니메이션을 재생할 수 있도록 돕는 역할을 합니다.

**이미지 파일 업로드 제한이 있나요?**

업로드하는 이미지 파일은 최대 20MB까지만 지원합니다. 또한, AI 기능 사용 시 처리 가능한 프레임 수에는 제한이 있으므로 화면의 안내를 참고하시기 바랍니다.
