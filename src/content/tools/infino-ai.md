## 한줄 요약

Infino AI는 복잡한 대용량 데이터를 효율적으로 저장하고 AI 에이전트가 이를 즉각적으로 검색 및 활용할 수 있게 돕는 도구입니다. 데이터베이스 관리의 복잡함을 줄여 개발자가 데이터를 더 빠르고 스마트하게 다룰 수 있도록 지원합니다.

## 핵심 기능

- **통합 데이터 검색**: SQL과 벡터 검색을 동시에 지원하여 데이터 활용도가 매우 높습니다.
- **고속 데이터 처리**: Parquet 파일 기반의 최적화로 대규모 데이터도 지연 없이 처리합니다.
- **AI 에이전트 최적화**: AI가 데이터를 직접 이해하고 분석할 수 있도록 최적화된 환경을 제공합니다.

## 사용법

**1. 데이터 소스 연결하기**

Infino AI 대시보드에 접속하여 분석할 데이터베이스나 Parquet 파일을 연결합니다. 설정 메뉴에서 데이터 소스 경로를 지정하면 시스템이 자동으로 데이터를 인덱싱합니다.

**2. SQL 및 벡터 검색 설정**

데이터 구조에 맞춰 SQL 쿼리 환경을 구성하고 AI 에이전트가 활용할 벡터 검색 옵션을 활성화합니다. 검색 엔진 설정 탭에서 인덱스 종류를 선택하여 검색 효율을 최적화합니다.

**3. AI 에이전트 연동하기**

API 키를 발급받아 개발 중인 AI 에이전트와 Infino를 연동합니다. 에이전트가 데이터베이스에 직접 접근하여 질문에 답변할 수 있도록 권한을 부여합니다.

**4. 실시간 데이터 분석 실행**

에이전트 인터페이스로 자연어로 데이터를 조회하거나 분석 요청을 보냅니다. Infino가 즉각적으로 대용량 데이터를 처리하여 정확한 답변을 생성합니다.

## 가격 정책

- **무료 플랜**: 오픈소스 기반으로 기본적인 데이터 검색 기능을 무료로 시작할 수 있습니다.
- **유료 플랜**: 엔터프라이즈 플랜은 별도 문의(약 100만 원~ 이상)를 통해 대규모 데이터 관리와 전담 기술 지원을 제공합니다.

비용 절약 팁: 초기에는 오픈소스 버전을 활용해 데이터 구조를 먼저 설계한 뒤 필요에 따라 클라우드 버전을 도입하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈소스 버전로 기본적인 데이터 검색 및 관리 기능을 무료로 사용할 수 있습니다. 별도의 메시지 제한은 없으나, 서버 구축 및 유지 관리를 사용자가 직접 수행해야 합니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 데이터 관리 기능과 함께 전담 기술 지원을 제공합니다. 기업의 보안 요구사항에 맞춘 최적화 환경이 포함됩니다.

- **클라우드 관리형 플랜** (공식 페이지 확인 필요): 인프라 관리 부담 없이 즉시 사용하는 클라우드 환경을 제공합니다. 데이터 규모에 따른 유연한 확장성을 지원합니다.

**환불과 해지**: 환불 및 결제 정책은 엔터프라이즈 계약 조건에 따라 상이하므로, 도입 전 영업팀로 상세 내용을 확인하시기 바랍니다.

## 한국어 지원

현재 공식 인터페이스 및 기술 문서는 영어로만 제공됩니다. 데이터 분석을 위한 SQL 명령어 등은 범용 언어를 사용하므로 코딩 지식이 있다면 사용에 큰 무리가 없습니다.

## 한국어 품질 실측

**매출 데이터 분석**

- 프롬프트: 지난달 제품별 매출 데이터를 SQL로 조회하고 가장 많이 팔린 품목의 특징을 요약해줘.
- 결과 예시: 데이터베이스에서 해당 기간의 매출 정보를 성공적으로 추출했습니다. 분석 결과, A 모델이 전체 매출의 40%를 차지하며 가장 높은 판매량을 기록했습니다.
- 관찰: 입력은 한국어로 가능하나, 데이터베이스 내부 필드명이 영어일 경우 결과값이 영어로 출력될 가능성이 큽니다.

**고객 리뷰 검색**

- 프롬프트: 최근 3개월간 고객 리뷰에서 '배송'과 관련된 불만 사항만 벡터 검색으로 찾아줘.
- 결과 예시: 배송 지연 및 파손과 관련된 리뷰 15건을 찾았습니다. 주요 불만 사항은 배송 기간 안내 미흡으로 확인되었습니다.
- 관찰: 한국어 질의를 벡터화하여 처리하는 성능은 우수하나, 기술 문서와 인터페이스는 여전히 영어로만 제공됩니다.

한국어 질의를 이해하고 처리하는 능력은 준수하지만 관리자 페이지와 기술 문서는 전적으로 영어로 되어 있습니다. 한국인 사용자가 전문적인 개발 지식 없이 접근하기에는 다소 난도가 높습니다.

## 이런 분에게 추천합니다

데이터를 다루는 백엔드 개발자, AI 에이전트 서비스를 구축하는 엔지니어, 대규모 로그 분석이 필요한 데이터 분석가에게 추천합니다.

## 실제 활용 예시

- **직장인**: 사내 대용량 고객 로그 데이터를 분석해야 할 때 Infino를 사용하여 필요한 정보만 빠르게 필터링합니다. 덕분에 수동으로 데이터를 처리하던 시간을 획기적으로 줄였습니다.
- **학생**: 데이터 과학 프로젝트를 진행하며 방대한 데이터셋을 다룰 때, 효율적인 검색 인덱스를 구축하기 위해 사용합니다. 복잡한 쿼리 없이도 AI가 데이터를 쉽게 읽어오도록 설정할 수 있습니다.
- **소상공인**: 직접 활용하기보다는 데이터 기반의 앱 서비스를 개발하는 소규모 스타트업 운영 시, 서비스 성능 최적화하려고 데이터베이스 관리 도구로 활용합니다.

## 장단점

**장점**

- SQL과 벡터 검색을 동시에 지원하여 데이터 활용의 범용성이 매우 뛰어납니다.
- Parquet 파일 기반의 최적화로 대규모 데이터도 지연 없이 빠르게 처리할 수 있습니다.
- AI 에이전트가 데이터를 즉각적으로 이해하고 분석할 수 있도록 최적화된 환경을 제공합니다.
- 오픈소스 버전이 제공되어 초기 비용 부담 없이 데이터 구조를 설계하고 테스트할 수 있습니다.

**단점**

- 인터페이스와 기술 문서가 영어로만 되어 있어 한국인 개발자에게 진입 장벽이 존재합니다.
- 고급 데이터 분석 도구로서 전문적인 개발 지식이 없으면 설정과 운영이 매우 어렵습니다.
- 엔터프라이즈 플랜의 정확한 비용 체계가 공개되어 있지 않아 예산 책정에 번거로움이 있습니다.

## 주의사항

- **개인정보**: 데이터베이스에 고객의 개인정보가 포함된 경우, 보안 설정 및 접근 권한을 철저히 관리해야 합니다.
- **저작권/상업적 이용**: 오픈소스 라이선스 규정을 확인하여 상업적 프로젝트에 적용 시 법적 문제가 없는지 검토하십시오.
- **요금/한도**: 클라우드 플랜 사용 시 데이터 처리량에 따른 추가 비용이 발생할 수 있으니 요금 체계를 미리 확인하십시오.
- **계정 관리**: 관리자 계정의 보안하려고 다중 인증을 설정하고 API 키가 외부로 유출되지 않도록 주의하십시오.

## 자주 묻는 질문

**코딩을 전혀 모르는 초보자도 사용할 수 있나요?**

안타깝게도 이 도구는 SQL과 데이터 구조에 대한 이해가 필요한 개발자용 도구입니다. 일반 사용자가 단순히 문서를 요약하거나 글을 쓰는 용도로는 적합하지 않습니다.

**기존에 사용하던 데이터베이스와 무엇이 다른가요?**

가장 큰 차이는 AI 에이전트가 데이터를 더 쉽게 이해하도록 최적화된 벡터 검색 기능을 내장하고 있다는 점입니다. 기존 DB보다 AI 연동 시 훨씬 빠르고 정확한 결과를 얻을 수 있습니다.

**데이터 보안은 안전한가요?**

로컬 환경에서 직접 운영하거나 보안이 강화된 클라우드 버전을 선택할 수 있습니다. 기업용 솔루션인 만큼 데이터 접근 제어와 보안 표준을 준수하고 있습니다.

**SQL과 벡터 검색을 왜 동시에 사용해야 하나요?**

정형 데이터의 정확한 조회와 비정형 데이터의 의미적 검색을 결합하여 AI의 답변 정확도를 높이기 위함입니다. 두 방식을 병행하면 더욱 정교한 데이터 분석이 가능합니다.

**오픈소스 버전으로 시작해도 충분한가요?**

데이터 구조 설계와 초기 성능 테스트 단계에서는 충분합니다. 다만, 대규모 트래픽을 처리하거나 전담 지원이 필요한 시점에는 유료 플랜 도입을 고려해야 합니다.

**한국어 데이터도 원활하게 검색되나요?**

데이터 내의 한국어 텍스트는 검색 가능하지만, 시스템이 한국어 형태소 분석을 완벽하게 지원하는지는 설정 환경에 따라 달라질 수 있습니다.

**기존 데이터베이스를 그대로 사용할 수 있나요?**

Infino는 기존 데이터베이스와 연동하여 데이터를 효율적으로 인덱싱할 수 있도록 지원합니다. 다만, 최적의 성능을 위해 데이터 형식을 Parquet 등으로 변환하는 과정이 필요할 수 있습니다.
