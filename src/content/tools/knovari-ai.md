## 한줄 요약

Knovari AI는 기업의 기밀 문서나 고객 데이터가 포함된 자료를 공유할 때, 민감한 정보를 자동으로 감지하고 삭제해주는 보안 도구입니다. 수작업으로 일일이 내용을 검토하던 번거로움을 줄여주어, 데이터 유출 걱정 없이 안전하게 협업하는 데 도움이 되습니다.

## 핵심 기능

- **자동 정보 마스킹**: 개인 식별 정보를 AI가 스스로 찾아내어 안전하게 가려줍니다.
- **맥락 기반 탐지**: 단순 키워드가 아닌 문맥을 파악해 민감한 정보를 더욱 정교하게 제거합니다.
- **인사이트 보존**: 보안 정보는 지우되, 문서의 핵심 내용과 통찰은 그대로 유지합니다.

## 사용법

**1. 문서 업로드**

Knovari AI 대시보드에서 보안 처리가 필요한 파워포인트나 문서를 업로드합니다. 드래그 앤 드롭 방식으로 간편하게 파일을 불러올 수 있습니다.

**2. 민감 정보 감지**

AI가 문서의 문맥을 분석하여 고객명, 계좌번호, 계약 조항 등 민감한 정보를 자동으로 찾아냅니다. 전체 문서 구조를 유지하며 정교하게 식별합니다.

**3. 마스킹 및 수정**

식별된 정보를 삭제하거나 가리는 마스킹 작업을 수행합니다. 필요에 따라 사용자가 직접 수정 사항을 검토하고 조정할 수 있는 편집 기능을 제공합니다.

**4. 결과물 다운로드**

보안 처리가 완료된 문서를 최종 확인 후 다운로드합니다. 원본의 차트나 통계 데이터는 그대로 유지되므로 업무 보고용으로 즉시 활용 가능합니다.

## 가격 정책

- **무료 플랜**: 기본적인 보안 기능을 체험해볼 수 있는 무료 플랜을 제공합니다.
- **유료 플랜**: Freemium 모델로 운영되며, 상세 가격은 공식 웹사이트의 기업용 플랜 문의로 확인 가능합니다.

비용 절약 팁: 무료 플랜으로 먼저 문서 처리 성능을 테스트해본 뒤 팀 단위 도입을 고려하는 것을 추천합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: Freemium 모델로 운영되며, 무료 플랜로 기본적인 보안 기능을 체험할 수 있습니다. 구체적인 처리 가능 문서 수나 기능 제한은 공식 홈페이지에서 확인이 필요합니다.

- **유료 플랜(Paid Upgrades)** (공식 페이지 확인 필요): 기업용 보안 요구사항을 충족하는 고급 기능과 대량 문서 처리 권한을 제공합니다.

- **기업용 플랜(Enterprise)** (공식 페이지 확인 필요): SOC 2 Type II 준수 및 프라이빗 클라우드 배포 옵션 등 고도화된 보안 환경을 지원합니다.

**환불과 해지**: 결제 후 14일 이내에 환불을 요청할 수 있으며, 자동 갱신 기능이 포함되어 있으므로 결제 설정을 미리 확인해야 합니다.

## 한국어 지원

현재 인터페이스는 영어로 제공되지만 문서 내 텍스트 처리 시 한국어 데이터도 문맥 파악로 보안 처리가 가능합니다.

## 한국어 품질 실측

**고객사 보고서 보안 처리**

- 프롬프트: 이 파워포인트 문서 내에 포함된 모든 고객사 이름과 계약 금액을 식별하여 마스킹해 주세요.
- 결과 예시: AI가 문서 내 'OOO사', '₩000,000,000'과 같이 민감 정보를 찾아내어 텍스트를 블라인드 처리한 결과물을 생성합니다.
- 관찰: 한국어 문맥을 이해하고 처리하지만 전문적인 법률 용어는 검토가 필요합니다.

**개인정보 비식별화**

- 프롬프트: 문서에 포함된 담당자 성함과 연락처 정보를 찾아 비식별화 처리해 주세요.
- 결과 예시: AI가 문서의 맥락을 파악하여 이름과 전화번호 부분을 자동으로 가리고, 나머지 통계 수치는 그대로 보존합니다.
- 관찰: 한국어 이름과 연락처 형식를 준수한 탐지율을 보입니다.

인터페이스는 영어로 제공되지만 한국어 문서 내의 민감 정보 탐지 능력은 준수합니다. 다만 복잡한 한국어 문장 구조에서는 추가적인 검수가 필요할 수 있습니다.

## 이런 분에게 추천합니다

고객 데이터를 다루는 컨설턴트, 사내 보안 규정이 엄격한 직장인, 민감 정보를 포함한 문서를 자주 공유해야 하는 관리자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 고객사 보고서를 상부에 보고하기 전, 개인정보를 일일이 지우는 대신 이 툴을 사용하여 업무 시간을 대폭 단축합니다.
- **학생**: 연구 데이터를 외부와 공유할 때, 참여자의 신상 정보가 노출되지 않도록 데이터 세트를 안전하게 익명화합니다.
- **소상공인**: 고객 상담 내역을 분석 업체에 맡길 때, 고객의 연락처와 성함을 자동으로 제외하여 개인정보 유출 사고를 예방합니다.

**단점:**

## 장단점

**장점**

- 파워포인트 문서의 레이아웃을 깨뜨리지 않고 민감한 정보만 정교하게 마스킹할 수 있습니다.
- 단순 키워드 검색이 아닌 문맥 기반의 탐지 방식을 사용하여 정보 유출 위험을 획기적으로 낮춰줍니다.
- SOC 2 Type II 인증을 획득하여 기업 수준의 높은 보안 표준을 준수하고 있어 신뢰할 수 있습니다.
- 수작업으로 수시간 걸리던 문서 보안 작업을 단 몇 분 만에 완료하여 업무 효율성을 극대화합니다.

**단점**

- 사용자 인터페이스가 영어로만 제공되어 한국어 사용자가 초기 설정 시 다소 불편함을 느낄 수 있습니다.
- 무료 플랜의 상세 한도가 명확히 공개되어 있지 않아 대량 작업 시 비용 예측이 어려울 수 있습니다.
- 고급 보안 기능은 유료 플랜로서만 제공되므로 소규모 팀에는 비용 부담이 발생할 수 있습니다.

## 주의사항

- **개인정보**: 보안 도구라 하더라도 민감한 개인정보를 업로드할 때는 사내 보안 규정을 반드시 준수해야 합니다.
- **저작권/상업적 이용**: 생성된 결과물의 상업적 활용 권한은 서비스 이용 약관을 반드시 확인하시기 바랍니다.
- **요금/한도**: 자동 갱신 기능이 포함되어 있으므로 무료 체험 후 유료 전환 여부를 신중히 결정해야 합니다.
- **계정 관리**: 기업용 계정 사용 시 관리자 권한을 설정하여 데이터 접근 범위를 제한하는 것이 안전합니다.

## 자주 묻는 질문

**문서에 포함된 한글 개인정보도 잘 지워지나요?**

네, 문맥을 분석하는 AI 기반이므로 한국어 문서 내의 이름이나 주소 등도 효과적으로 식별하여 지울 수 있습니다.

**데이터가 외부로 유출될 위험은 없나요?**

보안을 최우선으로 설계된 툴이지만 매우 민감한 국가 기밀이나 극비 자료는 보안 정책에 따라 사용을 신중히 결정해야 합니다.

**어떤 형식의 파일을 처리할 수 있나요?**

일반적인 문서 파일(PDF, Word 등)과 이미지 파일, 코드 파일 등 다양한 형식의 데이터를 지원합니다.

**파워포인트 외에 다른 문서도 처리 가능한가요?**

주로 파워포인트 XML 기반의 슬라이드 작업에 최적화되어 있으나, 이미지나 기타 문서 형식도 지원합니다.

**한국어 문서도 완벽하게 보안 처리가 되나요?**

문맥 기반 탐지를 지원하므로 한국어 데이터도 처리 가능하지만, 정확도를 위해 최종 확인 과정을 거치는 것을 권장합니다.

**데이터가 클라우드에 저장되나요?**

보안을 위해 SOC 2 표준을 준수하며, 필요시 프라이빗 클라우드 배포 옵션을 선택하여 데이터 보안을 강화할 수 있습니다.

**수정된 내용을 되돌릴 수 있나요?**

수정 작업은 투명하게 기록되며, 검토 및 조정 워크플로우를 통해 필요시 설정을 변경할 수 있습니다.
