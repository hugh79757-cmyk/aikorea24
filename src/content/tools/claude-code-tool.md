## 한줄 요약

터미널에서 자연어로 명령하면 Claude가 코드베이스를 분석하고 복잡한 개발 작업을 자율적으로 수행하는 AI 코딩 에이전트입니다.

## Cursor·Windsurf와의 차이

GUI 기반 IDE가 아닌 터미널(CLI) 환경에서 동작하며, 파일 읽기·쓰기·터미널 명령 실행까지 직접 수행합니다. CI/CD 파이프라인이나 서버 환경에 통합하기 쉬워 자동화 워크플로우 구축에 강점이 있습니다.

## 이런 분에게 추천

터미널에 익숙한 백엔드·DevOps 개발자, 반복적인 코드 작업을 완전 자동화하고 싶은 시니어 개발자에게 추천합니다.
