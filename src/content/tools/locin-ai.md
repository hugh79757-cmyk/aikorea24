## 한줄 요약

LocIn AI는 앱의 다국어 번역을 지원하며 브랜드의 톤을 유지합니다. 번역 과정이 간편해져 글로벌 시장 진출이 쉬워집니다.

## 핵심 기능

- **자동화된 번역**: 번역 과정을 자동화하여 시간 절약이 가능합니다.
- **톤 유지**: 브랜드 목소리를 살려 번역하여 일관성을 유지합니다.
- **다국어 지원**: 50개 이상의 언어를 지원하여 글로벌 진출이 용이합니다.

## 사용법

**1. CLI 도구 설치 및 설정**

프로젝트 환경에서 터미널을 열고 LocIn AI 명령어를 실행하여 코드베이스 스캔과 초기 설정을 진행합니다. React나 Next.js 같은 프레임워크를 자동으로 감지하여 번역 파이프라인을 구축합니다.

**2. 전체 번역 플로우 실행**

터미널에 명령어 한 줄을 입력하여 소스 코드 추출, 업로드, 번역, 내보내기, 검증까지의 7가지 단계를 한 번에 처리합니다. 수동으로 파일을 주고받을 필요 없이 자동화된 파이프라인으로 작동합니다.

**3. 코드 맥락 및 변수 확인**

일반 인공지능과 달리 코드의 컴포넌트와 주석을 읽어 실제 UI 맥락에 맞는 번역을 제공합니다. 변수나 중괄호({}) 같은 문자열 보간이 깨지지 않도록 안전하게 유지되었는지 결과물을 확인합니다.

**4. 빌드 및 배포 연동**

CI/CD 파이프라인에 LocIn을 통합하여 깃허브 메인 브랜치 푸시 등의 이벤트 발생 시 자동으로 최신 번역이 반영되도록 설정합니다. 릴리즈 지연 없이 글로벌 사용자에게 즉시 배포할 수 있습니다.

## 한국어 지원

LocIn AI는 한국어를 포함한 다국어 번역을 지원하며 사용자 친화적인 인터페이스를 제공합니다.

## 한국어 품질 실측

**앱 UI 다국어 번역**

- 프롬프트: 환영 메시지 컴포넌트의 영어 문구와 변수를 한국어로 자연스럽게 번역해 주세요.
- 결과 예시: 환영 문구와 사용자 이름 변수가 코드 구조를 해치지 않으며 한국어 UI 맥락에 맞게 자연스럽게 출력될 것입니다.
- 관찰: 코드 내 변수와 UI 맥락을 유지하면서 한국어 존댓말과 번역투를 자연스럽게 처리하는지 확인이 필요합니다.

**버튼 및 메뉴 텍스트**

- 프롬프트: 예약하기 버튼의 'Book'이라는 단어를 주변 코드 맥락에 맞춰 올바르게 번역해 주세요.
- 결과 예시: 단순 서적을 뜻하는 번역이 아니라 예약 기능의 버튼에 알맞은 올바른 한국어 UI 용어로 변환될 것입니다.
- 관찰: 중의적인 단어가 UI 위치와 주변 소스 코드의 맥락에 따라 정확한 한국어로 반영되는지 살펴볼 수 있습니다.

개발 환경에 특화되어 소스 코드와 변수를 보호하면서 번역하므로 한국어 UI에서도 문법적 오류 없이 깔끔한 결과물을 기대할 수 있습니다.

## 장단점

**장점**

- 단순한 JSON 번역을 넘어 소스 코드와 컴포넌트, 주석까지 읽어 정확한 맥락을 파악합니다.
- 명령어 한 번으로 스캔부터 추출, 번역, 검증까지 전체 파이프라인을 완전 자동화합니다.
- 일반 거대 언어 모델이 자주 깨뜨리는 변수와 문자열 보간을 안전하게 보호합니다.
- 리액트, 뷰, 넥스트제이스 등 주요 프레임워크와 CI/CD 파이프라인에 쉽게 연동됩니다.

**단점**

- 개발자 친화적인 CLI 도구 중심으로 설계되어 비개발자 직군이 단독으로 활용하기에는 다소 어렵습니다.
- 무료 플랜과 유료 플랜의 구체적인 크레딧 한도 및 기능 차이가 명확하게 공개되어 있지 않습니다.
- 코딩 지식이 없는 마케터나 기획자가 직접 번역 파일을 관리하고 수정하는 데 한계가 있습니다.

## 주의사항

- **개인정보**: 소스 코드 내부에 민감한 개인정보나 API 시크릿 키가 포함된 상태로 번역 서버에 업로드되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 인공지능이 생성한 다국어 번역 결과물의 상업적 사용 권한 및 소유권 규정은 공식 서비스 약관을 별도로 확인해야 합니다.
- **요금/한도**: 프로젝트 규모에 따라 번역 요청량이 급증할 수 있으므로 요금제별 월간 사용 한도와 추가 과금 여부를 사전에 점검해야 합니다.
- **계정 관리**: 개발팀과 번역팀이 협업할 때 API 액세스 키와 터미널 권한이 안전하게 관리되도록 보안 설정에 신경 써야 합니다.

## 자주 묻는 질문

**LocIn AI는 어떤 언어를 지원하나요?**

LocIn AI는 50개 이상의 언어를 지원하여 다양한 시장을 겨냥할 수 있습니다.

**번역 품질은 어떤가요?**

AI가 코드와 문맥을 이해하여 보다 자연스러운 번역 결과를 제공합니다.

**유료 플랜의 주요 혜택은 무엇인가요?**

유료 플랜에서는 더 많은 기능과 빠른 지원을 받을 수 있습니다.

**어떤 프레임워크와 개발 환경을 지원하나요?**

React, Next.js, Vue, Nuxt 및 표준 i18next 설정을 CLI가 자동으로 감지합니다. 커스텀 환경을 사용하는 경우 설정 파일을 통해 파일 경로를 직접 지정할 수 있습니다.

**번역 과정에서 코드 내 변수나 중괄호가 손상되지 않나요?**

일반 인공지능과 달리 변수와 문자열 보간을 철저하게 보호하도록 설계되어 있습니다. 코드가 깨지지 않도록 안전하게 다국어 스트링을 유지합니다.

**수동으로 모든 번역을 검토하고 수정해야 하나요?**

자동 파이프라인 안에서 검증 단계까지 한 번에 처리되므로 수동으로 일일이 손볼 부담이 크게 줄어듭니다. 터미널이나 CI 환경에서 빌드 직후 바로 반영할 수 있습니다.

**CI/CD 파이프라인에 도구를 어떻게 연동하나요?**

깃허브 푸시 등의 이벤트가 발생할 때 터미널 명령어 형태로 자동 실행되도록 설정할 수 있습니다. 수동 핸드오프 대기 없이 업데이트된 번역을 즉시 배포할 수 있습니다.
