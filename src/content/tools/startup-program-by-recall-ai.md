## 한줄 요약

Recall.ai는 화상 회의 플랫폼의 데이터를 내 소프트웨어로 가져올 수 있게 해주는 개발자용 API 도구입니다. 복잡한 연동 과정을 생략하고 회의 기록, 영상, 캘린더 데이터를 활용한 서비스를 빠르게 만들 수 있게 합니다.

## 핵심 기능

- **통합 API 제공**: 줌, 구글 미트 등 다양한 플랫폼의 데이터를 하나의 API로 관리합니다.
- **회의 데이터 연동**: 회의 영상, 음성, 캘린더 정보를 내 앱에 실시간으로 가져옵니다.
- **스타트업 할인**: 초기 창업자하려고 시간당 0.25달러의 저렴한 비용으로 API를 제공합니다.

## 사용법

**1. 스타트업 프로그램 신청**

공식 홈페이지의 스타트업 프로그램 페이지로 이동하여 회사 정보와 구축 중인 제품에 대한 내용을 작성하고 신청서를 제출합니다.

**2. 승인 및 계정 설정**

운영 팀의 심사 및 승인을 거치면 초기 할인 혜택이 적용된 개발자 계정을 활성화하여 API 연동 준비를 마칩니다.

**3. API 및 SDK 연동**

회의 봇 API, 데스크톱 및 모바일 녹화 SDK, 캘린더 API 등의 도구를 활용하여 필요한 화상 회의 데이터를 서비스에 직접 연결합니다.

**4. 데이터 수집 및 개발**

줌, 구글 미트 등 다양한 플랫폼의 녹화 영상, 대화 내용, 메타데이터를 안정적으로 수집하며 본격적인 맞춤형 기능을 개발합니다.

## 가격 정책

- **무료 플랜**: 별도의 무료 플랜은 명시되어 있지 않으나, 스타트업을 위한 할인된 요금제를 제공합니다.
- **유료 플랜**: 스타트업 전용 요금제(시간당 약 350원)를 통해 초기 개발 비용을 크게 절감할 수 있습니다.

비용 절약 팁: 초기 단계의 스타트업이라면 공식 홈페이지의 스타트업 프로그램을 신청하여 할인 혜택을 반드시 확인하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 제공된 크롤링 텍스트에 별도의 상시 무료 플랜 한도는 명시되어 있지 않습니다. 다만 초기 스타트업 프로그램로 할인된 요금으로 서비스를 이용할 수 있습니다.

- **스타트업 프로그램 요금제** (시간당 0.25달러 (약 350원)): 첫 10,000시간의 녹화 사용량 동안 적용되는 할인된 요금으로, 회의 데이터 관련 제품을 만드는 초기 스타트업을 지원합니다.

- **일반 유료 플랜** (공식 페이지 확인 필요): 스타트업 프로그램 적용 대상 외의 일반 기업이나 기본 사용량을 초과하는 경우에 적용되는 요금제입니다.

**환불과 해지**: 환불, 해지 및 정기 결제 변경에 대한 구체적인 정책은 공식 홈페이지의 요금 페이지나 고객센터 문의로 확인이 필요합니다.

## 한국어 지원

API 문서 및 서비스 인터페이스는 모두 영어로 제공됩니다. 한국어 처리를 위해서는 별도의 번역 API를 연동해야 합니다.

## 한국어 품질 실측

**화상회의 봇 연동**

- 프롬프트: Zoom 회의를 자동으로 녹화하고 텍스트로 변환하기 위해 Recall.ai API를 호출하는 코드를 작성합니다.
- 결과 예시: API endpoint를 통해 줌 회의에 봇을 참가시키고 녹화 파일을 받아오는 개발용 JSON 응답 데이터가 생성됩니다.
- 관찰: 개발자용 API 서비스이므로 인터페이스와 응답 데이터는 모두 영어로 제공됩니다.

**캘린더 데이터 연동**

- 프롬프트: Google Calendar에 등록된 회의 일정과 녹화본을 매칭하여 캘린더 API 연동 결과를 확인합니다.
- 결과 예시: 회의 일정의 메타데이터와 녹화 파일이 연결되어 캘린더 ID와 함께 반환되는 구조를 보여줍니다.
- 관찰: 한국어 미지원 서비스이므로 회의 제목 등이 포함될 경우 별도의 인코딩이나 번역 처리가 필요합니다.

본 도구는 개발자를 위한 API 서비스로 대화면 인터페이스나 프롬프트 응답 형태가 아닙니다. 문서와 설정 화면이 모두 영문으로 제공되므로 국내 개발자가 이용할 때 추가적인 번역 확인이 필요합니다.

## 이런 분에게 추천합니다

회의록 자동화 서비스를 기획 중인 개발자에게 추천합니다. 고객 상담 데이터를 분석하여 인사이트를 얻고자 하는 기업에게 적합합니다. 화상 회의 플랫폼 연동에 어려움을 겪는 기술 스타트업에 유용합니다.

## 실제 활용 예시

- **직장인**: 사내 회의 자동 기록 시스템을 구축하여 팀원들의 업무 효율을 높일 수 있습니다. 회의 내용을 자동으로 텍스트화하여 공유함으로써 기록 누락을 방지합니다.
- **학생**: 온라인 강의 내용을 자동으로 요약해주는 학습 보조 앱을 개발할 수 있습니다. 강의 중 중요한 내용을 자동으로 추출하여 복습 시간을 단축합니다.
- **소상공인**: 고객과의 화상 상담 내용을 데이터화하여 서비스 개선점을 찾을 수 있습니다. 상담 중 자주 나오는 질문을 분석하여 응대 매뉴얼을 최적화합니다.

- 초기 스타트업 프로그램은 별도의 심사 과정을 거쳐야 하므로 즉시 가입하여 이용하는 데 제약이 있습니다.

- **계정 관리**: API 키와 개발자 계정 권한이 유출될 경우 민감한 회의 데이터가 노출될 수 있으므로 보안 관리에 각별히 유의해야 합니다.

## 자주 묻는 질문

**개발 지식이 없어도 사용할 수 있나요?**

아니요, 이 툴은 개발자를 위한 API 서비스이므로 기본적인 프로그래밍 지식이 필수적입니다. 개발자가 아닌 경우, 이 툴을 활용해 만들어진 완제품 서비스를 이용하시는 것을 권장합니다.

**한국어 회의도 분석할 수 있나요?**

Recall.ai는 회의 데이터를 수집하는 도구이므로, 수집된 음성 데이터를 한국어 인식 엔진(STT)에 연결하면 한국어 회의 분석도 충분히 가능합니다.

**보안은 안전한가요?**

기업용 데이터를 다루는 만큼 보안을 최우선으로 설계되어 있습니다. 다만, 실제 서비스 도입 시 데이터 저장 및 처리 정책을 상세히 검토하시기 바랍니다.

**스타트업 프로그램 신청은 어떤 기업이 대상인가요?**

대화 데이터를 활용하여 제품을 만드는 초기 단계의 스타트업을 대상으로 하며, 신청서 작성 후 운영 팀의 심사를 거쳐 승인됩니다.

**지원하는 화상 회의 플랫폼의 종류는 무엇인가요?**

줌, 구글 미트, 마이크로소프트 팀즈, 슬랙 등 다양한 주요 화상 회의 및 협업 플랫폼의 녹화 인프라를 안정적으로 지원합니다.

**회의 봇 외에 다른 녹화 방식도 제공하나요?**

봇 방식 외에도 기기 내에서 직접 녹화하는 데스크톱 및 모바일 녹화 SDK 기능을 함께 제공합니다.

**한국어 회의 음성도 텍스트로 변환할 수 있나요?**

Recall.ai는 회의 데이터 연동 API를 제공하며, 한국어 음성 인식 및 처리를 위해서는 별도의 번역 또는 STT 연동이 필요할 수 있습니다.
