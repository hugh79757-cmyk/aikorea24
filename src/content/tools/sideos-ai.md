## 한줄 요약

sideOS는 맥북 화면을 인식하여 사용자의 지시를 수행하는 AI 에이전트입니다. 단순한 텍스트 답변을 넘어 직접 마우스를 클릭하고 앱을 조작함으로써 반복적인 PC 업무 시간을 획기적으로 줄여줍니다.

## 핵심 기능

- **화면 인식 기능**: 현재 화면 상태를 파악해 버튼 클릭이나 메뉴 선택을 스스로 수행합니다.
- **로컬 AI 처리**: 데이터가 외부 서버로 전송되지 않아 보안이 중요한 업무에 적합합니다.
- **음성 제어**: 키보드 단축키를 누른 채 말만 하면 복잡한 마우스 클릭 과정을 대신합니다.

## 사용법

**1. 설치 및 접근 권한 허용**

sideOS를 설치하고 맥북의 손쉬운 사용 권한을 허용합니다. 맥북 상단 노치 영역에 아이콘이 나타나면 준비가 완료된 것입니다.

**2. 단축키 입력 및 음성 명령**

Control + Option 키를 누른 상태에서 수행할 작업을 말합니다. 예를 들어 '이메일 확인 후 답장해줘'와 같이 자연스럽게 지시합니다.

**3. 화면 영역 지정 및 제어**

특정 버튼이나 영역을 지목해야 할 경우, 마우스로 화면을 원형으로 표시합니다. AI가 해당 영역을 인식하여 클릭하거나 타이핑을 수행합니다.

**4. 작업 결과 확인 및 종료**

AI가 앱을 조작하는 과정을 지켜보며 작업이 완료되기를 기다립니다. 완료 후 결과를 AI가 음성으로 보고합니다.

## 가격 정책

- **무료 플랜**: 무료 체험판은 제공되지 않으며 웹사이트로 구매가 가능합니다.
- **유료 플랜**: One-time Purchase(약 6~8만 원 내외 예상, 환율에 따라 변동)로 한 번 구매 시 평생 이용 가능합니다.

비용 절약 팁: 구독료 부담 없이 한 번의 결제로 모든 기능을 평생 사용할 수 있어 장기적으로 경제적입니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 공식 홈페이지에서는 무료 체험판을 제공하지 않습니다. 모든 기능을 사용하기 위해서는 유료 구매가 필요합니다.

- **One-time Purchase** (공식 요금 페이지에서 확인 필요): 한 번의 결제로 평생 이용이 가능하며 추가 구독료 없이 모든 AI 에이전트 기능을 사용합니다.

**환불과 해지**: 환불 정책은 구매 시점의 공식 홈페이지 약관을 따라야 하므로 결제 전 확인이 필요합니다.

## 한국어 지원

현재 인터페이스와 음성 인식은 영어 기반으로 작동합니다. 한국어 입력은 가능할 수 있으나 시스템 제어 명령은 영어로 수행하는 것이 가장 정확합니다.

## 한국어 품질 실측

**이메일 초안 작성**

- 프롬프트: 지메일 열어서 팀원에게 주간 회의 시간 변경 메일 써줘.
- 결과 예시: 지메일 앱을 실행하고 수신인과 제목을 입력합니다. 본문에 '주간 회의 시간을 월요일 오전으로 변경합니다'라는 내용을 작성합니다.
- 관찰: 시스템 명령은 영어로 수행할 때 가장 정확하며 한국어 입력은 가능하나 제어 정확도가 떨어질 수 있습니다.

**일정 등록**

- 프롬프트: 캘린더 열어서 내일 오후 2시에 미팅 추가해줘.
- 결과 예시: 캘린더 앱을 열고 내일 날짜를 선택합니다. 오후 2시 슬롯에 '미팅'이라는 이벤트를 입력하고 저장합니다.
- 관찰: 한국어 명령을 이해할 수 있으나, 복잡한 UI 제어 시에는 영어 명령어가 더 안정적입니다.

한국어 입력을 지원하지만 인터페이스 및 시스템 제어 명령은 영어에 최적화되어 있습니다. 한국어 사용 시 번역 과정에서 미세한 오작동이 발생할 수 있으므로 주의가 필요합니다.

## 이런 분에게 추천합니다

반복적인 컴퓨터 작업으로 시간을 뺏기는 직장인, 맥북을 활용해 생산성을 극대화하고 싶은 프리랜서, 보안 문제로 클라우드 AI 사용이 조심스러운 사용자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 아침 반복되는 웹 사이트 로그인과 데이터 추출 업무를 음성 명령 한 번으로 끝낼 수 있습니다.
- **학생**: 여러 개의 참고 자료 PDF를 열어두고 특정 내용을 찾아 정리하는 작업을 AI에게 맡겨 시간을 절약합니다.
- **소상공인**: 고객에게 보낼 안내 메일을 화면에 띄워두고 AI에게 적절한 답장 작성을 지시하여 응대 속도를 높입니다.

## 유사 툴과 비교

**장점:**
- 로컬 환경에서 작동하여 보안이 강력함
- 구독료 없는 일회성 결제 방식

**단점:**
- macOS 전용으로 윈도우 사용자 사용 불가
- 한국어 명령 인식 정밀도가 다소 낮을 수 있음

**이런 분에게 가장 적합합니다:** 보안이 중요한 환경에서 맥북의 반복적인 마우스·키보드 작업을 자동화하려는 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 맥북의 노치 영역에 상주하여 필요할 때 즉시 호출할 수 있어 접근성이 매우 뛰어납니다.
- 사용자의 데이터를 외부 서버로 보내지 않고 로컬에서 처리하여 보안성이 매우 높습니다.
- 별도의 API 키 없이도 화면의 버튼을 직접 인식하여 마우스 클릭과 타이핑을 수행합니다.
- 구독형 서비스가 아닌 일회성 결제 방식을 채택하여 장기적인 비용 부담이 적습니다.

**단점**

- 한국어보다는 영어 명령에 최적화되어 있어 한국어 사용 시 정확도가 다소 낮을 수 있습니다.
- 무료 체험판을 제공하지 않아 구매 전 기능을 직접 테스트해 볼 수 없는 제약이 있습니다.
- 맥 OS 환경에서만 작동하므로 윈도우 사용자나 다른 운영체제 환경에서는 사용할 수 없습니다.

## 주의사항

- **개인정보**: 로컬 AI 처리를 지원하지만 작업 중 화면에 노출되는 민감한 정보가 AI 모델에 의해 처리될 수 있으므로 주의해야 합니다.
- **저작권/상업적 이용**: 상업적 이용 시 해당 도구의 라이선스 규정을 확인해야 하며 생성된 결과물의 저작권은 사용자 본인에게 있습니다.
- **요금/한도**: 일회성 결제 방식이지만 향후 업데이트나 정책 변경에 따라 추가 비용이 발생할 가능성이 있는지 확인이 필요합니다.
- **계정 관리**: 구매한 라이선스는 본인의 맥북 기기에 귀속될 수 있으므로 계정 연동 및 관리 정책을 반드시 확인하십시오.

## 자주 묻는 질문

**개인정보가 외부로 유출되지 않나요?**

sideOS는 로컬 AI를 사용하여 데이터를 처리하므로 사용자의 정보가 서버로 전송되지 않습니다. 보안이 중요한 기업 환경에서도 안심하고 사용할 수 있습니다.

**윈도우 컴퓨터에서도 사용할 수 있나요?**

아니요, 현재 sideOS는 macOS 전용으로 설계되었습니다. 맥북의 노치(Notch) 기능을 활용하는 구조이므로 윈도우 환경에서는 설치가 불가능합니다.

**어떤 작업을 가장 잘 수행하나요?**

웹 사이트 탐색, 파일 이동, 앱 실행 등 사람이 반복적으로 마우스를 클릭해야 하는 단순 업무를 가장 잘 수행합니다. 복잡한 창의적 작업보다는 자동화 업무에 특화되어 있습니다.

**인터넷 연결 없이도 사용할 수 있나요?**

로컬 AI 처리를 기반으로 하므로 기본적인 화면 제어는 인터넷 연결 없이도 가능할 수 있습니다. 다만 일부 외부 검색 기능은 인터넷이 필요합니다.

**어떤 앱들을 제어할 수 있나요?**

메일, 캘린더, 메모장 등 맥북의 기본 앱은 물론 화면 상에 표시되는 대부분의 앱을 버튼 인식으로 제어할 수 있습니다.

**화면 인식은 어떤 방식으로 작동하나요?**

단순 이미지 분석뿐만 아니라 접근성 트리(Accessibility Tree)를 사용하여 버튼의 이름을 정확히 파악하고 클릭합니다.

**사생활 보호는 확실한가요?**

데이터가 외부 서버로 전송되지 않고 로컬에서 처리되므로 정보 유출 위험이 낮습니다. 모든 작업은 사용자의 기기 내에서만 이루어집니다.
