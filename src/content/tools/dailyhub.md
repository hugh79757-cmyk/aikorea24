## 한줄 요약

복잡한 노션이나 리니어 대신 가볍고 직관적으로 프로젝트와 할 일, 매일의 습관을 관리할 수 있는 개인용 업무 허브 툴입니다. 복잡한 설치 없이 간단한 명령어 한 줄로 내 컴퓨터에서 바로 실행할 수 있습니다.

## 핵심 기능

- **로컬 실행**: 복잡한 도커 설정 없이 명령어 한 줄로 빠르게 실행합니다.
- **습관 추적**: 매일 지켜야 하는 루틴과 연속 달성 기록을 관리합니다.
- **업무 통합**: 프로젝트와 할 일을 하나의 화면에서 깔끔하게 정리합니다.

## 사용법

**1. 터미널에서 프로그램 실행하기**

컴퓨터의 터미널(CMD 또는 터미널) 프로그램을 엽니다. 'npx @baselhusam/daily-hub' 명령어를 입력하면 별도의 설치 과정 없이 즉시 웹 브라우저로 도구가 실행됩니다.

**2. 프로젝트 및 할 일 등록하기**

메인 화면의 'Quick Add' 기능을 활용하여 진행 중인 업무를 입력합니다. 프로젝트별로 할 일을 분류하고 마감 기한과 세부 메모를 추가하여 업무 목록을 체계적으로 정리합니다.

**3. 습관 및 루틴 관리하기**

매일 반복해야 하는 루틴을 'Habits' 메뉴에 등록합니다. 체크박스를 클릭하여 완료 여부를 표시하면 자동으로 달성 기록이 누적되어 성취도를 시각적으로 확인할 수 있습니다.

**4. 업무 성과 분석 확인하기**

상단 메뉴의 'Analytics' 탭으로 이동하여 그동안 완료한 업무와 습관 달성률을 확인합니다. 날짜별로 어떤 업무를 처리했는지 기록로 개인의 생산성 흐름을 파악합니다.

## 가격 정책

- **무료 플랜**: 오픈소스 프로그램으로 완전 무료로 사용하실 수 있습니다.
- **유료 플랜**: 유료 플랜은 없으며 완전히 무료로 제공됩니다.

비용 절약 팁: 별도의 서버 비용 없이 내 컴퓨터에서 직접 구동하여 비용 부담 없이 활용합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: DailyHub는 오픈소스 기반의 무료 도구로 모든 기능을 제한 없이 사용할 수 있습니다. 별도의 유료 플랜이 존재하지 않으며 개인의 컴퓨터에서 직접 구동하는 방식이라 추가 비용이 발생하지 않습니다.

- **무료 오픈소스 플랜** (무료): 모든 핵심 기능과 로컬 데이터 저장 기능을 무제한으로 사용할 수 있습니다.

- **유료 플랜 없음** (해당 없음): 공식적으로 제공되는 유료 구독 모델은 없으며 완전 무료로 제공됩니다.

**환불과 해지**: 별도의 결제 시스템이 없는 무료 오픈소스 프로젝트이므로 환불이나 결제 관련 정책은 적용되지 않습니다.

## 한국어 지원

서비스 인터페이스는 영어로 제공되지만 입력하는 프로젝트명이나 할 일은 한국어로 자유롭게 작성할 수 있습니다.

## 한국어 품질 실측

**프로젝트 할 일 추가**

- 프롬프트: 오늘의 할 일로 '마케팅 기획안 초안 작성'을 추가하고 마감일을 오늘로 설정합니다.
- 결과 예시: 할 일 목록에 '마케팅 기획안 초안 작성'이 추가되며, 오늘 날짜의 업무 카테고리에 해당 항목이 표시됩니다.
- 관찰: 한글 입력은 문제없이 가능하지만 인터페이스 메뉴는 영문으로만 표기됩니다.

**습관 루틴 관리**

- 프롬프트: 매일 하는 습관으로 '30분 독서'를 추가하고 완료 처리를 수행합니다.
- 결과 예시: Habits 탭에 '30분 독서' 항목이 생성되며, 체크박스를 누르면 오늘 완료한 습관으로 기록됩니다.
- 관찰: 사용자가 직접 입력하는 데이터는 한글로 잘 표시되나 시스템 안내 문구는 영어입니다.

사용자가 직접 입력하는 업무명이나 할 일은 한국어로 자유롭게 작성 가능합니다. 다만 메뉴와 설정 등 시스템 언어는 한국어를 지원하지 않으므로 영문 인터페이스에 익숙해야 합니다.

## 이런 분에게 추천합니다

여러 개의 프로젝트와 부업을 동시에 진행하는 1인 창업가 분들에게 추천합니다.
복잡한 기능보다 가볍고 빠른 업무 관리 툴을 찾는 직장인 분들에게 추천합니다.
매일의 습관과 할 일을 체계적으로 기록하고 싶은 분들에게 추천합니다.

## 실제 활용 예시

- **직장인**: 본업과 사이드 프로젝트 일정을 분리하여 오늘 처리해야 할 업무의 우선순위를 간편하게 정리합니다.
- **학생**: 학업 일정과 자격증 공부 루틴을 매일 체크하며 꾸준히 학습 습관을 유지합니다.
- **소상공인**: 가게 운영 일정과 마케팅 관련 할 일들을 한눈에 모아보고 빠짐없이 관리합니다.

## 유사 툴과 비교

**장점:**
- 설치가 매우 간단하고 가볍게 작동합니다.
- 인터넷 연결 없이 로컬에서 안전하게 데이터를 관리합니다.

**단점:**
- 한국어 인터페이스를 지원하지 않습니다.
- 팀 협업보다는 1인 사용자에게 최적화되어 있습니다.

**이런 분에게 가장 적합합니다:** 복잡한 협업 툴 대신 혼자서 가볍게 프로젝트와 일상을 관리하고 싶은 분에게 가장 적합합니다.

## 장단점

**장점**

- 복잡한 설치 과정이나 계정 가입 없이 명령어 한 줄로 즉시 내 컴퓨터에서 실행할 수 있습니다.
- 모든 데이터가 사용자의 로컬 환경에 저장되므로 외부 서버로 정보가 유출될 위험이 없어 보안성이 뛰어납니다.
- 프로젝트와 습관, 업무 분석을 한 화면에서 직관적으로 관리할 수 있어 1인 창업가에게 매우 효율적입니다.
- 오픈소스로 제공되어 누구나 비용 부담 없이 모든 기능을 평생 무료로 활용하는 장점이 있습니다.

**단점**

- 한국어 인터페이스를 지원하지 않아 영어 메뉴가 낯선 사용자에게는 초기 적응 시간이 필요할 수 있습니다.
- 클라우드 동기화 기능을 지원하지 않아 여러 대의 기기를 동시에 사용하는 환경에서는 데이터 공유가 어렵습니다.
- 별도의 고객 지원 센터가 없으므로 사용 중 발생하는 기술적인 오류는 직접 해결하거나 커뮤니티를 찾아야 합니다.

## 주의사항

- **개인정보**: 데이터가 로컬 컴퓨터에 저장되므로 보안은 뛰어나지만 컴퓨터 분실 시 데이터 복구가 불가능할 수 있어 주기적인 백업이 필요합니다.
- **저작권/상업적 이용**: 오픈소스 라이선스를 따르며 개인적인 업무 관리 용도로 사용하는 것은 자유로우나 상업적 활용 시 라이선스 범위를 확인해야 합니다.
- **요금/한도**: 현재 완전 무료로 제공되지만 향후 업데이트 시 기능 변화가 있을 수 있으므로 공식 깃허브 페이지로 최신 정보를 확인하십시오.
- **계정 관리**: 별도의 계정 가입이 없는 로컬 도구이므로 비밀번호 분실 등의 문제는 없으나, 데이터 파일 자체를 안전하게 보관하는 것이 중요합니다.

## 자주 묻는 질문

**컴퓨터에 설치하는 과정이 어렵지 않나요?**

프로그래밍 지식이 없어도 웹사이트에 안내된 명령어 한 줄만 복사해서 붙여넣으면 누쉽게 실행할 수 있습니다.

**인터넷이 안 되는 환경에서도 쓸 수 있나요?**

네, 내 컴퓨터에서 로컬로 실행되는 방식이기 때문에 인터넷 연결 여부와 상관없이 자유롭게 사용할 수 있습니다.

**작성한 데이터는 안전하게 보관되나요?**

모든 데이터가 외부 서버가 아닌 사용자 본인의 컴퓨터에 저장되므로 프라이버시가 철저하게 보호됩니다.

**인터넷 연결이 없어도 사용할 수 있나요?**

네, 로컬에서 구동되는 방식이므로 인터넷 연결과 관계없이 컴퓨터만 켜져 있다면 언제든지 업무를 관리할 수 있습니다.

**데이터는 어디에 저장되나요?**

데이터는 사용자의 컴퓨터 내 특정 폴더에 파일 형태로 저장됩니다. 클라우드에 업로드되지 않으므로 외부 노출 걱정이 없습니다.

**다른 기기와 동기화할 수 있나요?**

기본적으로 로컬 저장 방식이라 자동 동기화는 지원하지 않습니다. 다만 데이터 파일을 직접 복사하여 옮기는 방식으로 관리할 수는 있습니다.

**설치 시 별도의 프로그램이 필요한가요?**

Node.js가 설치되어 있어야 npx 명령어를 사용할 수 있습니다. 혹은 도커(Docker)를 활용하여 컨테이너 방식으로도 실행이 가능합니다.
