## 한줄 요약

Basedash는 AI가 직접 데이터를 분석하고 대시보드와 리포트를 자동으로 만들어 주는 비즈니스 인텔리전스 플랫폼입니다. 복잡한 BI 설정 없이 팀이 신뢰할 수 있는 인사이트를 빠르게 얻을 수 있도록 도와줍니다.

## 핵심 기능

- **AI분석가**: 데이터를 자동으로 분석해 신뢰할 수 있는 답변을 제공합니다.
- **대시보드**: 실시간으로 시각화된 대시보드를 생성해 업무 효율을 높입니다.
- **브리핑**: AI가 일일 데이터 브리핑을 작성해 업무 시간을 절약합니다.

## 가격 정책

- **무료 플랜**: 무료 체험 플랜으로 기본 대시보드와 데이터 연결 기능을 사용합니다.
- **유료 플랜**: Pro 플랜 49USD(약 60,000원) 월간, 고급 대시보드, API 접근 및 무제한 데이터 소스 연결이 포함됩니다.

비용 절약 팁: 필요 기능이 생기면 무료 플랜에서 Pro 플랜으로 업그레이드하면 비용을 절감할 수 있습니다.

## 한국어 지원

현재 한국어 UI는 제공되지 않으며, 영어 및 프랑스어 등으로 사용해야 합니다.

## 이런 분에게 추천합니다

이런 분에게 추천합니다. 1) 데이터 기반 의사결정이 필요한 중소기업 관리자 2) 마케팅 팀에서 실시간 인사이트를 활용하고자 하는 팀원 3) BI 도구를 단순화하고자 하는 데이터 분석가

## 실제 활용 예시

- **직장인**: 팀 회의에서 매출 추이를 한눈에 보고 싶을 때, Basedash에 매출 데이터를 연결해 실시간 대시보드를 생성하고 공유합니다.
- **학생**: 학과 프로젝트에서 대학교별 연구비 사용 현황을 분석해 보고서를 작성할 때, AI 브리핑 기능으로 핵심 인사이트를 빠르게 도출합니다.
- **소상공인**: 점포 매출과 재고 데이터를 연결해 자동 리포트를 받아 재고 관리와 판매 전략을 조정합니다.

## 자주 묻는 질문

**Basedash는 어떤 데이터 소스를 연결할 수 있나요?**

750개가 넘는 데이터 소스를 지원하며 SQL, CSV, Google Analytics, Salesforce 등 다양한 소스와 연결이 가능합니다.

**무료 플랜으로도 대시보드를 만들 수 있나요?**

네, 무료 플랜에서도 기본 대시보드와 데이터 연결이 가능하지만 고급 기능은 Pro 플랜에서 제공됩니다.

**한국어로 사용하려면 어떻게 해야 하나요?**

현재 한국어 UI는 제공되지 않지만 API를 활용해 한국어 데이터를 입력하고 결과를 한국어로 해석해 활용할 수 있습니다.
