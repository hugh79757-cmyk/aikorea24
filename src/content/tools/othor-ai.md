## 한줄 요약

Othor AI는 복잡한 숫자 데이터에 숨겨진 인사이트와 이상 징후를 자동으로 찾아주는 AI 분석 도구입니다. 전문 데이터 분석가가 없어도 매출, 마케팅, 재무 지표 변화의 핵심 원인을 쉽게 파악하는 데 도움이 되습니다.

## 핵심 기능

- **자동 지표 분석**: 복잡한 수치 데이터 속 패턴과 이상 지점 자동 감지
- **원인 분석 리포트**: 지표가 변한 근본적인 원인을 쉬운 언어로 설명
- **대시보드 연동**: 주요 비즈니스 데이터와 연결하여 실시간 수치 확인

## 사용법

**1. 데이터 파일 업로드**

분석하려는 비즈니스 엑셀(CSV) 파일을 웹 화면 중앙의 업로드 영역으로 끌어다 놓습니다. 매출 지표나 마케팅 전환율 데이터 파일을 준비하시면 빠른 분석이 가능합니다.

**2. 추적 지표 지정하기**

화면 좌측 설정창에서 추적할 주요 비즈니스 핵심 지표(KPI)를 선택합니다. 매출액, 고객 획득 비용, 재방문율 등의 수치 항목을 지정하실 수 있습니다.

**3. AI 자동 분석 실행**

분석 시작 버튼을 누르면 AI가 데이터 내 이상 징후와 지표 변동 원인을 자동으로 탐색합니다. 결과는 수치 그래프와 함께 한눈에 파악하기 쉬운 리포트로 생성됩니다.

**4. 인사이트 리포트 내보내기**

우측 상단의 내보내기 버튼을 클릭하여 완성된 리포트를 PDF나 엑셀 파일로 다운로드합니다. 이 보고서를 팀원들과 공유하여 사업계획서나 보고서 초안으로 활용하실 수 있습니다.

비용 절약 팁: 무료 체판을 활용해 보유하신 엑셀 데이터를 먼저 분석해 보신 후 유료 구독을 결정하시는 것을 권장합니다.

- **Enterprise 플랜** (공식 페이지 확인 필요): 기업 맞춤형 대시보드 구축과 전담 계정 매니저 서비스를 제공합니다.

**환불과 해지**: 구독 해지 및 환불 정책에 대한 정확한 규정은 서비스 결제 페이지 또는 고객 센터로 확인하셔야 합니다.

## 한국어 지원

웹사이트 화면은 영문으로 구성되어 있으나, 한국어 데이터 입력 및 한국어 리포트 생성을 원활하게 지원합니다.

## 한국어 품질 실측

**쇼핑몰 매출 분석**

- 프롬프트: 지난달 스마트스토어 매출이 전월 대비 20% 감소한 이유를 엑셀 데이터 기반으로 분석해 주세요.
- 결과 예시: 유입 고객 수는 일정하나 결제 전환율이 3% 감소한 것이 주요 원인으로 추정됩니다. 특히 특정 카테고리 상품의 재고 부족이 매출 감소에 미친 영향이 큰 것으로 분석될 수 있습니다.
- 관찰: 한국어 데이터 입력 시 비즈니스 문맥에 맞춘 자연스러운 원인 분석 리포트 조성이 가능합니다.

**마케팅 성과 인사이트**

- 프롬프트: SNS 광고 집행 데이터 중에서 가장 효율이 높은 채널과 그 원인을 분석해 주세요.
- 결과 예시: 인스타그램 광고의 고객 획득 비용(CAC)이 가장 낮아 최적의 효율을 보였습니다. 20대 여성 타깃의 영상 소재 클릭률이 타 채널 대비 1.5배 높은 점이 주요 요인으로 제시될 수 있습니다.
- 관찰: 전문적인 마케팅 용어와 한국어 문장 표현을 무난하게 처리하여 인사이트를 전달합니다.

웹사이트 기본 인터페이스는 영문 중심이나 한국어 데이터 처리가 원활합니다. 생성되는 보고서 문장 역시 자연스러운 비즈니스 어조를 유지하여 실무 보고서 작성에 유용합니다.

## 이런 분에게 추천합니다

전문 분석가 없이 매출 지표의 원인을 빠르게 파악하고 싶은 스타트업 대표님입니다.
매월 수치 데이터를 보고서로 요약해야 하는 마케팅 및 기획 담당자님입니다.
매장 매출 변화 원인을 분석하여 마케팅 전략을 세우려는 소상공인 사장님입니다.

## 실제 활용 예시

- **직장인**: 주간 매출 보고서를 작성할 때 엑셀 수치를 Othor AI에 업로드하여 핵심 인사이트를 추출합니다. AI가 파악해 준 하락 원인을 보고 실용적인 대응 전략 보고서를 빠르게 완성합니다.
- **학생**: 경영학 과제나 공모전 제출하려고 기업의 재무 데이터를 분석할 때 활용합니다. 수치 간의 상관관계를 자동으로 해석받아 수월하게 발표 자료를 준비합니다.
- **소상공인**: 네이버 스마트스토어의 월간 판매 데이터를 업로드하여 인기 상품의 구매 요인을 분석합니다. 추출된 인사이트를 바탕으로 다음 달 프로모션 상품과 재고량을 효율적으로 기획합니다.

- 복잡한 수치 데이터에서 핵심 변동 원인을 자동으로 찾아주어 분석 시간을 획기적으로 줄여줍니다.
- 전문 데이터 분석가가 없어도 쉬운 언어로 작성된 인사이트 보고서를 바로 얻을 수 있습니다.
- 엑셀 파일 업로드는 물론 다양한 대시보드 시스템과 연결하여 실시간 수치 확인이 가능합니다.
- 마케터나 소상공인이 직관적으로 이해할 수 있는 비즈니스 지표 중심의 시각화를 제공합니다.

**단점**

- 현재 도메인이 매물로 등록되어 있어 실제 서비스 운영 여부에 대한 추가 확인이 필요합니다.

- 대용량 복합 데이터나 데이터 정합성이 낮은 원본 데이터는 사전에 정제 작업이 필요합니다.

## 자주 묻는 질문

**데이터 분석 지식이 전혀 없어도 사용할 수 있습니까?**

네, 전문적인 데이터 분석 지식이 없어도 누구나 쉽게 사용할 수 있습니다. AI가 복잡한 통계 수치를 쉬운 비즈니스 언어로 풀어서 설명해 줍니다.

**어떤 형식의 파일 데이터를 지원합니까?**

일반적으로 많이 사용하는 CSV 및 엑셀(XLSX) 파일 업로드를 지원합니다. 데이터 파일을 올려두시면 AI가 즉시 주요 지표를 분석해 드립니다.

**한국어로 작성된 데이터도 분석이 가능합니까?**

네, 한국어로 된 열 이름이나 데이터 내용도 문제없이 인식하여 분석합니다. 결과 리포트 역시 한국어로 받아보실 수 있습니다.

**Othor AI 도메인 접속이 잘 안 되는데 어떻게 해야 하나요?**

현재 othorai.com 도메인은 매각 절차가 진행 중이거나 서비스 주소가 변경되었을 수 있습니다. 접속이 원활하지 않을 경우 서비스 공식 안내 채널이나 재분배된 URL을 확인하셔야 합니다.

**데이터 분석 전문가가 아닌 일반 소상공인도 쉽게 사용할 수 있나요?**

네, 전문적인 통계 지식 없이도 엑셀 파일만 업로드하면 AI가 수치 변화의 원인을 글로 설명해 주므로 초보자도 쉽게 활용할 수 있습니다.

**한국어로 작성된 엑셀 데이터를 그대로 넣어도 잘 인식하나요?**

네, 한국어 열 이름과 수치 데이터를 올바르게 인식하여 분석 결과를 한국어 리포트로 생성해 줍니다.

**유료 플랜 결제 후 즉시 해지가 가능한가요?**

대부분의 서비스와 마찬가지로 구독 관리 페이지에서 언제든지 자동 결제를 해지하실 수 있으며, 정확한 해지 절차는 공식 서비스 페이지를 확인해 주시기 바랍니다.
