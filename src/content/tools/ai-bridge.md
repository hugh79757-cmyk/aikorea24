## 한줄 요약

AI Bridge는 맥 환경에서 여러 AI 코딩 에이전트(Claude Code, Codex, Grok 등)를 한 번에 실행하고 관리하는 통합 플랫폼입니다. 프로젝트별로 에이전트를 배치하고 작업 상태를 유지할 수 있어, 개발 흐름이 끊기지 않고 효율적으로 업무를 이어갈 수 있습니다.

## 핵심 기능

- **에이전트 통합**: 여러 AI 코딩 도구를 하나의 앱에서 관리하여 창 전환의 번거로움을 줄입니다.
- **프로젝트 관리**: 프로젝트별로 에이전트와 관련 파일을 묶어 관리하므로 문맥 유지가 쉽습니다.
- **작업 상태 저장**: 하던 작업을 그대로 저장하여 다음 날 바로 이어서 시작할 수 있습니다.

## 사용법

**1. 워크스페이스 생성 및 프로젝트 설정**

앱을 설치한 후, 관리할 프로젝트를 생성하고 워크스페이스를 구성합니다. 각 워크스페이스마다 특정 작업 범위와 관련된 폴더, 레포지토리, 자동화 규칙을 할당하여 체계적으로 관리합니다.

**2. AI 에이전트 연동 및 실행**

Claude Code, Codex, Grok 등 이미 구독 중인 CLI 기반 AI 에이전트를 앱 내에서 실행합니다. 각 에이전트가 담당할 업무를 지정하면, 터미널 명령어를 직접 입력하지 않고도 통합 환경에서 제어할 수 있습니다.

**3. 통합 대시보드에서 상태 모니터링**

메인 대시보드에서 현재 작동 중인 모든 에이전트의 상태를 한눈에 확인합니다. 에이전트가 사용자의 승인을 기다리거나 작업을 완료했는지 실시간으로 확인하여 즉각적인 대응이 가능합니다.

**4. 작업 중단 및 재개 관리**

진행 중인 모든 작업 상태를 앱 내에 저장합니다. 다음 날 업무를 시작할 때 이전 작업 환경 그대로 에이전트를 다시 불러와 끊김 없이 개발 업무를 이어갈 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료로 시작할 수 있으며, 기본적인 에이전트 관리 기능을 제공합니다.
- **유료 플랜**: 구체적인 유료 플랜 가격은 공식 홈페이지의 'See plans' 메뉴로 확인 가능하며 고급 기능과 우선 지원이 포함됩니다.

비용 절약 팁: 기존에 이미 구독 중인 유료 CLI 도구들을 연동하여 사용하는 방식이므로, 중복 지출을 방지할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜은 기본적인 에이전트 관리 기능을 제공하여 사용자가 직접 시작해 볼 수 있도록 구성되어 있습니다. 상세한 기능 범위와 제한 사항은 공식 홈페이지의 요금 페이지로 확인이 필요합니다.

- **Standard Plan** (공식 페이지 확인 필요): 고급 에이전트 관리 기능과 함께 우선적인 고객 지원 서비스를 제공합니다.

- **Pro Plan** (공식 페이지 확인 필요): 대규모 프로젝트 관리와 복잡한 워크스페이스 구성을 위한 모든 프리미엄 기능을 포함합니다.

**환불과 해지**: 결제 및 환불 정책은 서비스 이용 약관에 따르며, 구체적인 안내는 공식 홈페이지의 결제 관리 섹션에서 확인하시기 바랍니다.

## 한국어 지원

현재 인터페이스는 영어로 제공되지만 AI 에이전트가 작성하는 코드나 대화 내용은 설정에 따라 한국어 사용이 가능합니다.

## 한국어 품질 실측

**코드 리뷰 요청**

- 프롬프트: 현재 작성된 결제 API 코드의 오류 가능성을 검토하고 수정안을 제시해 줘.
- 결과 예시: 코드 분석 결과, 특정 조건에서 예외 처리가 누락된 부분을 확인했습니다. 해당 부분을 보완한 수정 코드를 제안하며 502 에러 방지를 위한 로직을 추가했습니다.
- 관찰: AI 에이전트가 영어로 답변할 가능성이 높으며, 한국어 입력 시 문맥은 이해하나 출력 언어는 모델 설정에 따라 달라집니다.

**데이터베이스 쿼리 작성**

- 프롬프트: 오늘 가입한 사용자 중 특정 플랜을 이용하는 인원수를 집계하는 SQL 쿼리를 작성해 줘.
- 결과 예시: 사용자 테이블과 구독 테이블을 조인하여 오늘 날짜 기준으로 가입자를 필터링하는 쿼리입니다. 작성된 쿼리를 확인하고 데이터베이스에 실행하십시오.
- 관찰: 기술적인 전문 용어는 정확하게 처리하지만 한국어 답변의 자연스러움은 연동된 AI 모델의 성능에 의존합니다.

도구 자체 인터페이스는 영어로만 제공되므로 한국어 설정은 지원하지 않습니다. 다만, 연동된 AI 모델이 한국어를 지원한다면 대화형 작업은 한국어로 수행 가능합니다.

## 이런 분에게 추천합니다

여러 AI 도구를 동시에 활용하는 전문 개발자에게 추천합니다. 프로젝트 단위로 코딩 에이전트를 효율적으로 관리하고 싶은 분들에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 프로젝트별로 에이전트를 따로 배정하여 업무를 분리합니다. 덕분에 여러 업무를 동시에 진행해도 코드 꼬임 없이 깔끔하게 관리합니다.
- **학생**: 학기 프로젝트를 수행할 때 AI 에이전트마다 서로 다른 역할(코드 작성, 디버깅)을 맡깁니다. 작업이 중단되어도 마지막 상태를 기억해 주어 과제 효율이 크게 오릅니다.
- **소상공인**: 간단한 결제 페이지 개발 시 AI 에이전트를 활용해 시간을 절약합니다. 전문 개발자가 아니더라도 에이전트별로 업무를 지정해 두면 관리가 훨씬 수월합니다.

## 유사 툴과 비교

**장점:**
- 다양한 AI 에이전트를 한곳에서 통합 관리 가능
- 프로젝트별 작업 컨텍스트 유지로 업무 연속성 확보

**단점:**
- 맥 운영체제에서만 사용 가능
- 영어 인터페이스로 인한 초기 학습 필요

**이런 분에게 가장 적합합니다:** 여러 AI 코딩 에이전트를 동시에 사용하며 프로젝트 관리가 필요한 맥 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 여러 개의 AI 코딩 에이전트를 하나의 맥 앱에서 통합 관리하여 창 전환의 번거로움을 획기적으로 줄여줍니다.
- 프로젝트별로 워크스페이스를 분리하여 관련 파일과 규칙을 체계적으로 관리함으로써 개발 문맥 유지가 매우 용이합니다.
- 이미 사용 중인 유료 CLI 도구들을 그대로 연동하여 사용할 수 있어 추가적인 구독 비용 부담 없이 효율을 높일 수 있습니다.
- 작업 상태를 저장하고 관리할 수 있어 업무 흐름이 끊기지 않고 다음 날 즉시 이어서 작업하는 것이 가능합니다.

**단점**

- 맥(macOS) 전용 도구로 설계되어 있어 윈도우나 리눅스 환경에서는 사용할 수 없다는 제약이 존재합니다.
- 인터페이스가 영어로만 제공되어 한국어 환경을 선호하는 사용자에게는 사용 초기 적응 기간이 필요할 수 있습니다.
- 사용자가 직접 CLI 기반의 에이전트를 연동해야 하므로, 개발 환경 설정에 익숙하지 않은 초보자에게는 진입 장벽이 높습니다.

## 주의사항

- **개인정보**: 연동된 AI 에이전트가 처리하는 코드나 데이터는 해당 에이전트의 보안 정책을 따르므로 민감한 정보는 주의가 필요합니다.
- **저작권/상업적 이용**: AI가 생성한 코드의 저작권은 사용 중인 개별 에이전트의 약관에 따라 결정되므로 상업적 프로젝트 사용 시 반드시 확인해야 합니다.
- **요금/한도**: 본 도구는 관리 플랫폼이며 실제 에이전트 사용료는 각 서비스별로 별도 청구되므로 중복 지출이 발생하지 않도록 관리해야 합니다.
- **계정 관리**: 연동된 모든 AI 서비스의 API 키와 계정 정보를 관리하므로, 앱의 보안 설정과 맥 시스템 보안을 철저히 유지하십시오.

## 자주 묻는 질문

**기존에 사용하던 AI 도구를 그대로 쓸 수 있나요?**

네, 이미 구독 중인 Claude Code나 Codex 등의 CLI 도구를 그대로 연동하여 사용할 수 있습니다. AI Bridge는 이들을 한데 모아주는 관리자 역할을 합니다.

**윈도우나 리눅스에서도 사용할 수 있나요?**

아쉽게도 현재는 맥(macOS) 환경만 지원하고 있습니다. 인텔 맥과 애플 실리콘 맥 모두 지원합니다.

**여러 에이전트를 동시에 실행하면 컴퓨터가 느려지지 않나요?**

각 에이전트는 프로젝트별로 독립적으로 실행되므로 관리 효율은 높지만 실행하는 에이전트 수에 따라 시스템 자원 소모가 발생할 수 있습니다.

**기존에 쓰던 유료 AI 도구 비용이 이중으로 발생하나요?**

아니요, AI Bridge는 사용자가 이미 구독 중인 CLI 도구를 연동하는 방식이므로 추가적인 구독료는 발생하지 않습니다.

**모든 AI 코딩 에이전트를 다 연동할 수 있나요?**

Claude Code, Codex, Grok 등 CLI 기반의 에이전트들을 지원하며, 상세한 지원 목록은 공식 가이드에서 확인 가능합니다.

**인텔 맥에서도 정상적으로 작동하나요?**

네, 공식 홈페이지에서 인텔 맥용 설치 파일을 별도로 제공하고 있어 인텔 기반 맥에서도 사용이 가능합니다.

**한국어 인터페이스로 바꿀 수 있는 설정이 있나요?**

현재는 영어 인터페이스만 지원하며, 향후 업데이트를 통해 추가될지는 공식 공지사항을 확인해야 합니다.
