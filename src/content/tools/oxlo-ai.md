## 한줄 요약

Oxlo.ai는 다양한 AI 모델을 활용하여 업무 효율성을 높이는 플랫폼입니다. 데이터 보안이 철저하여 사용자의 프라이버시를 보장합니다.

## 핵심 기능

- **모델 다양성**: 45개 이상의 AI 모델을 사용하여 다양한 작업을 수행할 수 있습니다.
- **데이터 보안**: 사용자의 데이터를 판매하거나 학습에 사용하지 않습니다.
- **무료 사용**: 무료로 시작할 수 있어 부담 없이 사용해 볼 수 있습니다.

## 사용법

**1. VS Code 확장 프로그램 설치**

VS Code의 확장 프로그램 마켓플레이스에서 OxCode를 검색하여 설치합니다. 설치 후 대시보드에 접속하여 계정을 연동합니다.

**2. 작업 공간(Workspace) 구성**

코딩을 진행할 프로젝트 폴더를 VS Code에서 엽니다. OxCode가 프로젝트 구조를 파악할 수 있도록 적절한 작업 환경을 준비합니다.

**3. AI 엔지니어와 계획 수립**

채팅창에 수행할 개발 과제를 입력하면 OxCode가 먼저 작업 계획을 제시합니다. 계획을 검토한 뒤 승인하여 코딩 작업을 시작합니다.

**4. 코드 생성 및 디버깅**

AI가 작성한 코드를 확인하고 필요 시 'Steer' 기능을 활용해 수정 방향을 지시합니다. 자동으로 실행되는 테스트로 오류를 즉시 수정합니다.

**데이터는 어떻게 보호되나요?**

사용자의 데이터는 외부에 판매되지 않으며, 학습에 사용되지 않도록 보장됩니다.

**무료로 사용하는 기능은 무엇인가요?**

기본적인 기능과 여러 AI 모델을 무료로 사용해 볼 수 있습니다.

**OxCode는 어떤 IDE에서 사용할 수 있나요?**

VS Code 및 Open VSX를 지원하는 모든 VS Code 기반의 IDE에서 설치하여 사용할 수 있습니다. 호환성 확인이 필요한 경우 공식 문서를 참조하십시오.

**코드를 수정할 때 AI가 제멋대로 바꾸지 않을까요?**

OxCode는 수정 전 계획을 먼저 제시하고 사용자의 승인을 받습니다. 또한 'Steer' 기능을 통해 사용자가 직접 수정 방향을 제어할 수 있습니다.

**무료로 사용할 수 있는 기능은 어디까지인가요?**

현재 1달러로 접근 권한을 얻는 방식이며, 무료 체험 기간이나 범위에 대해서는 공식 웹사이트의 요금 안내 페이지를 확인해야 합니다.

**팀 프로젝트에서도 유용하게 쓸 수 있나요?**

네, 팀 사용 시 할인 혜택이 제공되며 프로젝트 구조를 이해하고 협업하는 데 최적화되어 있습니다. 다만 구체적인 팀 플랜 가격은 고객센터 문의가 필요합니다.
