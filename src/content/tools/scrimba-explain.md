## 한줄 요약

Scrimba Explain은 사용자가 궁금한 주제를 입력하면 AI가 즉석에서 영상 강의를 생성해 주는 학습 도구입니다. 텍스트로만 읽기 어려운 복잡한 개념을 시각적인 영상으로 풀어주어 학습 효율을 크게 높여줍니다.

## 핵심 기능

- **즉석 영상 생성**: 질문과 동시에 맞춤형 설명 영상을 만들어 학습 시간을 단축합니다.
- **인터랙티브 학습**: 영상 속 코드를 직접 수정하며 실습할 수 있어 실전 감각을 익히기 좋습니다.
- **질문 기반 설명**: 궁금한 점만 콕 집어 설명해주어 불필요한 학습 과정을 생략합니다.

## 사용법

**1. 계정 생성 및 로그인**

Scrimba 공식 홈페이지에 접속하여 구글 계정 등으로 간편하게 가입합니다. 로그인 후 대시보드 화면에서 학습하고 싶은 프로그래밍 주제를 선택합니다.

**2. 질문 입력 및 요청**

학습 도구 내의 AI 챗봇 창에 궁금한 코딩 개념을 한국어로 입력합니다. 질문이 구체적일수록 AI가 더 정확한 설명 영상을 생성해 줍니다.

**3. 영상 강의 시청**

AI가 실시간으로 생성한 영상 강의를 시청하며 개념을 파악합니다. 영상은 복잡한 이론을 시각적으로 풀어내어 초보자도 쉽게 이해할 수 있습니다.

**4. 실시간 코드 실습**

영상 재생 중에 코드 에디터를 클릭하여 직접 코드를 수정하고 결과를 확인합니다. 영상 속 코드를 일시 정지하고 따라 해보며 실무 감각을 익힐 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 질문 및 영상 생성 기능을 무료로 체험할 수 있습니다.
- **유료 플랜**: Scrimba Pro 플랜(월 약 3~4만 원 수준)으로 모든 강의와 고급 기능을 무제한 이용 가능합니다.

비용 절약 팁: 무료 체험로 본인의 학습 스타일과 잘 맞는지 먼저 확인한 후 구독을 결정하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 코딩 강의와 튜토리얼을 무료로 이용할 수 있습니다. 다만, 모든 고급 기능이나 일부 심화 강의는 유료 구독이 필요할 수 있습니다.

- **Scrimba Pro** (공식 페이지 확인 필요): 모든 프리미엄 강의와 인터랙티브 학습 기능을 무제한으로 이용할 수 있습니다.

- **Team Plan** (공식 페이지 확인 필요): 기업이나 그룹 단위의 학습 관리가 필요한 경우 선택할 수 있는 옵션입니다.

**환불과 해지**: 구독 해지 및 환불 정책은 Scrimba 공식 홈페이지의 결제 설정 페이지에서 확인 가능합니다.

- 관찰: 한국어 질문을 정확히 이해하고 자연스러운 한국어로 답변을 제공합니다.

**CSS 레이아웃 질문**

- 프롬프트: Flexbox를 사용하여 요소를 화면 중앙에 배치하는 방법을 영상으로 알려주세요.
- 결과 예시: Flexbox의 justify-content와 align-items 속성을 사용하면 간단합니다. 아래 영상에서 코드를 직접 수정하며 정렬 상태가 어떻게 변하는지 관찰해 보세요.
- 관찰: 기술 용어와 한국어 설명이 적절히 섞여 학습에 매우 효과적입니다.

한국어 지원 수준은 매우 우수하며 기술적인 내용을 설명할 때도 번역투가 거의 느껴지지 않습니다. 프로그래밍 용어는 영어 원문을 유지하면서 설명은 한국어로 제공하여 학습 효율이 높습니다.

## 이런 분에게 추천합니다

독학으로 코딩을 시작하려는 초보자에게 추천합니다. 새로운 기술 개념을 빠르게 파악해야 하는 개발자에게 유용합니다. 시각적 자료로 학습하는 것을 선호하는 학생에게 적합합니다.

## 실제 활용 예시

- **직장인**: 업무 중 생소한 IT 용어가 나왔을 때 바로 질문합니다. 영상으로 개념을 빠르게 파악해 회의 준비 시간을 줄입니다.
- **학생**: 전공 수업 중 이해가 안 가는 코딩 개념을 질문합니다. 영상 속 코드를 직접 수정하며 실습하여 시험 대비를 합니다.
- **소상공인**: 온라인 쇼핑몰 운영을 위한 기초 웹 지식을 배울 때 사용합니다. 복잡한 설정법을 영상으로 보며 그대로 따라 합니다.

## 장단점

**장점**

- 영상 내 코드 에디터로 실시간으로 코드를 수정하고 실행 결과를 즉시 확인할 수 있어 학습 몰입도가 매우 높습니다.
- 복잡한 코딩 개념을 AI가 시각적인 영상으로 풀어주기 때문에 텍스트 위주의 강의보다 훨씬 직관적으로 이해할 수 있습니다.
- 궁금한 점을 질문하면 맞춤형으로 강의를 생성해 주어 불필요한 이론 학습 시간을 획기적으로 단축할 수 있습니다.
- 코딩 입문자에게 최적화된 인터페이스를 제공하여 처음 시작하는 사람도 어렵지 않게 학습을 이어갈 수 있습니다.

**단점**

- 모든 고급 강의와 인터랙티브 기능을 이용하려면 유료 구독이 필수적이므로 비용 부담이 발생할 수 있습니다.
- AI가 생성하는 설명의 깊이가 사용자의 질문 수준에 따라 달라질 수 있어 매우 전문적인 질문에는 한계가 있을 수 있습니다.
- 국내 오프라인 학원과 같은 밀착형 피드백을 기대하기에는 AI 기반 학습의 한계가 존재할 수 있습니다.

- **저작권/상업적 이용**: 제공되는 강의 콘텐츠는 개인 학습용으로만 사용해야 하며 이를 무단으로 복제하거나 상업적으로 재판매하는 행위는 금지됩니다.
- **요금/한도**: 무료 플랜과 유료 플랜의 이용 범위가 다를 수 있으므로 결제 전 본인의 학습량에 맞는 요금제를 선택하시기 바랍니다.
- **계정 관리**: 계정 공유는 서비스 정책 위반 사유가 될 수 있으므로 본인 명의의 계정으로 안전하게 이용하는 것을 권장합니다.

## 자주 묻는 질문

**질문하면 무조건 영상으로만 나오나요?**

네, 이 툴의 핵심은 텍스트가 아닌 영상 형태의 설명입니다. 시각적 학습을 극대화하기 위해 설계되었습니다.

**코딩 외의 일반적인 질문도 가능한가요?**

기술 및 학습 관련 질문에 특화되어 있습니다. 다만, 일반적인 지식 질문도 영상으로 답변받을 수 있습니다.

**영상 생성 속도는 얼마나 빠른가요?**

질문 내용에 따라 다르지만 일반적으로 수 초 내에 영상 생성이 시작됩니다. 기다림 없이 바로 학습을 시작할 수 있습니다.

**코딩을 아예 모르는 왕초보도 바로 시작할 수 있나요?**

네, 가능합니다. 기초적인 HTML, CSS부터 차근차근 영상으로 설명해 주므로 입문자에게 매우 친절한 플랫폼입니다.

**생성된 영상 강의를 다운로드해서 소장할 수 있나요?**

아니오, Scrimba의 플랫폼 내에서 실시간으로 학습하는 방식이며 영상 파일 자체를 다운로드하는 기능은 제공하지 않습니다.

**유료 구독을 하면 모든 강의를 다 들을 수 있나요?**

Pro 플랜을 구독하면 플랫폼 내의 거의 모든 프리미엄 강의와 인터랙티브 실습 기능을 무제한으로 이용할 수 있습니다.

**질문은 영어로만 해야 하나요?**

아니오, 한국어로 질문해도 AI가 이를 충분히 이해하고 한국어 답변과 영상을 제공하므로 언어 장벽 없이 학습이 가능합니다.
