## 한줄 요약

Cursor는 소프트웨어 개발을 위한 AI 코딩 에이전트로, 복잡한 코딩 작업을 쉽게 도와줍니다. 효율적인 코드 생성과 디버깅로 개발자의 생산성을 높입니다.

## 핵심 기능

- **코드 생성**: 필요한 기능의 코드를 자동으로 작성해 줍니다.
- **디버깅**: 코드의 오류를 찾아 수정 방법을 제시합니다.
- **API 개발**: 간편하게 API를 설계하고 구현할 수 있도록 도와줍니다.

## 사용법

**1. 프로그램 설치 및 실행**

공식 홈페이지에서 운영체제에 맞는 설치 파일을 다운로드하여 실행합니다. 기존 VS Code 환경을 가져올 수 있어 익숙한 설정 그대로 사용 가능합니다.

**2. 프로젝트 폴더 열기**

작업할 코드 폴더를 Cursor에서 엽니다. 좌측 사이드바에서 파일 구조를 확인하고 AI가 프로젝트 전체 문맥을 이해하도록 준비합니다.

**3. AI 명령창(⌘K) 활용**

코드 에디터 내에서 단축키 ⌘K를 누른 뒤, 원하는 기능이나 수정 사항을 한국어로 입력합니다. AI가 즉시 코드를 작성하거나 변경 제안을 제시합니다.

**4. 에이전트 모드 실행**

복잡한 작업은 에이전트 기능을 사용하여 전체적인 계획을 수립하게 합니다. AI가 스스로 파일을 생성하고 수정하는 과정을 지켜보며 최종 승인합니다.
