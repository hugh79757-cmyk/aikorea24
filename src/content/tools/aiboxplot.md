## 한줄 요약

aiboxplot은 복잡한 통계 수치를 클릭 몇 번으로 전문가 수준의 그래프로 바꿔주는 도구입니다. 엑셀 데이터를 복사해서 붙여넣기만 하면 박스 플롯, 히스토그램 등 다양한 시각 자료를 즉시 생성하여 보고서의 퀄리티를 높여줍니다.

## 핵심 기능

- **다양한 차트 생성**: 박스 플롯, 히스토그램 등 7종 이상의 전문 차트를 즉시 제작할 수 있습니다.
- **데이터 이상치 탐지**: 통계적 기준(IQR)을 적용해 데이터 오류나 이상치를 자동으로 찾아내어 분석의 정확도를 높입니다.
- **간편한 데이터 연동**: 엑셀이나 스프레드시트에서 데이터를 복사해 붙여넣기만 하면 바로 그래프가 그려집니다.

## 사용법

**1. 데이터 복사 및 붙여넣기**

웹사이트의 데이터 입력창에 엑셀이나 스프레드시트의 수치 데이터를 그대로 복사하여 붙여넣습니다. 별도의 파일 업로드 없이도 브라우저 내에서 즉시 데이터가 인식됩니다.

**2. 차트 유형 선택 및 설정**

화면 상단 메뉴에서 박스 플롯, 히스토그램 등 원하는 시각화 차트 유형을 선택합니다. 필요에 따라 이상치 탐지 민감도를 조절하거나 평균값 표시 여부를 설정합니다.

**3. AI 데이터 분석 및 확인**

도구에 내장된 AI 분석 기능을 활용하여 데이터의 통계적 요약과 분포 특징을 확인합니다. AI가 제안하는 시각화 방식을 참고하여 그래프의 완성도를 높입니다.

**4. 고해상도 이미지 내보내기**

완성된 그래프를 PNG, SVG 등 원하는 파일 형식으로 즉시 다운로드합니다. 워터마크가 없는 고해상도 결과물이므로 논문이나 보고서에 바로 활용할 수 있습니다.

## 가격 정책

- **무료 플랜**: 현재 무료로 모든 주요 데이터 시각화 기능을 제한 없이 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 명시되어 있지 않으며, 현재 무료 서비스로 운영됩니다.

비용 절약 팁: 대용량 데이터는 한 번에 처리하기보다 적절히 나누어 업로드하면 더 정확한 결과물을 얻을 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 모든 기능을 무료로 제한 없이 사용할 수 있습니다. 별도의 크레딧 제한이나 워터마크 삽입 없이 고해상도 출력이 가능합니다.

- **무료 플랜** (무료): 모든 차트 생성 기능과 AI 분석 도구를 제한 없이 사용할 수 있습니다.

- **유료 플랜 없음** (공식 페이지 확인 필요): 현재 별도의 유료 구독 모델은 운영되지 않고 있습니다.

**환불과 해지**: 결제 시스템이 존재하지 않는 무료 도구이므로 환불 관련 정책은 별도로 존재하지 않습니다.

## 한국어 지원

웹사이트 인터페이스는 영어로 제공되지만 데이터는 숫자 위주이므로 언어 장벽 없이 직관적으로 사용할 수 있습니다.

## 한국어 품질 실측

**영업 실적 데이터 시각화**

- 프롬프트: 입력된 5개 지점의 매출 데이터를 바탕으로 박스 플롯을 생성하고 이상치를 확인해 줘.
- 결과 예시: 지점별 매출 분포가 박스 플롯으로 나타나며, 통계적으로 벗어난 매출액이 자동으로 표시됩니다. AI가 데이터의 평균과 중앙값을 요약하여 보고서 형식으로 보여줍니다.
- 관찰: 인터페이스는 영어지만 숫자 데이터 중심이라 한국어 입력 시에도 차트 생성은 원활합니다.

**연구 데이터 통계 요약**

- 프롬프트: 수집한 실험 결과값들의 분포를 히스토그램으로 보여주고 통계적 요약을 작성해 줘.
- 결과 예시: 실험 데이터의 빈도 분포를 보여주는 히스토그램이 생성됩니다. 하단에 데이터의 5가지 핵심 수치 요약이 영어로 제공됩니다.
- 관찰: 결과물 내 텍스트는 영어로 출력되므로 보고서 작성 시 일부 번역이 필요할 수 있습니다.

웹사이트 인터페이스가 영어로만 제공되지만 수치 데이터를 다루는 도구 특성상 언어 장벽은 낮은 편입니다. 다만, AI가 제공하는 통계 요약 설명은 영어로 출력되므로 한국어 보고서 활용 시 추가적인 번역 과정이 필요합니다.

## 이런 분에게 추천합니다

데이터 분석이 필요한 대학생, 전문적인 보고서 작성이 잦은 직장인, 매장 매출 분석이 필요한 소상공인에게 추천합니다.

## 실제 활용 예시

- **직장인**: 분기별 성과 데이터를 엑셀에서 복사해 붙여넣어 회의용 보고서에 삽입할 깔끔한 차트를 만듭니다. 별도의 디자인 툴 없이도 전문적인 그래프를 얻을 수 있어 시간을 크게 절약합니다.
- **학생**: 졸업 논문에 필요한 설문 조사 결과를 시각화할 때 사용합니다. 복잡한 통계 프로그램 대신 웹에서 바로 그래프를 생성해 논문 초안에 바로 활용합니다.
- **소상공인**: 매일 기록하는 매출 데이터를 입력하여 우리 가게의 매출 분포를 확인합니다. 어느 요일에 매출이 튀는지 이상치를 파악하여 마케팅 전략을 세우는 데 활용합니다.

## 유사 툴과 비교

**장점:**
- 설치 없이 웹에서 즉시 사용 가능
- 통계 전문 지식 없이도 정확한 그래프 생성

**단점:**
- 한국어 지원 미흡
- 복잡한 데이터 가공 기능은 부족함

**이런 분에게 가장 적합합니다:** 빠르게 데이터를 시각화하여 문서에 삽입해야 하는 상황에 가장 적합합니다.

## 장단점

**장점**

- 엑셀 데이터를 복사하여 붙여넣기만 하면 즉시 전문적인 통계 그래프를 생성할 수 있어 업무 효율이 매우 높습니다.
- 데이터가 브라우저 내에서만 처리되므로 외부 서버로 데이터가 전송되지 않아 보안 측면에서 안심하고 사용할 수 있습니다.
- 박스 플롯, 히스토그램, 바이올린 플롯 등 다양한 차트 유형을 워터마크 없이 고해상도로 다운로드할 수 있습니다.
- 통계적 이상치를 자동으로 탐지하고 Tukey IQR 기준을 설정할 수 있어 데이터 분석의 신뢰도를 높일 수 있습니다.

**단점**

- 사용자 인터페이스가 모두 영어로 구성되어 있어 영어에 익숙하지 않은 사용자는 초기 설정에 다소 어려움을 느낄 수 있습니다.
- AI가 제공하는 통계적 분석 결과나 설명이 영어로만 제공되어 한국어 보고서에 바로 사용하기에는 번역 과정이 필수적입니다.
- 복잡한 데이터 분석을 위한 전문 통계 소프트웨어에 비해서는 세부적인 디자인 커스터마이징 기능이 다소 제한적일 수 있습니다.

## 주의사항

- **개인정보**: 데이터가 브라우저 내에서 처리되어 외부 유출 위험은 낮으나, 매우 민감한 개인정보가 포함된 데이터는 업로드 시 주의가 필요합니다.
- **저작권/상업적 이용**: 워터마크 없이 결과물을 제공하므로 상업적 보고서나 논문에 자유롭게 활용 가능하나, 결과물에 대한 저작권 정책은 공식 사이트의 약관을 다시 확인하시기 바랍니다.
- **요금/한도**: 현재는 무료로 운영되고 있으나 향후 정책 변경에 따라 유료화될 가능성이 있으므로 정기적으로 공식 요금 페이지를 확인하는 것이 좋습니다.
- **계정 관리**: 별도의 로그인 없이 브라우저에서 바로 사용 가능한 도구이므로, 작업 중인 데이터가 브라우저 종료 시 삭제될 수 있음을 유의하여 결과물을 미리 저장하십시오.

## 자주 묻는 질문

**엑셀 파일을 직접 업로드할 수 있나요?**

네, 데이터를 직접 업로드하거나 스프레드시트에서 복사하여 붙여넣는 방식을 모두 지원합니다. 데이터 형식이 맞으면 즉시 그래프로 변환됩니다.

**생성된 그래프를 다른 문서에 바로 사용할 수 있나요?**

네, 생성된 차트는 이미지 파일로 다운로드할 수 있어 파워포인트나 워드, 한글 문서 등에 바로 삽입하여 사용할 수 있습니다.

**통계 지식이 전혀 없어도 사용할 수 있나요?**

그렇습니다. 데이터만 입력하면 툴이 자동으로 분포를 계산하고 적절한 차트 유형을 제안해주므로 통계학을 몰라도 충분히 활용 가능합니다.

**데이터 보안은 안전한가요?**

모든 계산이 사용자의 브라우저 내에서만 이루어지는 클라이언트 사이드 방식을 사용합니다. 따라서 데이터가 서버로 전송되지 않아 보안상 비교적 안전합니다.

**논문에 바로 사용 가능한 수준인가요?**

네, 고해상도 출력을 지원하며 워터마크가 없기 때문에 학술 논문이나 전문 보고서에 바로 삽입하여 사용하기에 적합합니다.

**한 번에 얼마나 많은 데이터를 처리할 수 있나요?**

브라우저 성능에 따라 다르지만, 대용량 데이터는 한 번에 처리하기보다 적절히 나누어 업로드하는 것이 정확한 결과물을 얻는 데 도움이 됩니다.

**한국어 데이터도 인식하나요?**

숫자 위주의 데이터는 문제없이 인식하지만, 차트 내 범례나 제목에 한국어를 입력할 경우 폰트 지원 여부에 따라 글자가 깨질 수 있으니 확인이 필요합니다.
