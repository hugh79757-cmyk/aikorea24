## 한줄 요약

Living Brain은 AI가 사용자의 이전 대화나 업무 데이터를 기억하게 하여, 매번 같은 설명을 반복할 필요 없게 만드는 '기억 저장소'입니다. AI가 단순한 챗봇을 넘어 사용자의 업무 스타일과 히스토리를 이해하는 개인 비서처럼 작동하도록 돕습니다.

## 핵심 기능

- **맥락 기억**: 이전 대화 내용을 기억해 매번 상황을 설명할 번거로움을 줄여줍니다.
- **데이터 연동**: 여러 앱과 연결해 필요한 정보를 즉시 불러와 업무 효율을 높입니다.
- **에이전트 최적화**: AI가 사용자의 의도를 정확히 파악하도록 개인화된 환경을 제공합니다.

## 사용법

**1. 계정 생성 및 워크스페이스 연결**

공식 홈페이지에서 계정을 생성한 후, 사용 중인 AI 플랫폼이나 도구와 연동합니다. 설정 메뉴에서 API 키를 입력하거나 제공되는 연동 가이드를 따라 워크스페이스를 연결하십시오.

**2. 데이터 및 맥락 학습 시작**

업무에 필요한 문서, 대화 로그, 프로젝트 파일을 업로드하여 AI가 정보를 학습하게 합니다. 시스템이 자동으로 파편화된 정보를 구조화하여 기억 저장소로 변환합니다.

**3. AI 에이전트와 대화하기**

연동된 AI 에이전트에게 업무 질문을 던지면 Living Brain이 저장된 맥락을 토대로 답변합니다. 이전 대화 내용을 다시 설명할 필요 없이 즉각적인 피드백을 얻을 수 있습니다.

**4. 메모리 관리 및 최적화**

대시보드에서 AI가 기억한 정보의 중요도를 확인하고 관리합니다. 불필요한 정보는 삭제하거나 우선순위를 조정하여 에이전트의 답변 정확도를 높일 수 있습니다.

## 한국어 품질 실측

**지난 회의록 요약**

- 프롬프트: 지난주 마케팅 회의에서 결정된 주요 안건 3가지만 요약해줘.
- 결과 예시: 지난주 회의에서는 첫째, 신제품 타겟층을 30대 직장인으로 설정했고, 둘째, SNS 광고 예산을 20% 증액하기로 했습니다. 마지막으로 다음 달 캠페인 일정은 15일로 확정되었습니다.
- 관찰: 한국어 문맥 파악 능력이 뛰어나며 자연스러운 문장으로 요약 결과를 출력합니다.

**업무 지침 확인**

- 프롬프트: 우리 팀이 사용하는 디자인 가이드라인에 맞춰 로고 배치 방식을 알려줘.
- 결과 예시: 저장된 디자인 매뉴얼에 따르면 로고는 우측 상단에 배치하고 최소 20px의 여백을 유지해야 합니다. 해당 가이드는 지난 5월 업데이트된 문서를 기준으로 합니다.
- 관찰: 학습된 데이터를 바탕으로 정확한 출처를 인용하여 한국어로 답변합니다.

한국어 처리 능력이 매우 우수하며 번역투 없이 자연스러운 비즈니스 한국어를 구사합니다. 전문 용어 또한 문맥에 맞게 적절히 해석하여 업무 효율을 높여줍니다.

- **소상공인**: 단골 고객의 특이사항이나 이전 주문 내역을 AI가 기억하게 하여, 상담 시 훨씬 친절하고 정확한 응대를 자동으로 수행할 수 있습니다.

## 자주 묻는 질문

**개인정보가 유출되지는 않나요?**

사용자의 데이터는 보안 정책에 따라 관리되며, 본인이 허용한 범위 내에서만 학습에 활용됩니다. 민감한 정보는 설정에서 제외할 수 있으니 안심하고 사용하셔도 됩니다.

**어떤 AI 툴과 함께 사용할 수 있나요?**

API를 지원하는 대부분의 주요 AI 모델 및 업무 자동화 툴과 연동이 가능합니다. 상세한 연동 가능 목록은 공식 홈페이지의 가이드를 확인해 보세요.

**설정이 많이 어렵나요?**

초기에는 데이터 소스를 연결하는 과정이 필요하지만 가이드가 잘 되어 있어 단계별로 따라 하면 금방 익숙해집니다. 한 번 설정해두면 업무 효율이 크게 올라갑니다.

**기존에 쓰던 AI 챗봇과 무엇이 다른가요?**

일반 챗봇은 대화가 끝나면 맥락을 잊지만, 이 도구는 사용자의 업무 히스토리를 영구적으로 기억하여 매번 상황을 다시 설명할 필요가 없습니다.

**업로드한 데이터는 안전하게 보호되나요?**

데이터 보안을 위해 암호화 기술을 사용하며, 사용자가 제어권을 가질 수 있는 환경을 제공합니다. 다만 상세 보안 인증 정보는 공식 문서를 참고하십시오.

**어떤 종류의 앱과 연동할 수 있나요?**

MCP(Model Context Protocol)를 지원하는 모든 플랫폼과 연동이 가능하며, 60개 이상의 주요 AI 툴과 즉시 연결하여 사용할 수 있습니다.

**무료 플랜으로도 충분히 업무가 가능한가요?**

기본적인 기억 저장소 기능을 체험하기에는 충분합니다. 다만 업무량이 많거나 복잡한 맥락 연결이 필요하다면 유료 플랜 도입을 고려하는 것이 좋습니다.
