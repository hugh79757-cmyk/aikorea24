## 한줄 요약

Diet Claude는 Claude 사용자가 갑작스럽게 서비스 이용 제한을 당하지 않도록 실시간 사용량을 보여주는 도구입니다. 음료수 캔 모양의 직관적인 인터페이스로 현재 남은 사용량을 한눈에 파악하여 업무 효율을 높여줍니다.

## 핵심 기능

- **실시간 측정**: 현재 Claude 사용량을 시각적으로 표시하여 끊김 없는 작업 환경을 제공합니다.
- **자동 초기화**: Claude 세션이 초기화될 때 자동으로 측정기를 리셋하여 정확한 정보를 제공합니다.
- **간편 설치**: 크롬 웹 스토어에서 바로 설치하여 별도의 복잡한 설정 없이 즉시 사용 가능합니다.

## 사용법

**1. 크롬 웹 스토어 접속**

크롬 웹 스토어에 접속하여 'Diet Claude'를 검색합니다. 검색 결과에서 해당 확장 프로그램을 찾아 'Chrome에 추가' 버튼을 눌러 설치를 완료합니다.

**2. Claude 웹사이트 접속**

Claude 공식 웹사이트에 로그인하여 접속합니다. 설치된 확장 프로그램이 자동으로 페이지를 인식하여 화면 상단 혹은 측면에 음료수 캔 아이콘을 표시합니다.

**3. 사용량 모니터링**

대화창에서 질문을 입력하고 답변을 받을 때마다 화면 속 음료수 캔이 조금씩 줄어드는 것을 확인합니다. 이로 현재 세션에서 남은 사용 가능 횟수를 직관적으로 파악합니다.

**4. 세션 초기화 대기**

사용량이 거의 소진되면 작업을 잠시 멈추고 세션이 초기화되기를 기다립니다. 초기화가 완료되면 캔이 다시 가득 차며, 다시 원활하게 서비스를 이용할 수 있습니다.

## 가격 정책

- **무료 플랜**: 크롬 웹 스토어에서 제공하는 완전 무료 도구입니다.
- **유료 플랜**: 별도의 유료 플랜이 없는 무료 서비스입니다.

비용 절약 팁: 무료로 제공되므로 별도의 비용 절약 고민 없이 바로 설치하여 사용하시면 됩니다.

- **무료 플랜** (무료): 확장 프로그램의 모든 기능을 추가 비용 없이 평생 무료로 이용할 수 있습니다.

- **별도 유료 플랜 없음** (공식 페이지 확인 필요): 현재 개발사가 제공하는 유료 구독 모델은 없으며 추후 정책 변경 여부는 공식 웹사이트에서 확인이 필요합니다.

**환불과 해지**: 무료로 제공되는 서비스이므로 별도의 환불이나 결제 관련 정책은 적용되지 않습니다.

## 한국어 지원

프로그램 자체가 인터페이스 기반이라 언어의 장벽이 없으며, 한국어 환경에서도 문제없이 작동합니다.

**이메일 작성 요청**

- 프롬프트: 거래처에 보낼 정중한 사과 이메일을 작성해 줘. 납기 지연에 대한 내용이야.
- 결과 예시: 귀하의 너그러운 양해를 구합니다. 이번 납기 지연으로 불편을 드려 대단히 죄송하며 최대한 빠르게 조치하겠습니다.
- 관찰: 한국어 입력 시 자연스러운 문장 생성 능력을 보여주며, 확장 프로그램은 언어와 무관하게 사용량만 측정하므로 품질 저하가 없습니다.

**보고서 요약 요청**

- 프롬프트: 이 회의록을 보고 핵심 요약 3줄을 작성해 줘.
- 결과 예시: 1. 프로젝트 일정 연장 확정, 2. 예산 추가 확보 필요, 3. 다음 주 화요일 재회의 예정입니다.
- 관찰: 한글 문맥을 완벽하게 이해하고 답변을 생성하며 도구는 사용자 인터페이스를 방해하지 않고 조용히 사용량을 추적합니다.

본 도구는 인터페이스 기반의 측정 도구이므로 한국어 번역 품질과 무관하게 작동합니다. 메뉴나 설정값이 복잡하지 않아 한국어 사용자도 직관적으로 사용할 수 있습니다.

- **소상공인**: 고객 응대용 챗봇이나 마케팅 문구 생성 시 사용량을 체크합니다. 제한에 걸리지 않도록 효율적으로 AI 도구를 활용하여 업무 공백을 최소화합니다.

- 음료수 캔이 줄어드는 직관적인 디자인을 채택하여 현재 남은 사용량을 복잡한 숫자 계산 없이 한눈에 쉽게 파악할 수 있습니다.

- 완전 무료 도구로서 비용 부담 없이 Claude의 사용량을 효율적으로 관리하며 생산성을 높일 수 있는 경제적인 생산성 도구입니다.

**단점**

- Claude 서비스 자체의 정책 변경으로 인해 사용량 측정 방식이 바뀌면 확장 프로그램이 일시적으로 오작동할 가능성이 존재합니다.

## 자주 묻는 질문

**개인정보가 유출될 위험은 없나요?**

이 도구는 단순히 브라우저 내에서 사용량을 측정하는 용도이므로 대화 내용이나 개인정보를 수집하지 않습니다. 안심하고 사용하셔도 좋습니다.

**모든 브라우저에서 사용할 수 있나요?**

현재는 크롬(Chrome) 웹 스토어로 배포되므로 크롬 기반의 브라우저에서 가장 원활하게 작동합니다. 웨일이나 엣지 브라우저에서도 크롬 확장 기능을 지원한다면 설치가 가능합니다.

**사용량 제한이 초기화되었는데도 표시가 그대로라면 어떻게 하나요?**

브라우저를 새로고침하거나 확장 프로그램을 다시 활성화하면 최신 상태로 갱신됩니다. 만약 지속된다면 확장 프로그램 아이콘을 클릭하여 수동으로 재설정할 수 있습니다.

**사용량이 갑자기 줄어드는 이유는 무엇인가요?**

Claude와의 대화가 길어지거나 복잡한 답변을 요구할 경우 사용량이 더 빨리 소진될 수 있습니다. 이는 도구의 오류가 아니라 서비스 정책에 따른 자연스러운 현상입니다.

**다른 브라우저에서도 사용할 수 있나요?**

현재는 크롬 웹 스토어 전용으로 개발되어 크롬 브라우저에서만 공식 지원합니다. 엣지 등 크롬 기반 브라우저에서는 설치가 가능할 수 있으나 공식적인 지원은 아닙니다.

**이 도구를 쓰면 Claude 이용 제한이 풀리나요?**

아니요, 단순히 사용량을 시각적으로 보여주는 도구일 뿐입니다. 이용 제한을 직접적으로 해제하거나 늘려주는 기능은 포함되어 있지 않습니다.

**음료수 캔이 다시 차오르지 않아요.**

Claude 세션이 완전히 초기화되지 않았거나 페이지 새로고침이 필요할 수 있습니다. 잠시 기다린 후 페이지를 새로고침하면 캔이 다시 채워지는 것을 확인할 수 있습니다.
