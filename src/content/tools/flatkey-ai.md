## 한줄 요약

Flatkey AI는 다양한 AI 모델을 하나의 API 키로 쉽게 관리할 수 있게 도와줍니다. 여러 모델을 비교하고 테스트할 수 있어 팀의 생산성을 높이는 데 유용합니다.

## 핵심 기능

- **모델 통합**: 여러 AI 모델을 하나의 키로 관리할 수 있습니다.
- **비용 절감**: 토큰 비용이 50% 낮아 경제적입니다.
- **유연한 테스트**: 다양한 모델을 쉽게 테스트하고 요청을 라우팅할 수 있습니다.

## 사용법

**1. 플랫폼 회원가입 및 연동**

Flatkey AI 공식 웹사이트에 접속하여 계정을 생성합니다. 대시보드에서 제공하는 단 하나의 API 키를 발급받습니다.

**2. 개발 환경 설정 변경**

기존에 사용하던 개발 스택이나 AI 앱 설정에서 API 엔드포인트를 Flatkey에서 제공하는 base_url로 교체합니다. 복잡한 코드 수정 없이 주소만 바꾸어 200개 이상의 모델에 즉시 연결할 수 있습니다.

**3. 선호하는 AI 모델 선택**

대시보드 또는 요청 코드로 OpenAI, Claude, Gemini, DeepSeek 등 원하는 모델을 선택합니다. 필요에 따라 여러 모델을 번갈아 테스트하며 라우팅 설정을 조정할 수 있습니다.

**4. 비용 및 크레딧 관리**

첫 충전 시 제공되는 보너스 크레딧 혜택을 확인하고 필요에 따라 요금을 충전합니다. 통합된 결제 페이지에서 토큰 사용량을 한눈에 모니터링합니다.

## 가격 정책

- **무료 플랜**: 기본적인 기능은 무료로 제공됩니다.
- **유료 플랜**: 프리미엄 플랜 30,000원/월 + 추가 기능과 지원이 포함됩니다.

비용 절약 팁: 무료 플랜으로 시작해 필요에 따라 유료 플랜으로 전환할 수 있습니다.

## 장단점

**장점**

- 200개가 넘는 다양한 AI 모델을 단 하나의 API 키와 base_url 변경만으로 손쉽게 통합 관리할 수 있습니다.
- 여러 AI 공급자와 개별 계약을 맺을 필요 없이 하나의 플랫폼에서 일괄적인 빌링과 토큰 관리가 가능합니다.
- 토큰 비용이 기존 방식 대비 50% 낮아 여러 모델을 조합하여 사용하는 개발자와 스타트업의 비용 부담을 크게 덜어줍니다.
- 첫 충전 시 금액별로 풍부한 보너스 크레딧(예: $10 충전 시 $13 제공)을 지급하여 경제적인 테스트 환경을 지원합니다.

**단점**

- 플랫폼 인터페이스와 기술 문서가 주로 영어로 제공되어 국내 초급 사용자에게는 진입 장벽이 다소 높습니다.
- 중간 API 라우팅 레이어를 거치기 때문에 서비스 장애 발생 시 연결된 모든 모델에 일시적인 영향이 미칠 수 있습니다.
- 정확한 환불 규정이나 월 구독 플랜의 세부 한도가 공식 요금 페이지를 직접 확인해야만 파악 가능합니다.

- **저작권/상업적 이용**: Flatkey를 통해 호출하는 각 개별 AI 모델(OpenAI, Anthropic 등)의 상업적 이용 약관과 저작권 정책을 별도로 준수해야 합니다.

- **계정 관리**: 단 하나의 API 키로 모든 모델에 접근할 수 있는 만큼, 키가 유출되지 않도록 보안 관리에 각별한 주의를 기울여야 합니다.

Flatkey AI는 여러 AI 모델을 통합하여 사용하는 기능을 제공합니다. 이로 비용 절감과 효율적인 작업이 가능합니다.

**어떻게 시작하나요?**

웹사이트에 가입 후 무료 플랜으로 시작할 수 있으며, 필요에 따라 유료 플랜으로 업그레이드할 수 있습니다.

**한국어 지원이 가능한가요?**

네, Flatkey AI는 한국어를 지원하여 한국 사용자들이 쉽게 이용할 수 있습니다.

**Flatkey AI를 이용하려면 기존에 쓰던 코드를 많이 고쳐야 하나요?**

아닙니다. 기존 스택을 그대로 유지한 채 API의 base_url 주소 하나만 Flatkey 제공 주소로 변경하면 되므로 연동 과정이 매우 간단합니다.

**어떤 AI 모델들을 지원하나요?**

OpenAI의 GPT 시리즈, Anthropic의 Claude, Google의 Gemini, DeepSeek, ByteDance의 Seedance 등 200개 이상의 다양한 최신 AI 모델을 지원합니다.

신규 사용자가 처음 계정을 충전할 때 $10 충전 시 $13, $20 충전 시 $28, $200 충전 시 $300 형태의 추가 크레딧이 적용되는 혜택을 제공합니다.
