## 한줄 요약

IFTTT는 서로 다른 앱과 기기를 연결하여 특정 조건이 충족되면 자동으로 작업을 실행하는 서비스입니다. 반복되는 수동 업무를 자동화함으로써 업무 효율을 극대화하고 시간을 절약해 줍니다.

## 핵심 기능

- **앱 연동**: 수백 개의 앱을 서로 연결하여 복잡한 설정 없이 자동화 기능을 구현합니다.
- **레시피 공유**: 다른 사용자가 만들어둔 자동화 설정을 그대로 가져와 즉시 사용할 수 있습니다.
- **스마트 홈 제어**: IoT 기기와 앱을 연결하여 퇴근 시간에 맞춰 조명을 켜는 등 생활을 자동화합니다.

## 사용법

**1. 서비스 계정 연결하기**

메인 화면의 'Services' 탭에서 자주 사용하는 구글 드라이브, 슬랙, 인스타그램 등을 선택합니다. 각 서비스의 로그인 정보를 입력하여 IFTTT가 해당 계정에 접근할 수 있도록 권한을 승인합니다.

**2. 자동화 레시피 선택**

상단 검색창에 'Save Instagram photos to Google Drive'처럼 원하는 기능을 검색합니다. 이미 만들어진 수많은 레시피 중 본인에게 적합한 것을 골라 'Connect' 버튼을 누릅니다.

**3. 세부 조건 설정하기**

선택한 레시피의 설정 화면에서 파일 저장 경로를 지정하거나 특정 태그를 입력합니다. 'Save'를 클릭하면 해당 조건이 충족될 때 자동으로 작업이 실행될 준비가 완료됩니다.

**4. 자동화 활성화 확인**

나의 레시피 목록인 'My Applets' 탭에서 활성화 여부를 확인합니다. 이후 설정한 앱에서 이벤트가 발생하면 IFTTT가 백그라운드에서 자동으로 작업을 수행합니다.

## 가격 정책

- **무료 플랜**: 매달 2개의 자동화 레시피를 무료로 생성하고 사용할 수 있습니다.
- **유료 플랜**: Pro 플랜(월 약 4,000원~), Pro+ 플랜(월 약 13,000원~)으로 무제한 레시피와 고급 다단계 자동화를 제공합니다.

비용 절약 팁: 처음에는 무료 플랜으로 핵심 업무 2가지만 자동화해보고, 효율이 높다면 유료로 전환하는 것을 추천합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜은 매달 2개의 자동화 레시피를 생성하여 사용할 수 있습니다. 복잡한 다단계 작업보다는 단순한 1대1 앱 연동 기능을 체험해 보기에 적합합니다.

- **Pro 플랜** (월 4,000원 수준 (공식 페이지 확인 필요)): 무제한 레시피 생성이 가능하며 더 빠른 속도의 자동화 처리를 지원합니다.

- **Pro+ 플랜** (월 13,000원 수준 (공식 페이지 확인 필요)): 여러 단계를 거치는 복잡한 자동화 워크플로우를 구성할 수 있으며 개발자 도구 접근을 지원합니다.

**환불과 해지**: 구독 해지는 언제든지 설정 메뉴에서 가능하며 결제 주기 종료 시까지 서비스가 유지됩니다. 환불 규정은 결제 시점의 약관을 확인해야 합니다.

## 한국어 지원

서비스 인터페이스는 영어로 제공되지만 직관적인 아이콘과 구조 덕분에 영어를 유창하게 하지 않아도 쉽게 사용할 수 있습니다.

## 한국어 품질 실측

**이메일 첨부파일 저장**

- 프롬프트: Gmail에 첨부파일이 오면 구글 드라이브에 저장해줘.
- 결과 예시: Gmail에서 특정 라벨이 달린 이메일의 첨부파일을 지정된 구글 드라이브 폴더로 자동 업로드합니다.
- 관찰: 도구 자체가 영어 기반이므로 영어 키워드로 검색해야 정확한 레시피가 나옵니다.

**SNS 게시물 동기화**

- 프롬프트: 인스타그램에 올린 사진을 트위터에도 올려줘.
- 결과 예시: 인스타그램에 새 게시물이 업로드되면 해당 사진과 링크를 트위터에 자동으로 게시합니다.
- 관찰: 한국어 프롬프트보다는 영어로 된 앱 이름을 입력해야 원활한 검색이 가능합니다.

인터페이스가 영어로만 제공되어 한국인 사용자에게는 다소 생소할 수 있습니다. 하지만 아이콘 위주의 직관적인 디자인이라 영어 단어 몇 개만 알면 누구나 쉽게 적응할 수 있습니다.

## 이런 분에게 추천합니다

반복적인 단순 업무를 줄이고 싶은 직장인에게 추천합니다. 여러 SNS 채널을 동시에 관리해야 하는 마케터에게 유용합니다. 스마트 홈 기기를 효율적으로 제어하고 싶은 1인 가구에게 적합합니다.

## 실제 활용 예시

- **직장인**: 매일 아침 이메일 첨부파일을 구글 드라이브에 저장하는 작업을 자동화했습니다. 이제 수동으로 다운로드할 필요 없이 자동으로 분류되어 업무 시간이 크게 단축되었습니다.
- **학생**: 특정 뉴스 사이트의 공지사항을 RSS로 받아 슬랙으로 알림을 받도록 설정했습니다. 중요한 정보를 놓치지 않고 실시간으로 확인할 수 있어 매우 편리합니다.
- **소상공인**: 네이버 스마트스토어의 주문 내역을 구글 시트로 자동 정리하도록 설정했습니다. 수기로 장부를 작성하는 번거로움이 사라져 고객 응대에 더 집중하고 있습니다.

## 장단점

**장점**

- 코딩 지식이 전혀 없어도 마우스 클릭만으로 복잡한 앱 간의 연동을 완성할 수 있습니다.
- 수천 개의 서비스가 연동되어 있어 일상적인 업무부터 스마트 홈 제어까지 활용도가 매우 높습니다.
- 다른 사용자들이 만들어둔 검증된 레시피를 그대로 가져와 즉시 사용할 수 있어 편리합니다.
- 반복적인 수동 업무를 자동화함으로써 업무 시간을 획기적으로 단축하고 생산성을 높여줍니다.

**단점**

- 한국어 언어 설정을 지원하지 않아 메뉴 이용 시 영어 단어를 읽어야 하는 불편함이 있습니다.
- 무료 플랜에서는 생성 가능한 레시피 수가 2개로 제한되어 있어 본격적인 활용에는 한계가 있습니다.
- 연동된 서비스의 API 정책이 변경될 경우 예기치 않게 자동화 기능이 멈출 가능성이 있습니다.

## 주의사항

- **개인정보**: 각 서비스의 계정 정보를 입력해야 하므로 보안이 검증된 공식 앱만 연동하는 것이 안전합니다.
- **저작권/상업적 이용**: 자동으로 게시되는 콘텐츠의 저작권은 사용자 본인에게 있으며, 상업적 이용 시 각 플랫폼의 운영 정책을 준수해야 합니다.
- **요금/한도**: 무료 플랜의 레시피 개수 제한을 확인하고 필요에 따라 유료 플랜으로 업그레이드하여 한도를 관리하십시오.
- **계정 관리**: 연동된 계정이 해킹될 경우 자동화 기능이 악용될 수 있으므로 주기적으로 연결된 앱 목록을 점검해야 합니다.

## 자주 묻는 질문

**코딩을 전혀 못 하는데 사용할 수 있나요?**

네, 가능합니다. IFTTT는 '만약(If) 이것이 발생하면(This), 저것을 하라(That)'는 단순한 논리 구조로 되어 있어 코딩 지식이 없어도 누구나 쉽게 자동화를 만들 수 있습니다.

**무료 플랜으로 충분할까요?**

개인이 가장 핵심적인 업무 1~2개를 자동화하기에는 충분합니다. 하지만 여러 앱을 동시에 연결하거나 복잡한 다단계 워크플로우가 필요하다면 유료 플랜을 고려해야 합니다.

**연동 가능한 앱은 어디서 확인하나요?**

공식 홈페이지의 'Services' 메뉴에서 확인 가능합니다. 구글, 슬랙, 인스타그램, 트위터 등 일상에서 자주 쓰는 대부분의 앱이 지원됩니다.

**무료 플랜으로도 충분히 업무 자동화가 가능한가요?**

단순히 이메일을 저장하거나 SNS 게시물을 공유하는 정도라면 2개의 레시피로도 충분합니다. 다만 여러 앱을 엮는 복잡한 업무라면 유료 플랜이 필요합니다.

**자동화가 실행되지 않을 때는 어떻게 하나요?**

연동된 서비스의 비밀번호가 변경되었는지 확인하고, IFTTT 내 'Services' 탭에서 재인증을 시도해 보시기 바랍니다.

**사용 중인 앱이 목록에 없으면 어떻게 하나요?**

Webhooks 기능을 활용하면 API를 통해 직접 연동할 수 있지만, 이는 고급 사용자용 기능이므로 추가 학습이 필요합니다.

**스마트 홈 기기 제어도 가능한가요?**

네, 필립스 휴나 삼성 스마트싱스 등 지원하는 IoT 기기라면 퇴근 시간이나 날씨에 맞춰 조명과 가전을 자동으로 제어할 수 있습니다.
