## 한줄 요약

AirJelly는 사용자의 작업을 지켜보고 기억하여 필요한 때에 자동으로 지원하는 AI 도구입니다. 이로 작업의 효율성을 높일 수 있습니다.

## 핵심 기능

- **프로액티브 지원**: 사용자의 요구를 미리 파악하여 자동으로 도움을 줍니다.
- **작업 기억**: 과거의 작업 내용을 기억하여 반복적인 작업을 줄입니다.
- **일정 관리**: 일정을 효율적으로 관리하여 중요한 일정을 놓치지 않도록 돕습니다.

## 사용법

**1. 프로그램 설치 및 실행**

공식 홈페이지에서 AirJelly 설치 파일을 다운로드하여 실행합니다. 설치 후 계정을 생성하고 사용자 화면의 작업 내용을 모니터링할 수 있도록 권한을 승인합니다.

**2. 작업 흐름 모니터링 시작**

도구가 백그라운드에서 실행되며 사용자가 사용하는 앱과 웹 브라우저의 활동을 자동으로 기록합니다. 별도의 설정 없이도 업무 흐름이 타임라인 형태로 저장됩니다.

**3. 자동 생성된 작업 확인**

메신저나 회의 중 언급된 업무 내용을 도구가 자동으로 감지하여 태스크로 변환합니다. 대시보드에서 생성된 할 일 목록과 마감 기한을 확인합니다.

**4. 업무 요약 및 리포트 활용**

일과 종료 후 제공되는 데일리 리포트로 오늘 수행한 업무를 한눈에 파악합니다. 궁금한 과거 작업 내용은 검색창에 질문하여 즉시 답변을 얻습니다.
