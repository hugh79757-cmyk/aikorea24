## 한줄 요약

Lemonade AI는 다양한 AI 모델을 로컬에서 운영할 수 있는 플랫폼으로, 데이터 보안과 커스터마이징이 가능합니다.

## 핵심 기능

- **GUI 제공**: 사용자가 쉽게 접근할 수 있어 편리합니다.
- **REST API**: 다양한 애플리케이션과 연동할 수 있습니다.
- **모델 호스팅**: 다양한 AI 모델을 직접 운영할 수 있습니다.

## 사용법

**1. 설치 파일 다운로드**

공식 웹사이트나 저장소에서 Windows, macOS, Linux 등 사용 환경에 맞는 설치 파일이나 Docker 이미지를 내려받습니다. 로컬 컴퓨터 환경에 맞추어 런타임 서버와 관리 도구를 준비합니다.

**2. AI 모델 등록하기**

허깅페이스(Hugging Face) 모델 연동 기능과 모델 레지스트리를 활용하여 필요한 텍스트, 이미지, 음성 모델을 로컬 환경에 가져옵니다. vllm, Qwen, GLM 등의 백엔드를 선택하여 호스팅할 수 있습니다.

**3. 실행 환경 및 인터페이스 설정**

제공되는 GUI 화면, CLI 명령어, 또는 REST API 엔드포인트로 로컬 AI 모델의 실행 설정을 마칩니다. GPU 성능 측정 및 튜닝 도구를 사용하여 최적의 구동 환경을 조성합니다.

**4. 멀티모달 워크플로우 실행**

채팅 에이전트 구축, 이미지 생성, 실시간 음성 전사(Transcription) 등 원하는 작업을 로컬 환경에서 안전하게 수행합니다. 기업 데이터와 결합하여 하이브리드 또는 온프레미스 방식으로 활용합니다.

## 가격 정책

- **무료 플랜**: 무료 오픈 소스 플랜이 제공됩니다.
- **유료 플랜**: 유료 플랜은 없습니다. 모든 기능이 무료로 제공됩니다.

비용 절약 팁: 오픈 소스이므로 커스터마이징로 비용을 절감할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈소스 플랫폼으로 제공되어 신용카드 등록 없이 모든 핵심 기능을 무료로 이용할 수 있습니다. 텍스트, 이미지, 코드, 음성 워크플로우를 로컬 하드웨어 성능 한도 내에서 제한 없이 구동 가능합니다.

- **무료 오픈소스 플랜** (무료 (0원)): Apache 2.0 라이선스를 기반으로 소스코드와 모든 로컬 실행 기능이 제공됩니다.

- **유료 커스텀 플랜** (공식 페이지 확인 필요): 본 플랫폼은 유료 플랜이 별도로 존재하지 않으나, 추가 인프라 구축이나 지원에 대해서는 공식 요금 페이지를 확인해야 합니다.

**환불과 해지**: 오픈소스 무료 소프트웨어로 운영되므로 별도의 환불이나 유료 결제 해지 절차가 필요하지 않습니다.

## 한국어 지원

한국어 사용자도 쉽게 사용할 수 있도록 인터페이스와 문서가 제공됩니다.

## 한국어 품질 실측

**회의록 음성 전사**

- 프롬프트: 이번 주 팀 프로젝트 회의 음성 파일을 로컬에서 실시간으로 텍스트로 변환하고 주요 내용을 요약해 주세요.
- 결과 예시: 업로드된 음성 파일을 실시간 전사하여 텍스트로 변환하였으며, 논의된 주요 안건인 일정 조율과 예산 배정 항목을 요약하여 정리했습니다.
- 관찰: 로컬 음성 전사 기능이 원활하게 작동하며 자연스러운 한국어 요약 결과를 보여줍니다.

**고객 응대 에이전트**

- 프롬프트: 소상공인 매장을 위한 자주 묻는 질문 응대용 채팅 에이전트 프롬프트를 로컬 모델에 설정해 주세요.
- 결과 예시: 매장 운영 시간, 환불 규정, 위치 안내 등 고객이 자주 묻는 질문에 친절하고 정확하게 답변하도록 로컬 챗봇 에이전트가 설정되었습니다.
- 관찰: 전문적인 프롬프트 설정 과정에서 한국어 응답 품질이 안정적으로 유지됩니다.

오픈소스 기반 로컬 플랫폼 특성상 사용하는 모델의 종류에 따라 한국어 처리 능력과 자연스러움이 달라질 수 있습니다. 인터페이스와 문서 활용 시 기본적인 안내는 원활하게 이루어집니다.

## 이런 분에게 추천합니다

AI 개발에 관심이 있는 중급 개발자에게 추천합니다. 로컬에서 AI 모델을 운영하고 싶은 기업에 적합합니다.

## 실제 활용 예시

- **직장인**: 직장에서 프로젝트 관리하려고 Lemonade AI를 사용하여 팀 회의 내용을 요약합니다.
- **학생**: 대학 과제 제출하려고 Lemonade AI를 활용하여 보고서를 작성합니다.
- **소상공인**: 자신의 비즈니스 아이디어하려고 Lemonade AI를 사용하여 사업계획서를 만듭니다.

**장점:**
- 로컬에서 안전하게 데이터 처리 가능

**단점:**

**이런 분에게 가장 적합합니다:** 로컬에서 AI 모델을 운영하고자 하는 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 데이터가 외부로 유출되지 않고 로컬 환경에 안전하게 보존되어 프라이버시와 보안을 보장합니다.
- 텍스트, 이미지, 코드, 음성을 모두 아우르는 다양한 멀티모달 워크플로우를 직접 구축하고 실행할 수 있습니다.
- GUI, CLI, REST API 등 개발자와 일반 사용자 모두에게 편리한 다양한 접근 방식을 제공합니다.
- 허깅페이스 모델 연동과 vllm 등 다양한 인프라 백엔드를 지원하여 유연한 커스터마이징이 가능합니다.

**단점**

- 로컬 컴퓨터에서 AI 모델을 직접 구동하므로 고성능의 GPU와 충분한 하드웨어 사양이 필수적으로 요구됩니다.
- 설치와 모델 레지스트리 설정 과정에서 초보자에게는 다소 복잡한 기술적 지식이 필요할 수 있습니다.
- 클라우드 서비스와 달리 대규모 연산 시 개인용 하드웨어의 성능 한계에 부딪힐 수 있습니다.

## 주의사항

- **개인정보**: 모든 데이터와 모델이 로컬 환경에서 처리되며 기본적으로 텔레메트리가 없어 민감한 정보 보호에 유리합니다.
- **저작권/상업적 이용**: Apache 2.0 오픈소스 라이선스를 따르며, 로컬에 불러오는 개별 AI 모델의 라이선스 규정을 별도로 확인해야 합니다.
- **요금/한도**: 플랫폼 자체는 무료이지만 고성능 모델 구동 시 발생하는 전기세나 하드웨어 업그레이드 비용은 사용자가 부담합니다.
- **계정 관리**: 클라우드 회원가입 없이 로컬에서 직접 구동하는 방식이므로 별도의 계정 관리보다는 로컬 보안 설정이 중요합니다.

## 자주 묻는 질문

**Lemonade AI는 어떤 기능을 제공하나요?**

Lemonade AI는 텍스트, 이미지, 코드, 음성을 처리할 수 있는 다양한 기능을 제공합니다.

**설치 방법은 간단한가요?**

설치 과정이 다소 복잡할 수 있으나, 공식 문서를 참고하면 도움이 됩니다.

**다른 AI 툴과의 차별점은 무엇인가요?**

Lemonade AI는 로컬에서 모든 작업을 처리할 수 있어 데이터 보안이 뛰어납니다.

**인터넷에 연결되지 않은 오프라인 환경에서도 사용할 수 있나요?**

네, 로컬에서 모델을 다운로드하여 설치한 이후에는 인터넷 연결 없이도 온프레미스 환경에서 완전하게 구동할 수 있습니다.

**어떤 운영체제와 하드웨어 환경을 지원하나요?**

Windows, macOS, 주요 Linux 배포판뿐만 아니라 Docker 및 snap 환경을 지원하며, 원활한 구동을 위해 호환 가능한 GPU가 권장됩니다.

**허깅페이스에 있는 모델을 어떻게 가져와서 사용할 수 있나요?**

플랫폼 내에 제공되는 모델 레지스트리의 허깅페이스 임포트 기능을 활용하여 원하는 모델을 손쉽게 불러와 로컬에 호스팅할 수 있습니다.

**기업에서 보안이 중요한 데이터를 처리할 때 적합한가요?**

네, 데이터 유출 우려가 전혀 없는 로컬-우선(local-first) 아키텍처를 지원하므로 보안과 규정 준수가 필수적인 의료 및 금융 분야에 적합합니다.
