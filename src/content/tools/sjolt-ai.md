## 한줄 요약

SJolt AI는 이미지와 영상을 생성하고 배포하는 과정을 단순화하는 API입니다. 다양한 모델을 탐색하고 비교할 수 있어 사용자에게 유용합니다.

## 핵심 기능

- **모델 탐색**: 여러 생성 모델을 쉽게 비교할 수 있습니다.
- **API 통합**: 하나의 API로 다양한 작업을 수행할 수 있습니다.
- **성능 비교**: 모델의 출력 품질과 비용을 비교할 수 있습니다.

## 사용법

**1. 모델 탐색 및 선택**

상단 카탈로그 메뉴에서 이미지 및 영상 생성 모델을 조회합니다. 각 모델별 품질과 비용을 비교하여 본인의 프로젝트에 적합한 모델을 선택합니다.

**2. 플레이그라운드 테스트**

플레이그라운드 화면에서 프롬프트를 입력하고 비율, 영상 길이 등 옵션을 설정합니다. 생성 버튼을 눌러 결과물의 품질을 미리 확인합니다.

**3. API 코드 복사 및 통합**

테스트가 완료되면 제공되는 cURL, JavaScript, Python 예제 코드를 복사합니다. 이를 본인의 서비스나 개발 환경에 그대로 붙여넣어 연동을 시작합니다.

**4. 사용량 모니터링 관리**

대시보드 페이지에서 현재까지의 사용 기록과 모델별 비용을 확인합니다. 예산 범위 내에서 작업이 이루어지고 있는지 정기적으로 점검합니다.

## 가격 정책

- **무료 플랜**: 무료 플랜으로 기본 기능을 사용해 볼 수 있습니다.
- **유료 플랜**: 프리미엄 플랜 10,000원/월 + 추가 기능과 더 많은 요청량 제공.

비용 절약 팁: 무료 플랜으로 먼저 사용해보고 필요에 따라 유료로 전환하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 구체적인 무료 한도는 명시되어 있지 않으나, 플랫폼 내에서 모델을 테스트하고 API를 연동하는 기본 기능을 제공합니다. 상세한 무료 이용 범위는 공식 홈페이지의 요금 페이지를 확인해야 합니다.

- **구독형 플랜** (월 10,000원 (공식 페이지 확인 필요)): 더 많은 요청량과 추가적인 프리미엄 기능을 제공하며 사용량에 따른 비용이 별도로 부과될 수 있습니다.

- **종량제 모델 비용** (건당 0.04달러부터 (공식 페이지 확인 필요)): 사용하는 모델과 작업 종류에 따라 0.04달러에서 1.55달러까지 차등적으로 비용이 발생합니다.

**환불과 해지**: 구독 및 결제 관련 정책은 공식 홈페이지의 요금 안내 페이지로 직접 확인하시기 바랍니다.

- 결과 예시: 해변의 파도 소리와 함께 여유롭게 커피를 즐기는 여성의 모습이 담긴 고화질 영상이 생성됩니다.
- 관찰: 입력한 한국어 프롬프트를 바탕으로 영상 생성 모델이 자연스럽게 반응합니다.

**제품 홍보 이미지**

- 프롬프트: 세련된 디자인의 스마트워치를 착용한 손목 클로즈업 사진을 생성해줘.
- 결과 예시: 스마트워치의 디테일이 살아있는 고품질의 손목 클로즈업 이미지가 결과물로 제공됩니다.
- 관찰: 한국어 명령어를 정확히 이해하고 이미지의 세부 묘사를 수행합니다.

한국어 프롬프트를 입력했을 때 결과물의 품질이 준수하게 나타납니다. 다만, 기술적인 API 문서나 설정 메뉴는 영어로 제공될 가능성이 높으므로 참고가 필요합니다.

## 장단점

**장점**

- 다양한 생성 모델을 하나의 API로 통합하여 관리할 수 있어 개발 효율성이 매우 높습니다.
- 플레이그라운드로 코딩 없이도 모델의 출력 품질을 미리 테스트하고 비교할 수 있습니다.
- 비동기식 작업 처리를 지원하여 긴 영상 제작 작업도 안정적으로 수행할 수 있습니다.
- 모델별로 발생한 비용과 사용 기록을 대시보드에서 투명하게 확인할 수 있어 예산 관리에 유리합니다.

**단점**

- 기술적인 API 기반 서비스이므로 일반 사용자보다는 개발자나 제품 기획자에게 적합한 난이도입니다.
- 사용하는 모델마다 가격이 다르게 책정되어 있어 예산 산정에 다소 복잡함이 있을 수 있습니다.
- 공식 문서와 기술 지원 내용이 주로 영어로 작성되어 있어 한국인 사용자가 학습하는 데 시간이 걸릴 수 있습니다.

- **저작권/상업적 이용**: 생성된 이미지와 영상의 상업적 이용 가능 여부는 각 모델의 라이선스 정책에 따라 다르므로 반드시 확인 후 사용해야 합니다.
- **요금/한도**: 종량제 방식으로 운영되므로 API 사용량에 따라 예기치 않은 비용이 발생할 수 있으니 대시보드를 수시로 확인하십시오.
- **계정 관리**: API 키는 외부로 유출되지 않도록 엄격히 관리해야 하며 타인과 공유하지 않는 것이 안전합니다.

Kling, ByteDance 등 다양한 최신 영상 생성 모델을 지원합니다. 상세 지원 목록은 홈페이지의 모델 카탈로그에서 확인 가능합니다.

**비용은 어떻게 결제되나요?**

주로 사용한 모델과 작업량에 따른 종량제로 운영됩니다. 정확한 결제 방식과 구독 플랜 정보는 공식 홈페이지의 요금 페이지를 참조하십시오.
