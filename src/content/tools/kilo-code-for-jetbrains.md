## 한줄 요약

Kilo Code는 JetBrains IDE 환경에서 여러 AI 에이전트를 동시에 가동해 코딩 업무를 돕는 도구입니다. 개발자가 IDE를 벗어나지 않고도 600개 이상의 모델을 활용해 복잡한 로직 구현이나 코드 리뷰를 자동화할 수 있습니다.

## 핵심 기능

- **멀티 에이전트**: 여러 작업을 병렬로 처리하여 개발 속도를 획기적으로 높입니다.
- **IDE 통합**: 기존에 사용하던 JetBrains 환경 그대로 사용하여 적응 시간이 필요 없습니다.
- **모델 선택권**: 600개 이상의 다양한 AI 모델 중 프로젝트에 최적화된 모델을 선택할 수 있습니다.

## 사용법

**1. 플러그인 설치 및 연동**

JetBrains IDE의 마켓플레이스에서 Kilo Code 플러그인을 검색하여 설치합니다. 설치 후 설정 메뉴에서 본인의 API 키를 입력하거나 원하는 로컬 모델을 선택하여 연결합니다.

**2. AI 에이전트 호출**

코드 에디터 내에서 단축키를 눌러 Kilo 인터페이스를 활성화합니다. 채팅창에 해결하고자 하는 프로그래밍 작업을 자연어로 입력하여 에이전트를 호출합니다.

**3. 멀티 에이전트 작업 수행**

여러 개의 에이전트를 동시에 실행하여 복잡한 로직 구현과 코드 리뷰를 병렬로 처리합니다. 작업 트리 내에서 각 에이전트의 진행 상황을 실시간으로 확인합니다.

**4. 코드 반영 및 검토**

AI가 제안한 코드 변경 사항을 확인하고 'Apply' 버튼을 눌러 프로젝트에 즉시 적용합니다. 변경된 코드가 의도대로 작동하는지 테스트를 실행하여 최종 검증합니다.

## 가격 정책

- **무료 플랜**: 플러그인 설치 및 일부 기본 기능을 무료로 체험할 수 있습니다.
- **유료 플랜**: Enterprise 플랜(가격 별도 문의)을 통해 팀 단위 협업 및 고급 모델 사용 권한을 제공합니다.

비용 절약 팁: 다양한 모델을 테스트해 보고 자신의 개발 스타일에 가장 잘 맞는 모델을 선택하여 효율을 극대화하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 플러그인 설치와 핵심 기능을 무료로 체험할 수 있습니다. 모델 사용 시 별도의 마크업 비용 없이 원가 그대로 이용 가능하며 개인 API 키를 등록하여 활용할 수 있습니다.

- **Enterprise 플랜** (공식 페이지 확인 필요): 팀 단위 협업 기능과 고급 AI 모델 사용 권한을 제공합니다. 기업 환경에 최적화된 보안 및 관리 기능을 포함합니다.

- **사용자 API 키 이용 방식** (사용량에 따라 상이 (공식 페이지 확인 필요)): 본인이 보유한 OpenAI 등 AI 서비스의 API 키를 직접 등록하여 사용합니다. 중개 수수료 없이 실제 모델 사용료만 지불합니다.

**환불과 해지**: 결제 및 환불 정책은 Kilo 공식 홈페이지의 이용 약관을 따라야 하며 구독 해지는 계정 설정 페이지에서 언제든 가능합니다.

## 한국어 지원

플러그인 인터페이스는 영어로 제공되지만 AI 모델이 한국어 프롬프트를 완벽하게 이해하고 한국어로 코드 주석이나 설명을 생성할 수 있습니다.

## 한국어 품질 실측

**코드 주석 작성**

- 프롬프트: 이 파이썬 함수를 한국어로 상세한 설명을 주석으로 달아줘.
- 결과 예시: # 입력받은 리스트에서 중복을 제거하고 정렬하는 함수입니다.
# 반환값은 오름차순으로 정렬된 새로운 리스트입니다.
- 관찰: 한국어 주석의 문맥 파악 능력이 뛰어나며 자연스러운 문장으로 출력합니다.

**에러 원인 분석**

- 프롬프트: 지금 발생한 코드 에러 메시지를 한국어로 해석하고 해결 방법을 알려줘.
- 결과 예시: 해당 에러는 변수 타입 불일치로 인해 발생했습니다. 문자열 대신 정수형을 사용하도록 코드를 수정하면 해결됩니다.
- 관찰: 기술적인 전문 용어와 한국어 설명이 혼합되어 이해하기 쉽게 제시됩니다.

한국어 프롬프트에 대한 이해도가 매우 높으며, 결과물 또한 매끄러운 한국어로 생성됩니다. 다만 IDE 인터페이스 자체는 영어로 구성되어 있어 초기 설정 시 약간의 영문 이해가 필요합니다.

## 이런 분에게 추천합니다

복잡한 프로젝트를 관리하는 전문 개발자에게 추천합니다. 여러 기능을 동시에 개발해야 하는 팀장급 개발자에게 적합합니다. 최신 AI 모델을 활용해 코드 품질을 높이고 싶은 개발자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 레거시 코드 분석 시 여러 AI 에이전트에게 각기 다른 모듈의 리팩토링을 맡겨 작업 시간을 단축합니다. 변경된 코드의 차이점을 IDE 내에서 바로 확인하며 효율적으로 업무를 처리합니다.
- **학생**: 졸업 작품 개발 시 복잡한 알고리즘 구현을 AI에게 요청하여 학습 시간을 확보합니다. 다양한 모델을 비교하며 어떤 모델이 내 코드 스타일에 가장 정확한 제안을 하는지 실험해 볼 수 있습니다.
- **소상공인**: 간단한 사내 관리용 웹 서비스를 직접 개발할 때, AI 에이전트를 활용해 반복적인 UI 코드 작성을 자동화합니다. 전문 개발자가 아니더라도 IDE 내에서 가이드를 받으며 빠르게 서비스를 구축할 수 있습니다.

## 장단점

**장점**

- 500개 이상의 다양한 AI 모델을 자유롭게 선택하여 프로젝트 성격에 맞는 최적의 성능을 끌어낼 수 있습니다.
- JetBrains, VS Code, CLI 등 개발자가 평소 사용하는 환경 어디서든 일관된 AI 에이전트 경험을 제공합니다.
- AI 모델 사용 시 중개 마크업 비용이 발생하지 않아 직접 API 키를 연동하면 비용을 효율적으로 관리할 수 있습니다.
- 오픈 소스 기반으로 설계되어 코드 처리 과정의 투명성이 보장되며, 보안이 중요한 프로젝트에서도 안심하고 사용 가능합니다.

**단점**

- 고급 기능을 모두 활용하기 위해서는 API 키 설정 및 환경 구성 등 초기 학습 곡선이 다소 높은 편입니다.
- IDE 인터페이스가 영어로만 제공되기 때문에 한국어 사용자에게는 설정 메뉴 접근 시 다소 불편함이 있을 수 있습니다.
- 무료 플랜과 유료 플랜의 세부적인 기능 차이가 명확하므로 기업용 도입 시 비용 산정을 위한 별도의 상담이 필요합니다.

## 주의사항

- **개인정보**: API 키를 직접 등록하여 사용할 경우 키가 외부로 유출되지 않도록 환경 변수 관리 등에 각별히 유의해야 합니다.
- **저작권/상업적 이용**: AI가 생성한 코드는 저작권 문제의 소지가 있을 수 있으므로 상업적 프로젝트 적용 전 반드시 코드 검토를 거쳐야 합니다.
- **요금/한도**: 사용하는 AI 모델의 API 제공업체별 요금 체계를 사전에 확인하여 예상치 못한 비용 발생을 방지하시기 바랍니다.
- **계정 관리**: 기업용 플랜의 경우 팀원 간 계정 공유보다는 개별 계정 사용을 권장하며 보안 정책을 준수하여 관리해야 합니다.

## 자주 묻는 질문

**기존에 사용하던 AI 코딩 툴과 무엇이 다른가요?**

Kilo Code는 단순히 코드 완성만 돕는 것이 아니라, 여러 에이전트를 동시에 실행하여 복잡한 프로젝트 구조를 관리하고 테스트까지 수행하는 제어실 역할을 합니다.

**어떤 JetBrains 제품에서 사용할 수 있나요?**

IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Rider 등 거의 모든 JetBrains 기반 IDE에서 사용 가능합니다.

**보안이 걱정되는데 코드가 외부로 유출되나요?**

기업용 플랜의 경우 보안 정책에 따라 데이터 처리 방식을 설정할 수 있습니다. 자세한 내용은 공식 홈페이지의 보안 가이드를 확인하시기 바랍니다.

**기존에 사용하던 JetBrains 플러그인과 충돌하지 않나요?**

대부분의 주요 플러그인과 호환되도록 설계되었습니다. 다만 리소스 사용량이 많은 AI 모델을 다수 가동할 경우 IDE가 느려질 수 있습니다.

**오프라인 환경에서도 사용할 수 있나요?**

로컬 모델을 지원하므로 인터넷 연결 없이도 로컬 환경에서 에이전트를 구동할 수 있습니다. 이 경우 높은 사양의 PC 환경이 권장됩니다.

**기업에서 보안을 위해 자체 서버에 설치할 수 있나요?**

오픈 소스 기반이므로 보안이 중요한 기업 환경에서는 자체 서버에 호스팅하여 사용하는 것이 가능합니다.

**어떤 모델을 선택해야 할지 모르겠어요.**

작업의 복잡도에 따라 추천 모델이 달라집니다. 간단한 코딩은 가벼운 모델을, 복잡한 로직은 고성능 모델을 선택하여 테스트해보시길 권장합니다.
