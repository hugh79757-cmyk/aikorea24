## 한줄 요약

Tenet Security는 기업에서 사용하는 AI 에이전트가 의도치 않은 정보를 유출하거나 악의적으로 동작하지 않도록 실시간으로 감시하는 보안 도구입니다. 복잡한 AI 환경에서 발생할 수 있는 보안 사고를 예방하여 기업의 소중한 데이터를 보호합니다.

## 핵심 기능

- **행동 감시**: AI 에이전트가 수행하는 모든 작업을 실시간으로 추적하여 이상 징후를 즉시 파악합니다.
- **자동 차단**: 보안 정책을 위반하는 에이전트의 동작을 시스템이 자동으로 차단하여 사고를 방지합니다.
- **위협 분석**: 축적된 데이터를 바탕으로 잠재적인 보안 위협을 분석하고 상세한 리포트를 제공합니다.

## 사용법

**1. 공식 데모 신청하기**

Tenet Security 공식 웹사이트에 방문하여 기업용 데모 신청 양식을 작성합니다. 회사 이메일과 담당자 정보를 입력하여 상담 일정을 조율합니다.

**2. AI 에이전트 연동하기**

보안 담당자가 사내에서 운용 중인 AI 에이전트 및 시스템과 본 솔루션을 API 방식으로 연동합니다. 실시간 감시를 위한 기본 보안 정책 규칙을 설정합니다.

**3. 실시간 모니터링 시작**

대시보드 화면에 접속하여 AI 에이전트가 수행하는 작업 흐름을 실시간으로 추적합니다. 이상 징후가 감지되는지 로그 기록을 주기적으로 확인합니다.

**4. 위협 분석 리포트 검토**

주간 및 월간 단위로 제공되는 보안 위협 분석 리포트를 다운로드합니다. 정책 위반 사례와 차단 내역을 검토하여 사내 AI 보안 가이드라인을 보완합니다.

## 가격 정책

- **무료 플랜**: 현재 공식 홈페이지로 데모 신청 및 상담을 지원하고 있습니다.
- **유료 플랜**: 기업용 맞춤형 요금제(Enterprise)로 운영되며, 상세 가격은 기업 규모에 따라 견적을 문의해야 합니다.

비용 절약 팁: 도입 전 데모 버전로 우리 회사의 시스템 환경과 호환되는지 먼저 확인하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 정확한 무료 체험 범위나 기간은 공개되어 있지 않습니다. 다만 공식 홈페이지로 사전 데모 신청 및 맞춤형 상담을 먼저 받아볼 수 있습니다.

- **Enterprise 플랜** (공식 페이지 확인 필요 (기업 규모별 맞춤 견적)): 기업 내 AI 에이전트 실시간 감시, 자동 보안 위협 차단, 상세 분석 리포트 제공 등 맞춤형 기능이 포함됩니다.

- **Custom 솔루션** (공식 페이지 확인 필요): 대규모 인프라 환경에 맞춘 전담 기술 지원 및 사내 보안 시스템 연동 서비스를 제공합니다.

**환불과 해지**: 기업용 맞춤 견적 계약 형태로 진행되므로 환불 및 해지 조건은 별도의 서비스 계약서로 확인해야 합니다.

## 한국어 지원

현재 인터페이스 및 기술 지원은 영어로만 제공됩니다. 한국어 서비스는 아직 지원하지 않습니다.

## 한국어 품질 실측

**보안 정책 설정**

- 프롬프트: Set a security rule to block AI agents from leaking customer phone numbers.
- 결과 예시: The rule has been successfully created. Any outbound message containing customer phone numbers will be automatically blocked by the system.
- 관찰: 영어 인터페이스 기반이므로 명령어 역시 영어로 입력할 때 가장 정확한 결과를 얻을 수 있습니다.

**이상 징후 분석**

- 프롬프트: Analyze the abnormal behavior log from yesterday and summarize potential risks.
- 결과 예시: Yesterday's log shows 3 instances of unauthorized API access attempts by Agent B. All attempts were successfully blocked with zero data leakage.
- 관찰: 전문적인 보안 용어가 포함된 리포트가 생성되며, 한국어 번역 기능은 별도로 지원되지 않습니다.

Tenet Security는 전면 영문 인터페이스로 제공되어 한국어 지원이 되지 않습니다. 기업 보안 담당자가 영문 대시보드와 리포트 해석에 익숙해야 원활한 활용이 가능합니다.

## 이런 분에게 추천합니다

사내 AI 에이전트를 도입하여 운영 중인 IT 기업의 보안 담당자에게 추천합니다. 데이터 유출 방지가 필수적인 금융 및 공공기관의 보안 관리자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 AI 챗봇이 고객 정보를 학습하지 않도록 보안 정책을 적용합니다. 에이전트의 모든 활동 기록을 대시보드로 확인하며 관리합니다.
- **학생**: 해당하지 않습니다. 주로 기업 환경의 보안을 다루는 전문가용 도구입니다.
- **소상공인**: 해당하지 않습니다. 개인 사업자가 사용하기에는 보안 설정 범위가 매우 넓고 전문적입니다.

## 유사 툴과 비교

**장점:**
- AI 에이전트 특화 보안 기능 제공
- 실시간 대응 및 자동화된 보안 정책 적용

**단점:**
- 전문적인 보안 지식이 필요하여 일반 사용자에게는 어려움
- 한국어 지원 부재

**이런 분에게 가장 적합합니다:** AI 에이전트를 활발하게 활용하는 기업의 보안 환경 구축에 가장 적합합니다.

## 장단점

**장점**

- AI 에이전트의 오작동이나 데이터 유출 사고를 실시간으로 예방하여 기업 자산을 안전하게 보호합니다.
- 보안 정책 위반 시 시스템이 즉각적으로 동작을 차단하여 휴먼 에러로 인한 사고를 줄여줍니다.
- 축적된 데이터를 바탕으로 상세한 위협 분석 리포트를 제공하여 체계적인 보안 관리가 가능합니다.
- 기업 맞춤형 솔루션을 지향하여 사내 인프라 환경에 최적화된 보안 체계를 구축할 수 있습니다.

**단점**

- 한국어 인터페이스와 기술 지원을 지원하지 않아 국내 담당자가 사용하기에 진입 장벽이 다소 높습니다.
- 명확한 정가 요금제가 공개되어 있지 않고 기업 규모별 맞춤 견적을 거쳐야 하므로 예산 편성이 번거롭습니다.
- 일반 개인이나 소상공인이 가볍게 쓰기에는 적합하지 않고 대규모 기업 환경에 초점이 맞춰져 있습니다.

## 주의사항

- **개인정보**: AI 에이전트가 처리하는 고객의 민감한 개인정보가 외부로 유출되지 않도록 사전에 철저한 보안 필터링 규칙을 설정해야 합니다.
- **저작권/상업적 이용**: 기업 내부 업무 자동화하려고 도입하는 솔루션이므로, 사내 규정과 라이선스 범위를 준수하여 상업적 목적의 데이터 처리에 활용해야 합니다.
- **요금/한도**: 정확한 비용과 에이전트 연동 한도는 기업별 계약 내용에 따라 달라지므로 도입 전 담당 부서와 명확한 조율이 필요합니다.
- **계정 관리**: 보안 대시보드에 접근할 수 있는 관리자 계정은 권한별로 철저하게 분리하여 무단 접근이나 설정 변경을 방지해야 합니다.

## 자주 묻는 질문

**일반 사용자도 쉽게 사용할 수 있나요?**

아니요, 이 툴은 기업용 보안 솔루션으로 네트워크와 보안에 대한 전문적인 지식이 있는 관리자를 대상으로 설계되었습니다.

**한국어 지원은 언제 되나요?**

현재 공식적인 한국어 지원 계획은 발표되지 않았습니다. 향후 글로벌 확장 전략에 따라 업데이트될 가능성이 있습니다.

**어떤 AI 에이전트를 보호할 수 있나요?**

기업에서 사내망이나 클라우드 환경에 구축한 다양한 AI 에이전트 모델과 연동하여 보안 정책을 적용할 수 있습니다.

**Tenet Security는 어떤 기업에서 도입해야 하나요?**

사내에서 생성형 AI 에이전트나 자동화 봇을 활발하게 운용하며, 데이터 유출 및 보안 위협을 실시간으로 차단하고자 하는 중견·대기업에 적합합니다.

**한국어 안내나 기술 지원을 받을 수 있나요?**

현재 공식 홈페이지 및 모든 서비스가 영어로만 제공되므로 한국어 지원은 불가하며, 영문 응대만 가능합니다.

**기존에 사용 중인 AI 모델과 연동하기 어렵지 않나요?**

API 연동 방식을 지원하여 주요 AI 에이전트 시스템과 결합할 수 있지만, 도입 시 사내 개발 및 보안 팀의 기술 검토가 필수적입니다.

**무료로 먼저 체험해 볼 수 있나요?**

상시 오픈된 무료 가입 플랜은 제공되지 않으며, 공식 웹사이트를 통해 데모 신청을 접수한 후 상담을 거쳐 체험 여부를 결정할 수 있습니다.
