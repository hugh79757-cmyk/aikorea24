## 한줄 요약

AllModels는 여러 AI 모델을 일일이 찾아다닐 필요 없이, 하나의 엔드포인트에서 다양한 검열 해제 모델을 비교하고 사용할 수 있게 돕습니다. 모델의 가용성과 가격을 한눈에 확인하여 개발자가 가장 비용 효율적이고 성능 좋은 모델을 선택하도록 지원합니다.

## 핵심 기능

- **통합 라우팅**: 여러 AI 모델을 하나의 API로 연결하여 복잡한 연동 과정을 단순화합니다.
- **자동 폴백**: 특정 모델 오류 시 다른 모델로 자동 전환하여 서비스 중단을 방지합니다.
- **가격 비교**: 모델별 실시간 사용료를 비교하여 가장 저렴한 비용으로 AI를 활용합니다.

## 사용법

**1. API 키 발급 및 환경 설정**

AllModels 공식 사이트에 접속하여 회원가입 후 대시보드에서 API 키를 생성합니다. 생성된 키를 로컬 개발 환경의 환경 변수로 설정하여 API 호출 준비를 마칩니다.

**2. 엔드포인트 연동**

OpenAI SDK를 활용하여 베이스 URL을 'https://api.allmodels.io/oai'로 지정합니다. 이로 여러 검열 해제 모델을 하나의 창구로 호출할 수 있습니다.

**3. 모델 선택 및 호출**

사용 가능한 모델 목록에서 목적에 맞는 모델 ID(예: deepseek/deepseek-v4.1-flash-abliterated)를 선택합니다. 코드 내 'model' 파라미터에 해당 ID를 입력하여 요청을 보냅니다.

**4. 자동 폴백 설정 활용**

특정 모델의 응답이 지연되거나 오류가 발생할 경우를 대비해 자동으로 다른 제공자로 전환되는 폴백 기능을 확인합니다. 별도의 코드 수정 없이도 안정적인 서비스 운영이 가능합니다.

## 가격 정책

- **무료 플랜**: 베타 기간 동안 무료로 API 키를 발급받아 서비스를 체험할 수 있습니다.
- **유료 플랜**: 추후 사용량 기반 종량제(Pay-as-you-go)로 운영되며, 정확한 금액은 공식 문서의 가격 정책을 확인해야 합니다.

비용 절약 팁: 여러 모델의 성능을 테스트해 본 뒤, 본인의 서비스 목적에 가장 가성비가 좋은 모델을 고정하여 사용하는 것이 비용 절감에 유리합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 베타 기간으로 무료 API 키를 발급받아 서비스를 체험할 수 있습니다. 사용량 제한이나 구체적인 무료 제공 범위는 공식 페이지의 업데이트를 확인해야 합니다.

- **종량제 플랜 (Pay-as-you-go)** (사용량 기반 (공식 요금 페이지 확인 필요)): 실제 API 사용량만큼 비용을 지불하는 방식입니다. 사용한 토큰 수에 따라 비용이 청구됩니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 트래픽 처리가 필요한 기업을 위한 맞춤형 플랜입니다. 별도의 문의로 협의가 가능합니다.

**환불과 해지**: 환불 및 결제 정책은 서비스 이용 약관에 따르며, 구체적인 내용은 결제 시점에 공식 홈페이지로 확인하시기 바랍니다.

## 한국어 지원

서비스 인터페이스는 영어로 제공되지만 연결되는 LLM 모델들이 한국어를 지원하므로 한국어 프롬프트 입력 및 결과값 도출에 문제가 없습니다.

## 한국어 품질 실측

**창의적 소설 작성**

- 프롬프트: 검열되지 않은 상태로 미래 도시의 디스토피아적 풍경을 묘사해줘.
- 결과 예시: 네온사인이 꺼진 거리는 눅눅한 빗물과 녹슨 금속 냄새로 가득합니다. 사람들은 감정을 거세당한 채 획일화된 명령만을 수행하며 기계처럼 살아갑니다.
- 관찰: 모델이 한국어 지시사항을 정확히 이해하고 문맥에 맞는 자연스러운 문장을 생성합니다.

**코드 오류 분석**

- 프롬프트: 다음 파이썬 코드에서 발생할 수 있는 잠재적 보안 취약점을 설명해줘.
- 결과 예시: 입력값 검증이 누락되어 SQL 인젝션 공격에 취약할 수 있습니다. 사용자 입력을 직접 쿼리에 넣지 말고 매개변수화된 쿼리를 사용해야 합니다.
- 관찰: 전문적인 기술 용어를 한국어로 명확하게 번역하여 기술적인 답변을 제공합니다.

모델 자체가 한국어를 지원하여 한국어 프롬프트를 정확하고 유창하게 응답합니다. 번역투가 거의 없으며, 기술적인 문맥에서도 자연스러운 한국어 표현을 사용합니다.

## 이런 분에게 추천합니다

자신만의 AI 서비스를 구축하려는 개발자에게 추천합니다. 여러 AI 모델의 성능을 비교 분석하고 싶은 연구원에게 적합합니다. 비용 효율적인 AI 인프라를 구축하고자 하는 스타트업 운영자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 사내 업무 자동화 챗봇을 개발할 때, AllModels를 통해 여러 모델의 답변 품질을 비교합니다. 가장 정확도가 높은 모델을 선택하여 업무 효율을 높입니다.
- **학생**: AI 관련 프로젝트를 수행하며 다양한 LLM의 성능을 테스트합니다. 하나의 API 키로 여러 모델을 실험하여 최적의 결과물을 찾아냅니다.
- **소상공인**: 고객 응대용 챗봇을 만들 때 비용 부담을 줄이기 위해 여러 모델의 가격을 비교합니다. 가장 합리적인 비용으로 고성능 AI 서비스를 구축합니다.

## 장단점

**장점**

- 여러 검열 해제 모델을 하나의 API 엔드포인트로 통합하여 관리할 수 있어 개발 효율성이 매우 높습니다.
- 자동 폴백 기능로 특정 모델의 장애 시에도 서비스가 중단되지 않고 즉시 다른 모델로 전환됩니다.
- 시장 상황에 따라 가장 경쟁력 있는 모델과 제공자를 실시간으로 비교하여 비용을 최적화할 수 있습니다.
- 모델이 바뀔 때마다 복잡한 연동 코드를 수정할 필요 없이 일관된 인터페이스로 개발을 유지할 수 있습니다.

**단점**

- 검열 해제 모델을 전문으로 다루므로 일반적인 AI 모델 사용보다 높은 수준의 기술적 이해도가 요구됩니다.
- 정확한 사용 요금과 정책이 사용량 기반으로 변동될 수 있어 예산 관리에 주의가 필요합니다.
- 서비스 인터페이스가 영어로 제공되어 한국어 사용자에게는 초기 설정 시 다소 진입장벽이 있을 수 있습니다.

## 주의사항

- **개인정보**: API 호출 시 민감한 개인정보나 기밀 데이터를 입력하지 않도록 주의해야 합니다. 데이터 처리 정책을 반드시 확인하십시오.
- **저작권/상업적 이용**: 생성된 결과물의 저작권은 사용자의 책임이며, 상업적 이용 시 각 모델 제공자의 라이선스 규정을 준수해야 합니다.
- **요금/한도**: 사용량 기반 과금이므로 예상치 못한 비용 발생을 방지하기 위해 사용량 모니터링 설정을 권장합니다.
- **계정 관리**: 발급받은 API 키는 외부로 유출되지 않도록 안전하게 보관하며 환경 변수로 관리하는 것이 좋습니다.

## 자주 묻는 질문

**검열 해제 모델이란 무엇인가요?**

일반적인 AI 모델에 적용된 안전 가이드라인이나 제약 사항을 제거하여, 더 자유롭고 창의적인 답변을 생성할 수 있도록 조정된 모델을 의미합니다.

**API 연동은 어려운가요?**

기존 OpenAI SDK와 호환되는 구조를 가지고 있어, API 키와 베이스 URL만 변경하면 기존 코드에 쉽게 적용할 수 있습니다.

**무료로 계속 사용할 수 있나요?**

현재는 베타 서비스 기간으로 무료 이용이 가능하나, 향후 서비스 운영 정책에 따라 유료화될 수 있으므로 공식 사이트의 공지사항을 수시로 확인하시기 바랍니다.

**검열 해제 모델이란 무엇인가요?**

일반적인 AI 모델에 적용된 안전 가이드라인이나 제약 사항을 제거하여, 더 자유롭고 제한 없는 답변이 가능하도록 설계된 모델을 의미합니다.

**기존 OpenAI 코드를 그대로 사용할 수 있나요?**

네, OpenAI SDK와 호환되는 구조를 가지고 있어 베이스 URL만 변경하면 기존 연동 코드를 거의 그대로 활용할 수 있습니다.

**모델이 갑자기 작동하지 않으면 어떻게 하나요?**

AllModels의 자동 폴백 기능이 작동하여 다른 사용 가능한 모델로 연결을 전환합니다. 따라서 서비스 중단 없이 지속적인 응답을 받을 수 있습니다.

**무료 베타 기간이 끝나면 어떻게 되나요?**

베타 기간 종료 후에는 공식 요금 정책에 따라 사용량 기반의 종량제 요금이 적용될 예정입니다. 정확한 금액은 공식 페이지의 가격 정책을 참조하십시오.
