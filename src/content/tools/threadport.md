## 한줄 요약

ThreadPort는 여러 AI 챗봇을 사용할 때 발생하는 '대화 단절' 문제를 해결합니다. 대화 내용을 복사하고 붙여넣는 번거로움 없이, 클릭 한 번으로 다른 AI 서비스에 기존 대화 맥락을 그대로 유지하며 이동할 수 있습니다.

## 핵심 기능

- **원클릭 이동**: 복사·붙여넣기 없이 버튼 클릭만으로 대화 내용을 다른 AI로 즉시 전송합니다.
- **맥락 유지**: 이전 대화의 흐름과 문맥을 그대로 가져가서 AI가 상황을 바로 파악하게 합니다.
- **개인정보 보호**: 별도의 서버를 거치지 않고 브라우저 내에서만 작동하여 보안 걱정이 없습니다.

## 가격 정책

- **무료 플랜**: 현재 모든 기능을 무료로 사용하는 오픈 소스 기반 확장 프로그램입니다.
- **유료 플랜**: 유료 플랜은 별도로 존재하지 않으며, 현재 완전 무료로 제공됩니다.

비용 절약 팁: 별도의 계정 생성이나 구독이 필요 없으니 브라우저 확장 프로그램 설치 후 바로 사용하십시오.

## 한국어 지원

인터페이스가 매우 단순하여 한국어 환경에서도 언어 장벽 없이 직관적으로 사용할 수 있습니다.

## 이런 분에게 추천합니다

여러 AI 챗봇의 장점을 비교하며 업무를 보시는 분, AI와의 대화 맥락을 끊기지 않고 이어가고 싶은 분에게 추천합니다.

## 실제 활용 예시

- **직장인**: ChatGPT로 작성한 보고서 초안을 Claude로 옮겨 문체 교정을 요청할 때 유용합니다. 맥락이 유지되어 다시 설명할 필요가 없습니다.
- **학생**: Gemini로 자료 조사를 한 뒤, 그 내용을 ChatGPT로 가져와 논문 요약이나 정리 작업을 수행할 때 편리합니다.
- **소상공인**: ChatGPT로 만든 홍보 문구를 Claude로 옮겨 더 감성적인 마케팅 카피로 수정하는 등 다양한 AI의 결과물을 조합할 때 사용합니다.

## 유사 툴과 비교

**장점:**
- 대화 맥락 유지 기능이 탁월함
- 별도 서버를 거치지 않아 보안이 안전함

**단점:**
- 브라우저 확장 프로그램 설치가 필수임

**이런 분에게 가장 적합합니다:** 여러 AI 챗봇을 동시에 활용하며 업무 효율을 극대화하려는 사용자에게 가장 적합합니다.

## 자주 묻는 질문

**개인정보는 안전한가요?**

네, ThreadPort는 서버를 거치지 않고 브라우저 로컬 환경에서만 작동합니다. 따라서 사용자의 대화 내용이 외부로 유출될 위험이 없습니다.

**어떤 브라우저에서 사용할 수 있나요?**

크롬(Chrome)과 엣지(Edge) 브라우저에서 설치하여 사용할 수 있습니다. 해당 브라우저의 웹스토어로 간편하게 추가 가능합니다.

**사용법이 어렵지 않나요?**

매우 간단합니다. AI 페이지에서 대화 중에 확장 프로그램 아이콘을 클릭하고 원하는 목적지 AI를 선택하기만 하면 새 창에서 대화가 이어집니다.
