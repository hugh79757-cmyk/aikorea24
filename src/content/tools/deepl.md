## 한줄 요약

DeepL은 텍스트와 음성을 고품질로 번역하여 다양한 언어로 소통할 수 있게 도와주는 툴입니다. 실시간 번역 기능으로 언어 장벽을 허물 수 있습니다.

## 핵심 기능

- **고급 번역**: 자연스러운 번역 결과를 제공합니다.
- **음성 번역**: 실시간 대화에서 언어를 번역해 줍니다.
- **API 연동**: 자사 시스템에 번역 기능을 쉽게 통합할 수 있습니다.

## 사용법

**1. 텍스트 및 문서 번역하기**

웹사이트 메인 화면의 번역 창에 텍스트를 입력하거나 '파일 번역' 탭을 눌러 문서를 업로드합니다. 드래그 앤 드롭 방식으로 PDF나 워드 파일을 올리면 레이아웃을 유지하며 즉시 번역됩니다.

**2. 실시간 음성 번역 활용**

DeepL Voice 기능을 선택하여 마이크를 켭니다. 실시간으로 대화 내용을 상대방 언어로 번역하여 화면에 텍스트로 보여주거나 음성으로 출력할 수 있습니다.

**3. DeepL Write로 문장 교정**

작성한 외국어 문장이 어색하다면 DeepL Write 기능을 활용합니다. 문법 오류를 수정하고 문맥에 맞게 더 자연스러운 표현으로 다듬어 줍니다.

**4. 브라우저 확장 프로그램 설치**

크롬 등 브라우저 확장 프로그램을 설치하면 웹 서핑 중 마우스 드래그만으로 즉시 번역이 가능합니다. 별도의 창을 띄우지 않아도 되어 업무 효율이 크게 향상됩니다.

## 자주 묻는 질문

**DeepL은 무료로 사용할 수 있나요?**

DeepL은 기본적인 번역 기능을 무료로 제공합니다. 하지만 프리미엄 플랜로 더 많은 기능을 이용할 수 있습니다.

**DeepL의 번역 품질은 어떤가요?**

DeepL은 고급 AI 기술을 사용하여 번역 품질이 뛰어나며, 자연스러운 문장을 생성합니다.

**음성 번역 기능은 어떻게 사용하나요?**

DeepL의 음성 번역 기능을 사용하면 실시간으로 대화 중에 언어를 번역할 수 있어 매우 편리합니다.

**DeepL Pro는 무료 버전과 무엇이 다른가요?**

Pro 버전은 데이터 보안이 강화되며, 번역 글자 수 제한이 없고 문서 번역 시 파일 용량 제한이 훨씬 큽니다. API 사용이 가능하여 업무 자동화 연동도 지원합니다.

**번역한 문서의 레이아웃이 깨지나요?**

DeepL은 문서의 서식과 레이아웃을 최대한 유지하도록 설계되었습니다. 다만 복잡한 표나 특수 서식은 드물게 조정이 필요할 수 있습니다.

**오프라인에서도 번역할 수 있나요?**

DeepL은 인터넷 연결이 필요한 클라우드 기반 서비스입니다. 오프라인 상태에서는 번역 기능을 사용할 수 없으니 인터넷 환경을 확인해 주세요.

**기업용 보안은 어떻게 보장되나요?**

유료 비즈니스 플랜 사용 시 번역된 데이터는 학습에 사용되지 않으며, 높은 수준의 암호화 기술을 통해 정보 보호를 지원합니다.
