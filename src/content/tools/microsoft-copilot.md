## 한줄 요약

마이크로소프트 코파일럿은 워드·엑셀·파워포인트·아웃룩·팀즈 등 이미 쓰는 오피스 앱 안에 탑재된 AI 비서입니다. 별도 툴을 익힐 필요 없이 익숙한 화면에서 글쓰기, 데이터 분석, 프레젠테이션 제작, 메일 초안, 회의 요약까지 한 번에 해결할 수 있습니다.

## 핵심 기능

- **앱 내장 AI**: 워드·엑셀·PPT·아웃룩·팀즈 안에서 바로 호출돼 컨텍스트 전환 없이 작업 가능
- **데이터 기반 답변**: 내 문서·메일·캘린더·스프레드시트를 참조해 환각 없는 업무 결과물 생성
- **코파일럿 스튜디오**: 코딩 없이 사내 챗봇·자동화 에이전트를 만들어 반복 업무 완전 자동화

## 사용법

**1. 마이크로소프트 계정 로그인**

웹 브라우저에서 코파일럿 공식 사이트에 접속하여 마이크로소프트 계정으로 로그인합니다. 로그인 후 상단의 채팅창로 즉시 대화를 시작할 수 있습니다.

**2. 오피스 앱 내 코파일럿 호출**

워드나 엑셀 등 오피스 앱을 실행한 뒤 상단 리본 메뉴에 있는 코파일럿 아이콘을 클릭합니다. 나타나는 사이드바 입력창에 작성하고 싶은 문서나 분석할 데이터를 요청합니다.

**3. 업무 데이터 참조 요청**

채팅창에 '@' 기호를 입력하여 특정 파일이나 이메일을 선택해 불러옵니다. 이로 코파일럿이 내 업무 문서를 기반으로 정확한 답변을 생성하도록 합니다.

**4. 자동화 에이전트 생성**

코파일럿 스튜디오 기능을 활용해 반복적인 업무를 처리할 에이전트를 만듭니다. 코딩 없이 자연어로 원하는 동작을 설명하면 자동화된 워크플로우가 구축됩니다.

## 가격 정책

- **무료 플랜**: 윈도우·웹·모바일에서 기본 코파일럿(구 빙 챗) 무료 이용 가능
- **유료 플랜**: Copilot Pro 월 29,000원(개인) / Microsoft 365 Copilot 월 44,500원(기업, 연간 약정) — 오피스 앱 완전 통합·엔터프라이즈 보안·우선 모델 접근 포함

비용 절약 팁: 기업은 Microsoft 365 E3/E5 라이선스 보유 시 추가 비용만 내면 되니 기존 구독 확인 필수

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 웹 버전과 윈도우 앱에서 기본 AI 채팅 기능을 무료로 이용할 수 있습니다. 다만 오피스 앱 내 통합 기능이나 고급 모델 접근 권한은 제한됩니다.

- **Copilot Pro** (월 29,000원): 개인 사용자를 위한 플랜으로 워드, 엑셀, 파워포인트 등 오피스 앱에서 AI 기능을 우선적으로 사용할 수 있습니다.

- **Microsoft 365 Copilot** (월 44,500원(기업용)): 기업 보안 환경에 최적화된 플랜이며 연간 약정 기준으로 제공됩니다. 조직 내 데이터 보안과 팀 단위 협업 기능을 지원합니다.

**환불과 해지**: 구독 취소 및 환불 정책은 마이크로소프트 공식 계정 관리 페이지에서 확인 가능합니다. 결제 주기와 해지 시점에 따라 환불 금액이 달라질 수 있습니다.

## 한국어 지원

한국어 UI·입력·출력 모두 네이티브 수준으로 지원하며 한글 맞춤법·비즈니스 용어·존댓말 톤까지 자연스럽게 처리합니다.

## 한국어 품질 실측

**회의록 요약 요청**

- 프롬프트: 지난주 팀 회의 내용을 보고 주요 결정 사항과 다음 주 과제를 한국어로 정리해줘.
- 결과 예시: 지난주 회의의 핵심 결정 사항은 신규 프로젝트 마케팅 예산 승인입니다. 다음 주까지 담당자별로 세부 실행 계획안을 작성하여 공유하기로 결정되었습니다.
- 관찰: 한국어 문장 구조가 자연스럽고 비즈니스 문체로 정확하게 요약됩니다.

**이메일 초안 작성**

- 프롬프트: 거래처에 보낼 프로젝트 지연 사과 메일을 정중한 한국어 비즈니스 어투로 작성해줘.
- 결과 예시: 귀사의 무궁한 발전을 기원합니다. 예정되었던 프로젝트 일정이 내부 사정으로 인해 부득이하게 지연되었습니다. 너른 양해 부탁드리며 보완된 일정을 즉시 공유하겠습니다.
- 관찰: 한국의 비즈니스 예절에 맞는 적절한 경어체 표현을 매우 잘 구사합니다.

한국어 처리 능력이 매우 뛰어나며 자연스러운 비즈니스 문장을 생성합니다. 전문 용어나 한국식 업무 표현도 문맥에 맞게 정확히 반영합니다.

## 이런 분에게 추천합니다

매일 오피스 365로 문서·메일·회의하는 직장인에게 가장 적합합니다. 엑셀 함수·피벗·차트를 몰라도 데이터 인사이트가 필요한 기획·영업 담당자에게 추천합니다. 소규모 팀에서 별도 개발자 없이 챗봇·자동화 워크플로를 만들고 싶은 운영자에게 유리합니다.

## 실제 활용 예시

- **직장인**: 아침에 아웃룩을 열면 코파일럿이 밤새 온 메일 30통을 3줄 요약해주고, 답장 초안까지 띄워줍니다. 엑셀 원시 데이터를 붙여넣고 '분기별 매출 트렌드 차트 그려줘' 한 마디면 1분 만에 발표용 차트가 완성됩니다.
- **학생**: 워드에서 논문 초안을 쓰다가 '참고문헌 APA 스타일로 정리해줘'라고 하면 인용문 형식이 자동 교정됩니다. 팀즈 조별 과제 녹음 파일을 올리면 '할 일 리스트만 뽑아줘' 명령으로 액션 아이템이 바로 나옵니다.
- **소상공인**: 파워포인트에서 '신메뉴 출시 제안서 10장 만들어줘' 하면 목차·디자인·문구까지 초안이 생성돼 30분 만에 PT 완성이 가능합니다. 아웃룩으로 온 고객 문의 메일에 '친절하게 답장 초안 써줘' 하면 바로 보낼 수 있는 답장이 나옵니다.

## 장단점

**장점**

- 기존에 사용하는 워드와 엑셀 등 익숙한 오피스 프로그램 안에서 바로 AI를 호출해 작업 효율을 극대화할 수 있습니다.
- 내 컴퓨터에 저장된 문서나 이메일 내용을 AI가 직접 참조하여 개인화된 답변을 제공하므로 정보의 정확도가 매우 높습니다.
- 코딩 지식이 없어도 자연어로 복잡한 데이터 분석이나 자동화 에이전트를 손쉽게 생성할 수 있는 편리함을 제공합니다.
- 기업용 보안 기준을 충족하고 있어 민감한 업무 데이터를 다룰 때도 안심하고 사용하는 보안 체계를 갖췄습니다.

**단점**

- 오피스 앱 내의 모든 기능을 원활하게 사용하려면 유료 구독이 필수적이라 개인 사용자에게는 다소 가격 부담이 있을 수 있습니다.
- 방대한 데이터를 처리할 때 간혹 답변 속도가 느려지거나 복잡한 요청의 경우 처리 과정에서 시간이 소요될 수 있습니다.
- AI가 생성한 결과물은 항상 검증이 필요하며 특히 중요한 문서 작성 시에는 사실 관계를 직접 확인하는 과정이 반드시 수반되어야 합니다.

## 주의사항

- **개인정보**: 업무용 데이터가 학습에 사용되지 않도록 기업용 플랜의 보안 설정을 반드시 확인하십시오.
- **저작권/상업적 이용**: AI가 생성한 콘텐츠의 저작권은 서비스 약관에 따라 달라질 수 있으므로 상업적 활용 전 약관을 검토하십시오.
- **요금/한도**: 구독 플랜별로 사용 가능한 기능과 메시지 한도가 다르므로 본인의 업무량에 맞는 플랜을 선택하십시오.
- **계정 관리**: 개인 계정과 회사 계정을 혼용할 경우 데이터 접근 권한이 달라질 수 있으므로 계정 분리에 주의하십시오.

## 자주 묻는 질문

**무료 버전과 유료 버전 차이는 무엇인가요?**

무료 코파일럿(웹·윈도우·모바일)은 일반 웹 검색·글쓰기·이미지 생성만 가능하고 오피스 앱(워드·엑셀·팀즈 등) 안에서는 작동하지 않습니다. 유료 Copilot Pro(개인) 또는 Microsoft 365 Copilot(기업)을 구독해야 앱 내 사이드바·리본 메뉴·컨텍스트 인식 기능이 열립니다.

**한글 문서(.hwp)도 읽고 쓸 수 있나요?**

직접 .hwp 파일을 열지는 못하지만 한컴오피스나 폴라리스 오피스에서 복사·붙여넣기 또는 PDF로 변환 후 업로드하면 내용을 읽고 요약·편집할 수 있습니다. 워드 온라인에 붙여넣으면 실시간 공동 편집도 가능합니다.

**사내 기밀 데이터가 외부로 유출되지 않나요?**

Microsoft 365 Copilot(기업용)은 테넌트 경계 안에서만 데이터를 처리하며 프롬프트·응답·임베딩이 모델 학습에 사용되지 않습니다. EU 데이터 경계·ISO 27001·SOC 2 등 인증을 충족해 금융·공공기관도 도입 중입니다.

**기존에 쓰던 오피스 앱에서 바로 사용할 수 있나요?**

네, 구독 플랜을 활성화하면 워드, 엑셀, 파워포인트 등 앱 내부에 코파일럿 버튼이 자동으로 생성되어 바로 사용할 수 있습니다.

**무료 버전과 유료 버전의 가장 큰 차이는 무엇인가요?**

무료 버전은 웹 기반 채팅 위주이며, 유료 버전은 오피스 앱과의 직접적인 연동과 더 높은 수준의 보안 및 우선적인 AI 모델 접근 권한을 제공합니다.

**기업에서 사용하면 보안 문제는 없나요?**

기업용 플랜은 마이크로소프트의 엔터프라이즈급 보안 정책을 따르며, 사용자의 데이터가 외부로 유출되지 않도록 설계되어 있습니다.

**한국어 지원은 완벽한가요?**

네, 한국어 UI와 프롬프트 이해도가 매우 높으며 한국 비즈니스 환경에 적합한 답변을 생성하는 데 최적화되어 있습니다.
