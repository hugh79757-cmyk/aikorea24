## 한줄 요약

FutureMail은 개인이 소유한 도메인으로 이메일 주소를 무제한 생성하고 AI 에이전트까지 연동할 수 있는 새로운 이메일 호스팅 서비스입니다. 복잡한 설정 없이 개발자와 AI가 이메일을 쉽게 주고받을 수 있도록 REST API와 단축키 중심의 빠른 수신함을 제공합니다.

## 핵심 기능

- **무제한 주소**: 내 도메인으로 원하는 만큼 이메일 주소를 자유롭게 생성합니다.
- **AI 에이전트 연동**: AI 비서가 이메일을 직접 읽고 인증 코드를 확인할 수 있습니다.
- **보안 설정**: DKIM, SPF, DMARC 등의 보안 설정을 간편하게 완료합니다.

## 사용법

**1. 도메인 연결 및 구독**

FutureMail 계정을 생성하고 월 20달러 프로 플랜을 구독합니다. 설정 페이지에서 보유한 도메인을 등록하고 안내되는 DNS 레코드를 도메인 관리 사이트에 입력하여 연결을 완료합니다.

**2. 이메일 주소 생성**

대시보드에서 원하는 이메일 접두사(예: support@, hello@)를 입력하여 필요한 만큼 무제한으로 주소를 생성합니다. 'catch-all' 기능을 활성화하면 도메인으로 들어오는 모든 메일을 수신할 수 있습니다.

**3. AI 에이전트 연동 설정**

에이전트 전용 수신함을 만들고 해당 주소에 대한 API 키를 발급받습니다. REST API나 CLI를 통해 에이전트가 메일을 읽고 인증 코드를 자동으로 추출하도록 프로그래밍합니다.

**4. 수신함 관리 및 활용**

키보드 중심의 빠른 인터페이스로 메일을 확인하고 관리합니다. 필요 시 웹훅이나 자동화 스크립트를 연결하여 메일 수신 시 특정 작업이 실행되도록 설정합니다.

## 가격 정책

- **무료 플랜**: 별도의 무료 플랜은 제공되지 않으며 체험 기간을 확인할 수 있습니다.
- **유료 플랜**: 프로 플랜 월 20달러(약 2만 7천 원)로 인원 추가 비용 없이 무제한 주소와 API를 제공합니다.

비용 절약 팁: 여러 명의 팀원이나 다수의 AI 에이전트를 활용하는 개발자나 기업에게 인원별 추가 요금이 없어 경제적입니다.

## 요금제 자세히

- **Pro Plan** (월 20달러 (약 2만 7천 원 내외)): 무제한 도메인과 이메일 주소, 에이전트 전용 수신함 및 API 접근 권한을 제공합니다. 월 5만 건의 수신자 발송 한도가 포함되어 있습니다.

**환불과 해지**: 결제는 월 단위로 진행되며, 빌링 포털로 언제든지 구독을 취소할 수 있습니다. 환불 정책은 결제 시점의 서비스 이용 약관을 확인해야 합니다.

## 한국어 지원

서비스 인터페이스와 문서는 영어로 제공되며, 한글 이메일 송수신 자체는 문제가 없으나 설정 과정에 영어 이해가 필요합니다.

## 한국어 품질 실측

**고객 문의 자동 응답**

- 프롬프트: 수신된 고객 문의 메일을 읽고 내용을 요약하여 슬랙으로 전달해줘.
- 결과 예시: AI 에이전트가 메일 본문을 분석하여 '고객 A님이 결제 오류를 문의했습니다'와 같이 요약된 텍스트를 반환합니다.
- 관찰: 서비스 인터페이스는 영어지만 AI 에이전트가 한국어 메일 내용을 처리하는 데는 큰 무리가 없습니다.

**인증 코드 추출**

- 프롬프트: 가입 인증 메일에서 6자리 숫자 코드를 추출해줘.
- 결과 예시: 에이전트가 메일 본문에서 '인증번호는 482913입니다'를 찾아내어 숫자값만 추출하여 반환합니다.
- 관찰: 숫자 기반의 데이터 추출은 언어와 관계없이 매우 정확하게 작동합니다.

서비스 인터페이스와 설정 문서가 모두 영어로 되어 있어 초기 설정 시 언어 장벽이 있을 수 있습니다. 다만, 실제 이메일 본문인 한국어 내용을 AI가 처리하는 데는 기술적인 제약이 거의 없습니다.

- **학생**: 개인 포트폴리오 사이트용 맞춤형 도메인 이메일을 만들어 전문적인 인상을 줍니다.
- **소상공인**: 고객 문의용 주소와 주문 안내용 주소를 각각 만들어 체계적으로 고객 응대를 관리합니다.

## 장단점

**장점**

- 인원수 제한 없는 요금 체계로 팀원이나 다수의 AI 에이전트를 추가 비용 없이 자유롭게 활용할 수 있습니다.
- 무제한 도메인과 이메일 주소 생성을 지원하여 프로젝트별로 세분화된 업무 환경을 구축하는 데 매우 유리합니다.
- 개발자 친화적인 REST API와 CLI, MCP 서버를 제공하여 자동화된 이메일 워크플로우를 쉽게 구현할 수 있습니다.
- DKIM, SPF, DMARC 등 복잡한 이메일 보안 설정을 가이드에 따라 간편하게 적용할 수 있어 안정적인 메일 발송이 가능합니다.

**단점**

- 서비스 내 모든 메뉴와 설정 가이드가 영어로 제공되어 한국어 사용자에게는 초기 진입 장벽이 다소 높을 수 있습니다.
- 별도의 무료 플랜이 존재하지 않아 서비스의 기능을 미리 충분히 테스트해 보기에는 경제적 부담이 발생할 수 있습니다.
- 일반적인 이메일 서비스와 달리 개발 지식과 API 연동 능력이 요구되어 일반 사용자가 단독으로 활용하기에는 난이도가 높습니다.

- **요금/한도**: 월 5만 건의 수신자 발송 한도가 존재하며 이를 초과할 경우 추가 비용이나 제한 사항이 발생할 수 있으므로 상세 요금 정책을 확인하십시오.
- **계정 관리**: API 키가 유출되면 외부에서 내 메일을 읽거나 발송할 수 있으므로, 키 관리를 철저히 하고 주기적으로 갱신하는 것을 권장합니다.

## 자주 묻는 질문

**기존에 가지고 있는 도메인을 사용할 수 있나요?**

네, 이미 소유하고 있는 도메인을 연결하여 사용할 수 있으며 안내에 따라 DNS 설정만 완료하면 즉시 사용 가능합니다.

**AI 에이전트는 어떻게 이메일을 읽나요?**

제공되는 REST API, CLI, 또는 MCP 서버로 AI 에이전트가 이메일을 송수신하고 인증번호까지 확인할 수 있습니다.

**이메일 주소 개수에 제한이 있나요?**

주소 개수에 제한이 없으므로 필요에 따라 무제한으로 생성하여 사용할 수 있습니다.

**기존에 사용하던 도메인을 그대로 쓸 수 있나요?**

네, 본인이 이미 소유하고 있는 도메인을 연결하여 사용할 수 있습니다. DNS 레코드 설정만 완료하면 즉시 메일 서비스를 이용할 수 있습니다.

**인원 추가 시 요금이 더 발생하나요?**

아니요, 인원당 과금(Per-seat pricing)이 없으므로 팀원이나 에이전트를 추가해도 월 20달러의 고정 비용으로 이용 가능합니다.

**AI 에이전트가 메일을 읽는 과정이 안전한가요?**

에이전트별로 별도의 API 키를 발급하여 접근 범위를 제한할 수 있습니다. 특정 수신함에만 접근하도록 설정하면 보안 위험을 최소화할 수 있습니다.

**이메일 수신만 가능한가요?**

아니요, 메일 수신뿐만 아니라 API와 CLI를 통해 메일을 발송하고, 읽고, 검색하는 모든 기능을 자동화할 수 있습니다.
