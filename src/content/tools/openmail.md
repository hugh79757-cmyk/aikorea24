## 한줄 요약

OpenMail은 인공지능 에이전트가 이메일을 직접 읽고 보낼 수 있도록 고유한 이메일 정체성을 부여해주는 서비스입니다. 개발자나 기업 사용자가 AI와 이메일 시스템을 쉽게 연동하여 고객 소통 및 업무 자동화를 구현하는 데 도움이 되습니다.

## 핵심 기능

- **이메일 부여**: AI 에이전트 전용 이메일 주소를 간편하게 생성합니다.
- **자동 송수신**: 들어오는 메일을 AI가 실시간으로 읽고 답장합니다.
- **API 연동**: 다양한 AI 모델과 이메일 시스템을 쉽게 연결합니다.

## 사용법

**1. 회원가입 및 계정 생성**

OpenMail 공식 웹사이트에 접속하여 이메일 주소로 회원가입을 진행합니다. 로그인 후 대시보드 화면에서 AI 에이전트 관리를 위한 기본 설정을 시작할 수 있습니다.

**2. AI 에이전트 이메일 생성**

대시보드 내 생성 메뉴에서 AI 에이전트 전용 고유 이메일 주소를 발급받습니다. 원하는 사용자 아이디를 입력하여 고유한 이메일 계정을 확보합니다.

**3. AI 모델 및 API 연동**

사용 중인 AI 챗봇이나 자동화 시스템과 OpenMail을 연결하기 위한 API 키를 발급받습니다. 설정 메뉴에서 웹훅 주소와 API 엔드포인트를 지정하여 실시간 연동을 완료합니다.

**4. 자동 응답 테스트 진행**

생성된 AI 에이전트 이메일 주소로 테스트 메일을 발송하여 정상적으로 수신되는지 확인합니다. AI가 메일 내용을 읽고 자동으로 올바른 답장을 보내는지 결과 화면에서 검증합니다.

## 자주 묻는 질문

**일반 지메일(Gmail) 계정과 무엇이 다른가요?**

일반 지메일은 사람이 사용하는 개인용 계정이지만 OpenMail은 인공지능 에이전트가 프로그램적으로 메일을 읽고 자동으로 답장할 수 있도록 최적화된 API 기반의 이메일 환경을 제공합니다.

**코딩을 전혀 몰라도 사용할 수 있나요?**

기본적인 API 연동이나 에이전트 설정 과정이 필요하므로, 완전한 초보자보다는 개발 지식이 조금 있거나 AI 툴을 다뤄본 분에게 더 적합합니다.

**한국어 이메일도 문제없이 처리되나요?**

네, 연동하는 AI 모델의 성능에 따라 자연스러운 한국어 이메일 작성 및 독해가 가능합니다.

**기존에 사용하던 개인이나 회사 이메일 주소를 그대로 AI 에이전트에 연동할 수 있나요?**

OpenMail은 AI 에이전트 전용의 고유한 이메일 주소를 새로 생성하여 부여하는 방식에 특화되어 있습니다. 기존 이메일 주소의 직접 연동 가능 여부는 공식 지원 문서를 통해 별도로 확인이 필요합니다.

**AI 에이전트가 보낸 이메일 답장이 잘못되었을 경우 사람이 직접 개입하여 수정할 수 있나요?**

대시보드를 통해 AI가 작성한 응답 초안을 사전에 검토하거나 수동으로 수정할 수 있는 기능을 지원합니다. 자동 발송 모드와 수동 승인 모드를 목적에 맞게 설정하여 오발송을 방지할 수 있습니다.

**프로 플랜 월 15,000원 외에 추가로 결제해야 하는 비용이 발생할 수 있나요?**

기본적인 프로 플랜 비용 외에 연동하여 사용하는 외부 AI 모델의 API 사용량에 따라 추가 비용이 발생할 수 있습니다. 정확한 비용 산정 기준은 공식 요금 안내 페이지를 참고하시기 바랍니다.

**한국어 고객 문의 이메일을 처리할 때 AI가 어색한 번역투로 답변을 보낼까 봐 걱정입니다.**

최신 언어 모델을 기반으로 연동되기 때문에 비즈니스 환경에 알맞은 자연스러운 한국어 문장 구사가 가능합니다. 다만 프롬프트 설정에서 구체적인 어조와 격식을 지정해주면 훨씬 완성도 높은 한국어 답변을 얻을 수 있습니다.
