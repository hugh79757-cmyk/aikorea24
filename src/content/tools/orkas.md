Orkas는 오픈소스, 로컬 우선 데스크톱 AI 워크스페이스입니다. 사용자는 하나의 대화에서 목표를 설명하고, Commander가 조사, 코딩, 데이터 분석, 문서 작성 등 전문 에이전트를 조율합니다. 앱의 핵심 기능은 무료이며, 선택한 모델 서비스 이용에는 비용이 발생할 수 있습니다.

## 한줄 요약

Orkas는 다양한 전문 AI 에이전트를 채팅으로 조율하여 복잡한 업무를 자동화하는 데스크톱 도구입니다. 리서치부터 디자인, 코딩까지 여러 도구를 오갈 필요 없이 하나의 작업 환경에서 효율적으로 프로젝트를 완수할 수 있습니다.

## 핵심 기능

- **멀티 에이전트**: 기획, 디자인, 코딩 등 각 분야 전문가 AI가 협업하여 결과물을 만듭니다.
- **데스크톱 환경**: 웹 브라우저를 벗어나 내 컴퓨터에서 직접 파일을 처리하여 보안성이 높습니다.
- **오픈소스 기반**: 무료로 시작할 수 있고 투명하게 운영되어 누구나 안심하고 사용할 수 있습니다.

## 사용법

**1. 프로그램 설치 및 실행**

공식 홈페이지에서 macOS 또는 Windows용 설치 파일을 내려받아 실행합니다. 설치가 완료되면 프로그램을 열어 초기 계정 설정을 진행합니다.

**2. AI 에이전트 호출**

메인 대화창(Commander)에 수행할 업무를 입력합니다. 사용자의 명령에 따라 조사, 코딩, 문서 작성 등 적합한 전문 에이전트가 자동으로 호출됩니다.

**3. 작업 지시 및 조율**

대화창로 에이전트에게 구체적인 요구사항을 전달합니다. 여러 에이전트가 협업하는 경우, Commander를 통해 전체적인 작업 흐름을 제어할 수 있습니다.

**4. 결과물 확인 및 수정**

생성된 문서, 코드, 이미지 등 결과물을 확인합니다. 추가 수정이 필요하면 대화창에 피드백을 입력하여 내용을 보완합니다.

## 한국어 품질 실측

- 결과 예시: 한국 1인 가구의 간편식 선호도가 증가하고 있으며, 건강과 영양을 고려한 프리미엄 밀키트가 주목받고 있습니다. 관련 데이터를 바탕으로 시장 규모와 주요 타겟층을 정리한 보고서 초안입니다.
- 관찰: 한국어 입력은 가능하나, 내부 처리 과정에서 영어 기반 모델이 작동할 경우 결과물의 어색함이 발생할 수 있습니다.

- 결과 예시: pandas 라이브러리를 사용하여 엑셀 파일을 불러오고 평균을 계산하는 코드 예시입니다. 아래 코드를 복사하여 실행하시면 됩니다.
- 관찰: 기술적인 코드 생성은 매우 정확하게 수행하나, 한국어 설명 부분에 번역투가 섞일 가능성이 있습니다.

도구 자체가 한국어를 공식 지원하지 않으므로, 영어 프롬프트를 사용하는 것이 훨씬 효율적입니다. 한국어 입력 시 결과물은 도출되지만 문법이나 자연스러움 면에서 다소 부족할 수 있습니다.

## 자주 묻는 질문

**컴퓨터 사양을 많이 타나요?**

로컬에서 구동되는 특성상 고사양의 작업을 처리할 때는 메모리 점유율이 올라갈 수 있습니다. 일반적인 문서 작업이나 리서치 용도라면 일반 사무용 PC로도 충분합니다.

**데이터 보안은 안전한가요?**

Orkas는 로컬 우선(Local-first) 방식을 지향하여 사용자의 작업 내용이 외부 서버로 전송되는 것을 최소화합니다. 민감한 기획안이나 내부 자료를 다룰 때 훨씬 안심할 수 있습니다.

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 채팅으로 지시하는 방식이라 코딩 지식이 없어도 충분히 사용 가능합니다. 다만, 에이전트에게 더 정확한 결과물을 얻으려면 구체적으로 상황을 설명하는 프롬프트 작성 능력이 중요합니다.

**오프라인에서도 사용할 수 있나요?**

로컬 우선 도구이므로 로컬 모델을 설정하면 인터넷 연결 없이도 기본적인 AI 작업을 수행할 수 있습니다. 다만, 외부 모델 API를 연동할 때는 인터넷 연결이 필요합니다.

**제공되는 500 크레딧은 어떻게 사용하나요?**

설치 후 계정을 생성하면 자동으로 지급되며, 프로그램 내에서 공식 제공되는 클라우드 모델을 사용할 때 차감됩니다. 크레딧 소진 후에는 추가 구매가 필요할 수 있습니다.

**어떤 운영체제를 지원하나요?**

현재 macOS(Apple Silicon 및 Intel 칩셋)와 Windows 환경을 모두 지원합니다. 설치 시 본인의 기기 사양에 맞는 버전을 선택하여 다운로드하십시오.

**직접 만든 모델을 연결할 수 있나요?**

네, 사용자가 선호하는 모델 제공자를 직접 연결하거나 로컬 모델을 설정하여 사용할 수 있습니다. 기술적인 연동 방법은 공식 API 문서를 참고하시기 바랍니다.
