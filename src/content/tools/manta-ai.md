## 한줄 요약

Manta AI는 웹 애플리케이션을 실제 사용자처럼 탐색하여 문제를 자동으로 감지하는 도구입니다. 이로 개발자들은 더욱 효율적으로 웹사이트의 품질을 관리할 수 있습니다.

## 핵심 기능

- **실시간 분석**: 즉각적으로 웹 애플리케이션의 동작을 분석합니다.
- **자동 버그 탐지**: 사용자가 경험하는 오류를 자동으로 찾아냅니다.
- **사용자 흐름 시각화**: 사용자의 행동을 시각적으로 분석하여 개선점을 제공합니다.

## 사용법

**1. 웹사이트 주소 입력하기**

Manta AI 공식 웹사이트에 접속한 뒤, 테스트를 진행할 웹 애플리케이션의 URL 주소를 입력합니다. 별도의 테스트 스크립트 작성이나 복잡한 설정 없이 주소만 넣으면 바로 시작할 수 있습니다.

**2. 자율 탐색 및 맵핑 확인하기**

도구가 실제 사용자처럼 웹페이지를 자동으로 탐색하며 화면의 모든 경로와 구성 요소를 실시간으로 분석합니다. 로그인, 대시보드, 설정 등 앱의 전체 구조가 자동으로 지도처럼 그려집니다.

**3. 사용자 여정 정의하기**

회원가입부터 이메일 인증, 대시보드 진입까지 중요하게 점검해야 할 사용자 흐름을 한 문장으로 간단히 설명합니다. 정해진 스케줄이나 CI/CD 파이프라인과 연동하여 정기적으로 실행할 수 있습니다.

**4. 오류 보고서 및 분석하기**

버그, 깨진 흐름, 작동하지 않는 클릭 등이 발견되면 스크린샷과 재현 경로가 포함된 상세한 버그 리포트가 제공됩니다. 개발자는 사용자가 문제를 겪기 전에 미리 원인을 파악하고 수정할 수 있습니다.

## 한국어 지원

## 한국어 품질 실측

**회원가입 흐름 점검**

- 프롬프트: 신규 사용자가 회원가입 후 이메일 인증을 거쳐 대시보드에 정상적으로 도달하는지 확인해 줘.
- 결과 예시: 입력하신 여정을 보고 로그인 페이지부터 대시보드까지의 이동 경로를 시뮬레이션한 결과, 인증 버튼 클릭 후 대시보드 로딩 단계에서 지연이 발생하는 것을 확인했습니다. 관련 화면 캡처와 재현 단계를 보고서로 제공합니다.
- 관찰: 사용자 흐름을 자연스럽게 이해하고 한국어 프롬프트에 따른 테스트 경로를 잘 설정합니다.

**결제 페이지 오류 탐지**

- 프롬프트: 쇼핑몰 결제 화면에서 상품을 장바구니에 담고 결제하기 버튼을 눌렀을 때 오류가 발생하는지 점검해 줘.
- 결과 예시: 장바구니 담기부터 결제 모듈 호출까지의 UI 요소를 자율 탐색한 결과, 결제 버튼 클릭 시 응답 없는 링크 구간을 발견했습니다. 해당 깨진 흐름에 대한 스크린샷과 트레이스 정보를 제공합니다.
- 관찰: 웹 애플리케이션의 특정 기능 점검 요청을 정확하게 수행하고 결과물 형태를 잘 갖추어 줍니다.

Manta AI는 직관적인 URL 입력 방식과 자연어 기반 여정 설정 기능을 지원하여 한국 사용자도 쉽게 접근할 수 있습니다. 다만, 서비스 인터페이스나 상세 리포트의 일부 전문 용어는 국내 개발 환경에 맞춰 해석이 필요할 수 있습니다.

## 장단점

**장점**

- 복잡한 테스트 스크립트나 셀렉터를 직접 작성하고 유지보수할 필요가 없어 업무 효율이 크게 향상됩니다.
- 웹 애플리케이션 주소만 입력하면 실제 사용자처럼 스스로 탐색하여 전체 구조를 자동으로 맵핑해 줍니다.
- UI 구조나 DOM이 변경되어도 동작 기반으로 테스트를 추적하므로 기존 테스트가 쉽게 깨지지 않습니다.
- 사용자가 오류를 발견하기 전에 버그와 깨진 흐름을 스크린샷과 함께 미리 감지하여 빠르게 수정할 수 있습니다.

**단점**

- AI가 스스로 웹페이지를 탐색하는 과정에서 예상치 못한 복잡한 사용자 인터랙션은 추가 설정이 필요할 수 있습니다.
- 실시간 웹 애플리케이션 분석의 깊이와 실행 횟수에 따라 무료 플랜만으로는 대규모 프로젝트에 한계가 있을 수 있습니다.
- 정확한 유료 플랜의 기능 제한과 가격 정책에 대한 상세 정보는 공식 페이지를 직접 대조해 보아야 합니다.

- **개인정보**: 스테이징 환경이나 개발용 URL이 아닌 실제 운영(Production) 환경을 테스트할 때는 민감한 사용자 개인정보나 결제 데이터가 노출되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: Manta AI를 통해 생성된 테스트 결과물과 버그 리포트 데이터는 기업 내부의 품질 관리 및 웹사이트 성능 개선 목적으로 안전하게 활용할 수 있습니다.
- **요금/한도**: 무료 플랜과 월 9,900원 플랜의 구체적인 테스트 실행 횟수나 크레딧 한도는 정책에 따라 달라질 수 있으므로 결제 전 반드시 요금표를 확인해야 합니다.
- **계정 관리**: 팀 단위로 웹 애플리케이션 테스트를 공유하고 관리하려면 올바른 권한 설정과 보안 인증 관리가 필수적으로 수반되어야 합니다.

## 자주 묻는 질문

**Manta AI는 어떻게 사용하나요?**

Manta AI는 웹 애플리케이션의 URL을 입력하면 자동으로 탐색을 시작합니다. 이후 분석 결과를 제공하여 문제를 쉽게 파악할 수 있습니다.

**모든 웹사이트에서 사용할 수 있나요?**

대부분의 웹 애플리케이션에서 사용 가능하지만 특정 기술 스택에 따라 호환성 문제가 있을 수 있습니다.

**버그가 발견되면 어떻게 하나요?**

Manta AI는 발견된 버그에 대한 상세한 리포트를 제공하여 개발자가 쉽게 수정하는 데 도움이 되습니다.

**테스트 스크립트를 전혀 작성하지 않아도 정말 작동하나요?**

그렇습니다. Manta AI는 별도의 스크립트나 셀렉터 코드 없이 URL 입력만으로 웹 앱을 자율 탐색하여 작동합니다.

**웹사이트의 UI나 디자인이 바뀌어도 테스트가 깨지지 않나요?**

네, 코드의 셀렉터가 아닌 실제 사용자 동작과 행동 패턴을 추적하기 때문에 UI가 일부 수정되어도 테스트 커버리지가 유지됩니다.

**운영(Production) 환경에서도 안전하게 사용할 수 있나요?**

실제 운영 환경의 URL을 입력해 점검할 수 있으나, 민감한 데이터 입력이나 결제 등 부작용이 우려되는 기능은 스테이징 환경에서 먼저 테스트하는 것을 권장합니다.

**팀원들과 함께 테스트 결과를 공유하고 관리할 수 있나요?**

발견된 버그와 재현 경로, 스크린샷 등이 리포트 형태로 제공되므로 개발팀 및 QA 엔지니어와 원활하게 공유할 수 있습니다.
