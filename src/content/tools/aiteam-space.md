## 한줄 요약

aiteam.space는 개별 AI 에이전트에게 전용 컴퓨터 환경을 제공하여 사람이 직접 하던 반복 업무를 대신 수행하게 하는 서비스입니다. 단순한 챗봇을 넘어 웹 브라우징, 파일 조작 등 실제 PC 환경에서의 작업을 자동화하여 업무 생산성을 극대화합니다.

## 핵심 기능

- **전용 컴퓨터**: 각 AI가 독립된 가상 PC 환경에서 작업을 수행하여 정확도가 높습니다.
- **워크플로우**: 여러 단계의 복잡한 업무를 순차적으로 자동 실행하여 시간을 절약합니다.
- **실시간 제어**: AI가 수행하는 작업 과정을 실시간으로 모니터링하고 수정할 수 있습니다.

## 사용법

**1. 대기 명단 등록하기**

공식 웹사이트에 접속하여 이메일 주소를 입력하고 대기 명단에 등록합니다. 현재는 초대로서만 서비스에 접근할 수 있으므로 이메일을 미리 제출해야 합니다.

**2. AI 계정 연결하기**

사용 중인 Claude, ChatGPT, Gemini 등 각 AI 계정을 플랫폼에 연동합니다. 기존에 결제하여 사용 중인 각 서비스의 계정을 그대로 활용하는 방식입니다.

**3. 프로젝트 환경 설정**

팀원과 AI가 함께 작업할 공유 프로젝트를 생성합니다. 각 AI 에이전트가 작업할 별도의 브랜치를 설정하여 파일이 겹치지 않게 관리합니다.

**4. 작업 승인 및 실행**

동료나 AI가 요청한 작업 내용을 대시보드에서 확인합니다. 모든 작업은 사용자의 최종 승인을 거쳐야만 실행되므로 안전하게 업무를 제어할 수 있습니다.

- 결과 예시: AI가 영어로 이메일 초안을 작성하여 공유 문서에 반영합니다. 사용자가 승인하면 해당 내용이 최종 파일에 저장됩니다.
- 관찰: AI 모델 자체가 한국어를 이해하므로 요청 사항을 정확히 처리합니다.

**코드 오류 수정 요청**

- 프롬프트: 이 파이썬 코드에서 리스트 인덱스 에러가 발생하는데 원인을 찾아서 수정해줘.
- 결과 예시: AI가 코드의 오류를 분석하고 수정된 코드를 브랜치에 제안합니다. 사용자가 확인 후 승인하면 코드가 업데이트됩니다.

인터페이스는 영어로 제공되지만 내부 AI 엔진이 한국어를 지원하므로 한국어 프롬프트 입력에 문제가 없습니다. 전문적인 업무 맥락도 충분히 이해하는 수준입니다.

## 자주 묻는 질문

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 복잡한 코딩 없이도 자연어 명령어로 에이전트에게 업무를 지시할 수 있습니다. 다만, 에이전트가 작업을 잘 수행하도록 단계별로 명확하게 지시하는 연습이 필요합니다.

가상 컴퓨터 환경에서 작업이 이루어지므로 보안이 강화되어 있습니다. 하지만 중요한 개인정보가 포함된 문서를 업로드할 때는 항상 주의를 기울이는 것이 좋습니다.

**어떤 업무를 자동화하는 것이 가장 효과적인가요?**

매일 똑같은 웹사이트에 접속해서 데이터를 복사하거나, 특정 조건에 따라 파일을 정리하는 업무에 가장 효과적입니다. 사람이 매일 30분 이상 반복하는 업무부터 시작해 보세요.

**어떤 AI 모델들을 연결할 수 있나요?**

Claude, ChatGPT, Gemini, Cursor, Copilot 등 사용자가 이미 구독 중인 다양한 AI를 지원합니다. 상세한 호환 목록은 공식 페이지에서 확인하십시오.

**팀원들과 동시에 작업할 수 있나요?**

네, 공유 프로젝트 기능을 통해 팀원들이 각자의 AI와 함께 협업할 수 있습니다. 각자의 작업물이 브랜치로 분리되어 충돌을 방지합니다.

**AI가 내 파일을 마음대로 수정하나요?**

아니요, AI가 제안한 모든 변경 사항은 사용자가 승인 버튼을 누르기 전까지는 실제 파일에 반영되지 않습니다.

**비용은 어떻게 지불하나요?**

AI 사용료는 각 서비스 업체에 직접 지불하며, 본 플랫폼은 협업 환경을 위한 별도의 요금 체계를 운영합니다.
