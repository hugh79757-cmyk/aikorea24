## 한줄 요약

Command Code AI는 여러 AI 모델과의 세션 관리로 복잡한 작업을 단순화합니다. 개발자들이 효율적으로 AI를 활용하는 데 도움이 되습니다.

## 핵심 기능

- **세션 관리**: 다양한 세션을 쉽게 관리할 수 있어 개발에 유용합니다.
- **슬라이딩 윈도우 메모리**: 효율적인 데이터 처리로 더 나은 결과를 제공합니다.
- **다양한 모델 지원**: 여러 AI 모델을 지원하여 유연한 작업이 가능합니다.

## 사용법

**1. CLI 도구 설치하기**

명령 프롬프트나 터미널을 열고 Command Code AI를 시스템에 설치합니다. 공식 안내에 따라 개발 환경에 맞는 패키지를 내려받고 실행 준비를 마칩니다.

**2. AI 모델 및 세션 연결**

터미널 환경에서 사용할 대형 언어 모델을 선택하고 세션을 시작합니다. 슬라이딩 윈도우 메모리 기능과 명령어 입력로 작업 흐름을 구성합니다.

**3. 명령어 및 자동화 실행**

백그라운드 셸 작업이나 대용량 파일 읽기 등 필요한 개발 업무 명령어를 입력합니다. 헤드리스 TUI 모드를 활용하여 지속적인 모니터링과 자동화를 수행합니다.

**4. 세션 저장 및 결과 확인**

디스크에 자동으로 유지되는 세션을 재개하거나 포크 기능을 사용하여 이전 작업 이력을 관리합니다. 로그 출력로 코드 오류나 디버깅 결과를 최종 점검합니다.
