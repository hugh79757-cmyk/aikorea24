## 한줄 요약

Claude Overlay는 사용자의 화면을 인식하여 질문에 답변하는 AI 챗봇입니다. 코드 작성 및 디버깅에 유용합니다.

## 핵심 기능

- **화면 인식**: 사용자의 화면을 읽어 답변을 제공합니다.
- **실시간 대화**: 즉각적인 질문 응답으로 효율성을 높입니다.
- **개인화된 경험**: 사용자의 Claude 구독로 맞춤형 서비스를 제공합니다.

## 사용법

**1. 깃허브 저장소 방문하기**

공식 깃허브 페이지에서 프로그램 관련 소스와 설치 파일을 확인합니다. 윈도우 환경에서 실행할 수 있는 오픈소스 프로젝트입니다.

**2. 프로그램 실행 및 설정**

컴퓨터에 프로그램을 내려받고 실행하여 화면 위에 띄울 수 있는 창을 준비합니다. 별도의 복잡한 API 키 발급 과정 없이 이용이 가능합니다.

**3. Claude 계정 연동**

사용 중인 본인의 Claude 구독 계정을 프로그램에 연동합니다. 추가 비용 없이 기존 구독을 그대로 활용할 수 있습니다.

**4. 화면 인식 후 질문하기**

작업 중인 화면을 도구가 인식하도록 한 뒤 궁금한 점을 입력합니다. 화면에 띄워진 코드나 오류 메시지를 바탕으로 즉각적인 답변을 얻습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 제공되지 않습니다.
- **유료 플랜**: 유료 플랜은 Claude 구독이 필요하며 가격은 개인의 구독 요금에 따릅니다. 사용자 맞춤형 지원을 받을 수 있습니다.

비용 절약 팁: 무료 체험이나 프로모션을 이용해 비용을 절약할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 프로그램 자체는 오픈소스로 제공되나 별도의 무료 플랜이나 체험 기간에 대한 정보는 수집되지 않았습니다. 정확한 이용 조건은 공식 저장소에서 확인이 필요합니다.

- **Claude 개인 구독 연동** (개인의 Claude 구독 요금에 따름 (공식 요금 페이지 확인 필요)): 별도의 API 키 입력 없이 사용자의 기존 Claude 구독을 활용하여 화면 인식 기능을 이용할 수 있습니다.

**환불과 해지**: 환불 및 결제 정책은 본 프로그램이 아닌 연동하는 Claude 서비스의 정책을 따르므로 해당 플랫폼에서 확인해야 합니다.

## 한국어 지원

한국어로 질문하고 응답을 받을 수 있어, 한국 사용자에게 매우 유용합니다.

## 한국어 품질 실측

**파이썬 오류 분석**

- 프롬프트: 화면에 나타난 파이썬 에러 메시지를 보고 원인과 해결 방법을 한국어로 설명해 주세요.
- 결과 예시: 화면의 15번째 줄에서 발생한 타입 에러는 문자열과 정수를 더하려고 하여 발생했습니다. 두 변수의 자료형을 일치시키도록 코드를 수정하면 해결됩니다.
- 관찰: 화면 캡처를 기반으로 한 오류 분석 결과가 한국어로 자연스럽게 출력됩니다.

**코드 리팩토링**

- 프롬프트: 현재 화면에 있는 반복문을 더 효율적인 리스트 컴프리헨션 방식으로 바꿔주세요.
- 결과 예시: 제시해주신 반복문은 다음과 같이 한 줄의 리스트 컴프리헨션으로 간결하게 작성할 수 있습니다. 가독성을 높인 코드를 확인해 보세요.
- 관찰: 프로그래밍 관련 한국어 지시사항을 정확하게 이해하고 대안 코드를 제시합니다.

한국어 질문과 프롬프트를 원활하게 인식하며 개발 관련 전문 용어도 자연스럽게 처리합니다. 번역투가 적고 직장인과 학생이 바로 활용하기 좋은 답변을 제공합니다.

## 이런 분에게 추천합니다

프로그래밍을 배우고 있는 학생에게 추천합니다. 또한, 코드 리뷰가 필요한 개발자에게도 적합합니다.

## 실제 활용 예시

- **직장인**: 소프트웨어 개발 팀에서 코드 작성 시, 실시간으로 질문하며 도움을 받을 수 있습니다.
- **학생**: 프로그래밍 수업 중 과제를 하면서 코드 오류를 질문하여 해결할 수 있습니다.
- **소상공인**: 자신의 웹사이트를 개발하며 필요한 코드를 작성할 때, 즉시 도움을 받을 수 있습니다.

## 장단점

**장점**

- 별도의 복잡한 API 키를 발급받을 필요 없이 기존에 사용하던 본인의 Claude 구독으로 간편하게 실행할 수 있습니다.
- 윈도우 화면을 실시간으로 인식하기 때문에 창을 전환하지 않고도 현재 작업 중인 내용을 보고 질문할 수 있습니다.
- 항상 위에 떠 있는 플로팅 창 형태로 디자인되어 코딩이나 문서 작업을 하면서 방해받지 않고 참조하기 편리합니다.
- 프로그래밍 작업 중 발생하는 에러 화면을 그대로 읽어 빠른 원인 분석과 해결책을 이끌어낼 수 있습니다.

**단점**

- 윈도우 운영체제 환경에 특화되어 있어 맥이나 리눅스 등 다른 운영체제를 사용하는 사용자에게는 호환성이 제한될 수 있습니다.
- 오픈소스 데스크톱 애플리케이션 특성상 일반 상용 프로그램에 비해 초기 설치 과정이 다소 복잡하게 느껴질 수 있습니다.
- 화면 인식 기능을 지속해서 구동할 때 컴퓨터 환경에 따라 시스템 자원을 소모할 가능성이 있습니다.

## 주의사항

- **개인정보**: 화면 전체를 인식하는 특성상 민감한 개인정보나 사내 기밀 문서가 화면에 노출되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 화면로 인식하는 소스코드나 콘텐츠의 저작권 및 라이선스를 준수하며 활용해야 합니다.
- **요금/한도**: 연동된 Claude 계정의 사용량 한도에 따라 호출 제한이 걸릴 수 있으므로 이용량을 수시로 확인해야 합니다.
- **계정 관리**: 개인 Claude 구독 계정 정보가 타인에게 유출되지 않도록 안전한 환경에서 프로그램을 실행해야 합니다.

## 자주 묻는 질문

**이 툴은 어떻게 사용하나요?**

툴을 설치한 후, 화면에서 질문하고 답변을 받을 수 있습니다. 사용자 경험을 개선하기 위해 지속적으로 업데이트됩니다.

**지원하는 언어는 무엇인가요?**

주로 영어를 지원하지만 한국어로도 질문하고 답변을 받을 수 있습니다.

**어떤 환경에서 사용할 수 있나요?**

Windows 운영체제에서 사용 가능하며 Claude 구독이 필요합니다.

**API 키 없이 어떻게 사용할 수 있나요?**

이 프로그램은 별도의 API를 호출하는 방식이 아니라 사용자의 기존 Claude 구독 계정을 활용하여 작동합니다. 따라서 별도의 유료 API 키를 등록할 필요 없이 바로 연동할 수 있습니다.

**맥(Mac)이나 리눅스에서도 쓸 수 있나요?**

현재 윈도우 환경에 특화되어 개발된 플로팅 화면 인식 챗봇이므로 맥이나 리눅스 운영체제 지원 여부는 공식 저장소를 통해 확인이 필요합니다.

**화면 인식 기능은 어떤 방식으로 동작하나요?**

사용자의 윈도우 화면을 캡처하거나 인식하여 그 안에 담긴 텍스트와 코드 내용을 기반으로 질문에 답변합니다. 별도의 복사 붙여넣기 없이 화면을 보며 대화할 수 있습니다.

**프로그램 설치와 실행이 어렵지 않나요?**

깃허브에 공개된 오픈소스 프로젝트이므로 파이썬 환경이나 관련 실행 파일 다루기에 익숙하지 않은 초보자에게는 진입 장벽이 있을 수 있습니다.
