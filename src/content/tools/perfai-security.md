## 한줄 요약

Perfai Security는 AI로 개발된 앱의 보안을 자동으로 관리하는 플랫폼입니다. 사용자의 앱을 분석하여 보안 취약점을 찾아내고, 자동으로 수정 요청을 생성합니다.

## 핵심 기능

- **자동 보안 점검**: 24시간 자동으로 보안 점검을 수행합니다.
- **취약점 탐지**: 70가지 이상의 AI 기반 위협을 분석하여 검출합니다.
- **자동 수정**: 발견된 문제를 자동으로 수정 요청으로 전환합니다.

## 사용법

**1. 서비스 연동 및 앱 등록**

Perfai Security 홈페이지에 접속하여 개발 중인 앱의 URL을 입력합니다. Replit, Cursor 등 사용 중인 개발 환경과 연동하여 앱의 구조를 분석할 수 있도록 설정합니다.

**2. 비전 에이전트 실행**

Vision Agent 기능을 활성화하여 현재 라이브 상태인 앱의 화면과 기능을 학습시킵니다. 시스템이 자동으로 앱의 UI와 API 권한을 파악하도록 대기합니다.

**3. 보안 취약점 자동 테스트**

90개 이상의 보안 카테고리를 기반으로 앱의 접근 제어 오류를 자동으로 검사합니다. 시스템이 잠재적인 데이터 유출 경로를 스스로 탐색합니다.

**4. 취약점 수정 및 배포**

발견된 취약점를 시스템이 제시하는 수정 사항을 확인합니다. 검증된 수정 코드를 앱에 적용하여 보안 문제를 즉시 해결합니다.

## 가격 정책

- **무료 플랜**: 기본적인 보안 점검 기능이 제공됩니다.
- **유료 플랜**: 프리미엄 플랜 99,000원 + 고급 보안 기능 및 지원이 포함됩니다.

비용 절약 팁: 정기적인 사용으로 할인 혜택을 받을 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜에서는 기본적인 보안 테스트 기능을 제공하며 현재까지 2만 개 이상의 앱이 해당 플랜로 검증되었습니다. 구체적인 테스트 횟수나 기능 제한은 공식 요금 페이지에서 확인이 필요합니다.

- **프리미엄 플랜** (월 99,000원 (달러 결제 시 환율에 따라 변동 가능)): 고급 보안 기능과 우선적인 기술 지원이 포함되어 대규모 프로젝트 관리에 적합합니다.

**환불과 해지**: 결제 및 환불 정책은 서비스 이용 약관에 따르며, 상세한 해지 방법은 공식 홈페이지의 계정 설정 메뉴에서 확인하시기 바랍니다.

## 한국어 지원

한국어로 지원되며, 사용자 친화적인 인터페이스를 제공합니다.

## 한국어 품질 실측

**보안 취약점 분석 요청**

- 프롬프트: 현재 개발 중인 앱의 로그인 페이지에서 발생할 수 있는 접근 제어 취약점을 점검해 줘.
- 결과 예시: 로그인 API의 권한 설정에서 취약점이 발견되었습니다. 사용자 토큰 검증 로직을 보완하는 수정 코드를 생성했습니다.
- 관찰: 입력한 한국어 명령을 정확히 이해하고 기술적인 해결책을 한국어로 제공합니다.

**보안 보고서 요약**

- 프롬프트: 이번 테스트에서 발견된 보안 문제들을 요약해서 보고서 형태로 알려줘.
- 결과 예시: 총 3개의 보안 이슈가 발견되었습니다. 데이터 유출 위험이 있는 API 경로와 이를 해결하기 위한 권장 조치 사항을 정리했습니다.
- 관찰: 전문적인 보안 용어를 사용하면서도 이해하기 쉬운 한국어 문장으로 결과를 출력합니다.

한국어 인터페이스와 명령 처리가 매우 자연스럽습니다. 전문적인 보안 용어도 문맥에 맞게 정확히 번역되어 한국인 개발자가 사용하기에 적합합니다.

## 이런 분에게 추천합니다

AI 기반 앱을 개발하는 중소기업 및 스타트업에 추천합니다. 보안 관리에 어려움을 겪는 개발자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: AI 앱의 보안을 점검하고 발견된 취약점을 즉시 수정 요청합니다.
- **학생**: 프로젝트로 만든 AI 앱의 보안을 검사하여 발표 자료를 준비합니다.
- **소상공인**: 자신의 웹 서비스를 보호하기 위해 AI 보안 솔루션을 활용합니다.

## 장단점

**장점**

- 90개 이상의 방대한 보안 카테고리로 앱의 접근 제어 문제를 정밀하게 탐지할 수 있습니다.
- Vision Agent가 앱을 직접 학습하여 사람이 일일이 설정하지 않아도 자동으로 보안 점검을 수행합니다.
- 단순히 취약점을 찾아내는 것에 그치지 않고 검증된 수정 코드를 직접 제시하여 빠른 대응이 가능합니다.
- Replit, Cursor 등 현대적인 개발 환경과 원활하게 연동되어 개발 생산성을 크게 높여줍니다.

**단점**

- 보안 테스트의 상세 범위나 유료 플랜의 구체적인 혜택이 공식 페이지에 다소 파편화되어 있어 확인이 필요합니다.
- 매우 복잡한 커스텀 로직을 가진 앱의 경우, 자동화된 비전 에이전트가 모든 상황을 완벽히 이해하지 못할 수 있습니다.
- 한국어 지원은 원활하지만 보안 관련 기술 문서나 심층 가이드는 영어로 작성된 경우가 많아 학습이 필요할 수 있습니다.

## 주의사항

- **개인정보**: 앱 테스트 과정에서 실제 사용자 데이터가 포함된 환경을 연결하지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 생성된 수정 코드는 직접 검토 후 적용해야 하며 결과물에 대한 상업적 책임은 사용자에게 있습니다.
- **요금/한도**: 무료 플랜의 사용 한도는 정책에 따라 변경될 수 있으므로 정기적으로 요금 페이지를 확인하십시오.
- **계정 관리**: 보안 플랫폼 특성상 계정 접근 권한 관리를 철저히 하여 외부 유출을 방지해야 합니다.

## 자주 묻는 질문

**Perfai Security는 어떤 앱에서 사용할 수 있나요?**

Cursor, Bolt, GitHub Copilot 등 다양한 AI 개발 플랫폼에서 사용할 수 있습니다.

**보안 점검은 얼마나 자주 이루어지나요?**

24시간 자동으로 이루어지며, 사용자가 별도로 설정할 필요가 없습니다.

**무료 플랜과 유료 플랜의 차이는 무엇인가요?**

무료 플랜은 기본적인 기능만 제공되며, 유료 플랜은 고급 기능과 지원이 포함됩니다.

**어떤 개발 환경을 지원하나요?**

Replit, Cursor, Bolt.new, Claude Code 등 최신 AI 개발 도구와 연동을 지원합니다. 지원하는 환경은 업데이트에 따라 추가될 수 있습니다.

**보안 테스트가 실제 앱 작동에 영향을 주나요?**

테스트는 주로 읽기 전용이나 시뮬레이션 환경에서 수행되지만, 운영 중인 앱에 적용할 때는 반드시 백업 후 진행하시기 바랍니다.

**자동 수정 기능은 안전한가요?**

시스템이 제안하는 수정 코드는 검증 과정을 거치지만, 최종 배포 전 반드시 개발자가 코드 내용을 직접 검토해야 합니다.

**무료 플랜으로도 충분한 보안 점검이 가능한가요?**

기본적인 접근 제어와 취약점 스캔이 가능하여 소규모 프로젝트에는 적합합니다. 다만 고급 기능은 유료 플랜에서만 제공됩니다.
