## 한줄 요약

Perfai Security는 AI로 개발된 앱의 보안을 자동으로 관리하는 플랫폼입니다. 사용자의 앱을 분석하여 보안 취약점을 찾아내고, 자동으로 수정 요청을 생성합니다.

## 핵심 기능

- **자동 보안 점검**: 24시간 자동으로 보안 점검을 수행합니다.
- **취약점 탐지**: 70가지 이상의 AI 기반 위협을 분석하여 검출합니다.
- **자동 수정**: 발견된 문제를 자동으로 수정 요청으로 전환합니다.

## 가격 정책

- **무료 플랜**: 기본적인 보안 점검 기능이 제공됩니다.
- **유료 플랜**: 프리미엄 플랜 99,000원 + 고급 보안 기능 및 지원이 포함됩니다.

비용 절약 팁: 정기적인 사용으로 할인 혜택을 받을 수 있습니다.

## 한국어 지원

한국어로 지원되며, 사용자 친화적인 인터페이스를 제공합니다.

## 이런 분에게 추천합니다

AI 기반 앱을 개발하는 중소기업 및 스타트업에 추천합니다. 보안 관리에 어려움을 겪는 개발자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: AI 앱의 보안을 점검하고 발견된 취약점을 즉시 수정 요청합니다.
- **학생**: 프로젝트로 만든 AI 앱의 보안을 검사하여 발표 자료를 준비합니다.
- **소상공인**: 자신의 웹 서비스를 보호하기 위해 AI 보안 솔루션을 활용합니다.

## 유사 툴과 비교

**장점:**
- 자동화된 보안 점검으로 시간 절약
- 다양한 취약점 탐지 기능 제공

**단점:**
- 고급 기능은 유료로 제공되며 비용이 발생할 수 있음

**이런 분에게 가장 적합합니다:** AI 기반 앱 개발 및 보안 관리가 필요한 상황에 가장 적합합니다.

## 자주 묻는 질문

**Perfai Security는 어떤 앱에서 사용할 수 있나요?**

Cursor, Bolt, GitHub Copilot 등 다양한 AI 개발 플랫폼에서 사용할 수 있습니다.

**보안 점검은 얼마나 자주 이루어지나요?**

24시간 자동으로 이루어지며, 사용자가 별도로 설정할 필요가 없습니다.

**무료 플랜과 유료 플랜의 차이는 무엇인가요?**

무료 플랜은 기본적인 기능만 제공되며, 유료 플랜은 고급 기능과 지원이 포함됩니다.
