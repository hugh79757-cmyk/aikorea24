## 한줄 요약

Opper AI는 300개 이상의 AI 모델을 통합하여 제공하는 API입니다. 개발자와 기업이 쉽게 다양한 AI 기능을 활용하는 데 도움이 되습니다.

## 핵심 기능

- **모델 접근**: 다양한 AI 모델에 쉽게 접근할 수 있습니다.
- **GDPR 준수**: 유럽의 데이터 보호 규정을 준수하여 안전합니다.
- **비용 효율**: 사용한 만큼만 비용을 지불하는 유연한 요금제를 제공합니다.

## 사용법

**1. Opper AI 계정 생성하기**

공식 웹사이트에 방문하여 회원가입을 진행합니다. 이메일 인증을 완료한 후 대시보드에 접속합니다.

**2. API 키 발급받기**

대시보드 내 API 관리 메뉴에서 새로운 API 키를 생성합니다. 발급받은 키는 외부에 노출되지 않도록 안전하게 보관합니다.

**3. SDK 및 엔드포인트 설정**

프로젝트 환경에 맞춰 OpenAI 또는 Anthropic SDK를 설치합니다. 제공되는 기본 URL을 연동 코드에 입력하여 설정을 마칩니다.

**4. AI 모델 호출하기**

코드 내에서 원하는 모델명을 지정하여 API 요청을 보냅니다. 700개 이상의 다양한 모델을 유연하게 전환하며 테스트할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 기본 API 사용이 가능합니다.
- **유료 플랜**: 프리미엄 플랜 월 20,000원으로 고급 기능을 이용할 수 있습니다.

비용 절약 팁: 필요한 기능만 선택하여 사용하면 비용을 절약할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜의 구체적인 메시지 수나 크레딧 한도는 공식 요금 페이지에서 확인이 필요합니다. 기본 API 접근 및 테스트 용도로 주로 제공됩니다.

- **페이아스가우(Pay-as-you-go)** (사용한 만큼 과금 (정확한 금액은 공식 요금 페이지 확인 필요)): 700개 이상의 주요 AI 모델을 사용량에 따라 유연하게 요금을 지불하는 구조입니다.

- **유료 구독 플랜** (월 20,000원 (수집된 기준 가격)): 고급 API 기능 및 추가 한도를 제공하는 프리미엄 플랜입니다.

**환불과 해지**: 환불 정책 및 정기 결제 해지 방법은 공식 웹사이트의 이용약관 및 결제 페이지에서 직접 확인해야 합니다.

**장점**

- 700개 이상의 다양한 최신 AI 모델을 하나의 API로 통합하여 편리하게 접근할 수 있습니다.
- 유럽 지역 호스팅 및 ISO 27001 인증을 획득하여 데이터 보안성이 매우 뛰어납니다.
- 기존 OpenAI 및 Anthropic SDK와 완벽하게 호환되어 코드 수정 없이 쉽게 연동이 가능합니다.
- 사용량 제한 기능과 모델 허용 목록 설정로 예산 초과를 효과적으로 예방할 수 있습니다.

- 무료 플랜과 유료 플랜의 상세한 크레딧 한도가 문서에 명확히 표기되어 있지 않습니다.
- 유럽 기반 서비스 특성에 따라 국내 전용 고객 지원이나 자료가 상대적으로 부족할 수 있습니다.

- **계정 관리**: API 키가 외부에 유출될 경우 타인이 무단으로 사용하여 비용이 발생할 수 있으므로 환경 변수 등으로 안전하게 관리해야 합니다.
