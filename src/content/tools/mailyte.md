## 한줄 요약

Mailyte는 팀 메일함, 뉴스레터 캠페인, 앱에서 자동 발송되는 트랜잭셔널 이메일(영수증, 비밀번호 재설정, 주문 알림 등)을 자체 도메인으로 통합 관리하는 서비스입니다. 오픈소스(AGPL-3.0)로 제공되어 직접 서버에 설치하거나 관리형 클라우드를 이용할 수 있으며, 10개 메일함까지 무료로 사용할 수 있어 스타트업과 소규모 팀의 이메일 인프라 비용을 크게 줄여줍니다.

## 핵심 기능

- **통합 메일함**: 팀원 전체가 자체 도메인 이메일을 브라우저와 메일 앱에서 바로 사용 가능합니다.
- **캠페인 발송**: 뉴스레터·프로모션 메일을 대량 발송하고 열람률·전달률을 실시간 확인합니다.
- **API 자동 발송**: 앱에서 영수증·알림 메일을 API로 안정적으로 자동 발송합니다.

## 가격 정책

- **무료 플랜**: 메일함 10개까지 무료 제공, 기본 기능 모두 사용 가능합니다.
- **유료 플랜**: Managed Cloud 플랜: 월 $29(약 39,000원)부터, 메일함 무제한·전담 지원·고급 분석 포함.

비용 절약 팁: 기술 역량이 있다면 오픈소스 버전을 직접 호스팅해 완전 무료로 운영하세요.

## 한국어 지원

관리자 UI와 문서는 영어로만 제공되나, 메일 본문 작성과 수신자 인터페이스는 한글을 포함한 모든 언어를 문제없이 지원합니다.

## 이런 분에게 추천합니다

자체 도메인 이메일을 저렴하게 구축하려는 초기 스타트업 창업자에게 적합합니다. 트랜잭셔널 메일 발송이 필요한 SaaS 개발팀에게 추천합니다. 마케팅 뉴스레터와 팀 이메일을 한 도메인으로 통합 관리하려는 마케터에게 유용합니다.

## 실제 활용 예시

- **직장인**: 회사 도메인으로 팀 전체 메일함을 개설해 아웃룩·지메일 앱에서 바로 송수신합니다. 마케팅팀은 별도 툴 없이 Mailyte 캠페인 기능으로 월간 뉴스레터를 발송하고 성과를 확인합니다.
- **학생**: 동아리·프로젝트 팀 도메인으로 공식 메일 주소를 만들어 대외 협력 메일을 전문적으로 보냅니다. 졸업 작품 웹서비스에 회원가입·비밀번호 찾기 메일 API를 연동해 자동 발송합니다.
- **소상공인**: 쇼핑몰 자체 도메인으로 주문 확인·배송 알림 메일을 자동 발송해 고객 신뢰도를 높입니다. 월 1만 명 이하 발송량이면 무료 플랜으로 운영비 없이 이메일 인프라를 유지합니다.

## 유사 툴과 비교

**장점:**
- 메일함·캠페인·트랜잭셔널 메일을 단일 플랫폼에서 통합 관리
- 오픈소스로 벤더 락인 없이 직접 호스팅 가능
- 10개 메일함까지 완전 무료로 초기 비용 제로

**단점:**
- 한국어 관리자 UI 미지원, 영문 문서만 제공
- 셀프호스팅 시 메일 서버 운영 지식(DKIM, SPF, DMARC) 필요
- 대량 발송 시 전용 ESP 대비 딜리버리 최적화 기능 제한적

**이런 분에게 가장 적합합니다:** 자체 도메인 이메일 인프라를 저렴하게 직접 구축·운영하려는 기술 친화적 팀에 가장 적합합니다.

## 자주 묻는 질문

**한국 포털(네이버, 다음) 메일로 발송 시 스팸함에 안 가나요?**

DKIM, SPF, DMARC 레코드를 도메인 DNS에 정확히 설정하면 주요 포털에서도 높은 수신함 도달률을 보입니다. Mailyte는 설정 가이드를 제공하며 관리형 플랜 이용 시 전문가가 대신 설정해줍니다.

**기존 구글 워크스페이스·아웃룩 계정을 이전할 수 있나요?**

IMAP 마이그레이션 도구로 기존 메일함 전체를 Mailyte로 이전 가능합니다. 도메인 MX 레코드만 Mailyte 서버로 변경하면 끊김 없이 전환됩니다.

**무료 플랜 10개 메일함 초과 시 어떻게 되나요?**

11번째 메일함 생성 시 자동으로 유료 플랜 결제 안내로 넘어갑니다. 셀프호스팅 버전은 메일함 수 제한 없이 서버 리소스 범위 내 무제한 생성 가능합니다.
