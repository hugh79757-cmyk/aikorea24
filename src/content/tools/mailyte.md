## 한줄 요약

Mailyte는 팀 메일함, 뉴스레터 캠페인, 앱에서 자동 발송되는 트랜잭셔널 이메일(영수증, 비밀번호 재설정, 주문 알림 등)을 자체 도메인으로 통합 관리하는 서비스입니다. 오픈소스(AGPL-3.0)로 제공되어 직접 서버에 설치하거나 관리형 클라우드를 이용할 수 있으며, 10개 메일함까지 무료로 사용할 수 있어 스타트업과 소규모 팀의 이메일 인프라 비용을 크게 줄여줍니다.

## 핵심 기능

- **통합 메일함**: 팀원 전체가 자체 도메인 이메일을 브라우저와 메일 앱에서 바로 사용 가능합니다.
- **캠페인 발송**: 뉴스레터·프로모션 메일을 대량 발송하고 열람률·전달률을 실시간 확인합니다.
- **API 자동 발송**: 앱에서 영수증·알림 메일을 API로 안정적으로 자동 발송합니다.

## 사용법

**1. 자체 도메인 등록하기**

회사의 고유 도메인을 플랫폼에 연결하여 비즈니스 이메일 계정을 생성합니다. 웹 브라우저나 자주 사용하는 아웃룩 같은 메일 앱에서 바로 쓸 수 있도록 셋팅합니다.

**2. 팀원 메일함 및 권한 부여**

관리자 대시보드에서 직원별로 개별 메일함과 저장 공간을 배정합니다. 팀원 초대 기능로 사내 구성원들이 즉시 협업을 시작할 수 있도록 설정합니다.

**3. API 및 SMTP 연동하기**

개발자 대시보드에서 발급받은 API 키를 활용하여 앱과 서비스를 연동합니다. 주문 확인서나 비밀번호 재설정 같은 자동 발송 메일이 정상 작동하는지 테스트 모드에서 확인합니다.

**4. 마케팅 캠페인 작성하기**

뉴스레터나 프로모션 공지사항을 작성하고 발송 일정을 예약합니다. 실시간 전달률과 오픈 여부를 대시보드에서 한눈에 모니터링하며 고객 소통을 관리합니다.

## 가격 정책

- **무료 플랜**: 메일함 10개까지 무료 제공, 기본 기능 모두 사용 가능합니다.
- **유료 플랜**: Managed Cloud 플랜: 월 $29(약 39,000원)부터, 메일함 무제한·전담 지원·고급 분석 포함.

비용 절약 팁: 기술 역량이 있다면 오픈소스 버전을 직접 호스팅해 완전 무료로 운영하세요.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본 플랜에서는 5개의 메일함이 무료로 제공됩니다. 자체 도메인 연동과 보안 및 발송 도구 등의 필수 기능을 비용 부담 없이 시작할 수 있습니다.

- **Managed Cloud 플랜** (월 39,000원 상당 (공식 요금 페이지에서 나이라 또는 달러로 확인 필요)): 메일함 무제한 생성, 대규모 이메일 마케팅 캠페인, 전담 고객 지원 및 고급 분석 기능을 제공합니다.

- **Open Source Self-host 플랜** (무료 (직접 서버 호스팅)): AGPL-3.0 오픈소스 코드를 활용하여 자체 서버에 직접 설치하고 운영 비용을 완전히 절감할 수 있습니다.

**환불과 해지**: 환불 및 결제 정책에 대한 세부 조건은 공식 웹사이트의 요금 및 결제 페이지에서 직접 확인해야 합니다.

## 한국어 지원

관리자 UI와 문서는 영어로만 제공되나, 메일 본문 작성과 수신자 인터페이스는 한글을 포함한 모든 언어를 문제없이 지원합니다.

## 한국어 품질 실측

**뉴스레터 초안 작성**

- 프롬프트: 이번 주 신제품 출시 소식을 알리는 뉴스레터 본문과 제목을 작성해 줘.
- 결과 예시: 제목: [신제품 출시] 새로운 기능을 만나보세요! 본문: 안녕하세요 고객님, 기다려주신 신제품이 드디어 출시되었습니다. 자세한 내용은 링크를 확인해 주세요.
- 관찰: 관리자 인터페이스가 영어로만 제공되므로 이메일 본문 작성 시 한국어 입력은 가능하나 UI 번역 지원은 제한적입니다.

**고객 문의 응대**

- 프롬프트: 배송 지연를 사과하고 다음 주에 발송된다고 안내하는 메일을 작성해 줘.
- 결과 예시: 제목: 배송 지연 안내 및 사과의 말씀 본문: 고객님, 이용에 불편을 드려 죄송합니다. 주문하신 상품은 물류 사정으로 인해 다음 주에 안전하게 발송될 예정입니다.
- 관찰: 메일 작성 시 한글 입력과 가독성은 유지되나 플랫폼 자체의 한국어 가이드는 찾아보기 어렵습니다.

관리자 UI와 대시보드가 영어로만 제공되어 국내 일반 직장인이 처음 접하기에는 다소 진입장벽이 있습니다. 다만 이메일 본문 자체는 한글 입력 및 발송에 문제가 없어 실무 활용은 충분히 가능합니다.

## 이런 분에게 추천합니다

자체 도메인 이메일을 저렴하게 구축하려는 초기 스타트업 창업자에게 적합합니다. 트랜잭셔널 메일 발송이 필요한 SaaS 개발팀에게 추천합니다. 마케팅 뉴스레터와 팀 이메일을 한 도메인으로 통합 관리하려는 마케터에게 유용합니다.

## 실제 활용 예시

- **직장인**: 회사 도메인으로 팀 전체 메일함을 개설해 아웃룩·지메일 앱에서 바로 송수신합니다. 마케팅팀은 별도 툴 없이 Mailyte 캠페인 기능으로 월간 뉴스레터를 발송하고 성과를 확인합니다.
- **학생**: 동아리·프로젝트 팀 도메인으로 공식 메일 주소를 만들어 대외 협력 메일을 전문적으로 보냅니다. 졸업 작품 웹서비스에 회원가입·비밀번호 찾기 메일 API를 연동해 자동 발송합니다.
- **소상공인**: 쇼핑몰 자체 도메인으로 주문 확인·배송 알림 메일을 자동 발송해 고객 신뢰도를 높입니다. 월 1만 명 이하 발송량이면 무료 플랜으로 운영비 없이 이메일 인프라를 유지합니다.

## 장단점

**장점**

- 팀 업무용 메일, 앱 자동 발송 메일, 마케팅 뉴스레터를 하나의 플랫폼과 대시보드에서 통합 관리할 수 있습니다.
- 메일 작성 중에 골뱅이 기호(@)를 입력하여 동료를 곧바로 태그하고 협업할 수 있어 업무 효율성이 크게 향상됩니다.
- SPF, DKIM, DMARC 인증 설정을 지원하여 스팸퍼블릭 필터에 걸리지 않고 안전하게 이메일을 전달할 수 있습니다.
- 오픈소스(AGPL-3.0) 라이선스로 제공되므로 기술 역량이 있다면 자체 서버에 구축하여 비용을 아낄 수 있습니다.

**단점**

- 한국어 지원이 전혀 되지 않아 모든 관리자 메뉴와 설정 가이드를 영어로 읽고 처리해야 합니다.
- 무료 플랜에서 제공하는 메일함 개수가 5개로 제한되어 있어 중소기업 이상 규모에서는 유료 전환이 필수적입니다.
- 자체 호스팅을 선택할 경우 서버 유지보수와 보안 관리를 직접 담당해야 하므로 IT 전문 인력이 필요합니다.

## 주의사항

- **개인정보**: 고객의 이메일 주소와 비즈니스 커뮤니프 데이터가 플랫폼로 오가므로, 사내 보안 규정과 개인정보 보호법 준수 여부를 확인해야 합니다.
- **저작권/상업적 이용**: 오픈소스 버전을 상업적으로 활용할 때는 AGPL-3.0 라이선스 조항을 면밀히 검토하고 준수해야 합니다.
- **요금/한도**: 무료 플랜의 메일함 5개 한도와 유료 플랜의 월 구독료 및 발송량 제한 조건을 가입 전에 반드시 점검해야 합니다.
- **계정 관리**: 이메일 인프라의 특성상 관리자 계정 권한이 유출될 경우 기업 보안에 큰 위협이 되므로 2단계 인증 등을 철저히 설정해야 합니다.

## 자주 묻는 질문

**한국 포털(네이버, 다음) 메일로 발송 시 스팸함에 안 가나요?**

DKIM, SPF, DMARC 레코드를 도메인 DNS에 정확히 설정하면 주요 포털에서도 높은 수신함 도달률을 보입니다. Mailyte는 설정 가이드를 제공하며 관리형 플랜 이용 시 전문가가 대신 설정해줍니다.

**기존 구글 워크스페이스·아웃룩 계정을 이전할 수 있나요?**

IMAP 마이그레이션 도구로 기존 메일함 전체를 Mailyte로 이전 가능합니다. 도메인 MX 레코드만 Mailyte 서버로 변경하면 끊김 없이 전환됩니다.

**무료 플랜 10개 메일함 초과 시 어떻게 되나요?**

11번째 메일함 생성 시 자동으로 유료 플랜 결제 안내로 넘어갑니다. 셀프호스팅 버전은 메일함 수 제한 없이 서버 리소스 범위 내 무제한 생성 가능합니다.

**기존에 쓰던 지메일이나 아웃룩 메일 앱과 연동해서 쓸 수 있나요?**

네, 그렇습니다. 자체 도메인 기반의 메일함을 제공하므로 애플 메일, 아웃룩, 스마트폰 기본 메일 앱을 그대로 연결해서 사용할 수 있습니다.

**개발 지식이 없어도 뉴스레터를 대량으로 보낼 수 있나요?**

네, 그렇습니다. 웹 대시보드 내의 컴포즈(작성) 기능을 통해 일반적인 뉴스레터와 프로모션 메일을 직접 작성하고 예약 발송할 수 있습니다.

**스팸 메일함으로 빠지지 않도록 설정하는 기능이 있나요?**

네, 그렇습니다. SPF 인증 레코드를 자동으로 생성해주고 DKIM 및 DMARC 설정을 지원하여 스팸 필터를 통과하도록 돕습니다.

**오픈소스 버전과 유료 클라우드 버전의 기능 차이가 있나요?**

오픈소스는 직접 서버에 설치해 비용 없이 쓸 수 있으며, 유료 관리형 클라우드는 서버 관리 없이 메일함 무제한과 전담 지원 혜택을 받습니다.
