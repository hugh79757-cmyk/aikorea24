## 한줄 요약

Revix AI는 팀의 기존 코드베이스를 학습하여 시니어 개발자 수준의 코드 리뷰를 자동으로 수행합니다. 개발자가 작성한 코드의 잠재적 오류와 표준 위반 사항을 실시간으로 감지하여 코드 품질을 높이고 리뷰 시간을 획기적으로 줄여줍니다.

## 핵심 기능

- **자동 규칙 추출**: 기존 코드를 분석해 팀의 표준을 자동으로 학습합니다.
- **실시간 리뷰**: 코드 수정 시 즉시 리뷰를 제공하여 개발 속도를 높입니다.
- **통합 지원**: GitHub, Bitbucket 등 주요 개발 도구와 바로 연결됩니다.

## 사용법

**1. 서비스 연동 시작하기**

Revix AI 공식 홈페이지에서 'Start free trial' 버튼을 클릭하여 계정을 생성합니다. 이후 GitHub, Bitbucket, GitLab 중 팀이 사용하는 저장소를 선택하여 권한을 부여합니다.

**2. 코드베이스 분석 수행**

연동된 저장소의 기존 코드를 AI가 자동으로 스캔합니다. 별도의 규칙 설정 없이도 팀 내 시니어 개발자의 코딩 스타일과 패턴을 스스로 학습합니다.

**3. 코드 리뷰 확인하기**

새로운 Pull Request를 생성하면 AI가 실시간으로 코드를 검토합니다. 대시보드에서 코드의 위험 수준과 변경 사항 요약을 확인하고 수정 사항을 검토합니다.

**4. 리뷰 규칙 커스터마이징**

AI가 추출한 규칙이 적절하지 않다면 관리자 페이지에서 직접 수정하거나 비활성화할 수 있습니다. 팀의 표준에 맞춰 리뷰의 세부 기준을 지속적으로 최적화합니다.

## 가격 정책

- **무료 플랜**: 14일간 신용카드 등록 없이 무료로 모든 기능을 체험할 수 있습니다.
- **유료 플랜**: 유료 플랜은 팀 규모에 따라 다르게 책정되며, 월 약 3~5만 원(사용자당) 수준부터 시작합니다.

비용 절약 팁: 무료 체험 기간 동안 팀의 핵심 프로젝트를 연동하여 실제 리뷰 성능을 충분히 테스트해 보시기 바랍니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 공개 저장소(Open Source)에 대해서는 항상 무료로 모든 기능을 사용합니다. 신용카드 등록 없이 14일간 모든 유료 기능을 체험할 수 있는 무료 평가판을 제공합니다.

- **Starter** (월 20~25유로 (사용자당, 연간 결제 시)): 모든 Pull Request에 대한 자동 리뷰와 저장소 분석, 규칙 추출 기능을 포함합니다.

- **Pro** (월 40~50유로 (사용자당, 연간 결제 시)): Starter 기능에 더해 Slack 및 Jira 연동, 전문가의 규칙 관리 지원과 우선 고객 지원을 제공합니다.

- **Enterprise** (가격 별도 문의 (공식 페이지 확인 필요)): 조직 맞춤형 보안 인증, 사용자 권한 관리, 전용 기술 지원 및 맞춤형 기능 개발을 제공합니다.

**환불과 해지**: 연간 결제 시 20% 할인 혜택이 제공되며, 결제 및 환불 정책은 공식 홈페이지의 계약 조건 및 결제 페이지로 확인해야 합니다.

## 한국어 지원

현재 인터페이스와 리뷰 결과는 영어로 제공되지만 코드 내의 주석이나 변수명은 한국어 환경에서도 무리 없이 분석 가능합니다.

## 한국어 품질 실측

**코드 주석 분석**

- 프롬프트: 이 함수는 한국어로 된 주석이 포함되어 있습니다. 이 주석의 의미를 파악하고 코드 로직과 일치하는지 확인해 주세요.
- 결과 예시: AI는 코드의 변수명과 로직을 분석하여 한국어 주석이 설명하는 기능과 실제 동작이 일치하는지 판단합니다. 결과는 영어로 출력되지만 한국어 주석의 맥락을 정확히 이해하고 리뷰 내용을 생성합니다.
- 관찰: 인터페이스는 영어지만 코드 내 한국어 데이터를 처리하는 데는 큰 문제가 없습니다.

**리뷰 결과 해석**

- 프롬프트: AI가 제시한 코드 리뷰 피드백을 한국어로 요약해서 보여주세요.
- 결과 예시: AI는 해당 코드의 성능 문제나 표준 위반 사항을 영어로 보고합니다. 사용자는 이 내용을 별도의 번역 도구로 한국어로 해석하여 팀원들과 공유할 수 있습니다.
- 관찰: 직접적인 한국어 출력 기능은 없으므로 번역 과정이 필요할 수 있습니다.

인터페이스와 리뷰 결과가 모두 영어로 제공되므로 한국어 전용 도구를 찾는 사용자에게는 다소 불편할 수 있습니다. 다만 코드 내의 한국어 주석이나 변수명 인식은 준수한 편입니다.

## 이런 분에게 추천합니다

코드 리뷰에 너무 많은 시간을 쏟는 개발 팀장님께 추천합니다. 코드 품질을 상향 평준화하고 싶은 스타트업 개발팀에게도 매우 유용합니다.

## 실제 활용 예시

- **직장인**: 바쁜 업무 중 코드 리뷰 요청이 쌓였을 때, Revix AI를 통해 1차 검토를 마치고 핵심적인 부분만 직접 확인합니다.
- **학생**: 개인 프로젝트를 진행하며 혼자서도 시니어 개발자의 관점에서 코드의 문제점을 파악하고 수정할 수 있습니다.
- **소상공인**: 외주 개발자가 작성한 코드의 품질이 걱정될 때, 이 툴을 사용하여 표준 규칙 준수 여부를 객관적으로 확인할 수 있습니다.

**장점:**

**단점:**

**이런 분에게 가장 적합합니다:** 코드 스타일이 정립되어 있고, 리뷰 속도를 높이고 싶은 기술 팀에 가장 적합합니다.

## 장단점

**장점**

- 별도의 규칙을 수동으로 작성할 필요 없이 기존 코드베이스를 학습하여 즉시 리뷰가 가능합니다.
- GitHub, Bitbucket, GitLab 등 주요 개발 플랫폼과 완벽하게 연동되어 워크플로우를 유지합니다.
- 코드 리뷰 시 리뷰의 의도와 심각도를 레이블로 표시하여 개발자가 우선순위를 쉽게 파악합니다.
- 코드 변경 사항에 대한 핵심 요약을 제공하여 시니어 개발자의 리뷰 시간을 획기적으로 단축합니다.

**단점**

- 서비스 내 모든 인터페이스와 리뷰 결과가 영어로만 제공되어 한국인 개발자에게는 언어 장벽이 존재합니다.
- 사용자당 지불하는 월간 구독료가 다소 높게 책정되어 소규모 팀이나 개인 개발자에게는 부담이 될 수 있습니다.
- 복잡한 비즈니스 로직에 대한 심층적인 이해는 여전히 사람의 판단이 필요하며 AI가 완벽하지 않을 수 있습니다.

## 주의사항

- **개인정보**: 코드 저장소의 데이터를 AI가 분석하므로, 보안이 중요한 핵심 소스 코드나 비밀 키 등이 포함되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 분석된 코드의 저작권은 사용자에게 있으나, 서비스 이용 약관에 따라 AI 학습 데이터 활용 범위를 반드시 확인해야 합니다.
- **요금/한도**: 플랜별로 리뷰 가능한 코드의 양이나 토큰 제한이 다를 수 있으므로 사용량에 따른 비용을 사전에 검토하시기 바랍니다.
- **계정 관리**: 연동된 저장소의 접근 권한은 보안과 직결되므로, 퇴사자 발생 시 즉시 권한을 회수하는 등 철저한 계정 관리가 필요합니다.

## 자주 묻는 질문

**기존에 사용 중인 GitHub와 바로 연동되나요?**

네, GitHub, Bitbucket, GitLab과 기본적으로 연동을 지원합니다. 설정 페이지에서 계정을 연결하면 즉시 코드 분석이 시작됩니다.

**우리 팀만의 코딩 스타일을 학습할 수 있나요?**

Revix AI의 핵심 기능이 바로 그것입니다. 기존 저장소의 코드를 분석하여 팀 고유의 규칙을 자동으로 추출하고 적용합니다.

**보안상 안전한가요?**

기업용 도구로서 코드 보안을 최우선으로 고려하여 설계되었습니다. 자세한 보안 정책은 공식 홈페이지의 보안 문서를 확인하시기 바랍니다.

**기존의 린터(Linter)와 무엇이 다른가요?**

린터는 문법적 오류나 정해진 규칙 위반을 확인하지만, Revix AI는 팀의 실제 코딩 스타일을 학습하여 시니어 개발자가 하는 수준의 맥락 있는 리뷰를 제공합니다.

**규칙을 직접 작성해야 하나요?**

아니요, Revix AI는 저장소를 읽고 자동으로 규칙을 추출합니다. 물론 필요에 따라 사용자가 직접 규칙을 수정하거나 추가할 수 있습니다.

**보안 인증은 되어 있나요?**

Enterprise 플랜의 경우 SOC 2 Type II 및 ISO 27001 인증을 제공하여 기업 수준의 보안 요구사항을 충족합니다.

**무료 플랜으로도 충분한가요?**

공개 저장소는 무료로 제한 없이 사용 가능하지만, 비공개 프로젝트의 경우 기능 제한이 있을 수 있으니 팀 규모에 맞는 유료 플랜 검토가 필요합니다.
