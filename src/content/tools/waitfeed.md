## 한줄 요약

WaitFeed는 AI 챗봇이 답변을 처리하는 동안 발생하는 대기 시간에 최신 기술 뉴스 피드를 노출하여 사용자 경험을 개선하는 도구입니다. 단순히 기다리는 시간을 줄이는 것을 넘어, 사용자에게 유익한 정보를 제공함으로써 이탈률을 낮추고 서비스의 가치를 높여줍니다.

## 핵심 기능

- **뉴스 피드 연동**: 최신 기술 동향을 실시간으로 가져와 대기 화면에 자연스럽게 노출합니다.
- **대기 시간 활용**: 응답 대기 중인 사용자가 지루함을 느끼지 않도록 읽을거리를 제공합니다.
- **간편한 설정**: 복잡한 코딩 없이 기존 AI 챗봇 서비스에 쉽게 통합할 수 있습니다.

## 사용법

**1. 서비스 계정 생성 및 로그인**

공식 웹사이트에 접속하여 이메일 계정으로 회원가입을 진행합니다. 대시보드에 로그인한 후 새로운 프로젝트를 생성하여 서비스를 시작할 준비를 마칩니다.

**2. AI 챗봇과 연동 설정**

제공되는 연동 가이드를 확인하여 현재 운영 중인 챗봇 서비스와 연결합니다. 설정 메뉴에서 API 키를 입력하거나 제공된 스크립트를 복사하여 웹사이트 코드에 삽입합니다.

**3. 뉴스 피드 항목 최적화**

대기 화면에 노출될 뉴스 카테고리를 선택합니다. 사용자의 관심사에 맞는 기술 분야를 지정하여 대기 시간이 지루하지 않도록 콘텐츠를 맞춤 설정합니다.

**4. 실시간 대기 화면 확인**

챗봇이 답변을 생성하는 동안 화면에 뉴스 피드가 정상적으로 나타나는지 테스트합니다. 실제 사용자 환경에서 대기 시간이 효율적으로 활용되는지 모니터링하며 설정을 조정합니다.

- **유료 플랜**: Pro 플랜(월 약 27,000원 상당)을 통해 더 많은 뉴스 소스 선택과 커스텀 디자인 기능을 지원합니다.

비용 절약 팁: 초기 도입 시 무료 플랜으로 서비스와의 호환성을 충분히 테스트한 후 유료 전환을 결정하시기 바랍니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜에서는 기본적인 뉴스 피드 연동 기능을 체험할 수 있습니다. 다만 상세한 커스텀 디자인이나 고급 뉴스 소스 선택에는 제한이 있을 수 있습니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 비즈니스를 위한 맞춤형 지원과 우선적인 기술 상담 서비스를 제공합니다.

**환불과 해지**: 결제 및 환불 정책은 공식 요금 페이지로 확인해야 하며 구독 해지는 언제든지 설정 메뉴에서 가능합니다.

**기술 뉴스 피드 설정**

- 프롬프트: 최신 인공지능 트렌드 관련 뉴스만 보여주도록 설정해줘.
- 결과 예시: AI-related news feed has been activated. Users will now see the latest updates on AI technology while waiting for the response.
- 관찰: 입력은 한국어로 가능하나 결과값은 영어로 출력되는 경향이 있습니다.

**대기 화면 디자인 변경**

- 프롬프트: 배경색을 파란색으로 바꾸고 뉴스 글자 크기를 키워줘.
- 결과 예시: The background color has been updated to blue, and the font size for the news feed has been increased for better readability.
- 관찰: 명령어는 한국어로 이해하지만 시스템 인터페이스는 영어 위주로 작동합니다.

한국어 프롬프트에 대한 이해도는 있으나 결과물과 인터페이스는 영어로 제공됩니다. 한국어 뉴스 콘텐츠 연동을 위해서는 별도의 API 설정이 필요할 수 있습니다.

- **소상공인**: 쇼핑몰 고객 상담 챗봇에 연동하여 고객이 문의 답변을 기다리는 동안 관련 업계 소식을 보여줍니다. 고객의 체류 시간을 늘리고 브랜드 이미지를 전문적으로 관리할 수 있습니다.

## 장단점

**장점**

- AI 챗봇의 응답 대기 시간을 유익한 기술 정보 습득 시간으로 전환하여 사용자 경험을 획기적으로 개선할 수 있습니다.
- 복잡한 코딩 지식 없이도 간편하게 기존 챗봇 서비스에 뉴스 피드를 통합할 수 있어 도입 장벽이 매우 낮습니다.
- 사용자가 답변을 기다리는 동안 이탈하지 않고 화면에 머물게 하여 서비스 체류 시간을 자연스럽게 늘릴 수 있습니다.
- 다양한 기술 뉴스 소스를 실시간으로 연동하여 항상 최신의 정보를 사용자에게 제공하는 환경을 구축합니다.

**단점**

- 현재 뉴스 콘텐츠와 인터페이스가 영어 중심으로 구성되어 있어 한국어 사용자에게는 정보 전달의 한계가 존재합니다.
- 무료 플랜에서는 디자인 커스터마이징 기능이 제한적이므로 브랜드 고유의 느낌을 살리기에는 어려움이 있을 수 있습니다.
- 뉴스 피드 내용이 사용자의 비즈니스 성격과 완전히 일치하지 않을 경우 오히려 정보가 산만하게 느껴질 가능성이 있습니다.

- **요금/한도**: 무료 플랜과 유료 플랜의 기능 차이가 크므로 도입 전 비용 대비 효율을 충분히 검토하는 것이 좋습니다.
- **계정 관리**: 계정 공유를 방지하고 보안하려고 정기적으로 비밀번호를 변경하며 관리자 권한을 엄격히 관리해야 합니다.

## 자주 묻는 질문

**기존에 사용 중인 챗봇에 바로 추가할 수 있나요?**

네, 제공되는 스크립트로 간단하게 기존 챗봇 서비스에 통합할 수 있습니다. 다만, 사용 중인 챗봇 플랫폼이 외부 API 연동을 지원하는지 먼저 확인해야 합니다.

**뉴스 콘텐츠를 직접 선택할 수 있나요?**

유료 플랜을 이용하시면 특정 기술 분야나 선호하는 뉴스 소스를 필터링하여 사용자에게 보여줄 수 있습니다. 무료 버전은 기본 설정된 피드를 제공합니다.

**한국어 뉴스도 보여줄 수 있나요?**

현재는 영문 뉴스 피드에 최적화되어 있습니다. 한국어 뉴스 적용을 위해서는 별도의 API 연동이나 커스텀 설정이 필요할 수 있으니 기술 문서를 참고하시기 바랍니다.

**한국어 뉴스 피드를 노출할 수 있나요?**

기본적으로는 영어 뉴스 피드를 제공합니다. 한국어 뉴스 연동을 위해서는 별도의 RSS 피드 설정이나 외부 API 연동이 필요할 수 있습니다.

**모든 챗봇 서비스와 호환되나요?**

대부분의 웹 기반 챗봇과 호환되도록 설계되었습니다. 다만 특정 프레임워크에서는 별도의 스크립트 삽입 과정이 필요할 수 있으니 기술 문서를 참조하십시오.

**무료 플랜으로 충분할까요?**

기본 기능을 테스트하기에는 충분합니다. 다만 브랜드 디자인을 적용하거나 더 많은 뉴스 소스가 필요하다면 유료 플랜 전환을 고려해야 합니다.

**뉴스 피드가 챗봇 성능에 영향을 주나요?**

뉴스 피드는 별도의 레이어에서 작동하므로 챗봇의 응답 생성 속도나 성능에는 직접적인 영향을 주지 않도록 설계되어 있습니다.
