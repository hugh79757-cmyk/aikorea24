## 한줄 요약

MeetStream AI는 화상회의 플랫폼과 연동하여 회의 내용을 자동으로 녹화, 스트리밍, 텍스트 변환을 수행하는 API 서비스입니다. 개발자가 복잡한 연동 과정 없이 화상회의 데이터를 AI 에이전트에 즉시 활용하는 데 도움이 되습니다.

## 핵심 기능

- **통합 API**: 줌, 구글 미트, 팀즈를 하나의 API로 통합 관리하여 개발 효율을 높입니다.
- **실시간 녹취**: 회의 내용을 지연 없이 텍스트로 변환하여 실시간 데이터 처리가 가능합니다.
- **스트리밍 지원**: 회의 오디오와 비디오 데이터를 외부 AI 모델로 즉시 전송할 수 있습니다.

## 사용법

**1. 회원가입 및 크레딧 확인**

공식 웹사이트에 접속하여 계정을 생성한 뒤, 개발 테스트를 위한 5달러 무료 크레딧이 정상적으로 지급되었는지 확인합니다. API 키를 발급받기 위한 첫 단계입니다.

**2. API 키 발급받기**

대시보드 메뉴에서 개발용 인증에 필요한 API 키를 생성하고 안전한 곳에 보관합니다. 이 키는 줌이나 구글 미트 등의 화상회의 플랫폼과 봇을 연동할 때 사용됩니다.

**3. 봇 생성 API 호출하기**

제공되는 cURL 명령어 또는 API 문서를 참고하여 회의에 참여할 봇을 프로그래밍 방식으로 생성합니다. 연동할 화상회의 링크와 필요한 설정을 파라미터로 입력합니다.

**4. 데이터 스트리밍 및 수신**

회의가 시작되면 봇이 자동으로 화상회의에 참여하여 오디오, 비디오, 실시간 텍스트 변환 데이터를 서버로 전송합니다. 이를 외부 AI 에이전트와 연동하여 실시간으로 활용합니다.

## 가격 정책

- **무료 플랜**: 가입 시 5달러(약 6,500원) 상당의 무료 크레딧을 제공합니다.
- **유료 플랜**: 종량제(Pay-as-you-go) 방식이며, 사용량에 따라 비용이 청구되는 합리적인 구조입니다.

비용 절약 팁: 개발 단계에서는 무료 크레딧을 활용해 API 연동 테스트를 충분히 수행한 뒤 유료 전환을 고려하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 가입 시 5달러 상당의 무료 크레딧을 제공하여 개발 단계에서 충분한 API 연동 테스트를 진행할 수 있습니다. 무료 플랜의 구체적인 만료 기한은 공식 요금 페이지에서 확인이 필요합니다.

- **종량제 플랜** (사용량 기반 (정확한 금액은 공식 요금 페이지 확인 필요)): 화상회의 봇 생성 및 실시간 텍스트 변환, 스트리밍 사용량에 따라 비용이 청구되는 합리적인 구조입니다.

- **기업용 맞춤 플랜** (별도 문의 (정확한 금액은 공식 요금 페이지 확인 필요)): 대규모 회의 데이터 처리와 기업 고객을 위한 전담 기술 지원 및 맞춤형 인프라를 제공합니다.

**환불과 해지**: 사용량 기반 과금 시스템의 환불 및 결제 수단 변경에 대한 상세 정책은 공식 홈페이지의 이용약관 및 결제 페이지를 참고해야 합니다.

## 한국어 지원

현재 서비스 인터페이스와 API 문서는 영어로 제공됩니다. 다만, 처리된 회의 텍스트 데이터는 한국어를 포함한 다국어를 지원합니다.

## 한국어 품질 실측

**한국어 회의 녹취**

- 프롬프트: API를 통해 수집된 한국어 화상회의 오디오 데이터를 실시간 텍스트로 변환합니다.
- 결과 예시: 참가자 1: 이번 주 프로젝트 진행 상황를 공유해 주세요. 참가자 2: 디자인 시안 검토가 완료되어 개발을 시작할 수 있습니다.
- 관찰: 다국어 텍스트 데이터 처리는 지원하나, 서비스 인터페이스와 API 문서는 영어로 제공됩니다.

**회의록 요약 연동**

- 프롬프트: 변환된 회의 텍스트를 AI 모델로 전달하여 주요 안건과 액션 아이템을 추출합니다.
- 결과 예시: 1. 주요 안건: 디자인 시안 최종 확정. 2. 액션 아이템: 개발 팀은 오늘 오후까지 API 연동 테스트 완료하기.
- 관찰: 한국어 내용 자체는 외부 AI 에이전트로 자연스럽게 요약될 수 있습니다.

서비스 자체의 인터페이스와 도큐먼트는 영어를 기준으로 하지만 회의 과정에서 오고 간 한국어 텍스트 변환 데이터는 정상적으로 수집 및 처리됩니다. 개발자가 직접 한국어 처리 파이프라인을 구축할 때 유용하게 활용할 수 있습니다.

## 이런 분에게 추천합니다

자체 AI 회의 비서 서비스를 개발 중인 개발자에게 추천합니다. 또한 화상회의 데이터를 자동화 시스템에 연동하려는 기업형 서비스 운영자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 AI 회의 요약 서비스를 구축하여 팀원들이 회의록 작성 부담 없이 업무에 집중하도록 돕습니다.
- **학생**: 온라인 강의 내용을 자동으로 텍스트화하여 나중에 복습할 수 있는 개인 학습 보조 툴을 만듭니다.
- **소상공인**: 고객 상담 화상회의 내용을 자동으로 녹취하고 데이터화하여 고객 관리 및 서비스 개선에 활용합니다.

## 장단점

**장점**

- 줌, 구글 미트, 마이크로소프트 팀즈 등 주요 화상회의 플랫폼을 단 하나의 API로 통합하여 간편하게 관리할 수 있습니다.
- 회의 내용을 지연 없이 실시간으로 텍스트화하고 오디오 및 비디오 데이터를 외부 AI 모델로 즉시 전송할 수 있습니다.
- 가입 시 무료 크레딧을 제공하므로 복잡한 결제 없이도 개발 단계에서 충분한 사전 테스트를 진행할 수 있습니다.
- 화상회의 봇 인프라 구축에 소요되는 시간과 리소스를 크게 줄여 개발자가 AI 에이전트 핵심 로직에 집중할 수 있습니다.

**단점**

- 개발자용 API 서비스 특성상 일반 사용자는 직접 활용하기 어렵고 프로그래밍 지식이 필수적으로 요구됩니다.
- 웹 인터페이스와 API 문서가 모두 영어로 제공되어 국내 개발자가 처음 접할 때 진입장벽이 존재합니다.
- 사용량 기반의 종량제 과금 구조를 가지고 있어 대규모 회의를 빈번하게 처리할 경우 예상보다 비용이 증가할 수 있습니다.

## 주의사항

- **개인정보**: 화상회의 중 수집되는 음성 및 영상 데이터에는 민감한 개인정보나 기업 기밀이 포함될 수 있으므로 보안 정책을 철저히 검토해야 합니다.
- **저작권/상업적 이용**: 회의 녹화 및 텍스트 변환 데이터를 상업적으로 활용하거나 제3자에게 제공할 때는 참가자들의 사전 동의를 반드시 얻어야 합니다.
- **요금/한도**: 종량제 방식으로 운영되므로 API 호출 오류나 무한 반복 요청으로 인해 과도한 요금이 청구되지 않도록 사용량을 모니터링해야 합니다.
- **계정 관리**: 발급된 API 키가 외부로 유출되지 않도록 안전하게 관리하고 팀원 간 권한 설정을 철저히 분리하여 운영해야 합니다.

## 자주 묻는 질문

**일반인도 바로 사용할 수 있나요?**

아니요, 이 툴은 개발자를 위한 API 서비스입니다. 코딩 지식이 없는 일반 사용자가 사용하기에는 진입 장벽이 높습니다.

**어떤 화상회의 플랫폼을 지원하나요?**

현재 줌(Zoom), 구글 미트(Google Meet), 마이크로소프트 팀즈(Microsoft Teams)를 모두 지원하고 있습니다.

**무료 크레딧은 어떻게 사용하나요?**

회원가입 후 API 키를 발급받으면 자동으로 5달러 크레딧이 충전되며, 이를 API 호출 비용으로 사용할 수 있습니다.

**일반 직장인이나 학생도 이 도구를 바로 사용할 수 있나요?**

아니오, 이 서비스는 개발자를 위한 API 도구이므로 프로그래밍 코드 작성 능력이 필요합니다. 일반 사용자는 줌이나 구글 미트의 자체 녹화 기능이나 별도의 일반 회의록 요약 서비스를 이용하는 것이 적합합니다.

**어떤 화상회의 플랫폼을 지원하나요?**

줌(Zoom), 구글 미트(Google Meet), 마이크로소프트 팀즈(Microsoft Teams)를 하나의 API로 통합하여 지원합니다. 회의에 자동으로 참여하는 봇을 생성하여 데이터를 수집할 수 있습니다.

**무료 크레딧은 어떻게 사용할 수 있나요?**

회원가입 시 제공되는 5달러 상당의 무료 크레딧을 통해 API 연동 및 테스트를 비용 부담 없이 진행할 수 있습니다. 소진 후에는 종량제 플랜으로 전환하여 계속 이용할 수 있습니다.

**한국어 회의 내용도 텍스트로 변환할 수 있나요?**

네, 회의 중 오고 간 한국어 오디오 데이터를 텍스트로 변환하는 처리가 가능합니다. 다만 서비스 가이드와 대시보드는 영어로 제공되므로 API 연동 시 참고가 필요합니다.
