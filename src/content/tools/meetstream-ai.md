## 한줄 요약

MeetStream AI는 화상회의 플랫폼과 연동하여 회의 내용을 자동으로 녹화, 스트리밍, 텍스트 변환을 수행하는 API 서비스입니다. 개발자가 복잡한 연동 과정 없이 화상회의 데이터를 AI 에이전트에 즉시 활용하는 데 도움이 되습니다.

## 핵심 기능

- **통합 API**: 줌, 구글 미트, 팀즈를 하나의 API로 통합 관리하여 개발 효율을 높입니다.
- **실시간 녹취**: 회의 내용을 지연 없이 텍스트로 변환하여 실시간 데이터 처리가 가능합니다.
- **스트리밍 지원**: 회의 오디오와 비디오 데이터를 외부 AI 모델로 즉시 전송할 수 있습니다.

## 가격 정책

- **무료 플랜**: 가입 시 5달러(약 6,500원) 상당의 무료 크레딧을 제공합니다.
- **유료 플랜**: 종량제(Pay-as-you-go) 방식이며, 사용량에 따라 비용이 청구되는 합리적인 구조입니다.

비용 절약 팁: 개발 단계에서는 무료 크레딧을 활용해 API 연동 테스트를 충분히 수행한 뒤 유료 전환을 고려하십시오.

## 한국어 지원

현재 서비스 인터페이스와 API 문서는 영어로 제공됩니다. 다만, 처리된 회의 텍스트 데이터는 한국어를 포함한 다국어를 지원합니다.

## 이런 분에게 추천합니다

자체 AI 회의 비서 서비스를 개발 중인 개발자에게 추천합니다. 또한 화상회의 데이터를 자동화 시스템에 연동하려는 기업형 서비스 운영자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 AI 회의 요약 서비스를 구축하여 팀원들이 회의록 작성 부담 없이 업무에 집중하도록 돕습니다.
- **학생**: 온라인 강의 내용을 자동으로 텍스트화하여 나중에 복습할 수 있는 개인 학습 보조 툴을 만듭니다.
- **소상공인**: 고객 상담 화상회의 내용을 자동으로 녹취하고 데이터화하여 고객 관리 및 서비스 개선에 활용합니다.

## 유사 툴과 비교

**장점:**
- 다양한 플랫폼을 하나의 API로 통합 지원
- 실시간 스트리밍에 최적화된 성능

**단점:**
- 개발 지식이 필요한 API 형태라 일반 사용자가 직접 쓰기 어려움

**이런 분에게 가장 적합합니다:** 화상회의 데이터를 활용한 AI 에이전트 및 자동화 서비스 개발 시 가장 적합합니다.

## 자주 묻는 질문

**일반인도 바로 사용할 수 있나요?**

아니요, 이 툴은 개발자를 위한 API 서비스입니다. 코딩 지식이 없는 일반 사용자가 사용하기에는 진입 장벽이 높습니다.

**어떤 화상회의 플랫폼을 지원하나요?**

현재 줌(Zoom), 구글 미트(Google Meet), 마이크로소프트 팀즈(Microsoft Teams)를 모두 지원하고 있습니다.

**무료 크레딧은 어떻게 사용하나요?**

회원가입 후 API 키를 발급받으면 자동으로 5달러 크레딧이 충전되며, 이를 API 호출 비용으로 사용할 수 있습니다.
