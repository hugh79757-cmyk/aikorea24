## 한줄 요약

Atomic Mail Agentic은 AI 에이전트가 독립적으로 이메일을 읽고, 보내며 반응할 수 있는 서비스입니다. 이로 업무 효율성을 높일 수 있습니다.

## 핵심 기능

- **자동 이메일 관리**: AI가 이메일을 자동으로 관리하여 시간을 절약합니다.
- **독립 실행**: 인간의 개입 없이 AI가 스스로 작업을 수행합니다.
- **간편한 설정**: 복잡한 설정 없이 쉽게 사용할 수 있습니다.

## 사용법

**1. 에이전트 이메일 등록**

터미널 환경에서 npx 명령어로 에이전트 계정을 생성하고 사용자 이름을 지정합니다. 신용카드나 복잡한 도메인 설정 없이 즉시 실제 이메일 주소를 발급받을 수 있습니다.

**2. API 또는 MCP 연동**

JMAP 프로토콜이나 MCP 설정을 활용하여 AI 에이전트가 이메일 송수신 기능을 수행할 수 있도록 연결합니다. Claude Desktop이나 Cursor 등 사용 중인 에이전트 도구에 맞춰 코드를 입력합니다.

**3. 이메일 작업 명령**

에이전트에게 뉴스레터 구독, 이메일 확인, 자동 답변 작성 등의 구체적인 임무를 지시합니다. 에이전트는 독립적으로 받은편지함을 모니터링하고 피드백을 처리합니다.

**4. 오류 디버깅 및 모니터링**

API 요청 중 오류가 발생할 경우 제공되는 명확한 평문 힌트를 참고하여 에이전트가 스스로 코드를 수정하도록 합니다. 작업 결과물과 평판 점수를 주기적으로 확인합니다.

## 가격 정책

- **무료 플랜**: 현재 무료 플랜이 제공되고 있습니다.
- **유료 플랜**: 유료 플랜 10만원/월부터 시작하며 추가 기능을 이용할 수 있습니다.

비용 절약 팁: 무료 플랜으로 기능을 시험해보고 필요에 따라 유료로 전환할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 서비스는 오픈 알파 상태로 100% 무료로 이용할 수 있습니다. 별도의 신용카드 등록 없이 에이전트용 실제 이메일함을 생성하고 테스트할 수 있습니다.

- **오픈 알파 플랜** (무료 (크롤링 텍스트 기준, 공식 요금 페이지 확인 필요)): 도메인 설정 없이 AI 에이전트용 이메일함 생성 및 JMAP, MCP 연동 기능을 제공합니다.

- **유료 플랜 (추후 도입)** (월 10만원 (제공된 수집값 기준)): 추가적인 확장 기능과 대규모 에이전트 관리를 위한 리소스를 제공할 수 있습니다.

**환불과 해지**: 현재 오픈 알파 무료 기간으로 운영되고 있으며, 향후 유료 플랜 전환 시의 환불 및 해지 정책은 공식 웹사이트로 확인해야 합니다.

## 한국어 지원

한국어 지원이 가능하여 한국 사용자들이 쉽게 접근할 수 있습니다.

## 한국어 품질 실측

**뉴스레터 자동 요약**

- 프롬프트: 구독한 산업 뉴스레터들을 읽고 내 관심사에 맞는 내용만 추려서 하루에 한 번 요약해 줘.
- 결과 예시: 에이전트가 메일함에 도착한 뉴스레터를 분석하여 사용자가 지정한 관심사 키워드와 일치하는 핵심 정보만 모아 일일 요약본 형태로 제공합니다.
- 관찰: AI 에이전트가 이메일 API와 연동하여 한국어 뉴스레터를 자연스럽게 분류하고 요약하는지 점검합니다.

**지원서 자동 발송**

- 프롬프트: 구직 사이트의 채용 공고를 찾아서 맞춤형 이력서를 작성하고 내 메일함에서 바로 발송해 줘.
- 결과 예시: 에이전트가 독립적인 메일함을 이용해 채용 담당자에게 지원 메일을 발송하고 이후 답장을 모니터링하여 유의미한 회신만 사용자에게 전달합니다.
- 관찰: 한국어 구직 공고 맥락을 이해하고 적절한 비즈니스 톤으로 이메일을 작성할 수 있는지 확인합니다.

개발자 중심의 도구 특성상 인터페이스는 영어 위주로 구성되어 있으나, 연동된 LLM(예: Claude 등)을 통해 한국어 이메일 작성 및 요약 작업을 원활하게 처리할 수 있습니다.

## 장단점

**장점**

- 신용카드나 신원 인증 없이 AI 에이전트 전용 이메일 주소를 즉시 생성할 수 있습니다.
- 표준 JMAP 및 REST API를 지원하여 복잡한 벤더 SDK 없이 LLM이 직접 연동하기 편리합니다.
- API 에러 발생 시 명확한 평문 힌트를 제공하여 에이전트가 스스로 오류를 디버깅할 수 있습니다.
- 작업 성공률에 따라 평판 점수가 부여되어 보안성과 신뢰성을 체계적으로 관리합니다.

**단점**

- 일반적인 사용자용 웹메일이 아닌 개발자 및 AI 에이전트 전용 API 서비스여서 진입 장벽이 높습니다.
- 현재 오픈 알파 단계로 제공되며 향후 정식 유료화 시 가격 변동 가능성이 존재합니다.
- 그래픽 사용자 인터페이스(GUI)보다는 터미널 및 코드 기반 설정이 필수적입니다.

## 주의사항

- **개인정보**: AI 에이전트가 독립적인 이메일함을 관리하므로, 민감한 개인정보나 기밀 데이터가 외부 에이전트나 LLM에 노출되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 에이전트로 자동으로 수집하고 발송하는 뉴스레터나 이메일 콘텐츠의 저작권 및 상업적 활용 규정을 준수해야 합니다.
- **요금/한도**: 현재는 오픈 알파로 무료 제공되나 추후 유료 플랜 이용 시 정확한 비용과 API 호출 한도를 공식 페이지에서 반드시 확인해야 합니다.
- **계정 관리**: 에이전트가 자율적으로 메일을 송수신하므로 비정상적인 메일 발송이나 스팸으로 오인되지 않도록 평판 점수와 작동 상태를 수시로 점검해야 합니다.

## 자주 묻는 질문

**Atomic Mail Agentic은 어떻게 작동하나요?**

AI 에이전트가 이메일을 자동으로 관리하며 사용자가 설정한 규칙에 따라 작업을 수행합니다.

**무료 플랜의 기능은 무엇인가요?**

무료 플랜에서는 기본적인 이메일 관리 기능을 제공하며 추가 기능은 유료 플랜에서 이용할 수 있습니다.

**어떻게 시작하나요?**

웹사이트에 접속하여 계정을 만들고, 제공되는 가이드를 따라 설정하면 됩니다.

**인간의 개입 없이 AI 에이전트가 정말 혼자서 이메일을 만들 수 있나요?**

네, 크롤링 내용에 따르면 신용카드나 도메인 설정 없이 API 요청을 통해 에이전트가 실시간으로 실제 이메일함을 생성하고 즉시 업무를 시작할 수 있습니다.

**어떤 AI 에이전트와 도구들을 지원하나요?**

Claude, Hermes, LangGraph, Autogen Studio, ChatGPT, CrewAI 등 다양한 에이전트와 MCP(Model Context Protocol) 및 AgentSkill을 지원하는 환경에서 사용 가능합니다.

**에이전트가 API 오류를 내면 어떻게 해결하나요?**

이 서비스는 LLM 오류 복구에 특화되어 있어서, API 에러 발생 시 명확한 평문 힌트를 반환하여 에이전트가 스스로 요청을 수정하고 디버깅할 수 있습니다.

**일반 사용자도 웹 브라우저에서 쉽게 쓸 수 있나요?**

이 서비스는 주로 개발자와 AI 에이전트 연동을 위한 API 제품이므로, 터미널 명령어와 MCP 설정 등 기본적인 개발 지식이 필요합니다.
