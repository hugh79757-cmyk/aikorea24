## 한줄 요약

BaseTab AI는 매번 새 탭을 열 때마다 마주하는 빈 화면을 AI 작업 공간으로 바꿔줍니다. 웹 서핑 중 즉시 질문하고 메모하며 필요한 정보를 바로 정리할 수 있어 업무 흐름이 끊기지 않습니다.

## 핵심 기능

- **AI 챗봇 통합**: 새 탭에서 바로 AI와 대화하며 궁금한 점을 즉시 해결할 수 있습니다.
- **빠른 메모 기능**: 웹 서핑 중 떠오르는 아이디어를 즉시 기록하고 저장할 수 있습니다.
- **맞춤형 작업 공간**: 사용자 취향에 맞게 레이아웃을 설정하여 업무 집중도를 높여줍니다.

## 사용법

**1. 확장 프로그램 설치**

웹 브라우저의 확장 프로그램 스토어에서 BaseTab AI를 검색하여 설치합니다. 설치가 완료되면 브라우저의 새 탭을 열 때마다 자동 실행됩니다.

**2. AI 챗봇 실행**

새 탭 중앙에 위치한 입력창에 원하는 질문을 입력합니다. 엔터키를 누르면 별도의 사이트 이동 없이 즉시 AI의 답변을 확인할 수 있습니다.

**3. 메모 기능 활용**

화면 한쪽에 제공되는 메모장 아이콘을 클릭하여 내용을 적습니다. 웹 서핑 중 떠오르는 아이디어를 즉시 기록하고 보관할 수 있습니다.

**4. 레이아웃 설정**

설정 메뉴에서 배경 이미지나 위젯 배치를 변경합니다. 사용자의 업무 스타일과 취향에 맞게 작업 공간을 최적화할 수 있습니다.

사용자의 입력 데이터는 보안 정책에 따라 처리되며, 민감한 개인 정보는 입력하지 않는 것을 권장합니다. 일반적인 업무 보조 용도로는 충분히 안전하게 설계되어 있습니다.

**모든 브라우저에서 사용할 수 있나요?**

주로 크롬(Chrome) 및 엣지(Edge)와 같은 크로미움 기반 브라우저 확장 프로그램으로 제공됩니다. 설치 전 사용 중인 브라우저의 확장 프로그램 스토어를 확인해 주세요.

**무료 버전으로도 충분한가요?**

일반적인 검색 보조나 간단한 메모, 글쓰기 용도로는 무료 버전으로도 충분히 훌륭한 성능을 발휘합니다. 더 긴 문맥 처리나 빠른 응답이 필요할 때 유료 플랜을 고려하세요.

**무료 플랜으로도 충분히 업무가 가능한가요?**

기본적인 채팅과 메모 기능은 충분히 활용 가능합니다. 다만, 더 빠른 응답과 고급 기능을 원하신다면 유료 전환을 고려해 보시기 바랍니다.

**브라우저 속도가 느려지지는 않나요?**

일반적인 사용 환경에서는 큰 영향이 없으나, 브라우저에 너무 많은 확장 프로그램을 설치할 경우 속도 저하가 발생할 수 있습니다.

**한국어 질문을 해도 잘 알아듣나요?**

네, 한국어 질문을 완벽하게 이해하고 문맥에 맞는 자연스러운 답변을 제공합니다.

**메모한 내용은 어디에 저장되나요?**

사용자의 브라우저 로컬 환경이나 계정 동기화 설정을 통해 저장됩니다. 정확한 저장 방식은 설정 메뉴를 확인하시기 바랍니다.
