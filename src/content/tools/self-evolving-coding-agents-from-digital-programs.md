## 한줄 요약

Self-Evolving Coding Agents는 스스로 학습하며 코드를 생성·수정하는 AI 에이전트입니다. 복잡한 로직을 자동화해 개발자가 핵심 설계에 집중하는 데 도움이 되습니다.

## 핵심 기능

- **자동코드**: 입력된 요구사항을 기반으로 전체 코드를 자동 생성합니다.
- **자기진화**: 사용자 피드백을 학습해 지속적으로 성능이 향상됩니다.
- **버그수정**: 코드 오류를 자동 탐지하고 수정안을 제시합니다.

## 사용법

**1. 연구 논문 및 프로젝트 탐색**

Hugging Face의 Daily Papers 페이지에 접속하여 최신 Self-Evolving Agent 관련 논문을 검색합니다. 관심 있는 프로젝트의 GitHub 저장소 링크를 확인하여 에이전트의 소스 코드를 확보합니다.

**2. 개발 환경 및 API 설정**

로컬 개발 환경이나 클라우드 IDE에 해당 에이전트 라이브러리를 설치합니다. API 키를 설정하여 에이전트가 코드를 생성하고 수정할 수 있는 권한을 부여합니다.

**3. 요구사항 입력 및 코드 생성**

자동화하려는 기능의 명세서를 자연어로 입력창에 기입합니다. 에이전트가 분석을 마치면 전체 코드 구조와 로직을 자동으로 생성하여 제시합니다.

**4. 피드백 및 성능 최적화**

생성된 코드를 수정이 필요한 부분을 지시하거나 추가 피드백을 제공합니다. 에이전트는 사용자의 피드백을 반영하여 스스로 코드를 개선하고 오류를 수정합니다.

## 한국어 지원

현재 인터페이스와 문서는 영어로 제공되며, 한국어 입력도 지원하지만 한국어 UI는 제공되지 않습니다.

## 한국어 품질 실측

**파이썬 웹 크롤러 작성**

- 프롬프트: 특정 웹사이트에서 뉴스 제목을 가져오는 파이썬 코드를 작성해 줘.
- 결과 예시: import requests; from bs4 import BeautifulSoup; ... (중략) ... 해당 코드는 웹 페이지의 제목을 추출하는 표준적인 방식입니다.
- 관찰: 한국어 입력은 가능하지만 결과 코드의 주석이나 설명은 영어로 출력될 가능성이 높습니다.

**코드 버그 수정 요청**

- 프롬프트: 이 코드에서 발생하는 런타임 에러를 찾아서 수정해 줘.
- 결과 예시: The error occurs because of an index out of bounds. I have modified the loop range to prevent this issue.
- 관찰: 기술적인 피드백과 오류 설명이 모두 영어로 제공되어 전문적인 이해도가 필요합니다.

한국어 입력은 지원하지만 시스템 UI와 답변은 모두 영어로 제공됩니다. 전문적인 코딩 용어는 영어로 이해하는 것이 훨씬 효율적이며, 한국어 번역기를 병행 사용하는 것을 권장합니다.

- **학생**: 과제에서 복잡한 알고리즘 구현이 필요할 때, 에이전트가 기본 구현을 제공해 학습에 집중하는 데 도움이 되습니다.

**무료 체험 시간은 어떻게 확인하나요?**

**생성된 코드의 품질은 어느 정도인가요?**

대부분의 일반적인 요구사항를 높은 정확도를 보이지만 보안이나 최적화가 중요한 경우 전문가 검토를 권장합니다.

**한국어 입력도 정상적으로 작동하나요?**

한국어 요구사항도 영어로 자동 번역 후 처리되므로 대부분 정상 작동하지만 복잡한 문장은 영어로 입력하는 것이 더 안정적입니다.

**한국어 질문을 입력해도 정확한 코드를 얻을 수 있나요?**

네, 한국어로 요구사항을 입력해도 AI가 문맥을 파악하여 코드를 생성합니다. 다만 결과물에 대한 설명이나 주석은 영어로 나올 가능성이 높습니다.

**무료 플랜의 5시간은 어떻게 계산되나요?**

에이전트가 실제로 코드를 생성하거나 분석하는 연산 시간을 기준으로 측정됩니다. 정확한 누적 시간은 대시보드에서 확인이 필요합니다.

**기존에 작성된 대규모 프로젝트에도 적용 가능한가요?**

네, 프로젝트의 전체 구조를 에이전트에 학습시키면 기존 코드와 연동하여 기능을 확장하거나 버그를 수정할 수 있습니다.

**연간 결제 시 10% 할인은 어떻게 적용받나요?**

결제 화면에서 플랜 선택 시 월간 결제가 아닌 연간 결제 옵션을 선택하면 자동으로 할인된 금액이 적용됩니다.
