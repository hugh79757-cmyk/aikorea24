## 한줄 요약

앤트로픽의 개발자용 CLI 도구인 'Claude Code'의 사용 요금을 오프라인에서 실시간으로 계산해 주는 편리한 유틸리티입니다. 외부 API 호출 없이 로컬 로그만으로 작동하여 보안 우려가 없으며, 예상치 못한 API 비용 폭탄을 방지하도록 돕습니다.

## 핵심 기능

- **오프라인 계산**: 인터넷 연결 없이 로컬에서 안전하게 비용을 분석합니다.
- **무의존성 실행**: 추가 라이브러리 설치 없이 즉시 실행되어 가볍습니다.
- **소급 비용 추적**: 이전 세션의 로그까지 모두 찾아내어 누적 비용을 보여줍니다.

## 사용법

**1. 깃허브 저장소 방문하기**

웹브라우저를 열고 aitechexplore/claudebill 공식 깃허브 페이지에 접속합니다. 화면에 안내된 소스 코드와 설명서를 확인하여 도구의 기본 구조를 파악할 수 있습니다.

**2. 로컬 환경에 도구 다운로드**

터미널이나 명령 프롬프트를 사용하여 해당 레포지토리를 사용자의 컴퓨터에 클론하거나 필요한 파일을 다운로드합니다. 추가적인 복잡한 라이브러리 설치 과정 없이 바로 실행할 수 있는 구조로 제공됩니다.

**3. Claude Code 로그 확인**

사용자의 컴퓨터에 저장된 Claude Code의 로컬 로그 파일 위치를 확인합니다. 이 도구는 별도의 외부 서버 통신 없이 오직 내 PC에 남아 있는 로그 기록만을 보고 비용을 읽어냅니다.

**4. 비용 계산 실행하기**

터미널 명령어를 입력하여 claudebill을 실행하면 이전 세션에서 사용한 토큰 양과 총 비용이 화면에 나타납니다. 이로 예상치 못한 API 청구 폭탄을 사전에 방지하고 비용을 효과적으로 관리할 수 있습니다.

## 가격 정책

- **무료 플랜**: 오픈소스 도구로 깃허브에서 누구나 무료로 다운로드하여 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 존재하지 않으며 모든 기능을 제한 없이 평생 무료로 제공합니다.

비용 절약 팁: 무료 도구이므로 Claude Code를 실행하기 전에 항상 설치해 두시면 비용 관리에 큰 도움이 됩니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: MIT 라이선스를 따르는 오픈소스 도구로서 사용 횟수나 토큰 분석량에 대한 제한이 전혀 없습니다. 모든 기능을 평생 무료로 제약 없이 다운로드하여 활용할 수 있습니다.

- **무료 오픈소스 플랜** (무료 (0원)): 깃허브로 소스 코드를 제공하며 모든 비용 계산 기능을 제한 없이 무료로 사용합니다.

- **유료 플랜 없음** (공식 페이지 확인 필요): 현재 별도의 유료 구독 상품이나 추가 결제 플랜은 존재하지 않습니다.

**환불과 해지**: 비용을 지불하고 이용하는 유료 서비스가 아니므로 환불이나 구독 해지 절차가 필요하지 않습니다.

## 한국어 지원

공식적으로 한국어를 지원하지 않지만 터미널 명령어 기반의 단순한 도구이므로 영어에 익숙하지 않은 분들도 숫자와 달러 표시로 쉽게 이해하실 수 있습니다.

## 한국어 품질 실측

**비용 로그 확인**

- 프롬프트: claudebill을 실행하여 지난 작업 세션의 사용 요금을 한국어로 조회해 줘.
- 결과 예시: 이 도구는 터미널 기반의 CLI 유틸리티이므로 한글 프롬프트 입력 대신 영어 명령어 형태로 실행됩니다. 실행 결과 출력 화면에는 사용된 달러($) 금액과 토큰 수치가 숫자 위주로 깔끔하게 표시됩니다.
- 관찰: 공식 한국어 안내는 제공되지 않으나 출력되는 데이터가 주로 숫자와 통화 기호여서 직관적입니다.

**누적 요금 분석**

- 프롬프트: 이번 주에 개발 작업으로 발생한 API 총비용을 계산해 줘.
- 결과 예시: 로컬에 저장된 로그를 스캔하여 소급 추적된 총비용이 대시보드나 텍스트 형태로 출력됩니다. 영어 메뉴로 구성되어 있으나 개발 업무에 익숙한 사용자라면 쉽게 파악할 수 있는 수준입니다.
- 관찰: 전문적인 개발 용어가 포함되어 있으나 직장인과 개발자가 자주 쓰는 영어 단어 중심이라 이해하기 어렵지 않습니다.

공식적인 한국어 인터페이스를 지원하지 않지만 터미널 명령어와 숫자 중심의 결과값 덕분에 국내 개발자와 직장인도 큰 무리 없이 활용할 수 있습니다.

## 이런 분에게 추천합니다

Claude Code CLI를 자주 사용하는 개발자분들에게 추천합니다.
API 사용 요금이 얼마나 나올지 불안한 1인 창업자나 학생 개발자분들에게 적합합니다.

## 실제 활용 예시

- **직장인**: 회사 프로젝트에서 Claude Code를 도입한 후, 일일 API 사용량을 보고하기 위해 claudebill을 실행하여 정확한 달러 비용을 산출해 보고서에 첨부합니다.
- **학생**: 개인 토이 프로젝트를 진행하면서 API 요금이 초과되지 않도록 코딩 세션이 끝날 때마다 비용을 체크하며 알뜰하게 개발을 진행합니다.
- **소상공인**: 외주 개발을 맡기거나 직접 간단한 쇼핑몰 웹사이트를 수정할 때, 인공지능 코딩 도구의 실시간 소모 비용을 확인하여 예산 범위 내에서 개발을 통제합니다.

## 장단점

**장점**

- 인터넷 연결이 전혀 필요 없는 오프라인 환경에서 안전하게 비용을 분석할 수 있습니다.
- 추가 라이브러리를 복잡하게 설치할 필요가 없어 가볍고 빠르게 실행할 수 있습니다.
- 이전 작업 세션의 로그까지 모두 찾아내어 누적 비용을 정확하게 추적해 줍니다.
- 오픈소스 프로젝트로 제공되어 누구나 비용 부담 없이 평생 무료로 이용 가능합니다.

**단점**

- 초보자에게는 낯설 수 있는 터미널 명령어 기반으로 작동하여 진입 장벽이 다소 있습니다.
- 공식적인 한국어 인터페이스를 지원하지 않아 영어 화면에 익숙해져야 합니다.
- 그래픽 사용자 인터페이스(GUI)가 부재하여 시각적인 통계 확인이 제한적일 수 있습니다.

## 주의사항

- **개인정보**: 로컬 로그 파일만을 활용해 오프라인에서 작동하므로 사용자의 민감한 소스 코드나 개인정보가 외부 서버로 유출될 염려가 없습니다.
- **저작권/상업적 이용**: MIT 라이선스 조건 하에 제공되므로 오픈소스 약관을 준수하는 범위 내에서 자유롭게 활용할 수 있습니다.
- **요금/한도**: 도구 자체는 완전 무료이지만 이 도구가 분석하는 Claude Code 자체의 API 사용 요금은 앤트로픽 정책에 따라 부과되므로 주의가 필요합니다.
- **계정 관리**: 깃허브 계정로 소스 코드를 내려받고 업데이트를 관리해야 하므로 정기적인 레포지토리 확인이 권장됩니다.

## 자주 묻는 질문

**이 도구를 사용하려면 Claude API 키를 입력해야 하나요?**

아니요, API 키는 전혀 필요하지 않습니다. claudebill은 로컬 컴퓨터에 저장된 Claude Code의 세션 로그 파일만을 분석하여 비용을 계산하므로 개인정보나 API 키 유출 우려가 전혀 없습니다.

**인터넷이 연결되지 않은 상태에서도 작동하나요?**

네, 완벽하게 작동합니다. 오프라인 상태에서 로컬 로그 데이터를 기반으로 작동하도록 설계되어 있어, 언제 어디서나 즉시 비용을 확인할 수 있습니다.

**설치 방법이 복잡하지는 않은가요?**

깃허브 저장소에 안내된 간단한 터미널 명령어 한 줄만 입력하면 바로 설치하여 사용할 수 있습니다. 별도의 복잡한 환경 설정이나 의존성 패키지 설치가 필요 없어 초보 개발자분들도 쉽게 시작하실 수 있습니다.

**인터넷이 안 되는 환경에서도 비용 계산이 가능한가요?**

네, 그렇습니다. 이 도구는 완전한 오프라인 환경에서 사용자의 로컬 로그 파일만을 읽어와 계산하므로 인터넷 연결이 전혀 필요하지 않습니다.

**Claude Code를 사용하지 않아도 이 도구를 쓸 수 있나요?**

아니오, 이 도구는 Claude Code 세션에서 생성된 로그를 분석하는 용도로 특화되어 있어 해당 환경이 구축되어 있어야 정상적으로 작동합니다.

**이 도구를 사용하면 Claude Code 이용 요금이 할인되나요?**

아니오, 요금을 직접 할인해 주는 기능은 없습니다. 다만 현재까지 발생한 비용을 미리 파악하게 해 주어 요금 폭탄을 사전에 방지하도록 돕습니다.

**설치할 때 복잡한 추가 프로그램을 깔아야 하나요?**

아니오, 무의존성 실행을 지향하여 별도의 복잡한 외부 라이브러리 설치 없이 가볍고 빠르게 바로 실행할 수 있도록 제작되었습니다.
