## 한줄 요약

앤트로픽의 개발자용 CLI 도구인 'Claude Code'의 사용 요금을 오프라인에서 실시간으로 계산해 주는 편리한 유틸리티입니다. 외부 API 호출 없이 로컬 로그만으로 작동하여 보안 우려가 없으며, 예상치 못한 API 비용 폭탄을 방지하도록 돕습니다.

## 핵심 기능

- **오프라인 계산**: 인터넷 연결 없이 로컬에서 안전하게 비용을 분석합니다.
- **무의존성 실행**: 추가 라이브러리 설치 없이 즉시 실행되어 가볍습니다.
- **소급 비용 추적**: 이전 세션의 로그까지 모두 찾아내어 누적 비용을 보여줍니다.

## 가격 정책

- **무료 플랜**: 오픈소스 도구로 깃허브에서 누구나 무료로 다운로드하여 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 존재하지 않으며 모든 기능을 제한 없이 평생 무료로 제공합니다.

비용 절약 팁: 무료 도구이므로 Claude Code를 실행하기 전에 항상 설치해 두시면 비용 관리에 큰 도움이 됩니다.

## 한국어 지원

공식적으로 한국어를 지원하지 않지만 터미널 명령어 기반의 단순한 도구이므로 영어에 익숙하지 않은 분들도 숫자와 달러 표시로 쉽게 이해하실 수 있습니다.

## 이런 분에게 추천합니다

Claude Code CLI를 자주 사용하는 개발자분들에게 추천합니다.
API 사용 요금이 얼마나 나올지 불안한 1인 창업자나 학생 개발자분들에게 적합합니다.

## 실제 활용 예시

- **직장인**: 회사 프로젝트에서 Claude Code를 도입한 후, 일일 API 사용량을 보고하기 위해 claudebill을 실행하여 정확한 달러 비용을 산출해 보고서에 첨부합니다.
- **학생**: 개인 토이 프로젝트를 진행하면서 API 요금이 초과되지 않도록 코딩 세션이 끝날 때마다 비용을 체크하며 알뜰하게 개발을 진행합니다.
- **소상공인**: 외주 개발을 맡기거나 직접 간단한 쇼핑몰 웹사이트를 수정할 때, 인공지능 코딩 도구의 실시간 소모 비용을 확인하여 예산 범위 내에서 개발을 통제합니다.

## 유사 툴과 비교

**장점:**
- 인터넷 연결이나 API 키 입력이 필요 없어 보안상 매우 안전합니다.
- 설치가 간편하고 가벼우며 이전 세션 기록까지 완벽하게 추적합니다.

**단점:**
- Claude Code 이외의 다른 AI API 비용은 계산할 수 없습니다.

**이런 분에게 가장 적합합니다:** Claude Code를 사용하면서 API 요금 폭탄이 걱정되어 실시간으로 비용을 모니터링하고 싶을 때 가장 적합합니다.

## 자주 묻는 질문

**이 도구를 사용하려면 Claude API 키를 입력해야 하나요?**

아니요, API 키는 전혀 필요하지 않습니다. claudebill은 로컬 컴퓨터에 저장된 Claude Code의 세션 로그 파일만을 분석하여 비용을 계산하므로 개인정보나 API 키 유출 우려가 전혀 없습니다.

**인터넷이 연결되지 않은 상태에서도 작동하나요?**

네, 완벽하게 작동합니다. 오프라인 상태에서 로컬 로그 데이터를 기반으로 작동하도록 설계되어 있어, 언제 어디서나 즉시 비용을 확인할 수 있습니다.

**설치 방법이 복잡하지는 않은가요?**

깃허브 저장소에 안내된 간단한 터미널 명령어 한 줄만 입력하면 바로 설치하여 사용할 수 있습니다. 별도의 복잡한 환경 설정이나 의존성 패키지 설치가 필요 없어 초보 개발자분들도 쉽게 시작하실 수 있습니다.
