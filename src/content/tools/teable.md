## 한줄 요약

Teable은 단순한 스프레드시트를 넘어 AI를 결합한 업무 자동화 플랫폼입니다. 흩어진 데이터를 한곳에 모으고 AI 워크플로우를 설계하여 반복적인 업무를 효율적으로 처리하도록 돕습니다.

## 핵심 기능

- **AI 워크플로우**: 데이터 입력 시 AI가 자동으로 분류하거나 요약하여 업무 시간을 단축합니다.
- **데이터 통합**: 여러 곳에 흩어진 비즈니스 데이터를 한곳으로 모아 체계적으로 관리합니다.
- **맞춤형 앱 구축**: 코딩 없이도 우리 팀에 딱 맞는 업무용 관리 앱을 쉽게 만들 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 데이터 관리와 협업 기능을 무료로 제공합니다.
- **유료 플랜**: Pro 플랜은 월 약 30,000원(25달러) 수준부터 시작하며 고급 자동화 기능과 데이터 용량을 제공합니다.

비용 절약 팁: 무료 플랜으로 핵심 기능을 먼저 테스트해 본 뒤, 팀 규모에 맞춰 유료 전환을 고려하는 것이 경제적입니다.

## 한국어 지원

현재 인터페이스는 영어로 제공되지만 데이터 입력이나 AI 프롬프트 작성 시 한국어를 문제없이 처리할 수 있습니다.

## 이런 분에게 추천합니다

반복적인 데이터 입력 업무에 지친 직장인, 체계적인 고객 관리가 필요한 소상공인, 데이터 기반의 효율적인 협업을 원하는 팀에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 들어오는 고객 문의를 엑셀에 정리하는 대신, Teable에 입력하여 AI가 자동으로 분류하고 우선순위를 정하게 하여 업무 효율을 높입니다.
- **학생**: 여러 논문에서 추출한 데이터를 Teable에 저장하고 AI를 활용해 연구 주제별로 정리하거나 요약된 인사이트를 도출합니다.
- **소상공인**: 매장 매출 데이터와 재고 현황을 Teable에 통합하여 관리하고 재고가 부족할 때 AI가 자동으로 발주 리스트를 작성하도록 설정합니다.

## 자주 묻는 질문

**기존 엑셀 파일도 불러올 수 있나요?**

네, 기존에 사용하시던 엑셀이나 CSV 파일을 간편하게 업로드하여 Teable의 데이터베이스로 전환할 수 있습니다.

**코딩을 전혀 못 해도 사용할 수 있나요?**

그렇습니다. Teable은 노코드(No-code) 기반으로 설계되어 있어 마우스 클릭과 간단한 설정만으로도 복잡한 자동화 기능을 구현할 수 있습니다.
