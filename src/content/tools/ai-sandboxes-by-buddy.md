## 한줄 요약

AI Sandboxes 개발 환경은 AI 코딩 에이전트가 생성한 코드를 실제 Linux 서버 환경에서 안전하게 구동하도록 돕습니다. 일회성 컨테이너가 아닌 지속 가능한 50GB 디스크와 외부 HTTPS 엔드포인트를 제공하여 실제 배포 환경과 동일하게 테스트할 수 있습니다.

## 핵심 기능

- **격리 가상머신**: 독립된 Linux 환경에서 안전하게 AI 코드를 실행합니다.
- **지속성 디스크**: 재부팅 후에도 50GB 데이터가 유지되어 편리합니다.
- **공용 엔드포인트**: 외부 테스트를 위한 HTTPS URL을 즉시 생성합니다.

## 사용법

**1. CLI 도구 설치 및 초기화**

Buddy CLI를 설치한 후 터미널에서 'bdy sb create' 명령어를 입력하여 새로운 가상 머신 환경을 생성합니다. 사용자 설정에 따라 Ubuntu 버전 등을 지정할 수 있습니다.

**2. 코드 업로드 및 환경 설정**

로컬에 작성된 코드를 'bdy sb cp' 명령어로 가상 머신 내부로 복사합니다. 이후 필요한 의존성 패키지를 설치하거나 앱 실행을 위한 설정을 진행합니다.

**3. 외부 접속 엔드포인트 생성**

외부 테스트하려고 'bdy sb ep add' 명령어를 사용하여 HTTPS 엔드포인트를 생성합니다. 이로 웹 브라우저에서 즉시 애플리케이션 접속이 가능합니다.

**4. 코드 실행 및 테스트**

'bdy sb exec' 명령어를 사용하여 테스트 스크립트를 실행하고 로그를 확인합니다. 테스트가 완료되면 스냅샷을 저장하거나 환경을 삭제하여 리소스를 관리합니다.

비용 절약 팁: AI 에이전트 테스트 시 사용하지 않는 엔드포인트를 정기적으로 삭제하면 비용을 절감할 수 있습니다.

## 한국어 지원

대시보드 및 공식 문서는 영문으로 제공됩니다. 다만, 일반적인 개발 커맨드라인(CLI) 기반이므로 한글 안내 없이도 한국 개발자가 쉽게 이용할 수 있습니다.

## 한국어 품질 실측

**웹 서버 구동 테스트**

- 프롬프트: npm start 명령어를 사용하여 노드 서버를 실행하고 외부에서 접속 가능한 URL을 생성해줘.
- 결과 예시: 가상 머신 내부에서 서버가 성공적으로 구동되며, https://task-42.eu-1.buddy.app과 같은 고유한 HTTPS 주소가 출력됩니다.
- 관찰: CLI 기반 도구이므로 결과값은 영문 위주로 출력되나, 개발자가 이해하기에 충분히 명확한 정보를 제공합니다.

**환경 스냅샷 생성**

- 프롬프트: 현재 설정된 환경을 'checkout-fixed'라는 이름으로 스냅샷 저장해줘.
- 결과 예시: 현재 상태가 성공적으로 저장되었다는 메시지와 함께, 이후 동일한 환경으로 즉시 복구할 수 있는 상태가 됩니다.
- 관찰: 명령어 실행 결과는 영어로 표시되지만 직관적인 결과 메시지로 한국인 개발자도 어렵지 않게 파악할 수 있습니다.

대시보드와 문서가 영문으로만 제공되지만 개발자에게 익숙한 CLI 명령어 위주로 운영되어 언어 장벽이 낮습니다. 전문적인 개발 환경을 다루므로 번역투보다는 기술적인 용어 처리가 중점입니다.

## 이런 분에게 추천합니다

AI 코딩 에이전트를 개발 중인 백엔드 엔지니어에게 추천합니다. 보안 걱정 없이 생성된 코드를 안전하게 검증하고 싶은 DevOps 담당자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 개발팀 사원으로 AI가 작성한 서버 스크립트의 작동 여부를 검증해야 하는 상황입니다. 회사 내부망에 영향을 주지 않고 AI Sandboxes 가상 환경에서 즉시 코드를 실행해 안전하게 테스트를 마쳤습니다.
- **학생**: 컴퓨터공학과 학생으로 캡스톤 디자인 프로젝트에서 AI 에이전트를 구축하고 있습니다. 제공된 SDK와 CLI를 활용해 AI가 자동으로 외부 URL 테스트까지 실행하는 파이프라인을 구축했습니다.
- **소상공인**: 1인 IT 창업자로 자체 AI 웹 서비스를 빠르게 프로토타이핑하려는 상황입니다. 별도 서버 설정 없이 샌드박스 엔드포인트로 클라이언트 반응을 즉시 확인할 수 있었습니다.

## 장단점

**장점**

- 일회성 컨테이너와 달리 50GB의 지속성 디스크를 제공하여 재부팅 후에도 데이터가 유지되는 환경을 지원합니다.
- 루트 권한을 포함한 실제 Linux 가상 머신을 제공하므로 Docker 실행 등 복잡한 설정도 자유롭게 수행할 수 있습니다.
- HTTPS 엔드포인트를 즉시 생성할 수 있어 AI가 작성한 코드를 외부에서 바로 테스트하고 검증하는 과정이 매우 효율적입니다.
- CLI, SDK, REST API 등 다양한 인터페이스를 지원하여 사용자의 개발 워크플로우에 맞춰 유연하게 통합할 수 있습니다.

**단점**

- 한국어 지원이 전혀 되지 않으므로 영문 대시보드와 기술 문서에 익숙하지 않은 초보 개발자에게는 진입 장벽이 높을 수 있습니다.
- 무료 플랜의 정확한 사용 한도가 명확하지 않아 상업적 용도로 대규모 테스트를 진행할 경우 비용 예측이 어려울 수 있습니다.
- 일반적인 클라우드 서비스보다 전문적인 리눅스 지식을 요구하여 가상 머신 관리에 대한 숙련도가 필수적입니다.

## 주의사항

- **개인정보**: 가상 머신 내부에 민감한 개인정보나 API 키를 저장할 경우 보안 관리에 각별히 유의해야 하며 공개 엔드포인트 노출을 주의하십시오.
- **저작권/상업적 이용**: 생성된 코드의 저작권은 사용자에게 있으나, 서비스 제공자의 인프라를 이용하는 만큼 서비스 이용 약관의 상업적 사용 범위를 준수해야 합니다.
- **요금/한도**: 사용하지 않는 엔드포인트나 가상 머신을 방치하면 불필요한 비용이 발생할 수 있으므로 테스트 종료 후에는 반드시 삭제하는 습관이 필요합니다.
- **계정 관리**: SSH 키 관리 등 계정 보안 설정은 사용자의 책임하에 이루어지며, 공유 환경에서 계정 정보가 유출되지 않도록 주의해야 합니다.

## 자주 묻는 질문

**기존 도커(Docker) 컨테이너 실행과 무엇이 다른가요?**

일반적인 일회성 컨테이너와 달리 재부팅 후에도 50GB의 디스크 데이터가 지속적으로 유지됩니다. 또한 루트 권한(sudo)과 외부 HTTPS 엔드포인트를 기본으로 제공하여 실제 가상 서버처럼 작동합니다.

**MCP(Model Context Protocol) 툴과도 직접 연결할 수 있나요?**

네, 지원합니다. Claude Desktop 등 MCP를 지원하는 AI 에이전트 클라이언트에서 직접 명령어를 수행하도록 샌드박스를 연동할 수 있습니다.

**한국어 안내 문서가 제공되나요?**

현재 모든 문서와 인터페이스는 영문으로 제공됩니다. 다만 명확한 명령어 구조를 가지고 있어 표준 CLI 환경에 익숙하시다면 사용에 무리가 없습니다.

**AI 에이전트 없이 수동으로도 사용할 수 있나요?**

네, AI 에이전트와 연동하는 것이 주 목적이지만, 일반적인 Linux 가상 머신처럼 CLI를 통해 직접 명령어를 입력하여 수동으로 개발 환경을 구축할 수 있습니다.

**재부팅 시 데이터가 정말 유지되나요?**

네, 50GB의 지속성 디스크를 제공하므로 가상 머신이 중지되거나 재시작되어도 저장된 파일과 설정값은 그대로 보존됩니다.

**도커(Docker)를 가상 머신 안에서 실행할 수 있나요?**

네, 루트 권한을 지원하므로 가상 머신 내부에 Docker를 설치하여 컨테이너를 실행하거나 복잡한 시스템 구성을 테스트하는 것이 가능합니다.

**비용을 절약하는 방법이 있나요?**

사용하지 않는 가상 머신과 외부 엔드포인트를 정기적으로 삭제하고, 리소스를 최적화하여 관리하면 불필요한 비용 발생을 최소화할 수 있습니다.
