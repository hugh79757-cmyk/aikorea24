## 한줄 요약

AI Sandboxes 개발 환경은 AI 코딩 에이전트가 생성한 코드를 실제 Linux 서버 환경에서 안전하게 구동하도록 돕습니다. 일회성 컨테이너가 아닌 지속 가능한 50GB 디스크와 외부 HTTPS 엔드포인트를 제공하여 실제 배포 환경과 동일하게 테스트할 수 있습니다.

## 핵심 기능

- **격리 가상머신**: 독립된 Linux 환경에서 안전하게 AI 코드를 실행합니다.
- **지속성 디스크**: 재부팅 후에도 50GB 데이터가 유지되어 편리합니다.
- **공용 엔드포인트**: 외부 테스트를 위한 HTTPS URL을 즉시 생성합니다.

## 가격 정책

- **무료 플랜**: 무료 체험을 위한 기본 스토리지 및 가상 머신 사용량이 제공됩니다.
- **유료 플랜**: Standard 플랜: 월 약 $20 (약 27,000원)부터 시작하며 확장 가능한 인프라를 제공합니다.

비용 절약 팁: AI 에이전트 테스트 시 사용하지 않는 엔드포인트를 정기적으로 삭제하면 비용을 절감할 수 있습니다.

## 한국어 지원

대시보드 및 공식 문서는 영문으로 제공됩니다. 다만, 일반적인 개발 커맨드라인(CLI) 기반이므로 한글 안내 없이도 한국 개발자가 쉽게 이용할 수 있습니다.

## 이런 분에게 추천합니다

AI 코딩 에이전트를 개발 중인 백엔드 엔지니어에게 추천합니다. 보안 걱정 없이 생성된 코드를 안전하게 검증하고 싶은 DevOps 담당자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 개발팀 사원으로 AI가 작성한 서버 스크립트의 작동 여부를 검증해야 하는 상황입니다. 회사 내부망에 영향을 주지 않고 AI Sandboxes 가상 환경에서 즉시 코드를 실행해 안전하게 테스트를 마쳤습니다.
- **학생**: 컴퓨터공학과 학생으로 캡스톤 디자인 프로젝트에서 AI 에이전트를 구축하고 있습니다. 제공된 SDK와 CLI를 활용해 AI가 자동으로 외부 URL 테스트까지 실행하는 파이프라인을 구축했습니다.
- **소상공인**: 1인 IT 창업자로 자체 AI 웹 서비스를 빠르게 프로토타이핑하려는 상황입니다. 별도 서버 설정 없이 샌드박스 엔드포인트로 클라이언트 반응을 즉시 확인할 수 있었습니다.

## 유사 툴과 비교

**장점:**
- 일회성 컨테이너가 아닌 50GB 데이터 보존 가상 머신 제공
- CLI, SDK, REST API 및 MCP 연동 지원으로 뛰어난 확장성

**단점:**
- 클라우드 인프라 지식이 부족한 초보자에게는 진입 장벽이 존재함

**이런 분에게 가장 적합합니다:** AI 에이전트가 코드를 직접 테스트하고 작동 가능한 서버 형태로 실행해야 하는 개발자

## 자주 묻는 질문

**기존 도커(Docker) 컨테이너 실행과 무엇이 다른가요?**

일반적인 일회성 컨테이너와 달리 재부팅 후에도 50GB의 디스크 데이터가 지속적으로 유지됩니다. 또한 루트 권한(sudo)과 외부 HTTPS 엔드포인트를 기본으로 제공하여 실제 가상 서버처럼 작동합니다.

**MCP(Model Context Protocol) 툴과도 직접 연결할 수 있나요?**

네, 지원합니다. Claude Desktop 등 MCP를 지원하는 AI 에이전트 클라이언트에서 직접 명령어를 수행하도록 샌드박스를 연동할 수 있습니다.

**한국어 안내 문서가 제공되나요?**

현재 모든 문서와 인터페이스는 영문으로 제공됩니다. 다만 명확한 명령어 구조를 가지고 있어 표준 CLI 환경에 익숙하시다면 사용에 무리가 없습니다.
