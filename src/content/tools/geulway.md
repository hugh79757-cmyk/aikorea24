모바일에서 사진과 주제를 입력하면 사용자의 말투를 반영한 AI 초안을 생성합니다. 수정 후 발행 버튼을 누르면 집에 켜져 있는 컴퓨터의 글웨이 앱이 네이버 블로그 또는 티스토리 편집기에 자동으로 입력하여 발행합니다. Mac, Windows 모두 지원합니다.

## 한줄 요약

글웨이는 모바일로 간편하게 사진과 주제를 입력하면 AI가 블로그 초안을 작성해 주는 서비스입니다. 직접 내용을 검토한 뒤 발행을 누르면 집 컴퓨터에 설치된 앱을 통해 네이버와 티스토리에 자동으로 업로드됩니다.

## 핵심 기능

- **모바일 블로그 작성**: 스마트폰에서 사진과 주제만으로 블로그 글 초안을 완성합니다.
- **맞춤 말투 반영**: 사용자의 평소 글쓰기 말투를 AI에 적용하여 자연스러운 글을 만듭니다.
- **자동 발행 연동**: 집 컴퓨터의 앱을 연동하여 블로그 편집기에 자동으로 글을 입력하고 발행합니다.

## 사용법

**1. 컴퓨터에 글웨이 앱 설치하기**

집에 있는 Mac 또는 Windows 컴퓨터에 글웨이 앱을 설치하고 네이버 블로그나 티스토리 계정을 연결합니다. 블로그 로그인 정보는 서버에 저장되지 않고 컴퓨터 브라우저 프로필에서 안전하게 관리됩니다.

**2. 모바일에서 사진과 주제 입력**

스마트폰으로 직접 찍은 사진을 선택하고 작성하고 싶은 블로그 주제를 입력합니다. 평소 자신이 자주 쓰는 말투를 AI에 반영하여 초안을 구성할 수 있습니다.

**3. AI 초안 내용 검토 및 수정**

모바일 화면에서 AI가 생성한 초안의 사실 관계와 표현을 꼼꼼히 읽고 직접 다듬습니다. 완성도 높은 포스팅하려고 발행 전에 내용을 최종 확인하는 단계입니다.

**4. 원격 자동 발행 요청하기**

수정이 끝나면 모바일에서 발행 버튼을 누릅니다. 켜져 있는 집 컴퓨터의 글웨이 앱이 로그인된 브라우저로 네이버나 티스토리 편집기에 내용을 입력하고 자동으로 발행합니다.

**컴퓨터를 항상 켜두어야만 발행이 가능한가요?**

**AI가 작성한 글을 직접 수정할 수 있나요?**

모바일에서 AI가 생성한 초안을 미리 확인하고 사실관계나 표현을 직접 다듬은 뒤에 최종 발행을 누를 수 있습니다.

**어떤 블로그 플랫폼을 지원하나요?**

현재 네이버 블로그와 티스토리 발행을 지원하며, 사용자가 평소 사용하는 브라우저 계정과 연동하여 안전하게 업로드됩니다.

**컴퓨터가 꺼져 있으면 예약 발행이나 나중 발행이 가능한가요?**

집 컴퓨터나 글웨이 앱이 꺼져 있으면 발행 요청은 즉시 거절되며 나중에 자동으로 실행되지 않습니다. 반드시 컴퓨터와 앱을 켠 상태에서 다시 발행을 요청해야 합니다.

**모바일에서 바로 네이버와 티스토리에 발행할 수 있나요?**

무료체험, Plus, Pro 플랜에서는 모바일에서 발행을 요청하면 켜져 있는 집 컴퓨터의 글웨이 앱이 대신 발행을 진행합니다. 단, Lite 플랜은 모바일 실제 발행을 지원하지 않고 컴퓨터에서 입력까지만 가능합니다.

**블로그 로그인 정보가 서버에 해킹당할 위험은 없나요?**

블로그 로그인 정보는 중앙 서버에 저장되지 않고 사용자가 연결한 Mac 또는 Windows 컴퓨터의 브라우저 프로필에서 직접 관리되므로 보안상 안전합니다.

**Lite 플랜과 Plus 플랜의 가장 큰 차이점은 무엇인가요?**

Lite 플랜은 글 생성과 편집기 입력까지만 지원하여 모바일 실제 발행이 불가능하지만, Plus 플랜은 모바일에서 바로 발행 요청까지 완료할 수 있는 차이가 있습니다.
