## 한줄 요약

Jotform AI Data Assistant는 설문조사나 양식로 모인 복잡한 데이터를 AI가 즉시 분석해 주는 도구입니다. 엑셀을 따로 열지 않아도 대화하듯 질문하면 통계와 차트를 만들어 주어 데이터 정리 시간을 획기적으로 줄여줍니다.

## 핵심 기능

- **데이터 자동 요약**: 수백 개의 응답을 읽고 핵심 내용을 몇 초 만에 요약해 줍니다.
- **즉석 차트 생성**: 데이터를 시각화하여 보고서에 바로 활용 가능한 그래프를 제공합니다.
- **대화형 데이터 관리**: 채팅하듯 명령어를 입력하면 표를 수정하고 분류하는 작업이 가능합니다.

## 사용법

**1. 설문 폼 생성 및 데이터 수집**

Jotform 대시보드에서 드래그 앤 드롭 방식으로 설문지를 만듭니다. 생성된 링크를 공유하여 응답을 수집하면 Jotform Tables에 데이터가 자동으로 쌓입니다.

**2. AI 데이터 분석 도구 실행**

수집된 데이터가 담긴 Jotform Tables 화면 우측 상단의 AI 버튼을 클릭합니다. 분석하고 싶은 데이터 항목을 선택하여 AI 기능을 활성화합니다.

**3. 대화형 분석 질문 입력**

채팅창에 '이번 설문 응답자들의 주요 만족도를 요약해 줘'와 같이 명령어를 입력합니다. AI가 즉시 수치를 계산하여 텍스트로 결과를 보여줍니다.

**4. 차트 생성 및 리포트 활용**

분석된 내용을 보고 차트 생성을 요청하여 시각화된 그래프를 확인합니다. 생성된 그래프는 보고서나 발표 자료에 바로 활용할 수 있습니다.

## 한국어 지원

인터페이스는 영어로 제공되지만 AI 분석 결과는 한국어 프롬프트를 입력하면 한국어로 답변을 받을 수 있습니다.

## 한국어 품질 실측

**고객 만족도 요약**

- 프롬프트: 이번 설문 응답에서 고객들이 가장 불만족스러워하는 부분 3가지만 요약해서 알려줘.
- 결과 예시: 응답자들의 의견을 분석한 결과, 배송 지연, 상담원 연결의 어려움, 제품 포장 상태가 주요 불만 사항으로 나타났습니다.
- 관찰: 한국어 프롬프트를 자연스럽고 정확한 문장으로 답변을 생성합니다.

**데이터 시각화 요청**

- 프롬프트: 응답자들의 연령대 분포를 원형 차트로 그려줘.
- 결과 예시: 요청하신 연령대 분포를 원형 차트로 생성했습니다. 20대가 40%, 30대가 35%로 가장 높은 비중을 차지하고 있습니다.
- 관찰: 데이터 수치에 기반한 시각화 요청도 무리 없이 수행합니다.

인터페이스는 영어로 되어 있으나, AI 분석 결과는 한국어 프롬프트를 매우 매끄러운 한국어로 응답합니다. 전문적인 용어도 문맥에 맞게 잘 처리하는 편입니다.

- **직장인**: 사내 교육 만족도 조사 결과를 AI에게 분석시킵니다. 주요 개선 사항을 요약해 상사에게 보고할 자료를 빠르게 만듭니다.
- **학생**: 학술 연구를 위한 설문조사 데이터를 수집합니다. AI를 활용해 응답자의 성향을 분류하고 논문에 들어갈 통계 차트를 생성합니다.
- **소상공인**: 고객 주문서 데이터를 업로드합니다. 가장 많이 팔린 상품과 주문 시간대를 분석하여 재고 관리와 마케팅 전략을 세웁니다.

- AI가 수백 개의 응답을 즉시 요약하고 핵심 인사이트를 도출해주어 의사결정 속도를 크게 높여줍니다.

## 자주 묻는 질문

**데이터 보안은 안전한가요?**

Jotform은 보안을 최우선으로 하며 업로드된 데이터는 엄격한 보안 규정을 준수하여 처리됩니다. 중요한 개인정보가 포함된 데이터는 주의해서 다루는 것이 좋습니다.

**엑셀 파일도 분석할 수 있나요?**

네, 기존에 가지고 있는 엑셀이나 CSV 파일을 업로드하면 AI가 해당 데이터를 읽고 분석할 수 있습니다. 데이터를 직접 입력하지 않아도 파일 업로드만으로 간편하게 시작하세요.

**한국어로 질문해도 되나요?**

네, 한국어로 질문을 입력하면 AI가 내용을 이해하고 한국어로 답변을 제공합니다. 다만, 복잡한 전문 용어보다는 쉬운 문장으로 질문할 때 더 정확한 결과를 얻을 수 있습니다.

**AI가 분석한 결과가 정확한가요?**

AI는 수집된 데이터를 바탕으로 통계적 요약을 제공합니다. 다만, 데이터의 양이 너무 적거나 모호한 경우 결과가 달라질 수 있으니 중요한 보고서 작성 시에는 검토가 필요합니다.

**기존에 쓰던 엑셀 파일을 가져올 수 있나요?**

네, Jotform Tables를 통해 기존 데이터를 업로드하여 관리할 수 있습니다. 업로드된 데이터도 AI 분석 기능을 동일하게 적용하여 활용 가능합니다.

**한국어 설문지도 만들 수 있나요?**

설문지 내용 자체는 직접 한국어로 작성하시면 됩니다. AI는 한국어 응답을 이해하고 분석할 수 있으므로 한국어 설문 데이터 분석에 전혀 문제가 없습니다.

**무료 플랜으로 AI 기능을 계속 쓸 수 있나요?**

무료 플랜에서도 기능을 체험할 수 있지만, 매월 처리 가능한 데이터양이나 AI 사용 횟수에 제한이 있습니다. 사용량이 많다면 유료 전환이 필요합니다.
