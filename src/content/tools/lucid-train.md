## 한줄 요약

Lucid Train은 복잡한 소스 코드를 읽어 들여 시스템의 구조를 한눈에 볼 수 있는 다이어그램으로 그려줍니다. 외부 서버를 거치지 않고 내 컴퓨터에서 완전히 오프라인으로 작동하여 보안이 중요한 기업 환경에서 코드 유출 걱정 없이 사용할 수 있습니다.

## 핵심 기능

- **자동 도면 생성**: 복잡한 코드 구조를 자동으로 분석하여 시각적인 아키텍처 도면으로 즉시 변환합니다.
- **오프라인 보안**: 모든 모델이 로컬에서 실행되어 외부로 소스 코드가 유출될 위험이 전혀 없습니다.
- **코딩 에이전트 연동**: 생성된 도면을 코딩 에이전트의 설계서로 활용하여 자동화된 기능 개발을 지원합니다.

## 사용법

**1. 설치 및 저장소 연결**

공식 홈페이지에서 macOS, Windows, Linux용 데스크톱 앱을 다운로드하여 설치합니다. 분석할 코드 저장소(Repository)를 지정하면 코드를 읽기 시작합니다.

**2. 아키텍처 도면 생성**

프로그램이 소스 코드를 분석하여 자동으로 시스템 구조 다이어그램을 그려줍니다. 생성된 도면은 코딩 에이전트의 작업 설계서(Specification)로 곧바로 활용됩니다.

**3. 코딩 에이전트 작업 지시**

화면의 명령 팔레트나 채팅창을 열어 수정이 필요한 기능이나 버그 수정을 요청합니다. 에이전트는 도면과 코드를 참고하여 자동으로 코드를 편집합니다.

**4. 변경 사항 검토 및 승인**

에이전트가 제안한 모든 수정 사항은 리뷰 가능한 Diff 형태로 제공됩니다. 사용자가 직접 내용을 확인하고 승인해야 최종 저장소에 반영됩니다.

## 가격 정책

- **무료 플랜**: 현재 상세 가격 정책은 공식 홈페이지로 확인이 필요합니다.
- **유료 플랜**: 유료 플랜 도입 시 기업용 보안 기능과 더 큰 규모의 코드베이스 분석을 지원할 것으로 예상됩니다.

비용 절약 팁: 로컬 환경에서 구동되므로 고성능 GPU가 탑재된 PC를 사용하면 훨씬 빠른 분석 속도를 경험할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 제공되는 무료 사용 범위와 제한 사항은 공식 홈페이지의 요금 페이지에서 직접 확인이 필요합니다. 다만 화면 예시 화면에서 7일간의 트라이얼 기간 등이 확인됩니다.

- **정식 플랜** (정확한 금액과 결제 주기는 공식 요금 페이지에서 확인이 필요합니다): 로컬 환경에서 구동되는 데스크톱 앱과 멀티 프로젝트 워크스페이스 기능을 제공합니다.

**환불과 해지**: 환불, 구독 해지, 결제 주기 변경 등에 관한 규정은 공식 웹사이트의 이용약관 및 결제 페이지에서 확인해야 합니다.

## 한국어 지원

현재 인터페이스와 출력 결과는 영어로 제공됩니다. 코드 자체는 언어에 상관없이 분석 가능하지만 프롬프트 입력 시 영어 사용을 권장합니다.

## 한국어 품질 실측

**로그인 버그 수정 지시**

- 프롬프트: The login test is flaky. Find the race and fix it.
- 결과 예시: 로그인 테스트의 경쟁 상태(Race condition) 원인을 분석한 후, 관련 소스 코드 파일의 Diff 형태 수정본을 제안합니다.
- 관찰: 입력과 출력은 주로 영어 인터페이스 및 코드 기반으로 작동합니다.

**시스템 아키텍처 조회**

- 프롬프트: Show me the overall architecture and dependencies of this workspace.
- 결과 예시: 멀티 프로젝트 워크스페이스의 전체 구조를 시각적 다이어그램으로 그려주고 주요 구성 요소를 설명합니다.
- 관찰: 시각적 도면 생성이 중심이므로 텍스트 외에 구조화된 다이어그램 출력 능력이 뛰어납니다.

Lucid Train은 개발자 중심의 도구로 인터페이스가 영어로 제공되며, 한국어 전용 지원보다는 소스 코드 분석과 아키텍처 시각화에 집중되어 있습니다.

## 이런 분에게 추천합니다

보안이 중요한 기업의 개발자에게 추천합니다. 코드 유출 없이 시스템을 분석하고 싶어 하는 분에게 적합합니다. 복잡한 레거시 코드를 새로 파악해야 하는 프로젝트 관리자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 인수인계받은 복잡한 사내 시스템 코드를 분석할 때 사용합니다. 다이어그램로 전체 구조를 빠르게 파악하고 업무 효율을 높입니다.
- **학생**: 오픈소스 프로젝트를 공부할 때 사용합니다. 코드의 흐름을 시각적으로 확인하여 구조를 더 깊이 있게 이해할 수 있습니다.
- **소상공인**: 외주 개발자에게 맡긴 웹사이트의 구조를 직접 확인하고 싶을 때 사용합니다. 코드 지식이 부족해도 도면으로 전체 서비스 구조를 검토할 수 있습니다.

## 장단점

**장점**

- 외부 서버를 거치지 않고 내 컴퓨터에서 완전히 오프라인으로 작동하여 소스 코드 보안이 철저하게 유지됩니다.
- 복잡한 코드 구조를 시각적인 아키텍처 도면으로 자동 변환해 주어 전체 시스템 파악이 매우 쉽습니다.
- 생성된 도면을 보고 코딩 에이전트가 직접 코드를 수정하고 리뷰 가능한 Diff를 제공하여 편리합니다.
- VS Code, Cursor, Zed 등 주요 에디터와 원클릭으로 연동되며 멀티 프로젝트 워크스페이스를 지원합니다.

**단점**

- 프로그램 인터페이스와 출력 결과가 영어 중심으로 이루어져 있어 국내 일반 사용자가 다소 어렵게 느낄 수 있습니다.
- 로컬 환경에서 인공지능 모델을 직접 구동하므로 PC의 사양이나 GPU 성능에 따라 분석 속도가 달라질 수 있습니다.
- 무료 및 유료 플랜의 세부 가격 정책이 홈페이지에서 명확하게 공개되어 있지 않아 확인이 필요합니다.

## 주의사항

- **개인정보**: 로컬 환경에서 오프라인으로 작동하지만 외부 MCP 서버나 특정 모델 연동 시 민감한 개인정보나 사내 기밀 데이터가 노출되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: AI 코딩 에이전트가 생성한 소스 코드와 아키텍처 도면의 라이선스는 사용 중인 오픈소스 라이선스 및 툴의 이용 약관을 준수해야 합니다.
- **요금/한도**: 트라이얼 기간 이후 적용되는 유료 플랜의 가격과 구독 한도는 공식 홈페이지의 변경 사항을 수시로 확인하는 것이 안전합니다.
- **계정 관리**: 데스크톱 앱 및 연동된 개발 환경(VS Code, Cursor 등)의 계정 정보와 작업 기록은 로컬 저장소 안전 관리가 필요합니다.

## 자주 묻는 질문

**인터넷 연결 없이도 정말 작동하나요?**

네, Lucid Train은 로컬 모델을 사용하여 모든 작업을 오프라인에서 처리합니다. 따라서 인터넷이 차단된 폐쇄망 환경에서도 안심하고 사용할 수 있습니다.

**어떤 프로그래밍 언어를 지원하나요?**

대부분의 주요 프로그래밍 언어를 지원합니다. 다만 코드베이스의 규모가 너무 크다면 로컬 환경의 메모리 용량에 따라 분석 속도가 달라질 수 있습니다.

**초보자도 쉽게 사용할 수 있나요?**

코드 구조를 시각화하는 도구이므로 기본적인 개발 지식이 있으면 훨씬 유용합니다. 프로그래밍을 전혀 모르는 분보다는 개발자나 IT 기획자에게 더 적합한 툴입니다.

**인터넷이 안 되는 환경에서도 사용할 수 있나요?**

네, Lucid Train은 로컬 모델을 활용하여 완전히 오프라인으로 작동하므로 인터넷 연결이 제한된 보안 환경에서도 소스 코드 유출 걱정 없이 사용할 수 있습니다.

**어떤 에디터와 연동해서 쓸 수 있나요?**

버튼 클릭 한 번으로 VS Code, Cursor, Zed 등의 주요 코드 편집기와 연동하여 작업할 수 있으며 편리한 탭과 명령 팔레트를 제공합니다.

**생성된 아키텍처 도면은 어떻게 수정하나요?**

도면은 소스 코드를 기반으로 자동 생성되며, 사용자는 채팅과 명령어를 통해 에이전트에게 수정 사항을 지시하고 변경된 Diff를 리뷰하여 반영할 수 있습니다.

**코드 언어에 제한이 있나요?**

다양한 프로그래밍 언어의 저장소를 지원하며, 9개 이상의 생태계를 아우르는 의존성 및 MCP 감사 기능을 함께 제공합니다.
