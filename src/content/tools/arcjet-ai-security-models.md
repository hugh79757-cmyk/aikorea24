## 한줄 요약

AI가 작성한 코드의 보안 취약점을 사전에 차단하는 개발자용 보안 모델입니다. 코딩 에이전트를 사용할 때 발생할 수 있는 해킹이나 정보 유출 위험을 줄여줍니다.

## 핵심 기능

- **보안 모델**: AI 코딩 에이전트에 특화된 맞춤형 보안 검증 제공
- **취약점 차단**: 코드 작성 단계에서 위험 요소 사전 탐지 및 차단
- **안전한 개발**: 개발 생산성을 유지하면서 애플리케이션 보안 강화

## 사용법

**1. 서비스 가입하기**

공식 웹사이트에 접속하여 개발자 계정을 생성합니다. 대시보드 화면에서 API 키를 발급받아 환경 설정에 입력합니다.

**2. 보안 모델 연동**

사용 중인 AI 코딩 도우미 환경에 Arcjet 보안 모델 설정을 추가합니다. 프로젝트 설정 파일에 필요한 라이브러리와 규칙을 지정합니다.

**3. 코드 검증 수행**

AI가 생성한 소스코드를 입력하거나 커밋하는 시점에 보안 검증을 실행합니다. 대시보드에서 실시간으로 취약점 발견 여부를 확인할 수 있습니다.

**4. 피드백 및 예외 처리**

탐지된 보안 경고 내용을 검토하고 코드를 수정합니다. 필요한 경우 예외 규칙을 조정하여 오탐지를 줄입니다.

## 가격 정책

- **무료 플랜**: 기본적인 보안 검증 기능을 체험할 수 있는 무료 옵션이 제공됩니다.
- **유료 플랜**: 프로 플랜 월 29달러(약 4만 원)로 더 보안 모델과 API 호출량을 제공합니다.

비용 절약 팁: 개인 프로젝트나 소규모 테스트는 무료 플랜으로 시작하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 보안 검증 기능을 무료로 체험할 수 있는 플랜이 제공됩니다. 상세한 일일 호출량이나 상세 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **프로 플랜** (월 29달러 (약 4만 원, 정확한 원화 금액은 환율에 따라 변동)): 더 확장된 보안 모델과 충분한 API 호출량을 제공합니다.

- **엔터프라이즈** (공식 페이지 확인 필요): 대규모 기업 환경에 맞춘 맞춤형 보안 기능과 전담 지원을 제공합니다.

**환불과 해지**: 구독 해지 및 환불 규정에 대한 세부 사항은 공식 결제 페이지나 고객 센터로 확인해야 합니다.

## 한국어 지원

인터페이스와 문서가 영어로 제공되어 개발 관련 영어 독해 능력이 필요합니다.

## 한국어 품질 실측

**결제 코드 검증**

- 프롬프트: AI가 작성해 준 사내 결제 시스템 소스코드의 보안 취약점을 검사해 줘.
- 결과 예시: 입력하신 코드에서 SQL Injection 취약점이 발견되었습니다. 파라미터화된 쿼리로 수정하는 것을 권장합니다.
- 관찰: 인터페이스와 문서가 영어로 제공되므로 한국어 프롬프트 입력 시 번역 과정에서 약간의 제약이 있을 수 있습니다.

**API 키 노출 점검**

- 프롬프트: 소스코드 내부에 하드코딩된 API 키나 비밀번호가 있는지 확인해 줘.
- 결과 예시: 코드 14행에 API 키가 평문으로 노출되어 있습니다. 환경 변수 파일로 분리하여 관리해야 안전합니다.
- 관찰: 전문 개발 용어와 보안 관련 피드백은 영문 기반으로 출력될 확률이 높습니다.

한국어 인터페이스가 공식 지원되지 않아 주로 영문 화면과 문서로 이용해야 합니다. 개발 전문 용어 위주로 결과가 출력되므로 실무 영어 독해 능력이 도움이 됩니다.

## 실제 활용 예시

- **직장인**: AI가 작성해 준 사내 결제 시스템 코드를 적용하기 전에 보안 취약점이 없는지 검토합니다. 민감한 정보가 노출되지 않도록 안전한 코드로 수정합니다.
- **학생**: 졸업 작품 웹사이트를 만들 때 AI 툴이 생성한 로그인 코드에 보안 문제가 없는지 확인합니다. 해킹 위험을 미리 방지하여 완성도 높은 프로젝트를 제출합니다.
- **소상공인**: 외주 개발자 없이 AI로 만든 쇼핑몰 주문 페이지의 결제 보안을 점검합니다. 고객의 개인정보가 안전하게 보호되도록 보안 설정을 강화합니다.

## 장단점

**장점**

- AI 코딩 도우미가 작성한 코드의 잠재적 보안 취약점을 사전에 차단합니다.
- 개발 생산성을 떨어뜨리지 않으면서 애플리케이션의 전반적인 보안을 강화합니다.
- 코딩 단계에서 실시간으로 위험 요소를 탐지하여 사고를 예방할 수 있습니다.
- 스타트업이나 개인 개발자도 합리적인 비용으로 전문적인 보안 검증을 도입할 수 있습니다.

**단점**

- 인터페이스와 가이드 문서가 영어로만 제공되어 영어 독해에 부담이 있을 수 있습니다.
- 무료 플랜의 기능과 호출량에 제한이 있어 대규모 프로젝트에는 유료 전환이 필수적입니다.
- AI 도구의 특성상 복잡한 비즈니스 로직에서 가끔 오탐지가 발생할 수 있습니다.

## 주의사항

- **개인정보**: 소스코드 검증 과정에서 민감한 고객 정보나 사내 기밀이 포함되지 않도록 주의해야 합니다. 보안 정책에 맞는 안전한 환경에서 코드를 점검하는 것이 중요합니다.
- **저작권/상업적 이용**: AI가 생성하고 본 도구가 검증한 코드의 저작권과 라이선스 규정을 준수해야 합니다. 상업용 애플리케이션에 적용할 때는 오픈소스 라이선스 충돌 여부를 별도로 확인해야 합니다.
- **요금/한도**: 무료 플랜의 사용량을 초과하면 추가 비용이 발생하거나 서비스가 제한될 수 있습니다. 프로젝트 규모에 맞는 요금제를 선택하고 API 호출량을 주기적으로 모니터링해야 합니다.
- **계정 관리**: 발급받은 API 키와 개발자 계정 정보가 유출되지 않도록 엄격하게 관리해야 합니다. 팀원 간 권한 설정을 철저히 하여 무단 접근을 방지하는 것이 좋습니다.

## 자주 묻는 질문

**이 툴은 어떤 개발자에게 필요한가요?**

챗GPT나 클로드 같은 AI 코딩 에이전트를 적극 활용하여 소프트웨어를 개발하는 프로그래머에게 적합합니다. AI가 만든 코드에 숨겨진 보안 허점을 찾아내는 데 유용합니다.

**초보 개발자도 쉽게 사용할 수 있나요?**

어느 정도 프로그래밍 지식과 API 연동 경험이 필요하므로 완전한 초보자보다는 중급 이상의 개발자에게 알맞습니다.

**기존 보안 프로그램과 무엇이 다른가요?**

일반 정적 분석 도구와 달리, AI 코딩 에이전트의 특성을 이해하고 맞춤형으로 보안을 점검한다는 특징이 있습니다.

**어떤 AI 코딩 도우미와 함께 사용할 수 있나요?**

주요 AI 코딩 에이전트 및 개발 환경과 연동하여 사용할 수 있습니다. 구체적인 지원 목록은 공식 문서에서 확인할 수 있습니다.

**한국어 소스코드나 주석도 검증할 수 있나요?**

코드 내부의 문법과 로직을 중심으로 보안 취약점을 검사하므로 한글 주석이 포함되어 있어도 정상적으로 작동합니다. 다만 상세한 가이드는 영문으로 제공될 수 있습니다.

**무료 플랜에서 유료 플랜으로 언제든 업그레이드할 수 있나요?**

대시보드 결제 메뉴를 통해 언제든지 프로 플랜으로 전환할 수 있습니다. 업그레이드 즉시 더 많은 호출량과 고급 보안 모델을 이용할 수 있습니다.

**팀원들과 하나의 계정을 공유해서 사용할 수 있나요?**

보안과 접근 권한 관리를 위해 팀원 각자 계정을 생성하여 협업하는 것을 권장합니다. 요금제에 따른 팀원 초대 기능은 공식 요금 페이지를 참고해 주시기 바랍니다.
