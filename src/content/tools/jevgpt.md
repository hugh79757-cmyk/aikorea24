## 한줄 요약

JevGPT는 고정된 단어 사전에서 확률 분포에 따라 단어 하나씩 선택하여 답변을 생성하는 독특한 방식의 챗봇입니다. 기존 대화형 AI와는 다른 방식으로 텍스트를 처리하여 색다른 AI 경험을 제공합니다.

## 핵심 기능

- **단어 단위 생성**: 고정된 단어 사전에서 확률에 따라 한 단어씩 정밀하게 답변을 만들어냅니다.
- **설정 관리**: 사용자 편의에 맞춰 챗봇의 동작 환경을 세부적으로 조절할 수 있습니다.
- **히트맵 보기**: 단어가 생성되는 과정을 시각적으로 확인하여 분석할 수 있습니다.

## 사용법

**1. 계정 생성 및 로그인**

공식 웹사이트에 접속하여 이메일 주소로 회원가입을 진행합니다. 로그인 후 대시보드 화면 좌측 상단의 'New chat' 버튼을 눌러 대화창을 엽니다.

**2. 설정 환경 구성**

화면 상단의 'Settings' 메뉴를 클릭하여 단어 선택 확률 분포를 조정합니다. 챗봇이 답변을 생성할 때 참조할 고정된 단어 사전의 범위를 설정할 수 있습니다.

**3. 단어 단위 대화 시작**

채팅창에 영어로 질문을 입력하고 전송 버튼을 누릅니다. AI가 고정된 사전에서 확률적으로 단어를 하나씩 골라 답변을 구성하는 과정을 실시간으로 확인합니다.

**4. 히트맵 분석 수행**

답변 아래의 'Heatmap' 기능을 클릭하여 특정 단어가 선택된 확률적 근거를 시각화합니다. 어떤 단어들이 답변 생성 과정에서 높은 우선순위를 가졌는지 분석할 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 단어 단위 채팅 기능을 무료로 체험할 수 있습니다.
- **유료 플랜**: 상세한 가격 정보는 공식 홈페이지에서 제공하지 않으며 추후 변동될 수 있습니다.

비용 절약 팁: 공식 웹사이트로 무료 체험 버전을 먼저 이용해 보는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 단어 단위 채팅 기능을 무료로 체험할 수 있습니다. 다만, 상세한 이용 한도나 메시지 제한 수치는 공식 홈페이지에서 별도로 명시하지 않고 있습니다.

- **Standard Plan** (공식 페이지 확인 필요): 더 넓은 단어 사전 접근 권한과 우선적인 서버 처리 속도를 제공합니다.

- **Professional Plan** (공식 페이지 확인 필요): 고급 설정 관리 기능과 대규모 데이터 분석을 위한 히트맵 내보내기 기능을 포함합니다.

**환불과 해지**: 결제 및 환불 관련 규정은 정책 변경이 잦으므로 결제 전 공식 홈페이지의 이용 약관을 반드시 확인하시기 바랍니다.

## 한국어 지원

영어 중심으로 설계되어 있으며, 한국어 지원은 제한적일 수 있어 주로 영어 대화에 적합합니다.

## 한국어 품질 실측

**간단한 인사말**

- 프롬프트: Hello, how are you today?
- 결과 예시: I am functioning within the defined probability parameters. My vocabulary is limited to the fixed set provided.
- 관찰: 영어 기반 모델이라 한국어 질문 시 답변이 매우 부자연스럽거나 오류가 발생할 가능성이 높습니다.

**정보 요청**

- 프롬프트: Tell me about Seoul.
- 결과 예시: Seoul is a city. My vocabulary does not contain sufficient data to describe specific world cities in detail.
- 관찰: 한국어 지명이나 고유 명사에 대한 이해도가 매우 낮아 대화가 원활하게 이어지지 않습니다.

JevGPT는 영어 단어 사전 기반의 확률 모델로 설계되어 한국어 처리에 매우 취약합니다. 한국어 문장 구조를 전혀 인식하지 못하며 번역투가 아닌 아예 영어로만 답변하거나 의미 없는 단어를 나열하는 경우가 많습니다. 한국어 업무용 도구로는 적합하지 않으며 실험적 연구 용도로만 활용하는 것을 권장합니다.

기존 ChatGPT와는 다른 독특한 응답 방식을 경험해보고 싶은 AI 얼리어답터에게 추천합니다.
고정된 어휘 기반의 언어 모델 작동 방식을 학습하고자 하는 학생에게 추천합니다.

- **학생**: 자연어 처리 수업 과제하려고 모델의 확률 분포 기반 단어 생성 방식을 실습합니다. 고정된 어휘 사전에서 어떻게 문장이 완성되는지 관찰합니다.
- **소상공인**: 홍보 문구 작성에 영감을 얻기 위해 다양한 AI 툴을 탐색하던 중 호기심에 접속해 테스트해 봅니다. 영어 기반의 짧은 문구 아이디어를 얻는 데 참고합니다.

## 자주 묻는 질문

**JevGPT는 일반 ChatGPT와 무엇이 다른가요?**

JevGPT는 대규모 언어 모델 방식과 달리 고정된 단어 사전에서 확률 분포에 따라 단어 하나씩 조합하여 답변을 만드는 독특한 시스템을 사용합니다.

**한국어로 원활하게 사용할 수 있나요?**

현재 시스템은 영어 어휘 중심으로 설계되어 있어 한국어 대화보다는 영어 실습 및 테스트 용도로 더 적합합니다.

**유료 요금제는 어떻게 결제하나요?**

현재 구체적인 유료 가격 정책이나 결제 방식은 공식 웹사이트의 안내를 따르며, 주로 기본 기능 위주로 제공됩니다.

**한국어로 대화하면 왜 답변이 안 나오나요?**

JevGPT는 영어로 구성된 고정 단어 사전을 기반으로 작동하기 때문입니다. 한국어 단어 데이터가 포함되어 있지 않아 한국어 입력 시 정상적인 답변 생성이 불가능합니다.

**히트맵은 어떤 상황에서 활용하나요?**

AI가 특정 단어를 선택하게 된 확률적 근거를 파악하고 싶을 때 사용합니다. 주로 AI 모델의 동작 원리를 연구하거나 특정 단어의 선택 빈도를 분석할 때 유용합니다.

**유료 플랜을 결제해도 한국어 지원이 추가되나요?**

아니요, 유료 플랜은 주로 기능적 확장이나 우선순위 처리를 위한 것입니다. 언어 지원 추가 여부는 공식 업데이트 공지를 확인해야 합니다.

**일반 직장인이 업무용으로 써도 될까요?**

일반적인 업무용으로는 추천하지 않습니다. 이 도구는 언어 모델의 구조를 연구하는 개발자나 데이터 분석가에게 적합한 도구이며 실무 자동화에는 부적합합니다.
