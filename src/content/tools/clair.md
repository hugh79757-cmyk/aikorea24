## 한줄 요약

터미널에서 실행되는 AI 개발 도구인 Claude Code의 승인 요청을 안드로이드 폰이나 스마트워치로 원격 제어할 수 있는 유틸리티 앱입니다. 개발자가 자리를 비우더라도 빌드나 배포 과정에서 발생하는 질문에 즉시 답할 수 있어 작업 흐름이 끊기지 않도록 돕습니다.

## 핵심 기능

- **원격 승인 제어**: 스마트폰과 워치로 Claude Code의 권한 요청을 즉시 수락합니다.
- **종단간 암호화**: 내 컴퓨터와 모바일 기기 간의 통신 데이터를 안전하게 보호합니다.
- **백그라운드 실행**: 컴퓨터 로그인 시 에이전트가 자동 실행되어 항상 대기합니다.

## 가격 정책

- **무료 플랜**: 기본적으로 무료로 다운로드하여 사용하는 독립형 앱입니다.
- **유료 플랜**: 현재 별도의 유료 플랜은 없으며 모든 기능을 무료로 이용하실 수 있습니다.

비용 절약 팁: 공식 Anthropic 제품이 아니므로 보안 설정을 꼼꼼히 확인하고 사용하시는 것을 추천합니다.

## 한국어 지원

앱 자체는 영문으로 제공되지만 Claude Code가 전달하는 메시지 내의 한국어 텍스트는 모바일 기기에서 정상적으로 확인하실 수 있습니다.

## 이런 분에게 추천합니다

Claude Code를 활용해 터미널 환경에서 대규모 코딩 작업을 자주 수행하는 전문 개발자분들에게 추천합니다.
빌드나 테스트가 진행되는 동안 자리에서 일어나 휴식을 취하고 싶은 프리랜서 개발자분들에게 유용합니다.

## 실제 활용 예시

- **직장인**: 사무실 자리에서 일어나 커피를 마시러 가면서도 컴퓨터에서 실행 중인 Claude Code의 패키지 설치 승인 요청을 스마트폰으로 즉시 수락하여 작업 중단 없이 개발을 이어갑니다.
- **학생**: 컴퓨터공학과 학생이 밤샘 코딩 과제를 실행해 두고 침대에 누워 스마트워치로 오류 수정 제안을 확인하며 원격으로 디버깅을 진행합니다.
- **소상공인**: 1인 IT 쇼핑몰 운영자가 서버 업데이트 작업을 걸어두고 외출하여 이동 중에 스마트폰으로 보안 패치 적용 승인 버튼을 누릅니다.

## 유사 툴과 비교

**장점:**
- 자리를 비워도 모바일로 Claude Code 제어가 가능합니다.
- 종단간 암호화로 개발 소스나 명령어가 외부로 유출되지 않아 안전합니다.

**단점:**
- 안드로이드 및 Wear OS 기기만 지원하여 iOS 사용자는 이용이 어렵습니다.

**이런 분에게 가장 적합합니다:** 터미널 기반 AI 코딩 도구를 사용하면서 자리 이동이 잦은 개발자에게 가장 적합합니다.

## 자주 묻는 질문

**아이폰이나 애플워치에서도 사용할 수 있나요?**

현재 Clair는 안드로이드 폰과 Wear OS 기반의 스마트워치만 지원하고 있으며, iOS 환경은 지원하지 않습니다.

**회사 보안망 내에서도 작동하나요?**

종단간 암호화를 지원하지만 회사 방화벽 설정에 따라 컴퓨터 에이전트와 모바일 앱 간의 페어링 연결이 제한될 수 있으므로 사전에 확인이 필요합니다.

**이 앱을 사용하려면 Claude Code가 반드시 설치되어 있어야 하나요?**

네, 그렇습니다. Anthropic의 터미널 도구인 Claude Code가 PC에 먼저 설치되어 실행 중인 상태여야 Clair 앱과 연동하여 원격 제어를 사용하실 수 있습니다.
