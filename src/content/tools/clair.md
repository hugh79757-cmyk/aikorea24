## 한줄 요약

터미널에서 실행되는 AI 개발 도구인 Claude Code의 승인 요청을 안드로이드 폰이나 스마트워치로 원격 제어할 수 있는 유틸리티 앱입니다. 개발자가 자리를 비우더라도 빌드나 배포 과정에서 발생하는 질문에 즉시 답할 수 있어 작업 흐름이 끊기지 않도록 돕습니다.

## 핵심 기능

- **원격 승인 제어**: 스마트폰과 워치로 Claude Code의 권한 요청을 즉시 수락합니다.
- **종단간 암호화**: 내 컴퓨터와 모바일 기기 간의 통신 데이터를 안전하게 보호합니다.
- **백그라운드 실행**: 컴퓨터 로그인 시 에이전트가 자동 실행되어 항상 대기합니다.

## 사용법

**1. 컴퓨터에 에이전트 설치**

macOS 또는 Linux 환경에서 제공되는 설치 명령어를 터미널에 입력하여 백그라운드 에이전트를 실행합니다. 컴퓨터가 켜져 있고 로그인되어 있는 상태에서 에이전트가 계속 대기하도록 설정합니다.

**2. 모바일 앱과 페어링**

터미널에서 페어링 명령어를 실행하여 화면에 나타나는 코드를 모바일 앱으로 스캔합니다. 컴퓨터와 스마트폰 간의 안전한 연동을 완료하여 원격 제어 준비를 마칩니다.

**3. 스마트워치 및 폰 설정**

안드로이드 스마트폰과 Wear OS 스마트워치에 앱을 설치하고 알림 설정을 구성합니다. 워치 페이스나 타일로 현재 Claude Code 세션 상태와 토큰 사용량을 한눈에 확인하도록 맞춤 설정합니다.

**4. 원격 승인 및 피드백**

자리를 비운 동안 Claude Code가 권한 요청이나 질문을 보내면 알림로 내용을 확인합니다. 워치나 폰에서 터치나 음성 받아쓰기로 명령을 승인하거나 거부하여 작업을 이어갑니다.

## 가격 정책

- **무료 플랜**: 기본적으로 무료로 다운로드하여 사용하는 독립형 앱입니다.
- **유료 플랜**: 현재 별도의 유료 플랜은 없으며 모든 기능을 무료로 이용하실 수 있습니다.

비용 절약 팁: 공식 Anthropic 제품이 아니므로 보안 설정을 꼼꼼히 확인하고 사용하시는 것을 추천합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 제공되는 독립형 앱은 기본적으로 무료로 다운로드하여 사용할 수 있습니다. 컴퓨터와 모바일 기기 간의 원격 승인 및 제어 기능을 추가 비용 없이 이용할 수 있습니다.

- **무료 플랜** (무료 (0원)): 앱에서 제공하는 모든 원격 제어 기능과 스마트워치 연동 기능을 추가 결제 없이 이용할 수 있습니다.

- **유료 플랜** (공식 페이지 확인 필요): 현재 별도의 유료 플랜은 안내되어 있지 않으며, 정확한 향후 정책은 공식 요금 페이지에서 확인이 필요합니다.

**환불과 해지**: 무료로 제공되는 독립형 앱이므로 별도의 환불 및 결제 관련 정책은 적용되지 않습니다.

## 한국어 지원

앱 자체는 영문으로 제공되지만 Claude Code가 전달하는 메시지 내의 한국어 텍스트는 모바일 기기에서 정상적으로 확인하실 수 있습니다.

## 한국어 품질 실측

**빌드 오류 메시지 승인**

- 프롬프트: npm run build 명령 실행 중 발생한 오류에 대한 Claude Code의 수정안 검토 및 승인 요청
- 결과 예시: 스마트워치 화면에 빌드 오류 수정 제안 내용과 함께 승인 및 거부 버튼이 표시됩니다. 사용자는 터치나 음성으로 해당 수정안을 원격에서 간편하게 수락할 수 있습니다.
- 관찰: Claude Code가 생성한 메시지 내의 한국어 텍스트가 모바일 기기에서 깨짐 없이 정상적으로 표시됩니다.

**테스트 코드 실행 확인**

- 프롬프트: 모든 go test 실행 규칙을 세션 전체에 적용할지에 대한 Claude Code의 질문 확인
- 결과 예시: 워치 화면에서 제안된 규칙의 상세 내용을 읽고 매번 허용하거나 이번만 허용하는 선택지를 고를 수 있습니다. 거부할 경우 음성 받아쓰기로 직접 사유를 입력하여 보낼 수 있습니다.
- 관찰: 영문 인터페이스 환경에서도 사용자가 입력한 한국어 사유가 정확하게 전달되어 원활한 소통을 돕습니다.

앱 자체의 인터페이스는 영문으로 제공되지만 개발 과정에서 Claude Code가 전달하는 한국어 메시지 내용은 모바일과 워치에서 자연스럽게 읽고 처리할 수 있습니다.

## 이런 분에게 추천합니다

Claude Code를 활용해 터미널 환경에서 대규모 코딩 작업을 자주 수행하는 전문 개발자분들에게 추천합니다.
빌드나 테스트가 진행되는 동안 자리에서 일어나 휴식을 취하고 싶은 프리랜서 개발자분들에게 유용합니다.

## 실제 활용 예시

- **직장인**: 사무실 자리에서 일어나 커피를 마시러 가면서도 컴퓨터에서 실행 중인 Claude Code의 패키지 설치 승인 요청을 스마트폰으로 즉시 수락하여 작업 중단 없이 개발을 이어갑니다.
- **학생**: 컴퓨터공학과 학생이 밤샘 코딩 과제를 실행해 두고 침대에 누워 스마트워치로 오류 수정 제안을 확인하며 원격으로 디버깅을 진행합니다.
- **소상공인**: 1인 IT 쇼핑몰 운영자가 서버 업데이트 작업을 걸어두고 외출하여 이동 중에 스마트폰으로 보안 패치 적용 승인 버튼을 누릅니다.

## 유사 툴과 비교

**장점:**
- 자리를 비워도 모바일로 Claude Code 제어가 가능합니다.
- 종단간 암호화로 개발 소스나 명령어가 외부로 유출되지 않아 안전합니다.

**단점:**
- 안드로이드 및 Wear OS 기기만 지원하여 iOS 사용자는 이용이 어렵습니다.

**이런 분에게 가장 적합합니다:** 터미널 기반 AI 코딩 도구를 사용하면서 자리 이동이 잦은 개발자에게 가장 적합합니다.

## 장단점

**장점**

- 책상 자리를 비운 상태에서도 스마트폰이나 스마트워치로 Claude Code의 승인 요청을 실시간으로 처리할 수 있습니다.
- 종단간 암호화 기술을 적용하여 컴퓨터와 모바일 기기 간에 주고받는 데이터를 안전하게 보호할 수 있습니다.
- Wi-Fi나 LTE가 연결된 스마트워치만 차고 나가도 블루투스 범위를 벗어나 원격으로 작업 제어가 가능합니다.
- 터미널, 스마트폰, 스마트워치 중 어느 곳에서든 먼저 응답한 결과가 즉시 반영되어 작업 흐름이 끊기지 않습니다.

**단점**

- 공식 Anthropic 제품이 아니기 때문에 별도의 서드파티 앱 사용에 따른 보안 설정을 직접 꼼꼼히 확인해야 합니다.
- 원격 제어가 원활하게 작동하려면 집이나 사무실에 있는 컴퓨터가 계속 켜져 있고 온라인 상태를 유지해야 합니다.
- 앱의 기본 인터페이스와 설정 메뉴가 모두 영문으로만 제공되어 영어가 익숙하지 않은 사용자에게는 진입 장벽이 있습니다.

## 주의사항

- **개인정보**: 컴퓨터와 모바일 간의 통신은 종단간 암호화로 보호되지만 원격 제어 과정에서 민감한 소스코드나 시스템 정보가 모바일 기기로 전송될 수 있으므로 보안 관리에 유의해야 합니다.
- **저작권/상업적 이용**: 본 도구는 Anthropic에서 공식 제작한 프로그램이 아니며 독립형 유틸리티이므로, 상업 프로젝트에 적용할 때는 기업의 보안 정책과 라이선스 규정을 준수해야 합니다.
- **요금/한도**: 현재는 별도의 유료 플랜 없이 무료로 제공되고 있으나, 향후 기능 확장이나 정책 변경에 따라 정확한 비용 및 이용 한도는 공식 웹사이트에서 확인이 필요합니다.
- **계정 관리**: 컴퓨터의 백그라운드 에이전트와 모바일 기기 간의 페어링 코드가 타인에게 노출되지 않도록 관리하고 사용하지 않을 때는 세션 연결 상태를 수시로 점검하는 것이 안전합니다.

## 자주 묻는 질문

**아이폰이나 애플워치에서도 사용할 수 있나요?**

현재 Clair는 안드로이드 폰과 Wear OS 기반의 스마트워치만 지원하고 있으며, iOS 환경은 지원하지 않습니다.

**회사 보안망 내에서도 작동하나요?**

종단간 암호화를 지원하지만 회사 방화벽 설정에 따라 컴퓨터 에이전트와 모바일 앱 간의 페어링 연결이 제한될 수 있으므로 사전에 확인이 필요합니다.

**이 앱을 사용하려면 Claude Code가 반드시 설치되어 있어야 하나요?**

네, 그렇습니다. Anthropic의 터미널 도구인 Claude Code가 PC에 먼저 설치되어 실행 중인 상태여야 Clair 앱과 연동하여 원격 제어를 사용하실 수 있습니다.

**컴퓨터가 절전 모드에 들어가도 스마트워치로 제어할 수 있나요?**

아니오, 컴퓨터가 켜져 있고 온라인 상태를 유지해야 에이전트가 작동합니다. 컴퓨터가 절전 모드이거나 꺼져 있으면 모바일 기기와의 연결이 끊어져 원격 제어를 할 수 없습니다.

**스마트폰과 스마트워치 중 어디에서 먼저 응답해야 하나요?**

어느 기기에서든 먼저 응답한 결과가 최종 반영되며 터미널 화면에도 즉시 동기화됩니다. 먼저 답변이 처리되면 다른 기기의 알림은 자동으로 사라지므로 편한 기기를 사용하면 됩니다.

**이 앱은 공식 Anthropic에서 만든 공식 도구인가요?**

아니오, Anthropic이 제작하지 않은 독립형 서드파티 애플리케이션입니다. 공식 제품이 아니라는 점을 인지하고 보안 설정과 사용에 주의를 기울여야 합니다.

**블루투스 범위를 벗어난 야외에서도 스마트워치로 알림을 받을 수 있나요?**

네, 스마트워치에 Wi-Fi나 LTE 연결 기능이 있다면 블루투스 범위를 벗어난 야외에서도 인터넷을 통해 알림을 받고 답변을 보낼 수 있습니다.
