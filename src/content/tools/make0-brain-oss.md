## 한줄 요약

Make0 Brain OSS는 여러 AI 에이전트가 서로 다른 정보를 가지고 있어 발생하는 혼선을 방지합니다. 모든 에이전트가 동일한 문맥을 공유하게 함으로써 업무의 일관성을 유지하고 생산성을 극대화합니다.

## 핵심 기능

- **문맥 동기화**: 여러 AI 에이전트가 동일한 데이터를 공유하여 업무 일관성을 높입니다.
- **중앙 관리**: 흩어진 AI 에이전트의 정보를 한곳에서 관리하여 효율적입니다.
- **오픈소스 제공**: 직접 설치 및 커스터마이징이 가능하여 보안과 유연성이 뛰어납니다.

## 사용법

**1. 소스 코드 다운로드 및 환경 설정**

공식 저장소에서 코드를 내려받아 사내 서버나 로컬 환경에 설치합니다. 터미널로 필요한 의존성 패키지를 설치하고 환경 변수를 설정하여 기초 구동 환경을 마련합니다.

**2. 에이전트 연결 및 문맥 설정**

관리하고자 하는 각 AI 에이전트의 API 키를 대시보드에 입력합니다. 각 에이전트가 참조해야 할 공통 데이터베이스나 지식 베이스를 중앙 관리 설정에서 지정합니다.

**3. 데이터 동기화 규칙 정의**

에이전트 간에 공유할 데이터의 범위와 업데이트 주기를 설정합니다. 특정 에이전트가 생성한 결과물이 다른 에이전트의 입력값으로 활용되도록 워크플로우를 구성합니다.

**4. 통합 대시보드 모니터링**

중앙 대시보드에서 각 에이전트의 상태와 데이터 흐름을 실시간으로 확인합니다. 문제가 발생하면 로그를 분석하여 정보 공유가 원활하게 이루어지고 있는지 점검합니다.

## 가격 정책

- **무료 플랜**: 오픈소스 버전으로 무료로 사용 가능합니다.
- **유료 플랜**: 기업용 엔터프라이즈 플랜은 별도 문의가 필요하며 상세 가격은 규모에 따라 다릅니다.

비용 절약 팁: 오픈소스이므로 사내 서버에 직접 구축하면 라이선스 비용을 절감할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈소스 버전으로 무료로 사용 가능하며 직접 서버에 구축하면 별도의 라이선스 비용 없이 자유롭게 활용할 수 있습니다. 사용량에 따른 별도의 제한은 없으나 서버 사양에 따라 성능이 좌우됩니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 기업용 보안 기능과 기술 지원을 제공하며 조직 규모에 맞춘 맞춤형 설정이 가능합니다.

- **커스텀 구축 지원** (공식 페이지 확인 필요): 전문 컨설팅로 사내 인프라에 최적화된 구축 서비스와 유지보수를 지원받을 수 있습니다.

**환불과 해지**: 오픈소스 기반이므로 환불 정책은 없으며, 유료 서비스는 별도 계약 조건에 따라 처리됩니다.

## 한국어 지원

현재 인터페이스는 영어로 제공되지만 AI 에이전트가 처리하는 데이터는 한국어를 포함한 다국어를 지원합니다.

## 한국어 품질 실측

**마케팅 문구 통합**

- 프롬프트: 신제품 출시 홍보 문구를 작성해줘. 기존에 작성된 브랜드 가이드라인을 참조해서 작성해.
- 결과 예시: 브랜드 가이드라인에 따라 신뢰감 있는 어조로 작성된 홍보 문구가 출력됩니다. Make0 Brain이 동기화한 정보를 바탕으로 일관된 톤앤매너를 유지합니다.
- 관찰: 입력한 한국어 프롬프트를 정확히 이해하고 문맥에 맞는 한국어 문장을 생성합니다.

**고객 문의 응대**

- 프롬프트: 환불 규정를 고객에게 보낼 답변을 작성해줘. 이전에 저장된 회사 정책 문서를 참고해.
- 결과 예시: 회사 정책 문서에 명시된 환불 규정을 보고 정중한 한국어 답변이 생성됩니다. 여러 에이전트가 동일한 규정을 참조하여 일관된 답변을 제공합니다.
- 관찰: 한국어 전문 용어나 문맥 파악 능력이 준수하며 자연스러운 문장을 구성합니다.

인터페이스는 영어지만 한국어 데이터 처리 능력은 매우 우수합니다. 자연스러운 문장 생성과 한국어 문맥 유지가 가능하여 실무에 즉시 활용할 수 있습니다.

## 이런 분에게 추천합니다

다양한 AI 에이전트를 활용하여 복잡한 업무를 자동화하려는 개발자에게 추천합니다. 여러 부서의 데이터를 통합 관리해야 하는 IT 기획자에게 적합합니다. 사내 보안하려고 직접 AI 환경을 구축하려는 기업 담당자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 여러 AI 툴을 사용하다 보면 정보가 꼬일 때가 많습니다. 이 툴을 사용해 모든 에이전트의 최신 정보를 동기화하여 보고서 작성 시간을 단축합니다.
- **학생**: 연구 프로젝트하려고 여러 AI 모델을 동시에 활용합니다. 각 모델이 동일한 연구 배경을 이해하도록 설정하여 일관된 답변을 얻습니다.
- **소상공인**: 고객 응대 챗봇과 재고 관리 AI를 운영합니다. 두 에이전트가 동일한 재고 정보를 실시간으로 공유하게 하여 고객에게 정확한 안내를 제공합니다.

## 유사 툴과 비교

**장점:**
- 에이전트 간 정보 불일치 완벽 해결
- 오픈소스 기반의 높은 확장성

**단점:**
- 초기 설치 및 설정 과정이 다소 복잡함
- 한국어 가이드 부족

**이런 분에게 가장 적합합니다:** 여러 개의 AI 에이전트를 체계적으로 연결하여 복잡한 업무 프로세스를 자동화하려는 경우 가장 적합합니다.

## 장단점

**장점**

- 여러 AI 에이전트가 동일한 정보를 공유하여 업무 간의 불일치를 획기적으로 줄여줍니다.
- 오픈소스 기반으로 제공되어 기업의 보안 요구사항에 맞춰 내부 서버에 직접 설치할 수 있습니다.
- 중앙 관리 시스템로 흩어져 있는 업무 데이터를 한곳에서 효율적으로 통제할 수 있습니다.
- 사용자가 직접 기능을 커스터마이징할 수 있어 복잡한 사내 업무 환경에 유연하게 대응합니다.

**단점**

- 설치와 운영하려고 기술적 지식이 필요하여 초보자가 사용하기에는 난이도가 다소 높습니다.
- 인터페이스가 영어로만 제공되어 한국어 사용자에게는 초기 설정 시 진입 장벽이 있을 수 있습니다.
- 별도의 기술 지원을 받으려면 엔터프라이즈 플랜을 이용해야 하므로 관리에 노력이 필요합니다.

## 주의사항

- **개인정보**: 사내 서버에 직접 구축할 경우 데이터 보안은 전적으로 사용자에게 책임이 있으므로 철저한 보안 조치가 필요합니다.
- **저작권/상업적 이용**: 오픈소스 라이선스 규정을 반드시 확인하여 상업적 이용 시 준수해야 할 의무 사항을 파악해야 합니다.
- **요금/한도**: 유료 플랜 이용 시 기업 규모에 따라 가격이 달라지므로 공식 페이지로 정확한 견적을 문의해야 합니다.
- **계정 관리**: 중앙 관리 도구이므로 접근 권한 관리를 엄격히 하여 허가되지 않은 사용자가 데이터에 접근하지 않도록 해야 합니다.

## 자주 묻는 질문

**이 툴을 사용하려면 코딩 지식이 필수인가요?**

오픈소스 프로젝트이므로 설치와 초기 설정 과정에서 기본적인 기술적 이해도가 필요합니다. 개발 지식이 있다면 훨씬 자유롭게 커스터마이징할 수 있습니다.

**보안이 중요한 회사에서도 사용 가능한가요?**

네, 오픈소스이므로 사내 자체 서버(On-premise)에 직접 설치하여 운영할 수 있습니다. 외부 클라우드에 데이터를 노출하지 않고 안전하게 관리할 수 있는 것이 큰 장점입니다.

**어떤 종류의 AI 에이전트와 연동되나요?**

대부분의 현대적인 AI 에이전트 프레임워크와 호환되도록 설계되었습니다. API를 통해 다양한 언어 모델 및 에이전트 서비스와 연결하여 사용할 수 있습니다.

**개발자가 아닌데 사용할 수 있나요?**

설치 과정에 기술적 지식이 필요하므로 개발자의 도움 없이 운영하기는 어렵습니다. 비개발자라면 구축이 완료된 환경에서 가이드에 따라 사용하는 것만 가능합니다.

**기존에 쓰던 AI 서비스와 연동되나요?**

API를 제공하는 대부분의 AI 서비스와 연동이 가능합니다. 다만, 각 서비스의 API 연결 방식에 따라 추가적인 개발 작업이 필요할 수 있습니다.

**데이터 보안은 어떻게 보장하나요?**

사용자가 직접 사내 서버에 구축하므로 데이터가 외부 클라우드로 유출되지 않습니다. 자체적인 방화벽과 보안 정책을 적용하여 데이터를 안전하게 보호할 수 있습니다.

**한국어 설정은 어떻게 변경하나요?**

현재 인터페이스는 영어로 고정되어 있어 한국어 변경은 지원하지 않습니다. 하지만 에이전트가 처리하는 프롬프트와 결과물은 한국어로 자유롭게 입력하고 받을 수 있습니다.
