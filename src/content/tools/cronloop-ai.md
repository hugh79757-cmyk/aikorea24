## 한줄 요약

Cronloop AI는 반복적인 업무를 AI 에이전트가 대신 수행하도록 설정하는 자동화 툴입니다. 매일 혹은 매주 반복되는 복잡한 작업을 AI가 스스로 기억하고 실행하게 함으로써 업무 시간을 획기적으로 줄여줍니다.

## 핵심 기능

- **주기적 자동 실행**: 5분부터 일주일 단위까지 원하는 주기로 업무를 자동화할 수 있습니다.
- **에이전트 기억력**: 이전 실행 내용을 기억하여 다음 작업에 반영하므로 연속적인 업무 처리가 가능합니다.
- **다양한 모델 연동**: Codex나 Claude Code를 선택하여 본인의 목적에 맞는 AI를 활용할 수 있습니다.

## 사용법

**1. 에이전트 생성하기**

크롤링 텍스트를 바탕으로 대시보드에서 새로운 에이전트를 추가합니다. 마크다운 형식으로 업무 지시사항을 작성하고 실행 주기를 설정합니다.

**2. 도구 및 모델 연결**

Codex나 Claude Code 등의 AI 모델을 선택하고 본인의 구독 또는 API 키를 연결합니다. 작업에 필요한 Gmail, HubSpot 등의 외부 도구를 연동합니다.

**3. 실행 주기 및 조건 설정**

5분 간격부터 일주일 단위까지 원하는 스케줄을 지정합니다. 에이전트가 이전 실행 결과를 기억하고 스스로 개선할 수 있도록 설정을 마무리합니다.

**4. 자동화 실행 및 모니터링**

에이전트를 활성화하여 정해진 시간에 스스로 작동하도록 둡니다. 대시보드에서 각 실행 내역과 처리된 결과를 실시간으로 확인할 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 에이전트 생성 및 실행 기능을 무료로 이용할 수 있습니다.
- **유료 플랜**: Pro 플랜(약 3~4만 원대 예상, 변동 가능)으로 실행 시간 제한 해제 및 동시 작업 혜택을 제공합니다.

비용 절약 팁: 무료 플랜에서 충분히 테스트한 후, 업무 자동화 빈도가 높아질 때 유료 전환을 고려하세요.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 에이전트 생성 및 실행 기능을 무료로 이용할 수 있습니다. 다만 실행 시간이나 동시 작업 수에 제한이 있을 수 있으며, 상세한 한도는 공식 요금 페이지를 참고해야 합니다.

- **Pro 플랜** (공식 페이지 확인 필요): 월간 실행 시간 제한이 없고 최대 60분 동안 실행할 수 있으며 3개의 작업을 동시에 처리할 수 있는 혜택을 제공합니다.

**환불과 해지**: 환불 및 해지 정책에 대한 구체적인 내용은 크롤링 데이터에 명시되어 있지 않아 공식 홈페이지의 결제 안내를 확인해야 합니다.

## 한국어 지원

인터페이스는 영어로 제공되지만 AI에게 업무 지시를 내릴 때는 한국어로 상세히 입력해도 충분히 이해하고 수행합니다.

## 한국어 품질 실측

**영업 리드 발굴**

- 프롬프트: 타겟 고객군에 맞는 신규 잠재 고객 10명을 웹에서 찾아 조사하고 허브스팟에 등록해 줘.
- 결과 예시: 지정된 타겟 조건에 부합하는 잠재 고객 10명의 정보를 수집하여 허브스팟 CRM에 자동으로 입력하고 연구 노트를 남깁니다.
- 관찰: 한국어 지시를 명확하게 이해하고 CRM 연동 작업을 수행합니다.

**고객 지원 티켓 응답**

- 프롬프트: 지원 문서를 읽고 고객 문의 티켓에 답변을 이메일로 보내고 민감한 내용은 사람에게 전달해 줘.
- 결과 예시: 지원 문서 기반의 정확한 답변을 작성하여 이메일로 발송하고 특이사항이 있는 티켓은 담당자에게 에스컬레이션 처리합니다.
- 관찰: 복잡한 조건문이 포함된 업무 지시도 자연스럽게 처리합니다.

인터페이스는 영어 중심이지만 한국어로 상세한 업무 지시를 내릴 경우 AI가 충분히 이해하고 정확한 에이전트 작업을 수행합니다. 복잡한 비즈니스 로직도 매끄럽게 처리하는 편입니다.

## 이런 분에게 추천합니다

반복 업무로 인해 시간이 부족한 직장인, 고객 관리가 중요한 소상공인, 데이터 수집이 잦은 연구원에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 아침 뉴스레터를 수집하고 요약하는 업무를 자동화하여 보고서 작성 시간을 단축합니다. 매일 반복되는 리서치 과정을 AI가 대신하게 설정하여 퇴근 시간을 앞당길 수 있습니다.
- **학생**: 관심 있는 분야의 논문이나 아티클이 새로 올라오는지 주기적으로 확인합니다. 새로운 자료가 발견되면 즉시 요약본을 받아보도록 설정하여 학습 효율을 높입니다.
- **소상공인**: 신규 고객 문의를 주기적으로 확인하고 초기 응대 메시지를 자동으로 발송합니다. 고객 응대 누락을 방지하고 서비스 만족도를 높이는 데 활용합니다.

## 유사 툴과 비교

**장점:**
- 반복적인 업무를 완벽하게 자동화 가능

**단점:**
- 초기 설정 시 약간의 기술적 이해가 필요함
- 인터페이스가 영어로만 제공됨

**이런 분에게 가장 적합합니다:** 매일 똑같은 루틴의 업무를 반복하고 있는 분들에게 가장 적합합니다.

## 장단점

**장점**

- 5분부터 일주일 단위까지 원하는 주기에 맞춰 반복 업무를 완전 자동으로 처리할 수 있습니다.
- 에이전트가 이전 실행 내용을 기억하고 스스로 개선하여 연속성 있는 작업 처리가 가능합니다.
- Codex나 Claude Code 등 사용자가 원하는 AI 모델과 구독을 직접 연동하여 활용할 수 있습니다.
- 영업 아웃바운드부터 고객 지원, 마케팅 트래픽 관리까지 다양한 분야의 업무를 마크다운으로 쉽게 정의합니다.

**단점**

- 기본적인 인터페이스가 영어로 제공되어 국내 일반 사용자가 처음 이용할 때 다소 진입장벽이 있을 수 있습니다.
- 외부 도구와 API 키를 직접 연동해야 하므로 초기 설정 과정이 초보자에게는 복잡하게 느껴질 수 있습니다.
- 무료 플랜과 유료 Pro 플랜의 구체적인 가격과 크레딧 한도가 명확하게 공개되지 않아 확인이 필요합니다.

## 주의사항

- **개인정보**: 고객 데이터나 민감한 이메일 정보를 외부 AI 모델과 연동된 도구에 입력할 때는 보안 정책을 반드시 확인해야 합니다.
- **저작권/상업적 이용**: 에이전트가 자동으로 생성한 콘텐츠나 소셜 미디어 게시물은 상업적으로 발행하기 전에 사람이 직접 검토하는 과정이 필요합니다.
- **요금/한도**: 무료 플랜과 Pro 플랜의 실행 시간 및 동시 작업 제한이 다르므로 업무 규모에 맞게 요금제를 선택해야 합니다.
- **계정 관리**: Gmail, 허브스팟, 깃허브 등 다양한 외부 서비스의 API 키와 계정 권한이 연동되므로 주기적인 보안 점검이 필수적입니다.

## 자주 묻는 질문

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 마크다운(Markdown) 형식으로 업무 내용을 설명하기만 하면 되므로 전문적인 코딩 지식이 없어도 충분히 사용 가능합니다. 다만, 자동화의 논리를 설계하는 과정에서 약간의 학습이 필요할 수 있습니다.

**개인 정보나 기업 정보가 유출되지 않을까요?**

사용자의 API 키를 사용하여 실행되므로 보안은 본인의 API 제공업체 정책을 따릅니다. 중요한 민감 정보는 가급적 직접 입력하지 않는 것을 권장합니다.

**실행 주기를 아주 짧게 설정할 수도 있나요?**

네, 최소 5분 단위부터 설정이 가능합니다. 실시간에 가까운 업무 처리가 필요한 경우 짧은 주기를 활용해 보세요.

**프로그래밍 지식이 없어도 에이전트를 만들 수 있나요?**

마크다운 형식으로 수행할 업무를 자연스럽게 서술할 수 있다면 누구나 에이전트를 만들 수 있습니다. 다만 외부 도구와 API 키 연결 과정에서 약간의 사전 지식이 필요할 수 있습니다.

**어떤 AI 모델을 연동해서 사용할 수 있나요?**

크롤링 데이터에 따르면 Codex나 Claude Code 같은 모델을 본인의 구독이나 프로바이더 API 키를 통해 연동하여 사용할 수 있습니다.

**에이전트가 실행되는 동안 컴퓨터를 켜두어야 하나요?**

Cronloop AI는 클라우드 기반으로 스케줄에 따라 백그라운드에서 자동 실행되므로 사용자의 컴퓨터가 꺼져 있어도 정상 작동합니다.

**에이전트가 잘못된 작업을 수행하면 어떻게 하나요?**

대시보드에서 에이전트의 실행을 일시 정지하거나 중지할 수 있으며 이전 실행 내역을 모니터링하여 지시사항을 수정할 수 있습니다.
