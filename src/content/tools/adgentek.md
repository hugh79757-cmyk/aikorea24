## 한줄 요약

Adgentek는 AI 챗봇이나 대화형 서비스 운영자가 대화 창 내부에 자연스러운 광고를 삽입하여 수익을 올릴 수 있도록 돕습니다. 사용자의 대화 맥락을 해치지 않으면서 광고를 노출하여 개발자와 크리에이터의 부가 수익 창출을 지원합니다.

## 핵심 기능

- **광고 수익화**: AI 대화 화면에 광고를 연동해 자동으로 수익을 창출합니다.
- **맥락 분석**: 대화 주제를 분석하여 어울리는 맞춤형 광고를 노출합니다.
- **간편한 연동**: 기존 AI 서비스에 쉽게 API를 붙여 광고를 송출합니다.

## 사용법

**1. 서비스 회원가입 및 등록**

Adgentek 공식 홈페이지에 접속하여 개발자 계정을 생성합니다. 대화형 AI 서비스 정보를 입력하여 프로젝트를 등록합니다.

**2. API 연동 코드 삽입**

제공되는 연동 가이드와 API 키를 확인합니다. 운영 중인 AI 챗봇 서버 환경에 광고 송출 코드를 적용합니다.

**3. 대화 맥락 분석 설정**

챗봇 사용자의 대화 주제를 정확하게 파악할 수 있도록 세부 옵션을 설정합니다. 광고가 이질감 없이 노출되도록 빈도를 조율합니다.

**4. 수익 창출 및 성과 확인**

대화창 내부에서 발생하는 광고 노출과 클릭 데이터를 대시보드에서 모니터링합니다. 트래픽에 따른 정산 수익을 주기적으로 확인합니다.

## 가격 정책

- **무료 플랜**: 기본적인 API 연동 테스트를 무료로 지원합니다.
- **유료 플랜**: 프로 플랜 월 4만 5천 원 상당, 트래픽 기반 수익 분배 모델 제공.

비용 절약 팁: 초기에는 무료 플랜으로 연동 테스트를 거친 후 트래픽 규모에 맞춰 유료 플랜을 선택하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 API 연동 테스트를 무료로 지원합니다. 초기 개발 단계나 소규모 트래픽 환경에서 비용 부담 없이 기능을 시험해 볼 수 있습니다.

- **프로 플랜** (월 4만 5천 원 상당 (공식 페이지 확인 필요)): 트래픽 기반 수익 분배 모델과 확장된 광고 송출 기능을 제공합니다.

- **엔터프라이즈 플랜** (정확한 금액과 한도는 공식 요금 페이지에서 확인이 필요합니다.): 대규모 트래픽을 처리하는 기업 고객을 위한 맞춤형 광고 연동과 전담 기술 지원을 제공합니다.

**환불과 해지**: 구독 해지 및 환불 규정은 이용 약관에 따라 다를 수 있으므로 결제 전 공식 고객센터로 확인하는 것이 안전합니다.

- 프롬프트: 서울 근교의 조용한 한옥 카페를 추천해 줘. 분위기 좋은 곳으로 알려줘.
- 결과 예시: 사용자의 취향을 반영한 한옥 카페 목록을 안내한 뒤, 자연스럽게 근처 제휴 카페의 할인 쿠폰이나 관련 브랜드 광고를 텍스트 형태로 제안합니다.
- 관찰: 영문 중심 서비스이므로 한국어 대화 환경에서는 문맥에 맞는 자연스러운 광고 문구 생성하려고 별도의 세밀한 설정이 필요합니다.

**영어 회화 연습 챗봇 광고**

- 프롬프트: 비즈니스 이메일에 쓸 수 있는 정중한 표현을 몇 가지 알려주세요.
- 결과 예시: 업무용 영어 표현 예시를 꼼꼼하게 정리해 주고, 하단에 실전 화상 영어 프로그램이나 번역 유료 앱의 자연스러운 맞춤형 광고를 띄워줍니다.
- 관찰: 한국어 질문의 맥락을 분석할 때 어색한 번역투가 섞이지 않도록 프롬프트와 연동 설정을 꼼꼼하게 점검해야 합니다.

현재 영문 인터페이스를 중심으로 제공되고 있어 한국어 대화 환경에서 완벽한 자연스러움을 구현하려면 추가적인 설정과 테스트가 반드시 필요합니다.

## 자주 묻는 질문

**AI 대화 내용이 광고주에게 노출되나요?**

사용자의 프라이버시를 보호하며 구체적인 개인 정보가 아닌 대화의 주제와 맥락만을 분석하여 맞춤 광고를 매칭합니다.

**수익은 어떻게 정산되나요?**

광고 노출 수와 클릭률을 기반으로 매월 정산이 이루어지며, 설정된 계좌나 결제 수단로 지급됩니다.

**기존에 만들었던 챗봇에도 연동할 수 있나요?**

제공되는 API와 개발 가이드를 따르면 기존에 구축한 AI 대화 서비스에도 손쉽게 연동할 수 있습니다.

**챗봇 사용자에게 광고를 노출하면 거부감이 들지 않나요?**

Adgentek는 대화의 맥락과 주제를 분석하여 어울리는 정보형 광고를 제안하기 때문에 일반적인 배너 광고보다 거부감이 적습니다. 다만, 광고 빈도가 너무 높으면 사용자 경험을 해칠 수 있으므로 적절한 노출 빈도 조절이 필요합니다.

**한국어 챗봇 서비스에도 곧바로 연동해서 쓸 수 있나요?**

현재는 영문 인터페이스를 기준으로 최적화되어 있어 한국어 대화 환경에서는 맞춤형 광고가 자연스럽게 노출되도록 별도의 세부 설정과 테스트를 거치는 것이 좋습니다.

**수익은 어떤 방식으로 정산받게 되나요?**

사용자가 챗봇 내에서 광고를 보거나 클릭하는 등 트래픽 기반의 수익 분배 모델을 통해 정산됩니다. 정확한 정산 주기와 최소 출금 금액은 대시보드 및 공식 안내를 참고해야 합니다.

**개발 지식이 부족해도 API를 연동할 수 있나요?**

기본적인 웹 개발 지식과 API 연동 경험이 있는 개발자나 1인 창업자에게 적합한 툴입니다. 코딩 지식이 전혀 없다면 초기 연동 과정에서 약간의 어려움이 있을 수 있습니다.
