## 한줄 요약

DeepSeek Harness는 AI 에이전트가 수행하는 복잡한 작업을 플러그인 형태로 조립하여 관리하는 오픈소스 런타임입니다. 개발자가 AI의 작업 과정을 세밀하게 제어하고 필요에 따라 도구나 모델을 교체하며 효율적인 자동화 환경을 구축하도록 돕습니다.

## 핵심 기능

- **플러그인 구조**: 필요한 기능만 골라 조립하여 에이전트 성능을 최적화합니다.
- **작업 로그 확인**: 에이전트가 어떤 과정을 거쳐 결과를 냈는지 투명하게 확인합니다.
- **샌드박스 보안**: 안전한 환경에서 에이전트가 도구를 사용하도록 제어합니다.

## 사용법

**1. 개발 환경 설정하기**

Node.js 22.19 이상 버전을 설치한 후, 터미널에서 'npx @deepseek-ai/dsh web' 명령어를 입력합니다. 이로 로컬 환경에서 도구의 웹 인터페이스를 즉시 실행할 수 있습니다.

**2. 플러그인 구성하기**

Cordis 커널을 활용하여 모델, 도구, 샌드박스 등 필요한 기능을 플러그인 형태로 마운트합니다. 각 플러그인은 작업 흐름에 맞춰 자유롭게 교체하거나 제거할 수 있습니다.

**3. 에이전트 루프 실행**

웹 UI 또는 헤드리스 러너를 사용하여 정의된 에이전트 루프를 시작합니다. 에이전트가 모델을 호출하고 도구를 실행하는 모든 과정을 실시간으로 모니터링할 수 있습니다.

**4. 작업 로그 분석하기**

에이전트가 수행한 작업은 'Append-only' 세션 로그에 기록됩니다. 이로 에이전트가 어떤 경로로 결과를 도출했는지 추적하고 디버깅을 수행합니다.

## 가격 정책

- **무료 플랜**: 오픈소스 기반으로 무료 체험 및 사용이 가능합니다.
- **유료 플랜**: 별도의 엔터프라이즈 지원 플랜이 존재할 수 있으며, 상세 가격은 공식 웹사이트 문의가 필요합니다.

비용 절약 팁: 오픈소스 프로젝트이므로 직접 서버에 구축하면 추가 비용 없이 기능을 활용합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈소스 프로젝트로서 별도의 제한 없이 자유롭게 로컬 서버에 구축하여 사용할 수 있습니다. 공식 웹사이트에서 제공하는 무료 체험판로 기능을 미리 확인하는 것이 가능합니다.

- **엔터프라이즈 지원 플랜** (공식 페이지 확인 필요): 기업 환경에서의 대규모 배포 및 기술 지원을 위한 맞춤형 플랜입니다.

- **커스텀 통합 솔루션** (공식 페이지 확인 필요): 특정 기업의 인프라에 최적화된 플러그인 개발 및 유지보수를 지원합니다.

**환불과 해지**: 오픈소스 기반이므로 라이선스 정책에 따르며, 유료 지원 서비스의 경우 계약 내용에 따라 환불 규정이 달라질 수 있습니다.

## 한국어 지원

도구 자체가 개발자 중심의 기술적 인터페이스를 제공하며 공식 문서나 인터페이스는 영어로만 지원됩니다.

## 한국어 품질 실측

**데이터 추출 자동화**

- 프롬프트: 웹사이트에서 특정 데이터를 추출하여 JSON 형식으로 저장하는 에이전트 루프를 생성해줘.
- 결과 예시: 데이터 추출 플러그인을 마운트했습니다. 대상 URL에 접속하여 텍스트를 파싱한 뒤, 지정된 경로에 JSON 파일로 저장하는 루프가 활성화되었습니다.
- 관찰: 입력값은 영어로 처리하는 것이 안정적이며, 결과값은 설정에 따라 영어로 출력될 가능성이 높습니다.

**코드 검토 에이전트**

- 프롬프트: 작성한 TypeScript 코드의 오류를 검사하고 수정 제안을 해주는 에이전트를 설정해줘.
- 결과 예시: 코드 분석 샌드박스가 연결되었습니다. 현재 작성된 코드의 문법 오류와 잠재적 버그를 분석하여 수정 사항을 로그 창에 출력합니다.
- 관찰: 전문적인 개발 용어는 정확하게 전달되나, 자연스러운 한국어 문장 생성 능력은 다소 부족할 수 있습니다.

도구 자체가 개발자를 위한 기술적 인터페이스를 제공하므로 한국어 지원은 미비합니다. 인터페이스와 문서가 모두 영어로 구성되어 있어 한국어 사용자에게는 높은 진입 장벽이 존재합니다.

## 이런 분에게 추천합니다

복잡한 업무 자동화 시스템을 직접 구축하고 싶은 개발자, AI 에이전트의 실행 과정을 세밀하게 제어하고 싶은 기술 전문가, 오픈소스 기반의 AI 도구를 선호하는 분에게 추천합니다.

## 실제 활용 예시

- **직장인**: 반복적인 데이터 처리 업무를 자동화하기 위해 여러 AI 도구를 연결하는 파이프라인을 직접 구축합니다. 에이전트가 오류 없이 작동하는지 로그를 확인하며 업무 효율을 높입니다.
- **학생**: AI 에이전트 연구하려고 특정 모델과 도구를 결합한 실험 환경을 구축합니다. 플러그인을 교체하며 에이전트의 성능 변화를 체계적으로 기록합니다.
- **소상공인**: 고객 응대 자동화하려고 여러 외부 서비스와 연동되는 에이전트를 직접 설계합니다. 보안이 확보된 환경에서 고객 데이터를 안전하게 처리합니다.

## 장단점

**장점**

- 플러그인 기반 아키텍처로 필요한 기능만 선택적으로 조립하여 효율적인 에이전트 환경을 구축할 수 있습니다.
- 오픈소스 프로젝트로서 누구나 무료로 다운로드하여 자신의 서버에 직접 설치하고 자유롭게 커스터마이징이 가능합니다.
- 에이전트가 작업하는 모든 과정을 세밀하게 기록하는 세션 로그 기능로 투명한 디버깅과 결과 확인을 지원합니다.
- TypeScript 기반으로 설계되어 현대적인 개발 환경과 높은 호환성을 가지며, 헤드리스 러너를 통한 자동화 파이프라인 구성이 용이합니다.

**단점**

- 개발자 중심의 도구로 인터페이스와 문서가 모두 영어로 되어 있어 비개발자가 접근하기에는 난이도가 매우 높습니다.
- 별도의 클라우드 서비스가 아닌 로컬 환경 구축이 핵심이므로 서버 설정 및 관리에 대한 지식이 필수적으로 요구됩니다.
- 사용자 친화적인 GUI보다는 CLI 기반의 조작 비중이 높아 일반 사용자가 실무에 바로 적용하기에는 어려움이 있습니다.

## 주의사항

- **개인정보**: 로컬 환경에서 구동되지만 외부 API 호출 시 개인정보나 민감한 데이터가 포함되지 않도록 보안 설정에 유의해야 합니다.
- **저작권/상업적 이용**: MIT 라이선스를 따르는 오픈소스 프로젝트이므로 상업적 이용 시 해당 라이선스 조항을 반드시 준수해야 합니다.
- **요금/한도**: 도구 자체는 무료이나, 연결하는 AI 모델의 API 사용량에 따라 각 모델 제공업체의 별도 비용이 발생할 수 있습니다.
- **계정 관리**: 로컬 환경에서 실행하는 도구이므로 별도의 계정 관리보다는 로컬 설치 파일과 보안 키 관리에 주의를 기울여야 합니다.

## 자주 묻는 질문

**코딩을 전혀 못 해도 사용할 수 있나요?**

아니요, 이 도구는 개발자를 위한 런타임 환경이므로 기본적인 프로그래밍 지식과 터미널 환경 사용법을 알고 있어야 합니다.

**어떤 종류의 플러그인을 사용할 수 있나요?**

모델, 외부 도구, 데이터 저장소, 세션 관리 등 에이전트 실행에 필요한 다양한 기능을 플러그인 형태로 연결하여 사용할 수 있습니다.

**무료로 계속 사용할 수 있나요?**

네, 오픈소스 프로젝트이므로 소스 코드를 활용하여 직접 환경을 구축하면 무료로 사용이 가능합니다.

**일반인도 사용할 수 있나요?**

이 도구는 개발자를 타깃으로 설계되었습니다. 프로그래밍 지식과 Node.js 환경에 대한 이해가 없다면 사용이 매우 어렵습니다.

**클라우드에서 바로 쓸 수 있나요?**

기본적으로 로컬 환경에서 구동하는 것을 전제로 합니다. 서버에 직접 설치하여 실행해야 하며, 웹 UI는 127.0.0.1 주소로 제공됩니다.

**지원하는 AI 모델은 무엇인가요?**

플러그인 방식을 통해 OpenAI, Anthropic, DeepSeek 등 다양한 모델을 어댑터 형태로 연결하여 사용할 수 있습니다.

**데이터 보안은 안전한가요?**

로컬에서 실행되기 때문에 데이터가 외부 서버로 즉시 전송되지 않습니다. 다만, 사용자가 연결하는 외부 AI 모델의 정책에 따라 데이터 처리 방식이 달라질 수 있습니다.
