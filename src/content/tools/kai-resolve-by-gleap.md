## 한줄 요약

Kai Resolve는 복잡한 기술적 고객 문의를 스스로 분석하여 해결하는 AI 지원 도구입니다. 로그 기록, 코드, 계정 데이터를 종합적으로 검토하여 상담원의 업무 부담을 획기적으로 줄여줍니다.

## 핵심 기능

- **자동 티켓 분석**: 로그와 세션 데이터를 분석해 문제 원인을 즉시 파악합니다.
- **코드 기반 진단**: 실제 소스 코드를 참조하여 정확한 기술적 해결책을 제시합니다.
- **자동 에스컬레이션**: AI가 해결하기 어려운 문제는 담당자에게 적절한 진단서와 함께 전달합니다.

## 사용법

**1. 서비스 연동 및 데이터 소스 연결**

Gleap 대시보드 내 설정 메뉴에서 고객 문의 티켓이 접수되는 이메일이나 채널을 연동합니다. 기술적 분석하려고 소스 코드 저장소에 대한 읽기 전용 접근 권한을 부여합니다.

**2. 기술 지원 티켓 접수 및 분석**

고객이 버그나 기술 문제를 제보하면 Kai Resolve가 자동으로 화면 녹화, 로그 기록, 계정 데이터를 수집합니다. AI가 즉시 해당 데이터를 바탕으로 문제의 원인을 분석하기 시작합니다.

**3. AI 진단 및 해결책 제시**

분석이 완료되면 AI가 고객에게 직접 답변을 보내거나, 해결이 어려운 경우 진단 보고서를 작성합니다. 개발팀은 AI가 제안한 진단 내용을 확인하고 수정 작업을 수행합니다.

**4. 개발 작업 생성 및 리뷰**

AI가 확인한 버그를 바탕으로 개발 작업을 생성하여 팀 내 워크플로우에 등록합니다. 수정이 완료되면 개발자는 변경 사항을 리뷰하고 고객에게 최종 결과를 안내합니다.

## 한국어 지원

현재 인터페이스와 분석 엔진은 영어 기반으로 운영되며, 한국어 고객 문의 대응 시에는 별도의 번역 설정이 필요할 수 있습니다.

## 한국어 품질 실측

**기술 버그 문의 답변**

- 프롬프트: 로그인 후 버튼을 누르면 500 에러가 발생합니다. 원인을 분석해 주세요.
- 결과 예시: AI가 해당 세션의 로그를 확인한 결과, 데이터베이스 연결 오류를 발견했습니다. 수정이 필요하며 개발팀에 티켓을 에스컬레이션합니다.
- 관찰: 영어 기반 모델이므로 한국어 입력 시 문맥 파악이 다소 부정확할 수 있습니다.

**코드 오류 진단 요청**

- 프롬프트: 특정 API 호출 시 응답이 지연되는 이유를 소스 코드에서 찾아주세요.
- 결과 예시: 코드 분석 결과 특정 루프에서 메모리 누수가 발생하고 있습니다. 해당 코드 블록을 수정하는 작업을 생성했습니다.
- 관찰: 기술 용어는 영어로 처리될 때 가장 정확도가 높습니다.

현재 인터페이스와 분석 엔진이 영어로 최적화되어 있어 한국어 처리 시 번역 과정을 거쳐야 합니다. 기술적인 문맥은 잘 이해하지만 자연스러운 한국어 답변을 위해서는 별도의 프롬프트 조정이 필요합니다.

## 자주 묻는 질문

**기술적인 지식이 없어도 사용할 수 있나요?**

본 툴은 코드와 로그를 다루기 때문에 기본적인 개발 지식이 있는 팀원이 관리하는 것이 좋습니다. 기술 지원 자동화를 지향하는 만큼 설정 과정에서 기술적 이해도가 요구됩니다.

**한국어 고객 응대도 가능한가요?**

현재는 영어 기반의 분석에 최적화되어 있습니다. 한국어 문의를 처리하려면 프롬프트 설정로 한국어 대응이 가능하도록 튜닝하는 과정이 필요합니다.

**개인정보 보호는 어떻게 되나요?**

Gleap은 보안을 중요하게 생각하며 기업용 솔루션 수준의 데이터 보호 정책을 갖추고 있습니다. 상세한 보안 문서는 공식 홈페이지의 보안 페이지를 확인하시기 바랍니다.

**Kai Resolve는 모든 언어의 코드를 분석할 수 있나요?**

대부분의 주요 프로그래밍 언어를 지원하지만, 복잡한 프레임워크나 비표준 언어의 경우 분석 정확도가 다를 수 있습니다.

**보안을 위해 코드 분석 범위를 제한할 수 있나요?**

네, 설정에서 AI가 접근할 수 있는 저장소와 데이터 범위를 세밀하게 조정하여 보안 수준을 관리할 수 있습니다.

**AI가 해결하지 못한 티켓은 어떻게 처리되나요?**

AI가 진단 보고서와 수집된 증거 자료를 함께 담당 상담원에게 전달하여 사람이 즉시 후속 조치를 할 수 있도록 돕습니다.

**무료 체험 후 자동으로 유료 결제가 되나요?**

일반적으로 무료 체험 종료 후에는 요금제 선택 절차를 거치게 되며, 결제 정보 입력 여부에 따라 다릅니다. 공식 페이지의 안내를 확인하십시오.
