## 한줄 요약

AwaitIO는 개발자가 TypeScript 함수만 정의하면 관리자 화면(Admin Screen)을 즉시 생성해 주는 도구입니다. 복잡한 UI 개발 과정을 생략하여 백오피스 구축에 드는 시간을 획기적으로 줄여줍니다.

## 핵심 기능

- **자동 UI 생성**: 함수 로직에 맞춰 관리자 화면을 자동으로 구성하여 개발 시간을 단축합니다.
- **TypeScript 지원**: 익숙한 타입스크립트 문법을 사용하여 안정적인 코드 작성이 가능합니다.
- **빠른 백오피스**: 사내 관리용 도구를 별도 디자인 없이 빠르게 구현할 수 있습니다.

## 사용법

**1. 개발 환경 설정 및 연동**

AwaitIO 라이브러리를 프로젝트에 설치하고 기존 API 라우트와 유사한 방식으로 앱을 구성합니다. TypeScript 환경에서 app.defineAction을 사용하여 관리자 기능을 정의할 준비를 합니다.

**2. 관리자 기능 로직 작성**

관리자가 수행할 작업을 비동기(async) TypeScript 함수로 작성합니다. io.input, io.select 등 제공되는 컴포넌트를 사용하여 사용자로부터 입력받을 데이터 형식을 지정합니다.

**3. 화면 컴포넌트 호출**

코드 실행 중 io.input.text나 io.select.table 등을 호출하면 브라우저에 즉시 입력 폼이 생성됩니다. 개발자가 별도로 프론트엔드 UI를 만들 필요 없이 함수 로직이 흐름에 따라 화면을 제어합니다.

**4. 데이터 처리 및 완료**

사용자가 입력한 값을 보고 데이터베이스를 업데이트하거나 외부 API를 호출합니다. ctx.loading 기능을 사용해 작업 진행 상황을 관리자에게 시각적으로 보여주며 마무리합니다.

## 한국어 품질 실측

**고객 환불 처리**

- 프롬프트: 고객 이메일을 입력받아 주문 내역을 조회하고 환불을 진행하는 관리자 함수를 작성합니다.
- 결과 예시: 화면에는 'Customer email' 입력창이 나타나고, 이후 조회된 주문 목록이 테이블 형태로 출력됩니다. 관리자가 항목을 선택하고 'Refund'를 누르면 작업이 완료됩니다.
- 관찰: 입력창 라벨이나 버튼 이름은 영어로 출력되므로 한국어 환경에서는 별도의 설정이 필요할 수 있습니다.

**배송 상태 변경**

- 프롬프트: 주문 번호를 입력받아 배송 상태를 '배송 중'으로 변경하는 로직을 구현합니다.
- 결과 예시: 관리자 페이지에 주문 번호 입력 폼이 생성되고, 상태 변경 확인 메시지가 팝업으로 나타납니다. 모든 UI는 영어로 표시됩니다.
- 관찰: 도구 자체가 한국어를 지원하지 않아 관리자 페이지의 모든 텍스트를 영어로 작성해야 하는 번거로움이 있습니다.

현재 한국어 인터페이스를 지원하지 않아 모든 UI 요소와 가이드가 영어로 제공됩니다. 한국어 데이터를 처리할 수는 있으나 관리자 페이지의 레이블은 직접 영어로 코딩해야 합니다.

## 장단점

**장점**

- 별도의 프론트엔드 개발 없이 TypeScript 함수만으로 즉시 관리자 페이지를 구축할 수 있어 생산성이 매우 높습니다.
- 기존 API 라우트와 유사한 직관적인 문법을 사용하여 백엔드 개발자라면 누구나 빠르게 적응할 수 있습니다.
- 데이터베이스 연동 및 사용자 입력 처리가 코드 내에서 자연스럽게 흐르므로 복잡한 상태 관리를 줄일 수 있습니다.
- 사내 관리용 대시보드를 빠르게 프로토타이핑하거나 소규모 운영 도구를 제작할 때 최적의 효율을 제공합니다.

**단점**

- 한국어 인터페이스를 지원하지 않아 관리자 페이지의 모든 메뉴와 안내 문구를 영어로 작성해야 하는 불편함이 있습니다.
- UI 디자인을 세밀하게 커스텀하는 데 한계가 있어 브랜드 고유의 디자인 시스템을 적용하기 어렵습니다.
- 복잡한 비즈니스 로직이 포함된 대규모 관리자 시스템을 구축하기에는 확장성 측면에서 제한적일 수 있습니다.

## 자주 묻는 질문

**코딩을 전혀 모르는 초보자도 사용할 수 있나요?**

아니요, TypeScript 함수를 작성해야 하므로 기본적인 프로그래밍 지식이 필수적입니다. 개발 경험이 있는 분들에게 최적화된 도구입니다.

**생성된 페이지를 내 웹사이트에 바로 연결할 수 있나요?**

네, 생성된 관리자 화면은 기존 웹 프로젝트와 연동하여 즉시 관리 도구로 활용할 수 있습니다.

**보안 설정은 어떻게 하나요?**

관리자 페이지에 대한 접근 권한 설정은 제공되는 가이드를 따라 코드 수준에서 별도로 구현해야 합니다.

**프론트엔드 지식이 전혀 없어도 사용할 수 있나요?**

TypeScript를 활용한 백엔드 로직 작성 능력이 필요합니다. 프론트엔드 화면을 직접 코딩할 필요는 없지만, 기본적인 프로그래밍 언어 이해도는 필수입니다.

**기존에 운영 중인 데이터베이스와 바로 연동되나요?**

네, 코드 내에서 기존 데이터베이스 클라이언트를 사용하여 데이터를 조회하고 수정할 수 있습니다. 별도의 복잡한 연동 과정 없이 함수 내에서 호출하면 됩니다.

**한국어 데이터 입력이나 출력은 가능한가요?**

데이터 자체는 한국어로 저장하고 출력할 수 있습니다. 다만 관리자 페이지 내의 라벨이나 버튼 등 UI 요소는 영어로만 표시되므로 이 점을 고려해야 합니다.

**무료 플랜으로 실제 서비스 운영이 가능한가요?**

간단한 사내 도구라면 가능합니다. 다만 데이터 처리량이나 고급 기능이 필요한 경우 유료 플랜 전환이 필요할 수 있으니 공식 요금 페이지를 꼭 확인하십시오.
