## 한줄 요약

Cognee AI는 정보를 기억하고 검색할 수 있는 기능을 제공하여 업무 효율성을 높입니다. 다양한 플랫폼과 연동되어 사용이 편리합니다.

## 핵심 기능

- **지속적 메모리**: 이전 대화 내용을 기억하여 반복적인 질문을 줄입니다.
- **검색 기능**: 필요한 정보를 쉽게 찾아낼 수 있습니다.
- **다양한 연동**: 여러 플랫폼과 연결되어 데이터 통합이 가능합니다.

## 사용법

**1. 개발 환경에 SDK 설치하기**

공식 문서와 연동 가이드를 참고하여 프로젝트에 Cognee SDK를 설치합니다. 파이썬 환경 등에서 API를 활용할 수 있도록 기본 설정을 마칩니다.

**2. 데이터 소스 연결하기**

슬랙, 노션, 구글 드라이브 등 자주 사용하는 업무 도구나 파일 저장소를 연동합니다. 다양한 문서와 채팅 기록을 하나의 기억 레이어로 불러올 수 있습니다.

**3. 메모리 및 그래프 구축하기**

수집된 데이터를 바탕으로 에이전트가 맥락을 이해할 수 있도록 벡터 및 그래프 메모리를 생성합니다. 커스텀 데이터 모델을 활용해 정보 구조를 정립합니다.

**4. 에이전트 프레임워크와 연동하기**

Claude Code, Cursor, LangGraph 등 지원되는 에이전트 프레임워크와 연결하여 읽고 쓰는 메모리 기능을 활성화합니다. 세션을 넘어 지속되는 검색 기능을 활용합니다.

## 가격 정책

- **무료 플랜**: 기본 기능을 무료로 사용할 수 있습니다.
- **유료 플랜**: 프리미엄 플랜 10,000원으로 추가 기능을 제공합니다.

비용 절약 팁: 오픈소스라 무료로 활용하는 부분이 많습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본 제공되는 오픈소스 기능과 무료 사용 구간로 신용카드 등록 없이 도구를 이용할 수 있습니다. 로컬 환경 배포 및 기본 SDK 활용이 가능하며 구체적인 무료 API 호출 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **프리미엄 플랜** (월 10,000원 (정확한 금액은 공식 요금 페이지 확인 필요)): 클라우드 스케일링 기능 및 추가적인 관리자 도구를 제공하여 팀 단위의 효율적인 데이터 연동을 지원합니다.

- **Cognee Cloud 클라우드 플랜** (공식 페이지 확인 필요): 로컬 배포를 넘어 클라우드 환경에서 프로젝트 맥락과 과거 작업 기록을 안전하게 보존하고 확장할 수 있습니다.

**환불과 해지**: 유료 플랜 결제 및 환불, 구독 해지와 관련된 구체적인 규정은 공식 홈페이지의 요금 및 결제 정책 페이지에서 직접 확인해야 합니다.

## 한국어 품질 실측

**회의록 및 문서 통합 검색**

- 프롬프트: 지난주 구글 드라이브와 슬랙에 업로드된 프로젝트 회의록 중에서 마케팅 예산 관련 내용을 요약해 줘.
- 결과 예시: 구글 드라이브의 기획 문서와 슬랙 대화 내용을 보고, 지난주 논의된 마케팅 예산 확정안과 주요 수정 사항을 종합하여 정리해 줍니다. 세션을 넘어 지속되는 기억 기능로 관련 맥락을 정확하게 짚어냅니다.
- 관찰: 다양한 외부 플랫폼의 데이터를 매끄럽게 연결하여 한국어 질문에 정확한 답변을 도출합니다.

**개발 에이전트 맥락 유지**

- 프롬프트: 이전에 커서(Cursor) 에이전트와 나눴던 API 연동 방식에 대한 대화 내용을 기억해서 코드를 수정해 줘.
- 결과 예시: 이전 세션에서 논의했던 인증 토큰 처리 방식과 엔드포인트 구조를 반영하여, 현재 작성 중인 코드에 알맞은 수정안을 제시합니다. 반복적인 설명 없이도 이전 작업 맥락을 바로 이어갈 수 있습니다.
- 관찰: 개발 관련 전문 용어와 코드 맥락을 안정적으로 기억하고 처리하는 성능을 보여줍니다.

개발자 중심의 도구이지만 일반 업무 환경에서도 유연하게 활용할 수 있습니다. 번역투가 다소 느껴질 수 있으나 한국어 문맥을 이해하고 데이터를 검색하는 데 큰 무리가 없습니다.

**장점**

- 슬랙, 노션, 구글 드라이브 등 다양한 업무용 플랫폼과 간편하게 연동하여 데이터를 통합할 수 있습니다.
- 세션을 넘어 이어지는 지속적인 메모리 기능을 제공하여 에이전트가 이전 대화 맥락을 완벽하게 기억합니다.
- 오픈소스 기반으로 제공되어 개발 환경에 맞게 로컬에 직접 배포하고 온프레미스 제어가 가능합니다.
- 그래프 및 벡터 메모리를 활용해 복잡한 문서와 대화 속에서도 필요한 정보를 정확하게 검색할 수 있습니다.

- 한글화된 상세 가이드나 사용자 인터페이스가 부족하여 국내 사용자가 활용법을 익히기에 번거로울 수 있습니다.
- 클라우드 서비스 이용 시 가격 정책이나 상세 요금 구조가 명확하게 직관적이지 않을 수 있습니다.

- **요금/한도**: 무료 플랜과 클라우드 유료 플랜 간의 기능 차이 및 API 호출 한도가 변경될 수 있으므로 정기적으로 공식 요금 페이지를 확인해야 합니다.
- **계정 관리**: 다양한 개발자 도구 및 에이전트 프레임워크와의 연동 과정에서 API 키와 접근 권한 토큰이 유출되지 않도록 안전하게 보관해야 합니다.

## 자주 묻는 질문

**Cognee AI는 어떻게 사용하나요?**

Cognee AI는 다양한 플랫폼과 연동하여 정보를 기록하고 검색하는 데 사용됩니다. 사용자는 SDK와 API를 통해 쉽게 접근할 수 있습니다.

**무료로 사용하는 기능은 무엇인가요?**

Cognee AI의 기본 기능은 무료로 제공되며, 지속적인 메모리와 검색 기능을 포함합니다.

**어떤 플랫폼과 연동되나요?**

Slack, Notion, Google Drive 등 다양한 플랫폼과 연동되어 데이터 통합이 가능합니다.

**개발자가 아닌 일반 직장인도 쉽게 사용할 수 있나요?**

Cognee AI는 주로 개발자용 SDK와 에이전트 프레임워크를 지원하는 플랫폼입니다. 따라서 노코드 툴처럼 화면만 보고 바로 쓰기에는 난이도가 있으나, 연동된 도구들을 통해 간접적으로 혜택을 볼 수 있습니다.

**어떤 플랫폼과 데이터를 연동할 수 있나요?**

아마존 S3, 데이터 웨어하우스, 슬랙, 노션, 구글 드라이브 및 다양한 문서 저장소와 연결할 수 있습니다. 파일과 채팅, API 데이터를 하나의 검색 가능한 기억 레이어로 통합합니다.

**로컬 환경에 직접 설치해서 사용할 수 있나요?**

그렇습니다. 오픈소스 기반의 에이전트 메모리 플랫폼이기 때문에 사용자가 원할 경우 로컬 환경에 직접 배포하여 온프레미스로 제어할 수 있습니다.

**기존에 쓰던 AI 코딩 도구와 함께 쓸 수 있나요?**

Claude Code, Cursor, Codex 등 다양한 에이전트 프레임워크와 연동을 지원합니다. 개발 작업 중 세션을 넘어 이전 코딩 맥락을 기억하게 만드는 용도로 적합합니다.
