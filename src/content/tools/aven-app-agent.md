## 한줄 요약

Aven App Agent는 모바일 앱 내에서 사용자가 길을 잃지 않도록 실시간으로 안내하는 AI 비서입니다. 복잡한 서비스 이용 방법을 단계별로 가이드하여 고객의 만족도를 높이고 서비스 이탈을 방지하는 데 도움을 줍니다.

## 핵심 기능

- **실시간 가이드**: 사용자가 앱을 이용하는 도중 실시간으로 다음 단계를 안내해 줍니다.
- **행동 분석**: 사용자가 어디에서 막히는지 파악하여 가이드를 최적화할 수 있습니다.
- **코드 없는 연동**: 복잡한 코딩 없이도 기존 앱에 빠르게 기능을 추가할 수 있습니다.

## 사용법

**1. SDK 선택 및 연동**

공식 문서에서 제공하는 웹 또는 모바일 SDK를 선택하여 개발 중인 앱에 설치합니다. 개발자 대시보드에서 앱을 등록하고 필요한 라이브러리를 프로젝트에 추가합니다.

**2. UI 요소 및 페이지 등록**

앱 내에서 가이드가 필요한 특정 페이지와 버튼 등 UI 요소를 시스템에 명시적으로 등록합니다. 등록된 요소들은 AI가 사용자를 안내할 때 참조하는 주요 타겟이 됩니다.

**3. 워크플로우 정의**

사용자가 앱에서 수행할 특정 작업 흐름을 개발자가 직접 설정합니다. 예를 들어 '결제하기'나 '설정 변경하기'와 같은 단계를 정의하여 AI가 순서대로 안내하도록 구성합니다.

**4. 실시간 가이드 테스트**

설정이 완료되면 실제 앱 환경에서 사용자가 가이드를 잘 따라오는지 테스트합니다. AI가 사용자의 질문에 올바르게 답변하고 적절한 UI 위치로 안내하는지 확인합니다.

## 가격 정책

- **유료 플랜**: Pro 플랜은 월 약 130,000원(99달러)부터 시작하며 더 많은 사용자 수와 상세 분석 기능을 제공합니다.

비용 절약 팁: 초기 도입 시 무료 플랜으로 핵심 기능의 사용자 반응을 먼저 확인한 후 유료 전환을 결정하는 것이 좋습니다.

## 요금제 자세히

**환불과 해지**: 환불 및 결제 취소 정책은 공식 홈페이지의 Terms & Conditions 및 Refund & Cancellation 페이지에서 확인이 필요합니다.

## 한국어 지원

현재 인터페이스와 가이드 생성 기능은 영어로 제공됩니다. 한국어 앱에 적용하려면 직접 한국어 문구를 입력하여 가이드를 설정해야 합니다.

## 한국어 품질 실측

**결제 방법 안내**

- 프롬프트: 결제는 어디서 하나요? (Where can I make a payment?)
- 결과 예시: 결제는 상단 메뉴의 '결제하기' 버튼을 누르시면 됩니다. 해당 버튼을 클릭하여 결제 수단을 선택해 주세요.
- 관찰: AI는 영어로 응답하므로 한국어 앱에 적용하려면 관리자가 직접 한국어 답변을 미리 등록해야 합니다.

**설정 변경 가이드**

- 프롬프트: 알림 설정을 바꾸고 싶어요. (I want to change notification settings.)
- 결과 예시: 설정 메뉴로 이동하여 '알림' 탭을 선택하세요. 그곳에서 원하는 알림 항목을 활성화하거나 비활성화할 수 있습니다.
- 관찰: 입력된 한국어 문구에 대해서는 정확히 반응하지만 시스템이 자동으로 한국어를 생성하지는 않습니다.

현재 인터페이스와 AI 응답은 영어로만 제공되므로 한국어 서비스 적용 시 직접 번역된 콘텐츠를 입력해야 합니다. 한국어 문장 자체에 대한 인식은 가능하나, 자연스러운 한국어 대화형 가이드를 위해서는 별도의 언어 설정 과정이 필수입니다.

## 장단점

**장점**

- 복잡한 코딩 과정 없이도 기존 앱에 AI 가이드 기능을 빠르게 추가하여 개발 효율성을 높일 수 있습니다.
- 사용자가 앱 이용 중 막히는 부분을 실시간으로 파악하여 이탈률을 획기적으로 줄이는 데 큰 도움을 줍니다.
- 개발자가 직접 등록한 UI 요소와 워크플로우를 기반으로 작동하여 정확하고 신뢰성 있는 안내가 가능합니다.
- 사용자의 질문에 문맥을 파악하여 답변하므로 고객 응대 비용을 절감하고 서비스 만족도를 향상시킵니다.

**단점**

- 한국어를 기본적으로 지원하지 않아 한국어 사용자 대상 앱 적용 시 모든 가이드 문구를 직접 입력해야 하는 번거로움이 있습니다.
- 도구 활용하려고 SDK 연동 및 UI 요소 등록 등 기술적인 설정 과정이 필요하여 비개발자가 혼자 도입하기에는 다소 어렵습니다.
- 사용자 행동 분석 및 상세 가이드 기능을 충분히 활용하려면 유료 플랜 결제가 필수적이라 초기 운영 비용이 발생합니다.

## 자주 묻는 질문

**코딩을 전혀 못 하는데 사용할 수 있나요?**

네, 가능합니다. 개발 지식이 없어도 웹 대시보드에서 가이드를 설정하고 앱에 적용할 수 있도록 설계되어 있습니다.

**한국어 앱에도 적용 가능한가요?**

기술적으로는 가능합니다. 다만 AI가 자동으로 한국어 가이드를 생성해주지는 않으므로, 관리자가 직접 한국어 문구로 설정해야 합니다.

**앱 성능에 영향을 미치지 않나요?**

최적화된 라이브러리를 사용하므로 앱의 속도나 성능에 미치는 영향은 거의 없습니다. 안심하고 사용하셔도 됩니다.

**한국어 앱에 바로 적용할 수 있나요?**

기술적으로는 연동 가능하지만, AI가 출력하는 문구는 영어로 설정되어 있습니다. 따라서 한국어 앱에 적용하려면 관리자가 한국어로 번역된 가이드 문구를 직접 입력해야 합니다.

**코딩을 전혀 몰라도 사용할 수 있나요?**

코드 없는 연동을 지원하지만, 앱의 UI 요소를 등록하고 SDK를 삽입하는 과정은 개발 지식이 필요합니다. 비개발자라면 개발팀의 협조를 받는 것이 좋습니다.

**무료 플랜으로 기능을 충분히 테스트할 수 있나요?**

기본적인 가이드 기능은 테스트할 수 있으나, 상세 분석이나 대규모 사용자 대응은 유료 플랜이 필요합니다. 먼저 무료 플랜으로 핵심 기능의 작동 여부를 검증하시기 바랍니다.

**어떤 앱에 가장 적합한가요?**

복잡한 기능을 가진 서비스나 사용자가 처음 이용할 때 어려움을 겪는 앱에 적합합니다. 이탈률이 높은 특정 구간의 가이드를 강화하여 고객 경험을 개선할 수 있습니다.
