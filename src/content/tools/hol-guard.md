HOL Guard는 Claude Code, Codex, Cursor 등 AI 코딩 에이전트 옆에서 내 컴퓨터에 로컬로 동작합니다. 셸 명령, 시크릿·인증 정보 읽기, MCP 도구 호출, 패키지 설치를 실행 전에 잠시 멈추고, 사람이 판단해야 할 단계는 허용/차단을 묻습니다. 모든 선택은 로컬 결정 로그에 남아 나중에 에이전트가 무엇을 시도했는지 확인할 수 있습니다. 핵심은 Apache-2.0 오픈소스 Python CLI(macOS, Linux)이며 팀용 선택형 유료 Guard Cloud가 있습니다(프리미엄). 게이트웨이나 네트워크 방화벽이 아니며 프롬프트 인젝션을 완전히 막지 않고, 스캔 결과는 안전을 보장하지 않습니다. 인터페이스는 영어입니다. 설치: pipx install hol-guard && hol-guard init

## 사용법

**1. 설치 및 초기화**

터미널에서 'pipx install hol-guard'를 입력하여 프로그램을 설치합니다. 이후 'hol-guard init' 명령어를 실행하여 로컬 환경에 필요한 설정을 초기화합니다.

**2. AI 에이전트 연동**

사용 중인 Cursor나 Claude Code와 같은 AI 코딩 도구의 설정에서 HOL Guard를 연동합니다. 연동이 완료되면 AI가 수행하는 명령을 Guard가 감시하게 됩니다.

**3. 실시간 권한 승인**

AI가 셸 명령 실행이나 파일 접근을 시도할 때, 터미널에 나타나는 알림창을 확인합니다. 작업의 안전성을 검토한 후 'Allow(허용)', 'Ask(질문)', 'Block(차단)' 중 하나를 선택합니다.

**4. 로그 기록 확인**

작업이 끝난 후 로컬에 저장된 결정 로그로 AI가 어떤 명령을 시도했는지 검토합니다. 이로 향후 AI의 동작 패턴을 파악하고 보안 정책을 조정할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 개인 사용자는 한 대의 컴퓨터에서 무료로 제한 없이 기능을 사용합니다. 로컬 환경에서 실행되므로 별도의 계정이나 인터넷 연결 없이도 보안 기능을 활용 가능합니다.

- **Guard Cloud** (공식 요금 페이지에서 확인이 필요합니다): 팀 단위로 보안 정책을 통합 관리하고 허용 및 차단 기록을 클라우드에 동기화하여 팀 전체의 보안 수준을 높일 수 있습니다.

**환불과 해지**: 유료 플랜의 결제 및 환불 정책은 HOL 공식 홈페이지의 결제 페이지로 확인해야 합니다.

## 한국어 품질 실측

**패키지 설치 승인**

- 프롬프트: AI에게 'npm install' 명령을 수행하도록 요청합니다.
- 결과 예시: HOL Guard가 'npm install' 실행을 감지하고 'Allow/Block'을 묻는 영어 메시지를 출력합니다. 사용자가 승인하면 설치가 진행되고, 거부하면 즉시 중단됩니다.
- 관찰: 도구 인터페이스가 영어로 제공되어 한국어 프롬프트 입력 시에도 영어 알림이 표시됩니다.

**민감 정보 접근 제어**

- 프롬프트: AI에게 환경 변수(.env) 파일을 읽으라고 요청합니다.
- 결과 예시: Guard가 시크릿 파일 접근 시도를 차단하고 'Access to sensitive file detected'라는 경고창을 띄웁니다. 사용자의 승인 없이는 파일 내용이 AI에게 전달되지 않습니다.
- 관찰: 보안 관련 전문 용어가 영어로 표시되므로 기초적인 영어 이해도가 필요합니다.

도구 자체가 영어로만 제공되므로 한국어 지원은 되지 않습니다. 전문적인 개발 환경에서 사용되기에 한국어 번역이 없어도 개발자라면 직관적으로 이해할 수 있는 수준입니다.

## 장단점

**장점**

- AI 코딩 에이전트가 내 컴퓨터의 중요한 시스템 명령을 함부로 실행하지 못하도록 실시간으로 강력하게 통제할 수 있습니다.
- 모든 보안 검사가 로컬 환경에서 독립적으로 이루어지므로 외부 서버로 파일이나 민감한 정보가 유출될 위험이 전혀 없습니다.
- 오픈소스 기반으로 설계되어 투명한 보안 검증이 가능하며 다양한 AI 코딩 도구와 폭넓게 연동하여 사용할 수 있습니다.
- AI가 수행한 모든 작업 이력을 로컬 로그로 남겨주기 때문에 나중에 보안 사고가 발생했을 때 원인을 정밀하게 분석할 수 있습니다.

**단점**

- 인터페이스가 영어로만 제공되어 한국어 사용자에게는 초기 설정과 알림 메시지 이해에 다소 어려움이 있을 수 있습니다.
- 보안 정책을 직접 설정하고 판단해야 하므로 AI 코딩 도구에 대한 숙련도가 높은 고급 사용자에게 적합한 도구입니다.
- 네트워크 방화벽이나 프롬프트 인젝션을 완벽하게 막아주는 것이 아니므로 이 도구 하나만으로 모든 보안을 보장할 수는 없습니다.

## 주의사항

- **개인정보**: 로컬 환경에서 동작하므로 기본적으로 파일 내용이 외부로 전송되지 않으나, 클라우드 기능 사용 시에는 작업 이력이 동기화될 수 있습니다.
- **저작권/상업적 이용**: Apache-2.0 라이선스를 따르므로 오픈소스 규정을 준수해야 하며 상업적 이용 시에는 라이선스 정책을 반드시 재확인하시기 바랍니다.
- **요금/한도**: 개인용은 무료이나 팀용 유료 플랜의 정확한 금액과 한도는 공식 요금 페이지에서 확인이 필요합니다.
- **계정 관리**: 로컬 사용 시에는 계정이 불필요하지만 팀 협업을 위한 클라우드 기능을 사용하려면 별도의 계정 생성 및 관리가 필요합니다.
