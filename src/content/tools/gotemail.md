## 한줄 요약

GotEmail은 macOS 전용 메일 클라이언트로, 여러 메일 계정을 하나의 창에서 관리합니다. AI가 이메일 초안 작성과 내용 요약을 도와 업무 효율을 높여 줍니다.

## 핵심 기능

- **통합받함**: 여러 메일 계정을 한 화면에 모아 확인할 수 있어 시간 절약이 됩니다.
- **코드복사**: 인증코드·링크를 자동 인식해 한 번 클릭으로 복사·열 수 있습니다.
- **AI초안**: 프롬프트만 입력하면 이메일 초안·요약을 자동 생성합니다.

## 사용법

**1. 앱 다운로드 및 설치**

공식 웹사이트에서 GotEmail을 다운로드하여 macOS 응용 프로그램 폴더에 설치합니다. macOS 15 이상 버전에서 원활하게 작동하며 안전하게 서명 및 공인된 앱입니다.

**2. 이메일 계정 추가하기**

앱을 실행한 뒤 Gmail, Outlook, iCloud, Yahoo 등 보유한 이메일 계정을 연결합니다. Microsoft 계정은 마이크로소프트 로그인을, 그 외 서버는 앱 비밀번호를 입력하면 설정이 완료됩니다.

**3. 통합 받은편지함 확인**

여러 계정의 메일이 하나의 목록으로 모여 한눈에 들어오며, 읽지 않은 메일이나 별표 표시된 메일만 골라서 볼 수 있습니다. 메일 수신 시 상단 배너와 메뉴 바로 인증코드와 링크를 즉시 확인할 수 있습니다.

**4. AI 기능 활용하기**

이메일 답장을 작성할 때 'Tell Sam the launch moves to Friday'처럼 프롬프트를 입력해 초안을 바로 생성합니다. 긴 스레드가 있을 경우 중요한 날짜, 마감일, 금액이 포함된 2~3줄 요약을 요청하여 시간을 절약합니다.

## 한국어 지원

앱 UI와 문서는 영어로 제공되며, 한국어 입력·출력은 지원하지만 한국어 현지화는 제한적입니다.

## 한국어 품질 실측

**영업 미팅 일정 조율**

- 프롬프트: 다음 주 화요일 오후 2시로 미팅 일정을 변경해 달라고 정중한 어조로 메일 초안을 작성해 줘.
- 결과 예시: 안녕하세요, 김 담당자님. 일정 조율 다음 주 화요일 오후 2시로 변경을 요청드립니다. 확인 부탁드립니다.
- 관찰: 한국어 입력과 출력은 가능하나 앱 UI와 설정은 영어로 제공됩니다.

**긴 계약서 메일 요약**

- 프롬프트: 수신된 계약서 메일 스레드에서 주요 금액과 마감 기한을 요약해 줘.
- 결과 예시: 견적 금액은 총 4,800달러이며, 계약서 서명과 보증금 납부 마감일은 10월 24일 금요일까지입니다.
- 관찰: 다국어 지원 AI를 통해 한국어 긴 메일 스레드도 핵심 내용 위주로 파악할 수 있습니다.

앱의 인터페이스와 안내 문구는 영어 중심이나, 내장된 AI 모델이 한국어 입력 및 출력을 지원하여 일상적인 메일 작성과 요약 업무에 무리 없이 활용할 수 있습니다.

## 장단점

**장점**

- Gmail, Outlook, iCloud 등 여러 이메일 계정을 하나의 창에서 통합 관리할 수 있어 매우 편리합니다.
- 인증코드와 마법 링크를 자동으로 인식하여 단 한 번의 클릭으로 쉽게 복사하고 브라우저를 열 수 있습니다.
- 추가적인 API 키나 설정 없이 내장된 AI 기능을 활용해 메일 초안 작성과 긴 글 요약을 즉시 실행합니다.

## 자주 묻는 질문

**GotEmail은 Windows에서도 사용할 수 있나요?**

현재 GotEmail은 macOS 15 이상 전용으로 제공되고 있습니다. Windows 사용자는 다른 메일 클라이언트를 고려하셔야 합니다.

**AI 초안 기능은 어떤 언어를 지원하나요?**

AI 초안은 영어와 한국어를 포함한 다국어를 지원합니다. 다만 UI는 영어이므로 영어 입력에 익숙하신 분께 더 편리합니다.

**구매 후 환불 정책은 어떻게 되나요?**

일시 결제형 라이선스이므로 구매일로부터 14일 이내에 환불 요청 시 전액 환불이 가능합니다. 자세한 내용은 공식 사이트의 환불 정책을 참고해 주세요.

**윈도우나 아이폰에서도 GotEmail을 사용할 수 있나요?**

본 도구는 macOS 전용 네이티브 메일 앱으로 출시되었으며 윈도우 버전은 지원하지 않습니다. 모바일 앱 환경에 대해서는 공식 페이지의 향후 업데이트 공지를 참고해야 합니다.

**AI 기능을 쓰기 위해 별도의 API 키를 입력해야 하나요?**

별도의 API 키나 복잡한 외부 설정 없이 앱 내부에 AI가 내장되어 있습니다. 메일 작성 창이나 요약 요청 시 곧바로 기능을 사용할 수 있습니다.

**어떤 이메일 서비스 계정들을 연동할 수 있나요?**

Gmail, Outlook, iCloud, Yahoo, AOL, Fastmail, Zoho 및 기타 모든 IMAP 서버 계정을 지원합니다. 마이크로소프트 계정은 전용 로그인을, 일반 서버는 앱 비밀번호로 쉽게 연결됩니다.

**인증코드는 어떻게 찾아주나요?**

수신된 메일 중 인증코드와 마법 링크를 자동으로 감지하여 메시지 상단에 배너로 띄워줍니다. 메뉴 바에서도 최근 15분 동안 수신된 코드를 클릭 한 번으로 복사할 수 있습니다.
