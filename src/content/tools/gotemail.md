## 한줄 요약

GotEmail은 macOS 전용 메일 클라이언트로, 여러 메일 계정을 하나의 창에서 관리합니다. AI가 이메일 초안 작성과 내용 요약을 도와 업무 효율을 높여 줍니다.

## 핵심 기능

- **통합받함**: 여러 메일 계정을 한 화면에 모아 확인할 수 있어 시간 절약이 됩니다.
- **코드복사**: 인증코드·링크를 자동 인식해 한 번 클릭으로 복사·열 수 있습니다.
- **AI초안**: 프롬프트만 입력하면 이메일 초안·요약을 자동 생성합니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 제공되지 않습니다.
- **유료 플랜**: Standard 플랜 – 49달러(≈55,000원) 일시 결제로 영구 사용 가능, AI 초안·요약 기능 포함

비용 절약 팁: 공식 홈페이지에서 프로모션 코드를 적용하면 할인된 가격에 구매할 수 있습니다.

## 한국어 지원

앱 UI와 문서는 영어로 제공되며, 한국어 입력·출력은 지원하지만 한국어 현지화는 제한적입니다.

## 이런 분에게 추천합니다

메일을 자주 확인하는 마케터, 프로젝트 관리자를 위한 도구입니다. macOS를 주로 사용하는 프리랜서와 소규모 스타트업에게도 적합합니다.

## 실제 활용 예시

- **직장인**: 프로젝트 진행 상황을 팀에 보고할 때 GotEmail의 AI 초안 기능으로 빠르게 메일을 작성하고 인증코드가 포함된 메일을 바로 복사해 로그인합니다.
- **학생**: 과제 제출 마감 알림 메일을 GotEmail에서 한눈에 확인하고 AI 요약으로 중요한 내용만 빠르게 파악해 일정에 반영합니다.
- **소상공인**: 온라인 쇼핑몰 주문 확인 메일을 통합받함으로 관리하고 AI가 자동으로 주문 확인 메일 초안을 만들어 고객 응답 시간을 단축합니다.

## 유사 툴과 비교

**장점:**
- macOS 전용 최적화로 빠른 속도
- 인증코드 자동 인식·복사 기능
- AI 초안·요약으로 업무 효율 상승

**단점:**
- 한국어 UI가 없어 초기 학습 필요
- macOS 전용이라 Windows 사용자는 이용 불가

**이런 분에게 가장 적합합니다:** macOS 환경에서 여러 메일 계정을 동시에 관리하고 AI 기반 자동화를 원하는 사용자에게 가장 적합합니다.

## 자주 묻는 질문

**GotEmail은 Windows에서도 사용할 수 있나요?**

현재 GotEmail은 macOS 15 이상 전용으로 제공되고 있습니다. Windows 사용자는 다른 메일 클라이언트를 고려하셔야 합니다.

**AI 초안 기능은 어떤 언어를 지원하나요?**

AI 초안은 영어와 한국어를 포함한 다국어를 지원합니다. 다만 UI는 영어이므로 영어 입력에 익숙하신 분께 더 편리합니다.

**구매 후 환불 정책은 어떻게 되나요?**

일시 결제형 라이선스이므로 구매일로부터 14일 이내에 환불 요청 시 전액 환불이 가능합니다. 자세한 내용은 공식 사이트의 환불 정책을 참고해 주세요.
