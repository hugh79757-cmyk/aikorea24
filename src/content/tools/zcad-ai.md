## 한줄 요약

zCAD AI는 사용자가 요구사항을 글로 적으면 이를 구조화된 3D 모델로 변환해주는 도구입니다. 복잡한 CAD 소프트웨어 학습 없이도 아이디어를 즉시 편집 가능한 3D 설계도로 바꿀 수 있어 설계 시간을 획기적으로 단축합니다.

## 핵심 기능

- **텍스트 기반 설계**: 명령어 입력만으로 3D 모델을 생성하여 설계 초기 단계의 수고를 덜어줍니다.
- **편집 가능한 모델**: 생성된 모델은 수정이 가능하여 설계 변경이 잦은 업무 환경에 적합합니다.
- **규격화된 출력**: 엔지니어링 표준에 맞는 구조화된 데이터를 제공하여 실무 활용도가 높습니다.

## 사용법

**1. 설계 요구사항 입력**

메인 화면의 프롬프트 창에 제작하려는 부품의 기능, 치수, 형상을 영어로 상세히 입력합니다. 예시로 '60mm 높이의 L자형 브래킷'과 같이 구체적인 수치를 기입하면 더욱 정확합니다.

**2. 참고 이미지 추가**

설계하려는 모델과 유사한 참고 이미지를 함께 업로드하여 AI가 의도를 더 잘 파악하도록 돕습니다. 이미지를 추가하면 복잡한 구조를 설명하는 시간을 크게 줄일 수 있습니다.

**3. 3D 모델 생성 및 검토**

입력한 내용을 보고 생성된 3D 모델을 화면에서 확인합니다. 엔지니어링 표준에 맞게 구조화된 부품들이 제대로 생성되었는지 치수와 형상을 꼼꼼히 살펴봅니다.

**4. 모델 수정 및 정교화**

생성된 모델을 보고 추가적인 수정 명령을 내려 설계를 보완합니다. 수정된 내용은 즉시 반영되며, 최종적으로 편집 가능한 CAD 파일로 완성할 수 있습니다.

현재 인터페이스와 명령어 입력은 영어로만 지원합니다. 영어 프롬프트를 사용해야 정확한 결과물을 얻을 수 있습니다.

## 한국어 품질 실측

**기계 부품 설계**

- 프롬프트: Create a 50mm diameter circular plate with four holes at the corners.
- 결과 예시: 지름 50mm의 원형 판과 4개의 구멍이 포함된 3D 모델이 생성됩니다.
- 관찰: 영어 프롬프트를 사용해야 AI가 의도를 정확히 이해하고 규격에 맞는 결과물을 도출합니다.

**전자 기기 케이스**

- 프롬프트: Design a rectangular enclosure for a 60% keyboard with gasket mount.
- 결과 예시: 60% 키보드 규격에 맞는 직사각형 케이스와 가스켓 마운트 구조가 모델링됩니다.
- 관찰: 기술적인 전문 용어를 영어로 정확히 입력할수록 설계 오류가 줄어듭니다.

현재 인터페이스와 명령어 입력은 영어만 지원하므로 한국어 사용 시 번역기를 활용해야 합니다. 전문적인 공학 용어는 영어로 직접 입력하는 것이 설계 정확도를 높이는 데 유리합니다.

네, 기본적인 치수와 형태에 대한 이해만 있다면 텍스트 명령어로 누구나 쉽게 모델을 생성할 수 있습니다. 다만, 엔지니어링 기초 지식이 있다면 더 정교한 결과물을 얻을 수 있습니다.

**생성된 파일을 다른 3D 프로그램에서 열 수 있나요?**

네, zCAD AI에서 생성된 모델은 표준 CAD 형식으로 내보내기가 가능합니다. 이로 기존에 사용하던 전문 설계 프로그램으로 가져와 추가 작업을 할 수 있습니다.

**한국어 명령어를 입력해도 결과가 나오나요?**

현재는 영어 명령어에 최적화되어 있어 한국어로 입력할 경우 정확도가 떨어질 수 있습니다. 가급적 영어로 치수와 형태를 명확히 기재하는 것을 권장합니다.

**생성된 모델을 다른 CAD 프로그램에서 열 수 있나요?**

네, zCAD AI는 표준화된 CAD 형식으로 데이터를 제공하므로 일반적인 CAD 소프트웨어에서 불러와 추가 작업을 수행할 수 있습니다.

**한국어로 명령어를 입력해도 되나요?**

현재 영어만 지원하므로 한국어로 입력할 경우 AI가 의도를 오해할 수 있습니다. 가급적 영어 프롬프트 사용을 권장합니다.

**무료 플랜으로도 업무용 부품 설계가 가능한가요?**

무료 플랜은 기능 체험용이므로 복잡한 프로젝트나 연속적인 업무용 설계에는 한계가 있을 수 있습니다.

**생성된 모델의 치수를 정밀하게 수정할 수 있나요?**

네, 생성된 모델은 편집 가능한 상태로 제공되므로 사용자가 원하는 수치로 세부 수정이 가능합니다.
