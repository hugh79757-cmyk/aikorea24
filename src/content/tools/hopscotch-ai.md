## 한줄 요약

Hopscotch AI는 오픈AI, 앤트로픽, 구글 등 500개 이상의 인공지능 모델을 하나의 API로 통합하여 사용할 수 있게 돕습니다. 개발자나 기업이 개별 플랫폼과 일일이 계약할 필요 없이 비용을 통제하고 예산을 관리할 수 있도록 지원합니다.

## 핵심 기능

- **모델 통합 API**: 500개 이상의 AI 모델을 단일 API로 편리하게 호출합니다.
- **비용 통제**: 팀원과 워크스페이스별로 사용 금액 한도를 설정합니다.
- **자동 백업**: 메인 AI 모델 오류 시 다른 모델로 자동 전환합니다.

## 가격 정책

- **무료 플랜**: API 연동을 테스트할 수 있는 기본 무료 기능을 제공합니다.
- **유료 플랜**: 사용량에 따라 과금되는 종량제 플랜으로 상세한 비용 관리 기능을 제공합니다.

비용 절약 팁: 팀원별 사용량 한도를 미리 설정하여 예기치 않은 과다 청구를 방지합니다.

## 한국어 지원

서비스 이용 화면이나 공식 문서는 영어로 제공되지만 API를 통해 연동하는 AI 모델 자체는 한국어를 완벽하게 지원합니다.

## 이런 분에게 추천합니다

여러 인공지능 모델의 API를 동시에 관리하고 싶은 개발자
AI 사용 비용을 체계적으로 통제하고 싶은 스타트업 대표
백업 모델 연동으로 서비스 안정성을 높이고 싶은 서비스 기획자

## 실제 활용 예시

- **직장인**: 사내 AI 챗봇 서비스를 개발할 때 여러 모델을 테스트하고 예산 한도를 설정하여 관리합니다.
- **학생**: 졸업 작품으로 AI 연동 웹서비스를 만들 때 다양한 거대언어모델을 쉽게 호출하여 적용합니다.
- **소상공인**: 고객 응대 자동화 프로그램을 만들 때 월 지출 비용을 철저하게 통제하며 운영합니다.

## 유사 툴과 비교

**장점:**
- 수많은 AI 모델을 하나의 키로 사용 가능
- 정교한 예산 및 지출 제한 기능 제공

**단점:**
- 개발 지식이 없는 일반 사용자는 접근하기 어려움
- 한국어 인터페이스 미지원

**이런 분에게 가장 적합합니다:** 여러 AI 모델을 API로 연동하여 비용을 아끼고 싶고 개발 역량이 있는 사용자에게 가장 적합합니다.

## 자주 묻는 질문

**어떤 AI 모델들을 지원하나요?**

앤트로픽, 오픈AI, 구글 등 시중의 유명한 500개 이상의 인공지능 모델을 하나의 API로 지원합니다.

**비용은 어떻게 청구되나요?**

사용한 만큼만 지불하는 종량제 방식을 채택하고 있으며 워크스페이스별로 한도를 지정할 수 있습니다.

**일반 사용자도 사용할 수 있나요?**

API 연동이 필요한 개발자 중심의 툴이므로 코딩 지식이 없는 일반 사용자에게는 다소 어려울 수 있습니다.
