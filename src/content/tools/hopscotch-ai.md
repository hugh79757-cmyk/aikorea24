## 한줄 요약

Hopscotch AI는 오픈AI, 앤트로픽, 구글 등 500개 이상의 인공지능 모델을 하나의 API로 통합하여 사용할 수 있게 돕습니다. 개발자나 기업이 개별 플랫폼과 일일이 계약할 필요 없이 비용을 통제하고 예산을 관리할 수 있도록 지원합니다.

## 핵심 기능

- **모델 통합 API**: 500개 이상의 AI 모델을 단일 API로 편리하게 호출합니다.
- **비용 통제**: 팀원과 워크스페이스별로 사용 금액 한도를 설정합니다.
- **자동 백업**: 메인 AI 모델 오류 시 다른 모델로 자동 전환합니다.

## 사용법

**1. Hopscotch 계정 생성**

공식 웹사이트에 접속하여 회원가입을 진행합니다. 로그인 후 대시보드에서 API 연동을 위한 기본 키를 발급받을 수 있습니다.

**2. 기존 OpenAI SDK 설정 변경**

프로젝트 코드 내에서 OpenAI SDK의 기본 URL을 Hopscotch 주소로 변경합니다. API 키만 Hopscotch 전용 키로 교체하면 별도의 프로그램 설치 없이 연동이 완료됩니다.

**3. AI 모델 및 예산 한도 지정**

대시보드에서 팀원, 워크스페이스, 혹은 API 키별로 일일 지출 한도를 설정합니다. 사용할 Anthropic, OpenAI, Google 등의 다양한 모델을 선택하고 우선순위를 지정합니다.

**4. 사용량 및 요청 로그 모니터링**

대시보드의 사용량 분석 메뉴로 각 요청의 비용, 속도, 실패 여부를 실시간으로 확인합니다. 오류가 발생한 요청은 요청 ID를 통해 원인과 비용을 추적할 수 있습니다.

## 가격 정책

- **무료 플랜**: API 연동을 테스트할 수 있는 기본 무료 기능을 제공합니다.
- **유료 플랜**: 사용량에 따라 과금되는 종량제 플랜으로 상세한 비용 관리 기능을 제공합니다.

비용 절약 팁: 팀원별 사용량 한도를 미리 설정하여 예기치 않은 과다 청구를 방지합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: Hopscotch 플랫폼 자체의 이용 수수료는 부과되지 않으며 개발자는 각 제공 업체의 토큰당 정가만 지불합니다. 정확한 무료 크레딧이나 기본 테스트 범위는 공식 요금 페이지에서 확인이 필요합니다.

- **종량제 플랜** (사용량 기반 (수수료 $0.00, 정확한 금액은 공식 요금 페이지 확인 필요)): 마크업이나 추가 구독료 없이 각 AI 모델 제공 업체의 표준 토큰 가격으로 이용합니다. 팀원과 키별 세부 지출 한도 설정 및 자동 백업 기능을 제공합니다.

- **타사 라우팅 비교 플랜** (OpenRouter Standard 5.5% / Business 8% (정확한 금액은 공식 요금 페이지 확인 필요)): 타사 라우팅 서비스와 비교하여 추가 수수료가 없는 투명한 가격 구조를 지원합니다. 상세한 비용 분석과 모델별 실패 대응 로그를 제공합니다.

**환불과 해지**: 환불 및 결제 취소 정책에 대한 상세한 규정은 정식 서비스 이용 약관 및 공식 요금 페이지에서 확인이 필요합니다.

## 한국어 지원

서비스 이용 화면이나 공식 문서는 영어로 제공되지만 API를 통해 연동하는 AI 모델 자체는 한국어를 완벽하게 지원합니다.

## 한국어 품질 실측

**고객 응대 답변 생성**

- 프롬프트: 환불 규정를 문의하는 고객에게 정중하고 친절한 어조로 안내하는 답변을 작성해 주세요.
- 결과 예시: 고객님, 환불 규정를 문의해 주셔서 감사합니다. 구매 후 7일 이내에 미사용 상태인 경우 전액 환불이 가능합니다. 추가적인 문의 사항이 있으시면 언제든지 편하게 말씀해 주시기 바랍니다.
- 관찰: API를 통해 연결된 각 AI 모델이 한국어 문맥을 자연스럽게 이해하고 출력합니다.

**마케팅 문구 기획**

- 프롬프트: 신제품 출시를 알리는 직장인 대상 업무용 AI 툴 홍보 문구를 매력적으로 작성해 주세요.
- 결과 예시: 반복되는 업무는 이제 그만! 업무 효율을 극대화하는 스마트한 AI 솔루션을 만나보세요. 지금 바로 시작하여 일하는 방식을 혁신적으로 바꾸어 보시기 바랍니다.
- 관찰: 비즈니스 상황에 어울리는 정중하고 깔끔한 한국어 표현을 안정적으로 생성합니다.

플랫폼 자체 인터페이스와 문서는 영문이지만 연동하여 호출하는 대다수 대형 언어 모델들이 한국어를 완벽하게 지원합니다. 프롬프트 작성 시 한국어 품질은 사용하는 백엔드 모델의 성능에 따라 결정됩니다.

AI 사용 비용을 체계적으로 통제하고 싶은 스타트업 대표
백업 모델 연동으로 서비스 안정성을 높이고 싶은 서비스 기획자

## 실제 활용 예시

- **직장인**: 사내 AI 챗봇 서비스를 개발할 때 여러 모델을 테스트하고 예산 한도를 설정하여 관리합니다.
- **학생**: 졸업 작품으로 AI 연동 웹서비스를 만들 때 다양한 거대언어모델을 쉽게 호출하여 적용합니다.
- **소상공인**: 고객 응대 자동화 프로그램을 만들 때 월 지출 비용을 철저하게 통제하며 운영합니다.

## 유사 툴과 비교

**장점:**
- 수많은 AI 모델을 하나의 키로 사용 가능
- 정교한 예산 및 지출 제한 기능 제공

**단점:**
- 개발 지식이 없는 일반 사용자는 접근하기 어려움
- 한국어 인터페이스 미지원

**이런 분에게 가장 적합합니다:** 여러 AI 모델을 API로 연동하여 비용을 아끼고 싶고 개발 역량이 있는 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 500개 이상의 다양한 인공지능 모델을 하나의 통합 API로 편리하게 호출할 수 있습니다.
- 팀원과 워크스페이스, API 키별로 상세한 지출 한도를 설정하여 예기치 않은 과다 청구를 방지합니다.
- 메인 모델에 오류가 발생하거나 응답이 없을 때 설정한 순서대로 다른 모델로 자동 전환됩니다.
- 기존에 사용하던 OpenAI SDK에서 베이스 URL과 키만 변경하면 되므로 코드를 크게 수정할 필요가 없습니다.

**단점**

- 플랫폼의 인터페이스와 공식 문서가 모두 영어로 제공되어 국내 초급 사용자에게는 진입 장벽이 다소 높습니다.
- 사용량 기반의 종량제 구조로 인해 팀의 규모가 커질수록 세부 예산 관리에 각별한 주의가 필요합니다.
- 플랫폼 내 일부 고급 자원 및 리소스 페이지는 아직 준비 중이거나 업데이트가 진행되는 상태입니다.

## 주의사항

- **개인정보**: API를 통해 전달되는 데이터는 연동된 각 AI 모델 제공 업체의 프라이버시 정책에 따라 처리되므로 민감한 개인정보 입력 시 주의가 필요합니다.
- **저작권/상업적 이용**: 각 AI 모델로 생성된 결과물의 상업적 활용 여부 및 저작권 귀속은 해당 모델 원천사의 이용 약관을 반드시 확인해야 합니다.
- **요금/한도**: 자동 백업 및 다중 모델 호출 과정에서 예상치 못한 토큰 소모가 발생할 수 있으므로 사전에 지출 한도를 철저히 설정해야 합니다.
- **계정 관리**: API 키가 유출되면 타인이 예산을 무단으로 소모할 수 있으므로 키 권한을 철저히 분리하고 주기적으로 관리해야 합니다.

## 자주 묻는 질문

**어떤 AI 모델들을 지원하나요?**

앤트로픽, 오픈AI, 구글 등 시중의 유명한 500개 이상의 인공지능 모델을 하나의 API로 지원합니다.

**비용은 어떻게 청구되나요?**

사용한 만큼만 지불하는 종량제 방식을 채택하고 있으며 워크스페이스별로 한도를 지정할 수 있습니다.

**일반 사용자도 사용할 수 있나요?**

API 연동이 필요한 개발자 중심의 툴이므로 코딩 지식이 없는 일반 사용자에게는 다소 어려울 수 있습니다.

**기존에 작성한 OpenAI 코드를 수정하지 않고 바로 쓸 수 있나요?**

네, 그렇습니다. 기존 OpenAI SDK에서 베이스 URL과 API 키만 Hopscotch 정보로 변경하면 모델 이름 변경만으로 다른 AI 모델들을 자유롭게 호출할 수 있습니다.

**메인 AI 모델에 장애가 발생하면 어떻게 처리되나요?**

사전에 설정한 백업 모델 순서에 따라 자동으로 다른 모델로 전환되어 요청을 처리합니다. 이를 통해 서비스 중단 없이 안정적인 운영이 가능합니다.

**팀원별로 지출 비용을 각각 제한할 수 있나요?**

네, 그렇습니다. 각각의 API 키, 팀원, 워크스페이스별로 일일 지출 한도를 지정할 수 있어 예산 초과를 효과적으로 예방할 수 있습니다.

**한국어 인터페이스와 고객지원은 지원하나요?**

현재 플랫폼 화면과 문서는 영어로 제공되며 커뮤니티는 주로 영어를 중심으로 운영됩니다. 다만 연동된 모델 자체는 한국어를 정상적으로 지원합니다.
