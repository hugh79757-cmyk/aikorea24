## 한줄 요약

Logimu는 아마존 상품 데이터와 검색 기능을 하나의 API로 통합하여 제공하는 서비스입니다. 이커머스 쇼핑몰 운영자나 개발자가 복잡한 연동 과정 없이 아마존의 방대한 상품 정보를 활용하는 데 도움이 되습니다.

## 핵심 기능

- **통합 API**: 상품 데이터와 검색을 한 번에 연동합니다.
- **실시간 검색**: 아마존의 최신 상품 정보를 빠르게 조회합니다.
- **데이터 연동**: 내 쇼핑몰 시스템에 상품 정보를 쉽게 반영합니다.

## 사용법

**1. 공식 웹사이트 회원가입**

Logimu 공식 홈페이지에 접속하여 개발자 계정을 생성합니다. 이메일 인증을 완료한 후 로그인하여 대시보드로 이동합니다.

**2. API 키 발급 받기**

대시보드 내 API 관리 메뉴에서 개인용 인증 키를 발급받습니다. 이 키는 쇼핑몰 시스템이나 개발 환경에 연동할 때 필수적으로 사용됩니다.

**3. API 연동 및 테스트**

제공되는 API 문서를 참고하여 쇼핑몰 백엔드 코드에 연동 코드를 작성합니다. 무료 플랜의 호출 한도 내에서 검색과 데이터 조회가 정상 작동하는지 확인합니다.

**4. 실시간 데이터 활용**

아마존 상품 검색 및 상세 데이터가 자사 시스템으로 수신되는 것을 확인합니다. 이후 상품 가격 모니터링이나 쇼핑몰 상품 등록 자동화 업무에 활용합니다.

## 가격 정책

- **무료 플랜**: 무료 체험 플랜로 기본적인 API 호출 테스트가 가능합니다.
- **유료 플랜**: 유료 플랜은 호출 횟수에 따라 다르게 구성되며, 월 약 30,000원(29달러)부터 시작합니다.

비용 절약 팁: 개발 테스트 단계에서는 무료 플랜을 활용해 연동 가능성을 먼저 확인하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본적인 API 호출 테스트가 가능한 무료 체험 플랜을 제공합니다. 개발 및 연동 테스트 단계에서 비용 부담 없이 기능을 미리 점검할 수 있습니다.

- **기본 유료 플랜** (월 약 30,000원 (29달러부터 시작)): 호출 횟수에 따라 다양하게 구성되어 있으며 본격적인 이커머스 데이터 연동에 적합합니다.

- **추가 확장 플랜** (공식 페이지 확인 필요): 대규모 트래픽과 대량의 상품 데이터 조회가 필요한 기업 사용자용 맞춤형 플랜입니다.

**환불과 해지**: 환불 및 구독 해지 정책에 대한 구체적인 내용은 공식 요금 페이지에서 직접 확인이 필요합니다.

## 한국어 지원

서비스 인터페이스와 API 문서는 영어로 제공되며, 한국어 상품 데이터 검색 결과는 별도의 번역 처리가 필요합니다.

## 한국어 품질 실측

**아마존 상품 검색**

- 프롬프트: 아마존 API를 통해 특정 키워드의 최신 상품 리스트를 호출하는 요청을 전송합니다.
- 결과 예시: 아마존 영문 상품명, 가격, 재고 상태 등이 JSON 형태로 반환됩니다.
- 관찰: 서비스 인터페이스와 API 문서가 영어로 제공되므로 한국어 상품명 검색 시 별도의 번역 처리가 필요합니다.

**가격 모니터링 연동**

- 프롬프트: 경쟁사 상품의 ASIN 코드를 입력하여 실시간 가격 변동 데이터를 조회합니다.
- 결과 예시: 지정한 상품의 현재 달러 가격과 판매자 정보가 개발자 시스템으로 전달됩니다.
- 관찰: 응답 데이터가 영어 및 숫자로 구성되어 있어 국내 쇼핑몰 반영 시 데이터 가공 과정이 요구됩니다.

개발자 중심의 API 서비스로 인터페이스와 문서가 모두 영어로 제공됩니다. 한국어 상품 정보 조회를 위해서는 별도의 번역 로직을 구현해야 하는 번거로움이 있습니다.

## 주의사항

- **개인정보**: 개발자 계정 정보 및 API 인증 키가 타인에게 노출되지 않도록 안전하게 관리해야 합니다. API 호출 과정에서 민감한 고객 개인정보가 포함되지 않도록 주의가 필요합니다.
- **저작권/상업적 이용**: 아마존에서 수집한 상품 데이터를 상업적 쇼핑몰에 활용할 때는 아마존의 이용 약관 및 데이터 정책을 준수해야 합니다. 무단 대량 스크래핑이나 저작권 침해 소지가 없도록 점검이 필요합니다.
- **요금/한도**: 무료 체험 플랜의 호출 한도를 초과할 경우 예상치 못한 과금이 발생할 수 있으므로 사용량을 주기적으로 모니터링해야 합니다. 정확한 요금제 한도는 공식 요금 페이지를 참고해야 합니다.
- **계정 관리**: 팀 단위로 API를 활용할 경우 계정 공유보다는 권한 관리를 철저히 하여 보안 사고를 예방하는 것이 좋습니다. 서비스 정책 변경에 대비해 공지사항을 수시로 확인해야 합니다.

## 자주 묻는 질문

**API 연동하려고 전문 개발 지식이 필요한가요?**

그렇습니다. 기본적인 프로그래밍 지식과 API 활용 능력이 있어야 원활한 연동이 가능합니다.

**한국어 상품 정보도 검색할 수 있나요?**

아마존 글로벌 데이터를 기반으로 하므로 주로 영문 상품 정보가 제공되며, 한국어 검색에는 제약이 있을 수 있습니다.

**요금제는 어떻게 결제하나요?**

주로 신용카드를 통한 온라인 결제 방식을 지원하며 사용량에 따라 플랜을 선택할 수 있습니다.

**API 연동을 위해 프로그래밍 지식이 꼭 필요한가요?**

네, Logimu는 개발 도구이므로 쇼핑몰 백엔드 시스템이나 웹 개발에 대한 기본적인 이해와 코딩 능력이 필요합니다.

**한국어 상품명을 검색해도 정확한 결과가 나오나요?**

기본적으로 아마존 영문 데이터를 기반으로 하므로 한국어 검색 시 원하는 결과가 나오지 않을 수 있으며 별도의 번역 처리가 필요합니다.

**무료 플랜에서 유료 플랜으로 자동 전환되나요?**

결제 수단 등록 여부에 따라 다르며, 의도치 않은 과금을 방지하기 위해 구독 정책을 사전에 확인하는 것이 안전합니다.

**쇼핑몰 재고 관리와 가격 변동 모니터링에 바로 쓸 수 있나요?**

제공되는 API를 쇼핑몰 관리자 페이지와 연동하면 실시간 가격 및 재고 모니터링 시스템을 직접 구축할 수 있습니다.
