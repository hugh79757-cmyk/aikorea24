## 한줄 요약

The Brains는 유명 창업가, CEO, 투자자들의 공개된 강연과 글을 AI 모델과 연결해 주는 서비스입니다. 단순히 일반적인 답변을 주는 것이 아니라, 해당 전문가의 실제 발언을 근거로 답변하여 신뢰도 높은 인사이트를 제공합니다.

## 핵심 기능

- **전문가 지식 연동**: 유명 인사들의 철학을 AI 답변에 직접 반영합니다.
- **출처 명시**: 모든 답변의 근거가 된 원문 링크를 제공하여 신뢰도를 높입니다.
- **범용성**: Claude, Cursor, ChatGPT 등 다양한 도구와 연동 가능합니다.

## 사용법

**1. 전문가 브레인 검색 및 선택**

웹사이트 상단 검색창에 원하는 창업가나 투자자의 이름을 입력합니다. 검색 결과에서 원하는 인물을 클릭하여 해당 전문가의 데이터 서버 정보를 확인합니다.

**2. MCP 서버 주소 복사**

선택한 전문가의 브레인 페이지에서 제공되는 MCP 서버 연결 주소를 복사합니다. 이 주소는 Claude나 Cursor 등 AI 도구와 연동하기 위해 반드시 필요합니다.

**3. AI 도구 설정에 서버 추가**

사용 중인 Claude, Cursor, ChatGPT의 설정 메뉴 내 MCP(Model Context Protocol) 항목으로 이동합니다. 복사한 서버 주소를 입력하여 해당 전문가의 지식을 AI에 연결합니다.

**4. 전문가 관점 질문하기**

연결이 완료되면 채팅창에서 전문가의 이름을 언급하며 질문을 입력합니다. AI가 해당 전문가의 강연이나 글을 보고 근거가 포함된 답변을 생성합니다.

## 가격 정책

- **무료 플랜**: 공개된 브레인 데이터를 검색하고 활용하는 기능을 무료로 이용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 명시되어 있지 않으나, 향후 서비스 확장 시 구독 모델이 도입될 가능성이 있습니다.

비용 절약 팁: 자주 찾는 전문가를 미리 즐겨찾기하여 검색 시간을 단축하는 것이 비용 효율적입니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 공개된 브레인 데이터를 자유롭게 검색하고 MCP 서버 주소를 활용할 수 있습니다. 현재 서비스는 공개된 콘텐츠를 기반으로 운영되며 별도의 메시지 제한은 명시되지 않았습니다.

- **기본 이용** (무료): 모든 공개된 브레인 데이터 검색 및 MCP 서버 연동 기능을 제한 없이 사용할 수 있습니다.

- **향후 유료 플랜** (공식 페이지 확인 필요): 서비스 확장 시 추가적인 기능이나 프리미엄 데이터 접근에 대한 구독 모델이 도입될 가능성이 있습니다.

**환불과 해지**: 현재 무료 서비스 위주로 운영되므로 별도의 환불 규정은 없으며, 추후 유료화 시 공식 홈페이지의 이용 약관을 확인해야 합니다.

## 한국어 지원

툴 자체 인터페이스는 영어로 제공되나, AI 모델(Claude/ChatGPT 등)을 통해 질문하면 한국어로 자연스러운 답변을 얻을 수 있습니다.

## 한국어 품질 실측

**스타트업 제품 마케팅 전략**

- 프롬프트: 폴 그레이엄의 관점에서 초기 스타트업이 제품 마케팅을 할 때 가장 중요하게 생각해야 할 점은 무엇인가요?
- 결과 예시: 폴 그레이엄은 그의 에세이에서 '초기에는 마케팅보다 제품 그 자체의 완성도에 집중하라'고 강조합니다. 사용자가 자발적으로 입소문을 낼 수 있는 수준의 제품을 만드는 것이 최고의 마케팅이라고 언급한 바 있습니다.
- 관찰: AI 모델이 한국어로 질문을 이해하고 전문가의 논조를 자연스럽게 반영하여 답변합니다.

**투자 유치 조언 요청**

- 프롬프트: 샘 알트먼의 강연 내용을 보고 투자자에게 사업 계획서를 피칭할 때 주의할 점을 알려주세요.
- 결과 예시: 샘 알트먼은 투자자에게 사업의 비전과 거대한 시장 규모를 명확히 제시하는 것이 중요하다고 말합니다. 데이터와 함께 당신의 사업이 왜 지금 당장 필요한지 설득력 있게 전달해야 합니다.
- 관찰: 전문 용어의 번역이 매끄럽고 한국어 문맥에 맞게 잘 구성됩니다.

도구 자체는 영어 인터페이스이지만 연동된 AI 모델(Claude 등)이 한국어 답변을 완벽하게 지원합니다. 번역투가 거의 없으며, 전문가의 지식을 한국어 비즈니스 문맥으로 자연스럽게 풀어냅니다.

## 이런 분에게 추천합니다

새로운 비즈니스 아이디어를 찾고 있는 예비 창업자에게 추천합니다. 깊이 있는 경영 철학을 알고 싶은 직장인에게 적합합니다. 시장 트렌드를 분석해야 하는 투자자에게 유용합니다.

## 실제 활용 예시

- **직장인**: 신규 프로젝트 기획 시, 유명 경영자의 사례를 근거로 설득력 있는 보고서를 작성할 때 사용합니다.
- **학생**: 창업 관련 과제나 논문을 작성할 때, 전문가들의 실제 에세이를 인용하여 분석의 깊이를 더할 때 사용합니다.
- **소상공인**: 가게 운영 전략을 고민할 때, 성공한 CEO들의 운영 노하우를 검색하여 우리 가게에 적용할 점을 찾을 때 사용합니다.

## 유사 툴과 비교

**장점:**
- 검증된 전문가의 데이터 기반 답변
- 답변의 출처가 명확함

**단점:**
- 영어 기반 데이터가 많아 한국어 관련 정보는 제한적일 수 있음

**이런 분에게 가장 적합합니다:** 실제 성공한 사람들의 구체적인 생각과 전략을 참고하고 싶을 때 가장 좋습니다.

| Perplexity AI | 무료/유료 | 매우 높음 | 실시간 뉴스 및 일반적인 정보 검색과 출처 확인이 동시에 필요할 때 | 특정 인물의 철학을 깊이 있게 파고드는 기능은 The Brains보다 약함 |

## 장단점

**장점**

- 유명 창업가와 투자자의 실제 강연 및 글을 근거로 답변하여 정보의 신뢰도가 매우 높습니다.
- 모든 답변에 원문 출처 링크가 포함되어 있어 필요 시 직접 원문을 확인하기 편리합니다.
- Claude, Cursor 등 대중적인 AI 도구와 MCP 프로토콜로 쉽게 연동하여 확장성이 뛰어납니다.
- 직접 전문가를 찾지 않아도 해당 인물의 핵심 철학을 빠르게 파악하여 업무에 적용할 수 있습니다.

**단점**

- 현재 서비스되는 전문가의 데이터가 영어권 인물 위주로 구성되어 있어 한국인 전문가 정보는 부족할 수 있습니다.
- 웹사이트 인터페이스가 영어로만 제공되어 한국인 사용자가 처음 설정할 때 다소 생소하게 느껴질 수 있습니다.
- 공개된 콘텐츠를 기반으로 하므로 최신 트렌드나 아주 최근의 발언은 데이터 반영이 늦어질 가능성이 있습니다.

## 주의사항

- **개인정보**: 사용자가 AI에 질문하는 내용이 모델 학습에 사용될 수 있으므로, 민감한 기업 기밀이나 개인정보 입력은 지양해야 합니다.
- **저작권/상업적 이용**: 제공되는 답변은 공개된 콘텐츠를 요약한 것이므로, 이를 그대로 인용하여 상업적 출판물에 사용하는 것은 저작권 확인이 필요합니다.
- **요금/한도**: 현재는 무료로 운영되나 향후 서비스 정책 변경에 따라 유료화될 수 있으므로 이용 전 공식 요금 페이지를 주기적으로 확인하십시오.
- **계정 관리**: MCP 서버 연동 시 사용하는 외부 AI 도구의 계정 보안 설정을 철저히 관리하여 예기치 않은 데이터 노출을 방지해야 합니다.

## 자주 묻는 질문

**답변이 한국어로 나오나요?**

네, 연동하는 AI 모델(ChatGPT 등)이 한국어를 지원하므로, 한국어로 질문하면 한국어로 답변을 받을 수 있습니다.

**모든 전문가의 정보가 다 있나요?**

아니요, 현재 등록된 전문가 위주로 제공됩니다. 원하는 인물이 없다면 사이트에서 직접 요청(Request)할 수 있습니다.

**어떻게 설치하나요?**

웹사이트에서 제공하는 MCP 서버 주소를 복사하여, 사용 중인 AI 도구(Claude 등)의 설정에 추가하면 바로 연동됩니다.

**내가 원하는 전문가가 목록에 없으면 어떻게 하나요?**

웹사이트 내 'Request a brain' 메뉴를 통해 원하는 인물을 직접 요청할 수 있습니다. 가장 많은 요청을 받은 인물부터 우선적으로 구축됩니다.

**답변의 정확도는 어떻게 보장하나요?**

모든 답변은 해당 전문가의 공개된 강연, 에세이, 게시글을 근거로 생성됩니다. 답변 하단에 출처 링크가 명시되어 직접 검증이 가능합니다.

**MCP 서버가 무엇인가요?**

Model Context Protocol의 약자로, AI 모델이 외부 데이터나 도구와 안전하게 연결되어 정보를 주고받을 수 있게 해주는 표준 규격입니다.

**기업용으로 사용해도 되나요?**

개인적인 인사이트 확보에는 유용하나, 기업 내부 시스템에 도입할 경우 데이터 보안 정책과 서비스 이용 약관을 면밀히 검토해야 합니다.
