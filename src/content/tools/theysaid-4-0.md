## 한줄 요약

TheySaid 4.0은 실제 사용자를 구하기 어려운 상황에서 AI 가상 사용자로 서비스의 문제점을 미리 파악하게 해줍니다. 기획자나 디자이너가 매번 사람을 모집하는 번거로움 없이, 기획 단계에서 빠르게 피드백을 받아 완성도를 높일 수 있습니다.

## 핵심 기능

- **가상 사용자 테스트**: 사람을 모집할 필요 없이 AI가 대신 서비스 반응을 테스트합니다.
- **AI 인터뷰**: AI가 사용자와 대화하며 상세한 피드백을 자동으로 정리합니다.
- **자동 분석 리포트**: 수집된 데이터를 바탕으로 개선점을 자동으로 요약해 보여줍니다.

## 사용법

**1. 서비스 연동 설정하기**

사용 중인 업무 도구 내에서 TheySaid를 연결합니다. 별도의 새 앱을 켤 필요 없이 작업 환경 내에서 2분 만에 설정을 마칠 수 있습니다.

**2. 테스트 대상 설정하기**

테스트할 디자인이나 프로토타입을 업로드합니다. 실제 사용자 혹은 AI 가상 사용자를 선택하여 테스트를 진행할 준비를 합니다.

**3. 테스트 자동 실행하기**

업무 티켓이 'Design Done' 상태로 변경되면 자동으로 테스트가 시작됩니다. AI가 사용자의 반응을 수집하고 개선점을 도출합니다.

**4. 분석 결과 확인 및 수정**

테스트 결과를 확인하고 AI가 제공하는 수정 프롬프트를 복사합니다. 이를 Claude나 코드 에디터에 붙여넣어 즉시 문제를 해결합니다.

## 가격 정책

- **무료 플랜**: 무료 체험을 제공하며 기본적인 테스트 기능을 사용해 볼 수 있습니다.
- **유료 플랜**: Starter 플랜 기준 월 99달러(약 13만 원)부터 시작하며 더 많은 가상 사용자 테스트와 고급 분석 기능을 제공합니다.

비용 절약 팁: 먼저 무료 체험로 우리 서비스의 성격과 AI 테스트 결과가 잘 맞는지 충분히 검증한 후 유료 결제를 고려하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜은 별도의 신용카드 등록 없이 체험이 가능합니다. 첫 번째 테스트를 5분 이내에 시작할 수 있으며 기본적인 기능들을 검증해 볼 수 있습니다.

- **Starter Plan** (월 99달러 (약 13만 원, 환율에 따라 변동 가능)): 더 많은 가상 사용자 테스트와 상세한 분석 기능을 제공합니다. 팀 단위의 반복적인 검증 작업에 적합합니다.

- **Enterprise Plan** (공식 페이지 확인 필요): 대규모 조직을 위한 맞춤형 기능과 보안 옵션을 제공합니다. 정확한 견적은 영업팀 문의가 필요합니다.

**환불과 해지**: 결제 및 환불 정책은 공식 요금 페이지의 이용 약관로 확인해야 합니다. 구독 해지 시 다음 결제 주기부터 비용이 청구되지 않습니다.

## 한국어 지원

70개 이상의 언어를 지원하여 한국어를 포함한 다국어 테스트가 가능합니다. 한국어 인터페이스와 분석 결과도 원활하게 확인할 수 있습니다.

## 한국어 품질 실측

**쇼핑몰 UI 개선 피드백**

- 프롬프트: 이 결제 페이지 디자인에서 사용자가 이탈할 만한 요소가 무엇인지 분석해줘. 한국 사용자 관점에서 설명해줘.
- 결과 예시: 결제 버튼의 위치가 시각적으로 잘 띄지 않아 사용자가 혼란을 겪을 수 있습니다. 또한, 한국형 간편결제 옵션이 부족하여 이탈률이 15% 정도 발생할 것으로 예측됩니다.
- 관찰: 한국어 질문를 문맥을 잘 파악하며 자연스러운 분석 결과를 제시합니다.

**앱 사용성 테스트**

- 프롬프트: 회원가입 과정에서 입력 항목이 너무 많아 불편하다는 의견이 있어. 이를 어떻게 개선하면 좋을지 제안해줘.
- 결과 예시: 입력 항목을 3단계로 분할하고 SNS 간편 로그인 기능을 최상단에 배치하는 것을 추천합니다. 불필요한 개인정보 입력을 줄이면 전환율이 개선될 것입니다.
- 관찰: 비즈니스 전문 용어를 적절히 사용하여 한국어로 명확한 개선안을 도출합니다.

한국어를 포함한 70개 이상의 언어를 지원하여 다국어 테스트에 강점이 있습니다. 번역투가 거의 느껴지지 않을 정도로 자연스럽고 전문적인 한국어 분석 리포트를 제공합니다.

## 이런 분에게 추천합니다

서비스 출시 전 사용자 반응이 궁금한 기획자, 매번 리서치 비용과 시간이 부담되는 스타트업 대표, 디자인 개선점을 데이터로 증명하고 싶은 UX 디자이너에게 추천합니다.

## 실제 활용 예시

- **직장인**: 신규 앱 기능을 개발하기 전, 가상 사용자 테스트로 버튼 위치가 직관적인지 미리 확인합니다. 이로 개발 후 수정 비용을 크게 절감할 수 있습니다.
- **학생**: 졸업 작품으로 만든 웹 서비스의 사용성을 평가받을 때, 실제 사람을 섭외하기 어려우므로 AI를 활용해 객관적인 피드백을 수집합니다.
- **소상공인**: 온라인 쇼핑몰 상세 페이지를 개편할 때, 가상 고객의 의견을 물어 어떤 문구가 구매 욕구를 더 자극하는지 테스트합니다.

## 유사 툴과 비교

**장점:**
- 사람을 모집하는 시간과 비용이 획기적으로 줄어듭니다.
- 24시간 언제든 테스트 결과를 즉시 확인할 수 있습니다.

**단점:**
- 실제 사람의 미묘한 감정이나 돌발적인 행동까지 완벽하게 재현하기는 어렵습니다.

**이런 분에게 가장 적합합니다:** 서비스 기획 초기 단계에서 빠르게 가설을 검증하고 싶을 때 가장 적합합니다.

## 장단점

**장점**

- 실제 사용자를 모집할 시간을 기다릴 필요 없이 AI 가상 사용자로 즉각적인 피드백을 받을 수 있습니다.
- 기존에 사용하던 업무용 툴(Claude, Replit 등) 내에서 바로 테스트를 실행할 수 있어 작업 흐름이 끊기지 않습니다.
- 테스트 결과를 단순히 보여주는 것에 그치지 않고, 수정에 필요한 구체적인 프롬프트를 제공하여 실무 효율을 높여줍니다.
- 사용자의 주저함이나 불만 사항을 타임스탬프와 함께 기록하여 문제의 원인을 시각적으로 명확하게 파악할 수 있습니다.

**단점**

- AI 가상 사용자의 테스트 결과가 실제 사람의 복잡한 감정을 100% 대변하지 못할 가능성이 존재합니다.
- 월 99달러부터 시작하는 유료 플랜은 개인 사용자나 소규모 스타트업에게 다소 부담스러울 수 있는 비용입니다.
- 복잡한 서비스 도메인의 경우 AI가 맥락을 완벽히 이해하기 위해 초기 학습 단계가 필요할 수 있습니다.

## 주의사항

- **개인정보**: 테스트 과정에서 민감한 고객 정보가 유출되지 않도록 주의해야 합니다. 실제 데이터 대신 가상의 테스트 데이터를 사용하는 것을 권장합니다.
- **저작권/상업적 이용**: AI가 생성한 분석 결과의 저작권은 이용 약관에 따릅니다. 상업적 활용 시 해당 플랫폼의 정책을 반드시 확인하시기 바랍니다.
- **요금/한도**: 무료 체험 이후 유료 전환 시 자동으로 결제가 진행될 수 있으므로, 플랜별 테스트 횟수 한도를 사전에 확인해야 합니다.
- **계정 관리**: 팀 단위로 사용할 경우 권한 설정이 중요합니다. 계정 공유보다는 팀 멤버를 초대하여 안전하게 관리하는 것이 좋습니다.

## 자주 묻는 질문

**가상 사용자가 실제 사람과 얼마나 비슷한가요?**

AI는 방대한 데이터를 기반으로 일반적인 사용자 행동 패턴을 학습하여 반응합니다. 초기 기획 단계의 가설 검증용으로는 매우 유용하지만 최종 출시 전에는 실제 사용자 테스트를 병행하는 것이 좋습니다.

**한국어 설문조사도 가능한가요?**

네, 70개 이상의 언어를 지원하므로 한국어로 질문을 작성하고 답변을 받는 데 전혀 문제가 없습니다. 한국어 환경에서도 자연스러운 피드백 수집이 가능합니다.

**기술적인 지식이 없어도 사용할 수 있나요?**

별도의 코딩 지식 없이도 웹 기반 대시보드에서 설문이나 테스트를 생성할 수 있습니다. 직관적인 UI를 제공하여 기획자나 마케터도 쉽게 접근할 수 있습니다.

**실제 사용자 대신 AI를 믿어도 되나요?**

AI는 방대한 데이터를 바탕으로 일반적인 사용자 패턴을 학습했기 때문에 초기 기획 단계에서 문제점을 찾는 데 매우 유용합니다. 다만, 최종 출시 전에는 실제 사용자의 검증을 병행하는 것이 가장 안전합니다.

**기존에 쓰던 툴과 어떻게 연동하나요?**

별도의 복잡한 설치 과정 없이 API나 위젯 형태로 연동이 가능합니다. 티켓 관리 툴 등에서 특정 상태로 변경될 때 자동으로 테스트가 트리거되도록 설정할 수 있습니다.

**한국어 서비스도 테스트가 가능한가요?**

네, 70개 이상의 언어를 지원하므로 한국어 서비스도 충분히 테스트할 수 있습니다. 한국어 인터페이스와 분석 리포트 모두 자연스러운 수준으로 제공됩니다.

**무료 체험 후 결제가 자동으로 되나요?**

무료 체험 시 신용카드 정보를 요구하지 않는 경우가 많지만, 플랜 변경 시점에는 반드시 약관을 확인해야 합니다. 결제 주기와 한도에 대한 정확한 내용은 공식 페이지에서 확인하십시오.
