## 한줄 요약

BrickForgerAI는 상상 속의 물체를 레고 블록 모델로 자동 변환해주는 서비스입니다. 복잡한 3D 모델링 지식 없이도 프롬프트 입력만으로 조립 가능한 PDF 설명서와 부품 리스트를 얻을 수 있어 취미 활동이나 선물 제작에 매우 유용합니다.

## 핵심 기능

- **자동 모델링**: 텍스트 입력만으로 즉시 레고 형태의 3D 모델을 생성합니다.
- **PDF 조립 설명서**: 실제 레고처럼 따라 할 수 있는 단계별 조립 가이드를 제공합니다.
- **부품 목록 제공**: 모델 제작에 필요한 모든 레고 부품 리스트를 정리해 줍니다.

## 가격 정책

- **무료 플랜**: 매달 3개의 무료 크레딧을 제공하며 모델 생성 및 확인이 가능합니다.
- **유료 플랜**: 유료 플랜(가격 별도 문의)을 통해 .ldr 파일 다운로드 및 무제한 생성 혜택을 누릴 수 있습니다.

비용 절약 팁: 무료 크레딧으로 먼저 모델의 형태를 확인한 후, 마음에 드는 결과물일 때 다운로드 결제를 진행하는 것이 효율적입니다.

## 한국어 지원

현재 인터페이스는 영어로만 제공되지만 프롬프트 입력 시 간단한 영어 단어만으로도 충분히 원하는 결과를 얻을 수 있습니다.

## 이런 분에게 추천합니다

레고를 취미로 즐기는 키덜트족, 아이들을 위한 특별한 장난감을 만들고 싶은 부모님, 독특한 인테리어 소품을 직접 제작하고 싶은 분들에게 추천합니다.

## 실제 활용 예시

- **직장인**: 퇴근 후 스트레스 해소하려고 나만의 데스크테리어 소품을 직접 설계합니다. AI가 생성한 설명서를 보며 차분하게 조립하는 즐거움을 누립니다.
- **학생**: 학교 과제나 창의적 체험 활동으로 자신만의 독창적인 레고 작품을 만듭니다. 설계도 없이도 복잡한 구조를 구현할 수 있어 매우 편리합니다.
- **소상공인**: 매장 인테리어에 어울리는 작은 로고나 캐릭터를 레고로 제작해 배치합니다. 고객들에게 특별한 볼거리를 제공하여 매장의 개성을 살릴 수 있습니다.

## 유사 툴과 비교

**장점:**
- 조립 설명서까지 자동으로 생성되어 실물 제작이 매우 간편함
- 실제 구매 가능한 부품 위주로 설계되어 현실성 높음

**단점:**
- 영어 인터페이스라 초반 적응이 필요할 수 있음

**이런 분에게 가장 적합합니다:** 상상 속의 물체를 실제로 조립 가능한 레고 모델로 빠르게 구현하고 싶은 경우 가장 적합합니다.

## 자주 묻는 질문

**생성된 모델은 실제 레고 부품으로 조립 가능한가요?**

네, 실제 구매 가능한 레고 부품 라이브러리를 기반으로 설계됩니다. 대부분의 모델은 안정적으로 조립할 수 있도록 최적화되어 있습니다.

**다운로드한 .ldr 파일은 어디서 사용하나요?**

BrickLink Studio와 같은 전문 레고 설계 프로그램에서 열어볼 수 있습니다. 이로 모델을 수정하거나 렌더링하여 고화질 이미지로도 만들 수 있습니다.

**무료 크레딧을 다 쓰면 어떻게 하나요?**

매달 크레딧이 갱신되기를 기다리거나 유료 플랜을 구독하여 제한 없이 사용할 수 있습니다. 결제는 결과물을 다운로드할 때만 진행하면 됩니다.
