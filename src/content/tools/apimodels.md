180개 이상의 AI 모델을 하나의 API로 쓰는 통합 API. 종량제 $10부터, 월 구독료 없음. 제작사 Pixlume(싱가포르).

## 사용법

**1. API 키 발급받기**

공식 홈페이지에 접속하여 계정을 생성한 후, 대시보드의 'API Keys' 메뉴에서 새로운 키를 생성합니다. 생성된 키는 복사하여 개발 중인 프로그램이나 연동할 서비스에 안전하게 보관합니다.

**2. 모델 선택 및 확인**

홈페이지 상단의 'Models' 메뉴를 클릭하여 사용 가능한 184개 이상의 AI 모델 목록을 확인합니다. 각 모델별로 지원하는 기능과 특징이 명시되어 있으므로 프로젝트 목적에 맞는 모델을 선택합니다.

**3. 서비스 연동 및 호출**

제공되는 API 문서를 참고하여 개발 중인 코드에 API 엔드포인트를 설정합니다. 단일 API 키만으로 다양한 언어, 이미지, 영상 모델을 호출하여 사용할 수 있습니다.

**4. 비용 충전 및 관리**

종량제 방식으로 운영되므로 'Balance' 메뉴에서 최소 $10부터 필요한 만큼 크레딧을 충전합니다. 사용량은 'Usage' 탭에서 실시간으로 확인할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 별도의 무료 체험 플랜은 명시되어 있지 않으며, 종량제 방식을 채택하고 있습니다. 실패한 API 호출에 대해서는 비용이 청구되지 않으므로 효율적인 자원 관리가 가능합니다.

- **종량제(Pay-as-you-go)** (최소 $10부터 충전 가능): 184개 이상의 다양한 AI 모델을 사용한 만큼만 결제하며 월 구독료가 발생하지 않습니다.

**환불과 해지**: 정확한 환불 정책 및 결제 관련 세부 규정은 공식 홈페이지의 요금 페이지 및 이용 약관로 확인이 필요합니다.

## 한국어 품질 정리

**상품 홍보 문구 작성**

- 프롬프트: 친환경 텀블러를 홍보하기 위한 감성적인 인스타그램 문구를 3줄로 작성해줘.
- 결과 예시: 지구를 생각하는 마음을 담은 친환경 텀블러입니다. 일상 속 작은 실천으로 환경 보호를 시작해보세요. 당신의 소중한 일상에 따뜻함을 더해드립니다.
- 관찰: 모델 자체의 한국어 생성 능력은 뛰어나지만 API를 통해 호출하는 각 모델의 학습 데이터에 따라 품질 차이가 있을 수 있습니다.

**비즈니스 이메일 초안**

- 프롬프트: 거래처에 보낼 다음 주 회의 일정 변경 요청 이메일을 정중하게 작성해줘.
- 결과 예시: 안녕하세요, OO님. 다름이 아니오라 부득이한 사정으로 다음 주 회의 일정을 변경하고자 합니다. 편하신 시간을 알려주시면 최대한 조정하도록 하겠습니다.
- 관찰: 비즈니스 문맥을 잘 파악하여 정중한 어조로 생성하는 편이나, 한국어 전용 모델이 아닐 경우 어색한 표현이 섞일 가능성이 있습니다.

대부분의 LLM 모델이 한국어를 지원하므로 업무 활용도는 높습니다. 다만, 인터페이스 자체가 영어로 되어 있어 한국어 사용자에게는 초기 설정 시 다소 생소하게 느껴질 수 있습니다.

## 장단점

**장점**

- 단 하나의 API 키로 OpenAI, Anthropic, Google 등 다양한 기업의 180개 이상 AI 모델을 통합하여 사용할 수 있습니다.
- 오류가 발생한 API 호출에 대해서는 비용을 청구하지 않는 정책로 개발자의 비용 부담을 최소화합니다.
- 월 구독료 없이 사용한 만큼만 지불하는 종량제 방식을 채택하여 개인 개발자나 소규모 스튜디오에 경제적입니다.
- 자동 장애 조치(Failover) 기능을 지원하여 특정 모델의 서버가 불안정할 때 서비스 연속성을 안정적으로 유지합니다.

**단점**

- 서비스 인터페이스와 기술 문서가 영어로 제공되어 한국어 사용자에게는 접근 장벽이 존재할 수 있습니다.
- 다양한 모델을 한곳에서 관리하는 만큼, 각 모델별 특성과 최적화된 프롬프트 사용법을 개별적으로 숙지해야 합니다.
- 공식 홈페이지 외의 커뮤니티나 한국어 기술 지원 채널이 부족하여 문제 발생 시 해결이 어려울 수 있습니다.

## 주의사항

- **개인정보**: API를 통해 전송하는 데이터에 개인정보나 민감한 정보가 포함되지 않도록 주의해야 하며 서비스별 데이터 처리 방침을 확인해야 합니다.
- **저작권/상업적 이용**: 각 AI 모델마다 생성물의 저작권 정책이 다르므로, 상업적 용도로 활용 시 해당 모델의 이용 약관을 반드시 검토해야 합니다.
- **요금/한도**: 종량제 서비스이므로 예상치 못한 과다 사용을 방지하기 위해 잔액과 사용량을 주기적으로 모니터링하는 것이 권장됩니다.
- **계정 관리**: API 키가 유출될 경우 타인이 내 크레딧을 무단으로 사용할 위험이 있으므로 키 관리에 각별히 유의해야 합니다.
