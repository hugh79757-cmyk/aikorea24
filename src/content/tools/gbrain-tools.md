## 한줄 요약

GBrain Tools는 ChatGPT, Claude, Cursor 등 다양한 AI 도구에 개인 계정을 안전하게 연결해 주는 보안 관리 툴입니다. AI에게 실제 비밀번호를 제공하지 않고도 Gmail, Notion, GitHub 등의 데이터에 접근할 수 있게 해줍니다. 접근 권한 및 일일 호출 제한을 직접 설정할 수 있어 개인정보 유출 걱정을 줄여줍니다.

## 핵심 기능

- **일회성 계정 연동**: 서비스별 최초 1회 연동으로 모든 AI에서 안전 사용
- **세부 권한 제어**: AI별 접근 권한, 만료일, 일일 한도 설정 가능
- **통합 접근 기록**: 어떤 AI가 어떤 데이터를 조회했는지 한눈에 확인

## 사용법

**1. 서비스 계정 연동하기**

GBrain 대시보드에 접속하여 Gmail, GitHub, Notion 등 필요한 계정을 최초 1회 로그인합니다. 이 과정에서 각 서비스의 인증 키가 GBrain 서버 내에 안전하게 저장됩니다.

**2. AI 도구와 연결하기**

사용 중인 ChatGPT, Claude, Cursor 등의 AI 도구 설정 메뉴에서 GBrain에서 제공하는 연동 키를 입력합니다. 이제 AI가 직접 비밀번호를 알지 못해도 GBrain을 통해 정보를 조회할 수 있습니다.

**3. 접근 권한 및 제한 설정**

각 AI 서비스별로 접근 가능한 데이터 범위와 일일 호출 한도를 상세히 설정합니다. 특정 서비스에 대한 접근을 즉시 차단하거나 만료일을 지정하여 보안을 강화할 수 있습니다.

**4. 활동 기록 모니터링**

통합 대시보드의 로그 화면로 어떤 AI가 언제 어떤 데이터를 조회했는지 실시간으로 확인합니다. 비정상적인 접근 시도가 발생하면 즉시 해당 AI의 권한을 회수할 수 있습니다.

## 한국어 품질 실측

**이메일 초안 작성 요청**

- 프롬프트: Gmail에서 '협력사 미팅' 관련 마지막 메일을 찾아서 답장 초안을 작성해 줘.
- 결과 예시: GBrain을 통해 Gmail에 접근하여 최근 메일을 확인했습니다. '다음 주 수요일 오후 2시 미팅 가능합니다'라는 내용의 답장 초안을 작성해 드립니다.
- 관찰: 도구 자체가 한국어를 지원하지 않으므로, 사용자가 입력하는 프롬프트는 영어로 변환하여 입력하는 것이 더 정확한 결과를 얻을 수 있습니다.

**GitHub 이슈 확인**

- 프롬프트: 내 GitHub 저장소에서 최근 발생한 이슈 목록을 요약해 줘.
- 결과 예시: GitHub 저장소에 연결하여 현재 오픈된 이슈 3건을 확인했습니다. 주요 내용은 버그 수정 요청과 기능 개선 제안입니다.
- 관찰: AI 모델이 한국어를 이해하더라도 도구의 인터페이스가 영어이므로 한국어 처리 과정에서 다소 번역투가 섞일 수 있습니다.

대시보드와 설정 화면이 모두 영어로만 구성되어 있어 한국 사용자가 처음 접할 때 다소 어려움을 느낄 수 있습니다. AI가 처리하는 결과값은 한국어 입력에 대응하지만 설정 단계에서는 영어 숙련도가 필요합니다.

- **직장인**: 업무용 구글 계정을 GBrain에 한 번만 등록하여 사용합니다. Claude나 ChatGPT에 비밀번호를 직접 입력하지 않고도 일정 조회나 이메일 요약 작업을 안전하게 처리합니다.
- **학생**: 팀 프로젝트 진행 시 노션과 깃허브 계정을 AI 코딩 도구에 연결합니다. 개인 계정 정보의 유출 위험 없이 과제용 자동화 코드를 작성하고 관리합니다.
- **소상공인**: 고객 문의 응대용 AI에 메일 및 캘린더 계정을 연동합니다. 권한 만료일과 일일 제한을 설정하여 보안 사고를 예방하면서 자동으로 일정을 관리합니다.

- **계정 관리**: 연동된 계정의 권한은 사용자가 직접 관리해야 하며 불필요한 AI 연동은 즉시 삭제하여 보안 사고를 예방하는 습관이 필요합니다.

## 자주 묻는 질문

**AI가 제 비밀번호를 직접 볼 수 있나요?**

아닙니다. GBrain이 계정 인증을 대신 처리하고 AI에게는 요청 결과만 전달하므로 AI는 비밀번호를 절대로 알 수 없습니다.

**어떤 AI 도구들과 연동되나요?**

ChatGPT, Claude, Cursor, Claude Code 등 주요 AI 서비스 및 터미널 환경을 모두 지원합니다.

**특정 AI의 접근을 바로 중단할 수 있나요?**

네, 대시보드에서 클릭 한 번으로 특정 AI의 접근 권한을 즉시 비활성화하거나 차단할 수 있습니다.

**AI가 내 비밀번호를 정말로 알 수 없나요?**

네, GBrain은 인증 키만 보관하고 실제 비밀번호는 AI에게 전달하지 않습니다. AI는 오직 요청에 대한 결과값만을 받아 처리하므로 보안이 유지됩니다.

**무료로 체험해 볼 수 있는 방법은 없나요?**

현재 공식적으로 제공되는 무료 플랜은 없습니다. 모든 기능은 유료 구독을 통해서만 활성화되므로 공식 페이지의 요금 정보를 확인하시기 바랍니다.

**어떤 AI 도구들과 연동이 가능한가요?**

Claude, ChatGPT, Cursor, Claude Code 등 다양한 최신 AI 도구와 연동을 지원합니다. 정확한 호환 리스트는 홈페이지의 지원 목록을 참조하십시오.

**연동한 계정의 접근 권한을 즉시 취소할 수 있나요?**

네, 대시보드의 로그 화면에서 특정 AI의 접근을 즉시 차단하거나 권한을 회수할 수 있습니다. 보안 사고 발생 시 즉각적인 대응이 가능합니다.
