## 한줄 요약

Fluxmail은 Gmail을 위한 AI 이메일 클라이언트로, 중요한 이메일을 쉽게 정리하고 답장을 자동으로 작성해줍니다. 바쁜 업무 중 시간을 절약할 수 있도록 도와줍니다.

## 핵심 기능

- **우선 순위 정리**: 중요한 이메일을 쉽게 찾을 수 있습니다.
- **답장 자동 작성**: 사용자의 목소리로 이메일 답장을 작성합니다.
- **업무 자동화**: 이메일 관리의 번거로움을 줄여줍니다.

## 사용법

**1. 깃허브에서 소스코드 다운로드**

공식 깃허브 저장소에서 Fluxmail 소스코드를 내려받고 내 서버 환경에 설치를 진행합니다. 사용자가 직접 인프라를 구축하는 Self-hosted 방식을 지원합니다.

**2. 이메일 계정 및 API 연동**

Gmail, Outlook, Exchange, IMAP 등 사용하는 메일 계정을 연결하고 API 키를 발급받습니다. 터미널이나 설정 파일로 연동 상태를 확인합니다.

**3. MCP 및 인터페이스 연결**

Claude Code나 외부 AI 에이전트가 MCP, REST API, CLI 중 편한 방식로 이메일 인프라에 접근하도록 설정합니다. 이로 터미널이나 에이전트 채팅창에서 메일을 제어합니다.

**4. 에이전트를 통한 메일 업무 수행**

자연어 명령을 입력하여 안 읽은 고객 메일을 확인하고 답장 초안을 작성합니다. 검토 과정을 거친 뒤 메일을 안전하게 발송하거나 아카이브 처리합니다.

## 가격 정책

- **무료 플랜**: 무료 체험으로 기본 기능을 이용할 수 있습니다.
- **유료 플랜**: 프리미엄 플랜 5만원 + 추가 기능을 활용합니다.

비용 절약 팁: 무료 체험 후 필요에 따라 유료 플랜으로 전환할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 소스코드가 깃허브에 공개된 Source-available 형태이며 사용자가 직접 인프라를 구축하여 무료로 활용할 수 있습니다. 별도의 유료 플랜 가격이나 크레딧 한도에 대한 상세 정보는 공식 요금 페이지에서 확인이 필요합니다.

- **Self-hosted 기본 플랜** (정확한 금액은 공식 요금 페이지 확인 필요): 사용자 소유의 인프라에서 직접 서버를 구동하여 메일 인프라를 운영할 수 있습니다.

- **프리미엄 인프라 플랜** (월 5만원 (상세 조건 공식 페이지 확인 필요)): 추가적인 비즈니스 기능과 확장된 API 호출 환경을 제공합니다.

**환불과 해지**: 자체 호스팅 및 오픈소스 기반 프로그램 특성상 환불 및 결제 정책은 제공처의 방침에 따르며 공식 홈페이지로 확인해야 합니다.

## 한국어 지원

Fluxmail은 한국어를 지원하여 한국 사용자들이 쉽게 사용할 수 있습니다.

## 한국어 품질 실측

**고객 문의 메일 검색**

- 프롬프트: 오늘 아침에 온 안 읽은 고객 문의 메일을 검색해 줘.
- 결과 예시: support@acme.com 계정에서 안 읽은 고객 메일 3건을 성공적으로 찾았습니다. 해당 메일의 요약과 함께 답장 초안을 작성할 준비가 완료되었습니다.
- 관찰: 자연어 명령로 한국어로 된 이메일 검색 요청을 정확하게 처리합니다.

**분기별 보고서 메일 필터링**

- 프롬프트: ann@example.com에게서 온 분기별 보고서 메일을 찾아줘.
- 결과 예시: Outlook 메일박스에서 해당 발신자의 'quarterly report' 관련 메시지 2건을 발견했습니다. 요청하신 조건에 맞는 메일 목록을 터미널 화면에 출력합니다.
- 관찰: 특정 발신자와 키워드를 조합한 검색 명령을 안정적으로 수행합니다.

개발자 도구 및 에이전트 연동형 서비스이므로 명령어 중심의 인터페이스를 사용합니다. 한국어 프롬프트를 입력할 때 에이전트가 문맥을 잘 이해하여 메일 검색 및 초안 작성 작업을 원활하게 수행합니다.

## 이런 분에게 추천합니다

이메일 관리가 많은 직장인, 빠른 답변이 필요한 학생, 고객 관리가 중요한 소상공인에게 추천합니다.

## 실제 활용 예시

- **직장인**: 업무 이메일이 많아 시간을 절약하고 싶을 때 Fluxmail을 사용하여 중요한 이메일을 빠르게 확인하고 답장을 작성합니다.
- **학생**: 과제나 프로젝트 관련 이메일을 관리할 때 Fluxmail을 통해 중요한 이메일을 우선적으로 확인하고 답변합니다.
- **소상공인**: 고객과의 소통을 효율적으로 관리하기 위해 Fluxmail을 사용하여 중요한 고객 이메일을 놓치지 않고 처리합니다.

## 장단점

**장점**

- Gmail, Outlook, IMAP 등 다양한 이메일 제공 업체를 하나의 통일된 API로 연동할 수 있습니다.
- 사용자가 직접 서버를 구축하는 Self-hosted 방식이라 이메일 데이터가 외부 서버에 저장되지 않습니다.
- MCP, REST API, CLI 등 다양한 인터페이스를 지원하여 개발 환경에 맞춰 유연하게 활용 가능합니다.
- Claude Code나 AI 에이전트와 연동하여 자연어로 메일을 검색하고 답장 초안을 쉽게 작성할 수 있습니다.

**단점**

- 직접 서버를 구축하고 설정해야 하므로 일반 사용자나 초보자가 접근하기에 난이도가 다소 높습니다.
- 그래픽 사용자 인터페이스(GUI)보다는 터미널 및 API 중심이라 개발 지식이 필수로 요구됩니다.
- 상세한 가격 정책이나 유료 플랜의 구체적인 혜택이 공식 문서에 명확히 명시되어 있지 않습니다.

## 주의사항

- **개인정보**: 이메일 데이터가 제작사 서버가 아닌 사용자가 직접 운영하는 인프라에 저장되므로 보안성이 높습니다. 다만 서버 보안 설정 소홀 시 데이터 유출 위험이 있으므로 주의해야 합니다.
- **저작권/상업적 이용**: 깃허브에 공개된 소스코드는 Source-available 형태로 제공됩니다. 상업적 이용 및 재배포 시 라이선스 정책을 반드시 준수해야 합니다.
- **요금/한도**: 월 5만원의 유료 플랜이나 추가 기능 이용 시 정확한 결제 금액과 API 호출 한도는 변경될 수 있으므로 공식 요금 페이지를 참고해야 합니다.
- **계정 관리**: API 키와 메일 계정 연동 정보가 유출되지 않도록 환경 변수 관리를 철저히 해야 합니다. 권한 관리 소홀 시 외부에서 메일함에 무단 접근할 수 있습니다.

## 자주 묻는 질문

**Fluxmail은 어떻게 작동하나요?**

Fluxmail은 사용자의 이메일을 분석하여 가장 중요한 이메일을 우선적으로 정리하고 답장을 자동으로 작성하는 기능을 제공합니다.

**무료 체험은 어떻게 이용하나요?**

Fluxmail의 무료 체험로 기본 기능을 사용해볼 수 있으며, 이후 필요에 따라 유료 플랜으로 전환할 수 있습니다.

**Gmail 외에 다른 이메일 서비스도 지원하나요?**

현재 Fluxmail은 Gmail에 최적화되어 있으며, 다른 이메일 서비스에 대한 지원은 제공하지 않습니다.

**Fluxmail은 어떤 메일 계정을 지원하나요?**

Gmail, Google Workspace, Outlook, Microsoft Exchange뿐만 아니라 IMAP/SMTP를 지원하는 모든 메일박스를 연결할 수 있습니다. 다양한 이메일 제공 업체를 통합된 인터페이스로 관리할 수 있다는 장점이 있습니다.

**이메일 데이터가 외부 서버에 저장되나요?**

아니오, 저장되지 않습니다. Fluxmail은 사용자의 자체 인프라에서 구동되는 Self-hosted 방식을 취하므로, 이메일이 제작사의 서버로 전송되거나 저장되지 않고 프라이버시가 안전하게 보호됩니다.

**AI 에이전트와는 어떻게 연동하나요?**

Claude Code나 Codex 등 다양한 AI 에이전트에 MCP(Model Context Protocol) 서버를 연결하여 활용할 수 있습니다. 터미널이나 에이전트 채팅창에서 자연어로 메일함 검색과 초안 작성을 지시할 수 있습니다.

**설치하고 사용하기가 초보자에게도 쉬운가요?**

초보자보다는 개발자나 IT 인프라 구축 경험이 있는 직장인에게 적합합니다. 깃허브 소스코드 다운로드와 서버 설정, API 키 발급 등의 과정을 거쳐야 하므로 약간의 기술적 지식이 필요합니다.
