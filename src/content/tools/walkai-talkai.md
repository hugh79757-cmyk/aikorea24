## 한줄 요약

walkai-talkai는 무전기를 마이크와 스피커로 활용하여 PC의 AI 코딩 에이전트와 실시간으로 음성 대화를 나누게 해주는 툴입니다. 키보드 입력 없이도 현장에서 즉각적으로 코딩 지시를 내릴 수 있어 개발자의 작업 효율을 극대화합니다.

## 핵심 기능

- **무전기 연동**: 일반 무전기로 AI와 음성으로 직접 대화할 수 있습니다.
- **음성 인식**: 사용자의 음성을 정확하게 텍스트로 변환하여 AI에게 전달합니다.
- **로저 비프**: 무전기 특유의 신호음로 명령 수신 여부를 직관적으로 알 수 있습니다.

## 사용법

**1. 무전기 하드웨어 연결**

무전기의 오디오 출력 단자를 맥(Mac)의 마이크 입력 단자에 케이블로 연결합니다. 하드웨어 설정이 완료되면 맥에서 walkai-talkai 앱을 실행하여 오디오 입력을 인식시킵니다.

**2. 작업 타겟 창 설정**

앱 내에서 코딩 에이전트가 실행 중인 창(Cursor, 터미널 등)을 타겟으로 지정합니다. 이 설정은 무전기 명령이 정확히 해당 프로그램에 입력되도록 돕는 역할을 합니다.

**3. 무전기로 명령 전달**

무전기의 PTT(Push-to-Talk) 버튼을 누른 상태에서 음성으로 명령을 내립니다. Whisper 기술이 음성을 텍스트로 변환하여 지정된 개발 툴에 자동으로 입력합니다.

**4. AI 응답 수신 확인**

AI의 답변이 로컬 API를 통해 전달되면 로저 비프음과 함께 무전기 스피커로 음성 안내가 출력됩니다. 작업을 완료하기 위한 피드백을 실시간으로 들을 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 제공되지 않습니다.
- **유료 플랜**: 얼리버드 라이선스 19.99달러(약 27,000원)로 평생 이용이 가능합니다.

비용 절약 팁: 초기 출시 할인 기간을 활용하여 정가보다 저렴하게 구매하는 것을 추천합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 공식 홈페이지에서 제공하는 무료 플랜은 확인되지 않습니다. 모든 기능은 유료 라이선스 구매로 활성화됩니다.

- **Early Bird 라이선스** (19.99달러 (약 27,000원)): 얼리버드 할인 기간 동안 제공되는 평생 이용권으로, 단일 맥 기기에서 모든 기능을 제한 없이 사용할 수 있습니다.

- **정가 라이선스** (29.99달러 (약 40,000원)): 얼리버드 기간 종료 후 적용되는 표준 가격으로, 1회 결제 시 추가 비용 없이 영구적으로 소프트웨어를 사용합니다.

**환불과 해지**: 라이선스 구매 및 환불 정책은 공식 홈페이지의 결제 페이지로 확인이 필요합니다.

## 한국어 지원

현재 한국어 음성 인식 및 음성 합성 기능은 공식적으로 지원하지 않으며, 영어 기반의 명령 수행에 최적화되어 있습니다.

## 한국어 품질 실측

**코드 오류 수정 요청**

- 프롬프트: 로그인 버튼 클릭 시 발생하는 오류를 수정해줘.
- 결과 예시: 로그인 버튼 컴포넌트의 이벤트 핸들러를 확인했습니다. 수정된 코드를 적용했습니다. 이상입니다.
- 관찰: 입력은 한국어로 가능하나, 시스템 내부 처리는 영어 기반으로 작동하여 응답 품질이 낮을 수 있습니다.

**터미널 명령 실행**

- 프롬프트: 현재 디렉토리의 파일 목록을 보여줘.
- 결과 예시: 파일 목록을 출력합니다. 현재 폴더에 5개의 파일이 있습니다. 이상입니다.
- 관찰: 간단한 명령어는 수행 가능하지만 복잡한 문맥 이해는 영어에 비해 정확도가 다소 떨어집니다.

한국어 음성 인식은 가능하지만 시스템 내부 엔진이 영어에 최적화되어 있어 한국어 명령 시 번역 오류가 발생할 수 있습니다. 복잡한 코딩 지시보다는 단순한 제어 명령에 사용하는 것을 권장합니다.

## 이런 분에게 추천합니다

키보드에서 손을 떼기 힘든 환경에서 작업하는 개발자에게 적합합니다. 현장 작업 중 코딩 수정이 필요한 엔지니어에게 유용합니다. 새로운 방식의 AI 인터페이스를 실험하고 싶은 얼리어답터에게 추천합니다.

## 실제 활용 예시

- **직장인**: 개발실에서 무전기를 들고 코드를 수정하며 키보드 조작 없이 음성만으로 AI에게 버그 수정을 요청합니다.
- **학생**: 코딩 실습 중 손을 쓰기 어려운 상황에서 무전기로 AI 튜터에게 코드 설명을 실시간으로 듣습니다.
- **소상공인**: 매장 관리 프로그램을 개발하는 소상공인이 작업대에서 이동하며 무전기로 AI에게 재고 관리 기능 수정을 지시합니다.

## 장단점

**장점**

- 키보드를 사용할 수 없는 현장 작업 환경에서도 무전기로 개발 에이전트를 제어할 수 있습니다.
- 오픈 소스 모델인 Whisper를 사용하여 오프라인 환경에서도 높은 정확도의 음성-텍스트 변환을 지원합니다.
- CoreML을 활용한 신경망 음성 합성으로 무전기 스피커로 자연스러운 응답을 즉각 청취할 수 있습니다.
- 한 번의 결제로 평생 라이선스를 획득할 수 있어 구독형 소프트웨어 대비 장기적인 비용 효율이 높습니다.

**단점**

- 맥(macOS) 환경 전용으로 출시되어 윈도우나 리눅스 사용자는 해당 도구를 활용할 수 없습니다.
- 무전기와 맥을 연결하기 위한 별도의 오디오 케이블 및 하드웨어 구성이 추가로 필요합니다.
- 한국어 공식 지원이 미비하여 영어로 명령을 내릴 때 가장 안정적인 성능을 기대할 수 있습니다.

## 주의사항

- **개인정보**: 음성 데이터가 로컬에서 처리되지만 외부 API와 통신할 경우 데이터 보안 설정을 반드시 확인해야 합니다.
- **저작권/상업적 이용**: 소프트웨어 라이선스는 개인용으로 제공되며, 기업 환경에서의 상업적 사용 여부는 라이선스 약관을 확인하십시오.
- **요금/한도**: 할인 기간이 종료되면 가격이 변동될 수 있으므로 결제 시점에 공식 홈페이지의 금액을 재확인하십시오.
- **계정 관리**: 라이선스는 단일 맥 기기에 귀속되나, 기기 변경 시 라이선스 이전이 가능하므로 구매 키를 안전하게 보관하십시오.

## 자주 묻는 질문

**어떤 무전기를 사용해야 하나요?**

Baofeng, Quansheng, Motorola 등 PTT(Push-to-talk) 기능을 지원하는 대부분의 양방향 무전기와 호환됩니다.

**macOS 버전 제한이 있나요?**

네, Apple Silicon을 탑재한 macOS 13 이상 환경에서만 정상적으로 작동합니다.

**인터넷 연결이 필수인가요?**

AI 에이전트와 통신해야 하므로 안정적인 인터넷 연결이 필수이며, 음성 처리는 로컬 CoreML을 활용합니다.

**어떤 종류의 무전기를 사용할 수 있나요?**

Baofeng, Quansheng, Motorola 등 PTT(Push-to-Talk) 기능을 지원하는 모든 일반 무전기와 호환됩니다. 오디오 출력 단자가 있는 제품이라면 문제없이 연결 가능합니다.

**인터넷 연결이 없어도 작동하나요?**

Whisper 음성 인식 모델이 로컬에서 구동되므로 기본적인 음성 변환은 가능합니다. 단, AI 에이전트가 클라우드 기반일 경우 인터넷 연결이 필요합니다.

**기존에 사용하던 코딩 에이전트와 바로 연결되나요?**

Cursor, Antigravity 등 터미널이나 창을 통해 명령을 받는 에이전트라면 API나 자동 입력을 통해 즉시 연동할 수 있습니다.

**로저 비프음은 무엇인가요?**

무전기 통신 종료 시 발생하는 신호음으로, AI가 명령을 수신하고 답변을 준비하고 있음을 사용자에게 직관적으로 알려주는 기능입니다.
