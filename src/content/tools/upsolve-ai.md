## 한줄 요약

Upsolve AI는 데이터 에이전트를 구축하고 신뢰성을 평가하는 플랫폼입니다. 사용자는 데이터 기반의 정확한 분석로 빠르게 의사결정을 할 수 있습니다.

## 핵심 기능

- **데이터 에이전트**: 정확한 데이터 분석로 신뢰할 수 있는 답변을 제공합니다.
- **사용자 맞춤형 분석**: 사용자의 요구에 맞춰 분석을 수행할 수 있습니다.
- **실시간 피드백**: 대화할수록 정확도가 향상됩니다.

## 사용법

**1. 데이터 소스 연결하기**

플랫폼의 대시보드에서 분석할 데이터베이스(Postgres 등)를 연결합니다. 테이블과 SQL 패턴을 업로드하면 AI가 데이터를 이해할 준비를 마칩니다.

**2. 비즈니스 맥락 설정하기**

슬랙, 이메일, 노션 등에서 사용하는 비즈니스 용어와 정의를 입력합니다. AI가 매출 계산법이나 환불 제외 기준 등 조직의 규칙을 학습하게 합니다.

**3. 데이터 에이전트 구축하기**

Agent Studio를 사용하여 분석 에이전트를 생성합니다. 약 30분 정도의 설정 과정을 거치면 신뢰할 수 있는 데이터 분석 에이전트가 완성됩니다.

**4. 질문하고 분석 결과 확인**

채팅창에 '지난 분기 이탈률은 얼마인가?'와 같은 질문을 입력합니다. AI는 검증된 KPI와 SQL을 바탕으로 정확한 수치와 분석 결과를 제공합니다.

## 가격 정책

- **무료 플랜**: 기본 기능을 무료로 제공하여 누구나 사용할 수 있습니다.
- **유료 플랜**: 유료 플랜은 제공되지 않습니다.

비용 절약 팁: 무료로 제공되는 기능을 잘 활용하여 데이터 분석을 진행할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 공식 홈페이지에서 'Start free'를 통해 무료 시작이 가능합니다. 구체적인 무료 플랜의 제한 사항이나 기능 범위는 공식 요금 페이지에서 확인이 필요합니다.

- **일반 유료 플랜** (공식 페이지 확인 필요): 더 많은 데이터 소스 연결 및 고급 분석 기능을 제공합니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 기업 규모에 맞춘 보안 강화 및 맞춤형 기술 지원을 제공합니다.

**환불과 해지**: 구독 해지 및 환불 정책은 결제 시점의 서비스 이용 약관을 반드시 확인해야 합니다.

## 한국어 지원

한국어로 지원되며, 사용자가 쉽게 이해할 수 있도록 인터페이스가 구성되어 있습니다.

## 한국어 품질 실측

**매출 분석 보고**

- 프롬프트: 지난달 우리 회사의 상품별 매출 순위를 알려줘.
- 결과 예시: 지난달 총매출은 5천만 원이며, '코어' 제품군이 2천만 원으로 가장 높은 매출을 기록했습니다. 이는 전월 대비 5% 성장한 수치입니다.
- 관찰: 한국어 질문를 데이터 기반의 분석 결과를 자연스러운 문장으로 답변합니다.

**이탈률 원인 파악**

- 프롬프트: 최근 3개월간 고객 이탈률이 높은 이유는 무엇이야?
- 결과 예시: 최근 3개월간 평균 이탈률은 2.1%입니다. 특히 '성장' 제품군에서 이탈이 집중되었으며, 이는 최근 가격 정책 변경과 관련이 있을 것으로 분석됩니다.
- 관찰: 비즈니스 맥락을 이해하여 전문적인 분석 결과를 한국어로 제시합니다.

한국어 입력를 원활하게 반응하며 데이터 분석 결과도 문맥에 맞게 잘 정리하여 출력합니다. 다만 복잡한 전문 용어는 영어 원문과 병기될 수 있으니 확인이 필요합니다.

- **학생**: 연구 과제하려고 필요한 데이터를 신뢰성 있게 분석할 수 있습니다.
- **소상공인**: 매출 데이터를 기반으로 비즈니스 전략을 세우는 데 도움을 받을 수 있습니다.

## 장단점

**장점**

- 데이터베이스와 비즈니스 맥락을 결합하여 신뢰할 수 있는 분석 결과를 제공합니다.
- 복잡한 SQL 작성 없이도 자연어 질문만으로 데이터 분석이 가능하여 효율적입니다.
- 대화가 진행될수록 분석의 정확도가 스스로 향상되는 학습 기능을 갖추고 있습니다.
- 데이터의 출처와 계산 방식을 추적할 수 있어 분석 결과의 투명성이 매우 높습니다.

**단점**

- 초기 설정 과정에서 데이터 소스와 비즈니스 규칙을 직접 입력하는 노력이 필요합니다.
- 매우 복잡한 데이터 구조를 가진 경우 설정에 시간이 다소 소요될 수 있습니다.
- 현재 가격 정책과 유료 플랜의 상세 내용은 공식 페이지로 직접 확인해야 합니다.

## 주의사항

- **개인정보**: 데이터베이스 연결 시 민감한 개인정보가 포함되지 않도록 사전에 비식별화 처리를 권장합니다.
- **저작권/상업적 이용**: 생성된 분석 데이터의 저작권은 사용자에게 있으나, 플랫폼 이용 약관에 따른 상업적 이용 범위를 확인하십시오.
- **요금/한도**: 무료 버전과 유료 버전의 사용 한도가 다를 수 있으므로 정기적으로 요금 페이지를 체크해야 합니다.
- **계정 관리**: 데이터 접근 권한이 포함된 계정이므로 보안하려고 다중 인증(MFA) 설정을 강력히 권장합니다.

## 자주 묻는 질문

**Upsolve AI는 어떤 기능을 제공하나요?**

Upsolve AI는 데이터 에이전트를 구축하고 신뢰성 있는 분석을 제공하는 기능을 갖추고 있습니다.

**무료로 사용할 수 있나요?**

네, Upsolve AI는 기본 기능을 무료로 제공하여 누구나 사용할 수 있습니다.

**어떻게 데이터 분석을 시작하나요?**

사용자는 플랫폼에 접속하여 필요한 데이터를 입력하고 분석을 요청하면 됩니다.

**SQL 지식이 없어도 사용할 수 있나요?**

네, 자연어 질문을 통해 분석을 수행하므로 SQL을 직접 작성하지 않아도 됩니다. 다만 초기 설정 시 데이터 구조를 이해하는 관리자의 도움이 필요할 수 있습니다.

**데이터 보안은 안전한가요?**

데이터 에이전트는 사용자가 승인한 데이터 소스 내에서만 작동하며, 보안 가이드라인에 따라 관리됩니다. 상세 보안 정책은 공식 문서에서 확인 가능합니다.

**실시간 데이터 분석이 가능한가요?**

연결된 데이터베이스의 최신 데이터를 실시간으로 반영하여 분석 결과를 제공합니다. 데이터 소스가 업데이트되면 에이전트도 즉시 반영합니다.

**분석 결과가 틀릴 수도 있나요?**

AI는 제공된 맥락과 데이터를 바탕으로 답변하므로, 입력된 비즈니스 규칙이 정확할수록 결과의 신뢰도가 높습니다. 검증된 소스를 활용하는 것을 권장합니다.
