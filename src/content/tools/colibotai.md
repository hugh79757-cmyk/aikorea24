## 한줄 요약

ColibotAI는 웹 페이지의 텍스트를 번역하고 요약하는 무료 도구입니다. 사용자는 개인 정보 보호를 보장받으며, 다양한 AI 엔진을 활용하여 텍스트를 쉽게 이해할 수 있습니다.

## 핵심 기능

- **번역**: 웹 페이지의 내용을 실시간으로 번역합니다.
- **요약**: 긴 텍스트를 짧고 간결하게 요약합니다.
- **설명**: 어려운 내용을 쉽게 설명해 줍니다.

## 사용법

**1. 확장 프로그램 설치하기**

크롬 웹스토어에서 ColibotAI를 검색하여 브라우저에 무료로 추가합니다. 설치가 완료되면 주소창 우측의 확장 프로그램 아이콘을 고정하여 쉽게 접근할 수 있습니다.

**2. 웹 페이지 텍스트 선택하기**

인터넷 서핑 중 번역이나 요약이 필요한 기사, 논문, 해외 자료 등의 텍스트를 마우스로 드래그하여 지정합니다. 텍스트를 지정하면 바로 옆에 ColibotAI 메뉴가 나타납니다.

**3. 원하는 기능 선택하기**

나타난 팝업 메뉴에서 번역, 요약, 설명 중 필요한 기능을 클릭합니다. 크롬의 자체 AI나 개인이 보유한 API 키를 활용하여 즉시 결과를 확인할 수 있습니다.

**4. 사이드 패널에서 결과 활용하기**

생성된 답변은 메모 사이드 패널에 저장하여 검색하고 주석을 달거나 내보내어 재사용할 수 있습니다. 추가 질문 기능로 문맥을 유지하며 대화를 이어갈 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료로 사용하는 크롬 확장 프로그램입니다.

비용 절약 팁: 무료로 제공되는 기능을 최대한 활용하여 비용을 절약할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: ColibotAI는 크롬 확장 프로그램으로 기본적으로 무료 제공됩니다. 온디바이스 AI를 사용하거나 본인의 API 키를 등록하여 추가 비용 없이 이용할 수 있습니다.

- **무료 기본 플랜** (0원 (무료)): 온디바이스 AI 기능과 개인 API 키 연동을 통한 무상 사용을 지원합니다. 정확한 유료 플랜 정책과 추가 기능 비용은 공식 요금 페이지에서 확인이 필요합니다.

- **후원 및 PRO 플랜** (공식 페이지 확인 필요): 개발자 지원을 위한 도네이션 및 PRO 지원 메뉴가 마련되어 있습니다. 구체적인 구독 비용과 혜택 범위는 공식 웹사이트의 PRO 안내에서 확인해야 합니다.

**환불과 해지**: 무료로 제공되는 확장 프로그램이며 별도의 유료 구독 환불 규정은 공식 요금 페이지와 후원 페이지에서 확인이 필요합니다.

- 관찰: 번역 품질은 사용하는 AI 엔진(온디바이스 또는 GPT·Claude 키)에 따라 달라질 수 있습니다.

**긴 보고서 요약하기**

- 프롬프트: 이 긴 비즈니스 보고서 내용을 읽기 쉽게 핵심 포인트 세 가지로 요약해 주세요.

2. 신규 해외 시장 진출 성공
3. 물류 비용 절감을 위한 공급망 개편 필요
- 관찰: 한국어 요약 시 문맥을 잘 파악하여 깔끔한 비즈니스 문장으로 출력해 줍니다.

한국어 지원을 충실히 제공하며 연동하는 AI 모델에 따라 자연스러운 비즈니스 한국어 결과물을 얻을 수 있습니다. 다만 온디바이스 AI의 경우 언어 설정과 브라우저 환경에 따라 번역투가 일부 섞일 수 있습니다.

## 장단점

**장점**

- 개인 정보 보호를 최우선으로 설계되어 사용자의 데이터가 외부에 저장되지 않습니다.
- 온디바이스 AI나 사용자가 보유한 OpenAI, Claude 등의 API 키를 직접 연동할 수 있습니다.
- 번역, 요약뿐만 아니라 어려운 텍스트 설명과 챗GPT 검색까지 한 번에 처리합니다.
- 토큰 절약 재사용 기능로 유사한 텍스트를 다시 조회할 때 비용을 아낄 수 있습니다.

**단점**

- 자체 유료 구독 모델 외에 사용자가 직접 유료 API 키를 발급받아 연결해야 하는 경우가 있습니다.
- 완전한 오프라인 환경이나 기기 성능에 따라 온디바이스 AI의 속도 차이가 발생할 수 있습니다.
- 크롬 브라우저 전용 확장 프로그램으로 출시되어 다른 브라우저 사용자는 이용이 제한됩니다.

## 주의사항

- **개인정보**: 데이터를 저장하지 않는 프라이버시 중심 구조이나, 외부 API 키를 입력할 때는 해당 서비스 제공사의 개인정보 처리방침을 함께 확인하는 것이 좋습니다.
- **저작권/상업적 이용**: 웹 페이지에서 번역하고 요약한 텍스트의 저작권은 원저작자에게 있으므로, 상업적 목적으로 활용할 때는 출처 표기와 저작권 침해 여부를 주의해야 합니다.
- **요금/한도**: 본인의 외부 API 키를 연동하여 사용할 경우, 과도한 텍스트 분석으로 인해 해당 AI 제공사로부터 추가 요금이 청구될 수 있으므로 사용량을 주기적으로 점검해야 합니다.
- **계정 관리**: 확장 프로그램 설정에 등록된 개인 API 키가 유출되지 않도록 브라우저 보안 설정을 철저히 관리하고 공용 PC 사용 시 주의를 기울여야 합니다.

## 자주 묻는 질문

**ColibotAI는 어떻게 설치하나요?**

크롬 웹 스토어에서 ColibotAI를 검색하여 설치하면 됩니다.

**이 툴은 무료인가요?**

ColibotAI는 무료로 제공되는 크롬 확장 프로그램입니다.

**어떤 언어를 지원하나요?**

주요 언어를 지원하며 사용자가 원하는 언어로 번역할 수 있습니다.

**ColibotAI를 사용하려면 반드시 유료 API 키가 필요한가요?**

아니오, 크롬의 자체 빌트인 온디바이스 AI를 지원하는 환경에서는 키 없이도 무료로 이용할 수 있습니다. 필요에 따라 본인의 Claude나 OpenAI API 키를 등록하여 확장된 기능을 사용할 수도 있습니다.

**제가 읽은 웹페이지의 내용이 서버에 저장되나요?**

아니오, 개인정보 보호를 최우선으로 설계되어 데이터가 저장되지 않으며 사용자의 API 키 역시 기기 외부로 유출되지 않습니다. GDPR 규정을 준수하여 안심하고 사용할 수 있습니다.

**토큰 절약 재사용 기능은 어떻게 작동하나요?**

거의 동일한 텍스트를 다시 실행할 경우, 이전에 저장된 답변을 재사용하여 새로운 AI 호출을 방지합니다. 사용자가 직접 유사도 임계값을 설정하여 불필요한 토큰 소모를 막을 수 있습니다.

**크롬 이외의 다른 인터넷 브라우저에서도 설치할 수 있나요?**

현재는 구글 크롬 브라우저 전용 크롬 확장 프로그램으로 제작되었습니다. 크롬 웹스토어를 통해서만 설치 및 이용이 가능합니다.
