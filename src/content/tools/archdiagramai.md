## 한줄 요약

ArchDiagramAI는 사용자가 입력한 영어 문장을 보고 시스템 아키텍처 다이어그램을 자동 생성합니다. 복잡한 구조를 시각적으로 쉽게 이해할 수 있도록 도와줍니다.

## 핵심 기능

- **다이어그램 생성**: 간단한 문장으로 전문적인 다이어그램을 생성합니다.
- **스타일 선택**: 다양한 시각적 스타일을 제공하여 필요에 맞게 조정할 수 있습니다.
- **이미지 업로드**: 기존 다이어그램을 업로드하여 수정할 수 있는 기능을 제공합니다.

## 사용법

**1. 회원가입 및 로그인**

공식 웹사이트에 접속하여 구글 계정 등으로 간편하게 회원가입을 진행합니다. 로그인 후 대시보드 화면에서 새로운 다이어그램 생성을 시작할 수 있습니다.

**2. 프롬프트 또는 이미지 입력**

텍스트 입력창에 원하는 시스템 구조를 영어 프롬프트로 작성합니다. 기존 스케치나 참조 이미지가 있다면 업로드하여 이미지 투 이미지 작업으로 진행할 수 있습니다.

**3. 스타일 및 비율 설정**

기술적 스타일, 미니멀, 다크 모드, 화이트보드 등 원하는 시각적 스타일을 선택합니다. 문서나 발표 자료에 맞는 화면 비율과 해상도를 지정합니다.

**4. 생성 및 다운로드**

생성 버튼을 누르면 컴포넌트와 데이터 흐름이 자동으로 정렬되며 20~60초 내에 결과가 나옵니다. 완성된 다이어그램을 고해상도 PNG 파일로 다운로드하여 활용합니다.

- **유료 플랜**: 기본 플랜 월 19달러(약 2만 5천 원)로 고해상도 다이어그램을 다운로드할 수 있습니다.

비용 절약 팁: 무료 체험을 활용하여 기능을 먼저 테스트해 보시기 바랍니다.

## 한국어 지원

ArchDiagramAI는 한국어 지원이 가능하여, 한국 사용자도 쉽게 사용할 수 있습니다.

## 한국어 품질 실측

**클라우드 구성도 생성**

- 프롬프트: Create an AWS cloud architecture diagram with an API Gateway, Lambda functions, and DynamoDB database.
- 결과 예시: API Gateway와 Lambda 함수, DynamoDB가 연결된 클라우드 인프라 구조도가 자동으로 시각화됩니다. 데이터 흐름과 컴포넌트 배치가 정돈된 기술적 스타일의 PNG 이미지로 출력됩니다.
- 관찰: 영어 프롬프트를 기반으로 작동하므로, 복잡한 시스템 구조를 영어로 명확히 작성하는 것이 중요합니다.

**마이크로서비스 지도**

- 프롬프트: Generate a microservices map showing user authentication, payment processing, and order management services.
- 결과 예시: 사용자 인증, 결제 처리, 주문 관리 서비스 간의 의존성과 관계를 보여주는 네트워크 구조도가 생성됩니다. 다크 모드나 미니멀 등 선택한 스타일에 맞춰 깔끔하게 정리된 다이어그램을 얻을 수 있습니다.
- 관찰: 입력된 프롬프트의 핵심 키워드를 정확하게 파악하여 자동으로 컴포넌트 레이아웃을 구성해 줍니다.

서비스 자체의 인터페이스와 결과물은 직관적이나 프롬프트 입력은 영어 중심입니다. 한국어 사용자라 하더라도 프롬프트는 영어로 작성하는 것이 가장 정확한 결과를 얻는 방법입니다.

- **학생**: 학교 프로젝트에서 시스템 아키텍처를 설명할 때, 간단한 문장으로 다이어그램을 만들어 발표 자료에 활용할 수 있습니다.
- **소상공인**: 자신의 비즈니스 모델을 설명하기 위해 시스템 구조를 시각적으로 정리하여 투자자에게 프레젠테이션할 수 있습니다.

## 장단점

**장점**

- 복잡한 시스템 아키텍처를 복잡한 드로잉 작업 없이 프롬프트 입력만으로 빠르게 생성할 수 있습니다.
- 기술, 미니멀, 다크, 화이트보드 등 다양한 시각적 스타일을 지원하여 용도에 맞게 선택이 가능합니다.
- 텍스트뿐만 아니라 기존 스케치나 참조 이미지 업로드를 통한 이미지 투 이미지 작업도 지원합니다.
- 선택 가능한 화면 비율과 최대 4K 해상도의 고해상도 PNG 파일로 결과물을 내보낼 수 있습니다.

**단점**

- 월 19달러의 프로 플랜 가격은 유사한 다이어그램 생성 도구들의 중간값에 비해 다소 비싼 편입니다.
- 프롬프트가 영어 기반으로 작동하여 상세한 구조 설정을 원할 때 영어 작성 능력이 필요합니다.
- 자동으로 컴포넌트를 배치해주지만 사용자가 세부적인 요소를 수동으로 편집하는 데는 한계가 있을 수 있습니다.

## 주의사항

- **개인정보**: 시스템 아키텍처 프롬프트 입력 시 회사 내부의 민감한 보안 키나 실제 개인정보, 내부 서버 IP 등이 노출되지 않도록 주의해야 합니다. 일반적인 구조 설명 위주로 프롬프트를 작성하는 것이 안전합니다.
- **저작권/상업적 이용**: 생성된 다이어그램을 상업적 문서나 블로그 포스트, 발표 자료에 활용할 수 있으나 플랫폼의 이용 약관을 준수해야 합니다. 타인의 저작물이나 상표가 포함된 이미지를 무단으로 업로드하지 않도록 주의가 필요합니다.
- **요금/한도**: Pro 및 Team 플랜은 자동 갱신(Auto-renewal) 방식으로 결제될 수 있으므로 지속해서 이용하지 않을 경우 미리 해지해야 합니다. 정확한 요금 청구 주기와 환불 정책은 공식 홈페이지에서 다시 확인해야 합니다.
- **계정 관리**: 구글 계정 등을 연동하여 로그인할 때는 계정 보안에 유의해야 합니다. 팀 플랜 이용 시 팀원 간의 권한 관리와 로그인 정보 공유에 주의를 기울여야 합니다.

## 자주 묻는 질문

**다이어그램 생성에 얼마나 시간이 걸리나요?**

간단한 프롬프트로 즉시 다이어그램이 생성되므로 빠르게 작업할 수 있습니다.

**어떤 형식으로 다이어그램을 다운로드할 수 있나요?**

고해상도 PNG 형식으로 다운로드할 수 있어 문서에 쉽게 삽입할 수 있습니다.

**다양한 스타일은 어떻게 선택하나요?**

다양한 시각적 스타일 중에서 원하는 스타일을 선택하여 다이어그램을 생성할 수 있습니다.

**ArchDiagramAI는 어떤 언어로 프롬프트를 입력해야 하나요?**

플랫폼은 일반 영어 프롬프트(plain-English prompts)를 기반으로 최적화되어 있습니다. 정확하고 완성도 높은 아키텍처를 얻으려면 영어로 작성하는 것을 권장합니다.

**기존에 손으로 그린 스케치도 다이어그램으로 바꿀 수 있나요?**

그렇습니다. 이미지 업로드 기능을 지원하므로 화이트보드 스케치나 기존 시스템 화면 캡처본을 업로드하여 표준화된 클라우드 인프라 구조도로 변환할 수 있습니다.

**생성된 다이어그램은 어떤 형식으로 저장할 수 있나요?**

고해상도 PNG 형식으로 내보낼 수 있으며, 문서나 발표 자료에 맞게 4:3, 16:9, 1:1, 세로 모드 등 다양한 화면 비율과 최대 4K 해상도를 선택할 수 있습니다.

**다이어그램이 생성되는 데 시간이 얼마나 걸리나요?**

입력된 프롬프트나 참조 이미지의 복잡도에 따라 다르지만, 일반적으로 컴포넌트와 데이터 흐름이 자동 정렬되어 20초에서 60초 사이에 결과물이 나옵니다.
