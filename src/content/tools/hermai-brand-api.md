## 한줄 요약

Hermai Brand API는 기업 고객을 위한 B2B 서비스 운영 시, 고객사의 브랜드 정보를 자동으로 가져와 서비스 화면에 적용해 주는 툴입니다. 복잡한 설정 없이 이메일 주소 하나만으로 로고와 색상 등을 추출하여 고객 맞춤형 환경을 즉시 구축할 수 있습니다.

## 핵심 기능

- **브랜드 정보 추출**: 이메일 도메인만으로 로고, 색상, 기업 설명을 즉시 가져옵니다.
- **자동 테마 적용**: 추출된 색상을 보고 대시보드 테마를 자동으로 구성합니다.
- **폼 자동 완성**: 고객 가입 시 회사 정보를 자동으로 채워 입력 번거로움을 줄입니다.

## 사용법

**1. API 연동 준비**

공식 홈페이지에서 계정을 생성하고 API 키를 발급받습니다. 서비스 백엔드 환경에서 API 호출을 처리할 수 있도록 개발 설정을 진행합니다.

**2. 이메일 정보 전송**

고객이 B2B 서비스에 업무용 이메일로 회원가입할 때 입력한 도메인 값을 추출합니다. POST 요청로 Hermai Brand API 서버로 해당 이메일 주소를 전달합니다.

**3. 브랜드 데이터 수신**

API 응답으로 고객사의 로고 이미지, 기업 설명, 그리고 대시보드에 즉시 적용할 수 있는 컬러 테마 정보를 JSON 형식으로 받습니다.

**4. UI 자동 적용**

전달받은 브랜드 색상과 로고를 웹 서비스의 대시보드나 고객 포털에 동적으로 반영합니다. 사용자가 직접 설정 페이지를 거치지 않아도 브랜드 맞춤형 환경이 구축됩니다.

## 가격 정책

- **무료 플랜**: 매월 1,000개의 브랜드 정보를 무료로 조회할 수 있습니다.
- **유료 플랜**: 유료 플랜은 사용량에 따라 책정되며, 자세한 가격은 공식 홈페이지 문의가 필요합니다.

비용 절약 팁: 초기 스타트업이라면 매월 제공되는 무료 1,000건의 쿼리를 활용해 비용 부담 없이 서비스를 테스트해 보세요.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 매월 1,000개의 브랜드 정보를 무료로 조회할 수 있습니다. 신용카드 등록 없이 무료로 시작할 수 있어 소규모 테스트나 초기 스타트업에 유용합니다.

- **사용량 기반 플랜** (공식 페이지 확인 필요): 무료 제공량을 초과하는 API 호출 건수에 따라 비용이 책정되는 구조입니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 트래픽을 처리하는 기업 고객을 위한 맞춤형 지원 플랜입니다.

**환불과 해지**: 환불 및 결제 정책에 대한 정확한 금액과 조건은 공식 요금 페이지 또는 고객 센터 문의로 확인이 필요합니다.

## 한국어 지원

서비스 인터페이스와 API 문서는 영어로 제공되지만 기술적인 구현을 위한 API 호출 방식은 직관적입니다.

## 한국어 품질 실측

**국내 기업 이메일 조회**

- 프롬프트: POST /v1/brand/retrieve 요청에 국내 업무용 이메일 주소를 입력하여 브랜드 정보를 요청합니다.
- 결과 예시: 해당 기업의 공식 로고 URL, 국문 또는 영문 기업 설명, 그리고 웹 화면에 어울리는 안전한 접근성 색상 테마 값을 반환합니다.
- 관찰: 국내 기업의 웹사이트 구조에 따라 기업 설명이나 메타 태그를 수집하는 정확도가 달라질 수 있습니다.

**대시보드 테마 적용**

- 프롬프트: 추출된 색상 코드를 B2B SaaS 대시보드의 액션 버튼 및 배경색 영역에 대입합니다.
- 결과 예시: 고객사 브랜드 고유의 색상이 대시보드 화면에 자연스럽게 녹아들어 화이트 라벨링된 맞춤형 화면을 구성합니다.
- 관찰: 색상 대비와 접근성을 고려한 팔레트가 제공되어 가독성을 유지하는 데 도움이 됩니다.

서비스 인터페이스와 API 문서는 영어로 제공되지만 반환되는 데이터는 표준화된 JSON 형식이므로 국내 개발자가 연동하는 데 큰 어려움이 없습니다. 다만, 국내 로컬 기업의 상세한 브랜드 정보를 처리할 때는 데이터 수집 범위를 사전에 테스트해 보는 것이 좋습니다.

## 이런 분에게 추천합니다

B2B SaaS를 운영하며 고객사별 맞춤형 화면을 제공하고 싶은 개발자에게 적합합니다. 가입 절차를 간소화하여 고객 경험을 개선하려는 서비스 기획자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: B2B 솔루션 개발 시 고객사 로고를 일일이 수동으로 등록할 필요가 없습니다. API를 연동하여 고객이 가입하는 즉시 서비스 화면에 해당 기업의 로고가 나타나도록 설정합니다.
- **학생**: 웹 개발 프로젝트를 진행할 때 실제 기업 데이터를 활용한 대시보드 기능을 구현해 볼 수 있습니다. API를 통해 가져온 색상 데이터를 CSS 변수로 사용하여 실감 나는 브랜드 맞춤형 페이지를 만듭니다.
- **소상공인**: 자체 쇼핑몰이나 예약 관리 솔루션을 운영하는 경우, 고객이 가입할 때 회사 정보를 자동으로 불러와 고객 관리 페이지의 완성도를 높일 수 있습니다.

## 유사 툴과 비교

**장점:**
- 이메일 기반의 매우 간편한 연동 방식
- 브랜드 에셋을 자동으로 분류하여 제공

**단점:**
- 영어 기반의 기술 지원
- 매우 특화된 기능으로 범용성은 낮음

**이런 분에게 가장 적합합니다:** B2B 서비스의 가입 온보딩 과정을 자동화하고 싶을 때 가장 효과적입니다.

## 대안 도구 비교

## 장단점

**장점**

- 고객이 직접 로고를 업로드하거나 색상을 설정하는 번거로운 과정을 완전히 없애줍니다.
- 이메일 도메인 입력 한 번으로 로고와 테마 색상을 실시간으로 가져와 자동 완성할 수 있습니다.
- 웹사이트의 메타 데이터를 기반으로 안전하고 접근성 높은 애플리케이션 테마 색상을 제안합니다.
- 매월 1,000개의 브랜드 정보를 무료로 조회할 수 있어 초기 비용 부담 없이 도입을 검토할 수 있습니다.

**단점**

- 서비스 인터페이스와 공식 문서가 영어로만 제공되어 국내 사용자에게는 다소 진입장벽이 있습니다.
- 무료 플랜의 제공량을 초과할 경우 발생하는 구체적인 요금 체계가 직관적으로 공개되어 있지 않습니다.
- 고객사가 웹사이트에 메타 데이터를 제대로 구축해 두지 않은 경우 정보 추출 결과가 제한적일 수 있습니다.

## 주의사항

- **개인정보**: 메일함의 사용자 이름은 절대 저장하지 않으며 도메인 영역만 읽어오므로 프라이버시 침해 우려를 최소화합니다.
- **저작권/상업적 이용**: 추출된 로고와 브랜드 정보는 고객사 맞춤형 화면 구성을 위해서만 활용해야 하며 무단 배포 시 법적 문제가 발생할 수 있습니다.
- **요금/한도**: 매월 제공되는 1,000건의 무료 조회 한도를 초과하면 추가 비용이 부과될 수 있으므로 사용량을 주기적으로 모니터링해야 합니다.
- **계정 관리**: 발급된 API 키가 외부로 유출되지 않도록 백엔드 환경에서 안전하게 관리하고 접근 권한을 엄격히 통제해야 합니다.

## 자주 묻는 질문

**API 연동이 많이 복잡한가요?**

개발 지식이 있다면 매우 간단하게 연동할 수 있습니다. 제공되는 API 엔드포인트에 이메일 주소만 전달하면 즉시 브랜드 정보를 응답받을 수 있습니다.

**모든 도메인의 정보를 가져올 수 있나요?**

대부분의 기업 도메인에서 데이터를 추출할 수 있지만 웹사이트가 존재하지 않거나 정보가 공개되지 않은 도메인은 데이터 추출이 어려울 수 있습니다.

**무료 플랜의 제한은 무엇인가요?**

매월 1,000건의 브랜드 데이터 조회가 가능하며 별도의 신용카드 등록 없이 즉시 시작할 수 있습니다. 사용량이 많은 경우 유료 플랜으로 전환하여 제한을 해제할 수 있습니다.

**개인용 이메일 주소로 가입한 고객도 브랜드 정보를 추출할 수 있나요?**

Gmail이나 네이버 같은 일반 개인용 도메인은 기업 브랜드 정보가 없거나 유효한 결과를 얻기 어려우므로 주로 업무용 이메일 도메인에 최적화되어 있습니다.

**고객사가 웹사이트 디자인을 바꾸면 API가 반환하는 색상도 자동으로 바뀌나요?**

네, Hermai API는 대상 웹사이트의 최신 상태를 기반으로 데이터를 가져오기 때문에 고객사가 사이트를 개편하면 다음 조회 시 변경된 테마가 반영될 수 있습니다.

**신용카드 등록 없이 무료 플랜을 바로 이용할 수 있나요?**

네, 별도의 신용카드 정보 입력 없이 가입 즉시 매월 1,000개의 브랜드 조회를 무료로 이용할 수 있습니다.

**추출된 브랜드 색상이 마음에 들지 않을 때 수정할 수 있나요?**

API가 반환한 데이터는 서비스 화면에 기본값으로 채워지는 형태이므로, 가입 완료 후 사용자가 직접 수정할 수 있도록 UI를 구성할 수 있습니다.
