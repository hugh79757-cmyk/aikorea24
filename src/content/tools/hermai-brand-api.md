## 한줄 요약

Hermai Brand API는 기업 고객을 위한 B2B 서비스 운영 시, 고객사의 브랜드 정보를 자동으로 가져와 서비스 화면에 적용해 주는 툴입니다. 복잡한 설정 없이 이메일 주소 하나만으로 로고와 색상 등을 추출하여 고객 맞춤형 환경을 즉시 구축할 수 있습니다.

## 핵심 기능

- **브랜드 정보 추출**: 이메일 도메인만으로 로고, 색상, 기업 설명을 즉시 가져옵니다.
- **자동 테마 적용**: 추출된 색상을 보고 대시보드 테마를 자동으로 구성합니다.
- **폼 자동 완성**: 고객 가입 시 회사 정보를 자동으로 채워 입력 번거로움을 줄입니다.

## 가격 정책

- **무료 플랜**: 매월 1,000개의 브랜드 정보를 무료로 조회할 수 있습니다.
- **유료 플랜**: 유료 플랜은 사용량에 따라 책정되며, 자세한 가격은 공식 홈페이지 문의가 필요합니다.

비용 절약 팁: 초기 스타트업이라면 매월 제공되는 무료 1,000건의 쿼리를 활용해 비용 부담 없이 서비스를 테스트해 보세요.

## 한국어 지원

서비스 인터페이스와 API 문서는 영어로 제공되지만 기술적인 구현을 위한 API 호출 방식은 직관적입니다.

## 이런 분에게 추천합니다

B2B SaaS를 운영하며 고객사별 맞춤형 화면을 제공하고 싶은 개발자에게 적합합니다. 가입 절차를 간소화하여 고객 경험을 개선하려는 서비스 기획자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: B2B 솔루션 개발 시 고객사 로고를 일일이 수동으로 등록할 필요가 없습니다. API를 연동하여 고객이 가입하는 즉시 서비스 화면에 해당 기업의 로고가 나타나도록 설정합니다.
- **학생**: 웹 개발 프로젝트를 진행할 때 실제 기업 데이터를 활용한 대시보드 기능을 구현해 볼 수 있습니다. API를 통해 가져온 색상 데이터를 CSS 변수로 사용하여 실감 나는 브랜드 맞춤형 페이지를 만듭니다.
- **소상공인**: 자체 쇼핑몰이나 예약 관리 솔루션을 운영하는 경우, 고객이 가입할 때 회사 정보를 자동으로 불러와 고객 관리 페이지의 완성도를 높일 수 있습니다.

## 유사 툴과 비교

**장점:**
- 이메일 기반의 매우 간편한 연동 방식
- 브랜드 에셋을 자동으로 분류하여 제공

**단점:**
- 영어 기반의 기술 지원
- 매우 특화된 기능으로 범용성은 낮음

**이런 분에게 가장 적합합니다:** B2B 서비스의 가입 온보딩 과정을 자동화하고 싶을 때 가장 효과적입니다.

## 자주 묻는 질문

**API 연동이 많이 복잡한가요?**

개발 지식이 있다면 매우 간단하게 연동할 수 있습니다. 제공되는 API 엔드포인트에 이메일 주소만 전달하면 즉시 브랜드 정보를 응답받을 수 있습니다.

**모든 도메인의 정보를 가져올 수 있나요?**

대부분의 기업 도메인에서 데이터를 추출할 수 있지만 웹사이트가 존재하지 않거나 정보가 공개되지 않은 도메인은 데이터 추출이 어려울 수 있습니다.

**무료 플랜의 제한은 무엇인가요?**

매월 1,000건의 브랜드 데이터 조회가 가능하며 별도의 신용카드 등록 없이 즉시 시작할 수 있습니다. 사용량이 많은 경우 유료 플랜으로 전환하여 제한을 해제할 수 있습니다.
