## 한줄 요약

Controller AI는 AI가 마음대로 행동하지 않고 사용자가 설정한 엄격한 규칙과 프로세스 내에서만 일하도록 돕는 도구입니다. 복잡한 비즈니스 로직을 노코드로 구현하여 업무 효율성을 높이고 실수를 방지합니다.

## 핵심 기능

- **노코드 워크플로우**: 코딩 없이 드래그 앤 드롭으로 업무 절차를 시각적으로 설계할 수 있습니다.
- **승인 프로세스**: AI가 최종 작업을 하기 전 사용자의 확인을 거치게 하여 사고를 예방합니다.
- **투명한 가시성**: AI가 왜 그런 결정을 내렸는지 과정을 기록하여 업무의 신뢰성을 높입니다.

## 사용법

**1. 에이전트 및 연동 설정**

컨트롤러 AI 대시보드에 접속하여 팀에서 사용하는 앱을 연결하고 에이전트가 수행할 기본 작업 범위를 지정합니다. 복잡한 코딩 없이 클릭 몇 번으로 필요한 앱 기능들을 에이전트에게 할당할 수 있습니다.

**2. 노코드 워크플로우 설계**

시각적 노드 기반 빌더를 사용하여 다단계 업무 프로세스를 블록 쌓듯 드래그 앤 드롭으로 연결합니다. 입력값과 출력값의 데이터 구조를 명확히 정의하여 AI가 규칙에서 벗어나지 않도록 설정합니다.

**3. 승인 규칙 및 경계 설정**

에이전트가 스스로 처리할 안전한 작업과 사람이 직접 검토하고 승인해야 하는 중요한 작업을 구분합니다. 예산 집행이나 외부 발송 등 민감한 단계에는 반드시 담당자 승인을 거치도록 설정합니다.

**4. 실행 내역 검토 및 디버깅**

업무 실행 기록과 에이전트의 의사결정 과정을 단계별로 상세히 확인하며 오류를 추적합니다. 개발 환경과 라이브 환경을 분리하여 안전하게 테스트를 마친 뒤 실제 업무 프로세스에 적용합니다.

## 가격 정책

- **무료 플랜**: 현재 무료 체험 또는 초기 이용 플랜을 제공하며 상세 내용은 웹사이트에서 확인 가능합니다.
- **유료 플랜**: 유료 플랜은 기능별로 구분되며, 구체적인 가격은 기업 규모와 사용량에 따라 맞춤형으로 책정됩니다.

비용 절약 팁: 초기에는 간단한 반복 업무부터 자동화하여 생산성 향상 효과를 검증한 후 유료 전환을 고려하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 제공되는 무료 체험 또는 초기 플랜의 구체적인 메시지 수나 크레딧 한도는 크롤링된 텍스트에 명시되어 있지 않습니다. 정확한 무료 이용 범위는 공식 웹사이트의 요금 페이지를 직접 확인해야 합니다.

- **사용량 기반 표준 플랜** (공식 페이지 확인 필요 (사용량에 따라 변동)): 팀에서 사용하는 앱 연동, 노코드 워크플로우 빌더, 실행 이력 및 디버깅 도구를 제공합니다.

- **기업용 맞춤형 플랜** (공식 페이지 확인 필요 (맞춤 견적)): 대규모 업무 자동화를 위한 고급 권한 관리와 안정적인 운영 환경, 개발 및 라이브 환경 분리 기능을 지원합니다.

**환불과 해지**: 환불, 구독 해지, 결제 수단 변경 등 정책에 대한 구체적인 내용은 공식 요금 페이지와 약관로 별도로 확인이 필요합니다.

## 한국어 지원

현재 인터페이스는 영어로만 제공되지만 AI 에이전트에게 한국어 처리 규칙을 설정하면 한국어 업무 수행도 가능합니다.

## 한국어 품질 실측

**고객 문의 분류**

- 프롬프트: 입력되는 고객 이메일을 분석하여 카테고리를 분류하고 담당 부서에 전달하는 규칙을 만들어 줘.
- 결과 예시: 이메일 내용이 '결제 오류'로 분류되어 재무팀 담당자에게 승인 요청 티켓이 생성되는 워크플로우가 실행됩니다. 모든 결정 과정과 입력 데이터가 로그에 투명하게 기록됩니다.
- 관찰: 인터페이스는 영어이나 설정하는 프롬프트와 규칙에 따라 한국어 처리 결과를 안정적으로 유도할 수 있습니다.

**보고서 데이터 정리**

- 프롬프트: 첨부된 주간 실적 데이터를 정해진 양식의 구조화된 데이터로 변환하여 슬랙에 요약해 줘.
- 결과 예시: 주간 데이터가 정해진 변환 단계를 거쳐 구조화된 결과로 반환되며, 중요한 수치는 사람이 최종 확인하는 승인 단계를 거친 뒤 슬랙으로 전송됩니다.
- 관찰: 복잡한 다단계 프로세스에서도 한국어 데이터의 입출력 구조를 명확히 정의하면 오류 없이 작동합니다.

컨트롤러 AI는 기본 인터페이스가 영어로 제공되지만 에이전트에게 내리는 지시어나 데이터 규칙을 한국어로 설정하면 국내 업무 환경에서도 충분히 활용할 수 있습니다. 전문적인 비즈니스 로직을 다룰 때 번역투나 띄어쓰기보다는 명확한 구조화 지침이 중요합니다.

## 이런 분에게 추천합니다

반복적인 업무로 인해 시간이 부족한 직장인에게 추천합니다. 정교한 프로세스 관리가 필요한 소상공인에게 유용합니다. AI 도입을 고민하는 팀장급 관리자에게 적합합니다.

## 실제 활용 예시

- **직장인**: 매일 반복되는 이메일 분류와 데이터 입력 업무를 자동화하여 퇴근 시간을 앞당길 수 있습니다. AI가 처리한 결과를 승인만 하면 되므로 업무 실수를 크게 줄입니다.
- **학생**: 여러 논문 사이트에서 자료를 검색하고 요약하여 노션에 정리하는 과정을 자동화할 수 있습니다. 리서치 시간을 획기적으로 단축하여 학업 효율을 높입니다.
- **소상공인**: 고객의 주문 정보를 엑셀에 정리하고 배송 알림을 보내는 과정을 자동화하여 운영 업무를 최소화합니다. 일일이 수동으로 처리하던 고객 응대 업무를 대폭 간소화할 수 있습니다.

## 장단점

**장점**

- AI 에이전트가 임의로 행동하지 않고 사용자가 설정한 엄격한 규칙과 프로세스 안에서만 작동하여 예측 가능성이 매우 높습니다.
- 코딩 지식이 전혀 없는 실무자도 드래그 앤 드롭 방식의 시각적 노드 빌더로 복잡한 다단계 업무 자동화를 쉽게 설계할 수 있습니다.
- 중요한 작업이 실행되기 전 담당자의 승인을 거치게 설정할 수 있어 예기치 않은 AI 실수를 사전에 방지하고 사고를 예방합니다.
- 에이전트의 모든 의사결정, 도구 호출, 오류 발생 및 비용 내역이 투명하게 기록되어 업무의 신뢰성과 추적 가능성을 크게 높여줍니다.

**단점**

- 기본적인 플랫폼 인터페이스와 설정 메뉴가 영어로만 제공되기 때문에 국내 일반 사용자가 처음 접할 때 언어적 장벽이 다소 존재합니다.
- 구체적인 요금제 금액과 사용량 제한 정책이 웹사이트에 명시적으로 공개되어 있지 않아 비용 산정을 미리 확인하기 어렵습니다.
- 단순한 챗봇 형태를 넘어 세부적인 워크플로우와 입력값 구조를 직접 설계해야 하므로 초기 세팅과 학습에 일정 시간이 소요됩니다.

## 주의사항

- **개인정보**: 에이전트가 외부 앱과 연동되어 데이터를 처리할 때 고객의 민감한 개인정보나 기밀 데이터가 포함되지 않도록 접근 권한을 안전하게 설정해야 합니다.
- **저작권/상업적 이용**: 자동화된 워크플로우로 생성되거나 변환된 콘텐츠와 데이터의 상업적 활용 시 발생할 수 있는 저작권 및 라이선스 규정을 준수해야 합니다.
- **요금/한도**: 사용량 기반으로 과금될 수 있으므로 에이전트가 반복 실행되거나 무한 루프에 빠져 예상치 못한 비용이 청구되지 않도록 사용량을 모니터링해야 합니다.
- **계정 관리**: 여러 팀원이 연결된 통합 계정과 에이전트 설정 권한을 안전하게 관리하고 중요 작업 승인 권한은 신뢰할 수 있는 관리자에게만 부여해야 합니다.

## 자주 묻는 질문

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 노코드 방식으로 설계되었기 때문에 프로그래밍 지식 없이도 워크플로우를 구성할 수 있습니다. 다만 업무 프로세스를 논리적으로 정의하는 연습은 필요합니다.

**기존에 쓰던 앱과 연동이 가능한가요?**

네, 다양한 외부 서비스와 연동할 수 있는 액션을 제공합니다. 사용 중인 업무 툴이 지원되는지 대시보드에서 바로 확인할 수 있습니다.

**AI가 실수하면 어떻게 하나요?**

승인 기능을 활용하여 AI가 작업을 완료하기 전 사용자가 직접 검토할 수 있습니다. 또한 모든 로그를 확인할 수 있어 문제 발생 시 즉각적인 대응이 가능합니다.

**컨트롤러 AI는 일반적인 생성형 AI 챗봇과 어떤 점이 다른가요?**

일반 챗봇은 프롬프트에 따라 자유롭게 답변하지만, 컨트롤러 AI는 사용자가 설계한 엄격한 규칙과 노코드 워크플로우 안에서만 행동합니다. 정해진 프로세스를 벗어나지 않도록 제어하고 사람이 직접 승인하는 단계를 추가할 수 있어 업무용으로 훨씬 안전합니다.

**코딩을 전혀 모르는 직장인도 워크플로우를 만들 수 있나요?**

네, 그렇습니다. 시각적 노드 기반의 드래그 앤 드롭 빌더를 제공하므로 코딩 지식이 없어도 블록을 연결하듯이 업무 절차를 시각적으로 설계할 수 있습니다. 다만 정교한 데이터 구조를 짜기 위해 약간의 업무 프로세스 이해도는 필요합니다.

**AI가 잘못된 행동을 하거나 실수를 하면 어떻게 막을 수 있나요?**

에이전트가 위험한 작업을 실행하기 전에 담당자의 확인과 승인을 거치도록 '승인 프로세스'를 설정할 수 있습니다. 또한 모든 실행 과정과 오류 내역이 투명하게 기록되므로 문제가 발생했을 때 원인을 쉽게 추적하고 수정할 수 있습니다.

**한국어 업무 처리도 원활하게 지원되나요?**

인터페이스 자체는 영어로 제공되지만, 에이전트에게 입력하는 지시어나 프롬프트, 데이터 처리 규칙을 한국어로 설정하면 국내 업무도 문제없이 수행합니다. 팀에서 사용하는 한국어 문서나 이메일 양식에 맞추어 규칙을 정교하게 다듬는 것이 좋습니다.
