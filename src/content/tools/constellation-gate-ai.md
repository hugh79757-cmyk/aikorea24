## 한줄 요약

Constellation Gate AI는 AI 모델과 사용자 간의 안전한 연결을 제공하여 보안 위협을 차단합니다. 이로 사용자들은 비용을 절감하고 효율적으로 작업할 수 있습니다.

## 핵심 기능

- **보안 차단**: 위험한 요청을 차단하여 안전성을 높입니다.
- **비용 절감**: 자동으로 토큰 사용량을 줄여줍니다.
- **간편 설정**: 몇 분 안에 설정이 완료됩니다.

## 사용법

**1. 서비스 연동하기**

공식 웹사이트에 접속하여 팀에서 이미 사용 중인 기존 AI 도구와 구독을 유지한 채 안전하게 연결합니다. 코드 작성 없이 손쉽게 데스크톱 툴을 게이트에 포인트하여 세팅할 수 있습니다.

**2. 보안 방어 설정**

프롬프트 인젝션 방어와 개인정보(PII) 마스킹 기능을 활성화하여 위험한 요청을 원천 차단합니다. AI 모델이 응답을 내보내기 전에 민감한 정보가 포함되어 있는지 실시간으로 검사합니다.

**3. 토큰 절감 확인**

대시보드에서 각 요청마다 자동으로 토큰 사용량이 최적화되는 과정을 모니터링합니다. 평균적으로 20퍼센트 이상 토큰 비용이 절감되는 지표를 직접 확인할 수 있습니다.

**4. 감사 추적 모니터링**

모든 메시지와 API 요청에 대한 검증된 기록을 보고 레이턴시와 비용 데이터를 상세히 조회합니다. 에이전트와 모델 사이의 모든 통신 내역을 투명하게 감사할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜이 제공되어 부담 없이 시작할 수 있습니다.
- **유료 플랜**: 프리미엄 플랜 29,000원으로 더 많은 기능을 이용할 수 있습니다.

비용 절약 팁: 무료 플랜으로 충분히 테스트한 후 유료 플랜을 고려하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 공개 벤치마크 및 기본 보안 기능을 활용하는 옵션이 제공되며, 정확한 무료 사용 한도는 공식 요금 페이지에서 확인이 필요합니다. 별도의 코드 수정 없이 기존 구독을 연동하여 테스트할 수 있습니다.

- **Standard 플랜** (공식 페이지 확인 필요 (월 29,000원 상당 기능 포함 가능)): 프롬프트 인젝션 방어와 토큰 절감 기능을 대규모로 활용할 수 있도록 지원합니다.

- **Enterprise 플랜** (공식 요금 페이지에서 확인 필요): 기업 고객을 위한 고급 감사 추적 및 맞춤형 보안 옵션을 제공합니다.

**환불과 해지**: 환불 및 구독 해지 정책에 대한 구체적인 내용은 공식 결제 페이지에서 직접 확인해야 합니다.

## 한국어 품질 실측

**영어 이메일 보안 검사**

- 프롬프트: 상사에게 보낼 영어 이메일에 포함된 내부 기밀번호와 개인정보를 안전하게 마스킹해 줘.
- 결과 예시: 게이트가 전송 과정에서 민감한 정보를 감지하여 자동으로 마스킹 처리한 뒤 모델로 전달합니다. 안전하게 검증된 영어 이메일 초안이 프롬프트 인젝션 없이 정상적으로 반환됩니다.
- 관찰: 보안 및 마스킹 관련 용어가 직관적으로 번역되어 한국어 사용자가 이해하기 쉽습니다.

**API 요청 텍스트 스캔**

- 프롬프트: 고객의 주민등록번호와 API 키가 포함된 텍스트를 입력했을 때 차단되는지 확인해 줘.
- 결과 예시: 시스템이 실시간으로 PII 및 비밀 유출 위험을 감지하여 모델이 응답을 반환하기 전에 차단합니다. 위협이 제거된 상태의 안전한 감사 로그가 대시보드에 기록됩니다.
- 관찰: 보안 검사 결과와 지표가 명확하게 표시되어 실무에서 활용하기 편리합니다.

한국어 인터페이스와 안내 문구가 매끄럽게 제공되어 초보자도 쉽게 적응할 수 있습니다. 전문적인 보안 용어도 직관적인 설명과 함께 노출되어 실무 활용도가 높습니다.

## 자주 묻는 질문

**이 툴은 어떻게 작동하나요?**

AI 모델과 사용자 간의 요청을 중간에서 차단하여 보안을 강화합니다.

**무료 플랜과 유료 플랜의 차이는 무엇인가요?**

무료 플랜은 기본 기능만 제공되며, 유료 플랜에서는 추가적인 기능을 이용할 수 있습니다.

**어떤 AI 모델과 호환되나요?**

OpenAI, Anthropic 등 다양한 AI 모델과 호환됩니다.

**기존에 쓰던 AI 구독이나 툴을 바꿔야 하나요?**

아닙니다. 팀에서 이미 사용 중인 AI 툴과 구독을 전혀 바꿀 필요 없이 그 사이에 게이트를 연결하여 그대로 사용할 수 있습니다.

**토큰 비용을 정말 20퍼센트 이상 줄일 수 있나요?**

그렇습니다. 게이트는 모든 요청에서 불필요한 토큰 사용량을 자동으로 줄여주어 평균적으로 20퍼센트 이상의 비용 절감 효과를 제공합니다.

**프롬프트 인젝션 공격을 어떻게 막아내나요?**

들어오는 모든 요청과 나가는 응답을 실시간으로 스캔하여 악의적인 공격자 텍스트가 모델에 도달하기 전에 사전에 차단합니다.

**코드 작성 없이 설정할 수 있나요?**

네, 복잡한 개발 지식이나 코드 작성 없이 데스크톱 툴을 게이트에 연동하는 방식으로 몇 분 안에 손쉽게 세팅할 수 있습니다.
