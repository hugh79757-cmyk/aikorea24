## 한줄 요약

Ticket Fairy CLI는 이벤트 기획자가 웹 대시보드에서 일일이 클릭하던 반복 작업을 명령어 한 줄로 처리하게 돕습니다. 행사 설정부터 데이터 추출까지 자동화하여 업무 효율을 높여줍니다.

## 핵심 기능

- **명령어 자동화**: 터미널에서 명령어를 입력해 행사 정보를 즉시 조회하고 관리합니다.
- **데이터 추출**: 티켓 판매 현황과 고객 리스트를 빠르게 파일로 내려받을 수 있습니다.
- **워크플로우 연동**: 예약된 작업이나 AI 어시스턴트와 연동하여 업무를 자동화합니다.

## 사용법

**1. Node.js 환경 구축**

컴퓨터에 Node.js가 설치되어 있지 않다면 공식 웹사이트에서 최신 버전을 내려받아 설치합니다. 터미널 창을 열어 정상적으로 설치되었는지 확인합니다.

**2. CLI 도구 설치**

터미널 창에 'npm install' 관련 명령어를 입력하여 Ticket Fairy CLI 패키지를 시스템에 내려받고 설치합니다. 정상적으로 완료되면 명령어 사용 준비가 끝납니다.

**3. 이벤트 설정 관리**

터미널 명령어로 웹 대시보드에 접속하지 않고도 행사 정보를 조회하거나 수정합니다. 반복되는 행사 세팅 작업을 명령어 한 줄로 빠르게 처리할 수 있습니다.

**4. 데이터 추출 및 보고**

티켓 판매 현황과 고객 리스트 등의 데이터를 터미널에서 즉시 파일로 내려받습니다. 수동으로 클릭하며 확인하던 리포팅 업무 시간을 대폭 단축합니다.

## 가격 정책

- **무료 플랜**: Ticket Fairy 계정이 있다면 별도의 추가 비용 없이 무료로 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 없으며, Ticket Fairy 서비스 이용료(수수료 기반)에 포함되어 있습니다.

비용 절약 팁: Node.js 환경이 필수이므로 최신 버전을 설치하여 호환성 문제를 미리 방지하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: Ticket Fairy 계정이 있다면 별도의 추가 비용 없이 기본 기능을 무료로 사용할 수 있습니다. 정확한 사용 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **기본 수수료 모델** (공식 페이지 확인 필요): 별도의 유료 플랜은 없으며 Ticket Fairy 서비스 이용료 및 수수료 기반에 포함되어 운영됩니다.

- **엔터프라이즈** (공식 페이지 확인 필요): 대규모 행사를 위한 맞춤형 기능 및 지원 제공 여부는 공식 요금 페이지로 확인해야 합니다.

**환불과 해지**: 서비스 이용료 및 환불 정책은 Ticket Fairy 플랫폼의 전체 이용약관 및 정책을 따릅니다.

## 한국어 지원

한국어 지원은 제공하지 않으며, 모든 명령어와 문서가 영어로 작성되어 있습니다.

## 한국어 품질 실측

**행사 판매 현황 조회**

- 프롬프트: Get ticket sales report for the upcoming event.
- 결과 예시: Connecting to Ticket Fairy... Total tickets sold: 150. Revenue: $4,500. Export completed to sales_report.csv.
- 관찰: 모든 명령어와 결과가 영어로 출력되므로 개발자용 터미널 환경에 대한 이해가 필요합니다.

**고객 리스트 추출**

- 프롬프트: Export guest list to local storage.
- 결과 예시: Fetching guest list... 150 records found. File saved successfully as guest_list.csv in the current directory.
- 관찰: 한국어 입력이나 출력을 지원하지 않아 국내 실무자가 사용하기에는 진입장벽이 존재합니다.

한국어 지원을 전혀 제공하지 않으며 모든 명령어와 안내 문구가 영어로만 출력됩니다. 개발자 중심의 도구이므로 텍스트 기반 인터페이스에 익숙해야 원활한 활용이 가능합니다.

## 이런 분에게 추천합니다

반복적인 이벤트 관리 업무를 자동화하고 싶은 기획자, 터미널 환경에 익숙한 개발자, 대규모 행사 데이터를 효율적으로 처리해야 하는 운영자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 아침 수동으로 확인하던 티켓 판매 현황을 스크립트로 작성해 자동으로 보고서를 생성합니다.
- **학생**: 대학 축제 티켓 관리 시스템을 구축할 때 터미널 명령어로 손쉽게 행사 정보를 업데이트합니다.
- **소상공인**: 소규모 공연을 자주 기획하는 경우, 행사마다 반복되는 설정 작업을 명령어로 저장해 시간을 절약합니다.

## 유사 툴과 비교

**장점:**
- 웹 대시보드보다 훨씬 빠른 데이터 처리 속도
- 반복 작업의 스크립트화 가능

**단점:**
- 터미널 환경에 익숙하지 않으면 사용이 어려움
- 한국어 지원 부재

**이런 분에게 가장 적합합니다:** 반복적인 이벤트 관리 업무를 자동화하여 운영 시간을 단축하고 싶은 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 웹 대시보드에 일일이 접속하지 않고도 터미널에서 행사 설정을 빠르게 처리할 수 있습니다.
- 반복적인 티켓 판매 데이터 추출과 리포팅 업무를 명령어 한 줄로 자동화합니다.
- Node.js 환경로 개발자 친화적인 워크플로우와 원활하게 연동됩니다.
- 행사 기획과 관리 과정에서 발생하는 불필요한 수동 클릭 시간을 획기적으로 줄여줍니다.

**단점**

- 한국어를 전혀 지원하지 않으며 모든 명령어와 문서가 영어로 작성되어 있습니다.
- 터미널 환경과 명령어 사용법에 익숙하지 않은 일반 기획자에게는 진입장벽이 매우 높습니다.
- Node.js 환경이 반드시 구축되어 있어야 하므로 사전 호환성 점검이 필요합니다.

## 주의사항

- **개인정보**: 티켓 구매자 및 게스트 리스트를 로컬 환경으로 내려받을 때 보안 관리에 각별히 유의해야 합니다. 추출된 파일이 외부에 유출되지 않도록 안전한 저장소에 보관해야 합니다.
- **저작권/상업적 이용**: Ticket Fairy 플랫폼의 공식 API 및 CLI 도구 이용약관을 준수하여 상업적 행사를 운영해야 합니다. 무단으로 데이터를 수집하거나 가공하는 행위는 제한될 수 있습니다.
- **요금/한도**: 별도의 유료 플랜은 없으나 플랫폼 수수료 정책에 변동이 있을 수 있으므로 주기적으로 확인해야 합니다. 정확한 비용 구조는 공식 요금 페이지에서 직접 검토해야 합니다.
- **계정 관리**: CLI 도구 구동하려고 연동하는 Ticket Fairy 계정의 인증 정보가 노출되지 않도록 관리해야 합니다. 터미널 환경에서 토큰이나 비밀번호가 기록되지 않도록 주의가 필요합니다.

## 자주 묻는 질문

**설치하려고 어떤 환경이 필요한가요?**

Node.js 20 버전 이상이 설치되어 있어야 합니다. 터미널에서 npm 명령어를 사용하는 환경이라면 어디서든 설치가 가능합니다.

**이 툴을 사용하면 웹 대시보드를 안 봐도 되나요?**

대부분의 일상적인 관리 업무는 CLI로 가능하지만 복잡한 설정이나 시각적인 분석이 필요한 경우 웹 대시보드와 병행하는 것이 좋습니다.

**보안상 안전한가요?**

기존 Ticket Fairy 계정으로 로그인하여 인증을 거치므로 안전합니다. 개인 계정 정보가 유출되지 않도록 API 키 관리 등에 유의하십시오.

**일반 행사 기획자도 쉽게 사용할 수 있나요?**

이 도구는 터미널 명령어 환경에 익숙한 개발자를 타겟으로 하므로, 코딩이나 CLI 경험이 없는 기획자에게는 다소 어려울 수 있습니다. 웹 대시보드를 이용하는 것이 더 편리할 수 있습니다.

**설치할 때 반드시 필요한 프로그램이 있나요?**

네, Node.js 환경이 필수적으로 요구됩니다. 최신 버전을 미리 설치해야 호환성 문제를 방지하고 원활하게 패키지를 내려받을 수 있습니다.

**한국어 명령어는 지원하지 않나요?**

한국어 지원은 제공되지 않으며 모든 명령어와 가이드, 결과 메시지가 영어로 출력됩니다. 영어 환경에서 작업하는 능력이 필요합니다.

**별도의 유료 구독 비용이 따로 청구되나요?**

Ticket Fairy 계정이 있다면 도구 자체는 추가 비용 없이 사용할 수 있습니다. 다만 플랫폼 이용에 따른 수수료 정책은 공식 페이지에서 확인해야 합니다.
