## 한줄 요약

Ticket Fairy CLI는 이벤트 기획자가 웹 대시보드에서 일일이 클릭하던 반복 작업을 명령어 한 줄로 처리하게 돕습니다. 행사 설정부터 데이터 추출까지 자동화하여 업무 효율을 높여줍니다.

## 핵심 기능

- **명령어 자동화**: 터미널에서 명령어를 입력해 행사 정보를 즉시 조회하고 관리합니다.
- **데이터 추출**: 티켓 판매 현황과 고객 리스트를 빠르게 파일로 내려받을 수 있습니다.
- **워크플로우 연동**: 예약된 작업이나 AI 어시스턴트와 연동하여 업무를 자동화합니다.

## 가격 정책

- **무료 플랜**: Ticket Fairy 계정이 있다면 별도의 추가 비용 없이 무료로 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜은 없으며, Ticket Fairy 서비스 이용료(수수료 기반)에 포함되어 있습니다.

비용 절약 팁: Node.js 환경이 필수이므로 최신 버전을 설치하여 호환성 문제를 미리 방지하십시오.

## 한국어 지원

한국어 지원은 제공하지 않으며, 모든 명령어와 문서가 영어로 작성되어 있습니다.

## 이런 분에게 추천합니다

반복적인 이벤트 관리 업무를 자동화하고 싶은 기획자, 터미널 환경에 익숙한 개발자, 대규모 행사 데이터를 효율적으로 처리해야 하는 운영자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 아침 수동으로 확인하던 티켓 판매 현황을 스크립트로 작성해 자동으로 보고서를 생성합니다.
- **학생**: 대학 축제 티켓 관리 시스템을 구축할 때 터미널 명령어로 손쉽게 행사 정보를 업데이트합니다.
- **소상공인**: 소규모 공연을 자주 기획하는 경우, 행사마다 반복되는 설정 작업을 명령어로 저장해 시간을 절약합니다.

## 유사 툴과 비교

**장점:**
- 웹 대시보드보다 훨씬 빠른 데이터 처리 속도
- 반복 작업의 스크립트화 가능

**단점:**
- 터미널 환경에 익숙하지 않으면 사용이 어려움
- 한국어 지원 부재

**이런 분에게 가장 적합합니다:** 반복적인 이벤트 관리 업무를 자동화하여 운영 시간을 단축하고 싶은 사용자에게 가장 적합합니다.

## 자주 묻는 질문

**설치하려고 어떤 환경이 필요한가요?**

Node.js 20 버전 이상이 설치되어 있어야 합니다. 터미널에서 npm 명령어를 사용하는 환경이라면 어디서든 설치가 가능합니다.

**이 툴을 사용하면 웹 대시보드를 안 봐도 되나요?**

대부분의 일상적인 관리 업무는 CLI로 가능하지만 복잡한 설정이나 시각적인 분석이 필요한 경우 웹 대시보드와 병행하는 것이 좋습니다.

**보안상 안전한가요?**

기존 Ticket Fairy 계정으로 로그인하여 인증을 거치므로 안전합니다. 개인 계정 정보가 유출되지 않도록 API 키 관리 등에 유의하십시오.
