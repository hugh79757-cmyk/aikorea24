## 한줄 요약

Off Grid AI는 클라우드 서버를 거치지 않고 사용자의 기기에서 직접 작동하는 AI입니다. 민감한 업무 자료나 개인적인 메모를 외부 유출 걱정 없이 안전하게 관리하고 활용하는 데 도움이 되습니다.

## 핵심 기능

- **로컬 데이터 처리**: 데이터가 외부로 나가지 않아 보안이 매우 철저합니다.
- **멀티 플랫폼 지원**: 윈도우, 맥, 안드로이드 등 어디서든 동일한 환경을 제공합니다.
- **기기 내 기억 기능**: 사용자의 이전 대화 맥락을 기억하여 맞춤형 답변을 제공합니다.

## 사용법

**1. 공식 홈페이지에서 설치 파일 다운로드**

Off Grid AI 홈페이지에 접속하여 사용 중인 운영체제(Windows, macOS 등)에 맞는 설치 파일을 내려받습니다. 설치가 완료되면 프로그램을 실행하여 초기 설정을 진행합니다.

**2. AI에게 데이터 접근 권한 허용**

AI가 내 기기의 파일, 화면, 회의 내용을 분석할 수 있도록 필요한 권한을 설정 메뉴에서 승인합니다. 모든 데이터는 외부 서버가 아닌 내 기기 내에서만 처리되므로 안심하고 허용해도 됩니다.

**3. 질문이나 작업 명령 입력**

메인 화면의 입력창에 '회의 내용 요약해줘' 또는 '지난주에 작성한 기획서 찾아줘'와 같이 자연스럽게 질문을 입력합니다. AI가 내 컴퓨터에 저장된 자료를 바탕으로 즉시 답변을 생성합니다.

**4. 결과 확인 및 작업 수행**

AI가 제시한 결과물 중 원하는 정보를 확인하고 필요시 '이메일로 보내줘'와 같은 추가 명령을 내립니다. 모든 작업은 사용자의 승인 후에만 외부로 전달되므로 보안이 철저하게 유지됩니다.

## 가격 정책

- **무료 플랜**: 현재 구체적인 무료 플랜 정보는 제공되지 않으며, 주로 유료 라이선스 형태로 운영됩니다.
- **유료 플랜**: Off Grid AI Pro, 약 11만 원(79.99달러)의 일회성 결제로 평생 이용 가능하며 모든 기능을 제한 없이 사용합니다.

비용 절약 팁: 출시 기념 할인 기간을 활용하여 평생 이용권을 구매하면 구독료 부담을 크게 줄일 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 현재 무료 플랜에 대한 구체적인 기능 제한 정보는 공식 홈페이지에 명시되어 있지 않습니다. 다만, 체험판 성격으로 제공될 가능성이 있으므로 설치 후 앱 내에서 확인이 필요합니다.

**환불과 해지**: 결제는 공식 홈페이지로 진행되며, 환불 정책이나 구독 해지 관련 사항은 구매 시점에 제공되는 약관을 반드시 확인해야 합니다.

## 한국어 지원

한국어 입출력을 지원하며 사용자가 작성한 한국어 문맥을 이해하고 자연스럽게 답변하는 수준입니다.

## 한국어 품질 실측

**회의록 요약하기**

- 프롬프트: 오늘 진행한 팀 회의 녹취록을 읽고 주요 결정 사항 3가지만 요약해줘.
- 결과 예시: 오늘 회의의 주요 결정 사항은 다음과 같습니다. 첫째, 신규 프로젝트 마감일이 11월 15일로 확정되었습니다. 둘째, 예산은 기존 대비 10% 증액하기로 했습니다. 셋째, 다음 주 월요일에 중간 점검을 진행합니다.
- 관찰: 한국어 문맥을 정확히 파악하며 자연스러운 문장으로 답변을 생성합니다.

**이메일 초안 작성**

- 프롬프트: 거래처에 보낼 사과 이메일을 정중한 한국어로 작성해줘.
- 결과 예시: 귀사의 업무에 불편을 드려 진심으로 사과드립니다. 요청하신 자료는 현재 수정 중에 있으며, 내일 오전까지 반드시 전달해 드리겠습니다. 너그러운 양해 부탁드립니다.
- 관찰: 비즈니스 상황에 맞는 정중한 한국어 어조를 잘 구현합니다.

한국어 입출력을 원활하게 지원하며 문법 오류 없이 자연스러운 문장을 구사합니다. 전문적인 비즈니스 용어 처리도 준수하여 업무용으로 사용하기에 부족함이 없습니다.

- **직장인**: 민감한 회사 기획안을 AI에게 요약 요청할 때 보안 걱정 없이 즉시 결과를 얻을 수 있습니다. 회의 내용을 정리하여 팀원들에게 공유할 메일 초안을 빠르게 작성합니다.
- **학생**: 개인적인 학습 노트와 논문 자료를 AI에 학습시켜 나만의 맞춤형 과외 선생님으로 활용합니다. 시험 기간에 방대한 자료를 요약하여 효율적으로 공부합니다.
- **소상공인**: 고객과의 상담 기록을 AI에 저장해두고, 재방문 고객에게 보낼 맞춤형 안내 메시지를 작성할 때 활용합니다. 매장 관리 업무를 자동화하여 운영 시간을 절약합니다.

## 자주 묻는 질문

**클라우드 기반 AI와 무엇이 다른가요?**

일반적인 AI는 사용자의 데이터를 서버로 보내 처리하지만 이 툴은 사용자의 기기 자체에서 모든 작업을 수행합니다. 따라서 인터넷 연결 없이도 작동하며 개인정보가 외부로 유출될 가능성이 없습니다.

**제 컴퓨터 사양이 낮아도 사용할 수 있나요?**

기본적인 작업은 가능하지만 AI 모델을 구동하는 특성상 메모리와 프로세서 성능이 어느 정도 뒷받침되어야 원활합니다. 최신 기기일수록 더 빠르고 쾌적한 환경에서 AI를 활용할 수 있습니다.

**여러 기기에서 동시에 사용할 수 있나요?**

네, 안드로이드, iOS, 윈도우, 맥, 리눅스를 모두 지원하므로 사용하시는 다양한 기기에 설치하여 연동할 수 있습니다. 기기 간 데이터 동기화 기능로 어디서든 업무를 이어갈 수 있습니다.

**인터넷이 끊겨도 사용할 수 있나요?**

네, 핵심 기능이 기기 내에서 로컬로 작동하기 때문에 인터넷 연결 없이도 기본적인 AI 답변과 데이터 처리가 가능합니다.

**내 컴퓨터 성능이 낮아도 잘 돌아가나요?**

기본적인 작업은 가능하지만, 복잡한 문서 분석이나 대용량 데이터 처리 시에는 높은 사양의 하드웨어가 필요할 수 있습니다.

**여러 기기에서 동시에 사용할 수 있나요?**

멀티 플랫폼을 지원하므로 각 기기에 설치하여 사용할 수 있으나, 라이선스 정책에 따른 기기 대수 제한은 공식 페이지 확인이 필요합니다.

**내 정보를 AI가 학습해서 다른 사람에게 유출하나요?**

아니요, 모든 데이터는 사용자의 기기 내에서만 머무르며 외부 서버로 전송되지 않으므로 정보 유출 걱정은 없습니다.
