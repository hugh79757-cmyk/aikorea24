## 한줄 요약

GroundingPI는 시각적 원시 요소와 언어를 결합해 물리적 지능을 모델링하는 기반 모델입니다. 연구자와 개발자가 멀티모달 데이터를 효율적으로 활용하도록 돕습니다.

## 핵심 기능

- **시각-언어 결합**: 이미지와 텍스트를 동시에 이해해 연구 효율을 높입니다.
- **프리트레인 모델**: 대규모 데이터로 사전 학습돼 바로 활용 가능합니다.
- **API 제공**: 클라우드 API로 손쉽게 추론 서비스를 이용할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜에서는 월 10만 토큰까지 사용 가능합니다.
- **유료 플랜**: Pro 플랜(월 50,000원)에서는 무제한 토큰과 전용 지원을 제공합니다.

비용 절약 팁: 무료 토큰 한도를 초과하지 않도록 배치 작업을 분할해 사용하면 비용을 절감할 수 있습니다.

## 한국어 지원

현재 인터페이스와 문서는 영어로 제공되며, 한국어 지원은 별도 번역 파일로 부분적으로 이용 가능합니다.

## 이런 분에게 추천합니다

AI 연구원: 최신 멀티모달 모델을 실험하고 싶습니다. 데이터 과학자: 시각·언어 데이터 분석 자동화를 원합니다. 스타트업 CTO: 차별화된 물리 지능 서비스를 빠르게 프로토타입하고 싶습니다.

## 실제 활용 예시

- **직장인**: 신제품 아이디어 회의 후, 시각·언어 데이터를 GroundingPI에 입력해 핵심 인사이트를 도출합니다. 이를 기반으로 보고서 초안을 빠르게 작성합니다.
- **학생**: 졸업 논문에서 물리 시뮬레이션 결과를 이미지와 설명으로 정리하고 모델을 이용해 자동 요약본을 생성합니다. 논문 작성 시간을 크게 단축합니다.
- **소상공인**: 상품 사진과 설명을 모델에 입력해 고객이 이해하기 쉬운 시각·텍스트 가이드를 자동 생성합니다. 온라인 쇼핑몰 페이지 제작에 활용합니다.

## 유사 툴과 비교

**장점:**
- 멀티모달 결합 성능이 뛰어나 연구에 바로 적용 가능
- API 기반으로 인프라 구축이 간편함

**단점:**
- 한국어 문서와 지원이 부족해 초기 학습에 시간이 필요함

**이런 분에게 가장 적합합니다:** 시각·언어 데이터를 동시에 다루는 AI 연구 및 프로토타입 개발에 가장 적합합니다.

## 자주 묻는 질문

**GroundingPI를 사용하려면 별도의 GPU가 필요합니까?**

클라우드 API를 통해 추론을 제공하므로 로컬 GPU 없이도 이용할 수 있습니다. 다만 대규모 배치 작업 시 비용을 고려해 자체 GPU 환경을 구축하는 것도 가능합니다.

**한국어 텍스트도 정확히 처리되나요?**

모델은 주로 영어 데이터로 학습되었지만 한국어 텍스트를 입력하면 기본적인 의미 파악은 가능합니다. 정확도를 높이려면 사전 번역이나 프롬프트 조정을 권장합니다.

**무료 플랜의 토큰 제한을 초과하면 어떻게 되나요?**

무료 토큰을 초과하면 요청이 차단되며, Pro 플랜으로 업그레이드하거나 다음 달 토큰이 리셋될 때까지 대기해야 합니다.
