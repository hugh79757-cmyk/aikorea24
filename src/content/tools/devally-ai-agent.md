## 한줄 요약

DevAlly AI Agent는 웹사이트와 앱의 접근성 표준 준수 여부를 자동으로 검사하고 발견된 문제를 해결할 수 있는 코드까지 생성해 주는 개발 지원 툴입니다. 개발 속도를 늦추지 않으면서도 장애인과 고령자 등 모든 사용자가 이용하기 편리한 디지털 제품을 만들 수 있도록 돕습니다.

## 핵심 기능

- **자동 감사**: 웹사이트 주소 입력만으로 10분 만에 접근성 위반 항목을 찾아냅니다.
- **우선순위 설정**: 시급하게 수정해야 할 법적 규제 위반 사항을 먼저 정리해 줍니다.
- **코드 자동 수정**: 깃(Git)과 연동되어 문제를 해결할 수 있는 정확한 코드를 생성합니다.

## 사용법

**1. 웹사이트 URL 입력 및 진단 시작**

메인 페이지의 입력창에 검사하고자 하는 웹사이트 주소를 입력합니다. 별도의 복잡한 설정 없이 10분 이내에 자동 감사가 시작됩니다.

**2. 접근성 위반 사항 우선순위 확인**

분석된 결과물에서 법적 규제 위반 사항과 시급한 수정이 필요한 항목을 확인합니다. AI가 중요도에 따라 문제를 분류해주므로 무엇부터 고쳐야 할지 명확히 알 수 있습니다.

**3. 코드 수정 제안 및 깃 연동**

AI가 생성한 문제 해결용 수정 코드를 검토합니다. 깃(Git)이나 CI/CD 파이프라인에 직접 연동하여 개발 과정 중에 즉시 코드를 반영할 수 있습니다.

**4. 접근성 보고서 및 증빙 자료 생성**

법적 대응이나 고객사 제출용으로 필요한 VPAT(자발적 제품 접근성 템플릿)와 접근성 준수 성명서를 대시보드에서 생성합니다.

- **무료 플랜**: 신용카드 등록 없이 첫 자동 감사를 무료로 체험할 수 있는 무료 플랜을 제공합니다.
- **유료 플랜**: 프로 플랜 월 약 45,000원(39달러 상당)부터 시작하며 지속적인 웹사이트 모니터링과 팀 협업 기능을 제공합니다.

비용 절약 팁: 초기에는 무료 진단 기능로 웹사이트의 심각한 접근성 오류를 먼저 파악하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 신용카드 등록 없이 첫 자동 감사를 무료로 체험할 수 있는 무료 플랜을 제공합니다. 구체적인 무료 사용 횟수나 기간은 공식 홈페이지의 정책에 따라 달라질 수 있습니다.

- **프로 플랜** (월 약 45,000원 (39달러)): 지속적인 웹사이트 모니터링과 팀 협업 기능을 제공하여 제품 개발 단계에서 상시 접근성을 관리할 수 있습니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 조직을 위한 맞춤형 접근성 관리와 보안 기능, 우선적인 기술 지원이 포함될 수 있습니다.

**환불과 해지**: 결제 및 환불 정책은 서비스 이용 약관에 따르며, 유료 플랜 해지 시 남은 기간에 대한 환불 가능 여부는 공식 고객센터로 확인해야 합니다.

## 한국어 지원

인터페이스와 분석 결과는 영어로 제공되지만 생성되는 웹 표준 코드는 국내 웹사이트 개발에도 동일하게 적용할 수 있습니다.

## 한국어 품질 실측

**웹 접근성 오류 리포트 확인**

- 프롬프트: 해당 웹사이트의 메인 페이지에서 장애인이 이용하기 어려운 요소가 무엇인지 리포트를 생성해줘.
- 결과 예시: The main page has 5 accessibility issues. Missing alt text on images and low contrast in the navigation menu are critical. Please fix these using the suggested code snippets.
- 관찰: 입력값과 결과값이 모두 영어로 출력되므로 한국어 사용자는 번역기를 병행하여 이해해야 합니다.

**수정 코드 생성 요청**

- 프롬프트: 로그인 버튼의 접근성을 개선하기 위한 HTML 수정 코드를 작성해줘.
- 결과 예시: To improve accessibility, add 'aria-label' and ensure color contrast meets WCAG standards. Here is the code snippet: <button aria-label='Login'>Login</button>.
- 관찰: 기술적인 코드 생성은 정확하지만 설명문은 영어로 제공되어 한국어 환경에서는 추가적인 확인이 필요합니다.

인터페이스와 분석 결과가 모두 영어로 제공되므로 한국어 사용자는 언어 장벽을 느낄 수 있습니다. 다만, 생성되는 웹 표준 코드는 언어와 무관하게 국내 웹 개발 환경에서도 동일하게 적용 가능합니다.

## 실제 활용 예시

- **직장인**: 회사 홈페이지 리뉴얼 과정에서 웹 접근성 인증을 받아야 할 때, AI 감사로 오류를 순식간에 찾아내고 수정 코드를 반영합니다.
- **학생**: 졸업프로젝트로 제작한 웹 서비스가 장애인 사용자도 불편 없이 이용할 수 있는지 테스트하고 개선합니다.
- **소상공인**: 쇼핑몰 웹사이트를 운영하면서 스크린 读者(리더) 사용자를 위한 대체 텍스트 누락 등의 문제를 자동으로 점검합니다.

## 유사 툴과 비교

**장점:**
- 별도의 복잡한 설정 없이 URL 입력만으로 빠른 진단 가능

**이런 분에게 가장 적합합니다:** 글로벌 기준에 맞추어 웹사이트 접근성 문제를 빠르고 효율적으로 해결하고 싶은 개발 팀

## 장단점

**장점**

- 웹사이트 주소 입력만으로 10분 이내에 접근성 위반 항목을 자동으로 감지하여 개발자의 업무 시간을 크게 단축해 줍니다.
- 단순한 오류 나열을 넘어 문제 해결을 위한 코드 수준의 수정안을 제시하므로 실제 개발 적용이 매우 용이합니다.
- 깃(Git)과 CI/CD 파이프라인에 직접 연동할 수 있어 배포 전 접근성 문제를 사전에 차단하는 자동화 환경을 구축할 수 있습니다.
- VPAT와 같은 법적 증빙 문서를 대시보드에서 즉시 생성할 수 있어 규제 준수와 대외적인 신뢰도 확보에 매우 효과적입니다.

**단점**

- 인터페이스와 모든 분석 결과가 영어로만 제공되기 때문에 한국어 사용자에게는 직관적인 사용이 다소 어려울 수 있습니다.
- 무료 플랜은 초기 체험 수준으로 제한되어 있어 지속적인 모니터링이나 팀 단위 협업을 위해서는 유료 결제가 필수적입니다.
- 웹 접근성 표준에 대한 기본 지식이 전혀 없는 사용자라면 AI가 제안하는 코드 수정안을 이해하고 적용하는 데 시간이 걸릴 수 있습니다.

## 주의사항

- **개인정보**: 웹사이트 스캔 시 민감한 개인정보가 포함된 페이지가 노출되지 않도록 주의해야 하며 보안이 필요한 환경에서는 사전 검토가 필수입니다.
- **저작권/상업적 이용**: AI가 생성한 수정 코드는 참고용으로 활용하시고, 최종적인 웹사이트 적용 시에는 반드시 개발자가 코드의 적합성과 저작권 문제를 검토해야 합니다.
- **요금/한도**: 월 45,000원의 요금제 외에 추가 기능 사용 시 비용이 발생할 수 있으므로 공식 요금 페이지의 세부 항목을 반드시 확인하십시오.
- **계정 관리**: 팀 협업 기능을 사용할 경우 계정 권한 관리를 철저히 하여 외부 인원에게 민감한 개발 정보가 노출되지 않도록 관리해야 합니다.

## 자주 묻는 질문

**웹 접근성 전문 지식이 없어도 사용할 수 있나요?**

네, 복잡한 지식 없이 웹사이트 주소만 입력하면 AI가 자동으로 진단하고 수정 코드까지 제안해 주므로 초보 개발자도 쉽게 사용할 수 있습니다.

**기존에 사용 중인 개발 툴과 연동이 가능한가요?**

깃(Git)과 직접 연동되어 코드 레벨에서 수정 사항을 반영할 수 있도록 설계되어 있어 기존 개발 워크플로우에 쉽게 녹아듭니다.

**무료 플랜으로 어디까지 확인할 수 있나요?**

신용카드 정보 입력 없이 가입 후 첫 자동 감사를 무료로 실행하여 웹사이트의 전반적인 접근성 수준을 바로 확인할 수 있습니다.

**한국 웹사이트에서도 문제없이 사용할 수 있나요?**

네, 웹 표준을 준수하는 사이트라면 언어와 관계없이 접근성 진단 및 코드 수정 제안 기능을 활용할 수 있습니다. 다만 분석 결과가 영어로 나오므로 이를 확인하는 과정이 필요합니다.

**개발 지식이 없어도 사용할 수 있나요?**

웹 접근성 규정에 대한 이해가 있다면 접근성 진단 결과를 파악하는 데는 도움이 됩니다. 하지만 제안된 코드를 수정하고 반영하려면 기본적인 웹 개발 지식이 필요합니다.

**무료 플랜으로도 충분히 접근성 관리가 가능한가요?**

무료 플랜은 초기 진단용으로 적합합니다. 지속적인 모니터링과 팀 협업, 자동화된 배포 관리를 위해서는 유료 플랜으로 업그레이드하는 것이 좋습니다.

**결제는 어떻게 진행되나요?**

공식 웹사이트의 가격 페이지에서 프로 플랜을 선택하여 결제할 수 있습니다. 정확한 결제 방식과 환불 규정은 공식 홈페이지의 이용 약관을 참조하십시오.
