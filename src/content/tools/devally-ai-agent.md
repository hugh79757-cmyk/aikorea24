## 한줄 요약

DevAlly AI Agent는 웹사이트와 앱의 접근성 표준 준수 여부를 자동으로 검사하고 발견된 문제를 해결할 수 있는 코드까지 생성해 주는 개발 지원 툴입니다. 개발 속도를 늦추지 않으면서도 장애인과 고령자 등 모든 사용자가 이용하기 편리한 디지털 제품을 만들 수 있도록 돕습니다.

## 핵심 기능

- **자동 감사**: 웹사이트 주소 입력만으로 10분 만에 접근성 위반 항목을 찾아냅니다.
- **우선순위 설정**: 시급하게 수정해야 할 법적 규제 위반 사항을 먼저 정리해 줍니다.
- **코드 자동 수정**: 깃(Git)과 연동되어 문제를 해결할 수 있는 정확한 코드를 생성합니다.

## 가격 정책

- **무료 플랜**: 신용카드 등록 없이 첫 자동 감사를 무료로 체험할 수 있는 무료 플랜을 제공합니다.
- **유료 플랜**: 프로 플랜 월 약 45,000원(39달러 상당)부터 시작하며 지속적인 웹사이트 모니터링과 팀 협업 기능을 제공합니다.

비용 절약 팁: 초기에는 무료 진단 기능로 웹사이트의 심각한 접근성 오류를 먼저 파악하는 것을 권장합니다.

## 한국어 지원

인터페이스와 분석 결과는 영어로 제공되지만 생성되는 웹 표준 코드는 국내 웹사이트 개발에도 동일하게 적용할 수 있습니다.

## 이런 분에게 추천합니다

웹사이트의 장애인 접근성 지침을 빠르게 준수해야 하는 웹 퍼블리셔와 프론트엔드 개발자
글로벌 서비스를 운영하며 법적 소송 위험을 예방하고 싶은 스타트업 대표
누구나 이용할 수 있는 웹사이트를 구축하고자 하는 IT 서비스 기획자

## 실제 활용 예시

- **직장인**: 회사 홈페이지 리뉴얼 과정에서 웹 접근성 인증을 받아야 할 때, AI 감사로 오류를 순식간에 찾아내고 수정 코드를 반영합니다.
- **학생**: 졸업프로젝트로 제작한 웹 서비스가 장애인 사용자도 불편 없이 이용할 수 있는지 테스트하고 개선합니다.
- **소상공인**: 쇼핑몰 웹사이트를 운영하면서 스크린 读者(리더) 사용자를 위한 대체 텍스트 누락 등의 문제를 자동으로 점검합니다.

## 유사 툴과 비교

**장점:**
- 별도의 복잡한 설정 없이 URL 입력만으로 빠른 진단 가능
- 단순 진단에 그치지 않고 실제 코드 수정안을 바로 제공

**단점:**
- 한국형 웹 콘텐츠 접근성 지침(KWCAG)보다는 글로벌 표준(ADA/WCAG)에 특화됨
- 한국어 고객 지원이 다소 제한적임

**이런 분에게 가장 적합합니다:** 글로벌 기준에 맞추어 웹사이트 접근성 문제를 빠르고 효율적으로 해결하고 싶은 개발 팀

## 자주 묻는 질문

**웹 접근성 전문 지식이 없어도 사용할 수 있나요?**

네, 복잡한 지식 없이 웹사이트 주소만 입력하면 AI가 자동으로 진단하고 수정 코드까지 제안해 주므로 초보 개발자도 쉽게 사용할 수 있습니다.

**기존에 사용 중인 개발 툴과 연동이 가능한가요?**

깃(Git)과 직접 연동되어 코드 레벨에서 수정 사항을 반영할 수 있도록 설계되어 있어 기존 개발 워크플로우에 쉽게 녹아듭니다.

**무료 플랜으로 어디까지 확인할 수 있나요?**

신용카드 정보 입력 없이 가입 후 첫 자동 감사를 무료로 실행하여 웹사이트의 전반적인 접근성 수준을 바로 확인할 수 있습니다.
