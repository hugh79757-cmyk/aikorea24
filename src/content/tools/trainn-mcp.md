## 한줄 요약

Trainn MCP는 복잡한 영상 편집 기술 없이도 챗봇과 나눈 대화 내용을 즉시 영상이나 교육 코스로 변환해 주는 도구입니다. 매번 영상을 새로 기획하고 편집하는 번거로움을 줄여주어 업무 생산성을 비약적으로 높여줍니다.

## 핵심 기능

- **대화 기반 영상화**: 챗봇 대화 내용을 분석해 자동으로 영상 스크립트와 화면을 구성합니다.
- **교육 코스 생성**: 단순 영상을 넘어 체계적인 학습 과정(Course) 형태로 콘텐츠를 구성합니다.
- **빠른 수정 기능**: 영상 제작 후에도 텍스트 수정만으로 영상 내용을 쉽게 업데이트할 수 있습니다.

## 사용법

**1. 대화 내용 입력하기**

로그인 후 대시보드에서 새로운 프로젝트를 생성합니다. 챗봇 창에 영상으로 만들고 싶은 제품의 기능이나 교육 내용을 텍스트로 입력하여 대화를 시작합니다.

**2. 영상 스크립트 생성**

입력한 대화 내용을 보고 도구가 자동으로 영상 스크립트를 구성합니다. 생성된 스크립트의 문맥이 자연스러운지 확인하고 필요에 따라 내용을 수정합니다.

**3. 화면 구성 및 편집**

스크립트에 맞는 화면 레이아웃을 선택하고 필요한 이미지나 영상을 배치합니다. 텍스트 수정만으로 화면의 구성 요소가 실시간으로 변경되는 편집 기능을 활용합니다.

**4. 영상 내보내기 및 공유**

편집이 완료되면 영상 파일을 생성하여 다운로드하거나 공유 링크를 생성합니다. 생성된 콘텐츠는 교육용 코스 형태로 구성되어 고객이나 팀원에게 바로 전달할 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 영상 제작 기능을 체험할 수 있는 무료 플랜을 제공합니다.
- **유료 플랜**: Pro 플랜(월 약 35,000원~, 25달러 기준)부터는 무제한 영상 제작 및 워터마크 제거 기능을 지원합니다.

비용 절약 팁: 먼저 무료 플랜으로 영상 생성 품질을 확인한 후, 팀 단위 협업이 필요할 때 유료 전환을 고려하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜에서는 기본적인 영상 제작 기능을 체험할 수 있습니다. 다만, 영상 내 워터마크가 포함될 수 있으며 제작 가능한 영상 수나 기능에 제한이 있을 수 있습니다.

- **Pro 플랜** (월 35,000원 (25달러 기준, 공식 페이지 확인 필요)): 무제한 영상 제작이 가능하며 영상 내 워터마크를 제거하여 깔끔한 결과물을 얻을 수 있습니다.

- **Enterprise 플랜** (공식 페이지 확인 필요): 팀 단위 협업 기능과 기업용 맞춤형 보안 옵션 및 우선 지원 서비스를 제공합니다.

**환불과 해지**: 결제 및 환불 정책은 서비스 이용 약관에 따르며, 유료 플랜 해지는 계정 설정 메뉴에서 언제든지 가능합니다.

## 한국어 지원

현재 인터페이스와 생성 엔진은 영어 기반으로 작동합니다. 한국어 텍스트 입력 시 영상 구성은 가능하나, 자막이나 음성 합성 시 한국어 지원 여부를 사전에 확인해야 합니다.

## 한국어 품질 실측

**제품 소개 영상**

- 프롬프트: 우리 회사 신규 앱의 회원가입 방법을 안내하는 1분짜리 소개 영상을 만들어줘.
- 결과 예시: 회원가입 버튼 클릭 안내, 이메일 주소 입력, 인증번호 확인 단계가 순차적으로 영상에 담깁니다. 각 화면마다 간결한 설명 자막이 자동으로 생성됩니다.
- 관찰: 입력한 한국어 내용을 보고 영상 구성은 가능하나, 자막의 한국어 표현이 다소 어색할 수 있습니다.

**직원 교육 자료**

- 프롬프트: 사내 메신저 사용법을 설명하는 교육 콘텐츠를 생성해줘.
- 결과 예시: 메신저 설치부터 대화방 생성, 파일 전송까지의 과정이 학습 코스 형태로 정리됩니다. 각 단계별로 필요한 스크린샷과 설명이 매칭되어 나타납니다.
- 관찰: 한국어 텍스트 입력은 지원하지만 결과물의 음성이나 자막은 영어 기반으로 출력될 확률이 높습니다.

현재 한국어 입력은 가능하지만 출력물은 영어 기반으로 작동합니다. 한국어 자막이나 음성을 완벽하게 지원하지 않으므로, 생성 후 별도의 편집 과정이 필요합니다.

## 이런 분에게 추천합니다

매번 새로운 제품 소개 영상을 만드는 데 시간을 뺏기는 마케터에게 추천합니다.
신입 사원 교육용 매뉴얼을 영상으로 쉽고 빠르게 제작하고 싶은 인사 담당자에게 추천합니다.
고객 문의 응대를 위한 반복적인 설명 영상을 효율적으로 만들고 싶은 소상공인에게 추천합니다.

## 실제 활용 예시

- **직장인**: 신규 서비스 사용법을 챗봇에 입력하여 내부 공유용 가이드 영상을 5분 만에 완성했습니다.
- **학생**: 복잡한 프로젝트 과제 내용을 챗봇과 정리한 뒤, 이를 발표용 영상 코스로 만들어 제출했습니다.
- **소상공인**: 쇼핑몰 이용 방법을 챗봇 대화로 요약하고 이를 고객 안내용 튜토리얼 영상으로 자동 제작해 블로그에 올렸습니다.

## 장단점

**장점**

- 복잡한 영상 편집 기술이 없어도 챗봇 대화만으로 전문가 수준의 교육 영상을 빠르게 제작할 수 있습니다.
- 영상 제작 후에도 텍스트 수정만으로 화면 내용을 즉시 업데이트할 수 있어 유지보수가 매우 간편합니다.
- 단순한 영상 제작을 넘어 체계적인 교육 코스 형태로 콘텐츠를 구성할 수 있어 사내 교육용으로 적합합니다.
- 매번 영상을 새로 기획하는 번거로움을 줄여주어 반복적인 업무 생산성을 크게 향상시킬 수 있습니다.

**단점**

- 현재 인터페이스와 생성 엔진이 영어 중심으로 설계되어 있어 한국어 사용자에게는 언어적 장벽이 존재합니다.
- 결과물의 자막이나 음성이 한국어로 자연스럽게 출력되지 않아 추가적인 후반 작업이 요구될 수 있습니다.
- 무료 플랜에서는 워터마크가 포함될 수 있어 상업적인 용도로 활용하기에는 제약이 따릅니다.

## 주의사항

- **개인정보**: 챗봇에 대화 내용을 입력할 때 고객의 개인정보나 회사의 기밀 사항이 포함되지 않도록 주의해야 합니다.
- **저작권/상업적 이용**: 생성된 영상에 포함된 이미지나 소스 파일의 저작권 범위를 확인하고 상업적 이용 시에는 유료 플랜의 라이선스 규정을 준수해야 합니다.
- **요금/한도**: 무료 체험 후 유료 플랜으로 자동 결제될 수 있으므로, 결제 전 구독 정책과 월별 영상 제작 한도를 반드시 확인하십시오.
- **계정 관리**: 팀 단위로 사용할 경우 계정 공유보다는 개별 계정을 생성하여 데이터 관리의 보안성을 유지하는 것이 좋습니다.

## 자주 묻는 질문

**영상 편집 기술이 전혀 없어도 사용할 수 있나요?**

네, 별도의 편집 도구를 다룰 줄 몰라도 챗봇과의 대화 내용만 입력하면 AI가 알아서 영상을 구성해 줍니다.

**한국어로 된 영상도 만들 수 있나요?**

입력은 가능하지만 생성된 영상의 음성이나 자막이 한국어를 완벽하게 지원하는지 설정에서 확인이 필요합니다.

**무료 플랜으로도 충분한가요?**

간단한 테스트나 개인적인 용도로는 충분하지만 기업에서 전문적인 홍보 영상을 제작하려면 유료 플랜의 고화질 및 워터마크 제거 기능이 권장됩니다.

**한국어로 입력해도 영상이 잘 만들어지나요?**

내용 입력은 가능하지만, 생성되는 자막이나 음성 결과물은 영어로 나올 가능성이 높습니다. 한국어 결과물을 원하신다면 별도의 번역이나 편집 도구를 병행해야 합니다.

**영상 제작 후 수정이 가능한가요?**

네, 텍스트 기반으로 편집이 가능하여 영상 전체를 다시 만들 필요 없이 내용만 수정하면 실시간으로 반영됩니다.

**무료 플랜으로도 충분히 업무에 활용할 수 있나요?**

기본적인 기능 체험은 가능하지만, 워터마크가 포함되고 제작 수에 제한이 있을 수 있습니다. 본격적인 업무용이라면 유료 플랜 전환을 권장합니다.

**교육 코스 기능이 무엇인가요?**

단일 영상을 나열하는 것이 아니라, 여러 개의 영상을 논리적인 순서로 배치하여 학습자가 차례대로 내용을 익힐 수 있게 구성하는 기능입니다.
