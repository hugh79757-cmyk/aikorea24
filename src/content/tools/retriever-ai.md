## 한줄 요약

Retriever AI는 Chrome 확장프로그램과 클라우드 서비스 형태로 제공되는 AI 브라우저 에이전트입니다. 사용자가 로그인한 사이트와 공개 웹을 자동으로 탐색해 필요한 정보를 한 번에 가져와 업무 효율을 높여 줍니다.

## 핵심 기능

- **자동검색**: 키워드 입력만으로 관련 웹 페이지를 자동으로 찾아 결과를 요약합니다.
- **다중사이트**: 로그인된 여러 서비스에서 동시에 데이터를 수집합니다.
- **클라우드**: 클라우드 브라우저로 언제 어디서나 동일한 결과를 얻을 수 있습니다.

## 사용법

**1. 확장프로그램 설치**

크롬 웹스토어에서 Retriever AI를 검색하여 브라우저에 추가합니다. 설치가 완료되면 주소창 옆에 아이콘이 생성되어 언제든지 실행할 수 있는 상태가 됩니다.

**2. 작업 지시 입력**

자동화하고 싶은 웹사이트에 접속한 후, 팝업창이나 에이전트 인터페이스에 원하는 작업을 한국어로 입력합니다. 예를 들어 구글 맵에서 특정 지역의 업종별 연락처를 수집해달라고 요청할 수 있습니다.

**3. 에이전트 실행 및 모니터링**

에이전트가 브라우저를 직접 조작하며 로그인된 페이지와 공개 웹을 탐색하는 과정을 실시간으로 지켜봅니다. 사용자가 직접 클릭하거나 스크롤할 필요 없이 자동으로 데이터 수집이 진행됩니다.

**4. 결과 확인 및 내보내기**

수집이 완료되면 정리된 데이터를 화면에서 확인하고 스프레드시트 등의 형식으로 저장합니다. 반복적인 업무를 처리한 결과를 곧바로 다음 업무에 활용할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 기본 검색 및 결과 반환 기능을 무제한으로 제공합니다.
- **유료 플랜**: Enterprise 플랜 100,000원/월 – 전용 API 호출, 우선 지원, 커스텀 모델 이용이 가능합니다.

비용 절약 팁: 무료 플랜으로 충분히 사용 가능하니, 필요 시에만 유료 플랜을 검토하세요.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜은 광고 지원 형태로 제공되며, 7백만 개 이상의 작업 자동화 경험을 보고 기본 검색과 브라우저 에이전트 기능을 무료로 이용할 수 있습니다. 구체적인 월간 작업 횟수 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **클라우드 및 에이전트 스토어 플랜** (공식 요금 페이지 확인 필요): 클라우드 브라우저를 통한 대규모 자동화 실행과 에이전트 전용 결제 시스템을 지원합니다.

- **엔터프라이즈 및 API 플랜** (100,000원/월): 전용 API 호출, 우선 기술 지원, 커스텀 모델 이용 기능을 제공합니다.

**환불과 해지**: 환불 및 정기결제 해지 정책에 대한 상세한 내용은 공식 홈페이지의 결제 안내 페이지로 직접 확인해야 합니다.

## 한국어 지원

현재 UI와 문서는 영어로 제공되지만 프롬프트 입력은 한국어로 자유롭게 사용할 수 있습니다.

- 프롬프트: 구글 맵에서 서울 강남구 카페를 검색하고 상위 10개 매장의 전화번호와 평점을 정리해줘.
- 결과 예시: 에이전트가 구글 맵에 접속하여 강남구 카페를 순차적으로 클릭한 뒤, 상호명과 평점 및 연락처를 표 형식으로 깔끔하게 정리하여 반환합니다.
- 관찰: 한국어 프롬프트를 정확히 이해하고 웹사이트 내에서 알맞은 요소를 탐색합니다.

**구인구직 정보 추출**

- 프롬프트: 링크드인에서 채용 공고 페이지를 열고 파이썬 개발자 직무의 자격 요건을 스프레드시트로 만들어줘.
- 결과 예시: 로그인된 세션을 활용해 채용 공고 목록을 스크롤하며 주요 자격 요건과 기술 스택을 추출하여 데이터셋 형태로 보여줍니다.
- 관찰: 로그인이 필요한 사이트에서도 사용자의 세션을 유지하며 원활하게 작동합니다.

공식 인터페이스와 설명서는 영어로 제공되지만 작업 지시를 내리는 프롬프트 입력창에는 한국어를 자유롭게 사용할 수 있습니다. 복잡한 업무 지시도 자연스럽게 파악하여 웹 탐색 결과에 반영합니다.

- 크롬 확장프로그램과 클라우드 환경을 모두 지원하여 언제 어디서나 중단 없이 대규모 작업을 수행할 수 있습니다.

- 초보자도 복잡한 코딩 없이 자연어 프롬프트 입력만으로 브라우저 에이전트를 곧바로 실행할 수 있습니다.

- 웹사이트의 구조가 갑자기 변경되거나 보안 팝업이 뜰 경우 에이전트의 자동화 작업이 간헐적으로 중단될 수 있습니다.

## 주의사항

- **개인정보**: 브라우저 에이전트가 로그인된 사이트에서 작동하므로, 민감한 개인정보나 금융 정보가 포함된 화면에서는 사용에 각별한 주의가 필요합니다.
- **저작권/상업적 이용**: 웹사이트에서 자동으로 수집한 데이터를 무단으로 상업적 목적에 재배포하거나 이용할 때는 해당 플랫폼의 이용약관을 반드시 준수해야 합니다.
- **요금/한도**: 광고 지원 무료 플랜과 유료 플랜의 작업 수행 한도가 다를 수 있으므로, 대규모 업무를 처리하기 전에 이용량을 확인하는 것이 좋습니다.
- **계정 관리**: 자동화 도구가 사용자의 브라우저 세션과 연동되므로, 공용 PC보다는 개인 기기에서 안전하게 계정을 관리하며 사용하는 것을 권장합니다.

## 자주 묻는 질문

**Chrome에 설치 후 바로 사용할 수 있나요?**

네, Chrome 웹스토어에서 확장 프로그램을 설치하면 브라우저 상단 아이콘을 클릭해 바로 사용할 수 있습니다. 별도의 설정 없이도 기본 검색 기능이 작동합니다.

**무료 플랜에서도 검색 횟수 제한이 있나요?**

무료 플랜은 검색 횟수에 제한이 없으며, 기본적인 검색·요약 기능을 무제한으로 이용할 수 있습니다. 다만, 고급 API 호출은 유료 플랜에 포함됩니다.

**한국어로 프롬프트를 입력하면 정확히 처리되나요?**

예, 프롬프트는 한국어로 입력해도 자연어 처리 모델이 이해하여 원하는 결과를 반환합니다. 다만, UI와 문서는 영어이므로 참고가 필요합니다.

**로그인된 웹사이트에서도 에이전트를 안전하게 쓸 수 있나요?**

사용자가 이미 로그인한 브라우저 세션을 활용하므로 평소 접속하는 사이트의 데이터를 이어서 수집할 수 있습니다. 단, 보안이 엄격한 금융 서비스나 민감한 개인정보 페이지에서는 오작동이나 보안 차단이 발생할 수 있으므로 주의가 필요합니다.

**한국어로 작업 지시를 내려도 에이전트가 잘 알아듣나요?**

네, 인터페이스는 영어이지만 프롬프트 창에 한국어로 '이메일 주소를 모아서 엑셀로 만들어줘'처럼 입력하면 의도를 정확히 파악합니다. 웹페이지 내부의 영어 텍스트나 구조도 스스로 해석하여 작업을 수행합니다.

**무료 플랜만으로도 업무에 충분히 쓸 수 있나요?**

기본적인 검색과 웹 탐색 자동화 기능은 무료 플랜에서도 광고 지원 형태로 충분히 이용할 수 있습니다. 다만 대규모 데이터를 상시 수집하거나 전용 API 및 우선 지원이 필요할 때는 유료 플랜 검토가 필요합니다.

**수집한 데이터는 어떤 형식으로 다운로드할 수 있나요?**

웹 탐색이 완료된 결과물은 화면에서 표 형태로 바로 확인할 수 있으며, 스프레드시트나 데이터셋 형태로 내보내어 실무에 활용할 수 있습니다. 구체적인 파일 형식 지원 범위는 업데이트에 따라 달라질 수 있습니다.
