## 한줄 요약

Retriever AI는 Chrome 확장프로그램과 클라우드 서비스 형태로 제공되는 AI 브라우저 에이전트입니다. 사용자가 로그인한 사이트와 공개 웹을 자동으로 탐색해 필요한 정보를 한 번에 가져와 업무 효율을 높여 줍니다.

## 핵심 기능

- **자동검색**: 키워드 입력만으로 관련 웹 페이지를 자동으로 찾아 결과를 요약합니다.
- **다중사이트**: 로그인된 여러 서비스에서 동시에 데이터를 수집합니다.
- **클라우드**: 클라우드 브라우저로 언제 어디서나 동일한 결과를 얻을 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 기본 검색 및 결과 반환 기능을 무제한으로 제공합니다.
- **유료 플랜**: Enterprise 플랜 100,000원/월 – 전용 API 호출, 우선 지원, 커스텀 모델 이용이 가능합니다.

비용 절약 팁: 무료 플랜으로 충분히 사용 가능하니, 필요 시에만 유료 플랜을 검토하세요.

## 한국어 지원

현재 UI와 문서는 영어로 제공되지만 프롬프트 입력은 한국어로 자유롭게 사용할 수 있습니다.

## 이런 분에게 추천합니다

대량 리서치를 자주 하는 마케팅 담당자에게 추천합니다. 데이터 수집이 필요한 스타트업 창업자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: 신제품 출시 일정에 맞춰 경쟁사 가격 정보를 빠르게 수집하고 보고서 초안을 작성합니다.
- **학생**: 과제 주제와 관련된 최신 논문과 기사들을 자동으로 모아 정리하고 요약본을 작성합니다.
- **소상공인**: 온라인 마케팅 전략을 세우기 위해 주요 쇼핑몰 리뷰와 트렌드를 한 번에 수집해 분석합니다.

## 유사 툴과 비교

**장점:**
- 브라우저 확장으로 즉시 사용 가능
- 다중 사이트 동시 탐색으로 시간 절감
- 클라우드 옵션으로 기기 제약 없음

**단점:**
- 한국어 UI가 없어 초기 설정이 다소 불편함
- 고급 기능은 유료 플랜에 한정

**이런 분에게 가장 적합합니다:** 다양한 웹 소스에서 정보를 한 번에 모아야 하는 업무 자동화 상황에 가장 적합합니다.

## 자주 묻는 질문

**Chrome에 설치 후 바로 사용할 수 있나요?**

네, Chrome 웹스토어에서 확장 프로그램을 설치하면 브라우저 상단 아이콘을 클릭해 바로 사용할 수 있습니다. 별도의 설정 없이도 기본 검색 기능이 작동합니다.

**무료 플랜에서도 검색 횟수 제한이 있나요?**

무료 플랜은 검색 횟수에 제한이 없으며, 기본적인 검색·요약 기능을 무제한으로 이용할 수 있습니다. 다만, 고급 API 호출은 유료 플랜에 포함됩니다.

**한국어로 프롬프트를 입력하면 정확히 처리되나요?**

예, 프롬프트는 한국어로 입력해도 자연어 처리 모델이 이해하여 원하는 결과를 반환합니다. 다만, UI와 문서는 영어이므로 참고가 필요합니다.
