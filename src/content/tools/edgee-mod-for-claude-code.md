## 한줄 요약

Edgee Mod는 터미널 기반 개발 도구인 Claude Code에 직관적인 사이드바 인터페이스를 추가해 주는 도구입니다. 코딩 대화를 벗어나지 않고도 클릭 한 번으로 사용 모델을 교체하고 API 비용 절감 비율을 실시간으로 추적할 수 있습니다.

## 핵심 기능

- **스마트 사이드바**: 클릭 한 번으로 사이드바를 열어 세션 상태와 모델을 확인합니다.
- **모델 실시간 변경**: 작업 도중 원하는 LLM 모델이나 오픈소스 모델로 즉시 라우팅합니다.
- **비용 절감 모니터링**: 토큰 압축 기술로 절약된 예상 비용을 실시간으로 보여줍니다.

## 사용법

**1. Edgee CLI 설치 및 업데이트**

터미널에서 Edgee CLI를 설치하거나 기존 버전을 업데이트합니다. Claude Code는 2.1.287 버전 이상이어야 정상적으로 연동됩니다.

**2. Claude Code 실행하기**

터미널에 'edgee launch claude' 명령어를 입력하여 실행합니다. Edgee MCP가 활성화된 상태로 모드가 자동으로 로드됩니다.

**3. 사이드바 열기 및 모델 선택**

프롬프트 상단의 컴팩트한 바 우측 하단에 있는 [+] 버튼을 클릭하여 인터랙티브 사이드바를 엽니다. 사이드바에서 원하는 AI 모델이나 오픈소스 모델을 검색하여 세션을 즉시 라우팅할 수 있습니다.

**4. 세션 및 비용 절감 모니터링**

사이드바로 입력 토큰 압축 및 라우팅로 절약된 예상 비용과 응답별 토큰 사용량을 실시간으로 확인합니다. 작업이 끝나면 [-] 버튼을 눌러 사이드바를 접을 수 있습니다.

- **유료 플랜**: Edgee 엔터프라이즈 플랜(월 $20~/약 28,000원부터) 이용 시 온프레미스 구축 및 팀 가시성 모니터링을 제공합니다.

비용 절약 팁: 스마트 라우팅 및 토큰 압축 기능을 활용하면 고성능 모델 사용료를 최대 50% 이상 절감할 수 있습니다.

## 실제 활용 예시

- **직장인**: 백엔드 개발자가 Claude Code로 API 개발 작업을 하던 중 Edgee 사이드바를 열어 비용이 저렴한 모델로 즉시 전환했습니다. 세션별 토큰 절감액을 한눈에 보며 개발 예산을 효율적으로 관리했습니다.
- **학생**: 컴퓨터공학과 학생이 캡스톤 디자인 프로젝트 코딩 시 모듈별로 적절한 오픈소스 모델을 사이드바에서 선택해 사용했습니다. 제한된 API 무료 크레딧을 아끼며 프로젝트를 완료했습니다.
- **소상공인**: 1인 쇼핑몰 개발자가 자사 웹사이트 기능 확장 코드를 작성할 때 토큰 비용 추적 사이드바를 활용했습니다. 불필요한 AI 비용 지출을 줄이며 웹페이지 개편 코드를 성공적으로 빌드했습니다.

## 자주 묻는 질문

**Edgee Mod는 어떻게 설치하고 실행하나요?**

Claude Code 환경에 Edgee MCP를 활성화한 후 연동을 진행합니다. 작업 창 하단의 [+] 버튼을 누르면 스마트 사이드바가 즉시 활성화됩니다.

**어떤 모델로 교체할 수 있나요?**

Edgee 플랫폼에서 지원하는 다양한 상용 LLM 및 오픈소스 모델로 코딩 세션 도중 자유롭게 전환이 가능합니다.

**비용 절감 효과는 어떻게 측정되나요?**

Edgee의 토큰 압축 및 스마트 라우팅 알고리즘이 적용되어 절약된 예상 금액이 사이드바 상단에 수치로 실시간 표기됩니다.

**Edgee Mod를 사용하려면 Claude Code 버전에 제한이 있나요?**

네, 크롤링 텍스트에 따르면 Claude Code 2.1.287 버전 이상과 Edgee MCP가 활성화된 환경이 필수적입니다. 실행 전 터미널에서 버전을 업데이트하는 것이 안전합니다.

**비용 절감은 어떤 방식으로 이루어지나요?**

입력 토큰을 압축하여 불필요한 길이를 줄이고, 작업 도중 더 저렴한 오픈소스 모델이나 대체 모델로 스마트 라우팅하여 전체적인 API 비용을 낮춰줍니다.

**사이드바 인터페이스는 어떻게 열고 닫나요?**

Claude Code 프롬프트 상단 컴팩트 바의 우측 하단에 있는 [+] 버튼을 클릭하면 사이드가 열리고, [-] 버튼을 누르면 다시 접을 수 있습니다.

**한국어 사용자도 불편함 없이 이용할 수 있나요?**

Claude Code 내에서 AI와 대화할 때는 한국어 사용이 가능하지만, 사이드바 UI와 라우팅 메뉴는 영문으로만 제공되므로 영문 환경에 익숙해져야 합니다.
