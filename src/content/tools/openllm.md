## 한줄 요약

OpenLLM은 Claude Code나 Codex 같은 다양한 AI 모델을 하나의 인터페이스에서 통합 관리하게 해주는 도구입니다. 복잡한 API 설정 없이도 로컬 모델과 클라우드 모델을 자유롭게 전환하며 개발 환경의 효율성을 극대화합니다.

## 핵심 기능

- **통합 라우팅**: 여러 AI 모델을 하나의 창구에서 관리하여 작업 효율을 높입니다.
- **로컬 모델 지원**: 외부 서버를 거치지 않고 내 컴퓨터에서 직접 모델을 돌려 보안을 강화합니다.
- **즉시 사용 가능**: 별도의 API 키 연결 없이도 기본 추론 기능을 바로 사용할 수 있습니다.

## 사용법

**1. OpenLLM 설치하기**

공식 홈페이지에서 제공하는 설치 명령어를 복사하여 터미널에 입력합니다. 맥 앱을 다운로드하거나 터미널에서 한 줄 명령어를 실행하면 즉시 설치가 완료됩니다.

**2. 모델 연결 및 라우팅**

사용 중인 API 키나 로컬 모델(Ollama, LM Studio 등)을 OpenLLM 설정에 등록합니다. 여러 모델을 체인으로 연결하여 작업 도중 특정 모델이 제한될 경우 자동으로 다음 모델로 전환되도록 설정합니다.

**3. 개발 도구와 연동**

Claude Code나 Codex 등 평소 사용하는 개발 도구의 실행 명령어를 OpenLLM을 거치도록 설정합니다. 별도의 복잡한 설정 없이도 기존 개발 환경을 그대로 유지하며 도구를 사용할 수 있습니다.

**4. AI 모델 호출 및 실행**

터미널에서 'openllm [모델명]' 형식으로 명령어를 입력하여 AI를 호출합니다. 계정을 연결하지 않아도 기본 추론 기능이 포함되어 있어 즉시 테스트가 가능합니다.

## 가격 정책

- **무료 플랜**: 기본적인 추론 기능을 포함한 무료 플랜을 제공하여 즉시 사용이 가능합니다.
- **유료 플랜**: 추후 업데이트 예정인 유료 플랜은 고급 모델 접근 권한과 대규모 API 호출을 지원할 것으로 예상됩니다.

비용 절약 팁: 먼저 무료 버전의 로컬 모델 기능을 활용해 보고, 필요에 따라 유료 API를 연결하여 비용을 최적화하십시오.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 기본 추론 기능을 포함하며 별도의 카드 등록 없이 즉시 사용을 시작할 수 있습니다. 첫 요청부터 바로 작동하며 로컬 모델 및 API 라우팅 기능을 체험할 수 있습니다.

- **Start for free** (무료): 기본 추론 기능과 로컬 모델 라우팅, 컨텍스트 공유 기능을 제공합니다.

- **추후 업데이트 예정 플랜** (공식 페이지 확인 필요): 고급 모델 접근 권한 확대 및 대규모 API 호출 처리를 위한 유료 옵션이 준비될 예정입니다.

**환불과 해지**: 현재 무료로 시작할 수 있는 구조이며, 구체적인 결제 및 환불 정책은 공식 홈페이지의 요금 페이지로 확인해야 합니다.

## 한국어 지원

프로그램 인터페이스는 영어로 구성되어 있으나, AI 모델 자체가 한국어를 완벽하게 지원하므로 한국어 코딩 질문이나 문서화 작업에 아무런 문제가 없습니다.

## 한국어 품질 실측

**파이썬 코드 오류 수정**

- 프롬프트: 이 파이썬 코드에서 발생하는 'IndexError'의 원인을 찾고 수정된 코드를 작성해 줘.
- 결과 예시: 해당 오류는 리스트의 범위를 벗어난 인덱스 접근 때문에 발생합니다. 리스트의 길이를 확인하는 조건문을 추가하여 코드를 안전하게 수정하였습니다.
- 관찰: 모델 자체의 한국어 이해도가 높아 문맥에 맞는 정확한 답변을 생성합니다.

**코드 주석 한글화**

- 프롬프트: 다음 코드의 복잡한 로직을 한국어로 상세하게 주석으로 달아줘.
- 결과 예시: 입력받은 데이터를 정렬하는 과정입니다. 효율적인 검색하려고 이진 탐색 알고리즘을 적용했습니다.
- 관찰: 기술적인 용어와 일상적인 한국어 설명을 자연스럽게 혼용하여 출력합니다.

AI 모델이 한국어를 완벽하게 지원하므로 코딩 질문이나 코드 리뷰 요청 시 자연스러운 한국어 응답을 얻을 수 있습니다. 인터페이스는 영어로 제공되지만 실제 AI와의 상호작용에는 전혀 문제가 없습니다.

## 이런 분에게 추천합니다

여러 AI 코딩 도구를 동시에 사용하여 작업 효율을 높이고 싶은 개발자에게 추천합니다. 또한, 보안상의 이유로 로컬 환경에서 AI를 구동해야 하는 기업 실무자에게도 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 보안 정책상 외부 서버로 코드를 보낼 수 없을 때, 로컬 모델을 연결해 안전하게 코드 리뷰를 진행합니다.
- **학생**: 코딩 과제를 수행할 때 Claude와 같은 고성능 모델을 사용하다가, 간단한 수정은 로컬 모델로 전환하여 비용을 절감합니다.
- **소상공인**: 웹사이트 유지보수하려고 개발자를 따로 고용하지 않고, AI 모델로 간단한 코드 수정 작업을 직접 수행합니다.

## 유사 툴과 비교

**장점:**
- 다양한 모델을 하나의 인터페이스에서 관리 가능
- 로컬 모델 연동으로 보안성 확보

**단점:**
- 초기 설정 시 API 연결 등 기술적 이해도가 필요함

**이런 분에게 가장 적합합니다:** 여러 AI 모델을 상황에 맞춰 유연하게 교체하며 개발 생산성을 높이고 싶은 사용자에게 가장 적합합니다.

## 장단점

**장점**

- 다양한 AI 모델을 하나의 라우팅 계층으로 통합하여 관리할 수 있어 개발 작업의 효율성이 극대화됩니다.
- 로컬 모델과 클라우드 API를 유연하게 전환하며 사용할 수 있어 보안과 성능 사이의 균형을 유지할 수 있습니다.
- 특정 모델의 사용량 제한이 발생할 경우 자동으로 다음 모델로 전환되는 폴백 체인 기능을 제공합니다.
- 사용자의 API 키를 AES-256-GCM 방식으로 암호화하여 브라우저 내에서 안전하게 관리하므로 보안성이 뛰어납니다.

**단점**

- 도구의 인터페이스가 영어로만 구성되어 있어 한국어 사용자에게는 초기 설정 시 진입 장벽이 느껴질 수 있습니다.
- 터미널 기반의 조작이 주를 이루기 때문에 GUI 환경에 익숙한 사용자에게는 다소 생소할 수 있습니다.
- 고급 기능이나 대규모 사용량에 대한 유료 플랜의 세부 정보가 아직 구체적이지 않아 기업용 도입 시 검토가 필요합니다.

## 주의사항

- **개인정보**: API 키는 브라우저 내에서 암호화되어 관리되지만 민감한 프로젝트 정보가 AI 학습에 활용되지 않도록 모델별 설정에서 데이터 공유 옵션을 확인해야 합니다.
- **저작권/상업적 이용**: 생성된 코드의 저작권은 모델 공급사의 정책에 따라 다를 수 있으므로, 상업적 프로젝트에 적용 전 해당 모델의 약관을 확인하는 것이 좋습니다.
- **요금/한도**: 무료 플랜 이후 유료화될 경우 API 호출량에 따라 비용이 발생할 수 있으므로, 사용량을 주기적으로 모니터링하여 예산을 관리해야 합니다.
- **계정 관리**: 암호화된 키를 복구하기 위한 마스터 키가 별도로 존재하지 않으므로, 복구 문구(Recovery phrase)를 분실하지 않도록 각별히 유의해야 합니다.

## 자주 묻는 질문

**API 키가 없어도 바로 사용할 수 있나요?**

네, 기본적으로 추론 기능이 포함되어 있어 설치 후 바로 사용이 가능합니다. 다만 더 모델을 원할 경우 추후 API 키를 연결할 수 있습니다.

**개인 컴퓨터에서도 잘 돌아가나요?**

로컬 모델을 지원하므로 사양만 뒷받침된다면 개인 컴퓨터에서도 원활하게 작동합니다. 자신의 PC 사양에 맞는 모델을 선택하는 것이 중요합니다.

**기존에 쓰던 개발 툴과 연동되나요?**

네, 현재 사용 중인 다양한 개발 도구 및 환경과 매끄럽게 연결되도록 설계되었습니다. 별도의 복잡한 세팅 없이도 기존 워크플로우에 통합할 수 있습니다.

**기존에 사용하던 API 키를 그대로 쓸 수 있나요?**

네, 사용 중인 모든 API 키를 OpenLLM에 등록하여 통합 관리할 수 있습니다. 등록된 키는 안전하게 암호화되어 관리되므로 안심하고 사용하셔도 됩니다.

**인터넷 연결 없이 로컬에서만 사용할 수 있나요?**

로컬 모델을 사용한다면 외부 인터넷 연결 없이도 추론이 가능합니다. 다만, 클라우드 기반 모델을 호출할 때는 인터넷 연결이 필수적으로 요구됩니다.

**설정 중에 API 키를 분실하면 어떻게 되나요?**

마스터 키가 존재하지 않는 설계이므로 복구 문구를 잃어버리면 키를 다시 찾을 수 없습니다. 이 경우 설정을 초기화하고 키를 새로 등록해야 하니 주의가 필요합니다.

**어떤 개발 도구와 함께 사용하는 것이 가장 좋나요?**

Claude Code, Codex, Raycast 등 터미널이나 API 호출을 지원하는 모든 개발 도구와 호환됩니다. 본인의 작업 흐름에 맞춰 유연하게 연결하여 사용하십시오.
