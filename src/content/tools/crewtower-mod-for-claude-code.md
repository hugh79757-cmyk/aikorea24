## 한줄 요약

CrewTower는 맥북 사용자가 Claude Code나 Codex 같은 AI 코딩 에이전트를 편리하게 모니터링할 수 있는 맥 전용 앱입니다. 화면 전환 없이 노치 영역에서 바로 AI의 요청을 확인하고 승인할 수 있어 개발 작업의 집중도를 높여줍니다.

## 핵심 기능

- **노치 연동**: 맥북 노치에서 바로 AI 에이전트 상태를 확인합니다.
- **빠른 승인**: 터미널을 오가지 않고 클릭 한 번으로 명령을 승인합니다.
- **세션 점프**: 알림을 클릭하면 관련 터미널 창으로 즉시 이동합니다.

## 가격 정책

- **무료 플랜**: 무료 플랜은 제공되지 않으며 웹사이트에서 데모를 체험할 수 있습니다.
- **유료 플랜**: 1회성 평생 이용권 9.99달러(약 1만 4천 원)로 추가 구독료 없이 이용할 수 있습니다.

비용 절약 팁: 한 번 구매하면 맥북에서 지속적으로 AI 코딩 도구를 연동해 사용할 수 있습니다.

## 한국어 지원

앱 인터페이스는 영문으로 제공되지만 AI 에이전트가 처리하는 코드나 텍스트는 한국어 사용이 가능합니다.

## 이런 분에게 추천합니다

맥북을 사용하며 Claude Code나 Codex 등 AI 코딩 도구를 자주 활용하는 개발자
여러 개의 터미널과 에디터를 띄워두고 작업하여 화면 전환이 번거로운 직장인
AI 에이전트의 작업 상태를 놓치지 않고 실시간으로 관리하고 싶은 학생

## 실제 활용 예시

- **직장인**: 파이썬 자동화 스크립트를 작성하는 동안 맥북 노치에서 AI의 코드 승인 요청을 확인하고 즉시 처리합니다.
- **학생**: 프로그래밍 과제를 수행하면서 Claude Code가 제안하는 수정안을 노치 알림로 간편하게 검토합니다.
- **소상공인**: 1인 개발로 쇼핑몰 기능을 구현할 때 여러 AI 에이전트의 작업 진행 상황을 화면 전환 없이 모니터링합니다.

## 유사 툴과 비교

**장점:**
- 맥북 노치 디자인과 완벽하게 어우러지는 직관적인 UI
- 구독형이 아닌 합리적인 일회성 구매 가격

**단점:**
- 맥북 사용자만 이용 가능하며 윈도우 환경은 지원하지 않음

**이런 분에게 가장 적합합니다:** 맥북을 사용하며 평소 AI 코딩 에이전트를 자주 활용하는 개발자에게 가장 적합합니다.

## 자주 묻는 질문

**어떤 운영체제에서 사용할 수 있나요?**

이 앱은 맥OS 전용으로 개발되어 맥북의 노치 기능을 활용합니다. 윈도우나 리눅스 환경에서는 지원되지 않습니다.

**구독형인가요 아니면 평생 소장인가요?**

한 번 구매하면 추가 비용 없이 계속 사용하는 9.99달러의 1회성 구매 상품입니다.

**어떤 AI 코딩 도구와 연동할 수 있나요?**

Claude Code, Codex 및 기타 다양한 AI 코딩 에이전트와 터미널 기반 작업을 연동하여 사용할 수 있습니다.
