## 한줄 요약

StitchCraft는 복잡한 사진이나 간단한 텍스트 설명을 십자수 도안으로 즉시 변환해 주는 AI 서비스입니다. 직접 도안을 그릴 필요 없이 누구나 쉽게 나만의 자수 작품을 시작하는 데 도움이 되습니다.

## 핵심 기능

- **사진 도안 변환**: 좋아하는 사진을 업로드하면 십자수용 격자 도안으로 자동 변환합니다.
- **텍스트 기반 생성**: 원하는 그림을 글로 설명하면 AI가 그에 맞는 도안을 그려줍니다.
- **도안 최적화**: 실제 자수 작업이 가능하도록 색상과 패턴을 보기 좋게 정리해 줍니다.

## 가격 정책

- **무료 플랜**: 일부 기능을 무료로 체험하거나 기본 도안 생성이 가능합니다.
- **유료 플랜**: 구독형 플랜(월 약 15,000원~25,000원 수준)으로 무제한 도안 생성 및 고화질 출력을 지원합니다.

비용 절약 팁: 무료 체험로 본인의 작업 스타일에 적합한지 먼저 확인한 후 결제하는 것을 권장합니다.

## 한국어 지원

서비스 인터페이스는 영어로 제공되지만 텍스트 프롬프트는 번역기 등을 활용하여 입력하면 충분히 이용 가능합니다.

## 이런 분에게 추천합니다

취미로 십자수를 즐기시는 분, 세상에 하나뿐인 자수 선물을 만들고 싶은 분, 직접 도안을 그리기 어려운 초보자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 퇴근 후 취미로 십자수를 즐기며, 여행지에서 찍은 사진을 도안으로 만들어 액자로 장식합니다.
- **학생**: 친구의 생일을 맞아 좋아하는 캐릭터 사진을 도안으로 변환해 정성 가득한 수제 자수 선물을 만듭니다.
- **소상공인**: 공방을 운영하며 고객이 원하는 사진을 맞춤형 십자수 도안으로 제작해 주는 서비스를 제공합니다.

## 유사 툴과 비교

**장점:**
- 복잡한 도안을 수작업 없이 빠르게 생성
- 사진을 직접 변환할 수 있어 활용도가 높음

**단점:**
- 한국어 인터페이스 미지원
- 정교한 자수 기법까지는 구현이 어려울 수 있음

**이런 분에게 가장 적합합니다:** 사진을 기반으로 나만의 십자수 도안을 빠르게 얻고 싶은 분들에게 가장 적합합니다.

## 자주 묻는 질문

**십자수 도안을 출력해서 바로 사용할 수 있나요?**

네, 생성된 도안은 이미지 파일로 저장하여 출력한 뒤 실제 십자수 작업 시 가이드로 활용할 수 있습니다.

**사진의 화질이 결과물에 영향을 주나요?**

네, 사진의 화질이 좋을수록 AI가 색상과 형태를 더 정확하게 인식하여 도안의 퀄리티가 높아집니다.

**도안의 크기를 조절할 수 있나요?**

대부분의 도안 생성 툴에서 작업 범위를 설정할 수 있으므로, 원하는 작품 크기에 맞춰 조절이 가능합니다.
