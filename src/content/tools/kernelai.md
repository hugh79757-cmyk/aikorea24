## 한줄 요약

KernelAI는 스마트폰 자체에서 온디바이스로 동작하는 무료 AI 어시스턴트 앱입니다. 외부 서버로 데이터를 전송하지 않아 비행기 모드나 오프라인 상태에서도 안심하고 민감한 문서 분석 및 대화를 수행할 수 있습니다.

## 핵심 기능

- **오프라인 AI**: 인터넷 없이 스마트폰 단말기에서 완전히 동작합니다.
- **문서 분석**: PDF나 엑셀 파일을 서버 전송 없이 바로 분석합니다.
- **이미지 인식**: 영수증이나 메뉴판 사진을 찍어 한국어로 변환합니다.

## 사용법

**1. 모델 다운로드**

앱을 실행한 뒤 모델 카탈로그에서 기기 사양에 맞는 AI 모델을 선택하여 다운로드합니다. 모델별로 필요한 메모리 용량이 표시되므로 본인의 스마트폰 사양에 맞는 것을 고릅니다.

**2. 문서 파일 불러오기**

채팅창 하단의 파일 첨부 버튼을 눌러 PDF나 엑셀 문서를 업로드합니다. 데이터가 외부 서버로 전송되지 않으므로 보안이 필요한 문서를 안심하고 불러올 수 있습니다.

**3. 이미지 인식 활용**

카메라 아이콘을 눌러 영수증이나 메뉴판 등을 촬영합니다. 촬영된 사진 속 텍스트를 AI가 즉시 분석하여 내용을 요약하거나 한국어로 번역해 줍니다.

**4. 오프라인 대화 및 코딩**

비행기 모드 상태에서도 AI와 대화하거나 코딩 관련 질문을 할 수 있습니다. 코드 작성 시 문법 강조 기능이 포함되어 개발 업무를 효율적으로 보조합니다.

## 가격 정책

- **무료 플랜**: 계정 가입이나 구독 없이 53개 오픈소스 AI 모델을 무료로 다운로드하여 사용할 수 있습니다.
- **유료 플랜**: 별도의 유료 플랜이 없으며 모든 기능이 완전히 무료(0원)입니다.

비용 절약 팁: Wi-Fi 환경에서 필요한 AI 모델을 미리 다운로드해 두시면 데이터 비용을 절약할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 모든 기능이 완전 무료로 제공되며 메시지 제한이나 구독 모델이 존재하지 않습니다. 53개의 다양한 오픈소스 모델을 자유롭게 다운로드하여 사용할 수 있습니다.

- **무료 플랜** (0원): 모든 AI 모델 사용 및 오프라인 문서 분석 기능을 제한 없이 이용 가능합니다.

- **별도 유료 플랜 없음** (해당 없음): 구독형 서비스가 아니므로 추가 결제 없이 모든 기능을 평생 무료로 활용할 수 있습니다.

**환불과 해지**: 별도의 결제 시스템이 없으므로 환불이나 해지 절차가 필요하지 않습니다.

## 한국어 지원

한국어 인터페이스를 지원하며 한국어 성능이 뛰어난 오픈 모델을 선택하면 자연스러운 한국어 대화 및 문서 분석이 가능합니다.

## 한국어 품질 실측

**비밀 문서 요약**

- 프롬프트: 첨부된 기밀 프로젝트 보고서의 핵심 내용을 3줄로 요약해 줘.
- 결과 예시: 보고서의 주요 목적은 비용 절감이며, 3분기 내에 자동화 시스템을 도입하는 것이 핵심입니다. 또한 보안 유지 방침에 따라 데이터는 외부 유출 없이 내부망에서만 관리됩니다.
- 관찰: 한국어 문장 구조가 자연스럽고 핵심 요약 능력이 우수합니다.

**영수증 텍스트 추출**

- 프롬프트: 이 영수증 사진에서 결제 금액과 품목만 한국어로 정리해 줘.
- 결과 예시: 결제 품목은 사무용품 3종이며, 총 결제 금액은 45,000원입니다. 세부 내역은 영수증 하단에 기재된 항목을 기준으로 분류하였습니다.
- 관찰: 이미지 내 텍스트 인식률이 높고 한국어 번역이 정확합니다.

한국어 학습 모델을 선택할 경우 매우 자연스러운 대화가 가능합니다. 번역투가 거의 없으며, 전문 용어 처리도 준수하여 비즈니스 문서 분석에 적합합니다.

## 이런 분에게 추천합니다

대외비 보안 문서 유출을 엄격히 금지하는 기업의 직장인에게 추천합니다. 인터넷 연결이 불안정한 해외 출장이나 이동이 잦은 비즈니스맨에게 유용합니다. 개인정보 및 아이디어의 외부 유출을 원치 않는 창업가에게 적합합니다.

## 실제 활용 예시

- **직장인**: 보안이 중요한 사내 대외비 PDF 보고서를 오프라인 상태에서 앱에 첨부합니다. 외부 서버 업로드 없이 안전하게 핵심 내용과 시사점을 요약받아 보고서 초안을 작성합니다.
- **학생**: 데이터가 부족하거나 Wi-Fi가 없는 도서관에서 다운로드받은 논문 PDF를 분석합니다. 네트워크 연결 없이도 어려운 개념를 질문하고 설명을 들으며 학습합니다.
- **소상공인**: 해외 직구 물품의 설명서나 종이 영수증을 카메라로 촬영합니다. 오프라인 상태에서도 이미지 속 텍스트를 정확히 인식하여 한글 번역 및 정산 내역을 확인합니다.

## 유사 툴과 비교

**장점:**
- 서버로 데이터가 전송되지 않아 완벽한 개인정보 보안을 제공합니다.
- 구독료나 계정 가입 없이 온전히 무료로 사용할 수 있습니다.

**단점:**
- 스마트폰 하드웨어 성능에 따라 답변 생성 속도가 달라질 수 있습니다.

**이런 분에게 가장 적합합니다:** 인터넷이 없는 환경이거나 대외비 문서 보안이 최우선인 상황에 가장 적합합니다.

## 장단점

**장점**

- 인터넷 연결이 전혀 없는 환경에서도 모든 AI 기능을 완벽하게 사용할 수 있어 보안성이 매우 높습니다.
- 계정 가입이나 구독 절차 없이 앱 설치 후 즉시 사용 가능하여 개인정보 노출 위험이 전혀 없습니다.
- 스마트폰 기기 사양에 맞춰 실행 가능한 모델을 미리 알려주어 오류 없는 안정적인 사용이 가능합니다.
- PDF, 엑셀 등 다양한 문서 형식을 직접 분석하고 요약할 수 있어 직장인 업무 효율을 크게 높여줍니다.

**단점**

- 스마트폰의 하드웨어 사양에 따라 사용하는 AI 모델의 크기와 성능이 제한될 수 있습니다.
- 데이터를 직접 다운로드해야 하므로 초기 설정 시 Wi-Fi 환경이 반드시 필요하며 저장 공간을 차지합니다.
- 클라우드 기반 AI 서비스에 비해 복잡하거나 거대한 연산을 처리할 때 속도가 다소 느릴 수 있습니다.

## 주의사항

- **개인정보**: 모든 데이터가 기기 내에서 처리되므로 외부 유출은 없으나 기기 분실 시 정보 보호에 각별히 유의해야 합니다.
- **저작권/상업적 이용**: 사용하는 모델의 라이선스에 따라 상업적 이용 범위가 다를 수 있으므로 오픈소스 모델별 정책을 확인해야 합니다.
- **요금/한도**: 현재 모든 기능이 무료이나 모델 다운로드 시 발생하는 데이터 사용료는 통신사 요금제에 따라 상이할 수 있습니다.
- **계정 관리**: 별도의 계정 시스템이 없으므로 앱 삭제 시 기존 대화 내용이나 다운로드한 모델 데이터가 모두 초기화됩니다.

## 자주 묻는 질문

**인터넷 연결이 정말 전혀 필요 없나요?**

네, 처음에 AI 모델을 다운로드할 때를 제외하면 모든 대화와 문서 분석이 스마트폰 내부에서 처리되므로 비행기 모드에서도 완벽히 작동합니다.

**스마트폰 저장 용량을 많이 차지하나요?**

모델 크기에 따라 112MB부터 3.11GB까지 다양합니다. 스마트폰 저장 공간에 맞춰 적절한 용량의 모델을 선택하여 다운로드하시면 됩니다.

**ChatGPT 같은 클라우드 AI보다 성능이 떨어지나요?**

초대형 클라우드 AI에 비해 복잡한 추론은 제한적일 수 있지만 문서 요약, 텍스트 추출, 일반적인 질의응답 등의 업무에는 충분히 뛰어난 성능을 발휘합니다.

**비행기 모드에서도 모든 기능을 쓸 수 있나요?**

네, 모델을 한 번 다운로드해 두면 인터넷 연결 없이도 문서 분석, 이미지 인식, 대화 기능을 모두 사용할 수 있습니다.

**제 스마트폰에서 모델이 돌아가는지 어떻게 알죠?**

앱 내에서 기기의 RAM 용량을 자동으로 측정하여, 실행 가능한 모델과 불가능한 모델을 구분해 표시해 줍니다.

**웹 검색 기능을 사용하려면 어떻게 해야 하나요?**

기본적으로는 오프라인 전용이지만, 사용자가 직접 API 키를 입력하면 선택적으로 웹 검색 기능을 활성화할 수 있습니다.

**데이터가 정말로 외부로 나가지 않나요?**

네, 모든 연산은 스마트폰의 CPU와 GPU를 통해 로컬에서 수행되므로 데이터가 서버로 전송되는 일은 없습니다.
