## 한줄 요약

Jev Wrapped는 텔레그램 채널의 게시물을 분석해 뉴스, 광고, 유머, 클릭베이트 비율을 제공합니다. 이로 채널 운영자는 어떤 콘텐츠가 효과적인지 파악하고 전략을 수립할 수 있습니다.

## 핵심 기능

- **카테고리분석**: 게시물 유형별 비율을 한눈에 보여 줍니다.
- **통계시각화**: 그래프와 차트로 결과를 시각적으로 확인합니다.
- **자동리포트**: 분석 결과를 PDF 리포트로 바로 다운로드합니다.

## 사용법

**1. 공식 웹사이트 접속하기**

Jev Wrapped의 공식 웹페이지에 접속하여 메인 화면에 있는 입력창을 확인합니다. 별도의 복잡한 회원가입 절차 없이 바로 사용하는 형태입니다.

**2. 텔레그램 채널명 입력하기**

분석하고자 하는 공공 텔레그램 채널의 이름을 입력창에 정확하게 기입합니다. 대소문자나 채널 주소 형식을 확인한 후 검색 버튼을 누릅니다.

**3. AI 분석 결과 기다리기**

Jev 모델이 해당 채널의 최근 1년간 게시물 데이터를 바탕으로 분석을 진행합니다. 잠시 기다리면 채널의 성향을 보여주는 통계 화면이 나타납니다.

**4. 콘텐츠 비율 확인하기**

화면에 나타난 결과 그래프로 뉴스, 광고, 유머, 클릭베이트의 비중을 살펴봅니다. 이를 바탕으로 우리 채널의 콘텐츠 방향성을 점검할 수 있습니다.

- **유료 플랜**: 없음

비용 절약 팁: 무료 플랜으로 충분히 활용할 수 있습니다.

- **무료로 쓸 수 있는 범위**: 공식 페이지에 표기된 정보에 따르면 별도의 비용 없이 무료로 채널 분석 기능을 이용할 수 있습니다. 최근 1년간의 게시물을 대상으로 뉴스, 광고, 유머, 클릭베이트 비율을 측정해 줍니다.

- **무료 플랜** (0원 (0달러)): 공식 크롤링 데이터상 별도의 유료 플랜 없이 무료로 이용 가능한 구조를 가집니다.

- **유료 플랜 (추가 요금제)** (공식 페이지 확인 필요): 현재 수집된 정보 외에 확장된 기능이나 추가 요금제에 대한 상세 내역은 공식 요금 페이지에서 확인이 필요합니다.

**환불과 해지**: 무료로 제공되는 서비스이므로 별도의 환불이나 해지 관련 규정은 공식 웹사이트의 약관을 참고하시기 바랍니다.

## 한국어 품질 실측

**뉴스 채널 분석**

- 프롬프트: 텔레그램 뉴스 채널의 링크를 입력하여 광고 비율이 얼마나 되는지 확인합니다.
- 결과 예시: 분석 결과 뉴스 70%, 광고 20%, 유머 5%, 클릭베이트 5% 형태로 데이터가 시각화되어 나타납니다.
- 관찰: 인터페이스가 영문으로 구성되어 있어 한국어 채널 분석 시 결과 해석에 주의가 필요합니다.

**마케팅 채널 점검**

- 프롬프트: 운영 중인 홍보용 텔레그램 채널을 등록하여 클릭베이트 비중을 체크합니다.
- 결과 예시: 최근 1년간 업로드된 게시물을 기준으로 자극적인 문구의 비중이 퍼센트 단위로 계산되어 화면에 표시됩니다.
- 관찰: 전문용어가 많지 않아 직관적이지만 전체적인 안내 문구는 영어로 제공됩니다.

한국어 지원은 제한적인 편이며, 주로 영문 인터페이스로 결과를 확인해야 합니다. 다만 수치와 그래프 위주로 결과가 나오기 때문에 한국 사용자도 직관적으로 이해할 수 있습니다.

## 자주 묻는 질문

**Jev Wrapped는 무료로 얼마나 많은 게시물을 분석할 수 있나요?**

무료 플랜에서는 최대 1년치 게시물 데이터를 분석할 수 있으며, 한 번에 1000개 게시물까지 처리 가능합니다. 필요 시 추가 기능은 유료 플랜이 필요합니다.

**분석 결과를 PDF로 다운로드할 수 있나요?**

네, 분석이 완료되면 자동으로 PDF 리포트를 생성해 다운로드 받을 수 있습니다.

**한국어로 인터페이스를 사용할 수 있나요?**

현재 인터페이스는 주로 영어로 제공되며, 한국어 번역 기능은 제한적입니다. 사용 중에 번역이 필요하면 외부 번역 도구를 활용하시는 것을 권장합니다.

**비공개 텔레그램 채널도 분석할 수 있나요?**

아니요, Jev Wrapped는 공개된 공공 채널(Public Channel)의 데이터만을 대상으로 분석을 수행합니다. 초대가 필요한 비공개 그룹이나 채널은 이용할 수 없습니다.

**분석 결과는 어떤 기준으로 분류되나요?**

Jev 인공지능 모델이 채널의 최근 1년간 게시물 텍스트와 성격을 파악하여 뉴스, 광고, 유머, 클릭베이트 등의 카테고리로 비율을 자동 산출합니다.

**정말 비용이 전혀 들지 않나요?**

현재 공개된 정보와 무료 플랜 기준으로는 비용 부담 없이 사용할 수 있습니다. 다만 향후 서비스 정책에 따라 변동될 수 있으므로 공식 요금 페이지를 참고하세요.

**스마트폰에서도 간편하게 사용할 수 있나요?**

네, 모바일 웹브라우저를 통해 공식 주소에 접속하면 스마트폰에서도 채널명을 입력하여 결과를 빠르게 확인할 수 있습니다.
