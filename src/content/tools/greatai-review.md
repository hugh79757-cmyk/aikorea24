## 한줄 요약

Greatai Review는 오픈소스 프로젝트와 비영리 단체하려고 AI 기술과 실제 사람의 검토를 결합한 코드 리뷰 서비스입니다. 단순히 기계적인 분석을 넘어 사람의 관점까지 반영하여 코드의 품질을 높이고 유지보수를 돕습니다.

## 핵심 기능

- **AI 코드 분석**: AI가 코드의 오류와 개선점을 즉시 파악해 시간을 절약합니다.
- **전문가 검토**: 사람이 직접 코드를 확인하여 더 정교한 피드백을 제공합니다.
- **무료 서비스**: 오픈소스와 비영리 목적이라면 비용 부담 없이 이용 가능합니다.

## 사용법

**1. 서비스 계정 연동하기**

공식 웹사이트에 접속하여 GitHub 또는 GitLab 계정을 연동합니다. 프로젝트 저장소를 선택하면 AI가 분석을 시작할 준비가 완료됩니다.

**2. 분석 요청 생성하기**

대시보드에서 분석할 리포지토리를 선택하고 'Review' 버튼을 클릭합니다. 코드 변경 사항이 포함된 풀 리퀘스트(PR)를 제출하면 AI가 자동으로 검토를 수행합니다.

**3. AI 코드 리뷰 확인**

AI가 제시한 코드 수정 제안과 개선 사항을 대시보드에서 확인합니다. 코드의 가독성이나 성능을 높일 수 있는 구체적인 가이드를 검토합니다.

**4. 전문가 검토 요청**

AI 분석 후 추가적인 정밀 검토가 필요한 경우 전문가 리뷰를 요청합니다. 사람이 직접 코드의 논리적 결함을 확인하고 상세한 피드백을 남겨줍니다.

## 가격 정책

- **무료 플랜**: 오픈소스 및 비영리 프로젝트를 대상으로 모든 기능을 무료로 제공합니다.
- **유료 플랜**: 별도의 유료 플랜은 없으며, 공익적 목적의 프로젝트를 지원하는 데 집중하고 있습니다.

비용 절약 팁: 오픈소스 라이선스를 준수하는 프로젝트라면 비용 걱정 없이 무제한으로 활용할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈소스 및 비영리 프로젝트라면 모든 기능을 무료로 제한 없이 이용할 수 있습니다. 별도의 크레딧 제한 없이 커뮤니티 기여를 목적으로 하는 코드에 집중합니다.

- **오픈소스 무료 플랜** (무료): 오픈소스 라이선스를 준수하는 모든 프로젝트를 AI 분석과 전문가 검토를 무제한 제공합니다.

- **비영리 프로젝트 플랜** (무료): 공익을 목적으로 운영되는 비영리 단체의 프로젝트라면 비용 부담 없이 모든 기능을 활용합니다.

- **상업용 플랜** (공식 페이지 확인 필요): 상업적 프로젝트에 대한 지원 여부와 유료 정책은 공식 홈페이지의 요금 안내 페이지에서 확인이 필요합니다.

**환불과 해지**: 무료 서비스 위주로 운영되므로 별도의 환불 규정은 존재하지 않으며, 이용 중 문제가 발생하면 고객 지원 센터에 문의해야 합니다.

## 한국어 지원

서비스 인터페이스와 피드백은 영어로 제공됩니다. 다만, 코드 자체는 언어와 무관하므로 개발 환경에서 사용하는 데 큰 지장은 없습니다.

## 한국어 품질 실측

**코드 설명 요청**

- 프롬프트: 이 파이썬 코드의 논리적 오류를 찾아서 한국어로 설명해줘.
- 결과 예시: AI는 영어로 응답하며 코드의 버그를 지적합니다. 한국어 질문을 던져도 응답은 영어로 출력될 가능성이 높습니다.
- 관찰: 한국어 질문를 영어로 답변하는 번역투의 한계가 명확하게 나타납니다.

**리뷰 결과 해석**

- 프롬프트: 이 리뷰 내용을 한국어로 요약해줄 수 있어?
- 결과 예시: AI가 영어로 작성된 리뷰를 한국어로 번역하여 요약합니다. 다만 전문 용어는 영어 그대로 유지될 수 있습니다.
- 관찰: 번역 기능은 제공되지만 문맥이 다소 어색할 수 있으므로 주의가 필요합니다.

한국어 인터페이스를 지원하지 않아 모든 결과가 영어로 출력됩니다. 코드 자체는 언어와 무관하지만 상세한 피드백을 이해하려면 영어 독해 능력이 다소 요구됩니다.

## 이런 분에게 추천합니다

오픈소스 프로젝트를 운영하며 코드 퀄리티를 높이고 싶은 개발자에게 추천합니다. 비영리 단체에서 개발 비용을 절감하며 안정적인 서비스를 운영하고자 하는 분께 적합합니다.

## 실제 활용 예시

- **직장인**: 사내 오픈소스 프로젝트를 진행할 때, 코드 리뷰 시간을 줄이기 위해 AI의 1차 검토를 활용합니다. 이후 사람이 최종 확인하여 업무 효율을 높입니다.
- **학생**: 개인적인 코딩 프로젝트를 오픈소스로 공개할 때, 다른 개발자들에게 좋은 코드를 보여주기 위해 리뷰를 받습니다. 이로 프로그래밍 실력을 빠르게 향상합니다.
- **소상공인**: 소규모 비영리 웹 서비스를 운영할 때, 외부 개발자의 도움 없이도 코드의 보안 문제를 점검받아 안전하게 관리합니다.

## 유사 툴과 비교

**장점:**
- 사람의 검토가 포함되어 AI보다 정확도가 높음
- 오픈소스 프로젝트에 특화된 무료 정책

**단점:**
- 상업적 프로젝트에는 활용이 제한적임
- 한국어 지원이 부족함

**이런 분에게 가장 적합합니다:** 무료로 코드 품질을 높이고 싶은 오픈소스 메인테이너에게 가장 적합합니다.

## 장단점

**장점**

- 오픈소스 프로젝트를 운영하는 개발자라면 비용 부담 없이 수준 높은 코드 리뷰를 무제한으로 받을 수 있습니다.
- AI의 자동화된 분석과 실제 전문가의 수동 검토가 결합되어 코드의 품질을 정교하게 관리할 수 있습니다.
- GitHub 및 GitLab과 같은 주요 개발 플랫폼과 원활하게 연동되어 워크플로우를 방해하지 않고 이용 가능합니다.
- 비영리 및 공익적 목적의 프로젝트를 적극적으로 지원하여 개발 커뮤니티의 성장에 큰 도움을 줍니다.

**단점**

- 한국어를 공식적으로 지원하지 않아 모든 피드백과 인터페이스가 영어로 제공되는 불편함이 있습니다.
- 상업적 프로젝트에 대한 명확한 요금 정보가 부족하여 기업용으로 도입하기에는 다소 불확실한 부분이 있습니다.
- 전문가 검토 과정에서 사람이 직접 개입하기 때문에 AI 분석보다는 결과 도출까지 시간이 더 소요될 수 있습니다.

## 주의사항

- **개인정보**: 코드 내에 포함된 민감한 API 키나 개인 정보가 서버로 전송될 수 있으니 반드시 환경 변수 처리를 확인해야 합니다.
- **저작권/상업적 이용**: 상업적 프로젝트에 사용할 경우 라이선스 정책 위반 여부를 공식 홈페이지에서 반드시 확인해야 합니다.
- **요금/한도**: 무료 정책은 오픈소스 프로젝트에 한정되어 있으므로, 추후 정책 변경 가능성을 항상 염두에 두어야 합니다.
- **계정 관리**: GitHub 계정 연동 시 제공하는 권한 범위를 확인하고 불필요한 저장소 접근 권한은 부여하지 않는 것이 안전합니다.

## 자주 묻는 질문

**누구나 무료로 사용할 수 있나요?**

오픈소스 프로젝트나 비영리 단체 활동을 위한 경우에 한해 무료로 제공됩니다. 상업적인 용도로 사용하려면 운영 정책을 확인해야 합니다.

**AI가 코드를 어떻게 리뷰하나요?**

AI가 먼저 코드의 문법적 오류와 보안 취약점을 스캔하고 이후 사람의 검토를 거쳐 더 깊이 있는 피드백을 전달하는 하이브리드 방식입니다.

**한국어로 피드백을 받을 수 있나요?**

현재 서비스의 주요 언어는 영어입니다. 코드 리뷰 피드백 역시 영어로 제공되므로, 번역 도구를 함께 활용하는 것을 권장합니다.

**상업용 프로젝트에서도 무료로 쓸 수 있나요?**

본 서비스는 오픈소스 및 비영리 프로젝트를 지원 대상으로 합니다. 상업적 목적의 프로젝트라면 별도의 문의가 필요합니다.

**전문가 검토는 누가 진행하나요?**

해당 분야의 숙련된 개발자들이 커뮤니티 기여 차원에서 검토를 진행합니다. 다만 정확한 인력 구성은 공개되지 않았습니다.

**한국어 피드백을 받을 방법이 있나요?**

현재는 공식적으로 한국어를 지원하지 않습니다. 번역기를 활용하거나 영어로 소통해야 원활한 리뷰가 가능합니다.

**개인 프로젝트도 오픈소스로 등록하면 되나요?**

프로젝트가 오픈소스 라이선스를 갖추고 공개되어 있다면 등록 가능합니다. 비공개 저장소는 지원 범위에서 제외될 수 있습니다.
