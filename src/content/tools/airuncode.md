## 한줄 요약

Airuncode는 개인 컴퓨터 환경에서 직접 작동하는 AI 코딩 도구입니다. 외부 서버를 거치지 않아 보안이 뛰어나며, 음성 명령로 복잡한 코딩 작업을 효율적으로 수행하는 데 도움이 되습니다.

## 핵심 기능

- **로컬 실행**: 데이터가 외부로 유출되지 않아 기업용 보안 코드 작업에 안심입니다.
- **음성 제어**: 복잡한 타이핑 없이 말로 코드를 수정하고 명령을 내릴 수 있습니다.
- **비용 효율성**: AI 모델을 원가 수준으로 사용하여 대규모 개발 작업 시 비용이 절감됩니다.

## 가격 정책

- **무료 플랜**: 현재 초기 단계로 제품 웹사이트로 무료 체험 및 로컬 설치가 가능합니다.
- **유료 플랜**: 공식적인 유료 플랜은 추후 업데이트 예정이며, 사용량에 따른 합리적인 비용 체계를 지향합니다.

비용 절약 팁: 로컬에서 직접 모델을 구동하면 API 호출 비용을 획기적으로 줄일 수 있습니다.

## 한국어 지원

현재 인터페이스는 영어로 제공되나, AI 모델이 한국어 명령을 이해하고 한국어 주석이 포함된 코드를 작성할 수 있습니다.

## 이런 분에게 추천합니다

보안이 중요한 기업의 개발자에게 추천합니다. 외부 서버에 코드를 올리기 꺼려지는 개인 개발자에게 적합합니다. 음성을 활용해 생산성을 높이고 싶은 개발자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 사내 보안 정책상 클라우드 AI 사용이 어려운 경우, 로컬에서 안전하게 코드를 작성합니다. 음성 명령으로 반복적인 코드 수정 작업을 빠르게 처리합니다.
- **학생**: 코딩 과제를 수행할 때 로컬 환경에서 AI 도움을 받아 복잡한 알고리즘을 구현합니다. 오류 발생 시 즉각적인 디버깅 도움을 받아 학습 효율을 높입니다.
- **소상공인**: 직접 웹사이트를 관리할 때, 복잡한 코딩 지식 없이도 음성으로 필요한 기능을 추가합니다. 외부 개발자 없이도 간단한 웹 수정 작업을 스스로 해결합니다.

## 유사 툴과 비교

**장점:**
- 데이터 보안이 매우 뛰어남
- API 호출 비용을 원가 수준으로 절감

**단점:**
- 사용자의 로컬 컴퓨터 사양에 따라 속도 차이가 발생함

**이런 분에게 가장 적합합니다:** 보안이 중요한 환경에서 AI 코딩 에이전트를 활용하고자 하는 사용자에게 가장 적합합니다.

## 자주 묻는 질문

**컴퓨터 사양이 좋아야 하나요?**

로컬에서 모델을 직접 구동하므로 그래픽 카드(GPU) 사양이 좋을수록 더 빠르고 쾌적한 작업이 가능합니다. 낮은 사양에서는 일부 기능이 제한될 수 있습니다.

**한국어로 코딩 명령을 내려도 되나요?**

네, AI 모델이 한국어 명령을 인식할 수 있습니다. 다만, 코드 자체는 프로그래밍 언어 규칙을 따르며 주석이나 설명은 한국어로 요청 가능합니다.

**데이터가 정말 외부로 나가지 않나요?**

네, Airuncode는 로컬 우선(Local-first) 철학을 따릅니다. 사용자의 코드와 데이터가 기기 내에서 처리되므로 보안성이 매우 높습니다.
