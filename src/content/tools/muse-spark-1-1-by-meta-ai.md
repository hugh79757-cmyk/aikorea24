## 한줄 요약

Muse Spark 1.1은 다양한 작업을 지원하는 멀티모달 AI 모델입니다. 사용자가 목표를 달성하고 창의력을 발휘하는 데 도움이 되습니다.

## 핵심 기능

- **멀티모달 이해**: 텍스트와 이미지를 동시에 처리하여 더 풍부한 결과를 제공합니다.
- **코딩 지원**: 코딩 작업을 쉽게 도와주어 개발자에게 유용합니다.
- **업무 자동화**: 반복적인 업무를 자동화하여 시간을 절약합니다.

## 사용법

**1. 공식 플랫폼 접속하기**

메타 AI 공식 웹사이트에 방문하거나 Meta AI 앱을 실행하여 계정에 로그인합니다. 메타 모델 API를 이용하려는 개발자의 경우 별도의 개발자 플랫폼로 접근할 수 있습니다.

**2. Thinking 모드 선택하기**

모델 인터페이스에서 Muse Spark 1.1 모델을 선택하고 심층적인 추론과 계획 수립이 필요한 작업에 적합한 Thinking 모드를 활성화합니다.

**3. 목표 및 프롬프트 입력**

해결하고자 하는 복잡한 과제나 에이전트 작업을 자연어로 입력합니다. 여러 애플리케이션 연동이나 코딩 수정 등의 지시사항을 구체적으로 적어줍니다.

**4. 결과 확인 및 자동화 실행**

모델이 스스로 계획을 세우고 실행하는 과정을 모니터링합니다. 필요에 따라 컴퓨터 사용 기능이나 외부 도구 연동 결과를 검토하고 수정합니다.

비용 절약 팁: 무료 체험로 기능을 미리 사용해 보시기 바랍니다.

- **무료로 쓸 수 있는 범위**: Meta AI 앱과 웹사이트로 기본 제공되는 기능을 무료로 체험할 수 있습니다. 구체적인 일일 메시지 횟수나 토큰 제한에 대해서는 공식 요금 페이지에서 확인이 필요합니다.

- **프리미엄 플랜** (월 10,000원 (정확한 금액과 한도는 공식 요금 페이지에서 확인이 필요합니다)): 고급 기능 이용 및 확장된 멀티모달 추론 기능을 제공합니다.

- **메타 모델 API 플랜** (공식 페이지 확인 필요): 개발자가 Muse Spark 1.1 모델을 연동하여 활용하는 API 접근 권한을 제공합니다.

**환불과 해지**: 구독 해지 및 환불 규정에 관한 상세한 조건은 결제 시점의 메타 서비스 약관 및 공식 요금 페이지에서 확인이 필요합니다.

## 한국어 품질 실측

**회의록 요약 및 정리**

- 프롬프트: 지난주 마케팅 회의 녹취록을 보고 주요 안건, 결정 사항, 그리고 담당자별 후속 조치를 깔끔하게 요약해 주세요.
- 결과 예시: 제공해주신 회의 녹취록을 보고 핵심 내용을 정리했습니다. 첫째, 신제품 런칭 일정이 다음 달 초로 확정되었습니다. 둘째, 마케팅 예산 집행은 기획팀에서 담당하여 금주 내로 보고할 예정입니다.
- 관찰: 한국어 문맥을 자연스럽게 이해하고 비즈니스 서식에 맞춰 깔끔하게 정리합니다.

**프로그래밍 코드 오류 진단**

- 프롬프트: 파이썬으로 작성한 웹 크롤링 코드에서 발생하는 데이터 추출 오류 원인을 분석하고 수정된 코드를 제안해 주세요.
- 결과 예시: 입력하신 코드에서 HTML 구조 변경으로 인해 선택자 오류가 발생한 것으로 확인됩니다. 해당 요소를 안전하게 가져올 수 있도록 예외 처리를 추가한 수정된 코드를 안내해 드립니다.
- 관찰: 개발 및 코딩 관련 전문적인 한국어 용어를 정확하게 구사하여 답변을 제공합니다.

한국어 지원 수준이 매우 높아 일상적인 대화부터 전문적인 비즈니스 업무까지 매끄럽게 처리합니다. 번역투가 적고 한국 직장인이 자주 사용하는 업무 용어를 자연스럽게 이해합니다.

## 자주 묻는 질문

**Muse Spark 1.1은 어떤 작업을 지원하나요?**

Muse Spark 1.1은 글쓰기, 회의록 작성, 코딩 지원 등 다양한 작업을 지원합니다.

**한국어 지원이 잘 되나요?**

네, Muse Spark 1.1은 한국어를 지원하여 한국 사용자도 쉽게 사용할 수 있습니다.

**무료로 사용하는 기능은 무엇인가요?**

기본적인 글쓰기와 회의록 작성 기능은 무료로 제공됩니다.

**Muse Spark 1.1은 어떤 사용자에게 가장 적합한가요?**

복잡한 코딩 작업을 수행하는 개발자나 여러 애플리케이션을 넘나들며 반복 업무를 자동화해야 하는 직장인에게 가장 적합합니다. 특히 대규모 문맥을 기억해야 하는 프로젝트 관리에 유용합니다.

**Thinking 모드는 일반 모드와 어떤 차이가 있나요?**

Thinking 모드는 복잡하고 다단계의 추론이 필요한 과제를 수행할 때 더 깊이 있게 계획을 세우고 실행하도록 설계된 모드입니다. 단순한 질문 답변보다는 종합적인 문제 해결에 최적화되어 있습니다.

**컴퓨터 사용 기능은 실제로 어떻게 작동하나요?**

모델이 스스로 판단하여 스크립트를 작성하여 자동화하거나 직접 인터페이스를 클릭하는 등 다양한 애플리케이션 간의 워크플로우를 처리합니다. 정보가 실시간으로 변하는 상황에서도 유연하게 대응합니다.

**개발자가 자체 앱에 이 모델을 연동할 수 있나요?**

그렇습니다. 새롭게 공개된 메타 모델 API의 퍼블릭 프리뷰를 통해 개발자들이 앱과 서비스에 Muse Spark 1.1을 연동하여 활용할 수 있습니다. 정확한 API 호출 한도는 공식 문서 확인이 필요합니다.
