## 한줄 요약

Pair2FA는 기업이나 팀이 공용으로 사용하는 계정의 2단계 인증(2FA) 코드를 안전하게 공유하는 데 도움이 되는 보안 협업 툴입니다. 담당자가 자리를 비워도 팀원들이 필요한 인증 코드를 안전하게 확인할 수 있어 업무 공백을 막아줍니다.

## 핵심 기능

- **안전한 암호화**: AES-256-GCM 방식을 사용하여 민감한 인증 정보를 안전하게 보관합니다.
- **세밀한 권한**: 팀원별로 필요한 계정의 접근 권한을 관리자가 직접 제어할 수 있습니다.
- **간편한 공유**: 대기 시간 없이 팀원 간에 빠르게 인증 코드를 공유하여 업무 효율을 높입니다.

## 사용법

**1. 계정 추가 및 QR 등록**

대시보드에서 'Add Account'를 클릭합니다. 인증 앱의 QR 코드를 카메라로 스캔하거나, 수동으로 비밀 키를 입력하여 계정을 등록합니다.

**2. 팀원 초대 및 권한 설정**

팀원 이메일 주소를 입력하고 'Viewer' 또는 'Admin' 권한을 부여합니다. 초대장을 발송하면 팀원이 수락하여 협업을 시작할 수 있습니다.

**3. 인증 코드 공유 및 복사**

등록된 계정 목록에서 실시간으로 변하는 30초 단위 인증 코드를 확인합니다. 우측의 'Copy' 버튼을 눌러 간편하게 코드를 클립보드에 복사합니다.

**4. 권한 관리 및 접근 제어**

설정 메뉴에서 특정 팀원의 접근 권한을 수정하거나 삭제할 수 있습니다. 보안하려고 퇴사한 팀원의 접근 권한을 즉시 회수하는 것이 가능합니다.

## 가격 정책

- **무료 플랜**: 기본적인 팀 코드 공유 기능을 무료로 시작할 수 있습니다.
- **유료 플랜**: 프로 플랜은 월 15,000원(예상)부터 시작하며 고급 권한 관리와 무제한 팀원 기능을 제공합니다.

비용 절약 팁: 소규모 팀이라면 무료 플랜부터 시작하여 점진적으로 유료 전환을 검토하는 것이 좋습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 플랜은 2명의 팀원과 3개의 계정까지 이용할 수 있습니다. 신용카드 등록 없이 즉시 시작 가능하며 기본 공유 기능을 모두 사용할 수 있습니다.

- **Pro Plan** (월 15,000원(예상)부터 시작): 고급 권한 관리 기능을 제공하며 무제한 팀원 추가 및 계정 등록이 가능합니다. 정확한 금액과 한도는 공식 요금 페이지에서 확인이 필요합니다.

**환불과 해지**: 결제 및 환불 정책은 공식 홈페이지의 요금 페이지로 확인해야 합니다. 구독 해지 시 다음 결제 주기부터 요금이 청구되지 않습니다.

## 한국어 지원

인터페이스는 영어로 제공되지만 직관적인 대시보드 구조를 가지고 있어 영어 울렁증이 있는 사용자도 쉽게 적응할 수 있습니다.

## 한국어 품질 실측

**AWS 서버 접속**

- 프롬프트: AWS 관리 콘솔에 로그인하기 위해 Pair2FA에서 생성된 인증 코드를 복사합니다.
- 결과 예시: Pair2FA 대시보드에서 'AWS Cloud Infrastructure' 항목의 'Copy' 버튼을 누릅니다. 복사된 6자리 숫자를 AWS 로그인 화면의 인증 번호 입력란에 붙여넣습니다.
- 관찰: 인터페이스는 영어지만 숫자 복사 위주의 도구라 한국어 사용에 큰 불편함이 없습니다.

**팀원 권한 부여**

- 프롬프트: 새로 입사한 팀원에게 GitHub 개발 계정 접근 권한을 부여합니다.
- 결과 예시: Add teammate 메뉴에서 팀원의 이메일을 입력하고 'Viewer' 권한을 선택합니다. 초대가 완료되면 팀원은 자신의 계정으로 로그인하여 GitHub 인증 코드를 볼 수 있습니다.
- 관찰: 메뉴가 직관적인 영어 단어로 구성되어 있어 초보자도 쉽게 기능을 이해할 수 있습니다.

한국어를 공식 지원하지 않으나, 인터페이스가 매우 단순하여 영어 울렁증이 있는 사용자도 쉽게 적응할 수 있습니다. 버튼과 메뉴 명칭이 표준적인 영어라 번역기 없이도 직관적인 조작이 가능합니다.

## 이런 분에게 추천합니다

공용 계정의 2FA 인증 때문에 메신저로 매번 번호를 물어봐야 하는 IT 스타트업 팀장
외주 프로젝트를 진행하며 클라이언트와 계정 접근을 안전하게 공유해야 하는 프리랜서
마케팅 툴이나 쇼핑몰 관리자 계정을 여러 명이 함께 운영하는 소상공인 팀

## 실제 활용 예시

- **직장인**: 개발팀과 디자인팀이 AWS 및 GitHub 공용 계정에 로그인할 때 2FA 코드를 매번 사내 메신저로 요청하지 않고 안전하게 툴 내에서 바로 확인합니다.
- **학생**: 팀 프로젝트하려고 생성한 공동 SNS 계정이나 클라우드 서비스의 로그인 인증을 팀원 전원이 안전하게 공유하여 원활하게 과제를 수행합니다.
- **소상공인**: 직원들과 함께 네이버 스마트스토어 및 광고 관리자 계정에 접속할 때 보안을 유지하면서 편리하게 2FA 인증을 거칩니다.

## 장단점

**장점**

- AES-256-GCM 암호화 기술을 적용하여 팀이 공유하는 민감한 인증 정보를 최고 수준의 보안으로 안전하게 보호합니다.
- 번거로운 하드웨어 토큰이나 복잡한 브라우저 확장 프로그램 설치 없이 60초 만에 빠르게 설정을 완료할 수 있습니다.
- 팀원별로 뷰어와 관리자 권한을 세밀하게 나눌 수 있어 계정 보안을 유지하면서 효율적인 협업 환경을 조성합니다.
- 인증 코드를 확인하기 위해 휴대폰을 돌려가며 공유할 필요 없이 웹상에서 즉시 복사하여 업무 흐름을 유지합니다.

**단점**

- 한국어 인터페이스를 지원하지 않아 모든 메뉴와 설정 안내가 영어로 표시되므로 영어에 익숙하지 않은 사용자는 초기 학습이 필요합니다.
- 무료 플랜의 경우 2명까지만 팀원으로 초대할 수 있어 소규모 팀을 넘어서는 조직에서는 유료 전환이 필수적입니다.
- 오프라인 상태에서는 인증 코드 동기화가 불가능하며 웹 기반 서비스이므로 네트워크 연결이 반드시 유지되어야 합니다.

## 주의사항

- **개인정보**: 공유된 인증 코드는 계정 보안과 직결되므로 신뢰할 수 있는 팀원에게만 권한을 부여하십시오. 개인적인 민감 정보는 등록하지 않도록 주의가 필요합니다.
- **저작권/상업적 이용**: 본 도구는 업무용 협업 툴로 설계되었습니다. 상업적 이용 시 서비스 약관을 준수해야 하며 타인의 계정을 무단으로 등록하는 행위는 엄격히 금지됩니다.
- **요금/한도**: 무료 플랜의 계정 및 팀원 제한은 예고 없이 변경될 수 있습니다. 정확한 금액과 한도는 공식 요금 페이지에서 확인이 필요합니다.
- **계정 관리**: 관리자 계정의 비밀번호 분실은 전체 팀의 보안 위협이 됩니다. 2단계 인증을 강력하게 설정하고 복구 코드를 별도로 안전하게 보관하십시오.

## 자주 묻는 질문

**팀원 누구나 아무 계정의 2FA 코드나 볼 수 있나요?**

아닙니다. 관리자가 팀원별로 접근 권한을 세밀하게 제어할 수 있어 허가된 사람만 코드를 볼 수 있습니다.

**계정 소유자가 자리를 비워도 로그인이 가능한가요?**

그렇습니다. Pair2FA를 통해 권한이 부여된 팀원이 직접 인증 코드를 확인할 수 있어 계정 소유자가 오프라인일 때도 업무가 멈추지 않습니다.

**보안은 안전하게 유지되나요?**

AES-256-GCM 암호화 방식을 사용하여 저장되므로 외부 유출 위험으로부터 안전하게 보호됩니다.

**팀원이 퇴사하면 어떻게 하나요?**

관리자 설정 메뉴에서 해당 팀원의 접근 권한을 즉시 삭제할 수 있습니다. 권한이 삭제되면 팀원은 더 이상 공유된 인증 코드를 볼 수 없게 됩니다.

**인증 코드가 동기화되지 않습니다.**

사용자의 기기 시간이 서버 시간과 일치하는지 확인하십시오. 2FA 코드는 시간 기반으로 생성되므로 기기 시간이 정확해야 정상적으로 작동합니다.

**여러 팀에 동시에 속할 수 있나요?**

네, 하나의 계정으로 여러 팀 워크스페이스에 참여할 수 있습니다. 각 팀마다 별도의 계정 목록을 관리하므로 정보가 섞이지 않습니다.

**보안 사고 발생 시 어떻게 대응하나요?**

비정상적인 접근이 의심될 경우 즉시 해당 계정의 2FA 비밀 키를 재설정하고 팀원들의 접근 권한을 모두 회수하는 것이 좋습니다.
