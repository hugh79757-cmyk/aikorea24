## 한줄 요약

FastRouter.ai는 200개가 넘는 전 세계 주요 AI 모델을 하나의 OpenAI 호환 API로 통합 관리할 수 있는 서비스입니다. 개발자와 기업이 상황에 맞춰 가장 저렴하고 성능이 뛰어난 모델을 선택하여 비용을 아끼고 업무 효율을 높이도록 지원합니다.

## 핵심 기능

- **통합 API**: 하나의 코드로 200개 이상의 AI 모델을 자유롭게 전환합니다.
- **비용 최적화**: 트래픽을 분석하여 가장 비용 효율적인 모델로 자동 라우팅합니다.
- **성능 비교**: 여러 AI 모델의 답변 품질과 응답 속도를 한눈에 비교할 수 있습니다.

## 사용법

**1. 회원가입 및 API 키 발급**

FastRouter 웹사이트에 접속하여 계정을 생성한 뒤 대시보드에서 OpenAI 호환 API 키를 발급받습니다. 기존 OpenAI 연동 코드에서 엔드포인트 URL과 키만 변경하면 바로 연동을 시작할 수 있습니다.

**2. 모델 선택 및 라우팅 설정**

대시보드에서 연동할 200개 이상의 AI 모델 중 프로젝트에 필요한 모델들을 선택합니다. 비용 절감이나 속도 우선 등 스마트 라우팅 규칙을 지정하여 트래픽 분배 방식을 설정합니다.

**3. API 요청 및 테스트**

애플리케이션 백엔드에서 단일 API 규격에 맞춰 텍스트 생성이나 이미지 처리 등의 요청을 보냅니다. 시스템이 자동으로 가장 최적화된 제공자와 모델로 요청을 전달하여 응답을 받아옵니다.

**4. 대시보드 모니터링 및 인사이트**

통합 대시보드로 모델별 호출량, 비용, 응답 지연 시간(Latency) 및 오류 발생률을 실시간으로 확인합니다. 제공되는 인사이트를 참고하여 비용 누수를 막고 라우팅 설정을 최적화합니다.

## 가격 정책

- **무료 플랜**: 무료 체험로 주요 기능을 테스트하고 API 연동을 시작할 수 있습니다.
- **유료 플랜**: 사용량 기반 과금(Pay-as-you-go) 방식으로, 호출하는 AI 모델과 토큰 수에 따라 비용이 청구됩니다.

비용 절약 팁: 자주 사용하는 작업에 가장 가성비가 좋은 모델을 지정하면 API 사용료를 크게 아낄 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 무료 체험로 주요 기능을 테스트하고 API 연동을 시작할 수 있습니다. 구체적인 무료 크레딧이나 상시 무료 모델의 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **사용량 기반(Pay-as-you-go) 플랜** (공식 페이지 확인 필요 (제공사 목록 가격 그대로 $0 마크업 적용)): 호출하는 AI 모델과 사용한 토큰 수에 따라 비용이 청구되며, 200개 이상의 모델을 추가 마크업 없이 이용할 수 있습니다.

**환불과 해지**: 결제 및 환불 규정에 대한 상세한 정책은 공식 홈페이지의 이용 약관 및 요금 페이지로 직접 확인해야 합니다.

## 한국어 지원

개발자용 API 서비스이므로 인터페이스는 영문이지만 연동하는 AI 모델들이 뛰어난 한국어 처리 능력을 지원합니다.

## 한국어 품질 실측

**한국어 고객 응대 이메일 작성**

- 프롬프트: 쇼핑몰 지연 배송를 정중하게 사과하고 다음 주 월요일에 발송된다는 내용을 담은 고객 안내 이메일 초안을 작성해 주세요.
- 결과 예시: 안녕하세요, [고객명]님. 믿고 주문해 주신 상품의 배송 지연으로 불편을 드려 진심으로 사과드립니다. 고객님의 상품은 물류 사정으로 인해 다가오는 월요일에 안전하게 출고될 예정입니다.
- 관찰: 연동하는 백엔드 AI 모델의 성능에 따라 자연스러운 비즈니스 한국어 결과물을 안정적으로 생성합니다.

**한국어 시장 조사 보고서 요약**

- 프롬프트: 최근 국내 간편결제 시장의 트렌드와 주요 특징을 3가지 핵심 포인트로 요약하여 보고서 형태로 정리해 주세요.
- 결과 예시: 1. 모바일 중심의 결제 간소화 가속화
2. 오프라인 매장 내 QR 및 NFC 결제 비중 증가
3. 핀테크 기업과 전통 금융사의 제휴 확대
- 관찰: 전문적인 경제·비즈니스 용어가 포함된 한국어 텍스트를 구조화하여 깔끔하게 요약해 줍니다.

개발자용 API 게이트웨이 서비스로 인터페이스는 영문이지만 연동하여 호출하는 대다수 글로벌 AI 모델이 우수한 한국어 처리 능력을 갖추고 있어 실무에서 원활하게 활용할 수 있습니다.

- **학생**: AI 관련 논문 구현이나 개인 프로젝트 개발 시 여러 언어 모델의 응답 속도와 성능을 비교합니다.
- **소상공인**: 쇼핑몰 고객 응대 챗봇을 만들 때 비용이 저렴하면서도 답변이 정확한 AI 모델을 선택하여 적용합니다.

## 장단점

**장점**

- 200개가 넘는 전 세계 주요 AI 모델을 단 하나의 OpenAI 호환 API로 통합하여 간편하게 관리할 수 있습니다.
- 트래픽과 비용을 분석하여 가장 경제적인 모델로 자동으로 라우팅해 주므로 AI 운영 비용을 크게 절감할 수 있습니다.
- 제공자 장애 발생 시 자동으로 다른 정상 제공자로 요청을 우회하는 장애 복구 기능을 지원합니다.
- 프로젝트별 API 키 제한과 멤버 권한 관리로 예기치 못한 비용 폭탄이나 보안 사고를 예방할 수 있습니다.

**단점**

- 개발자 중심의 API 게이트웨이 서비스이므로 비개발자 일반 직장인이 단독으로 활용하기에는 진입 장벽이 높습니다.
- 다양한 모델과 라우팅 옵션을 세부적으로 설정하고 관리하는 과정에서 초기 학습과 테스트 시간이 필요합니다.
- 가격 및 구체적인 사용 한도와 관련된 상세 정보가 공식 홈페이지에 명확하게 공개되어 있지 않아 별도 확인이 필요합니다.

## 주의사항

- **개인정보**: API를 통해 전송되는 데이터와 민감한 개인정보가 라우팅 과정에서 타사 제공자를 거칠 수 있으므로, 기업의 보안 정책과 각 모델의 프라이버시 약관을 꼼꼼히 검토해야 합니다.
- **저작권/상업적 이용**: 플랫폼로 호출하는 개별 AI 모델(예: Claude, GPT 등)의 상업적 이용 허용 범위와 생성물 저작권 규정은 각 모델 제공사의 원본 정책을 따릅니다.
- **요금/한도**: 사용량 기반으로 과금되므로 프로젝트별 예산 한도와 알림 설정을 해두지 않으면 예상치 못한 대량 호출로 인해 높은 비용이 청구될 수 있습니다.
- **계정 관리**: 발급된 API 키가 유출되지 않도록 팀 내 권한 관리를 철저히 하고 퇴사자 발생 시 즉시 키를 재발급하거나 비활성화하는 보안 조치가 필요합니다.

## 자주 묻는 질문

**기존 OpenAI API 코드를 그대로 사용할 수 있나요?**

그렇습니다. OpenAI와 호환되는 단일 API를 제공하므로 기존에 작성한 코드에서 엔드포인트만 변경하여 손쉽게 연동할 수 있습니다.

**어떤 AI 모델들을 지원하나요?**

GPT 시리즈를 비롯하여 Claude, Gemini, Grok 등 전 세계적으로 유명한 200개 이상의 다양한 AI 모델을 지원합니다.

**비용은 어떻게 청구되나요?**

사용한 만큼만 지불하는 사용량 기반 과금 방식을 채택하고 있으며, 대시보드로 실시간으로 비용과 트래픽을 확인할 수 있습니다.

**기존에 OpenAI API를 사용하던 코드에서 변경이 많이 필요한가요?**

OpenAI 호환 API를 지원하므로 기본 엔터프라이즈 URL과 API 키만 변경하면 기존 코드를 거의 수정하지 않고도 다른 모델들을 함께 연동할 수 있습니다.

**비용 최적화 라우팅은 어떤 방식으로 작동하나요?**

사용자가 설정한 기준(비용, 응답 속도, 출력 품질 등)에 따라 시스템이 들어오는 요청을 분석하여 가장 적합하고 가성비가 좋은 모델로 자동 전환하여 전달합니다.

**특정 모델에 장애가 발생하면 어떻게 대응하나요?**

자동 장애 복구(Failover) 기능이 내장되어 있어 선택한 모델의 주요 제공자에 문제가 생기면 사전에 정의된 대체 모델이나 다른 정상 제공자로 즉시 요청을 우회합니다.

**팀원별로 API 사용량이나 예산을 따로 제한할 수 있나요?**

프로젝트 및 API 키 단위로 호출 한도와 예산을 설정할 수 있으며, 통합 대시보드와 알림 기능을 통해 비용 폭탄을 사전에 방지할 수 있습니다.
