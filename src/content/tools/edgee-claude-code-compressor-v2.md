## 한줄 요약

Edgee Claude Code Compressor V2는 코드 작업에서 발생하는 토큰 비용을 줄여주는 도구입니다. 세 가지 기술로 사용자는 비용 효율성을 높일 수 있습니다.

## 핵심 기능

- **결과 압축**: 출력 결과를 간결하게 만들어 줍니다.
- **작업 인식**: 사용자의 작업에 맞춰 최적화된 압축을 제공합니다.
- **출력 간소화**: 필요 없는 정보를 줄여주어 효율을 높입니다.

## 사용법

**1. Edgee CLI 설치하기**

터미널을 열고 제공되는 설치 명령어(curl -fsSL https://edgee.ai/install.sh | bash)를 입력하여 도구를 설치합니다. 맥이나 리눅스 환경에서 몇 분 안에 간편하게 연동을 시작할 수 있습니다.

**2. 코딩 에이전트 연동하기**

Claude Code, Cursor, GitHub Copilot 등의 코딩 에이전트와 Edgee 게이트웨이를 연결합니다. 애플리케이션 코드를 직접 수정할 필요 없이 투명한 게이트웨이 방식으로 작동합니다.

**3. 예산 및 라우팅 설정하기**

개발자 개인별, 팀별, 혹은 전체 조직 단위로 토큰 예산과 정책을 설정합니다. 예산이 소진될 경우 품질 저하 없이 오픈 웨이트 모델로 자동 전환되도록 관리합니다.

**4. 비용 및 사용량 모니터링하기**

대시보드와 콘솔로 개발자, 리포지토리, 풀 리퀘스트(PR)별 비용과 사용량을 실시간으로 확인합니다. 청구서가 나오기 전에 지출 내역을 정확하게 파악할 수 있습니다.

## 가격 정책

- **무료 플랜**: 무료 플랜이 제공되지 않습니다.
- **유료 플랜**: 유료 플랜은 가격이 명시되어 있지 않습니다. 주요 혜택은 코드 작업 시 토큰 비용 절감입니다.

비용 절약 팁: 효율적인 사용하려고 필요한 기능만 선택적으로 사용하시기 바랍니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 제공되는 크롤링 텍스트에 무료 플랜의 구체적인 범위나 메시지 한도가 명시되어 있지 않습니다. 정확한 무료 체험 여부는 공식 홈페이지의 요금 페이지로 확인이 필요합니다.

- **플랫 월간 요금제** (정확한 금액은 공식 요금 페이지에서 확인이 필요합니다): GLM, Kimi, MiniMax 등 코딩 작업에 최적화된 오픈 웨이트 모델을 터보 속도로 이용할 수 있습니다.

- **사용량 기반 과금제** (정확한 금액은 공식 요금 페이지에서 확인이 필요합니다): Edgee의 자체 키를 사용하거나 사용자가 직접 보유한 프로바이더 키를 연동하여 토큰 사용량에 따라 비용을 통제합니다.

**환불과 해지**: 환불, 해지 및 결제 변경과 관련된 구체적인 정책은 공식 문서나 지원 페이지로 직접 확인해야 합니다.

## 한국어 지원

현재 한국어 지원은 제공되지 않습니다. 영어로만 사용 가능합니다.

## 한국어 품질 실측

**코드 토큰 최적화**

- 프롬프트: Claude Code를 사용할 때 불필요한 툴 결과 페이로드를 줄여서 비용을 절감해 줘.
- 결과 예시: Edgee 게이트웨이가 입력과 출력 레이어에서 툴 결과를 압축하여 동일한 컨텍스트를 유지하면서도 청구되는 토큰 수를 최대 70%까지 줄여줍니다.
- 관찰: 영어가 기본인 개발 도구이므로 한국어 프롬프트 입력 시 작동 방식에 대한 이해가 필요합니다.

**팀 비용 모니터링**

- 프롬프트: 우리 팀 개발자들의 이번 주 리포지토리별 LLM 토큰 사용 비용을 분석해 줘.
- 결과 예시: 개발자 개인 및 리포지토리별로 세부적인 비용과 사용량이 콘솔에 기록되어, 엔지니어링 리더가 청구서 발행 전에 지출 내역을 정확하게 파악할 수 있습니다.
- 관찰: 개발 및 운영 지표를 다루는 전문 용어가 많아 국내 개발자 환경에 맞춘 해석이 요구됩니다.

Edgee Claude Code Compressor V2는 기본적으로 개발자용 코딩 에이전트와 LLM 제공자 사이를 중개하는 도구입니다. 한국어 전용 UI나 번역 기능보다는 기술적 라우팅과 토큰 압축에 집중하므로, 국내 개발자가 사용할 때는 영문 인터페이스와 명령어 기반 조작에 대한 숙지가 필요합니다.

## 이런 분에게 추천합니다

코드 작업을 자주 하는 개발자에게 추천합니다. 비용을 절감하고 싶은 스타트업 개발자에게도 유용합니다.

## 실제 활용 예시

- **직장인**: 프로젝트에서 코드 최적화를 하면서 비용을 줄이고 싶을 때 사용합니다.
- **학생**: 코딩 수업 과제를 제출할 때 비용을 절감하기 위해 활용할 수 있습니다.
- **소상공인**: 자체 개발한 애플리케이션의 운영 비용을 줄이기 위해 사용합니다.

## 유사 툴과 비교

**장점:**
- 비용 절감 효과가 뛰어납니다.
- 사용이 간편하여 빠르게 적용할 수 있습니다.

**단점:**
- 한국어 지원이 없어 사용에 불편함이 있을 수 있습니다.

**이런 분에게 가장 적합합니다:** 비용을 절감하고 싶지만 코드 작업을 많이 하는 개발자에게 가장 적합합니다.

## 대안 도구 비교

## 장단점

**장점**

- 애플리케이션 코드를 전혀 수정하지 않고도 토큰 비용을 최대 70%까지 절감할 수 있습니다.
- 개발자나 팀 단위로 토큰 예산을 설정하고 예산 소진 시 자동으로 오픈 웨이트 모델로 라우팅됩니다.
- 입출력 레이어에서 툴 결과 페이로드를 압축하여 코딩 작업의 품질 저하 없이 비용을 줄입니다.
- 도커 컴포즈나 헬름로 온프레미스 환경으로 배포하여 보안을 철저하게 유지할 수 있습니다.

**단점**

- 개발자 도구 특성상 한국어 지원이 되지 않아 초기 설정과 콘솔 이용 시 영문 소통이 필수적입니다.
- 무료 플랜의 구체적인 제공 범위가 명확하지 않아 도입 전 비용 대비 효과를 가늠하기 어렵습니다.
- 다양한 코딩 에이전트와 프레임워크에 대한 연동 지식이 부족한 초급 개발자에게는 다소 진입장벽이 높습니다.

## 주의사항

- **개인정보**: 온프레미스 배포 기능을 사용하면 프롬프트와 완성본, 프로바이더 키가 사내 네트워크 외부로 유출되지 않고 안전하게 보호됩니다.
- **저작권/상업적 이용**: 오픈 웨이트 모델 및 라우팅된 LLM 제공자의 상업적 이용 약관과 저작권 정책은 각 서비스의 규정을 별도로 준수해야 합니다.
- **요금/한도**: 설정한 토큰 예산 한도를 초과할 경우 예기치 않게 모델이 전환되거나 추가 과금이 발생할 수 있으므로 정책을 세밀하게 관리해야 합니다.
- **계정 관리**: 개발자 개인 키와 프로바이더 API 키를 연동할 때 권한 관리가 소홀하면 보안 취약점이 생길 수 있으므로 주의가 필요합니다.

## 자주 묻는 질문

**이 툴은 어떤 기능을 제공하나요?**

코드 작업에서 발생하는 토큰 비용을 줄여주는 압축 기능을 제공합니다.

**어떻게 사용하나요?**

기존 API 키와 계획을 그대로 사용하여 간편하게 설치할 수 있습니다.

**비용 절감 효과는 어느 정도인가요?**

일반 세션에서 최대 50%까지 토큰 비용을 절감할 수 있습니다.

**Edgee를 사용할 때 기존에 작성한 애플리케이션 코드를 수정해야 하나요?**

아니오, 코드를 수정할 필요가 없습니다. Edgee는 투명한 게이트웨이 방식으로 작동하여 에이전트와 LLM 제공자 사이에서 자동으로 요청을 중개합니다.

**토큰을 압축하면 코드 생성 결과물의 품질이 떨어지지 않나요?**

입력과 출력 레이어에서 툴 결과 페이로드를 간소화하더라도 코딩 작업에 있어서는 의미론적으로 손실이 없도록 설계되어 품질 저하를 방지합니다.

**예산이 소진되면 에이전트 작업이 중간에 중단되나요?**

작업이 중단되지 않고 세션 중에 자동으로 오픈 웨이트 모델로 라우팅되어 비용 효율적으로 연속성을 유지합니다.

**사내 인프라에 직접 설치해서 사용할 수도 있나요?**

그렇습니다. 도커 컴포즈(Docker Compose)나 헬름(Helm)을 이용하여 사내 네트워크 내부에 온프레미스로 배포할 수 있습니다.
