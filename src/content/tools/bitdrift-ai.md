## 한줄 요약

bitdrift.ai는 앱 개발자가 AI 에이전트를 활용해 사용자 기기에서 발생하는 실제 성능 데이터를 실시간으로 파악하게 해줍니다. 이로 개발자는 오류 발생 시 즉각적인 원인 파악과 해결이 가능해져 앱 안정성을 크게 높일 수 있습니다.

## 핵심 기능

- **실시간 데이터**: 샘플링 없이 기기 내 모든 성능 데이터를 즉시 확인하여 정확한 분석을 지원합니다.
- **AI 에이전트 연동**: AI가 직접 데이터를 쿼리하여 복잡한 오류의 원인을 자동으로 찾아내어 업무 효율을 높입니다.
- **사용자 경로 분석**: 사용자가 앱을 사용하는 실제 경로를 추적하여 문제 발생 지점을 명확히 짚어줍니다.

## 사용법

**1. 개발자 계정 생성**

공식 웹사이트에 접속하여 회원가입을 진행합니다. 모바일 앱 개발 프로젝트를 등록하기 위한 기본 설정을 마칩니다.

**2. SDK 연동 및 설정**

제공되는 모바일 앱 SDK를 프로젝트에 추가합니다. 기기 내 로그 수집과 링 버퍼 기능을 활성화하여 데이터를 준비합니다.

**3. AI 에이전트 연결**

원격 MCP(Model Context Protocol) 또는 CLI 도구를 활용합니다. Claude Code나 Cursor 같은 코딩 에이전트와 연동 설정을 완료합니다.

**4. 실시간 오류 분석**

에이전트에게 자연어로 오류 분석을 요청합니다. 수집된 실제 사용자 기기 데이터를 바탕으로 문제 원인을 파악하고 해결합니다.

## 가격 정책

- **무료 플랜**: 데모 신청로 서비스 체험이 가능하며 상세한 가격 체계는 문의가 필요합니다.
- **유료 플랜**: 기업용 엔터프라이즈 플랜(가격 별도 문의)으로 대규모 데이터 처리와 전용 기술 지원을 제공합니다.

비용 절약 팁: 도입 전 데모로 우리 앱의 데이터 구조와 호환되는지 먼저 확인하는 것이 비용 절약의 핵심입니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 데모 신청 및 무료 체험로 서비스를 시작할 수 있습니다. 정확한 무료 데이터 처리 용량과 한도는 공식 요금 페이지에서 확인이 필요합니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요 (견적 문의)): 대규모 모바일 앱 데이터 처리와 전용 기술 지원을 제공합니다. 기업 환경에 맞춘 확장 기능을 이용할 수 있습니다.

**환불과 해지**: 구독 해지 및 환불에 관한 세부 규정은 유료 플랜 계약 시 별도로 확인해야 합니다.

## 한국어 지원

현재 공식 홈페이지와 문서가 영어로만 제공됩니다. 기술적인 영어 독해 능력이 요구됩니다.

## 한국어 품질 실측

**오류 로그 분석**

- 프롬프트: 사용자 기기에서 발생한 ANR 오류의 원인을 분석해줘.
- 결과 예시: AI 에이전트가 실시간 기기 데이터를 쿼리하여 특정 화면 로딩 중 발생한 메모리 부족 현상을 찾아냅니다. 관련 세션 로그와 함께 문제 해결을 위한 코드 수정 가이드를 제시합니다.
- 관찰: 영어로 제공되는 기술 문서를 기반으로 하므로 한국어 프롬프트 입력 시 전문 용어 처리가 중요합니다.

**성능 저하 진단**

- 프롬프트: 앱 실행 시 느려지는 화면의 원인을 찾아줘.
- 결과 예시: 원격 MCP를 통해 수집된 3D 세션 리플레이와 성능 지표를 분석합니다. 특정 기기 모델과 OS 버전에서 발생하는 병목 구간을 정확히 짚어냅니다.
- 관찰: 개발 현장에서 쓰는 실무 용어가 포함된 프롬프트일수록 더 정확한 분석 결과를 도출합니다.

공식 인터페이스가 영어로만 제공되어 한국어 지원은 제한적입니다. 다만 개발용 에이전트 연동 시 자연어 프롬프트를 통한 분석 지시는 원활하게 작동합니다.

## 이런 분에게 추천합니다

앱의 안정성이 중요한 서비스 운영자, 복잡한 디버깅에 지친 개발자, 데이터 기반의 성능 최적화가 필요한 팀에게 추천합니다.

## 실제 활용 예시

- **직장인(앱 개발자)**: 출시한 앱에서 발생하는 미확인 오류를 AI 에이전트에게 실시간으로 질문하여 원인을 즉시 파악합니다.
- **학생(앱 개발 프로젝트)**: 졸업 작품 앱의 성능을 테스트하며 기기별로 발생하는 버그를 AI의 도움을 받아 효율적으로 수정합니다.
- **소상공인(자체 앱 운영자)**: 고객들이 앱 결제 시 겪는 불편사항을 데이터로 확인하여 개발자에게 구체적인 수정 요청을 전달합니다.

## 유사 툴과 비교

**장점:**
- 실시간 데이터 접근성 우수
- AI 에이전트와의 높은 연동성

**단점:**
- 높은 기술적 진입장벽
- 한국어 지원 부재

**이런 분에게 가장 적합합니다:** 기존 모니터링 툴로 해결되지 않는 복잡한 앱 성능 문제를 겪는 개발 팀에 가장 적합합니다.

## 장단점

**장점**

- 샘플링 없이 기기 내 모든 성능 데이터를 실시간으로 수집하여 정확한 분석을 지원합니다.
- Claude Code와 Cursor 등 다양한 코딩 에이전트와 연동하여 업무 효율을 높여줍니다.
- 앱스토어 재배포 없이 원격으로 데이터 수집 워크플로우를 변경하여 즉시 적용할 수 있습니다.
- 3D 세션 리플레이와 심층 로그를 제공하여 복잡한 모바일 오류를 빠르게 해결합니다.

**단점**

- 공식 웹사이트와 문서가 영어로만 제공되어 기술적 영어 독해 능력이 필수적입니다.
- 무료 플랜의 상세한 한도와 유료 가격 정책이 명확하게 공개되어 있지 않아 별도 문의가 필요합니다.
- 모바일 개발 및 에이전트 연동에 대한 사전 지식이 없으면 초기 설정이 다소 복잡할 수 있습니다.

## 주의사항

- **개인정보**: 사용자 기기의 실제 로그와 세션을 수집하므로 민감한 개인정보가 포함되지 않도록 주의해야 합니다. 프라이버시 관련 설정과 마스킹 기능을 철저히 검토해야 합니다.
- **저작권/상업적 이용**: 수집된 모바일 성능 데이터와 AI 분석 결과물은 상업용 앱 개발 및 운영 목적으로 활용할 수 있습니다. 오픈소스 표준 및 에이전트 연동 규정을 준수해야 합니다.
- **요금/한도**: 대규모 데이터를 처리할 때 발생하는 트래픽과 스토리지 비용은 기업별 계약에 따라 달라집니다. 도입 전에 예상 사용량과 비용 구조를 반드시 확인해야 합니다.
- **계정 관리**: 개발팀 내 권한 관리를 철저히 하여 중요한 앱 데이터와 에이전트 연동 키가 유출되지 않도록 보호해야 합니다. 퇴사자 발생 시 접근 권한을 즉시 회수하는 것이 안전합니다.

## 자주 묻는 질문

**기존 모니터링 툴과 무엇이 다른가요?**

기존 툴은 샘플링 데이터를 주로 사용하지만 bitdrift는 모든 기기 데이터를 실시간으로 AI가 직접 분석한다는 점이 가장 큰 차이입니다.

**설정하는 방법이 어렵지 않나요?**

GitHub의 가이드를 따라 스킬을 설치해야 하므로 개발 지식이 필요합니다. 초보자보다는 숙련된 개발자에게 적합한 도구입니다.

**개인정보 보호는 어떻게 되나요?**

사용자 기기 데이터를 다루는 만큼 민감 정보 처리에 대한 보안 정책을 준수하며 상세 내용은 기업용 보안 가이드를 확인해야 합니다.

**앱을 다시 배포하지 않고도 데이터를 수집할 수 있나요?**

네, 그렇습니다. 원격으로 워크플로우를 변경하여 앱스토어 심사나 재배포 없이 새로운 데이터를 수집할 수 있습니다.

**어떤 코딩 에이전트와 연동할 수 있나요?**

Claude Code, Cursor, Codex, Copilot 등 agentskills.io 오픈 표준을 지원하는 모든 에이전트와 연동이 가능합니다.

**앱 성능이나 배터리에 부정적인 영향을 주지 않나요?**

특허받은 링 버퍼와 기기 내 저장소를 활용하여 데이터 수집 효율을 높이므로 성능 저하를 최소화하도록 설계되었습니다.

**한국어 기술 지원을 받을 수 있나요?**

현재 공식 문서와 지원 서비스는 영어로만 제공됩니다. 한국어 전용 상담이나 가이드는 제공되지 않습니다.
