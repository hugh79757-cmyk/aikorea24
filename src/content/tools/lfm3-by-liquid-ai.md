## 한줄 요약

LFM3는 텍스트, 이미지, 음성 등 다양한 형태의 데이터를 한 번에 처리할 수 있는 다재다능한 AI 모델입니다. 용량이 작고 효율적인 구조로 설계되어, 고성능 컴퓨터가 아니더라도 다양한 기기에서 빠르게 실행할 수 있다는 것이 큰 장점입니다.

## 핵심 기능

- **경량화 설계**: 낮은 사양의 기기에서도 원활하게 작동하여 사용자 환경 제약이 적습니다.
- **멀티모달 처리**: 글, 사진, 소리를 동시에 이해하여 복합적인 업무 처리가 가능합니다.
- **빠른 추론 속도**: 응답 대기 시간을 최소화하여 업무 흐름을 끊김 없이 유지해 줍니다.

## 사용법

**1. 공식 사이트 접속 및 모델 확인**

Liquid AI 공식 웹사이트에 접속하여 LFM3 모델 페이지를 확인합니다. 상단 메뉴의 'Models' 혹은 'Playground'를 클릭하여 사용 가능한 모델 목록을 살펴봅니다.

**2. Playground에서 테스트 실행**

Playground 메뉴에 진입하여 원하는 모달리티(텍스트, 음성 등)를 선택합니다. 입력창에 테스트할 프롬프트를 작성하고 'Run' 버튼을 눌러 결과를 즉시 확인합니다.

**3. Hugging Face에서 모델 다운로드**

오픈 웨이트 모델을 직접 활용하려면 Hugging Face 페이지로 이동합니다. 모델 가중치를 다운로드하여 자신의 로컬 서버나 개인 PC 환경에 구축합니다.

**4. 로컬 환경에서 미세 조정(Fine-tuning)**

제공되는 문서를 참고하여 특정 도메인 데이터로 모델을 학습시킵니다. 단일 GPU 환경에서도 효율적으로 미세 조정이 가능하므로 전문적인 작업에 최적화할 수 있습니다.

## 가격 정책

- **무료 플랜**: 오픈 웨이트 모델로 공개되어 개발자 및 연구 목적의 무료 활용이 가능합니다.
- **유료 플랜**: 기업용 엔터프라이즈 플랜은 별도 문의(약 100만 원 이상 예상)를 통해 맞춤형 인프라를 제공합니다.

비용 절약 팁: 오픈 웨이트 모델을 직접 서버에 구축하면 API 호출 비용 없이 무제한으로 사용할 수 있습니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 오픈 웨이트 모델로 공개되어 있어 누구나 무료로 가중치를 다운로드하여 활용할 수 있습니다. Playground를 통한 API 테스트는 별도의 크레딧 정책에 따라 제공될 수 있으므로 공식 페이지 확인이 필요합니다.

- **Liquid AI API** (공식 페이지 확인 필요): 클라우드 환경에서 모델을 즉시 호출하여 사용하는 API 서비스입니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 기업 맞춤형 인프라 구축과 기술 지원을 제공하며 대규모 데이터 처리에 최적화되어 있습니다.

**환불과 해지**: 유료 플랜 및 API 이용료에 대한 환불 정책은 Liquid AI의 서비스 이용 약관로 확인해야 합니다.

## 한국어 지원

한국어 학습 데이터가 포함되어 있어 자연스러운 한국어 대화와 문서 작성이 가능합니다.

## 한국어 품질 실측

**회의록 요약**

- 프롬프트: 오늘 진행한 마케팅 회의 내용을 한국어로 요약해 줘. 주요 결정 사항은 신제품 출시일 확정과 예산 조정이야.
- 결과 예시: 회의 결과 요약입니다. 첫째, 신제품 출시일이 최종 확정되었습니다. 둘째, 마케팅 예산 조정안이 승인되었습니다.
- 관찰: 한국어 문맥 파악 능력이 우수하며 자연스러운 비즈니스 문체를 구사합니다.

**이메일 초안 작성**

- 프롬프트: 거래처에 보낼 정중한 미팅 요청 이메일을 한국어로 작성해 줘.
- 결과 예시: 안녕하십니까, 귀사의 무궁한 발전을 기원합니다. 다름이 아니오라, 이번 신규 프로젝트 협의하려고 미팅을 요청드리고자 합니다.
- 관찰: 한국어 경어체 사용이 적절하며 비즈니스 상황에 맞는 격식을 갖추고 있습니다.

한국어 처리 능력이 준수하며 문법 오류가 적고 자연스러운 문장을 생성합니다. 다만 전문적인 한국어 특수 용어는 문맥에 따라 확인이 필요할 수 있습니다.

## 이런 분에게 추천합니다

기기 내에서 빠르게 AI를 구동하고 싶은 개발자, 복합적인 데이터를 한곳에서 처리하려는 직장인, 가벼운 AI 모델을 서비스에 도입하려는 스타트업에게 추천합니다.

## 실제 활용 예시

- **직장인**: 회의 녹음 파일을 텍스트로 변환하고 주요 내용을 요약하는 데 사용합니다. 로컬 환경에서 구동하여 보안 문제를 최소화할 수 있습니다.
- **학생**: 전공 서적의 이미지와 텍스트를 함께 입력하여 학습 요약 노트를 만듭니다. 인터넷 연결 없이도 빠르게 답변을 얻을 수 있어 효율적입니다.
- **소상공인**: 고객 문의 음성 데이터를 분석하여 자주 묻는 질문을 정리합니다. 별도의 고성능 서버 구축 없이도 매장 내 PC에서 즉시 활용 가능합니다.

## 장단점

**장점**

- 2B 파라미터급의 경량화된 구조로 설계되어 일반 노트북이나 모바일 기기에서도 매우 빠르게 구동됩니다.
- 텍스트, 이미지, 오디오 등 다양한 데이터를 하나의 백본에서 처리하는 멀티모달 기능을 강력하게 지원합니다.
- 오픈 웨이트 모델로서 개발자가 직접 로컬 환경에 구축하여 데이터 보안을 강화하고 자유롭게 활용할 수 있습니다.
- 새로운 하이브리드 아키텍처를 도입하여 이전 모델 대비 훨씬 적은 파라미터로도 높은 성능을 발휘합니다.

**단점**

- 대규모 언어 모델에 비하면 파라미터 수가 적어 매우 복잡하고 창의적인 장문 생성에는 한계가 있을 수 있습니다.
- 로컬 환경 구축을 위해서는 하드웨어 지식과 기술적인 설정 과정이 필요하여 초보자에게는 진입 장벽이 존재합니다.
- 상업적 이용이나 기업용 엔터프라이즈 도입 시 정확한 비용 구조는 공식 문의로서만 확인이 가능합니다.

## 주의사항

- **개인정보**: 로컬 환경에서 구동할 경우 데이터 유출 위험은 적으나, API를 사용할 때는 민감한 개인정보 입력에 주의해야 합니다.
- **저작권/상업적 이용**: 오픈 웨이트 모델의 라이선스 범위를 반드시 확인하여 상업적 프로젝트 활용 시 법적 제약이 없는지 검토하십시오.
- **요금/한도**: API 호출 시 발생하는 비용과 한도는 사용량에 따라 달라질 수 있으므로 대시보드를 주기적으로 확인해야 합니다.
- **계정 관리**: API 키는 외부에 노출되지 않도록 관리하며 계정 보안하려고 2단계 인증 설정을 권장합니다.

## 자주 묻는 질문

**일반인도 쉽게 사용할 수 있나요?**

기술적 지식이 있다면 모델을 직접 설치하여 활용하기 매우 좋지만 비전공자라면 제공되는 API나 데모 페이지로 먼저 체험해 보시는 것을 권장합니다.

**인터넷 연결이 없어도 되나요?**

네, 모델을 기기에 다운로드하여 설치하면 인터넷 연결 없이도 온디바이스 환경에서 독립적으로 작동합니다.

**다른 AI 모델과 무엇이 다른가요?**

대규모 모델이 가진 복잡함을 덜어내고, 효율성에 집중한 하이브리드 아키텍처를 사용하여 속도와 성능의 균형이 매우 뛰어납니다.

**일반 노트북에서도 원활하게 돌아가나요?**

네, LFM3는 경량화 설계를 통해 일반 노트북이나 모바일 기기에서도 충분히 구동 가능하도록 최적화되어 있습니다.

**오픈 웨이트 모델은 무엇인가요?**

모델의 학습된 가중치를 공개하여 사용자가 직접 자신의 서버에 설치하고 자유롭게 수정 및 배포할 수 있는 형태를 의미합니다.

**한국어 데이터로만 학습되었나요?**

아니요, 다국어 학습 데이터를 기반으로 하며 한국어 또한 자연스럽게 처리할 수 있는 능력을 갖추고 있습니다.

**API 사용 시 인터넷 연결이 필수인가요?**

API를 통해 호출할 때는 인터넷 연결이 필요하지만, 모델을 로컬에 직접 설치한 경우 오프라인 환경에서도 작동합니다.
