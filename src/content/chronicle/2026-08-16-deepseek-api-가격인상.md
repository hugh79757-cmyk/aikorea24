## 💰 DeepSeek, API 가격 인상 단행

DeepSeek이 V4 Pro 공개 사흘 만에 API 가격 인상을 단행. 가성비의 상징이던 DeepSeek의 전략 변화로, AI 추론 시장의 수익성 전환 신호로 읽혔다.

### 배경과 의미

8월 16일 단행된 DeepSeek API 가격 인상은 업계에 충격을 주었습니다. 불과 사흘 전 V4 Pro를 공개하며 가성비 리더십을 과시했던 DeepSeek이 곧바로 가격을 올린 것은, 폭발적으로 증가한 API 수요에 대응하면서도 수익성을 확보하려는 전략적 판단으로 해석됩니다. 이는 '저가 공세로 시장을 장악한 뒤 가격을 정상화한다'는 전형적인 플랫폼 전략으로, AI 추론 시장이 성장 단계를 지나 수익화 단계로 접어들었음을 시사합니다. 개발자 커뮤니티에서는 아쉬움과 함께 '예견된 수순'이라는 반응이 교차했습니다.
