## 한줄 요약

Mermaid Flow는 복잡한 업무 프로세스를 시각적인 워크플로우로 설계하여 자동화 시스템을 구축하도록 돕는 툴입니다. 코딩 지식이 부족해도 직관적인 인터페이스로 업무 단계를 구성하고 효율적인 자동화 체계를 만들 수 있습니다.

## 핵심 기능

- **시각적 빌더**: 복잡한 업무 단계를 드래그 앤 드롭으로 쉽게 도식화할 수 있습니다.
- **자동화 연결**: 설계한 흐름을 실제 업무 툴과 연동하여 자동화 시스템으로 구현합니다.
- **실시간 협업**: 팀원들과 함께 워크플로우를 보며 업무 프로세스를 최적화할 수 있습니다.

## 사용법

**1. 대시보드에서 새 프로젝트 생성**

로그인 후 메인 화면 상단의 'New Workflow' 버튼을 클릭합니다. 빈 캔버스 창이 나타나면 좌측 사이드바에서 원하는 도형 요소를 선택하여 중앙 작업 공간으로 드래그합니다.

**2. 업무 단계별 흐름도 연결**

각 도형의 끝부분에 마우스를 올리면 나타나는 연결선을 클릭하여 다음 단계로 이어줍니다. 각 도형을 더블 클릭하여 해당 업무 단계의 이름과 세부 설명을 텍스트로 입력합니다.

**3. 자동화 설정 및 외부 툴 연동**

연결된 흐름의 특정 지점을 클릭하여 'Automation' 메뉴를 선택합니다. 연동 가능한 외부 서비스 목록에서 업무용 앱을 선택하고 계정을 연결하여 자동화 동작을 지정합니다.

**4. 완성된 워크플로우 공유 및 저장**

상단 메뉴의 'Share' 버튼을 눌러 팀원에게 접근 권한을 부여하거나 링크를 생성합니다. 작업한 모든 내용은 클라우드에 자동 저장되며, 필요시 이미지 파일로 내보낼 수 있습니다.

## 가격 정책

- **무료 플랜**: 기본적인 워크플로우 설계 기능을 무료로 체험할 수 있습니다.
- **유료 플랜**: Pro 플랜은 월 약 25,000원(19달러) 수준이며, 고급 자동화 연동과 무제한 프로젝트 생성을 지원합니다.

비용 절약 팁: 무료 플랜으로 핵심 프로세스를 먼저 설계해 본 뒤, 자동화 연동이 필요할 때 유료 전환을 고려하십시오.

## 요금제 자세히

- **Pro 플랜** (월 25,000원 (19달러)): 고급 자동화 연동 기능을 제공하며 무제한으로 프로젝트를 생성하고 관리할 수 있습니다.

**환불과 해지**: 정확한 환불 규정 및 결제 주기 변경은 공식 홈페이지의 계정 설정 내 요금 페이지에서 확인이 필요합니다.

## 한국어 지원

현재 인터페이스는 영어로만 제공되지만 도식화 도구 특성상 직관적인 아이콘을 사용하여 언어 장벽이 낮습니다.

## 한국어 품질 실측

**고객 응대 흐름도 제작**

- 프롬프트: 문의 접수 후 담당자 배정 및 이메일 발송 자동화 흐름을 그려줘.
- 결과 예시: 도구는 '문의 접수' 아이콘에서 '담당자 배정'으로 이어지는 화살표를 생성합니다. 이후 '이메일 발송' 단계로 연결되는 자동화 규칙이 설정된 워크플로우가 시각화됩니다.
- 관찰: 도구 인터페이스가 영어이므로 입력한 텍스트가 도형 내에 정상적으로 표시되지만 한글 폰트 깨짐 현상이 발생할 수 있습니다.

**재고 관리 업무 자동화**

- 프롬프트: 재고 부족 시 공급업체에 발주서를 자동으로 보내는 과정을 설계해줘.
- 결과 예시: 재고 확인 단계와 발주서 발송 단계가 논리적으로 연결된 도표가 생성됩니다. 조건부 분기 설정로 재고가 충분할 때와 부족할 때의 경로가 다르게 표시됩니다.
- 관찰: 전문적인 업무 용어 입력 시 영어 인터페이스와의 혼용으로 인해 가독성을 확인해야 합니다.

인터페이스가 영어로만 제공되어 한국어 사용자가 처음 접할 때 다소 생소할 수 있습니다. 시각적 아이콘 위주로 구성되어 있어 언어 장벽은 낮으나, 세부 설정 시 영문 문맥 파악이 필요합니다.

## 이런 분에게 추천합니다

반복적인 업무를 자동화하고 싶은 직장인에게 적합합니다. 복잡한 프로젝트의 흐름을 한눈에 정리하고 싶은 관리자에게 추천합니다.

## 실제 활용 예시

- **직장인**: 매일 발생하는 반복적인 보고서 취합 과정을 워크플로우로 그려 자동화합니다. 이로 수작업 시간을 대폭 줄이고 업무 효율을 높입니다.
- **학생**: 팀 프로젝트의 전체 진행 과정을 단계별로 시각화하여 팀원들과 공유합니다. 각자의 역할과 마감 기한을 명확히 파악할 수 있습니다.
- **소상공인**: 고객 주문 접수부터 배송 완료까지의 과정을 도식화하여 관리합니다. 누락되는 주문 없이 체계적인 고객 응대 시스템을 구축할 수 있습니다.

- 설계한 흐름도를 실제 업무용 소프트웨어와 직접 연결하여 즉각적인 자동화가 가능합니다.

- 무료 플랜에서 제공하는 기능과 유료 플랜의 기능 차이가 명확하여 고급 기능 사용 시 비용 부담이 발생합니다.
- 복잡한 자동화 로직을 설계할 때 영문 설명서에 의존해야 하는 번거로움이 존재할 수 있습니다.

- **저작권/상업적 이용**: 생성된 워크플로우의 상업적 활용 가능 범위는 서비스 이용 약관로 반드시 확인이 필요합니다.
- **요금/한도**: 무료 체험 후 유료 플랜으로 자동 전환될 수 있으므로 결제 정보를 입력할 때 주의해야 합니다.
- **계정 관리**: 팀 협업 시 계정 권한을 명확히 설정하여 업무 데이터의 유출을 방지하시기 바랍니다.

## 자주 묻는 질문

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 가능합니다. 코딩 지식 없이도 시각적인 도구들을 조합하여 워크플로우를 구성할 수 있도록 설계되어 있습니다.

**다른 업무 툴과 연동이 가능한가요?**

주요 생산성 도구 및 API 연동을 지원하여 설계한 흐름을 실제 업무 환경에 바로 적용할 수 있습니다.

**한국어 지원은 언제쯤 될까요?**

현재 공식적인 한국어 인터페이스 지원 일정은 없으나, 도구의 아이콘 기반 인터페이스 덕분에 한국 사용자도 큰 불편 없이 사용 가능합니다.

**코딩을 전혀 못 해도 사용할 수 있나요?**

네, 드래그 앤 드롭 방식의 시각적 빌더를 사용하므로 코딩 지식 없이도 충분히 업무 흐름을 설계할 수 있습니다.

**무료 플랜으로도 자동화 기능을 쓸 수 있나요?**

기본적인 설계는 가능하지만, 외부 툴과 연동하는 고급 자동화 기능은 유료 플랜에서만 제공될 수 있습니다.

**한국어 인터페이스는 언제 지원되나요?**

현재 공식적으로 한국어 지원 계획에 대해 발표된 바 없으며, 향후 업데이트 공지를 확인해야 합니다.

**팀원들과 동시에 작업할 수 있나요?**

네, 실시간 협업 기능을 지원하여 여러 명의 팀원이 동시에 접속해 워크플로우를 수정하고 의견을 나눌 수 있습니다.
