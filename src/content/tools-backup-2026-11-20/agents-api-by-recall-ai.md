## 한줄 요약

Agents API by Recall.ai는 화상회의 플랫폼(줌, 구글 밋, 팀즈 등)에 AI 봇을 자동으로 내보내어 미팅을 녹화하고 오디오 데이터를 수집할 수 있는 개발자용 도구입니다. 복잡한 화상회의 연동 개발 없이 API 하나로 AI 미팅 봇 서비스를 쉽게 구축할 수 있도록 도와줍니다.

## 핵심 기능

- **자동 회의 참석**: 개발한 AI 봇이 화상 미팅 링크에 스스로 접속합니다.
- **멀티 플랫폼 지원**: 줌, 구글 밋, 마이크로소프트 팀즈를 모두 지원합니다.
- **실시간 데이터**: 미팅 중 발생하는 오디오와 비디오 스트림을 확보합니다.

## 사용법

**1. 개발자 계정 가입**

Recall.ai 공식 웹사이트에 접속하여 개발자 계정을 생성합니다. 대시보드에 로그인한 후 API 키를 발급받아 연동 준비를 마칩니다.

**2. API 요청 설정**

미팅을 진행할 화상회의 플랫폼 링크와 봇의 이름을 설정합니다. 준비된 API 호출 코드를 활용해 봇 생성 요청을 전송합니다.

**3. 봇 회의 참석 확인**

줌, 구글 밋, 팀즈 등의 미팅 링크에 AI 봇이 스스로 접속하는지 확인합니다. 봇이 회의실 대기실에 있으면 입장 승인을 진행합니다.

**4. 오디오 데이터 수집**

회의가 진행되는 동안 실시간으로 수집되는 오디오 스트림 데이터를 확인합니다. 이후 음성 인식 모델과 연동하여 회의록 생성에 활용합니다.

## 가격 정책

- **무료 플랜**: 테스트를 위한 무료 체험 버전을 제공합니다.
- **유료 플랜**: 사용량에 따라 과금되는 개발자 플랜이 있으며, 월 약 7만 원(50 USD)부터 시작합니다.

비용 절약 팁: 실제 서비스 개발 전 무료 테스트로 API 연동 가능성을 먼저 확인하는 것을 권장합니다.

## 요금제 자세히

- **무료로 쓸 수 있는 범위**: 개발과 테스트를 진행할 수 있는 무료 체험 버전을 제공합니다. 정확한 무료 사용 한도와 제공량은 공식 요금 페이지에서 확인이 필요합니다.

- **개발자 플랜** (월 약 7만 원(50 USD)부터 시작): 사용량에 따라 과금되는 구조로 화상회의 봇을 서비스에 연동할 수 있습니다.

- **엔터프라이즈 플랜** (공식 페이지 확인 필요): 대규모 기업 고객을 위한 맞춤형 기능과 지원 서비스를 제공합니다.

**환불과 해지**: 환불 및 구독 해지 정책에 대한 상세한 내용은 공식 요금 페이지나 고객센터로 확인해야 합니다.

## 한국어 지원

서비스 자체 인터페이스는 영어 중심이지만 봇이 수집한 오디오를 한국어 음성 인식(STT) 모델과 연결하면 한국어 회의록 작성도 거뜬히 처리할 수 있습니다.

## 한국어 품질 실측

**화상회의 음성 수집**

- 프롬프트: 줌 미팅 링크를 전달하여 한국어 회의 오디오를 녹음하고 텍스트로 변환합니다.
- 결과 예시: 봇이 회의에 참석하여 오디오 스트림을 확보한 뒤, 외부 STT 모델로 회의 내용이 텍스트로 출력됩니다.
- 관찰: 서비스 자체는 영어 중심이나 음성 인식 모델과의 연동로 한국어 처리가 원활하게 이루어집니다.

**다국적 회의록 작성**

- 프롬프트: 구글 밋에서 진행된 한국어와 영어가 섞인 팀 미팅의 데이터를 수집합니다.
- 결과 예시: 참석자들의 발언 오디오가 각각 분리되어 수집되며, 다국어 음성 인식을 거쳐 통합 회의록의 기초 자료로 활용됩니다.
- 관찰: 오디오 추출 성능은 안정적이며 텍스트 변환 결과는 연결하는 AI 모델의 성능에 좌우됩니다.

서비스 자체 인터페이스는 영어로 제공되지만 개발자가 API를 통해 한국어 음성 인식 모델과 연동하면 한국어 회의록 작성 업무에 매우 유용하게 활용할 수 있습니다.

## 이런 분에게 추천합니다

자체 AI 회의록 서비스를 기획하고 있는 스타트업 개발자입니다.
고객 미팅 데이터를 자동으로 수집하고 분석 시스템을 구축하려는 IT 기업 담당자입니다.
화상회의 연동 기능을 자사 소프트웨어에 빠르게 추가하고 싶은 프로젝트 매니저입니다.

## 실제 활용 예시

- **직장인**: 사내 개발팀이 이 API를 활용하여 줌 회의가 끝나면 자동으로 핵심 내용을 요약해 주는 우리 회사만의 봇을 만듭니다.
- **학생**: 학생들이 팀플 화상 회의를 할 때 봇을 초대해 회의 내용을 놓치지 않고 텍스트로 기록합니다.
- **소상공인**: 온라인 상담 미팅 내용을 자동으로 데이터화하여 고객 관리 프로그램에 연동합니다.

## 유사 툴과 비교

**장점:**
- 다양한 화상회의 플랫폼을 하나의 API로 통합 연동 가능
- 복잡한 봇 개발 과정을 획기적으로 단축

**단점:**
- 개발 지식이 없는 일반 사용자는 직접 사용하기 어려움
- 사용량에 따라 비용이 발생함

**이런 분에게 가장 적합합니다:** 화상회의 관련 AI 서비스를 개발하려는 개발자 및 기업

## 장단점

**장점**

- 줌, 구글 밋, 팀즈 등 주요 화상회의 플랫폼을 하나의 API로 모두 지원하여 연동 과정이 편리합니다.
- 개발자가 복잡한 화상회의 연동 개발을 직접 하지 않고도 AI 미팅 봇 서비스를 쉽게 구축할 수 있습니다.
- 미팅 중 발생하는 오디오와 비디오 스트림 데이터를 실시간으로 안정하게 확보할 수 있습니다.
- 사전에 무료 테스트를 지원하므로 실제 서비스 개발 전에 연동 가능성을 먼저 확인할 수 있습니다.

**단점**

- 개발자 지식이 필요한 API 기반 도구이므로 일반 직장인이나 비개발자가 단독으로 쓰기에는 어렵습니다.
- 서비스 자체 인터페이스와 문서가 영어 중심으로 이루어져 있어 국내 사용자에게 다소 진입장벽이 있습니다.
- 사용량에 따라 비용이 청구되는 구조여서 대규모 미팅이 많을 경우 예상보다 비용이 늘어날 수 있습니다.

## 주의사항

- **개인정보**: 화상회의 녹화 및 오디오 데이터 수집 시 참가자들의 동의를 반드시 구해야 하며 민감한 정보 유출에 주의해야 합니다.
- **저작권/상업적 이용**: 수집한 미팅 데이터와 음성 파일의 상업적 활용 및 저장 범위는 관련 법규와 플랫폼 정책을 준수해야 합니다.
- **요금/한도**: 사용량 기반으로 과금되므로 예상치 못한 트래픽 발생 시 비용이 초과될 수 있어 요금 한도를 수시로 점검해야 합니다.
- **계정 관리**: API 키와 개발자 계정 정보가 유출되지 않도록 안전한 곳에 보관하고 권한 관리를 철저히 수행해야 합니다.

## 자주 묻는 질문

**일반 직장인도 바로 사용할 수 있나요?**

이 툴은 개발자를 위한 API 서비스입니다. 일반 사용자는 이 API를 활용해 만들어진 완성된 애플리케이션로 사용해야 합니다.

**어떤 화상회의 프로그램에서 쓸 수 있나요?**

줌(Zoom), 구글 밋(Google Meet), 마이크로소프트 팀즈(MS Teams) 등 주요 화상회의 플랫폼을 모두 지원합니다.

**한국어 회의 녹음도 가능한가요?**

봇이 수집한 오디오 데이터를 어떤 음성 인식 모델과 연동하느냐에 따라 한국어 회의 녹음 및 요약도 완벽하게 지원할 수 있습니다.

**개발 지식이 없어도 이 도구를 사용할 수 있나요?**

이 도구는 개발자를 위한 API 서비스이므로 일반 사용자가 화면 클릭만으로 쓰기에는 어렵습니다. 개발자의 도움을 받아 사내 서비스나 챗봇에 연동하는 방식으로 활용해야 합니다.

**어떤 화상회의 플랫폼에서 봇을 사용할 수 있나요?**

줌, 구글 밋, 마이크로소프트 팀즈 등 주요 화상회의 플랫폼을 모두 지원합니다. 따라서 기업에서 자주 쓰는 협업 툴과 상관없이 동일한 방식으로 봇을 내보낼 수 있습니다.

**한국어 회의 내용도 정확하게 수집되나요?**

봇 자체는 회의실에 들어가 오디오 스트림을 수집하는 역할만 담당합니다. 수집된 오디오를 한국어 음성 인식 모델과 연결하면 한국어 회의록도 정확하게 만들어낼 수 있습니다.

**비용은 어떤 방식으로 청구되나요?**

사용량에 따라 과금되는 개발자 플랜을 제공하며 월 약 7만 원부터 시작합니다. 구체적인 요금 체계는 사용량에 따라 달라지므로 공식 요금 페이지를 참고하는 것이 좋습니다.
