## 한줄 요약

Appxiom은 AI 코딩 도우미가 프로젝트의 전체 맥락을 이해하고 버그를 찾아 수정하는 데 도움이 되습니다. 개발 과정에서 발생하는 오류를 줄이고 작업 시간을 단축해 줍니다.

## 핵심 기능

- **맥락 분석**: 프로젝트 전체 구조를 파악해 정확한 오류 원인을 진단합니다.
- **자동 수정**: 발견된 버그에 대한 적절한 수정 코드를 빠르게 제안합니다.
- **도구 연동**: 기존에 사용하던 AI 코딩 에이전트와 손쉽게 연결됩니다.

## 사용법

**1. 개발 환경 연동하기**

Appxiom 공식 웹사이트에 접속하여 계정을 생성한 뒤, 현재 사용 중인 AI 코딩 에이전트와 도구를 연결합니다. 설정 메뉴에서 프로젝트 저장소를 연동하면 전체 코드 구조를 읽어 들일 준비가 완료됩니다.

**2. 프로젝트 맥락 분석 실행**

분석을 원하는 소스코드 폴더나 프로젝트 범위를 선택하고 맥락 분석 버튼을 누릅니다. 도구가 전체 파일의 구조와 연관 관계를 파악하여 오류 진단을 위한 데이터를 수집합니다.

**3. 버그 및 오류 진단하기**

분석이 완료되면 대시보드나 에디터 창에서 발견된 잠재적 버그와 오류 원인 리스트를 확인합니다. 각 항목을 클릭하여 코드의 어느 부분이 왜 잘못되었는지 상세한 설명을 검토합니다.

**4. 자동 수정 코드 적용하기**

제안된 수정 코드의 내용을 확인하고 승인 버튼을 눌러 프로젝트에 즉시 반영합니다. 수정 후에는 테스트를 구동하여 프로그램이 정상적으로 작동하는지 최종 점검합니다.
