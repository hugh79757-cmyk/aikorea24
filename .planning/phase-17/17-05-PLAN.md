       - 실제로는 image_url 대신 media upload 필요 — `POST /{ig-id}/media` with `media_type="IMAGE"`
       - 단, 이미지 URL이 아닌 파일 업로드는 Graph API가 지원 안 함 → media upload endpoint 사용
       - Simplified: `urllib.request`로 multipart/form-data 업로드 구현이 복잡하므로,
         **대신 meta-python-sdk-wheels 또는 직접 urllib로 구현**
       - **현실적 접근**: 파일을 임시 URL에 호스팅하거나,
         **`POST /{ig-id}/media`** with `media_type='IMAGE'` and `image_url` — 로컬 파일은 지원 안 함
       - **해결책**: `urllib.request`로 `requests_toolbelt` 없이 multipart POST 구현:
         ```python
         import json, urllib.request
         # Graph API는 image_url로 URL을 받음 — 로컬 파일 업로드는 별도 media upload endpoint 사용
         # 또는 bytes로 직접 업로드하는 multipart POST
         boundary = '----Boundary' + hex(int(time.time()*1000000))
         body = []
         # access_token 파트
         body.append(f'--{boundary}\r\nContent-Disposition: form-data; name="access_token"\r\n\r\n{ACCESS_TOKEN}\r\n')
         # is_carousel_item 파트  
         body.append(f'--{boundary}\r\nContent-Disposition: form-data; name="is_carousel_item"\r\n\r\ntrue\r\n')
         # media 파트 (파일 업로드)
         with open(image_path, 'rb') as f:
             image_data = f.read()
         body.append(f'--{boundary}\r\nContent-Disposition: form-data; name="media"; filename="{os.path.basename(image_path)}"\r\nContent-Type: image/png\r\n\r\n')
         body.append(image_data)
         body.append(f'\r\n--{boundary}--\r\n'.encode())
         body_bytes = b''.join(b if isinstance(b, bytes) else b.encode() for b in body)
         req = urllib.request.Request(
             f'{GRAPH_API_BASE}/{API_VERSION}/{INSTAGRAM_ACCOUNT_ID}/media',
             data=body_bytes,
             headers={'Content-Type': f'multipart/form-data; boundary={boundary}'}
         )
         ```
       - 반환: container_id (`{"id": "1234567890"}`)
