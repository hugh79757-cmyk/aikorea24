# Research: 블로그 description 첫 문장 추출 문제

## 문제 현상
- 블로그 포스트 frontmatter `description` 필드가 문장 중간에서 잘림
- 예: "사서들이 중심이 된 이 워크숍의 배경에는 디" (mid-word)

## 현재 구현 분석

### `_truncate_at_sentence_boundary` 함수 (라인 302-331)
```python
def _truncate_at_sentence_boundary(text, max_len):
    search_start = max(0, max_len - 50)  # 250-50=200
    truncated = text[:max_len]  # 250자
    
    sentence_end_pattern = re.compile(r'[.!?]|(?:다|요|함|습니다|입니다|했습니다|임|음|이다|한다|했다|이다|이다)[\s\.\!\?]*$')
    matches = list(re.finditer(r'[.!?]|(?:다|요|함|습니다|입니다|했습니다|임|음|이다|한다|했다|이다|이다)(?=\s|$)', truncated[search_start:]))
    ...
```

### 문제점 1: 한국어 종결어미 패턴 불완전
**누락된 주요 종결어미:**
- `합니다` (존댓말 현재형)
- `있습니다` (존댓말 현재형 - 있다)
- `였습니다` (존댓말 과거형)
- `됩니다` (존댓말 현재형 - 되다)
- `봅니다`, `듣습니다`, `옵니다`, `갑니다`, `줍니다`, `봅니다`, `삽니다`, `팝니다`, `만듭니다`
- `생각합니다`, `느낍니다`, `알고 있습니다`, `모릅니다`

### 문제점 2: 잘못된 자르기 로직
- `search_start = max_len - 50` → 250-50=200자부터 검색
- 마지막 50자(200~250) 구간에서 **마지막** 종결어미 찾기
- 첫 문장은 보통 80~150자에서 끝나는데, 200자 이후에서 찾으려 함

### 실제 예시 분석
```text
## 디지털 시대의 역설, 기술 피로에 지친 사람들

최근 전국의 도서관에서 개최된 'AI 피하기' 워크숍이 전례 없는 수요를 기록하고 있습니다. (pos ~85, 첫 문장 끝)
이 워크숍은 대기업 기술에 지친 사람들을 위해 기획되었으며... (두 번째 문장)
...
깊은 성찰을 요구합니다. (pos ~227, 세 번째 문장 끝)
사서들이 중심이 된 이 워크숍의 배경에는 디지털 기술에 대한 피로감이 자리잡고 있습니다. (pos ~276)
```

**현재 동작:** 250자에서 검색 → 227자에서 '.' 발견 → "깊은 성찰을 요구합니다. 사서들이..." (문장 중간)

**원하는 동작:** 첫 문장 "최근 전국의 도서관에서 개최된 'AI 피하기' 워크숍이 전례 없는 수요를 기록하고 있습니다." 추출

## 해결 방안

### Option A: 기존 함수 보완 (Defensive)
- 누락된 종결어미 모두 추가
- 하지만 여전히 "마지막 50자에서 찾기" 로직이라 첫 문장 보장 안됨

### Option B: 새 함수 `_extract_first_sentence` 생성 (Recommended)
- 본문 처음부터 검색하여 **첫 번째** 종결어미에서 자르기
- 최대 길이 제한(300자) 추가로 안전장치
- 기존 `_truncate_at_sentence_boundary`는 다른 용도로 유지

### 구현할 정규식 패턴
```python
# 첫 번째 종결어미 찾기 패턴
FIRST_SENTENCE_END = re.compile(
    r'[.!?]|'
    r'(?:'
    r'다|요|함|'
    r'습니다|입니다|했습니다|'

    r'봅니다|듣습니다|옵니다|갑니다|줍니다|삽니다|팝니다|만듭니다|'
    r'생각합니다|느낍니다|알고 있습니다|모릅니다|'
    r'임|음|이다|한다|했다'
    r')(?=[\s\.\!\?]|$)'
)
```
