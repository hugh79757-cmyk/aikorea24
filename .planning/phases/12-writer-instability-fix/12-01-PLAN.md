<objective>
Eliminate ALL card count instability by converting both `humanize_cards()` and `fix_cards()` from `--- join → LLM → --- split` to per-card individual processing.

**Purpose:** The root cause of the 10-hour publishing failure is the `--- join/split` pattern in every transform function. When LLM receives joined cards, it adds/removes `---` separators, causing card count explosion (6→8), truncation, and hook boundary corruption. Per-card processing guarantees card count invariance.

**Output:**
- `writer.py`: Both `humanize_cards()` and `fix_cards()` process each card individually — no global `---` join
- `writer.py`: Card count invariant guaranteed by code structure — not reliant on LLM compliance
- `validator.py`: Relaxed hook length (250→350) + content boundary safety check
- `test_writer.py`: Mocks updated for per-card LLM call patterns
</objective>

       ```python
       def humanize_cards(cards):
           from v3.model_router import chat_completion
           if not cards:
               return cards

           fixed = []
           for i, card in enumerate(cards):
               if len(card) < 10:
                   fixed.append(card)
                   continue
               prompt = f"""다음 카드의 AI 말투를 자연스러운 한국어로 다듬어라.

       [카드 내용]
       {card}

       [출력 규칙]
       - 내용(사실, 수치, 고유명사)은 절대 변경하지 말 것
       - 반말체(~임, ~했음, ~있음) 그대로 유지
       - 수정된 카드 내용만 출력 (부가 설명 금지)
       - 수정할 게 없으면 원본을 그대로 반환"""
               result = chat_completion(
                   system_prompt=system_prompt,
                   messages=[{'role': 'user', 'content': prompt}],
                   temperature=0.3,
                   max_tokens=2000,
               )
               if result:
                   result = _strip_instruction_leak(result)
                   result = _strip_model_explanatory(result)
                   result = result.strip()
                   if result:
                       fixed.append(result)
                   else:
                       fixed.append(card)
               else:
                   fixed.append(card)

           changed = sum(1 for i in range(len(cards)) if fixed[i] != cards[i])
           _log(f'  🧹 humanize: {changed}/{len(cards)}개 카드 수정')
           return fixed
       ```

    2. **Critical changes:**
       - NO `---\n`.join(cards) — each card goes to LLM individually
       - NO `result.split('---')` — LLM response is a single card
       - Card count is always preserved (= len(cards)) by code structure
       - Each card has its own LLM call → per-card failure doesn't affect others
       - Empty/invalid response → keep original card (graceful per-card fallback)

    3. **Prompt differences from current:**
       - Removed "--- 구분자 정확히 유지" (no longer relevant)
       - Removed "원본과 동일한 카드 수 유지" (guaranteed by code)
       - Added "수정된 카드 내용만 출력" (single card output)
       - Added "수정할 게 없으면 원본을 그대로 반환"

    4. **Edge cases:**
       - Empty card (<10 chars) → skip LLM, keep original
       - Card with LLM returning empty → keep original
       - Card with LLM returning model message → stripped → if empty, keep original

    **Why this fixes the root cause:**
    - Current: 6 cards → `---` join → LLM may add extra `---` → 5-7 segments → count mismatch → all-or-nothing failure
    - New: 6 cards → 6 individual calls → 6 individual results → count always 6 ✅
