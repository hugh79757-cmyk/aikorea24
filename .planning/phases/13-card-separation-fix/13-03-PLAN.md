## Tasks

### 1. Strengthen _repair_truncated_cards()
- File: `pipeline/threads/writer.py`
- Current logic: `fixed = [cards[0]]` → iterate `cards[1:]` → if prev incomplete, merge current into prev
- Enhancement: after first pass, reverse-iterate to handle case where a middle card remains incomplete after merge
  - Actually current logic already handles this via forward iteration. But need to confirm it handles EVERY card, especially the last.
  - After forward loop, if the last card in `fixed` is incomplete, merge with previous? No, last should be complete because forward iteration merges incomplete cards forward. Actually the current logic merges the NEXT card INTO the current card if current is incomplete. So the position shifts. The last card in `fixed` should always be complete because its predecessor merged into it if the predecessor was incomplete. But if the LAST card (original) is incomplete, it has no successor to merge from. So we need to merge the last incomplete card into its predecessor.
  - Enhancement: after forward pass, check last card. If incomplete, merge into previous.
- Ensure Hook (first card) is not merged into second if Hook is a single punch line? Actually Hook can be multiple sentences (as seen in YouTube case). The current logic merges incomplete hooks with the next card. That's correct. But if Hook is intentionally long (multiple sentences), it should stay. The content boundary check (enders_count > 5) catches that -- that's a different issue.
