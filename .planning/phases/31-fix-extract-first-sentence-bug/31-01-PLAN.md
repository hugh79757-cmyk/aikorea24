# Plan 31-01: 블로그 description 첫 문장 추출 버그 수정

## Objective
`_extract_first_sentence()` 함수가 본문 첫 문장이 아닌 중간 문장을 추출하는 버그 수정

## Root Cause Analysis
**파일**: `scripts/blog_draft_generator.py` 라인 387
```python
m = _KOR_END_PATTERN.search(text, max_len - 50)  # 위치 250부터 검색 ← BUG
```

**문제**: 
- 첫 문장(보통 50-150자)을 건너뛰고 위치 250 이후의 종결어미에서 자름
- 첫 문장 완결 후 중간 문장의 종결어미에서 잘림

**증상 예시** (알파폴드 포스트):
- 본문 첫 문장: "유전자 편집 기술은 생명과학 분야에서 혁명적인 도구로 자리 잡았습니다."
- 현재 추출 결과: "이러한 배경에서, 구글 딥마인드가 개발한 알파폴드 AlphaFold 인공지능이 새로운 해결책을 제시하고 있습니다"

## Fix Plan

### Task 1: `_extract_first_sentence()` 검색 위치 수정
**파일**: `scripts/blog_draft_generator.py` 라인 387
```python
# Before (BUG)
m = _KOR_END_PATTERN.search(text, max_len - 50)

# After (FIX)
m = _KOR_END_PATTERN.search(text)  # 위치 0부터 검색
```

- 헤딩/링크/서론 프리픽스 제거 후 첫 문장 추출 검증
