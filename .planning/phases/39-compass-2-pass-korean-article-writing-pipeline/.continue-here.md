## Blocking constraint

G4 Layer1 blocks slot3_context with false "출처 미매칭" tokens.
Root cause: `fact_gate.py:_layer1_substring_match` noun regex
`[가-힣]{2,8}` grabs noun+particle combos (e.g. `행사+를` = `행사를`,
`준공+할` = `준공할`, `그룹+의` = `그룹의`, `추진+하고` = `추진하고`,
`역량+을` = `역량을`, `사업+을` = `사업을`). These never appear
verbatim in the source body, so they are reported as missing.

Fix in progress: a `_suffixes` list (sorted longest-first) strips trailing
particles/descriptive suffixes from each noun before matching. Already
added: `을`, `습니다`, `했습니다`. STILL BROKEN — `있습니다` is not
stripped because the `_verb_endings` tuple (which runs FIRST) does not
match it (its entries are `했습니다/합니다/입니다...` — none end in
`습니다`+vowel), so the suffix loop never runs. Also `바탕으로`,
`기가와트급`, `방향성`, `어떤`-style tokens remain unmatched.
