# Plan 29-01: 블로그 description 백필 — 문장 경계 기준 재자르기

## Objective
기존 826개 블로그 포스트 중 250자 하드컷으로 문장 중간에서 잘린 155개 `description` 필드를 한국어 종결어미(`.`, `!`, `?`, `다`, `요`, `함`, `습니다`, `입니다`, `했습니다`, `임`, `음`, `이다`, `한다`, `했다` 등) 기준으로 잘리도록 재생성.

## Context
- **Root Cause**: `scripts/blog_draft_generator.py` `_save_file()` (라인 356-359) — `[:250].strip()` 하드컷
- **Impact**: 826개 중 155개(18.8%) truncation — 예: "배경에는 디", "자율성과", "보고서를 인용하"
- **Fix Applied**: Phase 28-03에서 `_truncate_at_sentence_boundary()` 구현 완료 (신규 포스트 자동 적용)
- **Remaining**: 기존 155개 일회성 백필 필요

## Files
| File | Action |
|------|--------|
| `scripts/backfill_descriptions.py` | **신규 생성** — 백필 전용 스크립트 |
| `scripts/blog_draft_generator.py` | 참조 — `_truncate_at_sentence_boundary()` import 재사용 |

## Requirements
- **REQ-29-01**: `_truncate_at_sentence_boundary()` 함수 재사용 (동일 로직 보장)
- **REQ-29-02**: `--dry-run` / `--apply` 모드 지원 (안전 검증)
- **REQ-29-03**: Frontmatter `description`만 치환, 본문 절대 변경 안 함
- **REQ-29-04**: 이미 종결어미로 끝나는 description은 skip (멱등성)
- **REQ-29-04**: 변경된 파일만 로그 출력, git diff로 검증 가능

## Tasks

### Task 1: 백필 스크립트 생성
- **File**: `scripts/backfill_descriptions.py` (신규)
- **Logic**:
  1. `src/content/blog/*.md` 전체 순회 (약 826개)
  2. Frontmatter에서 `description: "..."` 추출
  3. 한국어 종결어미 패턴으로 완결 여부 판정:
     ```python
     KOREAN_ENDINGS = re.compile(
         r'(다|요|함|습니다|입니다|했습니다|임|음|이다|한다|했다|이다|이다'
         r'|하옵니다|하옵니까|하시오|하시요|하쇼|하십시오|하십쇼)[\.\!\?]*\s*$'
     )
     ```
  4. 미완결 시 `_truncate_at_sentence_boundary(desc, 250)` 적용
  5. 결과가 원본과 다를 때만 Frontmatter에서 `description` 필드 치환
  6. `--dry-run`: 변경 예정만 출력 / `--apply`: 실제 파일 수정
  7. 진행률 + 변경 파일 리스트 출력

## Acceptance Criteria
1. **155개 truncated → 0개** — 모두 한국어 종결어미(`.`, `!`, `?`, `다`, `요`, `함`, `습니다`, `입니다`, `했습니다`, `임`, `음`, `이다`, `한다`, `했다` 등)로 끝남
2. **Zero regression** — 기존 671개 정상 description 변경 없음 (멱등성)
3. **Safe** — Frontmatter `description` 필드만 변경, 본문/기타 필드 절대 손상 안 함
4. **Idempotent** — 재실행 시 변경사항 0개
5. **Verifiable** — `git diff`로 전후 비교 가능, `--dry-run`으로 사전 검증 가능

## Risks & Mitigations
| Risk | Mitigation |
|------|------------|
| Frontmatter 파싱 오류로 본문 손상 | `description: "..."` 라인만 타겟 치환, YAML 파서 미사용 (단순 문자열 치환) |
| 따옴표 이스케이프 깨짐 | 원본/수정 모두 `.replace('"', '\\"')`로 이스케이프 통일 |
| 한글 깨짐 | `encoding='utf-8'` 명시, 파일 읽기/쓰기 동일 인코딩 |
| 대량 파일 수정 실수 | `--dry-run` 필수 1회 실행 강제, `--apply` 별도 플래그 |
