# Plan 28-02: 썸네일 중복 검증 게이트 (blog_draft_generator.py 통합)

## Objective
블로그 포스트 생성 후 발행 전, 생성된 썸네일들 간 중복 검증 단계 추가. MD5 해시 비교로 동일 이미지 감지 시 재생성 트리거 또는 경고 알림.

## Context
- 7/25 5개 포스트 동일 썸네일 발생 후 발견됨 (사후 인지)
- `blog_draft_generator.py`에서 각 기사 처리 완료 후 배치 검증 가능
- 텔레그램 알림에 중복 감지 결과 포함

## Requirements
- **REQ-28-06**: 배치 생성 완료 후 썸네일 파일 MD5 해시 비교
- **REQ-28-07**: 중복 감지 시 해당 기사 재시도 (다른 키워드로) 또는 placeholder 사용
- **REQ-28-08**: 텔레그램 알림에 중복 검증 결과 포함

## Tasks

### Task 1: 중복 검증 유틸리티 함수 추가
- **File**: `scripts/auto_thumbnail.py` 또는 별도 모듈
- **Function**: `check_thumbnail_duplicates(thumbnail_paths: list) -> dict`
- **Return**: `{"duplicates": [(path1, path2, hash), ...], "unique_count": N}`

### Task 2: blog_draft_generator.py에 검증 단계 통합
- **File**: `scripts/blog_draft_generator.py`
- **Location**: `main()` 함수, 텔레그램 알림 전 (라인 450-471 사이)
- **Logic**:
  1. 생성된 포스트들의 썸네일 경로 수집
  2. `check_thumbnail_duplicates()` 호출
  3. 중복 시: 해당 기사 재시도 (키워드 강제 변경) 또는 placeholder
  4. 결과 로깅 및 텔레그램 포함

### Task 3: 재시도 로직 구현
- **Strategy**: 중복된 썸네일의 기사에 대해 `process_thumbnail()` 재호출
- **Keyword forcing**: `DEEPSEEK_POOL`에서 사용되지 않은 키워드 강제 지정
- **Max retries**: 2회 (placeholder fallback 후 포기)

### Task 4: 텔레그램 알림 확장
- **File**: `pipeline/infra/telegram.py`
- **Add**: 중복 감지 시 `⚠️ 썸네일 중복 N건 감지 → 재시도/placeholder 처리`
- **Normal case**: `✅ 썸네일 중복 검증 통과 (N개 고유)`

## Acceptance Criteria

2. [ ] 중복 감지 시 자동 재시도 (최대 2회) 또는 placeholder
3. [ ] 텔레그램에 중복 검증 결과 명시
4. [ ] 기존 테스트 통과 + 신규 테스트 통과
