# Plan 28-04: 재발 방지 모니터링/알림 (텔레그램 중복 썸네일 감지)

## Objective
배치 썸네일 생성 시 중복 감지되면 즉시 텔레그램 알림 발송. 일일 썸네일 생성 통계 수집 및 주간 누적으로 모니터링 대시보드용 데이터 적재.

## Context
- 7/25 중복 썸네일은 수동 확인으로 발견 (사후 인지)
- 향후 동일 현상 발생 시 실시간 인지 필요
- 텔레그램은 이미 파이프라인 알림 채널로 활용 중

## Requirements
- **REQ-28-14**: 썸네일 배치 생성 완료 시 중복 감지 → 텔레그램 즉시 알림
- **REQ-28-15**: 일일 썸네일 생성 통계(총 생성, 중복, 재시도, placeholder 사용) 텔레그램 일일 리포트
- **REQ-28-16**: `config/pexels_used_ids.json` 증가 추이 모니터링 (고갈 예측)

## Tasks

### Task 1: 텔레그램 중복 알림 함수 추가
- **File**: `pipeline/infra/telegram.py`
- **Function**: `send_thumbnail_duplicate_alert(duplicates: list, date_str: str)`
- **Message format**:
  ```
  ⚠️ [2026-07-25] 썸네일 중복 감지
  중복 그룹: 1개 (5개 포스트 동일)
  MD5: 8c93b879...
  영향 포스트: 002, 003, 004, 005, 006
  조치: 재시도 N건, placeholder M건
  ```

### Task 2: 일일 썸네일 통계 리포트
- **File**: `pipeline/infra/telegram.py`
- **Function**: `send_daily_thumbnail_stats(stats: dict)`
- **Stats 수집** (`blog_draft_generator.py`에서):
  - 총 생성 요청: N
  - DeepSeek 성공/실패: X/Y
  - Pexels 고유 선택: X
  - 대체 쿼리 사용: X
  - Placeholder 폴백: X
  - 중복 감지/해결: X
  - 품질 검증 실패/재생성: X
- **Message format**:
  ```
  📊 [2026-07-25] 썸네일 일일 통계
  총 요청: 6 | 고유 선택: 1 | 재시도: 0 | Placeholder: 5
  DeepSeek 성공률: 16% (1/6)
  Used IDs 증가: +5 (총 343)
  ```

### Task 3: blog_draft_generator.py에 통계 수집 및 알림 호출 통합
- **File**: `scripts/blog_draft_generator.py`
- **Location**: `main()` 함수, 텔레그램 알림 섹션 (라인 450-471)
- **Logic**:
  1. `ThumbnailStats` 클래스/딕셔너리로 카운터 관리
  2. 각 `process_thumbnail()` 호출 전후 카운터 업데이트
  3. 중복 검증 결과 → `send_thumbnail_duplicate_alert()`
  4. 전체 완료 → `send_daily_thumbnail_stats()`

### Task 4: Used IDs 고갈 모니터링 (선택)
- **File**: `scripts/auto_thumbnail.py`
- **Function**: `check_used_ids_exhaustion() -> dict`
- **Metrics**: 
  - 총 used_ids 수
  - 키워드별 사용률 (추정)
  - `DEEPSEEK_POOL` 대비 커버리지
- **Alert threshold**: used_ids > 800개 시 경고 (50 keywords × 15/page × 1 page ≈ 750)
- **Action**: 텔레그램 경고 + 페이지네이션 확대 권장
