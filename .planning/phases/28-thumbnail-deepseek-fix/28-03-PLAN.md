# Plan 28-03: 이미지 품질 검증 + 발행 전 체크리스트

## Objective
썸네일 생성 후 품질 검증(파일 크기, 해상도, WebP 유효성) 추가. 발행 파이프라인에 체크리스트 단계 도입하여 품질 미달 이미지 자동 필터링/재생성.

## Context
- Pexels 다운로드 이미지 간 품질 편차 존재 (50KB ~ 120KB)
- 손상된 WebP, 비정상 해상도, 빈 파일 가능성
- `blog_draft_generator.py`의 자동 배포 단계 전 검증 필요

## Requirements
- **REQ-28-09**: 썸네일 최소 파일 크기 임계값 (예: 15KB)
- **REQ-28-10**: 해상도 검증 (정확히 800x800 WebP)
- **REQ-28-11**: WebP 디코딩 가능 여부 검증 (PIL로 open/verify)
- **REQ-28-12**: 품질 미달 시 자동 재생성 (키워드 변경) 또는 placeholder
- **REQ-28-13**: 발행 전 체크리스트 로그 출력 (파일 크기, 해상도, 포맷)

## Tasks

### Task 1: 이미지 품질 검증 함수 추가
- **File**: `scripts/auto_thumbnail.py`
- **Function**: `validate_thumbnail_quality(filepath: Path) -> Tuple[bool, str]`
- **Checks**:
  1. 파일 존재 및 읽기 가능
  2. 파일 크기 ≥ 15KB (설정 가능)
  3. PIL로 열기 성공 + `verify()` 통과
  4. 해상도 == (800, 800)
  5. 포맷 == 'WEBP'
- **Return**: `(True, "OK")` 또는 `(False, "reason")`

### Task 2: process_thumbnail에 품질 검증 통합
- **File**: `scripts/auto_thumbnail.py`
- **Location**: `create_thumbnail()` 후, `_save_used_id()` 전
- **Logic**:
  ```python
  ok, reason = validate_thumbnail_quality(output_path)
  if not ok:
      log(f"  ⚠️ 품질 검증 실패: {reason} → 재시도/placeholder")
      # 재시도 로직 (키워드 변경) 또는 placeholder
  ```

### Task 3: blog_draft_generator.py에 발행 전 체크리스트 추가
- **File**: `scripts/blog_draft_generator.py`
- **Location**: 자동 배포 단계 전 (라인 492-533 사이)
- **Checklist 출력**:
  ```
  === 발행 전 품질 체크리스트 ===
  2026-07-25-001: 45KB, 800x800, WebP ✅
  2026-07-25-002: 12KB, 800x800, WebP ❌ (파일 크기 미달)
  ...
  전체: N개 검증, M개 통과, K개 재생성 필요
  ```

### Task 4: 품질 미달 시 재생성/placeholder 로직
- **Strategy**: 품질 실패 → 키워드 변경 후 `process_thumbnail()` 재호출 (최대 2회)
- **Fallback**: 2회 실패 → `_use_default_thumbnail()` 호출
- **Logging**: 각 시도별 키워드, 결과, 최종 액션 기록

## Acceptance Criteria

5. [ ] 기존 테스트 통과 + 신규 품질 검증 테스트 추가
