# Plan 28-01: DeepSeek Fallback 개선 + Pexels 페이지네이션 + Placeholder 폴백

## Objective
DeepSeek API 실패 시 고정 키워드("abstract technology") 대신 다양한 fallback 전략 적용하고, Pexels 검색 결과 페이지네이션으로 미사용 사진 탐색 범위 확대, 최종 폴백을 placeholder 이미지로 변경하여 동일 썸네일 재사용 방지.

## Context
- **Root Cause**: 7/25 5개 블로그 포스트 동일 썸네일 사용 (MD5: 8c93b879...)
- **Location**: `scripts/auto_thumbnail.py` → `process_thumbnail()` 함수
- **Trigger**: DeepSeek API 실패 → "abstract technology" 고정 fallback → Pexels 검색 결과 모두 used_ids에 있음 → `photos[0]` 재사용 (라인 205)

## Requirements
- **REQ-28-01**: DeepSeek 실패 시 `DEEPSEEK_POOL`에서 랜덤 선택 (고정 fallback 제거)
- **REQ-28-02**: Pexels 검색 시 `page` 파라미터로 2~3페이지까지 탐색 (미사용 사진 확률 증가)
- **REQ-28-03**: 대체 쿼리 풀에서 원본 검색 키워드 제외 (중복 검색 방지)
- **REQ-28-04**: 최종 폴백을 `photos[0]` 재사용 → `_use_default_thumbnail()` (placeholder 복사)로 변경
- **REQ-28-05**: 로깅 강화 — 사용된 키워드, 페이지, 선택된 photo_id 기록

## Tasks

### Task 1: DeepSeek 실패 시 랜덤 키워드 선택
- **File**: `scripts/auto_thumbnail.py`
- **Function**: `_extract_deepseek_keyword()` 수정
- **Change**: 예외 발생 시 `random.choice(DEEPSEEK_POOL)` 반환 (기존: `"abstract technology"` 고정)
- **Import**: `import random` 추가

### Task 2: Pexels 검색 페이지네이션 지원
- **File**: `scripts/auto_thumbnail.py`
- **Function**: `search_pexels(query, per_page=15, max_pages=3)`
- **Change**: `page` 파라미터 루프 추가 (1~max_pages), 결과 누적 후 반환
- **Default**: `max_pages=3` (페이지당 15개 → 최대 45개 후보)

### Task 3: process_thumbnail() 로직 전면 재작성
- **File**: `scripts/auto_thumbnail.py`
- **Function**: `process_thumbnail()`
- **Changes**:
  1. 키워드 결정: DeepSeek 성공 → 해당 키워드 / 실패 → 랜덤 풀 선택
  2. 페이지네이션 검색: `search_pexels(keyword, max_pages=3)`
  3. 미사용 사진 탐색: 누적 결과에서 `_pick_unused_photo()`
  4. 대체 쿼리: 원본 키워드 제외한 `DEEPSEEK_POOL[:5]` 순회 (각각 페이지네이션 적용)
  5. 최종 폴백: placeholder 복사 (`_use_default_thumbnail()`)
  6. 모든 단계 로깅: `keyword`, `page`, `candidates`, `chosen_id`, `fallback_reason`

### Task 4: 대체 쿼리 풀에서 원본 키워드 제외
- **File**: `scripts/auto_thumbnail.py`
- **Logic**: `alt_queries = [q for q in DEEPSEEK_POOL if q != primary_keyword][:5]`
- **Reason**: "abstract technology" 검색 결과가 이미 used_ids에 다 있는데 동일 쿼리로 재시도 무의미

### Task 5: 테스트 추가
- **File**: `tests/test_auto_thumbnail.py` (신규)
- **Tests**:
  - `test_deepseek_failure_random_keyword`: DeepSeek 예외 시 랜덤 풀 선택 확인
  - `test_pexels_pagination`: page=2,3 결과 누적 확인
  - `test_exclude_original_keyword_from_alts`: 원본 키워드 대체쿼리 제외 확인
  - `test_final_fallback_placeholder`: 모든 후보 소진 시 placeholder 복사 확인
  - `test_logging_includes_keyword_page_chosen`: 로그에 키워드/페이지/선택ID 포함 확인

## Acceptance Criteria
1. [ ] DeepSeek API 실패 시 `"abstract technology"` 고정이 아닌 `DEEPSEEK_POOL` 랜덤 키워드 사용

3. [ ] 대체 쿼리에 원본 검색 키워드 포함되지 않음
4. [ ] 모든 Pexels 결과 소진 시 `photos[0]` 재사용 대신 placeholder(`news-keyword-og.webp`) 복사
