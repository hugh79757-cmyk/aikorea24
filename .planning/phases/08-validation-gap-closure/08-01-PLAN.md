### Task 1: `detect_prompt_leak()` 확장
**파일**: `pipeline/threads/pitch.py`
**변경**:
- `LEAKED_PROMPT_PATTERNS`도 함께 검사하도록 확장
- 검사 범위 `[:300]` → 전체 텍스트로 확장

```python
def detect_prompt_leak(text: str) -> tuple[bool, str]:
    # 1. 시스템 프래그먼트 검사 (기존)
    short = text[:300].lower()
    for frag in _SYSTEM_PROMPT_FRAGMENTS:
        if frag.lower() in short:
            return True, f"프롬프트 프래그먼트 탐지: {frag}"
    
    # 2. 프롬프트 라벨 검사 (신규)
    for pattern in LEAKED_PROMPT_PATTERNS:
        if re.search(pattern, text):
            return True, f"프롬프트 라벨 탐지: {pattern}"
    
    return False, "OK"
```

### Task 2: `validate_final_output()` 신규
**파일**: `pipeline/threads/validator.py`
**기능**: 최종 카드 통합 검증 (프롬프트 + 외국어 + 한글)

```python
def validate_final_output(cards: list[str]) -> tuple[bool, str]:
    """최종 카드 통합 검증 — 발행 전 3차 방어"""
    for i, card in enumerate(cards, 1):
        # 1. 프롬프트 노출 검사
        leaked, reason = detect_prompt_leak(card)
        if leaked:
            return False, f"Card {i}: {reason}"
        
        # 2. 외국어 검사
        chinese = _CHINESE_PATTERN.findall(card)
        if chinese:
            return False, f"Card {i}: 한자 감지 ({len(chinese)}개)"
        
        japanese = _JAPANESE_PATTERN.findall(card)
        if japanese:
            return False, f"Card {i}: 일본어 감지 ({len(japanese)}개)"
        
        # 3. 한글 비율 검사
        korean = len(_KOREAN_PATTERN.findall(card))
        total = len(card.strip())
        if total > 10 and korean < total * 0.1:
            return False, f"Card {i}: 한글 비율 부족 ({korean}/{total})"
    
    return True, "OK"
```
