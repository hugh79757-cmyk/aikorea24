    - Import: typing.Protocol, runtime_checkable, typing.Optional, time, datetime, logging
    - Import from pipeline.infra.models: PipelineStepResult
    - Import from pipeline.infra.logger: get_pipeline_logger, log_step
    - Import from pipeline.infra.d1_client: d1_query

    - Define `@runtime_checkable class PipelineStep(Protocol)` with:
      - `name: str` attribute
      - `def run(self) -> int: ...` method (0 = success, nonzero = failure)
      - docstring: "Protocol for pipeline steps. Each step must have a name and a run() returning exit code."

    - Define `class PipelineOrchestrator`:
      - `__init__(self, run_id: str = "")`: initialize self._steps = [], self.results = [], self.run_id = run_id or datetime.now().strftime("run_%Y%m%d_%H%M%S"), self._log = get_pipeline_logger("pipeline.orchestrator", run_id=self.run_id)
      - `register(self, step: PipelineStep) -> None`: appends to self._steps, self._log.info(f"Registered step: {step.name}")
      - `run(self, dry_run: bool = False) -> list[PipelineStepResult]`: iterate over self._steps, for each:
        - Create PipelineStepResult(step_name=step.name, success=False, duration_seconds=0.0, error=None, run_id=self.run_id)
        - Wrap step.run() in try/except
        - Inside try: with log_step(self._log, step.name): start = time.monotonic(); exit_code = 0 if dry_run else step.run(); elapsed = time.monotonic() - start. Set result.success = (exit_code == 0), result.duration_seconds = elapsed. If not success, result.error = f"exit code {exit_code}" and log error. Else log completion with duration.
        - On Exception: set result.success=False, result.duration_seconds=elapsed, result.error=f"{type(e).__name__}: {e}", log exception
        - Append to self.results, call _record_to_d1(result) if not dry_run
        - Track all_success flag
        - After loop: call _print_summary(), return self.results
      - `_record_to_d1(self, result: PipelineStepResult) -> None`: Best-effort INSERT with SQL escaping (single quotes in error_message doubled). INSERT with run_id, step_name, status('success'/'failure'), duration_seconds, error_message (NULL if no error), started_at, completed_at = datetime('now'). On exception, log warning, don't halt.
      - `_print_summary(self) -> None`: Print formatted summary with run_id, each step with status icon + duration + error, total time, all-ok indicator.

    - All comments in Korean per D-13.
    - Use emoji icons: checkmark ✅ for success, cross ❌ for failure.
    - Research examples at lines 378-499 of 03-RESEARCH.md are the reference implementation — follow their pattern faithfully.
