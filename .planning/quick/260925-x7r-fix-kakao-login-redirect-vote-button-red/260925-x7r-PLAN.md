# Fix Kakao Login Redirect + Vote Button redirect_to

## Problem

Tool page vote button → 401 → `/api/auth/login` (no redirect_to) → after login → `/` (home). User loses place in like/recommend sequence. Kakao callback has no state handling at all.

## Fix 1: Kakao callback state/redirect

**Files**: `src/pages/api/auth/kakao.ts`, `src/pages/api/auth/callback/kakao.ts`

- kakao.ts: read `redirect_to` param, pass as state to Kauth
- callback/kakao.ts: read state from Kakao callback, validate, redirect back
- Pattern: mirror Google flow (login.ts → callback/google.ts)

## Fix 2: Vote button redirect_to

**File**: `src/pages/tools/[id].astro`

- Vote POST → 401 → JS redirect to `/api/auth/login?redirect_to=${currentPath}`
- Google callback already reads state → works

## Fix 3: Consent page login links

**File**: `src/pages/auth/consent.astro`

- Pass `redirect_to` param to both Kakao and Google login links

## Verification

- git diff shows 3 files changed
- Kakao callback redirects to state URL
- Vote button passes redirect_to
- Build succeeds
