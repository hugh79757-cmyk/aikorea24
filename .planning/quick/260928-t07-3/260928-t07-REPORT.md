### 1.5 근본원인 가설

**가설: Pexels API rate limit(429)이 12건 연속 발생 → 전량 placeholder 폴백 → `is_placeholder_copy` 가드가 `image:` 주입을 차단 → 썸네일 누락. confidence: high.**

1. 로그에 429가 12건×약 7회 = 80회 이상 기록 (파일경로: `scripts/blog_draft.log:20577` 부근, 08:15:30~08:16대)
2. MD5 12건 전부 placeholder와 일치 (위 1.4)
3. 코드는 설계대로 동작 (`_add_image_to_frontmatter`의 placeholder 생략 분기, `blog_draft_generator.py:541-545`)

부가 관찰 (가설의 일부가 아님):

- 재시도 로직이 429 상황에서 역효과: 429인데도 대체 쿼리 5개를 즉시 재시도 → rate limit을 더 악화시키는 구조 (`auto_thumbnail.py:334-349`, sleep/backoff 없음)
- 품질 체크리스트(5b 단계)는 로그만 남기고 복구하지 않음
- 렌더링 측(`src/pages/blog/[...page].astro` 계열)에서 `image` 누락 시 폴백 OG 표시 여부는 이번 조사 범위 밖 — 후속 확인 필요
