# Phase 24-02: Pre-filtering 후보 사전 선별 (시간 절약)

## GOAL
27개 후보 기사 → LLM에 모두 보내는 대신 **상위 5~10개만 사전 선별** → 처리 시간 10분 → 2분 단축

## WHY NEEDED
- 현재: 27개 기사 → LLM 5개씩 6배치 → 6회 호출 → 시간 낭비
- 목표: 후보 10개 → LLM 1회 호출 → 시간 절약 + context overflow 방지

## SCOPE
- `pipeline/threads/pitch.py:get_pitches()` - 사전 필터링 로직 추가
- `scripts/threads/db_reader.py` - 날짜/관련도 필터 활용

## SUCCESS CRITERIA
1. D1 후보 27개 → 시의성/recency 기준 상위 10개 선택
2. LLM 호출 횟수 6회 → 2회 이하로 감소
3. 피치 품질 동등 수준 유지
4. 실행 시간 70% 이상 단축

```python
# get_pitches() 시작 부분에 삽입
def _pre_filter_candidates(articles, limit=10):
    """D1 후보 기사를 시의성 + AI 관련도 기준으로 선별"""
    def score_article(a):
        score = 0
        pub_date = a.get('pub_date', '')
        days_old = (datetime.now() - datetime.strptime(pub_date, '%Y-%m-%d')).days if pub_date else 999
        if days_old <= 1: score += 10
        elif days_old <= 3: score += 5
        elif days_old <= 7: score += 2
        
        title_desc = (a.get('title', '') + ' ' + a.get('description', '')).lower()
        ai_keywords = ['ai', '인공지능', '머신러닝', 'LLM', '챗GPT', '클로드', '제미나이', 'gemini', 'anthropic']
        for kw in ai_keywords:
            if kw in title_desc:
                score += 3
        return score
    
    scored = [(score_article(a), a) for a in articles]
    scored.sort(key=lambda x: -x[0])
    return [a for _, a in scored[:limit]]
```
