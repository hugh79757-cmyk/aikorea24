## 원인 구조

Hugo 테마의 `layouts/404.html` 이 `{{ define "main" }}` 만 정의한다 → 테마 `baseof.html` 을 상속한다
→ `<head>` 에서 사이트의 `extend_head.html` / `adsense` partial 이 로드된다 → 404 에도 광고 요청이 나간다.

## 검증된 수정 패턴

repo 루트에 **standalone** `layouts/404.html`(define 없이 raw HTML: noindex + 광고 없음)을 두면 테마 baseof 를 타지 않는다.

- 검증: `Projects/STAP/etf-hugo` 에 적용 후 `hugo -d /tmp/…` 빌드 → `adsbygoogle` **1 → 0**, 852바이트, `noindex` 포함.
