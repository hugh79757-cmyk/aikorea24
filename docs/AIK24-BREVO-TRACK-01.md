## 한 줄 목표

## 배경 (0번 진단 완료, 2026-10-04)
- `aikorea24.kr/tools/*` 6개 페이지 전부 HTTP 200 — 사이트 문제 아님.
- Gmail 원본 확인: 이메일의 모든 링크가 Brevo 추적 URL로 감싸져 있음.

- 코드베이스에 `sendibt2` 문자열 없음 → 추적 URL은 Brevo가 발송 시점에 생성. 코드가 가짜 URL 만드는 게 아님.
