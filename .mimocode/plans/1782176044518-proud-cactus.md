# 크롤링 성공 URL 기반 발행 링크 미스매치 수정

## 문제
`assemble_final()`이 `primary_url` 유효성 검사 실패 시 `related` 목록 전체에서 `validate_link()`를 통과하는 첫 번째 URL을 선택하는데, 이 URL이 실제 쓰레드 본문에 사용된 기사와 다를 수 있음.

## 해결
크롤링 성공한 URL만(`crawled_urls`) 대상으로 링크를 선택. 이미 크롤링에 성공했으므로 재검증 불필요.

## 수정 파일
`scripts/threads/v3/writer_v3.py`

### 2. `assemble_final()` 내부 로직 변경 (line 458~478)
- `crawled_urls`가 있으면: 크롤링 성공한 URL 중 `primary_url`이 포함되어 있으면 해당 URL 사용, 없으면 `crawled_urls`의 첫 번째 URL 사용
- `crawled_urls`가 없으면: 기존 로직 그대로 (하위 호환)

```python
def assemble_final(cards, articles, primary_url=None, crawled_urls=None):
    from db_reader import validate_link

    # 크롤링 성공 URL이 있으면 해당 URL만 사용 (재검증 불필요)
    if crawled_urls:
        # 1순위: primary_url이 크롤링 성공 목록에 있으면 사용
        if primary_url and primary_url in crawled_urls:
            cards.append(f'🔗 {primary_url}')
            return cards
        # 2순위: 크롤링 성공한 첫 번째 URL 사용
        cards.append(f'🔗 {crawled_urls[0]}')
        return cards

    # 기존 로직 (crawled_urls 없을 때)
    if primary_url:
        if validate_link(primary_url, timeout=5):
            cards.append(f'🔗 {primary_url}')
            return cards
        log(f'  ⚠️ primary URL 유효성 실패: {primary_url[:50]}...')
    if articles:
        for a in articles:
            url = a.get('link', '').strip()
            if url == primary_url:
                continue
            if not url or not url.startswith('http'):
                continue
            if validate_link(url, timeout=5):
                cards.append(f'🔗 {url}')
                return cards
            log(f'  ⚠️ URL 유효성 실패 — 다음 URL 시도: {url[:50]}...')
        log(f'  ❌ 모든 {len(articles)}개 URL 유효성 실패 — 링크 생략')
    return cards
```
