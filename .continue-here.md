## Decisions

| Decision | Rationale |
|----------|-----------|
| D1 `get_existing()` queries ALL links (not 7d) | Prevents `INSERT OR IGNORE` silent drops on UNIQUE constraint |
| `response_format` removed from writer | DeepSeek `deepseek-v4-flash` inconsistently enforces JSON output; falls back to plain text |
| Writer: sequential fallback (not ThreadPoolExecutor) | Only 1 model + 1 fallback — parallel race adds complexity without benefit |
| JSON parsing: 4 stages (not JSON-only) | Phase 15 removed delimiter fallback too aggressively; DeepSeek non-JSON output needs recovery path |
| Vectorize auto-index after collect | API cost is negligible (~$0.00002/article); real-time dedup is worth it |
