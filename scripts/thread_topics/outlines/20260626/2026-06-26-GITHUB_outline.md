## [TOPIC]
GitHub 사용법: 초보자를 위한 단계별 가이드

## [FACTS]
- GitHub: 소프트웨어 개발 프로젝트 관리 및 버전 컨트롤을 위한 플랫폼.
- 리포지토리: GitHub에서 코드와 파일을 저장하고 관리하는 기본 단위.
- 포크(Fork): 다른 사용자의 리포지토리를 복제하여 개인 계정에서 작업할 수 있게 하는 기능.
- 풀 리퀘스트(Pull Request): 포크한 리포지토리에서 변경사항을 원본 리포지토리에 반영하도록 요청하는 기능.
- 커밋(Commit): 코드 변경사항을 저장하고 기록하는 행위.
