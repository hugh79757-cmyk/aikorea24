Beam Free는 Reflection이 공개한 코딩·에이전트용 추론 모델의 무료판입니다. 2026년 10월 17일 기준으로 OpenCode 모델 선택 창에 `Beam Free`(제공자 OpenCode) 이름으로, Kilo 게이트웨이 목록에는 `reflection/beam-free` 로 올라와 있고 두 곳 모두 무료로 표시됩니다. 컨텍스트 길이는 1,048,576 토큰(약 100만), 한 번에 생성하는 최대 길이는 131,072 토큰입니다. 다만 목록 설명에 프롬프트와 생성 결과가 제공자 쪽에 보관되어 서비스 개선에 쓰일 수 있다고 적혀 있습니다. 사내 코드나 고객 데이터에는 권하지 않습니다.

이 글은 설치와 실행, 모델 선택 창에서 무료 모델을 고르는 방법, 이 모델의 조건, 무료 표기가 붙는 규칙, 목록 API로 직접 확인하는 방법, 실측 결과 순서로 정리했습니다. 아래 수치는 전부 2026년 10월 17일에 OpenCode 2.0.32 의 모델 선택 창과 모델 목록 API에서 확인한 값입니다.

## 1. 설치하고 실행합니다 — 창이 하나 뜹니다

[공식 설치 스크립트](https://opencode.ai/v2/install)를 쓰면 터미널 한 줄로 끝납니다.

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

설치가 끝나면 `opencode` 를 실행합니다. 대화형 창이 열리고 오른쪽 아래에 버전이 표시됩니다(이 글을 쓴 환경은 2.0.32). 버전은 `opencode --version` 으로도 확인합니다.

npm으로 설치할 때 패키지 이름은 `opencode-ai` 입니다. `npm install -g opencode` 는 존재하지 않는 패키지라 실패합니다.

## 2. 모델 선택 창에서 Free 를 골라 씁니다 — 사람이 쓰는 경로

대화형 창에서 `/models` 를 입력하면 **Select model** 창이 열립니다. 키로 열려면 `ctrl+x` 를 누른 뒤 `m` 입니다. 창에서 하는 일은 네 가지입니다.

1. 검색 — 위쪽 Search 칸에 `Free` 를 입력하면 무료 모델만 남습니다.
2. 고르기 — 오른쪽 열에 제공자 이름과 함께 **Free** 가 표시된 줄이 무료 경로입니다. `Beam Free` 는 제공자 `OpenCode` 줄에 있습니다. 방향키로 옮기고 Enter 로 고릅니다.
3. 즐겨찾기 — `ctrl+f` 로 즐겨찾기를 걸어 두면 다음부터 목록 위쪽 Favorites 에 남습니다. 최근 쓴 모델은 Recent 에 쌓이고 `f2` 로 최근 모델을 돌려 쓸 수 있습니다(되돌리기는 `shift+f2`).
4. 제공자 연결 — 창 아래 `ctrl+a` 입니다. Beam Free 는 OpenCode 제공자 줄에서 바로 보이지만, Kilo 게이트웨이처럼 API 키가 필요한 경로는 여기서 연결합니다.

| 하고 싶은 것 | 창에서 하는 방법 |
| --- | --- |
| 무료 모델만 보기 | `/models` 를 열고 Search 에 `Free` 입력 |
| Beam Free 쓰기 | `Beam Free`(제공자 `OpenCode`) 줄에서 Enter |
| 자주 쓰는 모델 고정 | `ctrl+f` 로 즐겨찾기 |
| 최근 모델로 빠르게 전환 | `f2` (되돌리기는 `shift+f2`) |
| 다른 제공자 연결 | 창 아래 `ctrl+a` |

무료인지 아닌지는 이 창에서 바로 판단합니다. 오른쪽 열에 `Free` 가 붙은 줄이 무료 경로이고, 그 표시가 없는 줄은 유료입니다. 창을 닫을 때는 `esc` 입니다. 이 글을 쓴 환경에서는 OpenCode 제공자에 별도 키를 넣지 않은 상태로 `Beam Free` 가 목록에 보였고 호출도 됐습니다.

## 3. 이 모델의 조건

| 항목 | 값 (2026-10-17 목록 기준) |
| --- | --- |
| 가격 | 입력·출력 모두 0 |
| 컨텍스트 | 1,048,576 토큰 |
| 한 번 생성 최대 | 131,072 토큰 |
| 입력 형식 | 텍스트만 |
| 지원 파라미터 | `max_tokens`, `temperature`, `tools`, `reasoning` |
| 데이터 보관 | 프롬프트·생성이 보관되어 학습에 쓰일 수 있음 |

가장 눈여겨볼 항목은 마지막 줄입니다. 목록 설명에 "프롬프트와 생성 결과가 보관되어 제공자의 서비스 개선과 학습에 사용될 수 있다"고 적혀 있고, 제로 리텐션(Zero Data Retention)은 제공되지 않는다고 명시돼 있습니다. 공개 저장소 코드나 학습용 예제에는 문제가 없지만, 사내 코드·고객 데이터·개인정보는 넣지 않는 편이 맞습니다. 같은 설명에 이 모델이 [Vercel AI Gateway](https://vercel.com/ai-gateway)를 통해 무료로 제공된다고 적혀 있습니다.

## 4. 무료 표시는 세 가지 방식으로 붙습니다

선택 창은 오른쪽에 `Free` 를 붙이고, 원시 목록은 값이나 이름으로 알려 줍니다. Beam 무료판은 세 방식이 모두 적용된 예입니다.

| 목록 | 무료를 알리는 방식 | Beam 무료판의 이름 |
| --- | --- | --- |
| OpenCode 모델 선택 창 | 오른쪽 열 `Free` 표시 | `Beam Free` (제공자 `OpenCode`) |
| Kilo 게이트웨이 목록 | 입력·출력 단가 0 | `reflection/beam-free` |
| [OpenCode Zen 목록](https://opencode.ai/zen/v1/models) | 이름 끝 `-free` | `beam-free` |

Zen 목록처럼 이름으로 구분하는 곳은 규칙이 일정합니다 — `space-bunny-free`, `mimo-v2.6-flash-free`, `longcat-2.5-preview-free` 모두 끝에 `-free` 가 붙습니다.

같은 이름의 유료판도 따로 있습니다. `reflection/beam-1.0-501b-a23b` 는 컨텍스트는 같지만 가격이 붙습니다.

| 모델 이름 | 입력 100만 토큰 | 출력 100만 토큰 | 비고 |
| --- | --- | --- | --- |
| `reflection/beam-free` | 0 | 0 | 무료판 |
| `reflection/beam-1.0-501b-a23b` | $0.25 | $1.00 | 501B 총 파라미터·23B 활성 MoE |

가격은 목록의 토큰당 단가(입력 0.00000025, 출력 0.000001)를 100만 토큰 기준으로 환산한 값입니다. 선택 창에서는 이 유료판 줄에 `Free` 표시가 붙지 않습니다. 무료 경로를 `:free` 접미사로 구분하는 목록도 많습니다 — 같은 목록의 `poolside/laguna-s-2.1:free` 는 접미사를 떼면 다른 라우트를 가리키므로 무료로 쓰려면 접미사까지 그대로 적어야 합니다. 유료판 쪽 모델 정보는 [OpenRouter 모델 페이지](https://openrouter.ai/reflection/beam-1.0-501b-a23b)에 정리돼 있고, 무료 경로 전체 목록은 [kilo.ai](https://kilo.ai/)에서 확인할 수 있습니다.

## 5. 목록 API로 값까지 확인하고 싶다면

창의 표시가 언제 바뀔지 모르니 값으로도 확인해 둡니다. Kilo 게이트웨이 모델 목록은 인증 키 없이 조회됩니다.

```bash
curl -s https://api.kilo.ai/api/gateway/models | python3 -c "
import json, sys
for r in json.load(sys.stdin)['data']:
    if r['id'] == 'reflection/beam-free':
        print(r['context_length'], r['pricing'])"
```

입력·출력 단가가 `0.000000000000` 으로 나오면 무료 경로입니다. 같은 모델이 OpenCode Zen 목록에도 `beam-free` 이름으로 있습니다.

```bash
curl -s https://opencode.ai/zen/v1/models | python3 -c "
import json, sys
print([r['id'] for r in json.load(sys.stdin)['data'] if 'beam' in r['id']])"
```

## 6. ai.kr.24 실측 결과

검증일은 2026년 10월 17일이고, ai.kr.24 에서 두 경로를 실제로 호출해 확인한 값입니다. 측정에 쓴 명령은 아래와 같고, 프롬프트는 "1+1의 답만 숫자로 출력하세요." 였습니다.

```bash
opencode run -m kilo/reflection/beam-free "1+1의 답만 숫자로 출력하세요."
opencode run -m opencode/beam-free "1+1의 답만 숫자로 출력하세요."
```

| 호출 경로 | 응답 | 지연 | 판정 |
| --- | --- | --- | --- |
| Kilo 게이트웨이 (`kilo/reflection/beam-free`) | `2` | 2.7초 | 정상 |
| OpenCode 제공자 (`opencode/beam-free`) | `2` | 1.0초 | 정상 |

두 경로 모두 정답을 반환했습니다. 같은 날 무료 모델 목록을 다시 수집한 결과 39개 중 신규 3건·제거 2건이 있었고, Beam 무료판은 Kilo 목록에서 신규로 잡혔습니다.

아직 하지 않은 검증도 적어둡니다. 코드 작성과 수정 능력을 재는 자체 평가 12문항에는 이 모델이 아직 포함되지 않았습니다. 품질 판단은 다음 평가 차례에 몰아서 하려고 합니다. 지금 단계에서 말할 수 있는 것은 "무료로 호출되고 정상 응답한다"까지입니다.

## 마무리 — Beam Free 를 어디에 쓰면 좋은가

무료라는 사실 자체보다 어느 자리에 넣을 수 있는지가 실전에서 중요합니다. 위에서 확인한 값만 놓고 보면 네 자리가 맞습니다.

- **문서 더미를 통째로 넣고 묻는 작업**: 컨텍스트가 1,048,576 토큰이라 저장소 하나나 문서 묶음을 잘라 붙이지 않고 그대로 넣고 물을 수 있습니다. 같은 작업을 유료 모델로 처리하면 입력 토큰마다 비용이 붙습니다.
- **긴 출력을 한 번에 받는 작업**: 한 번 생성 최대치가 131,072 토큰이라 파일 여러 개를 이어 쓰는 일을 나눠 받지 않아도 됩니다.
- **도구 호출이 들어간 자동화**: 목록상 `tools` 와 `reasoning` 파라미터를 받으므로 파일 읽기·검색 도구를 붙인 실행 흐름의 모델 자리에 넣을 수 있습니다.
- **호출 비용을 0으로 고정해야 하는 반복 실험**: 입력·출력 단가가 0으로 적혀 있으므로 프롬프트를 여러 번 고쳐 가며 돌리는 테스트에서 호출당 비용이 발생하지 않습니다.

반대로 넣지 말아야 할 자리도 분명합니다. 3절에서 본 것처럼 제로 리텐션이 제공되지 않아 프롬프트와 생성 결과가 제공자의 학습에 쓰일 수 있으므로 사내 코드·고객 데이터·개인정보는 넣지 않습니다. 이미지 입력도 받지 않아 화면 캡처를 읽히는 작업에는 쓸 수 없습니다(텍스트만 지원).

품질 판단은 아직입니다. 코드 작성과 수정 능력을 재는 자체 평가 12문항에 이 모델이 들어가면 결과를 이 글에 덧붙이겠습니다.
