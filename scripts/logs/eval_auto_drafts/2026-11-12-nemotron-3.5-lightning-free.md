터미널 두 줄이면 확인됩니다.


우리가 실제로 던진 것은 코드 수정 요청이었습니다. 만료 토큰을 찾는 함수에서 조건이 틀린 코드를 주고 고치라고 했더니, 아래처럼 고친 코드를 냈습니다.

```python
from datetime import datetime, timedelta

def get_expired_tokens(tokens, now):
    return [t for t in tokens
            if datetime.fromisoformat(t['expires_at']) < now]
```

이 문항은 제출한 코드를 실제로 실행해 판정했습니다 — 눈으로 읽고 점수를 준 것이 아닙니다.

## 어디서 걸리는가

12문항 중 4문항은 점수를 받지 못했습니다.

- **Q1 · 지시 이행** — 채점기 오탐입니다. 답변은 한국어로 쓰고 마지막 줄에 `---끝---`도 넣었는데, 본문에 코드 식별자(`add`)가 있어 '영문 3자 이상' 규칙에 걸렸습니다.
- **Q4 · 코딩 실무** — 측정 오염입니다. pytest 테스트를 새로 쓰라는 요청에 이 저장소의 기존 테스트 파일을 찾아 읽고 "이미 14개 테스트가 있다"고 답했습니다. 모델이 도구로 저장소를 읽을 수 있어 생긴 오염이라 능력 점수로 볼 수 없습니다.
- **Q11 · 에이전트(계획·도구·복구·판단)** — 채점기 불일치입니다. 4단계 계획은 만들었지만 키 이름을 `dom_screen`·`core_state_model` 로 썼습니다. 질문은 키 이름을 지정하지 않았는데 채점기는 `screen`·`state_model`·`verify` 만 인정합니다.
- **Q12 · 에이전트(계획·도구·복구·판단)** — 채점기 불일치입니다. '쿼리 > 메일 > 버튼' 순서로 우선순위와 근거를 냈지만, 채점기는 '지금/미룸' 두 그룹으로 나뉜 형식을 요구합니다.

한도에 걸리지 않았습니다. 응답도 빨랐습니다 — 문항당 중간값 12초, 최대 97초, 12문항 합계 6분 26초입니다.
