LL Alpha Free는 OpenCode Zen에서 한시적으로 무료로 제공되는 **스텔스 모델**입니다. 제공 업체가 공개되지 않았고, 모델 ID는 `ll-alpha-free`입니다. OpenCode Zen 공식 문서는 이 모델을 이렇게 소개합니다.

> LL Alpha Free is a stealth model that's free on OpenCode for a limited time. The team is using this time to collect feedback and improve the model.
> — [OpenCode Zen 공식 문서](https://opencode.ai/docs/zen/)

모델 등록 정보 기준으로 컨텍스트는 262,144 토큰, 최대 출력은 65,536 토큰입니다. 텍스트만 입력받고, 추론 강도(reasoning effort)를 5단계로 바꿀 수 있습니다. AIK24가 OpenCode CLI로 12문항을 돌려 본 결과는 **12문항 중 4문항 정답**(응답이 온 8문항 기준 4/8)이었고, 가장 큰 제약은 정확도가 아니라 **응답 지연**이었습니다 — 12문항 중 9문항이 60초를 넘겼습니다.

## 1. 공개된 것과 공개되지 않은 것

스텔스 모델이므로 무엇이 확인되고 무엇이 확인되지 않는지를 먼저 나눠야 합니다.

| 구분 | 내용 | 출처 |
| --- | --- | --- |
| 확인됨 | 제공 기간: 한시적 무료 (종료 시점 미공개) | [Zen 문서](https://opencode.ai/docs/zen/) |
| 확인됨 | 스펙: 컨텍스트 262,144 · 출력 65,536 · 텍스트 입출력 · 도구 호출 · 구조화 출력 | [models.dev](https://models.dev/) |
| 확인됨 | 추론 강도: low · medium · high · xhigh · max 5단계 | [models.dev](https://models.dev/) |
| 확인됨 | 가격표: 입력·출력·캐시 읽기·캐시 쓰기 모두 Free | [Zen 문서](https://opencode.ai/docs/zen/) |
| 미공개 | 제공 업체 — 익명. Zen 응답의 소유자 표기도 `opencode`, 모델 DB 설명도 `Best in class local model` 한 줄뿐 | — |
| 미공개 | 가중치·파라미터 수·학습 데이터 | — |

데이터 정책은 Zen의 기본 정책과 다릅니다. Zen은 평소 "제로-retention, 프롬프트를 학습에 사용하지 않음"을 명시하지만, LL Alpha Free는 예외 목록에 이름을 올렸습니다.

> LL Alpha Free: During its free period, collected data may be used to improve the model. Data is retained for 30 days.

**민감한 코드·개인정보를 넣을 모델은 아닙니다.** 같은 이유로 사내 저장소에서 키·토큰·고객 데이터가 포함된 파일을 이 모델에 붙여 넣으면 안 됩니다.

스텔스 무료 모델은 계속 교체됩니다. 스텔스 프로모션으로 풀렸던 Union Alpha 는 무료 기간이 끝나면서 목록에서 빠졌습니다. 2026년 10월 16일 조회 기준 Zen 모델 목록(88종)에 Union Alpha 는 없고, 공식 문서에 stealth 로 표기된 4종(Big Pickle·Space Bunny Free·Cat Jam Free·LL Alpha Free)만 남아 있습니다. 무료 기간은 예고 없이 끝나거나 조건이 바뀝니다.

## 2. OpenCode에서 쓰는 방법

| 항목 | 값 |
| --- | --- |
| 모델 ID (TUI) | `ll-alpha-free` |
| 모델 ID (CLI·에이전트) | `opencode/ll-alpha-free` |
| 표시명 | LL Alpha Free |
| 추론 강도 | low · medium · high · xhigh · max |
| 컨텍스트 | 262,144 토큰 |
| 최대 출력 | 65,536 토큰 |
| 입력 형식 | 텍스트 (이미지 입력 없음) |

### 모델 선택

TUI에서 `/models` 명령을 입력하거나 `Ctrl+X` 다음 `M` 을 눌러 모델 목록을 엽니다. 목록에서 `ll-alpha-free` 를 고르면 됩니다. 키보드 단축키는 [OpenCode 키바인드 문서](https://opencode.ai/docs/keybinds/)에 `model_list` 로 정의돼 있습니다.

### 추론 강도 설정

LL Alpha Free는 같은 질문에도 추론 강도를 low · medium · high · xhigh · max 5단계로 바꿀 수 있습니다. TUI에서는 `Ctrl+T` 로 순환 전환하고, CLI·스크립트에서는 모델 ID 뒤에 `#` 을 붙여 지정합니다.

```bash
opencode run -m opencode/ll-alpha-free#low "이 코드의 버그를 한 줄로 설명해줘"
```

AIK24가 12문항 세트의 1번 문항(한국어 코드 설명 + 마지막 줄에 `---끝---` 출력)을 강도별로 한 번씩 실측한 결과입니다.

| 추론 강도 | 응답 시간 (1회 측정) | 정답 여부 |
| --- | --- | --- |
| `#low` | 28초 | 정답 |
| `#medium` | 188초 | 정답 |
| `#high` | 60초 | 정답 |
| 미지정 (기본값) | 45초 | 정답 |

**강도와 응답 시간은 비례하지 않았습니다.** 같은 문항·같은 조건에서 28초에서 188초까지 흔들렸고, 12문항 평가에서도 편차는 그대로 나타났습니다 — 12문항 중 60초 안에 응답이 온 문항은 3개뿐이었고, 5개는 180초 재시도에서 응답했으며, 4개는 180초 안에도 응답이 없어 분모에서 제외했습니다.

실무에 붙일 때는 **타임아웃을 넉넉히** 잡아야 합니다. 대화형으로 즉답을 받는 용도보다, 결과를 기다려도 되는 작업(배치 요약·형식 변환)에 맞습니다.

### 기본 모델로 지정

매번 선택하지 않으려면 설정 파일에 적어 둡니다. 전체 ID는 `제공자/모델` 형식입니다.

```json
{
  "model": "opencode/ll-alpha-free"
}
```

## 3. 12문항 실측 — 축별 결과

OpenCode CLI에서 4개 축 × 3문항 = 12문항을 실행했습니다(AIK24 내부 하네스, 추론 강도 `#low` 고정, 문항 세트 v1). 응답이 60초 안에 오지 않으면 180초로 한 번 재시도하고, 그때도 오지 않으면 그 문항은 분모에서 제외합니다(하네스 규칙 — 모델 능력 실패가 아니라 호출 실패로 보기 때문).

| 항목 | 결과 |
| --- | --- |
| 종합 | 12문항 중 4문항 정답 (응답이 온 8문항 기준 4/8) |
| 지시이행 (언어·형식·길이) | 2/3 |
| 코딩실무 (버그 수정·테스트·리팩토링) | 0/3 — 1문항 오답, 2문항 응답 실패 |
| 맥락유지 (초반 지시 기억·긴 문서 참조·제약 동시 유지) | 2/3 |
| 역할판단 (계획 수립·단순 변환) | 0/3 — 1문항 오답, 2문항 응답 실패 |

맞힌 4문항은 지시이행 2개(코드 한 줄 설명 + 마커 출력, JSON만 출력)와 맥락유지 2개(긴 문서에서 함수 이름 추출, 앞선 요청 3가지 나열)였습니다. 놓친 문항은 형식 요구가 빡빡한 쪽이었습니다 — "각 문장을 15자 이내로 줄이고 정확히 3줄" 요구에서 첫 줄을 영어 원문 그대로 남겼고, "설명 없이 timestamp 열만 출력" 요구에는 코드블록을 씌워 내보냈습니다. 숫자 두 개를 주고 답하게 한 문항에서는 두 번째 숫자를 빠뜨렸습니다.

응답이 오지 않은 4문항은 코딩실무 2개(테스트 작성, 리팩토링)와 역할판단 2개(6개월 단계 계획, 우선순위 분류)로, 출력이 긴 편에 속하는 문항들입니다. 다만 이것이 강도 설정 때문이라고 단정할 근거는 없습니다 — 같은 조건에서도 응답 시간 편차가 워낙 큽니다(2절 실측).

### 지시를 그대로 지킨 예

"JSON으로만 출력하고 코드블록·설명 문장은 넣지 말 것"이라는 요구에 다음 한 줄만 돌려줬습니다(1점).

```json
{"이름":"김민수","나이":31,"취미":["등산","독서"]}
```

### 형식을 못 맞춘 예

"한국어 문장 3개를 각각 15자 이내로 줄이고, 출력은 정확히 3줄, 각 줄은 '-' 로 시작할 것"이라는 요구에 대한 답입니다(0점).

```
- henceforth
- 검색 증강 생성은 답변
- 회의는 다음 주 수요일
```

줄 수와 시작 문자는 맞췄지만 첫 줄을 영어 원문 그대로 두어 "15자 이내로 줄이라"는 요구를 이행하지 못했습니다.

## 4. 이런 작업에 맞습니다

- 무료로 최신 모델을 써보고 싶지만 유료 결제를 원하지 않는 분
- **짧은 입력·짧은 출력 작업** — 코드 한 줄 설명, 형식 변환(JSON), 문서에서 특정 값 추출. 이번 12문항에서 통과한 유형입니다
- **느린 응답을 기다릴 수 있는 작업** — 배치 요약·변환처럼 타임아웃을 길게 잡아도 되는 파이프라인
- 여러 모델을 같은 문항으로 비교해 보고 싶은 분 — 12문항 세트는 [오늘의 무료 모델 목록](https://emdash.aikorea24.kr/posts/free-models)에 같은 기준으로 정리돼 있습니다

## 5. 솔직한 한계

- **응답 지연이 큽니다.** 12문항 중 60초 안에 응답이 온 문항은 3개뿐이었고, 4문항은 180초 재시도에도 응답이 없었습니다. 즉답이 필요한 대화형 용도에는 맞지 않습니다.
- **제공 업체가 익명입니다.** 문제가 생겨도 책임 소재를 확인할 수 없고, 가중치·학습 데이터도 검증할 수 없습니다.
- **프롬프트가 학습에 사용될 수 있습니다.** 무료 기간 동안 수집된 데이터는 모델 개선에 쓰이고 30일 보관됩니다.
- **종료 예고가 없습니다.** 무료 기간이 끝나면 유료로 전환되거나 목록에서 사라집니다.
- **이미지 입력이 없습니다.** 텍스트 전용입니다.
- 스텔스 모델의 자기 소개는 근거가 되지 않습니다. 모델에게 제공사를 물어 답을 받아도, 그 답은 모델이 즉석에서 만든 것일 수 있습니다.

## 마무리 — 오늘 30분 안에 끝내는 3단계

1. `opencode --version` 으로 OpenCode가 설치돼 있는지 확인합니다. 없으면 [설치 안내](https://opencode.ai/docs/)를 따라 설치합니다.
2. `/models` (또는 `Ctrl+X` → `M`)로 `ll-alpha-free` 를 고르고, `Ctrl+T` 로 추론 강도를 낮게(예: `low`) 맞춥니다.
3. 민감 정보가 없는 파일 하나로 짧은 작업을 맡겨 봅니다. 예: `opencode run -m opencode/ll-alpha-free#low "README.md 를 3줄로 요약해줘"`. 응답이 바로 오지 않아도 60초 안팎은 기다려 보세요 — 이 모델은 60초를 넘기는 일이 흔합니다.

한시 무료 모델은 쓸 수 있을 때 써 두는 것이 남는 장사입니다. 무료 기간이 끝나면 이 글의 사용법은 그대로 남아도 모델은 사라질 수 있습니다. 모델·가격·데이터 정책의 최신 상태는 [OpenCode Zen 공식 문서](https://opencode.ai/docs/zen/)에서 확인하세요.
