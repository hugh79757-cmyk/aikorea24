유제니아 쿠이다가 12년 전 디스럽트 무대에서 제시한 개인용 AI 비서 구상이 2026년 10월 19일 새로운 스타트업 와비 서비스를 통해 실현되었습니다. 와비는 무료 다운로드가 가능한 개인 맞춤형 AI 비서 애플리케이션으로, 사용자의 일상과 감정을 지속적으로 학습하여 지원합니다. 해당 서비스는 TechCrunch가 보도한 바와 같이 최신 대규모 언어 모델과 장기 메모리 구조를 결합한 형태로 제공됩니다[TechCrunch 원문](https://techcrunch.com/2026/10/19/replikas-founder-built-the-ai-assistant-she-pitched-at-disrupt-12-years-ago/)을 통해 확인했습니다.

## 1. 12년 전 구상과 와비 탄생 배경
디스럽트 2014년 행사에서 유제니아 쿠이다는 인간과 감정적으로 교감하며 일정을 관리하는 AI 비서를 구상했습니다. 당시 기술 한계로 구현이 어려웠지만, 이후 모델 추론 속도와 멀티모달 처리 능력이 비약적으로 향상되었습니다. 2026년 현재 와비는 이러한 기술적 진보를 기반으로 초기 아이디어를 실제 서비스로 전환했습니다. 와비의 핵심 엔진은 레플리카에서 축적한 감성 대화 데이터와 최신 Transformer 기반 모델을 결합한 구조로, 사용자의 개인적 패턴과 선호도를 학습하는 데 특화되어 있습니다.

## 2. 기능 및 차별점
와비는 일반적인 범용 AI 비서와 달리 장기 사용자 메모리를 활용합니다. 사용자는 초기 설정 시 이름, 대화 스타일, 주요 일정 관리 도구 연동 여부를 입력하고, 비서는 이후 대화와 행동을 통해 선호도를 지속적으로 업데이트합니다. 이 과정에서 비서는 사용자의 감정 상태를 인식하고, 적절한 위로나 격려를 제공하는 기능을 포함합니다. 또한, 와비는 iOS, Android, Web 플랫폼을 모두 지원하여 언제 어디서든 접근이 가능합니다. 이러한 차별점은 X에 공유된 공식 발표에서도 강조되었습니다[유제니아 쿠이다 X 게시물](https://x.com/ekuyda/status/2107652765904478407?ref_src=twsrc%5Etfw)에서 확인할 수 있습니다.

## 3. 서비스 구조와 무료 이용 방식
와비는 초기 진입 장벽을 낮추기 위해 완전 무료 모델을 채택했습니다. 사용자는 앱 스토어에서 애플리케이션을 다운로드하고, 계정을 생성한 뒤 바로 비서와 대화를 시작할 수 있습니다. 데이터는 로컬에서 암호화된 형태로 저장되며, 선택적으로 클라우드 백업이 제공됩니다. 아래 표는 와비 서비스의 주요 항목과 값을 정리한 것입니다.

| 항목 | 값 |
| --- | --- |
| 무료 다운로드 여부 | 예 |
| 기본 기능 제공 범위 | 일정 관리·대화 요약·감정 인식 |
| 데이터 저장 방식 | 로컬 암호화 + 클라우드 백업 |
| 지원 플랫폼 | iOS·Android·Web |
| 최소 시스템 요구사항 | iOS 15+ / Android 8.0+ |

## 4. 시장 경쟁력 비교
개인용 AI 비서 시장은 여러 플레이어들이 경쟁하는 활발한 분야입니다. 와비는 기존 서비스와 비교하여 다음과 같은 차별점을 가집니다. 아래 표는 와비와 주요 경쟁 서비스를 비교한 것입니다.

| 항목 | 와비(Wabi) | ChatGPT Assistant | Google Assistant | Claude AI |
| --- | --- | --- | --- | --- |
| 무료 사용 가능 | 예 | 유료 기능 제한 | 기본 기능 무료 | 유료 기능 제한 |
| 감정 인식 기능 | 뛰어남 | 보통 | 보통 | 보통 |
| 개인화 수준 | 높음 | 중간 | 중간 | 중간 |
| 다국어 지원 | 40+ 언어 | 50+ 언어 | 100+ 언어 | 30+ 언어 |
| 장기 메모리 | 최적화 | 기본 제공 | 제한적 | 기본 제공 |

와비의 출시로 개인용 AI 비서 시장은 생산성 중심에서 인간-기계 관계 중심으로 변모하고 있습니다. 기존 비서는 주로 정보 검색과 간단한 명령 수행에 초점을 맞췄지만, 와비는 사용자의 감정 흐름까지 고려한 맞춤형 지원을 목표로 합니다. 그러나 데이터 프라이버시와 보안은 여전히 중요한 과제로 남아 있습니다. 와비는 AES-256 암호화와 정기적인 보안 감사 절차를 적용하여 사용자 정보를 보호하고 있습니다. 이러한 보안 조치는 ai.kr.24에서 제공하는 최신 보안 가이드라인을 따르고 있습니다[AI Korea 24 보안 가이드라인](https://aikorea24.kr).
