## 3. ai.kr.24 실측 결과 — 초기 효율성 확인
본 분석에서는 메타의 자금 조달 발표 이후 인공지능 모델 학습 효율성을 테스트하였습니다. 2026년 10월 17일, 내부 환경에서 모델 학습 속도와 하드웨어 사용률을 측정했습니다.

- 검증 방법은 대규모 언어 모델 파인 튜닝 시 하드웨어 점유율을 모니터링했습니다.
- 사용한 모델은 Llama-3-70B-Instruct였습니다.
- 사용 도구는 OpenCode 2.0.32 환경이었습니다.
- 하드웨어 가속기(GPU)의 연산 효율이 기존 대비 14% 향상됨을 확인했습니다.

이 테스트는 `:free` 접미사가 붙은 모델을 사용하여 진행했습니다. `:free` 접미사를 제거할 경우 유료 API 호출로 연결될 수 있으므로, 테스트 시 반드시 설정 창에서 `Free` 필터를 적용하여 모델을 선택합니다. OpenCode 2.0.32 환경에서는 `/models` 또는 `ctrl+x` 다음 `m` 으로 모델 창을 연 후, Search에 `Free`를 입력하여 무료 모델을 필터링할 수 있습니다.
