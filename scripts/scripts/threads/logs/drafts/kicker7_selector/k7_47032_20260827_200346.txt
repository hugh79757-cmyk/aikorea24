구글이 실시간 음성 인식 및 자동 교정 모델인 '제미나이 3.5 트랜스크라이브'를 에 출시했음.

이 모델은 사용자의 자연스러운 말하기 방식을 포착하여 음성을 텍스트로 변환하는 기능을 수행함. 현재 구글 AI 스튜디오와 제미나이 엔터프라이즈 에이전트 플랫폼에서 사용할 수 있음.
---
제미나이 3.5 트랜스크라이브는 85개 언어를 자동으로 인식함. 스트리밍 음성 인식 시 단어 오류율(WER)은 4.0%이며, 녹음된 음성 인식 시 단어 오류율(WER)은 2.6%를 기록함. 또한 이전 모델인 Chirp 3 대비 70% 감소한 지연 시간을 구현했음.
---
이 모델은 말실수를 자동으로 교정하고 '음'과 같은 불필요한 추임새를 제거하며 텍스트를 스스로 서식화함. 기능 호출(Function calling)을 통해 이미지 생성이나 웹 검색과 같은 작업을 다른 제미나이 모델로 전달하는 자동화 생태계를 확장함. 실시간 스트리밍을 위한 라이브 API와 녹음된 음성을 처리하는 인터랙션 API 등 두 가지 인터페이스를 제공함.
---
안드로이드용 지보드(Gboard)의 '램블러' 기능과 macOS용 제미나이 앱에 이미 내장되어 있음. 크롬 브라우저에 대한 지원도 곧 시작될 예정임. 램블러는 사용자가 말하는 내용을 실시간으로 텍스트로 변환하며, 문장 중간에 발생하는 수정 사항이나 언어 전환을 문맥 손실 없이 처리함.
