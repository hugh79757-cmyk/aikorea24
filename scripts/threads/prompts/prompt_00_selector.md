# 0단계 - 소재 선별 + 형식 선택 (절대 생략 금지)

여러 기사가 주어지면, 아래 기준으로 먼저 평가할 것.

## 좋은 소재의 조건
- 이름이 있는 사람이 "구체적인 행동"을 한 기록이 있는가
  (전화를 걸었다, 편지를 보냈다, 욕을 했다, 사직했다, 맞섰다, 백기를 들었다 등)
- 그 행동에 감정이 묻어나는가 (분노, 배신, 항복, 아이러니, 후회)
- 인물 간의 관계나 입장 차이가 있는가 (누가 누구를 겨눴는가)

## 나쁜 소재의 신호
- "~를 발표했다", "~가 출시됐다", "~퍼센트 증가했다" 같은
  보도자료성 사실만 있고, 누가 무엇을 느꼈거나 했는지가 없음
- 등장인물이 "회사", "정부", "업계" 같은 익명 집단뿐임

## 판단 후 행동
- 여러 소재 중 "인물의 행동 기록"이 있는 것을 최우선으로 선택할 것.
- 선택한 소재에 인물은 있지만 디테일이 부족하면, 추가 검색으로 다음을 찾을 것:
  -- 그 인물이 직접 한 말 (인용)
  -- 그 인물의 구체적 행동과 시간/순서
  -- 그 행동에 영향받은 다른 인물의 반응
- 검색해도 인물의 행동이 안 나오는 소재라면:
  "이 소재는 인물 행동이 없어서 스토리텔링보다 분석글에 적합함.
   분석형으로 진행할까, 다른 소재를 쓸까?" 라고 먼저 물을 것.

## 형식 선택 기준 (4가지)

### 형식 A — 탐사형 스토리텔링 (8개 카드)
**조건:** 아래를 모두 만족해야 함
- 등장인물이 "이름이 있는 사람"이고
- 그 사람이 "구체적인 행동"을 했으며 (전화, 사직, 맞섬, 백기 등)
- 행동에 감정(분노/배신/항복/아이러니/후회)이 묻어나고
- 인물 간 관계/입장 차이가 명확함 (누가 누구를 겨눴는가)

**부적합 신호:** 인물 없음, 행동 없음, 감정 없음, 단순 발표/출시

### 형식 B — 구조 분석형 (8개 카드)
**조건:** 아래 중 하나라도 만족
- 정부/기관의 정책 발표나 규제 변화
- 산업 구조, 시장 점유율, 경쟁 구도 분석
- 복수 기업/국가 간 비교가 핵심인 소재
- "A처럼 보이지만 실제로는 B" 구조가 명확한 데이터 기반 스토리
- 숫자/통계/데이터가 스토리의 중심

**부적합 신호:** 인물의 구체적 행동이 스토리의 중심, 단순 제품 출시 보도

### 형식 C — X 쓰레드형 (7개 트윗)
**조건:** 아래 중 하나라도 만족
- 짧은 뉴스 브리핑 / 긴급 속보
- 단순한 제품 출시나 서비스 발표
- 전개할 복잡한 맥락이나 반전 구조가 없음
- 7개 트윗으로 요약 가능한 단순 메시지

**부적합 신호:** 깊이 있는 분석 필요, 인물 행동 스토리 존재, 복수 계층의 반전

### 형식 D — 펀치 브리핑형 (5개 카드) ← 기본값
**조건:** 위 A/B/C 중 어느 것에도 명확히 해당하지 않을 때 사용
- 상식충돌 구조는 있지만 인물 행동이 중심이 아님
- 숫자/데이터가 풍부하고 punch-style 훅에 적합
- 5개 카드로 간결하게 전달할 수 있는 내용
- A/B/C의 조건을 부분적으로 만족하지만 어느 하나에 완전히 들어맞지 않음

**D를 선택해야 하는 경우의 예:**
- "분석은 필요한데 인물도 있고 데이터도 있는 복합 케이스"
- "스토리텔링만큼 극적이지는 않지만 X 쓰레드만큼 얕지도 않음"
- "A/B/C 중 두 개 이상의 조건이 비슷한 비중으로 섞여 있음"

## 형식 선택 우선순위
1. A 조건 만족 → A
2. A 불만족, B 조건 만족 → B
3. A/B 불만족, C 조건 만족 → C
4. 모두 불만족 또는 두 개 이상 혼합 → D

## 글 작성 전 반드시 먼저 제시할 것
핵심 논지: [한 줄]
선택 형식: [A/B/C/D] — [이유 한 줄]
