# 공통 문체 규칙 (모든 형식 A/B/C 적용)

## 문장 규칙
- 문장은 짧게. 한 문장 최대 20자 내외
- 숫자는 반드시 포함. 비교 가능한 단위로 환산
  (상암축구장 면적의 몇 배, 한반도 크기의 몇 배, 한강 유량의 몇 배 등)
- 전문 용어는 쓰되, 바로 다음 줄에 쉬운 말로 풀어줄 것
- 마지막 문장은 항상 선언형 ("이유가 있었음", "차이임", "없음")

## 톤 & 스타일
- 이모지 없이, 담담하고 냉정한 분석가 톤 유지
- "~로 분석됩니다", "~의미입니다" 같은 분석가 어휘 금지
- 직접 인용은 절대 다듬지 말고 날것으로
- 형용사 최소화. 사실 진술만
- 각 카드는 "정보 하나 + 인물의 행동/감정 하나"로 구성

## 절대 금지
- "정리하면", "교훈은" 같은 프레임
- 감탄사, 과장 표현 ("놀랍게도", "충격적으로")
- 볼드, 이탤릭 등 서식
- 중복 표현, 동어 반복
- 해시태그와 본문 혼용 (해시태그는 마지막 트윗 끝에 빈 줄 후 별도 배치)

## 자가 점검 (발행 전 반드시 확인)
- [ ] 1번 카드가 스크롤을 멈추게 만드는가?
- [ ] 모든 카드에 숫자가 있는가?
- [ ] 직접 인용이 다듬어지지 않았는가?
- [ ] 마지막 문장이 선언형인가?
- [ ] 이모지가 없는가?
- [ ] 형용사가 최소화되어 있는가?
- [ ] 1번 트윗 첫 줄이 15자 이내인가? (형식 C)
- [ ] 모든 트윗이 4줄 이내인가? (형식 C)
- [ ] 3~6번 트윗에 브릿지 문장이 있는가? (형식 C)

## 출처 표기 규칙
- 마지막 카드 CTA 바로 위에 원본 기사 URL 한 줄 표기
- 형식: "출처: [URL]"

## jisang0914 스타일 규칙 (최우선 적용)
- 1번 카드 첫 줄은 반드시 "어제" 또는 구체적 시간으로 시작
- 문장은 5~10자로 극단적으로 분절. 줄바꿈이 리듬임
- 인물 이름 대신 "역할"로 표현 ("세계 4위 부자가", "CIA가 만든 투자사")
- 숫자 바로 옆에 비교 맥락 한 줄 ("산 회사 값의 4배")
- 매 카드 마지막 줄은 결론 대신 불편한 팩트 하나를 툭 던질 것
- 정보 숨기기는 1번 카드뿐 아니라 매 카드마다 적용
- "근데" 를 반전 신호로 적극 활용

## 1번 카드 필수 구조 (가장 중요)
1번 카드는 전체 글의 축약판이어야 함.
아래 요소를 1번 카드 안에 모두 넣을 것:
- 인물 또는 기업의 구체적 행동 한 줄
- 독자가 모르는 반전 질문 한 줄
- 글로벌 vs 한국 대비 한 줄
- 숫자 최소 2개
- 독자 일상과 연결되는 체감 단위 한 줄
  (예: "AI 프롬프트 100단어 한 번에 생수 한 병")
- 마지막 줄은 "이게 단순한 X가 아님" 선언형

나머지 카드는 1번 카드의 각 요소를 하나씩 깊이 파는 구조.
1번 카드에서 정보를 아끼지 말 것. 전부 쏟아낼 것.
