# 형식 A - 탐사형 스토리텔링
> 인물 행동이 있을 때 사용. 총 8개 카드. 카드 번호는 "N / 8" 형식.

## 1번 카드 (장면)
- 가장 충격적이고 구체적인 "장면" 하나로 시작
- 누가, 무엇을, 언제 했는지 영화의 한 컷처럼
- 일반화하지 말고 사건 그대로
- 같은 카드에 "같은 날/직후 ~도 있었음"으로 두 번째 충격을 병렬 배치
- 마지막 줄은 의도적으로 정보를 숨길 것
  예: "그 사이, 누군가 먼저 전화를 걸었음. 그 사람은 아니었음"

## 2번 카드 (공개)
- 1번에서 숨긴 정보를 공개하며 시작
- 인물/조직의 이름, 배경을 구체적으로
- "그 사람이 한 말"을 직접 인용

## 3~5번 카드 (타임라인)
- 사건의 타임라인을 시간순으로 재구성
- 각 카드마다 인물의 행동 + 그 행동의 의도/감정을 한 줄로 짚을 것
  예: "근거 있는 반박이었음. 근데 결과는 백기"
- 인용은 짧고 날것 그대로. 절대 각색하지 말 것
- 인물들이 스스로 쓴 표현, 자조적 표현을 그대로 살릴 것
- 숫자는 비교 가능한 단위로 환산
  (상암축구장 몇 배, 한강 유량의 몇 배, 한반도 크기의 몇 배 등)

## 6번 카드 (한국 연결)
- 사건이 한국 독자와 연결되는 지점을 제시
- 구체적 인물/기관명을 넣을 것

## 7번 카드 (압축)
- 분석하지 말 것
- 타임라인을 한 줄씩 압축해서 재배열
- 각 줄은 "누가 무엇을 했다"로 끝낼 것

## 8번 카드 (결론)
- "다시 처음으로 돌아가서"로 시작
- 1번 카드의 숨긴 정보/질문에 답하는 형식
- 이유를 3~4개 항목으로 정리하되, 각 항목은 인물의 행동/선택을 근거로
- 마지막 문장은 "A와 B, 이 둘의 차이가 이번 사태의 전부임" 구조로
- 출처 + 후속 예고 한 줄
