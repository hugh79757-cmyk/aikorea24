## [TOPIC]
GitHub를 처음 사용하는 사람들을 위한 기초 사용법 가이드

## [FACTS]
- GitHub: 소프트웨어 개발 프로젝트를 위한 웹 기반 플랫폼으로, 협업과 버전 관리를 지원한다.
- Git: 분산 버전 관리 시스템으로, 코드의 변경 이력을 기록하고 관리할 수 있다.
- Repository: 프로젝트의 파일과 변경 기록을 저장하는 공간이다.
- Pull Request: 변경 사항을 검토하고 병합하기 위한 요청이다.
- Branch: 코드의 독립적인 작업 흐름을 관리하는 방법이다.
