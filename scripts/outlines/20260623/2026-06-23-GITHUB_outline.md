## [TOPIC]
초보자를 위한 GitHub 시작 가이드: 기본 사용법부터 프로젝트 관리까지

## [FACTS]
- GitHub: 소프트웨어 개발 프로젝트를 버전 관리하고 협업할 수 있는 플랫폼.
- 사용자 수: 전 세계적으로 5천만 명 이상의 개발자가 사용 중.
- 주요 기능: 저장소 생성, 코드 버전 관리, 협업, 이슈 트래킹, Pull Request 등.

## [TARGET]
GitHub 사용법을 검색하는 독자는 주로 프로그래밍을 처음 배우는 학생, 개발자 커리어를 시작하는 신입 개발자, GitHub를 처음 사용하는 비개발자(예: 디자이너, 프로젝트 매니저) 등이다.
